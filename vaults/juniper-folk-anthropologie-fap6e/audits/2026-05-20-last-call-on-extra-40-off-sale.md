# Last call on extra 40% off sale!
**Score:** 8/10 · **Type:** Email audit · **2026-05-20**
## Executive summary

- This is the urgency-escalation version of the same "EXTRA 40% off sale" creative that ran earlier today (scored 8/10). Anthropologie is doing the right thing with a last-call send — the subject line is tight, the offer is clear, and the scarcity nudge ("There Are So Few, Still…") above the product grid is a smart copy addition. But they've made the mistake of sending the full editorial treatment again rather than a stripped-down deadline-focused email. When a subscriber has already seen six editorial sections — The New Crop, The Color Shop, Phone Charms, Going Analog, Summer Beauty Edit — the second time through, "last call" creative should be a reminder blade, not a re-run.
- The multi-category CTA block (Shop Clothing / Sale Home / Sale Accessories / Sale Dresses / Shop Kitchen & Home) is still the right pattern for Anthropologie's broad assortment. The hero delivers the offer immediately and the visual hierarchy holds. But sending two near-identical full-length emails in one calendar day risks irritating subscribers who are already aware of the sale — the brand history shows four Anthropologie sends in three days, which is starting to feel like saturation.
- Judgment: a competent last-call send undermined by re-using full editorial creative instead of building a lean, deadline-first version. The best element is the scarcity copy in the product grid — it's the only thing that's genuinely new.

## What's working

- **Hero is immediate** — "EXTRA 40% OFF* SALE" lands at the top without any pre-lede friction; offer is visible without a single scroll.
- **Multi-category CTA block is practical** — five distinct buttons let different shopping intents self-select (clothing vs. home vs. accessories), which is smarter than a single "Shop Now."
- **"There Are So Few, Still…" copy** is the one genuinely fresh element vs. the earlier send — it injects real scarcity without sounding fake.
- **Subject line is crisp** — 32 characters, no spam signals, urgency is explicit and unambiguous.
- **No render bugs** — clean layout, images load, buttons are legible throughout the scroll.

## What's weak

- **Full editorial re-run is lazy for a last-call send** — six named editorial sections (The New Crop, Color Shop, Phone Charms, Going Analog, etc.) are unchanged from the earlier email. A subscriber who opened this morning is now being asked to scroll the same grid again.
- **No visible deadline or timestamp** — "Last call" implies urgency but there's no actual end-time (midnight tonight? tomorrow morning?) to make it credible.
- **Top banner is unreadable at render size** — whatever the "exclusive early access" or top-bar copy says is too small to register; it contributes nothing.
- **No personalization** — not a name, not a category, not a "based on your recent purchases" hook — anything to distinguish this from a batch blast.
- **Cadence fatigue risk** — this is the second Anthropologie email today and the fourth in three days. The "last call" urgency is diluted when the brand has been in the inbox constantly.

## Recommendations

- 1. **Strip the editorial, keep the offer** — a true last-call email should be ~40% of this length: hero offer, deadline timestamp ("Ends tonight at midnight"), five category buttons, product grid, done. Drop The New Crop / Color Shop / Going Analog entirely.
- 2. **Add a hard deadline with a clock** — "Sale ends tonight at 11:59 PM ET" converts "last call" from vague urgency to a real decision point. This is the single change that would lift this email most.
- 3. **Lead the product grid with sold-out-adjacent copy** — the "There Are So Few, Still…" line is good; move it above the fold and pair it with low-inventory callouts on specific SKUs.
- 4. **Suppress this send for openers of the earlier today's email** — subscribers who opened the 8/10 send this morning don't need the full re-run; send them a single-CTA blade with the deadline instead.
- **Subject Alt A:** `Ends tonight: extra 40% off sale`
- **Subject Alt B:** `40% off sale — last hours`
- **Preheader Alt A:** `Sale closes at midnight — grab your picks before they sell out.`
- **Preheader Alt B:** `Low stock on favorites. Extra 40% off ends tonight.`

### 3. Rendering & Accessibility

**MSO conditional CSS block — two syntax errors:**
```css
/* line 1 */
body, table, td { font-family: Arial, Helvetica, , 'Font-Normal'; !important; }
```
- Double comma between `Helvetica` and `'Font-Normal'` — malformed `font-family` value; Outlook will fall back to system default.
- `!important` appears after the semicolon, outside the declaration — invalid; the rule silently fails in Outlook 2016+.

**15 images missing `alt` text** — confirmed by QA scan:
- 2× banner images (`emailbanner_pencilline_1.jpg`, `emailbanner_pencilline_2.jpg`, each appearing twice)
- 9× Evergage/Salesforce Interaction Studio personalized recommendation tiles (`summary.png`)
- 1× static content image (`1e313de8...png`)
- 1× Dotomi retargeting pixel (`1_0`)
- 1× MonitorTrack pixel (`003a700000`)

All decorative images should carry `alt=""` at minimum; content-bearing images (banners, product recommendations) require descriptive alt text for screen readers and image-blocking clients.

**Multi-brand CSS bloat** — the stylesheet embeds font and button class definitions for UO, Free People, Beholden, Terrain, and Community alongside Anthropologie's own rules. No rendering breakage, but it adds ~3–4 KB of inert CSS to every send.

### 4. Personalization & Merge Tokens

No unfilled merge token syntax (e.g., `{{first_name}}`, `%%first_name%%`) detected in the truncated source.

Evergage recommendation tiles use `userId=003a700000uTza` in API URLs — consistent with the full Salesforce Contact ID (`003a700000uTzaxAAC`) visible in the MonitorTrack pixel, so truncation appears to be a QA capture artifact, not a production defect.

### 5. Compliance

**`List-Unsubscribe` header — not captured**
QA reports this header absent. Under Google and Yahoo's 2024 bulk sender requirements (>5K sends/day), a `mailto:` or HTTPS `List-Unsubscribe` header is mandatory. If genuinely missing from the envelope, this creates deliverability risk to Gmail and Yahoo inboxes.

**`List-Unsubscribe-Post` (RFC 8058) — not captured**
One-click unsubscribe requires this header paired with a POST-capable endpoint. Its absence means Gmail's native "Unsubscribe" button may fall back to a mailto flow or not render at all.

**Authentication-Results — not captured via AgentMail relay**
SPF/DKIM/DMARC pass/fail status is unknown for this message. Sending domain is `s.anthropologie.com`; relay should be surfacing these results. This is a gap in the QA pipeline's header capture, not necessarily a live authentication failure — but it cannot be ruled out.

**CAN-SPAM physical address** — not verifiable from truncated source; should be confirmed present in footer.
