# Extra 50% Off Sale + 25% Off Designer Denim
**Score:** 6/10 · **Type:** Email audit · **2026-08-28**
## Executive summary

- This is the two-offer stack Anthropologie has been threatening all week, finally combined into one send: "Extra 50% Off Sale" stacked directly on top of "25% Off Designer Denim" — the exact same maroon "Extra 50% Off" block from 8/25 and 8/26, now paired with a new blue denim panel underneath. It's a reasonably clean two-tier hero with two distinct CTAs, and it's honest about the split (online & in-store for the 50% off, online only for denim), which is more transparent than the buried fine print this brand often runs.
- But this is now the fourth-plus time this exact maroon "EXTRA 50% Off* SALE" creative has appeared in my inbox this week (8/25 twice, 8/26, now 8/28), and simply bolting a second offer under it doesn't reset the fatigue — it just makes the email longer. The "limited time!" badge is doing a lot of work with zero date attached, and after a week of "24hrs early," "Starts Now," and now this, the urgency reads as decorative rather than credible.
- Below the hero it's the standard long scroll-to-shop grid with no product-level detail — no prices, no review counts, nothing that would help a specific purchase decision. Solid, on-brand, forgettable execution of a fatigued promo.

## What's working

- Clean two-tier hero: two distinct offers, two distinct CTAs ("Shop Now" x2), no overlapping text or broken images.
- Denim panel is genuinely a new angle for this run — most sends have been pure "Extra 50% Off," this one bundles a category-specific offer.
- Both offers state a concrete number (50%, 25%) rather than vague "big savings" language.
- Color contrast between the maroon and blue blocks creates clear visual separation between the two offers.
- Loyalty/service tiles (AnthroPerks, Klarna, Styling Services) are present near the footer for return shoppers.

## What's weak

- This is a repeat of the same maroon "Extra 50% Off" creative run four times this week (8/25 x2, 8/26, 8/28) — zero visual refresh on the primary hero block.
- "limited time!" badge has no date or countdown, same complaint as 8/25's early-access send — after a week of this, it no longer reads as urgent.
- No product detail anywhere (price, size availability, reviews) — everything below the hero is image-plus-caption only, all links go to category pages, not specific products.
- Nine-image "Made With You In Mind" grid has zero labels or context — no idea what I'm clicking into.
- Subject line crams two offers into one string ("Extra 50% Off Sale + 25% Off Designer Denim") which is long and reads like a merged send rather than a single clear ask.

## Recommendations

- 1. Break the subject into a single clear lead offer instead of stacking two — pick whichever is scarcer (denim, since it's online-only) and let the sale be secondary, since 8/26's single-offer "25% OFF designer denim" subject already scored better (6.00) than this run's average.
- 2. Attach a real deadline to "limited time!" — a date or hour count would fix the credibility gap that's dogged every send this week.
- 3. Add at least category labels to the "Made With You In Mind" grid so recipients know what they're clicking before they click.
- 4. Rotate the hero creative — same maroon block since 8/25 is now visibly stale; even a new photo behind the same offer text would help.
