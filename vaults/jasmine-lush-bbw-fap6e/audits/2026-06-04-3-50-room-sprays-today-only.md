# 🤩 $3.50 room sprays—today only.
**Score:** 9/10 · **Type:** Email audit · **2026-06-04**
## Executive summary

- Bath & Body Works opens a new room spray arc on June 4 — a clean pivot off yesterday's $3.95 lip care send and the closing bell of the $10 single-wick run (June 1–3). The $3.50 price point anchors the hero, the "TODAY ONLY!" yellow banner fires immediately above the fold, and the lemon-citrus product shot communicates summer mood without ambiguity. This is structurally identical to the brand's proven playbook: single-offer launch, time-pressure banner, one SHOP button.
- The problem is the secondary section. "Feels Like a Sweet Time" with what reads as another 3-wick candle offer at ~$14 contradicts the launch energy — subscribers just watched the May 28–31 3-wick arc close out two days ago. It muddies the message and makes the email feel like a clearance sweep rather than a fresh drop.
- The room spray arc itself is well-executed. The secondary offer is unnecessary noise that B&BW should have held for a separate send.

## What's working

- **$3.50 price badge leads** — the number is the first thing the eye lands on after the TODAY ONLY! banner; zero ambiguity about the deal.
- **"TODAY ONLY!" banner placement** is disciplined — it appears immediately below the logo, before any product copy, which creates urgency before the sell.
- **Summer hero imagery** ("Spritz of the Bright Side," lemon/citrus visual) matches the June seasonal moment cleanly.
- **Clean render** — no broken images, no layout bugs, margins consistent throughout.
- **Fresh arc** — room sprays are distinct from every send in the last five days; cadence feels earned, not fatigued.

## What's weak

- **Generic "SHOP" CTA** — misses the chance to reinforce the offer copy ("Shop $3.50 Sprays" does more work).
- **3-wick secondary offer feels like a rerun** — B&BW just closed that exact arc on June 3 ("today's the last hurrah for $10 single wicks"); reviving 3-wicks in the same week as a buried secondary offer is confusing.
- **"TOP OFFERS" grid dilutes focus** — six small thumbnails after the hero pulls the eye in six directions; the room spray launch gets lost in product noise.
- **No scent names in the hero** — "Spritz of the Bright Side" is a fun tagline but doesn't tell you *which* room spray, which makes the CTA feel undirected.

## Recommendations

- 1. **Kill or defer the 3-wick secondary section.** One price arc per send. If 3-wicks need to move, give them their own dedicated send tomorrow.
- 2. **Rename the CTA to "Shop $3.50 Sprays"** — six extra characters that double the click pull.
- 3. **Name at least one hero scent in the product section** — "Bright Citrus Squeeze — $3.50 today only" gives subscribers something specific to want.
- 4. **Replace the "TOP OFFERS" grid with 2–3 cross-sells anchored to the room spray vibe** — "pairs well with these candles" or "complete the scent story" keeps the moment cohesive.
- **Subject Alt A:** `Your home smells like summer for $3.50 — today only`
- **Subject Alt B:** `$3.50 room sprays just dropped — grab yours`
- **Preheader Alt A:** `New summer scents. Same shocking price. Shop before they're gone.`
- **Preheader Alt B:** `Spritz the Bright Side into every room — $3.50, today only.`

## Technical Audit — Bath & Body Works `$3.50 room sprays` (2026-06-04)

### 1. Technical Summary

Email is built on Salesforce Marketing Cloud (SFMC) with standard click-redirect tracking via `click.e2.bathandbodyworks.com`. Three structural issues require remediation: content rendered outside the `<body>` tag, two broken image `src` attributes, and missing RFC 8058 one-click unsubscribe support.

---

### 2. Link & Tracking Issues

**25 click-redirect links** all pass through `click.e2.bathandbodyworks.com` — standard SFMC redirect; links themselves were not probed by QA.

**Open pixel** present:
```
https://click.e2.bathandbodyworks.com/open.aspx?EYJP23J3YWKENLNJWTXAOXFCG4.70251&d=70251&bmt=0
```
Pixel has `alt=""` — acceptable for a decorative 1×1.

**Everest engagement tracker** also present as a secondary pixel:
```
src: https://bbwus.everestengagement.com/ea/fw0q51vctP/?e=200511831233&c=060426_RDM_CRS_350CRSEE_NS_BAL_V1
```
This image is missing `alt` text (flagged by QA). Tracker pixel should carry `alt=""` explicitly.

**Two images with empty `src` attributes** — QA flagged two `<img>` tags where `src=""`. These render as broken images in most clients and may generate spurious HTTP requests to the current page URL.

---

### 3. Rendering & Accessibility

**Critical: Content placed outside `<body>`**

A variable-initialization `<table>` block appears between `</head>` and `<body>`:
```html
</head>
<!-- `date "+ET%m.%y"` -->
<table ... class="stylingblock-content-wrapper"> <!-- ← outside body -->
  <tr><td><!--Set variables to support dynamic template attributes--></td></tr>
</table>
<body style="...">
```
This is invalid HTML. Browsers and email clients will attempt to recover but behavior varies — Outlook in particular may mishandle anything outside `<body>`. The SFMC slot placeholder `<div data-type="slot" data-key="gvhu7dvhmx9">` is also in this block and commented out, suggesting a build artifact that wasn't cleaned up.

**Unstripped build comment** — visible in rendered HTML:
```html
<!-- `date "+ET%m.%y"` -->
```
This shell-template stub appears twice (before and after the out-of-body table). It was never resolved and leaks build tooling details.

**Missing alt text on content image:**
```
src: https://image.e2.bathandbodyworks.com/lib/fe9213737561047a72/m/1/418d0db7-5a65-43cb-b5c9-9c6c142e4fd2.png
```
This appears to be a visible content image (not a tracker), requiring descriptive alt text for screen readers and images-off rendering. QA flagged it; no alt attribute present.

**Preheader padding characters** — the hidden preheader filler block uses `&#847;`, `&zwnj;`, `&nbsp;`, `&#8199;`, `&shy;` sequences for inbox preview padding. This is a known technique but the sequence is unusually long and some characters (`&#847;` — Mongolian vowel separator) may render visibly in niche clients.

**`<meta charset>` placement** — the `Content-Type` meta appears after the MSO conditional comment block but is still within `<head>`, which is acceptable.

---

### 4. Personalization & Merge Tokens

No unresolved merge tokens (e.g., `%%FirstName%%`) visible in the truncated source — positive signal.

However, AMPscript logic comments are present in rendered HTML:
```html
<!--Adds daily APT set via ampscript. Adds preset APT for emails flagged NTF-->
<!--Set APT for NTF campaigns, otherwise respect email-defined APT-->
<!--If @NTF_Flag is "N", @APT should be set in the email; no default fallback here-->
```
These expose internal variable names (`@NTF_Flag`, `@APT`) and campaign segmentation logic to anyone viewing source. Strip or move to AMPscript `%%[ /* comment */ ]%%` blocks before rendering.

### 5. Compliance

| Check | Status | Evidence |
|---|---|---|
| `List-Unsubscribe` header | **WARN** | Not captured by AgentMail relay; may be present at SMTP level but unverifiable |
| `List-Unsubscribe-Post` (RFC 8058) | **FAIL** | Not found — required for Gmail/Apple one-click unsubscribe for bulk senders |
| SPF/DKIM `Authentication-Results` | **WARN** | Not captured via relay; sending domain `e2.bathandbodyworks.com` should have DKIM configured in SFMC |
| Physical address | Not verifiable from truncated source — must confirm footer contains mailing address per CAN-SPAM §5(a)(5) |
| Unsubscribe mechanism | 25 links present; unsubscribe link existence not individually confirmed from truncated source |

**RFC 8058 one-click unsubscribe is the actionable gap.** Gmail began enforcing this for bulk senders (>5k/day) in February 2024. SFMC supports it via `List-Unsubscribe-Post` header configuration in the send definition.

---

### 6. Email-to-Site Continuity

All 25 click links pass through `click.e2.bathandbodyworks.com` redirects, so destination URLs and UTM parameters cannot be directly inspected from source. The Everest tracker URL contains a campaign code:
```
c=060426_RDM_CRS_350CRSEE_NS_BAL_V1
```
This suggests campaign attribution is configured. Verify that redirect destinations append consistent UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) — SFMC click-redirect chains can silently drop UTMs if the final destination URL isn't explicitly tagged before wrapping.
