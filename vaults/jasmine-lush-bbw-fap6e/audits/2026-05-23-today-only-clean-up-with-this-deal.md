# today only: clean up with this deal. 🙌
**Score:** 7/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- This is B&BW's "clean pun" send — hero is All Foaming Hand Soaps at $3.50 TODAY ONLY, and the subject-to-hero link is tight: "clean up with this deal" → "A Clean Splash" → hand soaps with code B3050 printed in the email. That's good editorial discipline. The problem is everything wrapped around it.
- B&BW has stuffed three separate deals — hand soaps (today only), BOGO candles (limited time), and BUY 3 GET 3 body care (48 hours) — into a single send with identical "SHOP" buttons and zero visual weight differentiation. The eye lands on the hero, then immediately fractures across two more equal-rank sections. The candle BOGO is the more damaging problem: it ran as the featured hero two days ago (5/21 "all candles BOGO" send, scored 8/10). A subscriber who opened that email already processed this deal. Recycling it as section 2 of a hand soap email makes this feel like a weekly deals digest, not a campaign beat.
- The email is clean, functional, and on-brand — nothing broken. But compared to the 8-9/10 flash sends earlier this week, it's diluted by its own ambition to do three things at once.

## What's working

- "TODAY ONLY!" banner sits at the crown of the hero — scarcity framing established before a single body word is read.
- Subject–hero alignment is cohesive: the "clean up with this deal" pun carries through to "A Clean Splash" headline and hand soap imagery.
- Promo code B3050 is printed visibly in the hero section, reducing checkout friction vs. relying on auto-apply.
- The BUY 3 GET 3 body care deal in section 3 is genuinely strong value on its own terms.
- "Kick off summer with" framing is consistent across all three sections, giving thematic unity despite the deal sprawl.
- BOGO candles (section 2) is near-identical to the 5/21 hero offer — any subscriber who opened that email two days ago is looking at a recycled deal dressed in the same seasonal language.
- Three "SHOP" buttons of identical visual weight give the eye no hierarchy — the email is three ads in a trench coat.
- "SHOP" is the weakest possible CTA copy: no object, no pull, no reason to click this one vs. the other two.
- The "TOP OFFERS" category grid below the fold adds visual noise without tying back to any specific deal above it.
- The 48-hour window on body care vs. "today only" on hand soaps creates competing urgency clocks the design does nothing to distinguish.

## Recommendations

- 1. **Hero one deal and drop the candle BOGO entirely from this send.** It ran 48 hours ago. Reserve it for the "final hours" send or let it breathe a full campaign cycle before repeating. Let hand soaps own this email.
- 2. **Rewrite all three CTAs with verb + noun copy.** "Shop Hand Soaps" / "Claim Your Free Candle" / "Buy 3, Get 3 Free" — each one tells the shopper exactly what happens on click. "SHOP" does none of that work.
- 3. **Put the price in the subject.** "$3.50 hand soaps today only" outperforms the pun on both open intent and purchase conversion. Save the pun for the hero headline where it belongs.
- 4. **Give the 48-hour BUY 3 GET 3 body care deal its own send.** It's a strong enough mechanic to headline standalone — burying it in section 3 here is a waste.
- **Subject Alt A:** `$3.50 foaming hand soaps, today only. 🧼`
- **Subject Alt B:** `clean up with $3.50 hand soaps — today only.`
- **Preheader Alt A:** `Use code B3050 in-store or online — ends tonight.`
- **Preheader Alt B:** `Plus BUY 3, GET 3 FREE on body, skin & hair care.`

## Technical Audit

## Technical Audit — Bath & Body Works "today only: clean up with this deal"

---

### 1. Technical Summary

The email is structurally malformed (content rendered before `<body>` opens) and carries several unresolved template artifacts in the HTML source. Compliance headers are absent from the QA-captured relay copy, and three images lack alt text.

---

### 2. Link & Tracking Issues

**25 click-redirect links** all route through `click.e2.bathandbodyworks.com` — QA skipped HTTP probes on all of them. Destination UTM parameters and landing page validity are unverifiable from this capture.

**Third-party engagement tracker embedded as image:**
```
src: https://bbwus.everestengagement.com/ea/fw0q51vctP/?e=200511831233
     &c=052326_RDM_HS_350FOAMINGHSEE_NS_BAL_V1
```
This is an Everest Engagement pixel used as an `<img>` tag with no `alt` attribute (flagged by QA). It constitutes a second, undisclosed tracking layer beyond the native BBW open pixel at `click.e2.bathandbodyworks.com/open.aspx`.

**Open pixel** `click.e2.bathandbodyworks.com/open.aspx?IJKDG5N5HIAEVONN5J4ZHCBSFA.70250` uses `alt=""` — acceptable for a 1×1 tracking pixel.

---

### 3. Rendering & Accessibility

**Malformed document structure — content rendered before `<body>` tag opens:**
```html
</head>
<!-- `date "+ET%m.%y"` -->         ← outside body
<table ...>...</table>              ← outside body
<!-- `date "+ET%m.%y"` -->
<body style="...">                  ← body opens here
```
A `<table>` wrapping the preheader and a slot comment block are emitted after `</head>` but before `<body>`. Most email clients are tolerant, but Outlook and strict parsers may mishandle it.

**DOCTYPE is HTML 4.01 Transitional**, not HTML5. Acceptable for legacy email client compatibility but worth noting if templates are being modernized.

**Three images missing `alt` text (QA confirmed):**
| src | issue |
|-----|-------|
| `image.e2.bathandbodyworks.com/…/418d0db7…png` | `alt` attribute absent |
| *(empty src)* | `alt` absent + broken `src` |
| *(empty src)* | `alt` absent + broken `src` |
| `bbwus.everestengagement.com/ea/fw0q51vctP/…` | `alt` absent (tracking pixel) |

The two images with empty `src` values will produce broken image requests and console errors. These may be unfired dynamic slots or deleted content blocks with residual markup.

---

### 4. Personalization & Merge Tokens

**Unresolved AMPscript logic comments are visible in rendered HTML source:**
```html
<!--Adds daily APT set via ampscript. Adds preset APT for emails flagged NTF-->
<!--Set APT for NTF campaigns, otherwise respect email-defined APT-->
<!--If @NTF_Flag is "N", @APT should be set in the email; no default fallback here-->
```
These are implementation notes embedded as HTML comments — they expose internal template logic (APT = Audience Priority Token, NTF = New-to-File segmentation flag) to anyone viewing source. They should be stripped at render time or moved to the SFMC template layer.

**Shell command literal leaked as HTML comment (appears twice):**
```html
<!-- `date "+ET%m.%y"` -->
```
This is a bash command that was never executed — it appears verbatim as a comment. Likely a developer placeholder from a build script that was never wired up. No functional impact, but it is an information leak about internal tooling conventions.

**Slot placeholder left in source (commented out but present):**
```html
<!-- <div data-type="slot" data-key="gvhu7dvhmx9" data-label="Preheader"></div> -->
```
Commented-out slot definition suggests a content block was removed post-build rather than cleanly excised from the template.

---

### 5. Compliance

**`List-Unsubscribe` header absent** (QA: WARN). Gmail and Yahoo require this header for bulk senders (>5k/day). Its absence at the relay layer means one-click unsubscribe in Gmail's UI will not function — users must navigate to the in-email link instead.

**`List-Unsubscribe-Post` header absent** (QA: WARN, RFC 8058). Required for Gmail's native one-click unsubscribe button introduced in 2024. Non-compliance risks inbox placement penalties from Google.

**`Authentication-Results` header not captured** (QA: WARN). SPF/DKIM/DMARC pass/fail status is unknown for this copy. The sending domain `e2.bathandbodyworks.com` is an ESP subdomain — alignment should be verified against BBW's DMARC policy.

CAN-SPAM physical address and unsubscribe link: not verifiable from truncated HTML, but the email template structure includes an in-body unsubscribe mechanism (standard for BBW/SFMC). No issues confirmed from available source.

All 25 destination URLs are wrapped by `click.e2.bathandbodyworks.com` redirects — UTM parameters cannot be confirmed without following the redirect chain (blocked by QA policy on tracking domains). Specifically unverifiable:
