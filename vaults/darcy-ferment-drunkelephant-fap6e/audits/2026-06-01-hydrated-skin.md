# Hydrated skin
**Score:** 9/10 · **Type:** Email audit · **2026-06-01**
## Executive summary

- After a fourteen-email Friends & Family blitz that ended May 28, and a product launch for the Littles 8.0 kit on May 30, this email continues the content reset: no countdown timer, no fake deadline, just clean ingredient storytelling for the B-Hydra Intensive Hydration Serum. That tonal discipline is the right call. The "PLEASE HYDRATE RESPONSIBLY" headline is the best pun in recent Drunk Elephant creative, and the mid-email ingredient callouts — Pro-Vitamin B5, Sodium Hyaluronate, Pineapple Extract — give a skincare enthusiast an actual reason to read rather than just scroll for a promo code.
- The fatal mistake is the subject line. "Hydrated skin" is thirteen characters of category, not an offer, not a hook, not a reason to open. This email earns its clicks on brand loyalty and nothing else. Every element inside the email earns conversion; the subject line will strangle the open rate before subscribers get there.
- The secondary fumble: the 10% Off Club code is real value, but it's displayed in a small header block so visually light it reads like a receipt number. If Drunk Elephant is building a loyalty tier, it should feel like a privilege, not a footnote.

## What's working

- "PLEASE HYDRATE RESPONSIBLY" is genuinely clever brand voice — stops the scroll without being gimmicky.
- Ingredient callouts name both the ingredient and its specific skin benefit, which is the right formula for a premium skincare audience.
- The social proof block (97% smoother, 93% more hydrated, 93% more radiant) lands at exactly the right moment — after you've read the promise, before you're asked to buy.
- "B-HYDRA PLAYS WELL WITH OTHERS" is a soft upsell that creates basket-building context without feeling pushy.
- "Perfect for summer" is a timely hook that doesn't feel forced.

## What's weak

- "Hydrated skin" as a subject line gives subscribers no inbox reason to open — it names the category, not the opportunity.
- The 10% Off Club code is effectively hidden: tiny font, no CTA connection, no benefit language around it.
- No urgency mechanism whatsoever; after a blitz series built on fake deadlines, subscribers have no trained reason to act today.
- The "SUMMER SKIN, SORTED" footer product grid creates multi-product decision friction right before the exit — dilutes the B-Hydra focus.

## Recommendations

- 1. **Rewrite the subject line.** "Hydrated skin" fails every inbox signal. Lead with the hook that already exists in the body copy.
- **Subject Alt A:** `Thirst place is not a podium`
- **Subject Alt B:** `Your skin is thirsty. B-Hydra fixes that.`
- 2. **Make the 10% code feel like a benefit, not a barcode.** Move it immediately below the hero CTA, full-width, with language like "Your 10% Off Club discount is always applied." Right now subscribers may click, add to cart, and never use it.
- **Preheader Alt A:** `Your 10% is ready — meet your new summer hydration essential`
- **Preheader Alt B:** `For thirst place: B-Hydra + your member 10% waiting at checkout`
- 3. **Replace the footer product grid with a single pairing recommendation.** The "B-HYDRA PLAYS WELL WITH OTHERS" section already does the upsell work mid-email. The grid at the bottom duplicates and dilutes — cut it to one featured pairing with a specific CTA.
- 4. **Add soft urgency without a countdown timer.** Something like "formulated for summer, ships in 2–3 days" or a "batch freshness" signal creates reason to act without repeating the F&F clock fiasco.

### 3. Rendering & Accessibility

**[HIGH] HTML comment syntax inside CSS block — rules silently dropped**

Inside the `@media only screen and (max-width: 600px)` block:

```css
<!-- *[class=contenttable] { width:414px !important;} -->
<!-- *[class=mobile] { width:414px !important;height: auto !important;} -->
```

`<!--` / `-->` is HTML comment syntax, not CSS comment syntax (`/* */`). CSS parsers treat these as parse errors and drop the rules entirely. The `contenttable` and `mobile` responsive width overrides are non-functional on all clients.

---

**[MEDIUM] Duplicate font loading — `<link>` tags AND `@import` for same URLs**

The three `onlinewebfonts.com` font URLs are loaded twice: once via `<link rel="stylesheet">` in `<head>`, and again via `@import url(...)` inside the `<style>` block. This doubles HTTP requests against a third-party CDN on every open.

Affected URLs:
- `https://db.onlinewebfonts.com/c/4150d76a852e1c349e0b6fe15f29d9ca?family=Brown+Bold`
- `https://db.onlinewebfonts.com/c/6145ed704c26a497680e82c477f40b46?family=Brown-Light`
- `https://db.onlinewebfonts.com/c/68d0f9847ef9a5695d6efa71521067ec?family=Brown-Thin`

---

**[MEDIUM] `-webkit-text-size-adjust: none` — disables all text scaling**

```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none;}
```

`none` fully prevents the OS from scaling text on mobile, including for users who have set a larger system font size for accessibility reasons. Should be `100%`.

---

**[MEDIUM] `maximum-scale=1` in viewport meta**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Disables pinch-to-zoom on mobile. Accessibility failure (WCAG 1.4.4). Remove `maximum-scale=1`.

---

**[LOW] Universal `line-height: 100%` override**

```css
*{line-height: 100%}
```

Applying `line-height: 100%` to every element via universal selector causes text clipping on descenders in several email clients (notably Outlook 2016+, Gmail Android). Should be scoped to specific selectors.

---

**[LOW] Inconsistent font source strategy**

`BrownRegular` loads from self-hosted Demandware static (`drunkelephant.com/on/demandware.static/...`). `BrownBold`, `BrownLight`, `BrownThin` load from `db.onlinewebfonts.com` — a third-party CDN with no SLA guarantees. Font rendering will be inconsistent if that CDN has availability issues at send time.
