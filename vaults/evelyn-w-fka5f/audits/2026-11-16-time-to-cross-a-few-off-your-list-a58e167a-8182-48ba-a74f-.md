# Time to cross a few off your list
**Score:** 7/10 · **Type:** Email audit · **2026-11-16**
## Executive summary

- This is a Black Friday countdown send that works as a social-proof bestseller roundup. The navy banner, "BUY ONE, GET ONE 50% OFF" with a "20% OFF A SINGLE PAIR" fallback, is the strongest element and lands first. The five-star "WISH LIST WORTHY" hero then shifts the email from offer to curation. The Women's, Men's and Kids' blocks each show one hero shoe, a star rating, a review count and a customer quote. That structure is clean and easy to scan.
- The weakness is that every CTA says "Shop Best Sellers" and the email repeats that label five times. Each button leads to a category page, not a specific product. The three featured shoes (Arch Fit Arcade, Cozy Fit, Garage) carry no price, no sale price and no BOGO tag. The offer sits only in the top banner, so the reader has to remember it while scrolling. The Cozy Fit shoe is also a hero with no price anchor.
- It is the same Black Friday message as 2026-11-13 ("Our #1 style is calling your name") and 2026-11-14 ("Our top picks, all in one place"). A subscriber who has seen those would find this one familiar. Verdict: solid and trustworthy, but a low-urgency repeat. The reviews are a good idea that would work better with prices attached.

## What's working

- The navy BOGO 50% off banner is high-contrast and sits at the very top, so the offer is clear immediately.
- Star ratings, review counts and a customer quote under each hero shoe (4.4 with 2017 reviews, 4.7 with 1966 reviews) add credible social proof.
- The Women's, Men's and Kids' sections are consistently structured, so the layout is easy to scan.
- The oversized condensed headlines ("TOP PICKS FOR HER", "KID APPROVED") are bold and readable on mobile.
- The footer has Klarna/Afterpay, an app download and an in-store prompt, which gives reasonable secondary options.

## What's weak

- All four main CTAs read "Shop Best Sellers", which is generic and repetitive and goes to category pages, not products.
- No hero shoe shows a price or a "BOGO eligible" tag, so the offer isn't tied to the products.
- The kids' Garage shoe has only 12 reviews, which is weak next to the ~2,000 on the other two.
- The offer's fine print is buried in the footer ("Valid 11/12/26 – 11/17/26", sale styles excluded). The "Discount auto-applied at cart" line in the banner is tiny.
- The deadline is not visible in the hero. The email says "Black Friday countdown" but gives no date or hours left.

## Recommendations

- 1. Put the sale price and a "BOGO 50% off" tag under each hero shoe and link each button to that product, for example "Shop Arch Fit Arcade".
- 2. Put the end date ("Ends 11/17") in the banner. The footer shows the deal ends tomorrow, which is real urgency that the email doesn't use.
- 3. Replace the repeated "Shop Best Sellers" with specific verbs and nouns: "Shop Women's Sneakers", "Shop Men's Cozy Fit", "Shop Kids' Lights".
- 4. Replace the Garage shoe with one that has more reviews, or drop the review count.
- 5. Pull the "Sign Up for Texts & Get 20% Off" and member points messaging up from the footer. The top strip already mentions Skechers Plus, so show a real member price.

## Technical Audit

## 1. Technical Summary
The visible source is structurally sound (XHTML 1.0 Transitional, VML/Outlook namespaces, responsive media queries, Gmail JSON-LD). It has two non-HTTPS images without alt text, a viewport setting that blocks zoom, and header and link checks that could not be verified (34 tracking links unprobed, no authentication headers captured). The HTML source is truncated, so body-level checks are limited.

## 2. Link & Tracking Issues
- **34 tracking links were not probed.** The QA tool skipped them as click-redirect domains, so destinations, redirect chains and 404s are unverified.
- **Tracking pixel over plain HTTP:** `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif?mi_u=8108862811&mi_ecmp=MKG_US_NA_U_MULTI_ENGAGEDL30D_EN_11162026`. The non-HTTPS source may be blocked or flagged as mixed content, which can cause open-tracking loss and security warnings in some clients.
- **The pixel URL carries a per-recipient ID (`mi_u=8108862811`).** It is sent unencrypted over HTTP, so anyone on the network path can see it.
- **Mixed image domains and protocols in the head:** `<link rel="icon" href="http://image.emails.nl.skechers.com/...">` uses the `emails.nl.` subdomain, while the other assets use `image.emails.skechers.com`. The favicon is also served over HTTP. This is low impact because favicons are ignored in email clients, but it points to leftover template config.

## 3. Rendering & Accessibility
- **Missing alt text, flagged by QA:**
  - `o.gif` (the tracking pixel, which should carry `alt=""`).
  - `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/dde00662-169f-447d-b0e2-fc65f6c2290c.png`, a content image.
- **HTTP image source:** `dde00662-…png` is served over `http://` and may be blocked. This is fixable, since the same host serves the JSON-LD images over HTTPS.
- **Zoom disabled:** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">`. `maximum-scale=1` prevents pinch-zoom on some mobile clients (WCAG 1.4.4).
- **Text resizing disabled:** the global `* { -webkit-text-size-adjust: none; }` rule also works against user text scaling on iOS.
- **Not verifiable:** the `.mobile-content` / `.desktop-content` toggle pattern could expose duplicate content to screen readers in clients that ignore media queries or `display:none`. The truncated body does not show whether it is used.

## 4. Personalization & Merge Tokens
No issues found. No unresolved merge tokens (`%%…%%`, `{{…}}`, `[[…]]`) appear in the visible source. `mi_u` and `mi_ecmp` in the pixel are resolved values.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **`List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) were not found.** The QA tool notes AgentMail may strip these headers, so this is **unconfirmed**. If they are really absent, the email fails Gmail/Yahoo bulk-sender one-click unsubscribe requirements.
- **`Authentication-Results` was not captured**, so SPF, DKIM and DMARC alignment are unknown. The From domain `emails.skechers.com` has not been verified from the raw message.
- **Not verifiable:** the footer unsubscribe link and physical postal address are in the truncated portion of the source.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- The JSON-LD `PromotionCard` URLs (`https://www.skechers.com/{women|men|kids}/shoes/?srule=top-sellers&start=0&sz=12`) have no UTM parameters. The body links use click-redirects, so any UTM tagging cannot be confirmed because the QA tool skipped them.
- The pixel's campaign ID (`…_EN_11162026`) matches the send date, which is consistent with the campaign tracking.
- No landing-page mismatch is observable from the available data.

## 7. Recommendations
1. Serve `o.gif` and `dde00662-…png` over HTTPS, and add `alt=""` to the pixel and descriptive alt text to the content image.
2. Remove `maximum-scale=1` from the viewport meta tag, and drop the global `-webkit-text-size-adjust: none`.
3. Confirm `List-Unsubscribe` and `List-Unsubscribe-Post: List-Unsubscribe=One-Click` against the raw message (for example in Gmail "Show original"). Check SPF, DKIM and DMARC in the same view. Fix the QA relay if it is stripping the headers.
4. Resolve and probe the 34 redirect links in a headless session to verify destinations and UTM parameters.
5. Replace the `emails.nl.skechers.com` favicon reference with the HTTPS primary image domain, or remove it.
