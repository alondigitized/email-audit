# Summer sale is ON | Up to 40% off
**Score:** 10/10 · **Type:** Email audit · **2026-05-27**
## Executive summary

- This is Backcountry's Memorial Day-to-Summer pivot. They ended the MD sale this morning ("30% off ends in a couple hours") and are immediately relaunching under a new banner at a higher headline discount. The creative is genuinely well-executed: clean hero with two cyclists, legible "40% Off" headline, a real product grid with strikethrough pricing, and three distinct content wells (categories, Off-Duty Shirts, Sun Protection). Nothing is broken.
- The problem isn't the email — it's the same-day context. A subscriber who got the personalized "Your 15% off code ends tomorrow" email earlier today is now looking at a 40% off public sale. That 15% personal code just became the worst deal in their inbox. The brand is cycling through "personal" and "blast" modes so fast that neither lands as credible.
- Standalone execution: strong. In the actual inbox flow for this subscriber this week: a trust erosion moment that the cleaner creative can't fix.

## What's working

- Hero reads at a glance — "SUMMER SALE / Up to 40% Off" is unambiguous and dominant.
- Lifestyle photography (two cyclists on a mountain road) is well-matched to the season and audience.
- Product grid shows specific items with visible strikethrough prices — proof the discount is real, not just rhetoric.
- Three distinct content wells (categories, shirts, sun protection) extend relevance across shopper types.
- Subject at 33 characters is clean, mobile-safe, and spam-signal-free.

## What's weak

- Launches the same day as a "personal 15% code" email — the public 40% off sale makes the private code look comically weak.
- No deadline anywhere in the email body — "Summer Sale is ON" signals a long runway, which kills urgency.
- Five generic CTAs (SHOP NOW × 3, SHOP ALL × 2) with no differentiation between them dilute focus.
- The Top Categories tile grid reads like a nav bar transplanted into email — no offer copy, no reason to click over browsing the site directly.
- "Up to 40% off" with no floor threshold or category callout — the qualifier does a lot of quiet work that erodes the headline impact.

## Recommendations

- 1. **Separate this blast from the personal code by at least 48 hours, or segment them.** Send this to non-code recipients only. Let the code expire before blasting a bigger public discount. The current sequence actively punishes subscribers who engaged with the personal email.
- 2. **Add a deadline to the hero.** "Ends Sunday" or a specific date turns a passive announcement into a time-sensitive decision.
- 3. **Replace at least one "SHOP NOW" with a category-specific CTA.** "Shop Men's Hiking," "Shop Women's Apparel" — use behavioral data. One targeted CTA is more valuable than five identical ones.
- 4. **Lead the product grid with your deepest cuts.** If 40% is the headline, the first product shown should be 40% off, not a borderline case.
- 5. **Kill the categories tile section or give each tile a discount.** "Apparel — up to 40% off" beats a naked label and a photo.

- **Preheader Alt A:** `Hiking, run, and camp gear — real discounts, no code needed. Ends Sunday.`

## Full review
## 1. Overview

This is Backcountry's Memorial Day-to-Summer pivot. They ended the MD sale this morning ("30% off ends in a couple hours") and are immediately relaunching under a new banner at a higher headline discount. ## 3. What didn't

5. **Kill the categories tile section or give each tile a discount.** "Apparel — up to 40% off" beats a naked label and a photo.

### 3. Rendering & Accessibility

**[HIGH] CSS selector collision — `.md-fluid-row .col-8` defined twice with conflicting values:**

```css
/* Line 1 — correct */
.fluid-row .col-8, .md-fluid-row .col-8 { width: 66% !important; }

/* Line 2 — COLLISION: .md-fluid-row .col-8 appears again instead of .md-fluid-row .col-9 */
.fluid-row .col-9, .md-fluid-row .col-8 { width: 74.25% !important; }
```

Result: `.md-fluid-row .col-9` has no medium-breakpoint width rule (renders at 100% default), and `.md-fluid-row .col-8` is overridden to 74.25% instead of 66%. Any fluid 8- or 9-column block will misrender on tablets and intermediate viewports.

**[MEDIUM] External font stylesheet will be blocked in most clients:**

```html
<link rel="stylesheet" href="https://partner-fonts.bluecore.com/backcountry/backcountry_fonts_1769208036.css">
```

Gmail (web and app), Outlook (all desktop versions), and Apple Mail with Link Tracking Protection strip or block external `<link>` tags. No fallback `font-family` stack is declared in the visible CSS. Recipients on these clients will render system default fonts rather than the intended typeface.

**[LOW] `viewport` meta missing `initial-scale=1`:**

```html
<meta name="viewport" content="width=device-width">
```

Should be `content="width=device-width, initial-scale=1"`. Some Android WebView-based clients may apply unexpected zoom behavior without it.

**[LOW] `-webkit-text-size-adjust: none` applied too broadly:**

```css
div, p, a, li, span, td { -webkit-text-size-adjust: none !important; }
```

`none` fully disables iOS text scaling, which prevents the user's accessibility zoom setting from affecting these elements. Correct value is `100%` (prevents automatic size adjustment while preserving user-initiated zoom).
