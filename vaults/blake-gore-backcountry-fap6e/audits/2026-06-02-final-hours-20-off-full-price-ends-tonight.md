# Final hours! 20% off full-price ends tonight 🚨
**Score:** 9/10 · **Type:** Email audit · **2026-06-02**
## Executive summary

- This is a personalized cart-retargeting send slotted into — and nearly indistinguishable from — a five-email broadcast campaign that's already run its "ends today" lap. The central insight is correct: "items in your cart" signals behavioral segmentation, which is the smartest move Backcountry has made in this entire sequence. But the creative doesn't honor that insight at all. There are no cart products shown, no item names, no before/after prices. The hero is a stock outdoor landscape, and the CTA is the bluntest possible "SHOP NOW." The cart angle is set up and then completely abandoned.
- The Gearhead Alex persona saves it. The sender name, the first-line salutation, the Canyonlands aside, the sign-off image — the voice is consistent and lived-in. That authenticity is the single thing keeping this from feeling like a re-blast of yesterday's "Ends today!" send. But it can't compensate for a cart email with no cart.
- One flag worth noting: the fine print dates appear to show "5/29/28" as the start date, which looks like a year typo in the template — a small but observable data error. And this is the sixth email in a four-day promotion; the urgency pool is running very dry.

## What's working

- **Gearhead persona is fully committed** — sender display name, salutation, sign-off image, and conversational copy all reinforce the same voice without breaking character once.
- **Cart-targeting copy is the right segmentation move** — "items in your cart" is a meaningful upgrade over re-broadcasting the sale to the full list.
- **"FINAL HOURS!" ticker immediately establishes urgency** above the fold without requiring any reading.
- **Summit Club exclusivity banner is persistent** — loyalty framing at the very top keeps the "this is for members" signal alive.
- **Tone is natural, not screamy** — the Canyonlands line reads like a person, not a template, and that matters by email six.

## What's weak

- **No cart products shown** — the behavioral trigger is named but never paid off; the hero image is a generic mountain landscape instead of the subscriber's actual items.
- **"SHOP NOW" is the worst possible CTA for a cart email** — it points nowhere specific and signals no awareness that the subscriber has already expressed intent.
- **Cadence is now working against opens** — this is the sixth send in the same 20%-off campaign; the previous day's "Ends today!" send set the urgency ceiling and this one has nothing new to add.
- **Fine print contains what appears to be a year typo** ("5/29/28" for the offer start date) — a small but visible template data error that undermines credibility on close read.

## Recommendations

- **1. Show the cart.** Pull the top 2-3 abandoned items — product image, name, original price, and 20%-off price. This is the single change that would lift this email most. Without it, "items in your cart" is just copy.
- **2. Replace "SHOP NOW" with a cart-specific CTA.** "Return to Your Cart" or "Grab Your Gear — 20% Off Until Tonight" tells the subscriber exactly where they're going and why.
- **3. Cut the Canyonlands aside, lead harder with the product.** The warmth of the persona is doing its job, but once you add cart products, the copy should pivot faster to "here's what you left behind" rather than a trekking daydream.
- **4. Fix the fine print date field.** The "5/29/28" year appears wrong; get the template patched before the next campaign reuse.

### 3. Rendering & Accessibility

**Issue 1 — Viewport meta missing `initial-scale`:**
```html
<meta name="viewport" content="width=device-width">
```
Missing `initial-scale=1`. Without it, some mobile browsers (particularly older iOS WebKit) may apply unexpected default zoom. Correct value:
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

**Issue 2 — `-webkit-text-size-adjust: none` on interactive elements:**
```css
div,p,a,li,span,td { -webkit-text-size-adjust:none !important; }
```
Setting to `none` prevents users from overriding text size — a WCAG 1.4.4 (Resize Text) concern. The correct value is `100%`, which prevents automatic auto-scaling while still allowing user zoom.

**Issue 3 — CSS selector typo (col-9 / col-8 mismatch):**
```css
.fluid-row .col-9,.md-fluid-row .col-8 { width: 74.25% !important; }
```
The `.md-fluid-row` half of this rule targets `.col-8` instead of `.col-9`. This means 9-column `.md-fluid-row` cells will not receive the correct 74.25% width on mobile; they will fall through to the default (likely 100% from the stacked reset above). `.col-8` under `.md-fluid-row` is already correctly defined two lines earlier at 66%, so this selector is both wrong and redundant.
