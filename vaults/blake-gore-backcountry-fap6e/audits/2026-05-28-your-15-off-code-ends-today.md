# Your 15% off code ends today!
**Score:** 9/10 · **Type:** Email audit · **2026-05-28**
## Executive summary

- This is the final-day bookend to yesterday's "Your 15% off code ends tomorrow ⏳" (scored 8.0), and it executes the same mechanics cleanly: personal promo code displayed front and center, one-sentence body copy, black SHOP NOW button, clean layout. The urgency claim is now literally true — today is the day — which is the strongest thing this email has going for it.
- The creative, however, is working against itself. It's late May and the hero image is a skier burying face-shots in deep pow, followed by a second image of ski tourers on a frozen mountain. Backcountry is simultaneously running a summer sale ("Summer sale is ON | Up to 40% off," sent yesterday). This email looks like it was built for January and never refreshed. The Summit+ upsell appended below is a separate ask that dilutes the one-and-done urgency of a personal code expiring today. Dense fine print between the CTA and the second image is the other visual drag.
- Still, the core is sound: recognizable sender, specific offer, credible deadline, personal code that makes a subscriber feel like they have something to lose by not acting. It just needed a summer product swap and tighter focus.

## What's working

- Personal code (BCNTF29Q1G50YDJ8) is displayed prominently in the email body — the subscriber can see exactly what to type at checkout.
- Body copy is tight: "Enter your code at checkout for an extra 15% off all eligible full-price items in your cart, today only." Key restriction is stated upfront, not buried.
- Hero typography is legible on the action image — "YOUR Extra 15% Off EXPIRES TODAY" reads instantly at a glance.
- No render bugs — clean layout, no broken images, no overlapping text.

## What's weak

- Winter powder imagery in late May directly contradicts the summer sale Backcountry launched the day before — the creative signals don't cohere.
- "SHOP NOW" is the weakest possible CTA for a personal code mechanic — the button could be "Redeem Your Code" or "Use My 15% Off" and feel far more specific.
- Summit+ Club upsell section splits the urgency message — a subscriber feeling "my code expires today" now has two competing asks on the page.
- Dense fine-print block between the CTA and the secondary image is visually prominent and slows the scroll.
- The emoji (⏳) that made yesterday's subject line feel alive is gone — "ends today!" is functional but flat by comparison.

## Recommendations

- 1. **Swap the hero to summer gear.** Pull a hero image of trail runners, hiking packs, or mountain bikes — something that connects to both the personal code AND the summer sale that launched yesterday. The creative disconnect is the biggest lift available.
- 2. **Rename the CTA.** "SHOP NOW" → "Redeem My 15% Off" ties the button directly to the personal code mechanic and reduces generic browse anxiety.
- 3. **Cut the Summit+ upsell or move it post-purchase.** A code expiring today deserves a single-focus email. If Summit+ must be here, shrink it to two lines at the footer level.
- 4. **Condense the fine-print block.** The gray text wall between the CTA and the secondary image is a scroll-stopper. One line with "See full terms" link is enough.
- 5. **Restore urgency emoji or add specificity to the time claim.** "Ends at midnight MT" beats "ends today" because it's falsifiable and specific.
- **Subject Alt A:** `Your code BCNTF29Q expires tonight — use it`
- **Subject Alt B:** `15% off full-price gear: last hours`
- **Preheader Alt A:** `Extra savings on top of the summer sale, today only`
- **Preheader Alt B:** `Stack your code on summer essentials before midnight`

### 3. Rendering & Accessibility

### 5. Compliance

**FAIL — No plain-text MIME alternative**
- QA: `[FAIL] Plain-text fallback missing or too short: Text version is 0 chars`
- CAN-SPAM does not explicitly require a plain-text part, but its absence degrades deliverability (many spam filters treat HTML-only as a signal), prevents rendering in plain-text clients, and fails WCAG email accessibility guidance

**WARN — List-Unsubscribe header not captured**
- QA: `[WARN] List-Unsubscribe header not found`
- `[WARN] List-Unsubscribe-Post header not found (RFC 8058)`
- These headers are required by Gmail and Yahoo for bulk senders (>5k/day) under their 2024 enforcement. If the AgentMail relay is stripping them, the sending domain risks inbox placement degradation. Needs verification at the MTA/relay level — the headers may exist upstream but not be passed through to the captured version.

**WARN — Authentication-Results not captured**
- QA: `[WARN] Authentication-Results header not found`
- SPF/DKIM/DMARC pass status is unknown. Backcountry sends from `b.backcountry.com` (Bluecore subdomain), which typically has its own SPF/DKIM alignment — but this cannot be confirmed from the captured headers. Relay passthrough should preserve or synthesize this header for auditability.
