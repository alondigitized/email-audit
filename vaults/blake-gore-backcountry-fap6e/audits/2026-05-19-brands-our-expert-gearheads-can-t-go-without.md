# Brands our Expert® Gearheads can’t go without
**Score:** 8/10 · **Type:** Email audit · **2026-05-19**
## Executive summary

- This is Backcountry's brand-showcase format — eight logo tiles (Patagonia, The North Face, Black Diamond, Salomon, Smartwool, Outdoor Research, Helly Hansen, Backcountry's own brand) under the headline "Brands Our Gearheads Love," followed by a 15% off code and a Summit Club upsell. The concept is reasonable: use Gearhead authority to surface trusted brand choices. The execution is inert. Brand logos with a generic "SHOP NOW" button give a subscriber who already shops Patagonia and TNF exactly zero new information or pull.
- The timing compounds the problem. This is Backcountry's third unique format in two days — the clearance urgency close landed May 18 alongside the Gearhead Alex personal-voice send. A quiet brand-relationship email could work as a low-frequency trust touchpoint, but dropped into a Memorial Day promo blitz it reads as cadence filler, not a signal worth acting on.
- The 15% off code is the email's one transactional hook, and it's buried below the brand grid with no expiration and no mention in the subject. That's the entire problem in one sentence.

## What's working

- Brand logo grid is instantly scannable — Patagonia, TNF, Salomon in one view confirms Backcountry's multi-brand authority without requiring any copy.
- The 15% off code is clearly rendered with the code text visible, reducing friction to copy-paste.
- Summit Club cash-back section is sensibly placed as a loyalty upsell after the main offer rather than competing with it.
- No render bugs — hierarchy is intact, no broken images, no overlapping text.
- Memorial Day banner at the very top correctly anchors this within the ongoing sale week.

## What's weak

- Brand logo grid with three generic "SHOP NOW" CTAs provides zero differentiation — an outdoor shopper already knows what Salomon makes.
- The 15% code — the email's strongest lever — appears nowhere in the subject line or preheader, so subscribers who scan and delete never see it.
- No expiration date on the 15% offer kills urgency; the code feels open-ended rather than actionable now.
- No Gearhead product picks, no editorial angle — the "Gearheads can't go without" premise of the subject line is completely unfulfilled by the logo-grid body.
- Fifth Backcountry email in three days; the cadence is heavy enough that any non-urgent send risks getting reflexively deleted.

## Recommendations

- 1. **Move the 15% code to the subject line.** It's the only transactional hook in the email; hiding it below the fold is a direct conversion miss. Lead with the discount.
- 2. **Add a credible expiry.** "Use by Sunday" or "expires at midnight" on the code converts browsing intent to checkout behavior.
- 3. **Fulfill the subject's promise in the body.** If the email is "what Gearheads can't go without," show 1–2 specific Gearhead picks per brand — product name, one-sentence opinion, direct link. Consistent with the Gearhead Alex format Backcountry tested the same week.
- 4. **Collapse to one CTA.** Three "SHOP NOW" buttons with no destination specificity dilute intent. One "Redeem 15% Off" CTA + one secondary "Browse Brands" link would split the audience correctly.
- 5. **Rest this format until post-Memorial Day.** A brand-love, no-urgency send has a different job than a promo close; it belongs outside a sale week when it can breathe.

- **Subject Alt B:** `Your 15% code + the brands worth shopping`
- **Preheader Alt A:** `Patagonia, TNF, Salomon & more — code expires Sunday`
- **Preheader Alt B:** `Code inside: 15% off full-price gear from our top brands`

## 1. Overview

### 3. Rendering & Accessibility

**Confirmed issue — CSS selector typo:**

```css
.fluid-row .col-9,.md-fluid-row .col-8 { width: 74.25% !important; }
```

The second selector is `.md-fluid-row .col-8` — it should be `.md-fluid-row .col-9`. Any element using `.md-fluid-row .col-9` will not receive the `74.25%` width on mobile, falling back to whatever the default width is (likely `100%` from the earlier `#content-table,.row,...` rule). Affects 9-column blocks in `md-fluid-row` containers.

**Font loading via external CDN:**

```
https://partner-fonts.bluecore.com/backcountry/backcountry_fonts_1769208036.css
```

No CSS `font-family` fallback stack is visible in the inline styles. If Bluecore's CDN is unreachable, the email will render in the client's default serif/sans — not blocked, but worth noting as a resilience gap.
