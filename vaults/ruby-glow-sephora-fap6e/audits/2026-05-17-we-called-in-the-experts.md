- This is a content-forward editorial email from Sephora — structured as a two-part feature piece centered on Alani Nu founder Amber Fillerup Clark's slow-beauty routine, followed by "3 Makeup Tips, 1 Brilliant Artist" makeup advice attributed to Fara Homidi. ### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta** (line ~4):
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. This is a WCAG 1.4.4 (Resize Text) failure. Should be removed or set to `maximum-scale=5`.

**`text-size-adjust: none` applied to broad selector:**
```css
div, a, tr, table, body, span, img, strong, td { -webkit-text-size-adjust: none; ... }
```
Applied globally, not scoped to layout elements. Suppresses browser text scaling for users who rely on it. Should be scoped to structural containers only (e.g., `table, td`), not `span`, `a`, `body`.

**`<style>` block in `<head>` only:** Gmail has supported `<head>` styles since 2016, so this is not a defect in itself — but the truncated source shows no inline style fallbacks visible. If any Gmail-rendered elements rely solely on class-based rules without inline equivalents, they may break. Cannot confirm without full source.

**Single responsive breakpoint at 480px only:**
```css
@media only screen and (max-width: 480px) { ... }
```
No `600px` breakpoint, which means tablets and large-phone viewports (481–768px) receive desktop layout at a potentially awkward intermediate width.

**`alt` text on images:** Cannot audit — `<img>` tags not present in truncated source.

### 5. Compliance (CAN-SPAM, Unsubscribe, Authentication)

**Cannot confirm from truncated source:**

- Unsubscribe link presence and one-click RFC 8058 header

**Observable — robots meta value is malformed:**
```html
<meta name="robots" content="no index" />
```
The correct token is `noindex` (no space). `"no index"` is not a recognized directive and will be ignored by crawlers. Should be `content="noindex, nofollow"`. This does not affect deliverability but means the email's web-hosted version could be indexed if the sending platform publishes a hosted copy.
