# 50% off select beauty⏰
**Score:** 6/10 · **Type:** Email audit · **2026-09-12**
## Executive summary

- This one actually delivers on its subject for once. "50% off select beauty⏰" opens directly into a "GET 50% OFF" hero with the same pink gradient the brand has run all week, but this time the mid-page grid isn't a bait-and-switch — it's wall-to-wall 50%-off products (Clarins, Estée Lauder, Ouai, First Aid Beauty, Gucci, Benefit, and more) with visible strikethrough pricing all the way down. Compare this to 9/9's "Hair Styling Awards" switcheroo or 9/7's "bonus points" pivot — this is the coherent version of the send this brand has been trying to make all week.
- The tradeoff is freshness, not honesty. This is the same pink-gradient "GET 50% OFF" chassis and product mix pattern the brand history has now logged repeatedly, just executed cleanly instead of sloppily. A subscriber who's opened five of these this week has seen this layout before, even if the specific SKUs shifted. Solid, honest, unoriginal — a 6, held back mainly by fatigue and lack of segmentation, not execution.

## What's working

- Hero headline "GET 50% OFF" visually anchors the email immediately, no scroll needed.
- "TODAY ONLY" badge plus 3-product callout (Clarins, Estée Lauder, Ouai) gives concrete named products with visible before/after pricing.
- The full product grid below (8 more items) all show clear strikethrough-to-sale pricing, unlike recent sends where the grid drifted off-topic.
- "SHOP NOW" is an unambiguous, high-contrast CTA button placed right under the hero copy.
- Beauty Insider tier bar (Insider/VIB/Rouge) is visible, giving loyalty-status relevance for members.

## What's weak

- No hero product image at the very top — just gradient and text — so the first screen is copy-only until you scroll to "TODAY ONLY."
- This is visually the same pink-gradient chassis this brand has run multiple times this week; nothing distinguishes it as a new campaign moment.
- Small superscript "a" and dagger/exclusion footnotes are present but easy to miss, and "Exclusions/terms apply" sits in tiny text at both the very top and bottom.
- No urgency deadline more specific than "TODAY ONLY" — no countdown or end time shown.
- Product grid is dense (8 items, 2-column) with no differentiation of which are "hero" vs filler — everything competes equally for attention.

## Recommendations

- 1. Add a real hero product image (not just gradient text) above the fold — a shoppable visual first frame outperforms a text-only banner for click-through.
- 2. Differentiate the grid — pull 1-2 items into a larger "featured" tile so the eye has a clear first stop instead of 8 equal-weight tiles.
- 3. Replace vague "TODAY ONLY" with a specific end time (e.g., "Ends 11:59pm PT") to make urgency credible and click-worthy.
- 4. Rotate the chassis — swap the pink gradient for a different visual treatment so this doesn't blur into the same email subscribers have seen 5+ times this week.

- **Subject Alt B:** `Your 50% off beauty picks, ending tonight`
