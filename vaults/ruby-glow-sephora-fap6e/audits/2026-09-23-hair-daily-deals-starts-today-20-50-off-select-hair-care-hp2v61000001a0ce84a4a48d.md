# Hair Daily Deals starts today 🎉 20–50% off select hair care.
**Score:** 8/10 · **Type:** Email audit · **2026-09-23**
## Executive summary

- This is a genuinely coherent Sephora send — the rarity in this run. Subject promises "Hair Daily Deals starts today, 20-50% off select hair care," and the hero delivers exactly that: a burgundy banner reading "Hair Daily Deals / Get up to 50% OFF Hair Faves" stacked with a same-day-delivery bonus offer and a "TODAY ONLY" badge. Three named hero products (Vegamour, Shark Beauty, Amika) with real before/after pricing follow immediately, then a genuinely useful calendar-style "Daily Markdowns" grid running 9/23 through 10/4.
- Where it loses points is density and stacking: after the daily-deals section there's a second full offer ("20% off value-size hair care") with four more named products, then three more unrelated promo blocks (text alerts, fragrance, value sets) before the footer. It's a lot of "hair" real estate followed by a lot of "not hair" real estate in the same email — the subject sets up a focused hair-care send and the back half undercuts that focus.
- Solid, on-brand, well-targeted email that gets diluted by scope creep past the fold. If I were optimizing one thing, I'd cut it after the value-size hair section and make this a tight, single-category send.

## What's working

- Subject-to-hero match is exact: "20-50% off select hair care" is literally the banner headline, no bait-and-switch.
- Clear urgency device: "TODAY ONLY" badge plus a specific countdown end time (10/7 at 1pm PT) for the delivery promo.
- The multi-day markdown calendar (9/23–10/4) is a distinctive, useful format not seen in prior Sephora sends in this run.
- Real before/after pricing shown on every named product (e.g., Olaplex $58→$46.40, K18 $59→$47.20) — feels honest, not vague.
- Clean visual hierarchy: dark hero → product trio → calendar → second offer, each section has a clear anchor image.

## What's weak

- Email keeps going well past the hair-care premise into fragrance, value sets, and app sign-up — dilutes the focused subject line promise.
- Two separate "hero offers" (the 50% off banner and the 20% off value-size section) compete for attention instead of one clear primary CTA.
- The daily markdown calendar text is dense and small — hard to scan at a glance, especially on mobile.
- "§§2" and multiple superscript footnote markers (†††, §§2) clutter the copy without visible explanation nearby.

## Recommendations

- 1. Cut the email after the "20% Off Value-Size Hair Care" section — drop the text-alerts, fragrance, and value-sets blocks entirely so the send stays a focused hair-care promo matching the subject.
- 2. Pick one hero offer — either lead with "up to 50% off" or the "20% off value-size" line, not both, to avoid competing CTAs.
- 3. Simplify the markdown calendar to just today + next 2-3 days with larger type, and link "see full calendar" for the rest.
- 4. Move the same-day-delivery/DELIVERED code into a smaller secondary banner so it doesn't compete with the core hair-care discount as the top message.

- **Subject Alt B:** `20-50% off hair care, today only`
- **Preheader Alt A:** `New markdowns drop daily through 10/4 — see what's up today.`
- **Preheader Alt B:** `Plus free same-day delivery with code DELIVERED.`
