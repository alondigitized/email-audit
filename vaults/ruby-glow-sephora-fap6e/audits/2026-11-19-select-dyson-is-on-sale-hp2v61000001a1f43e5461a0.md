## 3. Rendering & Accessibility
- **Missing alt.** QA flags the tracking pixel above. It is hidden and decorative, so the impact is negligible. Adding `alt=""` would clear the warning.
- **No `lang` attribute.** `<html xmlns=... xmlns:v=... xmlns:o=...>` has no `lang`, which affects screen-reader pronunciation.
- **Layout tables lack `role="presentation"`.** This applies to the outer `<table class="full-wrap tbl_cntr">`, the 700px wrapper and the nested tables.
- **Zoom blocked.** `<meta name="viewport" content="..., maximum-scale=1">` blocks pinch zoom (WCAG 1.4.4). Most email clients ignore this meta tag.
- **Malformed CSS inside `@media`.** The `<!--[if mso]> img.mso-size {...}<![endif]-->` block sits inside `@media only screen and (max-width:480px)`. Conditional comments in CSS parse as part of the selector. The `<![endif]-->` token is prepended to `.mobileHeaderTierRouge`, so that rule is likely invalid and dropped. `.mso-size` is also dead, because Outlook does not read it there.
- **Possible mobile overflow.** The wrapper uses `min-width:700px; width:700px` (`class="tbl tbl_cntr"`). The visible mobile CSS has no override for `.tbl`/`.tbl_cntr`. Rules later in the truncated `<style>` could override it, but I can't see them.
- **Invalid meta value.** `<meta name="robots" content="no index">` should be `noindex`. It has no practical email impact.
- **Structured data.** The JSON-LD has `"discountCode": ""` and a bare `"@type": "PromotionCard"`, which isn't a recognized schema.org type. Gmail will ignore the markup, and Gmail's promotion annotations expect a valid code and dates.
