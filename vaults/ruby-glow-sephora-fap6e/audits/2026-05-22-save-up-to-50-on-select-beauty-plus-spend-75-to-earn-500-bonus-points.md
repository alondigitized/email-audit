# Save up to 50% on select beauty 💄 Plus spend $75 to earn 500 bonus points.
**Score:** 8/10 · **Type:** Email audit · **2026-05-22**
## Executive summary

- This is Sephora's "Stacking Weekend" sale — a dual-incentive push combining a 50% discount with a 500-point loyalty bonus for $75+ spend. The stacking mechanic is genuinely smart for a loyalty-heavy brand: it rewards both deal-seekers and Beauty Insider members simultaneously. The hero lands correctly — 50% and 500 points are large, scannable, and prominent above the fold.
- Where this email stumbles is prioritization. The subject line tries to communicate both offers at once and runs ~74 characters, almost certainly truncating before the 500-point hook on most mobile clients. "TODAY'S FINDS" in the preheader wastes the most valuable inbox real estate entirely. The product grid is broad but unfocused — skincare, hair, body, and makeup all share space without a curated angle to drive any one category.
- Compared to the May 17 editorial ("WE CALLED IN THE EXPERTS") and the May 1 onboarding send, this is the first genuinely commercial push in recent memory — and it's appropriately timed. This should be the best-converting email in the recent Sephora batch. The execution just leaves a few easy points on the table.

## What's working

- Dual-incentive hero (50% off + 500 pts) is large, immediately readable, and well-separated visually.
- "Stacking Weekend" as a branded event name gives the sale a distinct identity beyond a generic promo.
- In-store barcode in the footer is a smart omnichannel touch — drives offline redemption.
- "SHOP NOW" button is visually unambiguous; no confusion about what to do next.
- The product grid spans multiple categories, giving nearly every intent type something to click.

## What's weak

- Subject line is ~74 characters — truncates on mobile before the 500-point secondary offer, which may be the stronger hook for a loyalty member.
- "Up to 50% on select beauty" is a soft promise; the hedge immediately softens the urgency the number should carry.
- "TODAY'S FINDS" in the preheader is generic filler that completely wastes the preview slot.
- No personalization visible — no name, no category signal, despite Sephora having rich purchase history on every Beauty Insider member.
- "Stacking Weekend" doesn't appear in the subject line, squandering a branded recognition hook with repeat customers.

## Recommendations

- 1. **Lead with the event name in the subject.** "Stacking Weekend" is a branded moment that builds equity with repeat buyers — the current subject buries it entirely and just describes mechanics.
- **Subject Alt A:** `Stacking Weekend is here — save up to 50% + earn 500 pts`
- **Subject Alt B:** `Your Sephora Stacking Weekend: 50% off + 500 bonus points`
- 2. **Rewrite the preheader to extend the subject, not ignore it.** "TODAY'S FINDS" at 13 characters is a throwaway — the preview slot should do the work the truncated subject can't.
- **Preheader Alt A:** `This weekend only — stack savings and points on select beauty.`
- **Preheader Alt B:** `Spend $75, earn 500 bonus points. Plus up to 50% off select items.`
- 3. **Anchor the deadline.** "Weekend" implies urgency but floats it. Add "Ends Sunday, 11:59 PM" in the hero or preheader to make the time pressure concrete.
- 4. **Sharpen the CTA to echo the mechanic.** "SHOP NOW" is generic. "Stack My Savings" or "Claim the Offer" ties back to the branded event and feels less like a category page link.
- 5. **Surface one personalized category signal.** Even a simple "Because you bought [category]" product row above the broad grid would materially lift click-through for a brand with this level of purchase data.

### 3. Rendering & Accessibility

**Issue — zoom disabled (WCAG 1.4.4 violation):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` prevents pinch-to-zoom on iOS/Android. Combined with the next issue, text becomes unresizable for visually impaired users.

**Issue — text-size-adjust: none applied globally:**
```css
div, a, tr, table, body, span, img, strong, td {
  -webkit-text-size-adjust: none;
  -ms-text-size-adjust: none;
  -moz-text-size-adjust: none;
  text-size-adjust: none;
}
```
Suppresses OS-level font scaling across essentially every element. This is the standard Sephora shell pattern but, paired with `maximum-scale=1`, fully blocks text resizing.

**Issue — missing `lang` attribute on `<html>`:**
```html
<html xmlns="http://www.w3.org/1999/xhtml" ...>
```
No `lang="en"` present. Screen readers (JAWS, NVDA, VoiceOver) require this to select correct pronunciation rules.

**Issue — malformed robots meta value:**
```html
<meta name="robots" content="no index" />
```
`no index` (with space) is not a recognized directive; the correct token is `noindex`. Inconsequential for email rendering but signals a template copy-paste error.

**Minor — narrow mobile breakpoint:**
```css
@media only screen and (max-width: 480px) { ... }
```
Devices wider than 480px logical pixels (e.g., most Android tablets, some large-phone landscape views) receive the desktop fixed-table layout. Industry standard has moved to 600px.
