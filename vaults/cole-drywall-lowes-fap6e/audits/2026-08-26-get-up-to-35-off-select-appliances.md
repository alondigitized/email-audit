# Get up to 35% OFF select appliances 🤩
**Score:** 6/10 · **Type:** Email audit · **2026-08-26**
## Executive summary

- This is Lowe's revisiting the exact appliance beat from 8/21's "Get up to 35% OFF select appliances🥳" — same headline percentage, same red "Lowe's Deals" corner badge, same appliance lineup shot (washer/dryer, dishwasher, fridge, range/microwave). The hero is legible and the offer stack is dense but organized: 35% off, free delivery/install/haul-away, 2-year protection plan, and a "buy more save more" ladder — that's a lot of value communicated in one clean block.
- Where it falls apart is everything after the fold. This is a nine-module cascade (appliances → storage/vanities → doors/windows → essentials → curated picks → deals of the day → newsletter signup → footer) that dilutes the single appliance offer the subject promised. It reads less like a targeted appliance push and more like the weekly everything-grid Lowe's already sent on 8/17. Verdict: good top module, but it's the same appliance send with more clutter bolted on — nothing here differentiates it from the one three days ago.

## What's working

- Hero headline "Get up to 35% off select appliances" renders large, bold, and unmissable at the top.
- Offer stack is clear and complete: 35% off + free delivery/install/haul-away + 2-year protection plan + tiered "buy more save more" savings, all visible without confusion.
- Product photography (washer/dryer, dishwasher, fridge, range) is crisp, on-white, and immediately identifies the appliance category.
- No render bugs — all images load, text doesn't overlap, buttons are intact.
- "Ends Tomorrow" urgency badge on the storage module adds a credible deadline signal.

## What's weak

- The email buries the appliance offer under eight more modules (storage, vanities, doors/windows, essentials, curated picks, deals-of-day, newsletter) — classic scope creep for a subject that promised one thing.
- This is a near-repeat of the 8/21 "Get up to 35% OFF select appliances🥳" send — same discount tier, same category, same layout pattern, just three days later.
- Multiple unrelated CTAs ("Shop now" x5+, "Get Started," "Buy now" x3, "Sign up") compete for attention and blur the primary action.
- The "Curated with you in mind" module (storage tote, cleaner, moving box) has zero connection to appliances and feels randomly inserted.
- Small print at the bottom ("Buy 2, Save $100 / Buy 3, Save $200 / Buy 4+, Save $300") requires zooming to read — the ladder is a strong offer but under-sized.

## Recommendations

- 1. Cut the email to appliances + one adjacent module (doors/windows makes sense as a "home refresh" tie-in); drop essentials, curated picks, and deals-of-day into a separate send — this email is trying to be three emails at once.
- 2. Differentiate from the 8/21 send — if the discount tier hasn't moved, lead with the *new* element (the "buy more save more" ladder or the $300 Frigidaire bundle savings) instead of repeating "35% off" as the headline again.
- 3. Enlarge the "Buy 2/3/4+" savings ladder — it's the most specific, actionable offer in the email and it's currently the smallest text on the page.
- 4. Move "Ends Tomorrow" urgency to the appliance module itself, not just storage — right now the only credible deadline is attached to the wrong product.
- 5. **Subject Alt A:** `Buy more, save more: up to $300 off appliance bundles`
- 6. **Subject Alt B:** `Appliance sale + free delivery, install & haul-away`
- 7. **Preheader Alt A:** `Frigidaire & Electrolux bundles: stack savings up to $300`
- 8. **Preheader Alt B:** `Plus a free 2-year protection plan on qualifying purchases`
