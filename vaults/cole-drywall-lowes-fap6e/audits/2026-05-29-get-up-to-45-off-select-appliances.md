# Get up to 45% OFF select appliances 🎉
**Score:** 6/10 · **Type:** Email audit · **2026-05-29**
## Executive summary

- This is Lowe's first post-Memorial Day appliance sale push — sent May 29, four days after the holiday closed. The subject-to-hero handoff is clean: "Get up to 45% OFF select appliances" lands on a prominent 45% hero, a 25% secondary offer, and a buy-more-save-more tier that builds to a FREE item. The Whirlpool specific product with a price mid-scroll adds the concreteness the hero lacks. For an appliances shopper, the first half of this email works.
- The second half undermines it. Windows installation services, a MrBeast Kids Club workshop (still running), and a Deals of the Day module share real estate with the appliance sale. The MrBeast block is especially jarring — a children's in-store event in an adult appliance sale email. These aren't complementary cross-sells; they're leftover content from last week's cadence pasted in.
- The most damning visual is the top navigation bar, which still reads "MEMORIAL DAY" on May 29. The holiday ended Sunday. This email was presumably scheduled before the holiday and nobody updated the nav — it signals a batch-and-blast operation rather than a curated post-holiday reset. Compare this to the May 28 "Top picks for summer" send, which correctly shifted tone. This email drifts back.

## What's working

- **Hero percentage is large and legible** — "45% OFF" dominates the above-fold area; the eye lands on it immediately.
- **Tiered "Buy more, save more" with a FREE anchor** — three-tier structure with a free item at the top is a proven conversion pattern and is visually clear.
- **Whirlpool Top Freezer Refrigerator with price mid-scroll** — a named brand + visible price point gives the abstract "45% off" something to attach to.
- **Subject line is clean and specific** — category + percentage in under 40 characters, no spam signals, no vague "deals" language.
- **Appliances nav tab is visible** — reinforces the category story for anyone scanning the top bar.

## What's weak

- **"MEMORIAL DAY" nav label is still showing on May 29** — the holiday is four days behind us; this makes the email feel stale and auto-generated.
- **MrBeast Kids Club workshop block is completely off-topic** — a children's in-store event has no business in an appliances sale email; it signals content stuffing, not curation.
- **Windows installation services dilutes the appliance narrative** — a valid Lowe's service, but it resets the category story mid-scroll.
- **No visible deadline or urgency on the 45% offer** — the offer is compelling but open-ended; nothing tells me I need to act today.
- **Three separate "Shop now" blocks for appliances with near-identical creative** — the 45% hero, the Whirlpool product block, and a third appliance module at bottom feel repetitive rather than progressive.

## Recommendations

- 1. **Remove the MrBeast Kids Club block entirely** — it does not belong in an appliances sale email and breaks trust with the reader who opened for deals on fridges and dishwashers.
- 2. **Update or remove the "Memorial Day" nav label** — swap to "Appliances Sale," "Summer Savings," or just the standard category nav. This is a one-minute fix with outsized perception impact.
- 3. **Add a deadline to the 45% offer** — even "through Sunday" or "this week only" would lift urgency without being dishonest. The May 23 member-exclusive grill email earned an 8 partly because the offer felt bounded.
- 4. **Collapse the three appliance modules into one stronger one** — lead with the Whirlpool specific product, add two more named SKUs with prices, put a single prominent CTA below. More specific = more clicks.
- 5. **Reframe the Windows install block as a "while you're upgrading" cross-sell** — one smaller placement after the primary appliance story, not a full-width hero competing for attention.
- **Subject Alt A:** `45% off appliances — shop before it ends`
- **Subject Alt B:** `Your next fridge is 45% off right now`
- **Preheader Alt A:** `Whirlpool, GE, Samsung — big savings on the brands you know`
- **Preheader Alt B:** `Fridges, washers, dishwashers — all on sale this week`

### 3. Rendering & Accessibility

**Images missing alt text** — QA flagged 8 instances. Categorized by impact:

| Image | Type | Alt Required? |
|---|---|---|
| `c301e24e-201b-46f9-8172-27b5acdcbf99.jpg` | Content image (hero/product) | Yes — missing |
| `ad569dc5-361d-4d7d-8bc0-1ae6ec389f05.png` | Content image | Yes — missing |
| `o.gif` (open pixel, `mi.lowes.com`) | Tracking pixel | Should be `alt=""` |
| 5× `sli.lowes.com/imp?...` | Impression pixels | Should be `alt=""` |

Content images with no `alt` will show broken image icons in image-blocking clients (Outlook, many corporate environments) and fail screen reader accessibility. Tracking pixels should carry empty `alt=""` to suppress broken-image indicators.

**Malformed DOCTYPE** — missing space between `PUBLIC` and the quoted identifier:
```html
<!DOCTYPE html PUBLIC"-//W3C//DTD XHTML 1.0 Transitional//EN"
```
Should be `PUBLIC "-//`. No practical rendering impact in modern email clients, which ignore DOCTYPE, but technically invalid markup.

**Incorrect XHTML namespace** — `<html xmlns="https://www.w3.org/1999/xhtml">` uses `https://`; the canonical XHTML namespace URI is `http://www.w3.org/1999/xhtml`. No client enforces this, but it is non-conformant.

**Redundant `local()` font sources** — all four `@font-face` blocks duplicate the local font name:
```css
src: local('Fellix Regular'), local('Fellix Regular'), url(...) format('woff');
```
The duplicate `local()` is harmless but indicates a template generation defect.

**DIN Next font version mismatch** — `din-next.woff` loads from scaffold `1.4.4` while `din-next-bold.woff` and `din-next-black.woff` load from `1.2.0`. If the CDN versions differ in metrics, fallback rendering may show inconsistent spacing on clients that support web fonts (Apple Mail, iOS Mail).

**Responsive gap** — the email defines two independent media query breakpoints: `min-width: 375px AND max-width: 600px` (tablet) and `max-width: 480px` (mobile-only). Devices between 480–600px wide receive the tablet query only; devices at exactly 375–480px match both queries simultaneously. Specificity may resolve this correctly, but the overlap is fragile.
