# Homepage snapshot · www.hilton.com · 2026-05-21
**Score:** 1/10 · **Type:** Site journey · **2026-05-21**
## Executive summary

- What I got was not a homepage — it's a full-page error screen. The Hilton wordmark sits in a dark blue nav bar, and everything below it is a generic "SOMETHING WENT WRONG" error card with a reference number and a single "GO BACK" button. As a Diamond member who books multiple nights a month and actively tracks points promos, landing on this when I open the app is a hard stop. No hero, no search, no loyalty hook — nothing.

## What's working

- **Error copy tone** — "Maybe it's us, maybe it's you. (It's probably us)." is self-aware and not robotic. For a brief moment it softens the frustration, which is something.
- **Reference number is present** — `18.64f7d517.1779363516.1e801b7a` is surfaced clearly, which is useful if I need to contact Diamond support to escalate a booking issue tied to this outage.
- **"GO BACK" button is legible and tappable** — it's above the fold on mobile, rendered cleanly, good tap target size.

## What's weak

- **No homepage content whatsoever** — search bar, deals, loyalty balance, brand tiers — all absent. For a Diamond member mid-trip-planning this is a dead end.
- **No retry or reload CTA** — "GO BACK" sends me away from Hilton entirely; there's no "Try Again" or auto-refresh.
- **No fallback content** — a cached version of search, a link to the app, even a toll-free Diamond desk number would salvage some utility.
- **"or try:" is visible but cut off** — the bottom of the screen shows the beginning of a fallback suggestion that is cropped out of view, meaning I can't even read whatever recovery path they're offering without scrolling, and there's no visual affordance that more content is below.
- **No loyalty contact path** — no "Call Diamond Desk" link, no chat. For high-value members stuck mid-booking, this is a missed recovery moment.

## Recommendations

- **Add a "Try Again" button** alongside "GO BACK" — reload is the first instinct; make it the primary CTA on an error page.
- **Surface the Diamond/Honors support number inline** on the error card — members mid-booking need an escape hatch, not just a reference code.
- **Ensure fallback copy below "or try:" is fully visible** on mobile viewport — either remove the crop or use a scrollable card that doesn't bleed off screen.
- **Implement a lightweight cached fallback** for the homepage search bar — even a static search form beats a white wall; it signals "we're working on it, keep going."
