# 20% off $99 Nike & Jordan starts today!
**Score:** 9/10 · **Type:** Email audit · **2026-07-02**
## Executive summary

- This is the sharpest Foot Locker send since the Summer Savings blitz began — and context matters here. After seven consecutive "50% off / FINAL HOURS / EXTENDED" emails crammed into six days, a brand-specific, spend-threshold promo with July 4th creative is exactly the right pattern break. The hero is clean: "20% OFF $99" reads instantly, the fireworks backdrop is timely two days out from the holiday, and naming Nike & Jordan gives the offer a product identity the June 28 "Top styles of the season at prices you'll love" email conspicuously lacked.
- But the email contradicts itself on the scroll. The "Hot Styles" product grid — the section that should convert intent into clicks — is almost entirely HOKA and adidas. The headline promises Nike & Jordan faves; the merch grid delivers Bondi 7s and Lightning shoes. A subscriber who opened because of Jordan hype will scroll into HOKA thumbnails and wonder if they missed something. Worse, that subscriber might reasonably wonder whether the promo code even applies to what they see — because it might not.
- Secondary issue: the promo code "SAVE80" does not intuitively map to a 20% off offer. Next to a big "20% OFF" hero, SAVE80 reads like $80 off or 80% off. That brief cognitive hiccup is exactly the kind of micro-doubt that suppresses code usage at checkout.
- Fix the product grid and rename the code and this is a genuinely good email. As shipped, it's a smart strategy undermined by an execution mismatch.

## What's working

- **July 4th visual treatment lands clean** — navy background, red and white sparkle/fireworks graphics, and the two-days-prior timing are all right.
- **Subject line is the strongest of this audit run** — 39 characters, brand-specific, offer-specific, no spam signals.
- **Hero offer is immediately readable** — "20% OFF $99" in oversized type with the code called out beneath it requires no interpretation.
- **Family segmentation CTAs are well-executed** — Shop Men's / Women's / Girls' / Boys' lets the subscriber self-route without a cluttered hero.
- **FLX Rewards section is visible** — smart loyalty reinforcement even if it's buried toward the footer.

## What's weak

- **Product grid directly contradicts the promo** — "Hot Styles" shows HOKA Bondi 7, Bondi 8, Kawana TC, Mafate Speed, adidas Lightning, and HOKA Project Trail. None of these are Nike or Jordan. The email's central offer and its featured product inventory are in conflict.
- **SAVE80 doesn't parse as 20% off** — the code name implies a larger or different discount structure; it introduces a moment of doubt right before the subscriber acts.
- **No end date kills the urgency** — "starts today" without "ends July 6" or similar gives subscribers no reason not to defer. After the FINAL HOURS → EXTENDED → LAST CHANCE saga, Foot Locker's deadlines have no credibility anyway — a hard date is the only cure.
- **"Select Styles Exclusions Apply" + HOKA grid = skepticism** — the caveat is visible but vague, and paired with a grid of non-Nike shoes, it amplifies doubt about whether the discount applies to anything shown.

## Recommendations

- 1. **Swap the Hot Styles grid for Nike and Jordan products** — this is the single highest-impact fix. If the recommendation engine pulls "most popular styles" regardless of campaign, that coupling needs to break for brand-specific sends. Show the shoes the email promises.
- 2. **Rename the promo code** — NIKEJULY, JORDAN4TH, or even SAVE20 removes the ambiguity. SAVE80 actively misdirects.
- 3. **Add a hard deadline** — "Ends July 6" or "July 4 weekend only" converts intent into immediate action and partially rehabilitates Foot Locker's deadline credibility with this subscriber base.
- 4. **Sharpen the primary CTA** — "Shop Nike & Jordan Sale" over "SHOP THE SALE" reinforces the brand hook and reduces the identity confusion the HOKA grid creates.
- **Subject Alt A:** `Nike & Jordan faves: 20% off $99+ ends July 6`
- **Subject Alt B:** `July 4th deal: 20% off Nike & Jordan with code`
- **Preheader Alt A:** `Use code JORDAN4TH at checkout. Select Nike & Jordan styles — through July 6 only.`
- **Preheader Alt B:** `20% off when you spend $99 on Nike & Jordan faves. Offer ends Sunday.`

### 3. Rendering & Accessibility

**Bug — CSS selector typo in responsive grid (line in `@media` block):**
```css
.fluid-row .col-9,.md-fluid-row .col-8 { width: 74.25% !important; }
```
The second selector should be `.md-fluid-row .col-9`, not `.md-fluid-row .col-8`. As written, `.md-fluid-row .col-8` is re-declared (overriding the earlier `66%` rule) while `.md-fluid-row .col-9` gets no mobile width. Any 9-column element in an `md-fluid-row` will not collapse correctly on mobile.

**Missing `initial-scale` on viewport meta:**
```html
<meta name="viewport" content="width=device-width">
```
Best practice is `content="width=device-width, initial-scale=1"`. Without `initial-scale=1`, some Android webmail clients may render at a zoomed-out scale.

**External font stylesheet will be stripped by Gmail:**
```html
<link rel="stylesheet" href="https://partner-fonts.bluecore.com/footlocker/footlocker_fonts_1776712244.css">
```
Gmail (web and app) strips `<link>` tags. Any Foot Locker custom font loaded this way will silently fall back to the system font stack in Gmail. No fallback `font-family` stack is visible in the truncated source — needs verification that inline fallbacks exist on text elements.

**`format-detection` only suppresses phone numbers:**
```html
<meta name="format-detection" content="telephone=no">
```
iOS Mail will still auto-link dates and addresses. Add `address=no, date=no` if the email body contains date strings or address text (e.g., store addresses in the footer).

**Alt text on images:** Cannot verify — body images are in the truncated section. The product widget CSS references `.name`, `.price`, `.rating_stars`, `.prod_color` cells, suggesting image-based product cards. All product images must have descriptive alt text for rendering in image-blocked clients.
