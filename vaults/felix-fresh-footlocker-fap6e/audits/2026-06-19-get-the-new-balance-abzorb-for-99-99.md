# Get the New Balance Abzorb for $99.99.
**Score:** 8/10 · **Type:** Email audit · **2026-06-19**
## Executive summary

- This is a price-anchor product spotlight — "New Balance Abzorb, $99.99" — dropped one day after the NYC AF1 Low limited-drop send (June 18, scored 9/10). The sequencing logic is defensible: follow a hype drop with an accessible in-stock style at a locked price. The subject line is the strongest asset in this email. It is direct, price-explicit, 38 characters, and makes a promise a subscriber can act on immediately.
- The execution breaks down below the fold. The "Hot Styles" recommendation block surfaces six UGG products — slippers and boots, in June, in a New Balance email. That is not a creative choice; it is a personalization module that pulled general bestsellers instead of New Balance inventory. Any subscriber who opens because of "Abzorb for $99.99" and then sees Tazman Hoodies and Fluff Yeah sandals is going to feel misled about what this email is actually about.
- The hero is clean and the neon yellow-green Summer Savings frame provides visual continuity. But the email makes a specific product promise in the subject and then routes every CTA to a generic sale page — the gap between subject precision and landing experience is where conversion bleeds out.

## What's working

- **Subject line is the best in this recent run** — product name plus exact price at 38 characters is textbook price-forward; no vague "savings event" language.
- **Hero lands immediately** — "NEW BALANCE ABZORB / ONLY $99.99" with clean product photography, clear price, no clutter.
- **Summer Savings visual frame is consistent** — neon yellow-green background ties this send to the ongoing campaign without feeling recycled.
- **Secondary copy is accurate** — "Get up to half off hot New Balance styles like the New Balance Abzorb and more for a limited time" scopes the offer honestly without overpromising.

## What's weak

- **UGG "Hot Styles" block completely mismatches the email** — six UGG slippers and boots in a June New Balance spotlight. Looks like a dynamic module grabbed site-wide bestsellers rather than New Balance summer inventory.
- **CTAs route to a sale page, not the product** — the subject promises the Abzorb; "SHOP NEW BALANCE SALE" lands on a broader category page. The promise is never fulfilled at the click.
- **No product detail for the Abzorb** — no colorways listed, no sizing note, no "only a few left" signal. Nothing creates urgency around this specific shoe.
- **Double-offer creates decision noise** — "$99.99" and "UP TO 50% OFF TODAY" are two different value frames in one email and they undercut each other.
- **No social proof for the featured product** — star ratings appear only in the UGG section, not on the Abzorb hero.

## Recommendations

- 1. **Add a "SHOP THE ABZORB" CTA that links to the Abzorb PDP** — the subject makes a specific promise; the email must keep it. This is the single highest-leverage change and the root cause of the click gap.
- 2. **Replace the UGG module with New Balance summer styles** — or remove the recommendation block entirely. A product-specific email should not hand off to unrelated inventory.
- 3. **Add one specificity signal to the hero** — a star rating ("4.4★ / 1,200+ reviews") or a colorway count ("Available in 4 colors") does more conversion work than any copy tweak.
- 4. **Collapse to one offer frame** — commit to either "$99.99" or "UP TO 50% OFF." Both in the same email create decision paralysis.
- 5. **Replace "limited time" with a credible deadline** — "through Sunday" or "while sizes last" is concrete; "limited time" is noise.

- **Subject Alt B:** `Your size in the Abzorb is probably still here`
- **Preheader Alt A:** `Half off the Abzorb and more New Balance styles — shop before sizes run out.`
- **Preheader Alt B:** `Up to 50% off New Balance this weekend. The Abzorb starts at $99.99.`

### 3. Rendering & Accessibility

**[HIGH] CSS selector copy-paste bug — `col-9` mobile width never set for `md-fluid-row`:**

```css
/* Line in <style> block */
.fluid-row .col-9,.md-fluid-row .col-8 { width: 74.25% !important; }
```

The second selector should be `.md-fluid-row .col-9`, not `.md-fluid-row .col-8`. As written, `.md-fluid-row .col-8` is targeted twice (redundant with its own correct rule above) while `.md-fluid-row .col-9` is never explicitly set at mobile breakpoint — it will fall through to whatever cascade applies, likely 100% or an incorrect value.

**[MEDIUM] External versioned font asset — permanent breakage risk:**

```html
<link rel="stylesheet" href="https://partner-fonts.bluecore.com/footlocker/footlocker_fonts_1776712244.css">
```

The filename is fingerprinted (`_1776712244`). Emails are rendered at open time from the original source — if Bluecore rotates or removes this asset, every future open of this already-sent email will fall back to system fonts. No fallback `font-family` stack was confirmed in the visible CSS.

**[LOW] Overly broad `-webkit-text-size-adjust: none`:**

```css
div,p,a,li,span,td { -webkit-text-size-adjust:none !important; }
```

Suppressing auto text-size-adjust on every element prevents iOS Mail from scaling up small text, which is both an accessibility concern (WCAG 1.4.4) and breaks expected behavior for users with accessibility settings enabled.
