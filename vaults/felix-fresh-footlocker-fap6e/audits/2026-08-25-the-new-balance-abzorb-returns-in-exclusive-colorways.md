# The New Balance Abzorb returns in exclusive colorways.
**Score:** 5/10 · **Type:** Email audit · **2026-08-25**
## Executive summary

- This is a clean, athlete-driven launch send — a strong shift from the recycled purple New Balance sale creative Foot Locker has leaned on all week. The "EXCLUSIVE" badge, bold ABZORB 2010 wordmark, and Zach LaVine celebrity tie-in give it real specificity, and the single "SHOP NEW BALANCE" CTA sits directly under the hero with no scroll needed. It's a genuine product story, not a percentage-off blast.
- Where it falls apart is focus: right below the New Balance hero, the email pivots hard into a second, unrelated "FIRST DAY FRESH" back-to-school block with a Jordan 1 image that has nothing to do with New Balance or Abzorb. That kills the single-offer clarity this subject line promises and turns a tight launch email into a mixed bag by the midpoint. There's also no price, release date, or restock/reservation mechanic — for a subscriber who doesn't already know Zach LaVine, "exclusive colorways" alone is a soft hook.
- Solid top half, diluted bottom half — worth opening, moderate click odds concentrated entirely in that first block.

## What's working

- Clear hero hierarchy: badge → product name → lifestyle photo → CTA, all above the fold.
- Celebrity/athlete association (Zach LaVine) adds specificity and credibility beyond generic "new colorways" copy.
- Single unambiguous CTA ("SHOP NEW BALANCE") button visible without scrolling.
- No render bugs — image, type, and button all display cleanly.

## What's weak

- The "FIRST DAY FRESH" / Jordan 1 block directly beneath the New Balance hero is a jarring, off-brand-for-this-email tangent that dilutes the single-product focus.
- No price, release date, or purchase mechanic (buy now vs. reserve) — unclear if this is shoppable today or a teaser.
- "Exclusive colorways" is vague; the image doesn't actually show a colorway comparison or callout.
- FLX Rewards free-shipping banner is generic boilerplate, adding little incremental value this far down.

## Recommendations

- 1. Cut the "FIRST DAY FRESH" back-to-school block entirely from this send — it's a different campaign and undercuts the New Balance exclusivity story. Give Abzorb 2010 the whole email or add a second colorway image instead.
- 2. Add a price or "Available now" / release date line under the CTA — closes the single biggest gap versus the Jordan Retro 8 reservation sends, which used a countdown clock to good effect.
- 3. Show a second product shot with the actual exclusive colorway detail (close-up) since "colorways" is the subject's hook but never gets visually paid off.

# Technical Email Audit — Foot Locker / "New Balance Abzorb" (Bluecore ESP)

## 1. Technical Summary
Bluecore-templated (`bc.footlocker.com`) HTML email with a broken personalization conditional block and no plain-text MIME part; deliverability posture is weakened by missing unsubscribe/authentication headers at the relay layer.

## 2. Link & Tracking Issues
- Three distinct tracking endpoints observed: `mi.footlocker.com` (open pixel `o.gif`, redirect pixel `fa53ea8871ffa0e2.png`), `trk.bc.footlocker.com` (Bluecore ESP open beacon `ho.gif`), and `dv.footlocker.com` (dynamic-content/deep-link redirect `o/adc7c3e5-511c-45d3-bc3d-72e97f531b05?cp_tp=...`). Redundant open-tracking pixels from two separate vendor domains (`mi.footlocker.com` and `trk.bc.footlocker.com`) in the same send is unusual and worth confirming is intentional (e.g., a mid-migration ESP overlap) rather than a leftover integration.
- Tracked links use Bluecore-native params (`mi_u`, `mi_ecmp`, `cp_tp`) rather than standard `utm_*` — see §6.
- QA probe: 12 of 29 material links were probed (17 deprioritized as footer/utility/social); no broken-link failures reported among probed links.

## 3. Rendering & Accessibility
- 4 images missing `alt` text, all tracking/redirect assets: `o.gif`, `fa53ea8871ffa0e2.png`, `dv.footlocker.com/o/adc7c3e5-...`, `ho.gif`. These are non-visual tracking pixels/beacons, so the fix is `alt=""` (explicitly empty, not simply omitted) to avoid screen readers announcing the raw filename/URL.
- Head includes standard Outlook MSO conditional fixes, `x-apple-disable-message-reformatting`, and a mobile media query — no rendering red flags found in the head/CSS block reviewed.
- Body markup was truncated in the source provided; content-image alt text and structural markup beyond the head/first widget block could not be assessed.

## 4. Personalization & Merge Tokens
- **Malformed template tags**: the loyalty-tier conditional is written as `{ % if (...) % } { % else % } { % endif % }` — with a space between `{` and `%`. Standard Jinja/Liquid delimiters are `{% %}` with no internal space. If the Bluecore rendering engine requires the tight delimiter, this block will either fail to evaluate (falling through as literal text) or silently produce no styling differentiation for `ct_current_tier_level` X1/X2/X3 segments. Recommend verifying against a live Bluecore render for a tiered test customer — if the raw `{ % if ... % }` string appears in the rendered/sent HTML, this is a shipped bug.
- Tier-check filter usage (`customer|getattr("ct_current_tier_level", "")`) is otherwise structurally sound Jinja syntax, contingent on the delimiter fix above.
- No other merge-token placeholders (e.g. `{{first_name}}`) were visible in the truncated source to evaluate for unresolved/leaked tokens.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe header**: not found by the automated check (may be a relay-capture limitation rather than true absence — flagged WARN, not FAIL).
- **List-Unsubscribe-Post (RFC 8058)**: not found — if genuinely absent, this email does not support one-click unsubscribe, which is required by Gmail/Yahoo bulk-sender policy for senders at scale. Recommend confirming directly with Bluecore/Foot Locker ESP config rather than relying solely on relay capture.
- **Authentication-Results (SPF/DKIM/DMARC)**: not captured via the AgentMail relay — authentication status is unknown from this data, not confirmed failing.
- An unsubscribe link was present per the QA probe methodology (always included in probing), so a body-level unsubscribe mechanism appears to exist; its footer text/target was not visible in the truncated source.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- Tracked destination URLs use Bluecore proprietary params (`mi_u`, `mi_ecmp`, `cp_tp`) rather than standard `utm_source`/`utm_medium`/`utm_campaign`. If downstream analytics (GA4, etc.) expect UTM parameters for attribution, confirm Bluecore's params are mapped/translated server-side on the landing page — otherwise sessions from this email may not attribute correctly in non-Bluecore analytics tooling.
- Final landing page destinations were not visible in the truncated source (only pixel/tracking endpoints shown), so landing-page alignment (correct product/colorway page, working redirects) could not be verified. No issues found in what was available.

## 7. Recommendations
1. Fix the template delimiter bug: change `{ % if ... % }` / `{ % else % }` / `{ % endif % }` to `{% if ... %}` / `{% else %}` / `{% endif %}`, then re-render for a tiered (X1/X2/X3) test customer to confirm the conditional actually evaluates.
2. Add a plain-text MIME alternative — current plain-text part is 0 chars, which hurts spam-filter scoring and accessibility for text-only clients.
3. Confirm List-Unsubscribe and List-Unsubscribe-Post headers are actually being sent (check raw headers server-side, independent of the relay capture) and add RFC 8058 one-click support if missing.
4. Set `alt=""` on the four tracking-pixel images identified above.
5. Clarify whether both `mi.footlocker.com` and `trk.bc.footlocker.com` open-tracking pixels are intentionally both present, or one is a stale leftover.
6. Confirm Bluecore's `mi_u`/`mi_ecmp`/`cp_tp` params are captured by site-side analytics, or add standard UTM params for cross-platform attribution consistency.
