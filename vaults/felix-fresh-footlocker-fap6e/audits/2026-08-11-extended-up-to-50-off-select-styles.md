# Extended: Up to 50% off select styles.
**Score:** 6/10 · **Type:** Email audit · **2026-08-11**
## Executive summary

- This is Foot Locker's continuation of the "Big Sale" red-hero creative running since 8/8, and it's showing wear. The hero — bold "BACK-TO-SCHOOL BIG SALE / MORE STYLES ON SALE" with the AF1/adidas Campus pair — is clean and legible, and "up to 50% off" plus "SHOP THE SALE" gives a real, unambiguous offer. But directly below the CTA sit four solid black rectangles where content should be — a visible render bug that undercuts an otherwise competent hero.
- Past the fold, this drops into the now-familiar "Top Recommendations" product grid, which is generic and does the same job every Foot Locker send does — it's filler, not a hook. Subject says "Extended," which tracks with the brand's pattern of stretching the same sale multiple times this week (8/8 "Ending soon," 8/9 "Last day," now 8/11 "Extended"), which is starting to read as manufactured urgency rather than credible deadlines.
- Net: solid hero mechanics dragged down by a visible image/layout bug and a subject line that's the third "urgency" reframe of the same underlying sale in four days.

## What's working

- Clear, single-message hero: "up to 50% off," one unmissable "SHOP THE SALE" button.
- Visual hierarchy is strong — sale banner dominates above the fold, eye goes straight to the offer.
- Product imagery (AF1 + adidas Campus) is sharp and on-brand for a sneaker-first audience.
- Top nav and FLX Rewards banner give clear secondary paths (Join Now, Free Shipping/Returns).

## What's weak

- Four black/broken rectangular blocks render directly under the CTA button — a clear visual bug that looks unfinished or corrupted.
- "Extended" in the subject is the brand's third urgency variant this week (Ending soon → Last day → Extended), which erodes credibility of the deadline.
- Recommendations grid is generic Jordan/Nike kids' product tiles with truncated names ("Jordan Jordan 1 ...", "Jordan Son of Ma...") — sloppy and low-effort.
- No explicit expiration date/time visible anywhere in the hero, so "Extended" urgency has no concrete deadline to anchor it.

## Recommendations

- 1. Fix the broken black-block render before this ships again — that's the single biggest lift; a bug like this directly under the CTA can suppress clicks regardless of offer quality.
- 2. Add a concrete deadline (e.g., "Ends Sunday 11:59pm") to the hero so "Extended" urgency feels real, not perpetual.
- 3. Fix truncated product titles in the recommendation grid ("Jordan Jordan 1 ...", "Jordan Son of Ma...") — clip cleanly or shorten the copy so nothing reads as cut off.
- 4. Vary the creative from the 8/8–8/9 sends — same red gradient, same layout for the fourth time this week risks fatigue.
