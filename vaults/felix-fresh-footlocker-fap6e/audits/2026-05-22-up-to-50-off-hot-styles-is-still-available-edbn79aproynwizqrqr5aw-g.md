# Up to 50% off hot styles is still available! 🔥
**Score:** 8/10 · **Type:** Email audit · **2026-05-22**
## Executive summary

- Day 2 of the Summer Kickoff Sale. Yesterday's launch (May 21, scored 9/10) did the heavy lifting — "Up to 50% off starts today!" was a clean, high-energy opener with a strong summer pool hero. This follow-up reuses that exact hero creative, changes nothing in the body, and slaps a weaker, defensive subject on it. "Still available" communicates that the offer is aging, not that it's about to expire. For the subscriber who already opened yesterday and didn't click, nothing here gives a new reason to act.
- The one genuine addition is the "CURATED FOR YOU" product grid — but it under-delivers on its own label. Five of the six slots are New Balance La France colorway variants. That's an algorithm serving inventory pressure, not a personal editor. The FLX 3X points callout buried below the grid is actually the single strongest new piece of information in the email relative to yesterday, and it got no real estate.
- Bottom line: technically competent re-send, zero new reason to buy. The subscriber who opened yesterday is no closer to clicking.

## What's working

- **50% OFF hero is immediately legible.** Bold gold type against the summer pool-blue background is eye-catching and hierarchy is clear — the offer lands first.
- **"SHOP THE SALE" CTA is unambiguous.** Verb + noun, visible teal button, no ambiguity about the action.
- **FLX 3X points callout is the one genuinely new signal.** Loyalty members have a concrete new reason to act that wasn't in yesterday's email.
- **Star ratings on the curated product tiles** add lightweight social proof without cluttering the grid.
- **Layout is clean — no render bugs.** No broken images, no overlapping text, no lorem ipsum.

## What's weak

- **"Still available" is the weakest possible day-2 hook.** It's an apology for sending again, not a reason to open.
- **Hero creative is a direct copy of yesterday's launch email.** No deadline counter, no creative escalation, no new element to reward re-openers.
- **"CURATED FOR YOU" over-promises.** Five near-identical La France colorways is product-feed output, not editorial curation.
- **No deadline, no scarcity signal anywhere.** "Still available" implies things sell out, but nothing enforces it.
- **Third sale-related email in three days** (teaser May 20 → launch May 21 → this). List fatigue is building fast.

## Recommendations

- 1. **Rewrite the subject to create urgency, not status.** "Still available" communicates the sale hasn't ended, which is zero hook. A deadline — even a vague one ("this weekend only") — doubles the urgency.
- 2. **Put FLX 3X points in the hero or subject.** It's the only new information in the entire email and it's below the fold. Swap it into the subhead: "FLX members earn 3X points through Sunday."
- 3. **Add a countdown timer or explicit end date.** The sale is already a day old; without a visible deadline this email reads as "we're desperate for clicks" rather than "act fast."
- 4. **Break the La France monoculture in the curated grid.** At minimum, mix silhouettes. Five colorways of the same shoe signals broken recommendation logic and erodes trust in "CURATED."
- 5. **Vary the hero subhead to introduce something new.** Yesterday's said "get ready for summer." Today's could tease sell-through ("sizes going fast") or spotlight a different category to convert a new segment.

### 3. Rendering & Accessibility

**Confirmed bug — CSS selector typo in responsive grid:**
```css
/* Line as written: */
.fluid-row .col-9, .md-fluid-row .col-8 { width: 74.25% !important; }

/* Should be: */
.fluid-row .col-9, .md-fluid-row .col-9 { width: 74.25% !important; }
```
Effect: `.md-fluid-row .col-8` now receives two conflicting `width` declarations (66% from its correct rule, overridden by 74.25% here). `.md-fluid-row .col-9` receives no responsive width, breaking 9-column fluid layouts on mobile.

**`-webkit-text-size-adjust: none` applied too broadly:**
```css
div, p, a, li, span, td { -webkit-text-size-adjust: none !important; }
```
This disables iOS Safari's automatic text scaling for all content elements, preventing users from increasing text size for readability. WCAG 1.4.4 (Resize Text) concern.

**`<title>` emoji encoding:** `&#128293;` (🔥) is correctly HTML-encoded and will render fine in modern clients. Low risk.

**Widget empty-state risk:** Bluecore widget blocks (`#widget_ee80bf0f1892da582d912355b5373745`, `#widget_e49baa1ed820190ce870bdb4227b53c7`) use server-side render injection. If a widget fails to populate (e.g., no recommendation data for a recipient), the CSS defines fixed `height` values (`height: 24px`, `height: 25px`) on `.name`, `.gender_age`, `.price` cells — these will leave visible blank rows rather than collapsing gracefully.
