# Up to 50% off hot styles is still available! 🔥
**Score:** 7/10 · **Type:** Email audit · **2026-05-22**
## Executive summary

- This is Foot Locker's day-2 sale-reminder send — a re-engagement push to whoever didn't open or click yesterday's launch ("Up to 50% off starts today!"). The creative is essentially identical: same blue pool hero, same oversized "50% OFF" in yellow, same pool-float imagery. The only meaningful additions are a personalized "CURATED FOR YOU" product grid with star ratings and a gold FLX Rewards member callout strip. Both additions are good; the underlying creative recycling is not.
- The "still available" subject framing is the tell — this is a list scrub email dressed as a campaign beat. It works if you're re-engaging non-openers from yesterday, but it's a passive signal compared to a deadline-based urgency hook ("Ends midnight Sunday"). For anyone who already opened yesterday, this reads as the same email with a slightly apologetic subject line.
- The personalized product grid saves it. Six Nike shoes with visible star ratings and sale prices with strikethrough is a better below-the-fold experience than the launch email offered. But Foot Locker has now sent four promotional emails in five days — that cadence is starting to erode the credibility of each individual send.

## What's working

- **"CURATED FOR YOU" grid is the upgrade over yesterday** — six products with visible star ratings and before/after pricing give the user a reason to scroll beyond the hero.
- **Hero offer reads instantly** — oversized yellow "50% OFF" on a summer pool background, eye lands there first with no ambiguity.
- **FLX Rewards loyalty strip** in gold is prominently placed and reinforces member value without competing with the main offer.
- **"SHOP THE SALE" CTA button** is visually unambiguous — clean blue button, centered, no competing CTAs above the fold.
- **No render bugs** — layout is clean across the visible render; no overlapping text, no broken images, no empty blocks.

## What's weak

- **Carbon-copy creative from yesterday** — same pool hero, same color palette, same "50% OFF" treatment; a subscriber who opened May 21 will feel like they're looking at a resend, not a new reason to shop.
- **No deadline or countdown** — "still available" is soft urgency that says nothing about when it ends; a deadline would dramatically lift click pressure.
- **Product grid is mono-brand** — all six "CURATED FOR YOU" products appear to be Nike; a subscriber who wants New Balance or adidas gets no hook.
- **Cadence fatigue is visible** — four promo emails in five days (May 18–22); this send arrives without any earned pause or contrast beat.

## Recommendations

- 1. **Add a hard deadline** — "Ends Sunday" or a countdown timer in the hero is the single change that lifts this email most. "Still available" is uncertainty-safe copy for the brand but kills urgency for the buyer.
- 2. **Rotate the hero image** — even a 10% crop shift or different colorway hero signals "new send" to the subscriber who opened yesterday. Same exact pool shot reinforces the feeling of a duplicate.
- 3. **Subject: replace "still available" with a deadline frame** — see alts below.
- 4. **Diversify the product grid** — one row of Nike, one row of non-Nike brands shows range and captures different intent signals.
- 5. **Preheader should name a specific product or deadline** — if the grid has the user's size in stock, say so in the preheader.
- **Subject Alt A:** `Sale ends soon: up to 50% off top styles 🔥`
- **Subject Alt B:** `Your 50% off picks are selling out`
- **Preheader Alt A:** `Nike, New Balance, adidas — sale prices ending this weekend.`
- **Preheader Alt B:** `The styles curated for you are going fast. Shop before they're gone.`

### 3. Rendering & Accessibility

**[HIGH] CSS selector typo — col-9 mobile width broken**
```css
/* Line in media query: */
.fluid-row .col-9, .md-fluid-row .col-8 { width: 74.25% !important; }
```
`.md-fluid-row .col-9` is never assigned a mobile width; `.md-fluid-row .col-8` receives two conflicting rules (16.5% and 74.25%). Any `md-fluid-row` 9-column layout will render at desktop width on mobile.

**[MEDIUM] `<html>` missing `lang` attribute**
```html
<html>  <!-- no lang="en" -->
```
Screen readers cannot infer document language; fails WCAG 3.1.1.

**[MEDIUM] Text-size-adjust disabled globally**
```css
div,p,a,li,span,td { -webkit-text-size-adjust: none !important; }
```
Suppresses iOS automatic text scaling across all elements. If any text is sized below ~13px, it will remain illegible on small screens with no user recourse.

**[LOW] External render-blocking stylesheet**
```html
<link rel="stylesheet" href="https://partner-fonts.bluecore.com/footlocker/footlocker_fonts_1776712244.css">
```
Render depends on Bluecore CDN availability. No `font-display` fallback is possible in email context. A CDN outage produces unstyled text.

**[LOW] Bluecore widget CSS uses fixed pixel heights**
```css
#widget_e49baa1ed820190ce870bdb4227b53c7 .name { height: 24px !important; }
#widget_e49baa1ed820190ce870bdb4227b53c7 .gender_age { height: 25px !important; }
```
Product name/gender/color cells clamp to fixed heights. Long product names or localized strings will overflow or clip.
