# Reserve the adidas x Bad Bunny F50 Ghost Spirit!
**Score:** 8/10 · **Type:** Email audit · **2026-07-14**
## What's working

- **Countdown timers are correctly placed** — directly below each product image, right above the CTA, so urgency and action are in one eyeline.
- **High-contrast black hero blocks** — bold white type on black isolates each drop and makes the reservation deadline impossible to miss.
- **Two drops, one deadline** — pairing Bad Bunny collab with Jordan Retro 3 True Blue adds value without splitting urgency since both close at the same time.
- **FLX Rewards integration** — member benefit banner in the header and a dedicated strip in the footer reinforce loyalty without interrupting the reservation flow.
- **Cadence is right** — after the July 12 BTS content email, this exclusive launch reads as a gear-shift worth opening rather than another promo blast.

## What's weak

- **Subject says "Ghost Spirit," email body says "Ghost SPRINT"** — if this is wrong in the subject, any sneakerhead who looked this shoe up already knows the right name, and the mismatch damages trust; QC miss that should have been caught.
- **"Top Recommendations" section kills the single-action focus** — five generic product tiles (caps, shorts, sneakers) directly after the Jordan block scatter attention when the only job left is "Reserve before 7/17."
- **Preheader is wasted** — "View in Browser" text is visible at the top of the render, meaning the preview slot in the inbox is almost certainly leaking boilerplate instead of amplifying the collab hook.
- **No FLX-exclusive angle on the reservation** — FLX Rewards members appear throughout the footer and header, but the email never frames this as "your early-access window" — a missed opportunity to make members feel chosen.

## Recommendations

- 1. **Fix Spirit vs. Sprint before anything else** — whichever is the correct product name, the subject line and email body must match. A sneakerhead who googled this would notice immediately, and it signals sloppy QC on an exclusive launch.
- 2. **Cut the "Top Recommendations" section entirely** — this is a reservation email with a hard deadline. Every pixel below the Jordan Retro 3 block should be pushing toward "Reserve before 7/17 at 4 PM ET," not selling New Era caps.
- 3. **Add FLX-exclusive framing** — one line like "As an FLX member, lock in your reservation before the public window opens" costs nothing and converts a broadcast into a member moment.
- 4. **Write a real preheader** — the inbox trio of sender + subject + preview is only working at two-thirds capacity right now.
- **Subject Alt A:** `Bad Bunny x adidas F50 Ghost — reservation closes 7/17`
- **Subject Alt B:** `FLX: Reserve Bad Bunny F50 + Jordan Retro 3 True Blue now`
- **Preheader Alt A:** `Countdown live — 3 days to lock in your spot before 4 PM ET`
- **Preheader Alt B:** `Two heat drops, one deadline: Bad Bunny collab + True Blue close 7/17`

### 3. Rendering & Accessibility

**CSS selector bug — col-9 responsive width broken:**
```css
/* Line in the <style> block */
.fluid-row .col-9,.md-fluid-row .col-8 { width: 74.25% !important; }
```
The second selector is `.md-fluid-row .col-8`, which duplicates the col-8 rule defined above it. It should be `.md-fluid-row .col-9`. Any element using `.md-fluid-row .col-9` on mobile will not receive the 74.25% width and will likely collapse or fall through to a different rule.

**Missing `lang` attribute on `<html>`:**
```html
<html>  <!-- no lang="en" -->
```
Screen readers and translation tools cannot determine the content language. WCAG 2.1 §3.1.1 failure.

**External font dependency:**
```html
<link rel="stylesheet" href="https://partner-fonts.bluecore.com/footlocker/footlocker_fonts_1776712244.css">
```
External CSS is blocked by Outlook (all versions), Gmail in some configurations, and any client with remote resource blocking enabled. The email must render acceptably with system-font fallbacks — verify the fallback stack is defined inline.

**`<title>` tag:** Present and matches subject line. Good.
**Viewport meta:** Present. Good.
