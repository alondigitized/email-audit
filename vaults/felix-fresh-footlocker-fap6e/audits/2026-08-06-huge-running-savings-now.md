# HUGE running savings now!
**Score:** 7/10 · **Type:** Email audit · **2026-08-06**
## Executive summary

- Foot Locker leads with a genuinely on-subject hero this time — "ALL RUNNING SALE UP TO 40% OFF" over a HOKA and New Balance pair, which actually matches the "HUGE running savings now!" subject line. That's rarer than it should be for this brand's recent sends. But the subject itself is a spam-adjacent regression: "HUGE running savings now!" with the caps-and-exclamation combo is the weakest subject line in this brand's recent history, a step down from cleaner sells like "Get first day fresh with Vans, Converse & more."
- The bigger problem is the same one that's dogged nearly every Foot Locker send this month: after the hero, "Hot Styles" abandons running entirely — three graphic tees, a Jordan tee, a track jacket, and one more tee, zero running shoes. A subscriber who opens for "HUGE running savings" scrolls past the sale banner into an apparel catalog with no connection to the promise that got them to open. This is the fifth-plus "Up to 40% Off" markdown send since 07-28 (07-28, 08-01, 08-02 x2, 08-03, 08-04, now 08-06), and the offer is starting to feel like wallpaper rather than a reason to act today.
- Solid execution, familiar fatigue, and a subject line that undercuts its own hero. Middle-of-the-pack.

## What's working

- Hero copy ("ALL RUNNING SALE UP TO 40% OFF") directly matches the subject line's running focus — this is the first recent send where subject and hero actually agree.
- HOKA and New Balance shoes are well-lit, large, and identifiable — a real product hero, not a lifestyle shot.
- Two clear CTAs ("SHOP RUNNING STYLES ON SALE" / "SHOP THE SALE") sit right under the offer with no scroll needed.
- Clean render throughout — no overlapping text, broken images, or layout breaks.
- Category shopping block (Footwear/Apparel/Accessories/All Sale) gives a fallback path if running isn't the shopper's interest.

## What's weak

- "Hot Styles" grid is entirely apparel and non-running sneakers (graphic tees, a track jacket, a Jordan tee) — nothing reinforces the running offer that got the open.
- Subject line "HUGE running savings now!" reads as spam-adjacent (all-caps word + exclamation point) compared to this brand's better recent subjects.
- "Exclusions Apply" sits directly under the offer with no detail — same buried-caveat pattern flagged in prior audits.
- This is at minimum the sixth "Up to 40%" markdown email in under two weeks (07-28, 08-01, 08-02 x2, 08-03, 08-04, 08-06) — the offer no longer feels urgent or special.
- No loyalty/FLX-specific discount is shown — the FLX banner only pushes free shipping, not member pricing on the running sale itself.

## Recommendations

- 1. Swap the "Hot Styles" grid for actual running shoes on sale (Nike Pegasus, HOKA Clifton, adidas Ultraboost, etc.) — right now the module directly contradicts the hero and subject.
- 2. Fix the subject line — drop the caps-and-exclamation combo for something concrete and calmer.
- 3. Replace "Exclusions Apply" with a one-line specific (e.g., "Excludes new releases") so the caveat doesn't read as a hidden catch.
- 4. Vary the offer framing since this is the sixth 40%-off send in two weeks — try a category-specific stack (e.g., "extra 15% off running with FLX") to signal something new rather than repeating the same ceiling discount.
- 5. Add a real deadline ("Ends Sunday") to the hero — nothing in the render signals urgency beyond the word "now" in the subject.
- **Subject Alt A:** `Up to 40% off running shoes — HOKA, New Balance & more`
- **Subject Alt B:** `Your running shoe sale starts now: 40% off`
- **Preheader Alt A:** `HOKA, New Balance, Nike and more — running styles up to 40% off, this weekend only.`
- **Preheader Alt B:** `FLX members get free shipping on every running pair in the sale.`
