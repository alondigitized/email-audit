### 3. Rendering & Accessibility

**Confirmed issue — CSS grid selector typo (responsive layout bug):**

```css
/* Line in mobile media query: */
.fluid-row .col-9, .md-fluid-row .col-8 { width: 74.25% !important; }
```

The second selector should be `.md-fluid-row .col-9` — instead `.col-8` appears twice. This means `.md-fluid-row .col-9` columns will not resize correctly on mobile and will fall back to their desktop width, breaking the 9-column fluid layout on narrow viewports.

**`-webkit-text-size-adjust: none !important`** is applied globally to `div, p, a, li, span, td`. The `none` value (vs. `100%`) fully disables iOS auto-scaling, which fails WCAG 1.4.4 (Resize Text) for users relying on system font size settings.

**Image alt text and `role` attributes cannot be assessed** — no `<img>` tags are present in the visible truncated source.
