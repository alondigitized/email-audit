# Here to Help You Send Comfort 🤍 20% Off Sympathy Gifts
**Score:** 8/10 · **Type:** Email audit · **2026-06-11**
## Executive summary

- This is a clean tonal pivot for 1-800-Flowers — after a run of birthday themes and the relentless Double Blooms cadence, a sympathy email is the right call. The emotional scaffolding is thoughtful: the hero leads with "Support from Near & Far," an inspirational quote grounds the intent, and then the email branches into four product lanes (flowers, baskets, plants, cards). The 20% discount is visible in the top promo bar but doesn't anchor the body prominently enough for the offer to feel like the reason to act.
- The multi-section structure works for a consideration category like sympathy, where people are unsure what to send. The "Comfort Food" and "Grow Through What You Go Through" framing shows someone thought about emotional resonance, not just SKU promotion. That said, the email is trying to be both emotionally supportive content and a promotional send at the same time — and the 20% offer never gets its own dedicated moment in the body.
- The net judgment: this is a better-than-average sympathy send. The copy positioning is genuine, the design is restrained and appropriate for the occasion, and the cadence break from birthday/Double Blooms is strategically sound. But burying the discount in a top bar and then not reinforcing it in-body is a missed conversion lever on an already low-urgency occasion.

## What's working

- **Emotional arc is well-paced** — hero → inspirational quote → product categories follows a natural "you're not alone, here's how to help" narrative flow.
- **"Comfort Food" and "Grow Through What You Go Through" as section headers** — unexpected, resonant, and product-appropriate; elevates the email above a generic promo.
- **Multi-category layout** covers the full sympathy consideration set (flowers, food, plants, cards) in one scroll — reduces the "what do I even send?" friction.
- **Soft, muted palette** (whites, sage greens, light blush) is tonally correct for the occasion — no confetti-and-bold-red energy bleeding into a grief context.
- **Cadence break is earned** — after four Double Blooms sends and back-to-back birthday emails, this subject line lands fresh rather than stale.

## What's weak

- **20% off is a top-bar footnote, not a body moment** — the discount vanishes after the promo strip and never reappears in the CTAs or section headers; "SHOP GIFT BASKETS" doesn't know there's a deal on.
- **"Hope Delivered Today" section has two small side-by-side product cards** that can't communicate what makes these items sympathy-appropriate at this display size.
- **No urgency signal anywhere in the body** — sympathy is already a low-urgency occasion; without a deadline ("offer ends Sunday" or "order by X for same-day delivery"), the 20% gives no reason to act now.
- **CTA copy is generic** — "SHOP PLANTS," "SHOP GIFT BASKETS," "SHOP GREETING CARDS" are categories, not prompts; "Send Comfort Today" or "Find the Right Arrangement" would have more emotional pull.
- **Loyalty/Passport block appears only in the footer** — a moment mid-email ("Passport members save an extra 10%") would be a stronger retention signal for an occasion purchase.

## Recommendations

- 1. **Surface the 20% discount in at least one body CTA** — change "SHOP SAME DAY" to "Shop Sympathy — 20% Off" or add a mid-email offer callout. The discount is doing no work below the fold.
- 2. **Add a soft deadline** — "Offer ends Sunday, June 15" (or whenever it expires) turns a flat discount into a reason to act today rather than "sometime when I need it."
- 3. **Rewrite section CTAs to be occasion-verbed** — "Send Comfort Food" / "Gift a Living Plant" / "Write Something Meaningful" each carry more emotional weight than the category labels.
- 4. **Collapse "Hope Delivered Today" into the hero or cut it** — the two small product cards don't add clarity; a single featured arrangement shown large would create more desire.
- 5. **Move Passport benefits up one section** — sympathy is a considered purchase; reminding a member they have a savings benefit mid-email may be the tipping point.
- **Subject Alt A:** `20% Off Sympathy Gifts — We'll Help You Find the Right One`
- **Subject Alt B:** `Send Comfort Today — 20% Off Through Sunday`
- **Preheader Alt A:** `Flowers, plants, food & cards for every kind of loss — with 20% off this weekend.`
- **Preheader Alt B:** `Because sometimes you just need to let them know you're there. Save 20% on sympathy gifts.`

### 3. Rendering & Accessibility

**`maximum-scale=1` on viewport meta blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This prevents users from pinching to zoom — a WCAG 1.4.4 (Resize Text) failure and an accessibility regression on iOS/Android.

**Mobile breakpoint too narrow — 418px misses a wide range of devices**
```css
@media only screen and (max-width: 418px) { ... }
```
Modern phones (e.g., Pixel 7 at 412px CSS width, iPhone 14 Pro at 430px) may fall outside this breakpoint. Content between 419px–767px gets no responsive treatment. Consider raising to `max-width: 600px` or adding a second breakpoint.

**Duplicate and redundant `img` max-width media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 640px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
The `min-width: 768px` rule is fully superseded by `min-width: 640px` and has no effect. Dead code.

**Lato `@font-face` declarations missing `mso-font-alt`**
All six Lato variants (3 weights × italic/normal) lack an `mso-font-alt` fallback, while Playfair Display correctly includes `mso-font-alt:'Times New Roman'`. In Outlook, Lato will silently fall back to the system default rather than a declared safe serif/sans. Add `mso-font-alt:'Arial'` to all Lato declarations.

**One Playfair Display variant loads `.woff` instead of `.woff2`**
```css
/* weight:900 bold italic */
src:url(...nuFRD-...nYO7KN_gGUbtM.woff2) format('woff2');  /* ← italic 900: OK */

/* weight:900 normal */
src:url(...nuFvD-...PKfsukDT.woff) format('woff');  /* ← normal 900: only .woff */
```
`.woff2` is ~30% smaller and universally supported where web fonts load at all. This variant should be updated to `.woff2`.

**External font load from `fonts.gstatic.com` will fail in most email clients**
Gmail, Outlook, and Yahoo all block or ignore externally hosted web fonts. The `mso-font-alt` fallbacks on Playfair are the correct mitigation for Outlook; ensure system-safe stack fallbacks (`font-family: 'Playfair Display', 'Times New Roman', serif`) are present on all font-using elements in the HTML, not just in `@font-face`.

**Aggressive CSS reset on `*`**
```css
* { line-height: 100%; max-height: 1000000px; ... }
```
`max-height: 1000000px` is a known Gmail line-height bug workaround and is intentional. However, `line-height: 100%` as a universal reset can collapse text spacing on certain elements in Gmail's rendering engine. Scope this to `td, p, a` rather than the universal selector.
