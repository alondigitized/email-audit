# Celebrate Them + Get $13.80 Credit 🎉🌸
**Score:** 7/10 · **Type:** Email audit · **2026-07-25**
## Executive summary

- This is 1-800-Flowers running the same editorial numbered-listicle format as the July 23 "My Summer Birthday Faves" send — just two days later, with a different headline: "The 5 Hottest Birthday Blooms." Five numbered bouquets, product-editorial style, "SHOP TRENDING" CTA. The format hasn't changed, the concept hasn't changed, and the executional quality hasn't improved.
- The $13.80 credit in the subject is the one new element, and it undermines itself: that oddly specific amount reads like a loyalty account balance being liquidated, not a promotional incentive. It's not surfaced prominently in the body hero — the eye lands on the listicle, not the credit — so the subject promise and the body payoff are misaligned.
- The brand's two best sends this month (July 20: 9/10; July 21: 8/10) were single-concept, visually punchy, with a clear price anchor and a tight product focus. This email is the editorial listicle for the second time in 72 hours, and it's scoring worse each iteration.

## What's working

- **$13.80 credit is surfaced at the top** — a banner above the hero communicates the credit unlocked, so the subject line at least has a visible callback in the render.
- **Five distinct bouquets give options** — range from Pacific Drift to Warm Sunset to Celebrate the Day; variety matters for gifting decisions.
- **Clean render** — no broken images, no overlapping text, images load correctly across all five product slots.
- **"SHOP BY CATEGORY" grid below the fold** — useful secondary nav (Birthday, Same Day, Plants) for undecided buyers.

## What's weak

- **Same listicle format recycled immediately** — July 23 ran "My Summer Birthday Faves" (5 items, numbered editorial). This is structurally identical two days later; a repeat subscriber will feel zero novelty.
- **$13.80 is a confusing anchor** — odd-cent credits feel like leftover account balance, not a compelling promotional offer. Compare to the clean "20% off" or "double blooms" concepts that drove their best July numbers.
- **Subject promise ≠ body hero** — the subject sells the credit; the body leads with the listicle. A subscriber who opens expecting "here's your credit, here's what to spend it on" gets a product roundup instead.
- **No price anchors on the products** — unlike the July 20 send (which had a $44 anchor price clearly visible per bouquet), none of the five products show prices. The credit offer is meaningless without a price to apply it to.
- **No urgency mechanism anywhere** — no expiration on the credit, no "offer ends tonight," no same-day-delivery hook like the strong July 22 send.

## Recommendations

- 1. **Make the credit the hero, not the listicle.** One large product, one price, one line: "Your $13.80 credit brings this $50 bouquet down to $36.20 — order before midnight." That's the July 20 formula. The listicle buries the lede.
- 2. **Add a credit expiration.** "Your $13.80 credit expires in 48 hours" turns an account-balance-cleanup email into an urgency email. One line, massive lift.
- 3. **Show at least one price.** Every product image needs a "Was $X / Now $X with your credit" treatment. The credit is meaningless floating in a price-free listicle.
- 4. **Kill the listicle for one send.** Two listicles in three days is creative fatigue. Rotate back to the single-product hero that hit 9/10 on July 20.
- 5. **Preview text should do work.** If the preview is defaulting to "view in browser" or junk, swap it to: "Your $13.80 credit expires soon — here's the bouquet to spend it on."
- **Subject Alt A:** `Your $13.80 credit expires soon 🌸`
- **Subject Alt B:** `$13.80 off your next bouquet — use it today`
- **Preheader Alt A:** `Pick one of our 5 hottest birthday blooms before your credit disappears.`
- **Preheader Alt B:** `Your credit covers half of a $30 bouquet. Don't let it sit there.`

### 3. Rendering & Accessibility

**3a. Mobile breakpoint too narrow for modern devices**
```css
@media only screen and (max-width: 418px) { ... }
```
iPhone 15 Pro Max has a 430px logical viewport — it would NOT trigger this breakpoint and receives the desktop layout at mobile size. The `.mobile { width: 414px }` class targets iPhone 6/7/8 specifically. Recommend raising breakpoint to `480px` or `600px`.

**3b. Dark mode declared but not implemented**
```html
<meta name="color-scheme" content="light dark">
<meta name="supported-color-schemes" content="light dark">
```
```css
:root { color-scheme: light dark; supported-color-schemes: light dark; }
```
These declarations signal dark mode support to Apple Mail, iOS Mail, and Samsung Mail — but there are **zero** `@media (prefers-color-scheme: dark)` override blocks in the stylesheet. These clients will attempt automatic color inversion, producing white-on-white or washed-out inversions on dark backgrounds. Either add dark mode overrides or remove the declarations entirely to opt out.

**3c. Global `line-height: 100%` on all elements**
```css
* { line-height: 100%; ... }
```
This Outlook reset hack fires in all clients. A `line-height` equal to font-size eliminates leading on every `<p>`, `<td>`, and `<span>` that doesn't override it inline. Body copy will appear cramped in non-Outlook clients.

**3d. Global `p { text-align: center }`**
All paragraph elements are center-aligned by default. Any left-aligned body copy rendered in `<p>` tags requires inline overrides or it will be unintentionally centered.

**3e. Redundant media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 640px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
The 768px block is dead code — the 640px query already covers all viewports ≥640px with the same rule. Minor bloat, no functional impact.

**3f. Playfair Display weight 900 uses `.woff` instead of `.woff2`**
```css
/* All other weights: */
src: url(...) format('woff2');

/* Weight 900: */
src: url(https://fonts.gstatic.com/s/playfairdisplay/v22/...btM.woff) format('woff');
```
Inconsistent with all other `@font-face` declarations. WOFF is ~30% larger than WOFF2 and this weight will load slower where web fonts render (Apple Mail, Samsung Mail).

**3g. Missing `mso-font-alt` on all Lato `@font-face` declarations**
Playfair Display includes `mso-font-alt: 'Times New Roman'` as an Outlook fallback; none of the six Lato variants do. Outlook will substitute the system default font (typically Calibri or Times New Roman) rather than a specified sans-serif fallback like Arial.
