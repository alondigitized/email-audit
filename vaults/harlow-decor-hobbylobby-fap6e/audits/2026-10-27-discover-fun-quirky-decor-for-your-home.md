# Discover Fun & Quirky Decor For Your Home
**Score:** 6/10 · **Type:** Email audit · **2026-10-27**

- The 40% Home Decor hero is large, high-contrast and clearly tied to the subject.
- The category tiles (Doormats, Sheet Sets, Canvas Art, Wall Clocks) show real products and give many specific click paths.
- The render is clean. Nothing is broken or overlapping, and the images load.
- The brand is instantly recognizable, and the season (fall plus Christmas) is current.

## What's weak

- The first screen leads with a free-shipping bar and a banner, not the decor hero. The hero starts well below the fold.
- "Quirky" isn't backed by anything visible. The email reads as generic merchandise, not a curated edit.

## Technical Audit

## 1. Technical Summary
The visible HTML is a table-based ESP template (Outlook conditional comments, VML/Office namespaces) with a few invalid CSS declarations. The automated QA reported 0 failures and 4 warnings. Two of those warnings (the missing headers) are probably relay artifacts. The source was truncated, so the body, footer and link list were not reviewable.

## 2. Link & Tracking Issues
- **Link probing was partial.** 12 material links were probed and 40 were skipped. The QA data gives no per-link status codes, so redirect chains and 4xx/5xx responses can't be assessed.
- **Plain-text part is mostly URLs.** 14,943 of 17,150 characters (~87%) are URLs, over the 70% threshold. This points to long tracked redirect URLs and a plain-text alternative that is probably auto-generated. It can raise spam-filter scores.
- **Tracked images.** Images are served from the click-tracking domain, `link.hobbylobby.com/mo/...`. This is normal ESP behavior, but it means image rendering depends on that domain staying up.

## 3. Rendering & Accessibility
- **Missing alt text.** `https://link.hobbylobby.com/mo/eORqXTkAb7_837015858_141895_516026_150921.gif` has no alt attribute. The `/mo/` path and the `.gif` extension suggest it is a 1×1 open-tracking pixel. If so, the impact is minor, though `alt=""` is still the correct fix. If it is a visible image, it is a real accessibility gap. The truncated source doesn't let me confirm which.
- **Invalid CSS in the `<style>` block.**
  - `.ctacr1 {color:; ... -moz-border-radius:px; -webkit-border-radius:px; border-radius:px;}` has empty values. The `color` and radius declarations are dropped, so the CTA has no corner radius. Its text color depends on inheritance from other rules.
  - `.lhp2 {... verticl-align:middle;}` is a typo (`verticl-align`), so the vertical alignment never applies.
- **Mobile breakpoint.** The only visible media query is `@media only screen and (max-width:300px)`. That is far below any phone viewport width (typically 320–480px), so the responsive rules (`.fl`, `.fw`, `.image`, `.h1`) would not fire on common devices. The source is truncated, so a later query may exist. If not, the mobile layout is effectively non-responsive.
- **Non-standard markup.**
  - The `<html>` element carries the non-standard attribute `e-locale="en-US"`.
  - The document mixes an HTML 4.01 doctype with `xmlns` attributes.
  - The `<title>` is the generic "Hobby Lobby".
  - None of these usually breaks rendering in major clients.

## 4. Personalization & Merge Tokens
No issues found. No unresolved merge tokens (e.g. `{{...}}`, `%%...%%`) appear in the visible source. The truncated remainder was not checked.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe not found (WARN).** The QA notes it may not be captured by the AgentMail relay, so this is unconfirmed.
- **List-Unsubscribe-Post not found (WARN).** The same caveat applies. RFC 8058 one-click unsubscribe is a Gmail/Yahoo bulk-sender requirement. Verify against the raw headers before concluding it is missing.
- **Authentication-Results not found (WARN).** The relay is expected to strip it, so SPF, DKIM and DMARC status is unknown. This is a gap in the test data, not a confirmed sender failure.
- **Footer.** The in-body unsubscribe link and postal address are not visible in the truncated source. The QA says an unsubscribe link was included in probing, but gives no result.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Not assessable. No destination URLs, UTM parameters or probe results are in the provided data. Links go through the `link.hobbylobby.com` redirector, so UTM and landing-page behavior can only be checked by following the redirects.

## 7. Recommendations
1. Check the raw message headers (outside the relay) for `List-Unsubscribe`, `List-Unsubscribe-Post: List-Unsubscribe=One-Click`, and SPF/DKIM/DMARC alignment for `create.hobbylobby.com`.

3. Fix the CSS: give `.ctacr1` real `color` and `border-radius` values, and correct `verticl-align` to `vertical-align`.
