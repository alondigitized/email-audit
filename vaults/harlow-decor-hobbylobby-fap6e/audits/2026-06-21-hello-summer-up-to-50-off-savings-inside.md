# Hello Summer ☀️ Up To 50% Off Savings Inside
**Score:** 7/10 · **Type:** Email audit · **2026-06-21**
## Executive summary

- This is Hobby Lobby's "Hello Summer" send — and it's essentially the same mega-digest circular format as the June 18 "Up To 75% Off Savings Inside!" send, dressed up with a seasonal banner. The email stacks every department in the store — Home Decor, Textiles, Furniture, 4th of July, Classroom Decor, Dorm Essentials, Party, Floral, Frames, Yarn, Jewelry Making, Sewing Notions, Custom Frames — top to bottom like a printed insert, not a targeted email. There is no single hero moment.
- The one genuinely useful thing in here is the 4th of July section, arriving June 21 — thirteen days out. That's a credible, timely angle that should have led the entire send. Instead it's buried four sections deep in a wall of competing 40% badges.
- The "Hello Summer" branding is a missed opportunity. Hobby Lobby had a real seasonal peg here — summer crafts, outdoor entertaining, patriotic DIY — but chose to repurpose the weekly sale dump with a new header rather than build a focused send around it. The result is fatiguing, not energizing.

## What's working

- **4th of July section is genuinely timely** — 13 days of lead time is appropriate, and the patriotic product imagery is visible.
- **No render bugs** — the email displays cleanly; no broken images or layout failures visible.
- **Concrete discounts are everywhere** — 40%, 50%, 30%, 99¢ — no vagueness about whether a sale is happening.
- **"Hello Summer" header adds at least minimal seasonal signal** that differentiates this from an identical mid-winter send.

## What's weak

- **Same format as June 18 — again.** Subscribers who already sat through "Up To 75% Off Savings Inside!" are looking at an identical layout with a different banner. Creative fatigue is visible in the template itself.
- **No visual hierarchy** — eighteen sections compete at equal weight; the eye has nowhere to land.
- **Subject promises "Up To 50% Off" but the hero opens at 40% off Home Decor** — a small bait-and-switch that erodes trust.
- **4th of July — the most timely, differentiated section — is buried** at position four or five, not leading.
- **No single CTA button** — navigation is a wall of clickable section tiles, no one action feels primary.

## Recommendations

- 1. **Lead with 4th of July and make it the whole email** — this is the only angle with genuine urgency right now. One hero, one offer, one CTA. Save the mega-digest for the weekend sale push.
- 2. **Cut to five sections max** — Hobby Lobby's best recent send (June 17, 8/10) used a single category hero. The department count here is self-defeating.
- 3. **Add a single end-date to the offer** — "Ends Sunday" or "This week only" would add real urgency that the current email completely lacks.
- 4. **Match subject to hero** — if the first visible offer is 40% off Home Decor, say 40% in the subject; don't promise 50% then open lower.
- **Subject Alt A:** `4th of July Starts Now — 50% Off Décor & Party`
- **Subject Alt B:** `Red, White & Craft: 50% Off July 4th Picks`
- **Preheader Alt A:** `Flags, florals, and outdoor entertaining — all on sale through Sunday`
- **Preheader Alt B:** `13 days to go. Shop the July 4th sale before it ends.`

## Technical Audit — Hobby Lobby "Hello Summer" Email

---

### 1. Technical Summary

The email is a standard ESP-rendered HTML 4.01 Transitional template with Outlook VML support. Three CSS authoring defects in the rendered stylesheet will silently break CTA button styling; compliance headers are unverifiable at the relay layer.

---

### 2. Link & Tracking Issues

**No issues confirmed in the HTML source.** All links route through `link.hobbylobby.com` (ESP click-tracking redirect), which is expected. The open-pixel GIF also fires from `link.hobbylobby.com/mo/…`, consistent with the same tracking domain.

**QA flag — plain-text URL density:**
- 12,186 of 13,777 plain-text chars are URLs (88.5%), well above the 70% threshold.
- A plain-text alternative this URL-dense is effectively unreadable and may trigger Baracuda/SpamAssassin `URI_RATIO` rules. The plain-text version should summarize content in prose with 3–5 representative links rather than mirroring every tracked redirect.

---

### 3. Rendering & Accessibility

**Bug — malformed `border-radius` in `.ctacr1`:**
```css
.ctacr1 {
  -moz-border-radius:px;
  -webkit-border-radius:px;
  border-radius:px;
}
```
Missing numeric value before `px` — all three `border-radius` declarations are invalid and will be silently dropped. Any CTA button using `.ctacr1` renders with no border-radius in all clients.

**Bug — empty `color` value in `.ctacr1`:**
```css
.ctacr1 { color:; ... }
```
Empty value; the browser/client inherits color from the parent instead of whatever was intended. If the button text was meant to be a specific color, it will not apply.

**Bug — typo in `.lhp2`:**
```css
.lhp2, .lhp2 font { line-height:1.2; verticl-align:middle; }
```
`verticl-align` is not a valid CSS property (missing `a`). Vertical alignment will not apply for elements using this class.

**QA flag — missing alt text on tracking GIF:**
- `eORqXTkAb7_837015858_126693_3574496_136680.gif` has no `alt` attribute.
- Screen readers will announce the raw filename. Add `alt=""` to suppress the announcement (tracking pixels should be decorative-empty, not unnamed).

### 5. Compliance

**WARN — `List-Unsubscribe` header not captured:**
The QA relay did not observe a `List-Unsubscribe` header. Gmail and Outlook use this header to surface their native unsubscribe UI. For bulk senders (>5k/day to Gmail), its absence risks the "Report Spam" path being the only visible opt-out. Verify the header is set at the ESP send layer, not suppressed by the AgentMail relay.

**WARN — `List-Unsubscribe-Post` (RFC 8058) not captured:**
One-click unsubscribe (required by Gmail/Yahoo bulk sender policies since Feb 2024) depends on this header. Same caveat — may be a relay capture issue, but must be confirmed present in live send headers.

**WARN — `Authentication-Results` not captured:**
SPF, DKIM, and DMARC pass/fail status is unknown from this capture. `noreply@create.hobbylobby.com` sending via `link.hobbylobby.com` is a cross-subdomain pattern — confirm DKIM `d=` aligns with the From domain or an aligned subdomain, and that DMARC is not in `p=reject` mode for misaligned sends.

CAN-SPAM physical address and unsubscribe link: present in footer (visible from standard Hobby Lobby template pattern); no issues flagged from the HTML source.
