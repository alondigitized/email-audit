# Up To 75% Off Savings Inside
**Score:** 4/10 · **Type:** Email audit · **2026-07-09**
## Executive summary

- This is Hobby Lobby's mega-circular in its most familiar form — the same stacked two-column tile grid that has run on July 2, July 7, and now July 9, with only the headline discount swapped out. "Up To 75% Off" is the most aggressive number they've put in a subject line this week, and the email technically earns it: there's a Spring Shop Home Decor section mid-scroll showing 75% off. But "up to" is weasel language, and the hero above the fold opens at 40% — so the subject sets an expectation the first screen doesn't meet.
- More damaging: there's a July 4th tile still visible in the email on July 9th. Stale campaign imagery isn't a minor oversight — it tells the subscriber you're sending recycled creative on a batch scheduler. And "The Spring Shop" continues to appear in mid-July, a category name that's been past-season since May. The FALL FLORAL and FALL DECOR sections actually land better — forward-positioning to fall in early July is defensible — but they're buried under the more confused messaging above.
- Bottom line: the 75% hook is the best subject line Hobby Lobby has written this week, but it's propped up by a body that can't deliver on arrival.

## What's working

- **75% off is a real number** — the Spring Shop Home Decor section in the body actually carries the 75% label, so the subject isn't pure fabrication.
- **Fall pivot makes sense in early July** — FALL FLORAL and FALL DECOR sections position the brand ahead of the season, which is smart inventory timing.
- **DORM section continues the back-to-school thread** started July 5 — this is one of few signs of cross-email narrative continuity.
- **Subject line is short (30 chars)** — mobile-friendly and clean, even if the content is diluted.
- **No visible render bugs** — tiles load, text is legible, layout is intact.

## What's weak

- **July 4th tile is still live on July 9** — stale promotional imagery actively signals lazy scheduling to anyone who notices.
- **The Spring Shop label in July** — "Spring Shop" is a category that should have rolled off four to six weeks ago; it reads as clearance masquerading as a campaign.
- **"Up To 75% Off" buries the lead** — the 75% lives in the third content block; the first thing you see is 40% off Home Decor, which undersells the subject promise.
- **No CTA buttons anywhere** — it's an entirely tile-based layout with no primary action anchoring the email; click destination for any tile is ambiguous from the render.
- **Eighth Hobby Lobby email in nine days** — cadence fatigue is real, and this send adds nothing meaningfully different from July 7's Spring Shop send.

## Recommendations

- 1. **Lead with the 75% section, not 40%** — reorder the tiles so Spring Shop Home Decor 75% is the hero block above the fold. The subject promises it; the body should deliver it before the first scroll.
- 2. **Kill the July 4th tile immediately** — replace it with a Fall Decor teaser or a DORM hero image; anything that reads as current.
- 3. **Retire "Spring Shop" or rebrand it "Summer Clearance"** — the category name is doing active damage in July.
- 4. **Add at least one CTA button** — a single "Shop 75% Off" button under the hero section would give the click a clear destination and anchor the hierarchy.
- 5. **Add an expiry** — "This week only" or "Ends Sunday" turns a passive promo into a reason to act today.

- **Subject Alt B:** `Fall Decor Is Here — Plus 75% Off Inside`
- **Preheader Alt A:** `Spring Shop clearance hits 75% off — plus new Fall Floral arrivals just landed.`
- **Preheader Alt B:** `Dorm, Fall Decor, and Home Decor up to 75% off — all in one place.`

### 2. Link & Tracking Issues

**Plain-text version is URL-saturated**
- 12,732 of 14,348 chars (88.7%) in the plain-text part are URLs — well above the 70% QA threshold.
- This is a known spam-filter signal. It typically indicates the plain-text was auto-generated by the ESP by stripping HTML without collapsing redundant tracking links.
- **Evidence:** QA warning `Plain-text is >70% URLs: 12732/14348 chars are URLs`
- **Fix:** Configure the ESP to generate a human-readable plain-text alternative rather than a raw link dump.

**Tracking domain**
- All links route through `link.hobbylobby.com` (click tracking). No issues with the domain itself, but authentication status is unknown (see §5).

### 3. Rendering & Accessibility

**Missing alt text on tracked GIF**
- `eORqXTkAb7_837015858_129961_3826464_137855.gif` (served from `link.hobbylobby.com`) has no `alt` attribute.
- **Evidence:** QA warning `Image missing alt text: eORqXTkAb7_837015858_129961_3826464_137855.gif`
- This is likely a tracking pixel or a decorative separator. If decorative: add `alt=""`. If content-bearing: add descriptive alt text.

**CSS typo in `.lhp2`**
- `.lhp2, .lhp2 font { line-height:1.2; verticl-align:middle; }` — `verticl-align` is misspelled (missing `a`). Property is silently ignored in all clients.
- **Evidence:** HTML source, embedded `<style>` block.

**`.ctacr1` has empty border-radius values**
- `.ctacr1 { border-radius:px; -moz-border-radius:px; -webkit-border-radius:px; }` — unit without value renders as invalid. Likely should be `0px` or a specific radius. Harmless but sloppy.

**Viewport meta lacks `width=device-width`**
- `<meta name="viewport" content="initial-scale=1, user-scalable=yes">` is missing `width=device-width`, which can cause inconsistent initial rendering on some mobile clients before media queries apply.

**Doctype is HTML 4.01 Transitional**
- Expected for legacy email; no issue per se, but `xmlns:v` and `xmlns:o` VML namespaces are only needed if MSO VML shapes are actually used. If not used, these are dead weight.

### 5. Compliance

**List-Unsubscribe header not present (or not captured)**
- **Evidence:** QA warning `List-Unsubscribe header not found`
- Gmail and Yahoo require `List-Unsubscribe` for bulk senders (>5k/day) as of February 2024. Absence risks inbox demotion or bulk classification.
- If the header is set by the ESP but stripped by the AgentMail relay, the relay's header pass-through config needs adjustment. If it's genuinely absent, the ESP send configuration must be updated.

**List-Unsubscribe-Post (RFC 8058) not present**
- **Evidence:** QA warning `List-Unsubscribe-Post header not found`
- One-click unsubscribe (Gmail/Yahoo requirement for bulk senders) requires both `List-Unsubscribe: <https://...>` and `List-Unsubscribe-Post: List-Unsubscribe=One-Click`. Missing this header means recipients must navigate a multi-step flow, which violates current bulk sender requirements.

**SPF/DKIM authentication status unknown**
- **Evidence:** QA warning `Authentication-Results header not found`
- Cannot confirm DMARC alignment. The AgentMail relay should preserve or inject `Authentication-Results`. Without it, SPF/DKIM pass/fail status is unverifiable from the captured artifact.
- Sending domain is `create.hobbylobby.com`; DKIM should be signed under `hobbylobby.com` or `create.hobbylobby.com`. Needs direct header inspection at delivery.

**CAN-SPAM physical address**
