# Don’t miss up to 25% off select shoes.
**Score:** 8/10 · **Type:** Email audit · **2026-06-13**
## Executive summary

- Well, here comes New Balance again with another "Don't miss out" percentage-off email. I've been watching these land in my inbox for weeks now — June 3rd was 25% off, June 7th was 25% off, and now June 25th is… also 25% off. At some point "Don't miss out" starts to feel less like urgency and more like the brand crying wolf. My thumb almost just slid past this one on reflex.
- That said, once I opened it, the bones are solid enough. The offer is clear — 25% on shoes, 30% on clothes, use JUNESALE — and the layout doesn't make me fight to find the button. The price-tier grid in the middle is a smart shortcut for sorting where my budget falls. But then I scroll down to "More to explore" and I'm looking at a white cotton t-shirt on what looks like a 30-year-old guy. That's not me, and that's not why I'm here.
- The shoes in the tiles are a mixed bag. The Fresh Foam 680v8 catches my eye — I know that line has some cushioning behind it — but nothing in this email says "comfort" or "arch support" or "walking." It could be an email for a high school track athlete or a guy my age and there's no way to tell which. I'd mark this read and maybe circle back later through the website, but I wouldn't forward it to anyone.

## What's working

- **Offer is immediately legible** — "up to 25% off select shoes" + promo code JUNESALE is visible above the fold without any mystery.
- **Price-tier grid is genuinely useful** — Under $50 / $50–$100 / $100–$150 / $150+ lets me self-sort without scrolling through a wall of products.
- **Clean layout, no render issues** — No broken images, no overlapping text, nothing looks blown up or clipped on mobile.
- **Free shipping threshold is front-and-center** — $75 free shipping is exactly the kind of detail I need before I decide whether a shoe is worth buying online vs. driving to the store.
- **Fresh Foam 680v8 tile** — That one product, buried near the bottom, is actually in my wheelhouse. If I hadn't spotted it I wouldn't have noted it, but credit where it's due.

## What's weak

- **The hero image is a stack of red boxes, not shoes** — I have no idea what I'm about to buy. Show me a shoe on a foot, not packaging on a shelf.
- **"More to explore" includes a T-shirt on a young model** — I came here for shoes and now I'm looking at a cotton tee. That's noise, not signal, for me.
- **Zero comfort language anywhere in this email** — No "cushion," no "arch support," no "walking," no "wide width." These are the words that make me stop scrolling and read closer.
- **This feels like the third or fourth identical sale email** — I reviewed a "Now on: Enjoy up to 25% off select shoes" send back on June 7th. The creative looks nearly identical. At this cadence, the discount stops feeling like a deal and starts feeling like the regular price.
- **Fine print is unreadable on mobile** — I can see there's terms text below the CTA but I can't make out the deadline. If the sale expires on a specific date, put that somewhere I can actually read it.

## Recommendations

- 1. **Lead with a shoe, not a box** — Swap the stacked red-box hero for an on-foot shot of one of the walking or Fresh Foam styles. Give me something to imagine on my feet, not a warehouse shelf.
- 2. **Add one comfort hook to the hero copy** — Even a single line like "Built for all-day comfort" underneath "Don't miss out" would signal that this email is for me, not just anyone with feet.
- 3. **Drop the T-shirt tile or move clothing to a second email** — If I'm opening a shoe sale email, don't interrupt it with a cotton shirt. Save that upsell for a separate clothes send.
- 4. **Make the deadline visible** — Put the sale end date in large type right next to the CTA button. "Sale ends June 30" does more work than "Don't miss out."
- 5. **Differentiate this send from the June 7th one** — Rotate the discount angle. Lead with specific shoe families, not a blanket percentage. "25% off Fresh Foam walking shoes" would have stopped me cold.

## Technical Audit — New Balance "Up to 25% Off" Email

---

### 1. Technical Summary

The email uses a standard HTML 4.01 Transitional + table-based layout with dark mode support via `prefers-color-scheme`. Several code-level defects are confirmed in the truncated source: a plaintext HTTP asset URL containing an unreplaced placeholder, malformed `@font-face` declarations with no `src:`, and a duplicate CSS class producing a cascade conflict. Full link/compliance verification is blocked by source truncation.

---

### 2. Link & Tracking Issues

**HTTP asset with unreplaced placeholder token**
```css
.bgwhite {
  background-image: url('http://image.XXXXX.png');
}
```
Two issues in one rule:
- Protocol is `http://`, not `https://`. Modern email clients (Gmail, Outlook 365) block mixed-content assets and will show a broken image or strip the background entirely.
- `XXXXX` is an unfilled template variable. This image will 404 regardless of protocol.

**Cannot verify CTA link tracking** — source is truncated before the `<body>` product links. UTM parameters, click-tracking redirects, and tracking pixel `<img>` tags require the full source to audit.

---

### 3. Rendering & Accessibility

**Malformed `@font-face` declarations — no `src:` property**

All nine `@font-face` blocks declare `font-family`, `font-weight`, and `font-style` but omit the `src:` URL entirely:
```css
@font-face {
  font-family: proxima-nova, sans-serif;
  font-weight: 700;
  font-style: normal;
  /* no src: — font will never load */
}
```
Email clients that respect standard CSS (Apple Mail, Outlook for iOS/Android) will silently fall through to the declared fallbacks (`Arial`, `sans-serif`, `Times New Roman`). The fallback stack is reasonable, so rendering degrades gracefully — but the web font intent is defeated.

**Duplicate `.bg1` class — cascade conflict**
```css
/* line 1 */
.bg1 { background-color: #ffffff; }

/* line 2, later in same <style> block */
.bg1 { background: #58546d; }  /* purple-gray, overrides #ffffff */
```
Any element using `.bg1` will render with a purple-gray (`#58546d`) background, not white. This is likely a template merge error where a promotional variant's styles overwrote the base class.

**Missing `http-equiv` attribute on IE meta tag**
```html
<meta content="IE=edge" />
```
Correct form is:
```html
<meta http-equiv="X-UA-Compatible" content="IE=edge" />
```
Omitting `http-equiv` makes this tag a no-op. Low impact today but technically malformed.

**Mixed doctype/namespace**
The document declares `HTML 4.01 Transitional` but includes an XHTML namespace (`xmlns="http://www.w3.org/1999/xhtml"`). This is a common (and harmless) pattern in legacy email templates, but parsers in strict mode may reject self-closing tags like `<meta ... />`.

**Dark mode — forced link color**
```css
@media (prefers-color-scheme: dark) {
  a { color: #cf0a2c !important; }
}
```
The `!important` override applies to **all** anchor tags in dark mode, including footer compliance links and nav items. Red (`#cf0a2c`) on a dark background (`#151415`) passes contrast at large sizes but should be verified against WCAG AA (4.5:1) for small footer text.
