## Technical Audit — Skechers PLUS "Ready For Kick Off?" (2026-05-27)

---

### 1. Technical Summary

The email is structurally sound but has one broken-experience bug (empty merge token in greeting) and a widespread HTTP/mixed-content issue affecting 13 image assets served from `image.emails.skechers.com`. No critical compliance gaps found.

---

### 2. Link & Tracking Issues

**No broken destination links confirmed** — 27 click-redirect links through `click.emails.skechers.com` were skipped by the HTTP probe (expected behavior for tracking redirects; not flagged as broken).

**Third-party pixel exposure:** Three beacon pixels fire on open:
- `beacon.krxd.net` — user-match pixel with hashed subscriber UID (`partner_uid=9153f33f...`) and a plain subscriber ID (`partner_uid=121173391`). The plain integer ID in the second pixel is a potential PII vector if Krux/Salesforce DMP data is ever cross-referenced.
- `ink1000.com` tracking pixel served over **HTTP** (see §3).

---

### 3. Rendering & Accessibility

**[FAIL] 13 images served over HTTP**, all from `image.emails.skechers.com` and `ink1000.com`. Modern email clients (Gmail, Outlook.com, Apple Mail) proxy or block non-HTTPS image sources, causing these assets to appear broken or be silently suppressed.

Affected assets (representative set):
```
http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/dde00662-169f-447d-b0e2-fc65f6c2290c.png  ← Skechers logo
http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/11/49468f73-4651-4af3-bea2-61d1ae5db486.png  ← missing alt text
http://www.ink1000.com/p/up/7076d8b15a776085/o.gif?mi_u=8107766165&...  ← tracking pixel, no alt
```
App Store, Google Play, social icons (Instagram, Facebook, YouTube), Curbside Pickup, AfterPay, and Find A Store icons are all affected.

**[WARN] Two images missing `alt` text:** `o.gif` (tracking pixel — acceptable) and `49468f73...png` (functional image — needs alt).

**Dual `<style>` blocks in `<head>`:** CSS is split across two `<style>` tags. This is benign in most clients but can cause specificity ordering surprises in older Outlook builds; consolidating is low-risk cleanup.

**`-webkit-text-size-adjust: none`** is set globally. This suppresses iOS auto-sizing entirely; `100%` is the safer value to preserve legibility on small viewports without breaking layouts.

---

### 4. Personalization & Merge Tokens

**[FAIL — Broken Experience]** The greeting renders as `"Hi ,"` — the first-name merge token evaluated to an empty string. QA confirms: `Greeting has empty name field`.

This is either a missing fallback value in the ESP template or a segment that includes contacts with no `first_name` populated. The token should have a fallback, e.g.:
```
Hi {{first_name | default: "there"}},
```

No other unresolved merge tokens detected in the truncated source.

---

### 5. Compliance

**CAN-SPAM:** Physical mailing address and unsubscribe mechanism are expected in the footer (not visible in truncated source but standard for Skechers sends — no flag raised without evidence of absence).

**Sender authentication:** Sent from `no-reply@emails.skechers.com` via Salesforce Marketing Cloud infrastructure (`click.emails.skechers.com`, `image.emails.skechers.com`). No SPF/DKIM/DMARC header data provided — cannot audit authentication posture from HTML source alone.

**Preheader implementation:** Correctly hidden via `display:none !important` on `.preheader` class. Text reads "Head to Toe Skechers Comfort in Your Team Colors" — consistent with subject line topic.

---

### 6. Email-to-Site Continuity

The campaign ID `MKG_US_NA_U_LOYALTY_LOYL_EN_05272026` appears in the Krux impression beacon and the `ink1000.com` pixel, confirming consistent campaign tagging at the pixel level.

Destination URL UTM parameters cannot be confirmed from the truncated source (all 27 CTAs pass through `click.emails.skechers.com` redirects). If UTM params are appended at the redirect layer rather than the raw `href`, they should be verified in the redirect chain — a redirect failure would silently drop attribution.
