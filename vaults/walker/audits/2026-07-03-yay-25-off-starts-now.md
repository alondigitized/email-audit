### 3. Rendering & Accessibility

**Issue — Invalid `Src:` casing in all `@font-face` blocks (HIGH)**
All 10 `@font-face` rules use `Src:` (capital S) instead of the valid CSS property `src:`. Most rendering engines are lenient, but this is spec-invalid and can cause font load failures in strict parsers.
```css
/* BROKEN — appears in all 10 @font-face declarations */
Src: url("https://braze-images.com/.../original.woff") format('woff');
/* CORRECT */
src: url("https://braze-images.com/.../original.woff") format('woff');
```

**Issue — `maximum-scale=1` blocks user zoom (MEDIUM)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. This is an accessibility regression flagged by WCAG 1.4.4 (Resize Text). Removing `maximum-scale=1` is the fix.

**Issue — `text-size-adjust: none` on `*` selector (MEDIUM)**
```css
* { -webkit-text-size-adjust: 100%; -ms-text-size-adjust: none; text-size-adjust: none }
```
The unprefixed `text-size-adjust: none` overrides the 100% prefixed declarations and suppresses the user's OS-level text size accessibility setting. Should be `100%`, not `none`.

**Issue — Missing `http-equiv` on charset meta (LOW)**
```html
<!-- CURRENT (missing http-equiv) -->
<meta content="text/html; charset=utf-8" />
<!-- CORRECT -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```
Without `http-equiv="Content-Type"`, this tag is a no-op. Charset is inferred from the doctype instead, which works in practice but is technically broken markup.

**Issue — HelveticaNow fonts served as TTF only (LOW)**
Futura PT fonts are served as `.woff`, but the six HelveticaNow variants are `.ttf` only. TTF has weak email-client support. Adding a `.woff` fallback would improve rendering in Apple Mail and Outlook on Mac.

**Note — `supported-color-schemes` in CSS `:root` is non-standard**
```css
:root { supported-color-schemes: light dark; }
```
`supported-color-schemes` is valid only as a `<meta>` tag (already present). Inside CSS `:root` it is silently ignored. Not a bug in practice, but dead code.

**Alt text on images** — Cannot assess (body truncated). Flag for review: every `<img>` must have a non-empty `alt` attribute.
