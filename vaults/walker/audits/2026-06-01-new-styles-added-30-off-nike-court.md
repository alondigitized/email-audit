### 3. Rendering & Accessibility

**Conflicting responsive breakpoints — confirmed issue.**
Two separate breakpoints are defined for `.responsive-text`:
```css
/* Block 1 */
@media only screen and (max-width: 600px) { .responsive-text { font-size: 12px !important; } }
@media only screen and (min-width: 601px) { .responsive-text { font-size: 14px !important; } }

/* Block 3 (660px block) */
/* .responsive-text not redefined here, but layout classes override at 660px */
```
Devices 601–660px wide are caught by the `min-width: 601px` rule (desktop size) but also by the `max-width: 660px` layout block. Cascade order resolves this, but the gap creates unintended behavior on mid-range tablets.

**Malformed `<meta>` — confirmed.**
```html
<meta content="text/html;" charset="utf-8" />
```
This mixes two different meta syntaxes. The `content="text/html;"` attribute is only meaningful with `http-equiv="Content-Type"`, which is absent. The `charset` attribute alone is sufficient in HTML5, but the combined form as written is invalid and will be ignored by parsers. Correct forms:
- HTML5: `<meta charset="utf-8">`
- Legacy: `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">`

**Malformed IE compatibility meta — confirmed.**
```html
<meta content="IE=edge" />
```
Missing `http-equiv="X-UA-Compatible"`. Without this attribute, the directive is never read by IE/Outlook rendering engine. Should be:
```html
<meta http-equiv="X-UA-Compatible" content="IE=edge" />
```

**Redundant CSS declaration — minor.**
In the link reset block:
```css
color:inherit !important; color:inherit;
```
The second `color:inherit` is a no-op. Not a rendering bug but indicates copy-paste template debt.

**No dark mode support.**
```html
<meta name="color-scheme" content="light" />
<meta name="supported-color-schemes" content="light" />
```
Dark mode is explicitly disabled. Apple Mail and Gmail app dark mode users will see the email in forced-light mode. This is a deliberate choice but worth flagging if dark-mode readability has not been tested.
