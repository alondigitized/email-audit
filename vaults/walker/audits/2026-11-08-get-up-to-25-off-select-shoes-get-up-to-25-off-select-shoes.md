# Technical Audit: New Balance Offers, "Get up to 25% off select shoes, get up to 25% off select shoes"

## 1. Technical Summary
The email has no confirmed broken links, but the template has several code-level defects. The subject line repeats its phrase, there are placeholder and malformed CSS declarations, and three images have no alt attribute. SPF/DKIM could not be checked, and the HTML was truncated, so footer, header and UTM checks are incomplete.

## 2. Link & Tracking Issues
- **Probing coverage:** 12 material links were probed and 27 skipped. The QA data reports 0 issues, so no broken links are confirmed. The 27 skipped links are unverified.
- **Click-tracking redirects:** Assets and links sit on the ESP tracking domain `link.email.newbalance.com`. Destination URLs and parameters are not visible in the source provided.
- **Plain-text URL bloat:** 11,782 of 13,498 characters (87%) in the plain-text part are URLs. This is a spam-filter risk and makes the text part hard to read.
- **Placeholder asset URL:** The CSS rule `.bgwhite { background-image: url('http://image.XXXXX.png'); }` is an unreplaced placeholder. It also uses insecure `http://`. Clients that apply the class will request a dead URL, and mixed-content blocking is possible.
- **Template-reused asset path:** Images load from `/custloads/818512772/NBUS/myNB_Welcome/UpdatedImages/`. A promo email pulling from a "Welcome" asset folder suggests template reuse, so those assets could change independently of this campaign.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed, 3 images):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png`
  - `egR1f966kc_818512772_12589552_154033_23814982.gif`
  - The first two are content images, so any text in them is unavailable to screen readers or with images blocked.
  - The `/mo/…gif` file looks like the open-tracking pixel, which should carry `alt=""`.
- **`@font-face` rules have no `src`:** Every declaration (`proxima-nova`, `linotype-didot`, `ITC Garamond Book Condensed`, etc.) lacks a `src` descriptor, so no web fonts can load. The fallbacks `Arial` and `Times New Roman` always render. One rule also contains a stray second `font-family` declaration.
- **Doctype and namespace mismatch:** The HTML 4.01 Transitional doctype is combined with `<html xmlns="http://www.w3.org/1999/xhtml">`. The tag `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Conflicting `.bg1` rules:** `.bg1` is declared as `#ffffff` and again as `#58546d`. The later rule wins, so the white background is overridden.
- **Dark-mode link contrast:** `@media (prefers-color-scheme: dark) { a {color:#cf0a2c !important;} .bg1{background:#151415 !important;} }` forces red links onto a near-black background. My calculation gives about 3.3:1, below the WCAG AA 4.5:1 minimum for normal text. This applies wherever links sit on `.bg1`, and the truncated CSS prevents confirming the rest.
- **Title:** `<title>New Balance Template</title>` is an unedited template name.

## 4. Personalization & Merge Tokens
- **Duplicated subject phrase:** The subject is "Get up to 25% off select shoes, get up to 25% off select shoes." This looks like a subject and preheader merge, or a field concatenated twice.
- **Unresolved tokens:** None are visible in the truncated source. The `XXXXX` in the CSS is the only placeholder-style string found.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication:** `Authentication-Results` was not found, so SPF/DKIM/DMARC status is unknown. The QA tool attributes this to the AgentMail relay, so it is not a confirmed failure.
- **Unsubscribe:** The QA probe notes an unsubscribe link is always included in the probed set. The `List-Unsubscribe` and `List-Unsubscribe-Post` headers were not provided, so one-click support is unverified.
- **Physical address and sender ID:** The footer was truncated, so the postal address can't be verified. The From address `newbalance@email.newbalance.com` uses a branded subdomain, which is consistent.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)

- **Landing page alignment:** There is no data on whether the landing pages match the "up to 25% off select shoes" offer.

## 7. Recommendations
1. Fix the subject-line generation so the phrase isn't duplicated.
2. Remove or replace the `url('http://image.XXXXX.png')` placeholder, and use HTTPS for any real asset.

5. Fix the doctype and namespace mismatch and the `IE=edge` meta tag. Replace the template `<title>`.
6. Remove the duplicate `.bg1` rule. Check dark-mode link colors for 4.5:1 contrast.
7. Shorten the tracked URLs or add a cleaner text version to reduce the plain-text URL ratio.
8. Confirm SPF/DKIM/DMARC from the raw message headers. Confirm `List-Unsubscribe` and one-click headers, the footer address, and final-URL UTM values on the 27 unprobed links.
