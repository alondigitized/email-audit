## 3. Rendering & Accessibility
- **Missing alt text.** Both emltrk.com pixels (`ieezzy5m`, `0di86k1v`) have no alt. Tracking pixels should use `alt=""` with `width="1" height="1"` so screen readers skip them. This is low severity if they are 1x1 images.
- **Link styling removed globally.** The rule `a, a:link, a:visited, ... { text-decoration:none !important; color:inherit !important; }` strips color and underline from every anchor. Inline text links become indistinguishable from body copy unless they are styled elsewhere (not verifiable in the truncated source).
- **Malformed meta tags.** `<meta content="text/html;" charset="utf-8" />` lacks `http-equiv="Content-Type"`. `<meta content="IE=edge" />` lacks `http-equiv="X-UA-Compatible"`. The second one has no effect as written, and the first only works through the `charset` attribute.
- **Doctype mismatch.** The doctype is HTML 4.01 Transitional but the `<html>` tag carries `xmlns="http://www.w3.org/1999/xhtml"` and self-closing `/>` syntax. This is harmless in most clients but inconsistent.
- **Positive.** `lang="en"` is set and a viewport meta tag is present.
