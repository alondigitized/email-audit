## Technical Audit

## 1. Technical Summary
The email's markup is mostly sound, but the QA run found three problems: the Unsubscribe link returned HTTP 400 to the probe, there is no plain-text part, and 11 images load over `http://`. Several images also lack alt text. The HTML source was truncated, so findings below are limited to what the source and QA data confirm.

## 2. Link & Tracking Issues
- **Unsubscribe link returned 400 (FAIL).** `https://skechers.attn.tv/p/dvm?token=ChQwME5HVjkz…&attn_macro=dW5zdWJzY3JpYmVMaW5r&…`. The `attn_macro` value decodes to `unsubscribeLink`. A 400 may be probe-specific, since token-based Attentive endpoints often reject non-browser clients. It needs a manual click-through to confirm, because it is the one link that must work.
- **Two 429 responses (WARN, inconclusive).** These are the "Ready to check out? Complete your order" CTA and the `de642685-…jpg` image link, both on `skechers.e.attentivemail.com/e/c/…`. They are rate limiting, not confirmed breakage.
- **Probe coverage was partial.** 12 links were probed and 30 skipped, so the footer, social and utility links are unverified.

## 3. Rendering & Accessibility
- **Empty `<title>`.** The source has `<title></title>`.
- **Ineffective charset declaration.** `<meta content="text/html; charset=utf-8" />` has no `http-equiv` or `charset` attribute, so it does not declare the encoding. The preheader contains non-ASCII characters (`͏`, `­`), so this matters.
- **Missing alt text on 3 images (WARN):**
  - `…/m/23/de642685-77b3-46fa-950b-5bd9ee6800e1.jpg` is a linked image, which is the 429 link above. It has no accessible name, so the link text is read out as "[image: …]".
  - `…/m/5/a6ec5198-5437-4eaa-8613-eacc775726f9.jpg`.
  - The tracking pixel `skechers.attentivemail.com/wf/open?upn=…`. This is a pixel, so it should use `alt=""`. It is low severity.
- **11 images use `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/11/…`.** They include the logo `dde00662-….png`, the App Store and Google Play badges, Curbside Pickup, Afterpay, Find a Store and the Instagram, Facebook and YouTube icons. Non-HTTPS images can be blocked or flagged as mixed content. The same host already serves `de642685-….jpg` over HTTPS, so the https version should work.

## 4. Personalization & Merge Tokens
No issues found. The visible source has no unrendered merge tokens such as `{{…}}`, `%%…%%` or `[FIRST_NAME]`. The source was truncated, so the lower sections were not checked.

## 5. Compliance
- **Plain-text fallback missing (FAIL).** The QA check reports "Text version is 0 chars". A missing text alternative can hurt spam scoring and leaves text-only clients with nothing to read.
- **Unsubscribe link present but failing the probe.** See section 2.
- **Authentication-Results header not found (WARN).** The QA note attributes this to the AgentMail relay, so SPF/DKIM/DMARC status is unknown. This is not a confirmed failure.
- **Not verifiable from the data.** The physical postal address and the `List-Unsubscribe` and `List-Unsubscribe-Post` headers are not visible in the truncated source or the QA output.

## 6. Email-to-Site Continuity
No issues confirmed. All CTAs are wrapped in Attentive redirectors (`skechers.e.attentivemail.com/e/c/…`), so the final destinations and their UTM parameters cannot be seen from the source. The cart-recovery CTA's 429 prevented the probe from resolving its landing page.

## 7. Recommendations
1. **Check the unsubscribe URL in a real browser and fix it if it fails.** Treat it as high priority, since it is a compliance risk.
2. **Add a text/plain part** that includes the unsubscribe link.
3. **Change all 11 `http://image.emails.skechers.com/…` image URLs to `https://`.**
4. **Add descriptive alt text** to `de642685-….jpg` (it is a CTA link) and `a6ec5198-….jpg`. Set `alt=""` on the open pixel.
5. **Fix the head.** Use `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">` or `<meta charset="utf-8">`, and give `<title>` a value such as the subject line.
6. **Re-probe the two 429 links** with throttling, and follow the redirect chain on the cart CTA to confirm the landing page and UTMs.
7. **Check `Authentication-Results` and `List-Unsubscribe` headers** from the original message, not the AgentMail relay copy.
