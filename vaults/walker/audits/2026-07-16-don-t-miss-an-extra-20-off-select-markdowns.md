# Don’t miss an extra 20% off select markdowns.
**Score:** 8/10 · **Type:** Email audit · **2026-07-16**
## Executive summary

- I see New Balance in the sender column, I see "Don't miss an extra 20% off select markdowns" in the subject, and my first thought is: didn't I just get this deal? Five days ago — July 10th — they sent me the same "extra 20% off select markdowns" promo. That one scored well because I hadn't seen it before. This one feels like a copied-and-pasted reminder dressed up with different subject-line punctuation. At this point, New Balance has come at me eleven or twelve times in two weeks, and the familiarity has curdled into noise.
- That said, if I force myself to engage with the email on its own terms, the mechanics are clean. The code is right there — EXTRA20 — the deadline is visible (through Thursday), and the price-tier shopping tiles (Under $50, $50–$100, etc.) are the right idea for how I actually browse a sale. The hero is a stack of shoeboxes, which is a strange way to sell me shoes. I can't see what's inside those boxes. I don't buy boxes.
- The "More to explore" products sealed it for me: athletic shorts, a jacket, a tracksuit short, socks. All sportswear. No walking shoes, no mention of cushioning or arch support, and most of the models appear to be young women. I closed it and moved on. I won't be forwarding this.

## What's working

- The EXTRA20 code appears in both the preheader banner and the email body — I didn't have to hunt for it.
- "Through Thursday" gives me a real deadline; that's more credible than the usual "limited time" vagueness.
- The price-tier tile layout (Under $50, $50–$100, $100–$150, +$150) matches how I think about a sale — I start with budget, not brand.
- The layout is clean — nothing's broken, text isn't overlapping, images loaded.
- Free shipping threshold ($75+) is stated at the top where I can see it without scrolling.

## What's weak

- The hero image is stacked shoeboxes — attractive photography, completely useless for deciding what to buy. Show me the shoe that's on sale.
- The "More to explore" block is all athletic apparel — shorts, jackets, socks — with barely any women's-leaning styling and zero walking shoes or comfort product visible.
- No demographic match: the product models are young and athletic; nothing here signals "this is for a guy who wants to walk 18 holes without his knees complaining."
- This is the same promotion as the July 10 email, just reworded. At some point that reads as "we didn't sell enough so we're pushing again" — which undercuts urgency rather than building it.
- The preheader trail has a long run of invisible spacer characters that some inboxes render as a line of boxes or foreign characters — visually junky in the inbox preview.

## Recommendations

- 1. **Show me a shoe, not a box.** The hero should be a single on-sale men's comfort or walking shoe — something that stops a guy like me mid-scroll. The packaging aesthetic works for a brand campaign; it doesn't work for a clearance push.
- 2. **Lead "More to explore" with men's footwear on markdown.** If comfort walkers, trail shoes, or wide-width options are in the sale, put them here. Shorts and jackets belong in a separate send.
- 3. **Acknowledge the repeat.** If this is a reminder of the same promo, say so — "Last chance" or "3 days left" framing turns a repeat send into urgency rather than déjà vu.
- 4. **Add one specific product callout.** A single "Staff pick" or "Most popular under $75" shoe with the discounted price would do more than four price-range tiles.
- **Subject Alt A:** `Last chance: extra 20% off ends Thursday`
- **Subject Alt B:** `Men's shoes on sale — extra 20% off markdowns`
- **Preheader Alt A:** `Use EXTRA20 at checkout — ends Thursday night`
- **Preheader Alt B:** `Code EXTRA20 · men's walkers, trainers & more on sale`

### 3. Rendering & Accessibility

**`.bg1` class collision (hard render bug):**
The class `.bg1` is defined twice with conflicting values:
```css
.bg1 { background-color: #ffffff; }   /* line ~10 */
...
.bg1 { background: #58546d; }         /* line ~80, overrides */
```
Any element using `.bg1` expecting a white background will render with a purple-grey (`#58546d`) background instead. This is a copy-paste/template assembly error.

**`@font-face` declarations have no `src:` property:**
All nine `@font-face` blocks (`proxima-nova`, `linotype-didot`, `proxima-nova-condensed`, etc.) declare `font-family`, `font-weight`, and `font-style` but omit the `src:` URL entirely:
```css
@font-face { font-family: proxima-nova,sans-serif; font-weight: 700; font-style: normal; }
```
Without `src:`, these blocks are non-functional — the browser/client cannot fetch the font. Fallbacks (`Arial`, `Times New Roman`) will always render instead. Web font loading will silently fail.

**Duplicate property in one `@font-face` block:**
```css
@font-face { font-family: proxima-nova,sans-serif; font-weight: 700; font-style: italic; font-family: proxima-nova,sans-serif; }
```
The italic/bold variant has `font-family` declared twice in the same block — the second declaration overrides the first (same value here, but indicates a template generation error).

**Malformed IE compatibility meta tag:**
```html
<meta content="IE=edge" />
```
Missing required `http-equiv="X-UA-Compatible"` attribute. This tag has no effect as written and will not force IE/legacy Outlook rendering to edge mode.
