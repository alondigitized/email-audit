**Issue B — Tracking pixel missing `alt` attribute**
```html
<img style="visibility:hidden;display:none" height="1" width="1"
     src="https://demandwarecrocs.demdex.net/event?d_dpid=196107&...">
```
Hidden pixels should carry `alt=""` to be well-formed and avoid screen reader / validator noise.

**Issue C — Malformed `<meta>` tags**
Two `<meta>` tags in `<head>` are missing the required `http-equiv` attribute:
```html
<meta content="text/html; charset=utf-8" />        <!-- missing http-equiv="Content-Type" -->
<meta content="IE=edge" />                          <!-- missing http-equiv="X-UA-Compatible" -->
```
Most clients tolerate this, but it is non-conformant and can cause Outlook 2007–2013 to ignore the IE compatibility directive.

**Minor — Custom web font `TT Crocs`**
Loaded via `@font-face` from `media.crocs.com`. Web fonts are unsupported in Gmail, Outlook (Windows), and Samsung Mail. The fallback font stack is not visible in the truncated source — verify a safe-serif or system-sans fallback is present.
