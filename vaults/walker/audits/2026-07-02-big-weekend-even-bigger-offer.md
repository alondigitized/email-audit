## 3. Rendering & Accessibility

**[HIGH] Two `<meta>` tags are missing their `http-equiv` attribute — they are no-ops as written:**

```html
<!-- as sent — both are inert -->
<meta content="text/html; charset=utf-8" />
<meta content="IE=Edge" />

<!-- correct form -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

Without `http-equiv`, Outlook/IE ignores both directives. Character encoding fallback applies (likely UTF-8 anyway), but the IE rendering mode declaration has no effect.

**[MEDIUM] All ten `@font-face` blocks use `Src:` (capital S) instead of `src:`:**

```css
/* as sent — invalid CSS property name */
Src: url("https://braze-images.com/appboy/...woff") format('woff');
```

CSS property names are case-sensitive per spec. Modern WebKit/Blink handles this gracefully, but it is technically invalid and will fail strict parsers. Present in all 10 `@font-face` declarations.

**[MEDIUM] Italic font variants registered with `font-style: normal`:**

The following three faces declare `font-style: normal` when they should declare `font-style: italic`:
- `HelveticaNow_MediumItalic`
- `HelveticaNow_BoldItalic`
- `HelveticaNow_Italic`

As registered, CSS rules using `font-style: italic` cannot select these faces. Any italic rendering would fall back to browser-synthesized oblique rather than the actual italic cut.

**[LOW] `text-size-adjust` declared twice with conflicting values:**

```css
/* first declaration */
-ms-text-size-adjust: 100%;
-webkit-text-size-adjust: 100%;
/* ... later in the same rule ... */
-ms-text-size-adjust: none;   /* overrides the 100% above */
text-size-adjust: none;
```

`none` (rather than `100%`) blocks user font-size scaling. The `-ms-text-size-adjust: 100%` declaration earlier in the same block is overridden by `none` further down. WCAG 1.4.4 recommends text remain resizable; `none` is a hard block.

**[LOW] Font cache-busting inconsistency:** Futura PT `.woff` files have no query string; HelveticaNow `.ttf` files include `?1755182939`. Minor — no rendering impact, but makes cache invalidation asymmetric across the two families.
