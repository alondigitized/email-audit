# On now: BOGO 50% off sandals 🩴👡
**Score:** 8/10 · **Type:** Email audit · **2026-05-14**
## Executive summary

- I shop DSW — they're one of my go-to stops when I want a decent walking shoe without paying full Hoka prices. So the DSW name in my inbox gets a look. But this one burned that goodwill fast: every model is a young woman, the hero copy screams "tennis fashion," and when I scrolled to the size chart at the bottom, it runs from 5 to 7.5. I wear a men's 10.5 wide. This email was not written for me, full stop.
- The BOGO 50% off deal is loud and clear at the top, and I'm not going to pretend that doesn't get my attention. But a deal on something I can't buy is just noise. DSW knows I'm in their rewards program. They know enough about me to send me mail — so why am I looking at women's sandal drops and "court girl" styling?
- Mark as read. Wouldn't forward this to a single person I know.

## What's working

- **BOGO 50% off is the first thing I saw** — no hunting, no scrolling, the deal is right up top in clear language.
- **DSW is a brand I recognize and trust** — the logo bought a second glance that a random sender wouldn't have gotten.
- **"On now" in the subject** — low-key urgency without the exclamation-point hysteria I usually ignore.
- **Clean layout, nothing broken** — everything loaded, images were crisp, easy to scan top to bottom without squinting on my phone.
- **Loyalty program is mentioned** — I noticed DSW Rewards near the footer, which is a small signal that they know I'm a customer and not just a cold prospect.

## What's weak

- **This email is for women and I'm a 62-year-old man** — models, product, sizing chart, copy angle — all of it targets women. The targeting is completely wrong.
- **"WE GOTCHU FAM" is not language for me** — whoever wrote that headline, I promise they were not picturing me when they typed it. I felt like I'd walked into the wrong store.
- **Zero comfort language anywhere** — no arch support, no cushioning, no wide width callout for men, nothing that maps to why I actually shop at DSW.
- **Preview text talks about court shoes; subject talks about sandals** — these feel like two different emails cobbled together. I had no idea what I was opening.
- **The size grid runs 5 to 7.5** — that is the loudest possible signal that I am in the wrong place.

## Recommendations

- 1. **Fix the segmentation first — everything else is secondary.** I should never be receiving women's sandal campaigns. If DSW sends me a men's comfort or walking shoe BOGO, I'm genuinely interested. This is a list problem, not a creative problem.
- 2. **Build a men's version of this same BOGO mechanic** — the offer is solid. Show me men's sandals, slides, or walking shoes at the same discount and I'm reading every word.
- 3. **Drop the Gen Z copy** — "We Gotchu Fam," "Out of Bounds," the whole tennis-court-girl vibe. Keep it friendly and direct. Something like "Grab a pair before they're gone" works for everyone.
- 4. **Align the preview text to the subject** — "New court shoes for the crew" and "BOGO 50% off sandals" are not the same campaign. The preview should support the offer, not introduce a second storyline.
- 5. **If I'm a known loyalty member, lead with that** — "Your BOGO is waiting, Walker" would have been the hook that kept me reading.

### 3. Rendering & Accessibility

**Bug — invalid CSS property casing in all `@font-face` declarations:**
```css
Src: url("https://braze-images.com/...") format('woff');  /* invalid */
src: url("...") format('woff');                           /* correct */
```
`Src:` (uppercase S) is not a valid CSS property. Browsers and email clients with strict CSS parsers will silently discard these rules, causing all custom font stacks to fall back. Affects all 10 `@font-face` blocks.

**Bug — conflicting `text-size-adjust` values on the same selector:**
```css
-webkit-text-size-adjust: 100%;
-ms-text-size-adjust: 100%;   /* set to 100% here */
-ms-text-size-adjust: none;   /* then overridden to none on the next line */
```
The `none` value wins for `-ms-text-size-adjust`, which suppresses automatic text scaling in Windows Mail/Outlook on mobile — this is the opposite of the intended reset.

**Concern — `maximum-scale=1` in viewport meta:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on iOS, which is an accessibility barrier for low-vision users. WCAG 1.4.4 (Level AA) flags this. Consider removing `maximum-scale=1`.

**Note — TTF fonts served with cache-busting query strings:**
```
original.ttf?1755182939
```
TTF is significantly heavier than WOFF for email contexts (no WOFF2 fallback provided). This inflates the email payload on clients that do load web fonts. The Futura_PT faces correctly use WOFF; the HelveticaNow set does not.

**Note — dark mode CSS is truncated in the provided source** (ends mid-rule at `.dm-font-light…`). Cannot confirm whether dark mode selectors are complete or missing closing braces.
