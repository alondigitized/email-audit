### 3. Rendering & Accessibility

**`Src:` property capitalized in all `@font-face` declarations — invalid CSS**

Every `@font-face` block uses `Src:` (capital S):
```css
@font-face {
  font-family: 'Futura_PT_Regular';
  Src: url("https://braze-images.com/.../original.woff") format('woff');
}
```
CSS property names are case-sensitive in strict parsers. Most email clients that support web fonts (Apple Mail, iOS Mail) will silently reject these declarations and fall back to system fonts. This affects all 10 declared font families.

**Font format gaps**

- Futura PT variants: `.woff` only — no `.woff2` (20–30% smaller, supported by all modern email clients that allow web fonts)
- HelveticaNow variants: `.ttf` only — `.ttf` is the least efficient format and not supported by Outlook on Windows; `.woff`/`.woff2` would be preferred

**`maximum-scale=1` in viewport meta**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Prevents user-initiated zoom on mobile. Violates WCAG 1.4.4 (Resize Text, Level AA). Users with low vision cannot zoom the email on iOS/Android browsers.

**`-ms-text-size-adjust: none` on wildcard selector**

```css
* { -ms-text-size-adjust: none; }
```

Setting `none` (rather than `100%`) on `*` disables automatic text scaling on Windows Mobile/IE. The `-webkit-text-size-adjust: 100%` earlier in the same block correctly prevents auto-scaling without disabling user control; the `-ms-` value is more aggressive and unnecessary.

**Off-by-one hex color values (intentional workaround, worth documenting)**

Dark mode classes use `#000001` and `#00000F` instead of `#000000`:
```css
.dm-bg-black { background: #00000F !important; }
.dm-font-black { color: #000001 !important; }
border-top: 1px #000001 solid
```
This is a known workaround to prevent Gmail dark mode from inverting pure black (`#000000`). Technically correct behavior, but should be documented in the template as intentional to avoid future "bug fix" regressions.

**`<title>DSW</title>` does not match subject**

Generic title tag. Some clients (Samsung Mail, web-based clients in tabs) surface this. Not critical, but `20% off summer's hottest styles` would be consistent.
