### 3. Rendering & Accessibility

**Duplicate `<meta name="viewport">` tag**
Two identical viewport declarations appear in `<head>`:
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
<meta content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=yes" name="viewport" />
```
The second overrides the first and re-enables user scaling (`user-scalable=yes`), which contradicts the `maximum-scale=1` constraint on the first. Pick one.

**Malformed `<meta charset>` tag**
```html
<meta content="text/html; charset=utf-8" />
```
Missing the required `http-equiv="Content-Type"` attribute. Some older Outlook and webmail renderers rely on this for correct charset declaration. Should be:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```

**Empty `<title>` element**
```html
<title></title>
```
Rendered as the tab/window title in webmail clients (Gmail web, Outlook.com). Should carry the subject line or brand name for accessibility and preheader consistency.

**Malformed CSS — two broken mobile rules**
Inside `@media only screen and (max-width:480px)`:
```css
.nav_padding { padding-top:px !important; padding-bottom:px !important; }
.nav_border  { border-top:px solid ; }
```
Both are missing the numeric value (e.g., `10px`) and `.nav_border` is also missing a color value. These declarations will be silently ignored by all parsers, meaning mobile nav padding and border are unset.
