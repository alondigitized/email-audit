## Technical Audit

## 1. Technical Summary
The email is a Salesforce Marketing Cloud-style send with dark-mode support. The visible source has leftover template artifacts (a placeholder background URL, a template `<title>`, `@font-face` rules with no `src`) and a malformed, duplicated subject line. The HTML was truncated and the QA run reported 0 hard failures, so link, UTM and footer findings below are limited to what the data shows.

## 2. Link & Tracking Issues
- **Placeholder asset URL:** `.bgwhite {… background-image: url('http://image.XXXXX.png');}` is an unresolved placeholder. It is also plain `http://`, so it would be a mixed-content request if the class is ever applied.
- **Tracking pixel:** `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12539877_265415_23663812.gif` is the open-tracking pixel, and QA flags it as missing alt. This is cosmetic, and `alt=""` would be correct.
- **Probe coverage:** 12 links were probed and 27 skipped (footer, social and utility links were deprioritized). No broken-link results were reported. The 27 skipped links are unverified.
- **Plain-text part:** 13,484 of 15,202 characters (about 89%) are URLs, which is above the 70% threshold. This is typical of long tracked links but can raise spam-filter scoring.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png`
  - the tracking GIF above

  The first two are content images, so they need real alt text or an explicit `alt=""` if decorative.
- **`@font-face` has no `src`:** The rules for `proxima-nova`, `linotype-didot`, `proxima-nova-condensed` and others declare no `src`, so they can't load web fonts. Rendering falls back to Arial or Times New Roman. The `ITC Garamond Book Condensed` family name is also unquoted.
- **Malformed meta:** `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Doctype mismatch:** The HTML 4.01 Transitional DOCTYPE is paired with an XHTML `xmlns` and self-closing tags. Most clients tolerate this.
- **Duplicate selector:** `.bg1` is defined twice with different values (`#ffffff`, then `#58546d`). The later one wins, which is probably unintended.
- **Template `<title>`:** `New Balance Template` is a leftover. Some clients show it as the browser-view title.
- **Dark mode:** `color-scheme` meta tags and a `prefers-color-scheme` block are present. Not verified beyond that.

## 4. Personalization & Merge Tokens
- **Subject line defect:** `Do not miss up to 25% off select shoes , do not miss up to 25% off select shoes`.
  - The text is duplicated, with inconsistent casing and a stray space before the comma.
  - This looks like a subject and preheader or personalization-string concatenation error.
- No unresolved `%%…%%` or `{{…}}` tokens are visible in the truncated source. The body could not be fully checked.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication-Results:** The header was not found. QA attributes this to the AgentMail relay, so SPF, DKIM and DMARC status is unknown. This is a capture limitation and not evidence of a sender misconfiguration.
- **Unsubscribe:** QA says an unsubscribe link is always included in probing, but the footer is beyond the truncation point. The link, `List-Unsubscribe` and `List-Unsubscribe-Post` headers, and the physical postal address could not be verified.
- **Sender:** `New Balance Offers <newbalance@email.newbalance.com>` uses a branded subdomain, which is consistent with a proper sending setup.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Not assessable. The visible source is only CSS, and the QA data lists no CTA destinations or UTM values. All outbound links appear to be wrapped in `link.email.newbalance.com` redirects, so final landing URLs and parameters can't be checked.

## 7. Recommendations
1. Fix the subject-line template so the string isn't duplicated, and remove the space before the comma.
2. Remove or replace `http://image.XXXXX.png` in `.bgwhite`, or delete the unused class.
3. Add `alt` to `ShippingIcons_06.png` and `ShippingBanner_DarkMode_03.png`, and set `alt=""` on the tracking GIF.
