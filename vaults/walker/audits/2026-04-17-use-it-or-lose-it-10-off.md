# Use it or lose it: 10% OFF.
**Score:** 5/10 · **Type:** Email audit · **2026-04-17**
## Executive summary

- A functional email that will drive some clicks, but the weak discount, cluttered middle, and buried CTA hierarchy cap its upside.

## What's working

- **Urgency in the hero** — "USE THIS YET? LAST REMINDER!" + "10% Off" is a clear, compact headline with explicit promo code. No ambiguity.
- **Product grid breadth** — Women's, Men's, and Kids' categories plus Handbags are all represented; good for browse-mode shoppers.
- **VIP upsell placement** — The "We Want You in the Club" module is cleanly designed and logically positioned after product discovery. The 5% back benefit is called out specifically.
- **Utility strip** — Free shipping, in-store pickup, download app, and opt-in to texts icons are clear and easy to scan.
- **New Under $100 / New Under $75** CTAs — price-anchored discovery buttons are a smart addition for value-conscious shoppers.

## What's weak

- **10% is a weak hook for a "last reminder" framing.** Urgency language implies scarcity; a single-digit discount doesn't justify the alarm. The mismatch undermines credibility.
- **"Want 15% Off?" module immediately undercuts the hero.** Placed directly beneath the 10% CTA, it makes the 10% feel like the worse deal in the same email. This will cause hesitation.
- **CTA fatigue.** The email contains at least 7 distinct CTAs before the footer: Shop Now (implied), Go Go Go, Sign Up & Save, New Under $100, New Under $75, Join For Free, Learn More. No clear hierarchy of what action matters most.
- **Product grid is undifferentiated.** "Check Out What's New" with 10 category tiles is generic — no featured product, no editorial angle, no personalization signal. It reads like a site map, not a recommendation.
- **Discount code is small and easy to miss.** The promo code (EC1F4RPY5) is buried in fine print below the "GO, GO, GO" button rather than shown prominently on the button or near the headline.

## Recommendations

- 1. **Remove or reorder the 15% offer.** Don't let a better deal live in the same viewport as your hero discount. Either make 15% the lead offer or move the sign-up prompt to post-purchase.
- 2. **Tighten the CTA count to two.** Primary: redeem 10% now. Secondary: explore new arrivals. Cut the rest or push to footer.
- 3. **Surface the promo code visually.** Put it on the button or in a styled code block next to the headline — don't make the reader hunt for it.
- 4. **Add a deadline timestamp.** "Last reminder" with no visible date or hour creates weak urgency. "Expires tonight at midnight" converts better.
- 5. **Editorialize the product grid.** Replace the category dump with 2–3 featured products using the 10% framing: "Here's what your 10% off could get you."
- 1. **Fix `Src:` → `src:`** in all four `@font-face` blocks. This is the highest-priority fix — silent font fallback failure affects brand rendering across clients.
- 2. **Add `http-equiv` to both meta tags** (`Content-Type` charset and `IE=Edge`).
- 3. **Add `lang="en"` to `<html>` tag** for WCAG compliance.
- 4. **Remove `supported-color-schemes` from CSS `:root`** — it does nothing there; the meta tag handles it.
- 5. **Add woff2 format** to `@font-face` `src:` declarations alongside existing woff for better compression and load performance.
- 6. **Provide full HTML** to complete audit of body links, UTM coverage, unsubscribe footer, and Liquid token rendering.

### 3. Rendering & Accessibility

**Issues found:**

| # | Location | Issue |
|---|----------|-------|
| 1 | `<meta content="text/html; charset=utf-8" />` | Missing `http-equiv="Content-Type"` attribute. Without it, the charset declaration is non-functional in legacy parsers. Correct form: `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">` |
| 2 | `<meta content="IE=Edge" />` | Missing `http-equiv="X-UA-Compatible"`. Non-functional as written. Correct form: `<meta http-equiv="X-UA-Compatible" content="IE=Edge">` |
| 3 | All four `@font-face` blocks | CSS property `Src:` uses a capital `S`. Per CSS spec, property names are case-sensitive in some parsers. Should be lowercase `src:`. All four Futura PT variants are affected — font loading will silently fail in strict CSS engines. |
| 4 | `:root { supported-color-schemes: light dark; }` | `supported-color-schemes` is not a valid CSS property. It is Apple-proprietary and only functions as a `<meta name="supported-color-schemes">` tag (which is also present). The CSS `:root` declaration is a no-op and should be removed. |
| 5 | `<html xmlns="http://www.w3.org/1999/xhtml">` | No `lang` attribute present. WCAG 2.1 §3.1.1 requires `lang` on `<html>`. Screen readers cannot infer language without it. Should be `<html lang="en" ...>`. |

**No issues found:** Viewport meta, dark mode class structure (`dm-*` + `[data-ogsb]`/`[data-ogsc]` Outlook duplicates), mobile media queries.
