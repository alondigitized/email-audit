### 3. Rendering & Accessibility

**Malformed meta tags (two confirmed):**

```html
<meta content="text/html; charset=utf-8" />
<!-- Missing: http-equiv="Content-Type" -->

<meta content="IE=Edge" />
<!-- Missing: http-equiv="X-UA-Compatible" -->
```
Both tags are syntactically incomplete and may be ignored by parsers that require the `http-equiv` attribute.

**Invalid CSS property casing in all `@font-face` blocks:**
```css
Src: url("https://braze-images.com/...") format('woff');
```
`Src` (capital S) is not a valid CSS property name. The spec requires lowercase `src`. Most modern engines are case-insensitive here, but it will fail strict parsers and is worth correcting.

**Font format gaps:**
- Futura PT fonts: `.woff` only — no `.woff2` fallback (heavier payload, ~30% larger than woff2).
- HelveticaNow fonts: `.ttf` only — no `.woff` or `.woff2`. TTF is the least efficient web format and unsupported as a web font in some legacy email clients.

**Intentional quirk (not a bug):**
`color: #000001` and `border-top: 1px #000001 solid` are known Gmail dark-mode workarounds (Gmail ignores near-black but overrides true `#000000`). Correct behavior.

**Alt text:** Cannot audit — body truncated.
