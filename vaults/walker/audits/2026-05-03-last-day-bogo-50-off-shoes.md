### 3. Rendering & Accessibility

**CSS defect — invalid `Src:` property in all @font-face blocks (10 instances)**
All `@font-face` declarations use a capitalized `Src:` property, which is not valid CSS. The spec requires lowercase `src:`. Most email clients silently tolerate this, but it will fail strict parsers and is fragile.

```css
/* Affected — all 10 @font-face blocks, e.g.: */
Src: url("https://braze-images.com/appboy/...original.woff") format('woff');
/* Should be: */
src: url("...") format('woff');
```

**CSS defect — contradictory `text-size-adjust` values on `*` selector**
Prefixed values are set to `100%` (preserves scaling) but the unprefixed property is set to `none` (disables scaling entirely), which is an accessibility concern and contradicts the prefixed intent:

```css
-ms-text-size-adjust: 100%;
-webkit-text-size-adjust: 100%;
text-size-adjust: none;  /* ← should be 100% */
```
