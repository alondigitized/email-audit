# Get up to 40% off for warmer weather
**Score:** 7/10 · **Type:** Email audit · **2026-06-17**
## Executive summary

- Adidas finally figured out the one sentence that gets me to stop scrolling: "up to 40% off." No World Cup jerseys, no cleats, no talk of "fast culture" — just a summer sale. After that stretch of FIFA-themed emails leading into Father's Day (I lost count after the third soccer send in a row), this one at least feels like it belongs in my inbox.
- That said, this email doesn't really *know* me. It's a sale announcement, full stop. The "Summer Kickoff Event" branding is fine but it tells me nothing about what's actually discounted. Walking shoes? Slides? Soccer gear? I've got bad arches and I'm not clicking through to a homepage on the off chance something useful shows up. The email says 40% off but doesn't point me at a single thing I'd actually buy.
- I'll probably tap SHOP NOW out of mild curiosity. I won't forward this to anyone.

## What's working

- **"UP TO 40% OFF" is in the hero in bold** — I can see the number the instant the email opens. Easy math.
- **"Warmer weather" is the right seasonal signal** — it's June, it's hot, this isn't a stale promo.
- **Clean render, no visual clutter** — no broken images, no overlapping text, nothing looks busted. Loaded fine.
- **Consistent adidas branding** — black and white, recognizable. I trust this is actually adidas and not a phish.

## What's weak

- **Two nearly identical "Summer Kickoff Event" blocks stacked on top of each other** — the second one says basically the same thing as the first. That's filler, not content.
- **No specific product in the email at all** — just big decorative letters spelling "SUMMER." I have no idea if this sale includes walking shoes, cleats, or running gear.
- **No adiClub callout** — the June 19th "$30 off $100+" email at least made me feel like a member. This one treats me like a cold prospect.
- **No end date on the offer** — "Starts now" tells me nothing. These percent-off sales can disappear overnight. Give me a date I can hold in my head.

## Recommendations

- 1. **Put one specific shoe in the hero with a before/after price.** A walking shoe or slide with "$89 → $54" does more work than "SUMMER" in giant letters. That's the click.
- 2. **Add a deadline.** "Ends Sunday" or "Through July 4th" — something credible. No deadline, no urgency.
- 3. **Cut the duplicate block.** Two Summer Kickoff Event sections with the same copy is wasted real estate. Use it for a comfort/fit callout or a men's category link.
- 4. **Acknowledge I'm a member.** Even swapping "SHOP NOW" for "Shop the member sale" costs nothing and changes the entire dynamic.

## Technical Audit — adidas "Get up to 40% off for warmer weather"

---

### 1. Technical Summary

One click-tracking link has a broken redirect path that will deliver a dead experience to recipients who click it. The email also lacks a plain-text fallback entirely and serves several images over HTTP, both of which create deliverability and rendering risk.

---

### 2. Link & Tracking Issues

**[FAIL] Broken redirect — unknown URL type `/g/`**
The QA probe resolved a click-tracking URL to a path beginning with `/g/` instead of a valid landing page:
```
Unknown url type: '/g/c870e4fe-acc2-4ea4-bc7d-ba8594ae770f?txn=00a0be80-705d-11f1-88bb-ae32f7ad8416'
```
Source redirect: `https://dv.adidas.com/o/c870e4fe-acc2-4ea4-bc7d-ba8594ae770f?cp_tp=v3...`

The `dv.adidas.com/o/` redirect handler is returning a `/g/` path the probe cannot follow. This indicates a misconfigured or stale redirect target — likely a dead product page or removed campaign URL. Affected users will hit an error.

**[INFO] 36 tracking links not probed**
All pass through click-redirect domains; landing-page validation is not possible from this audit. UTM continuity on those links is unverified.

---

### 3. Rendering & Accessibility

**[WARN] HTTP image sources — may be blocked by clients**
The same arrow icon is loaded 8 times via HTTP, not HTTPS:
```
src: http://image.link.adidas.com/lib/fe6515707c62007e7715/m/3/b0c011a2-d468-414b-a8a2-8595b3ec7b34.jpg
```
Gmail, Outlook.com, and Apple Mail all block or proxy non-HTTPS image sources. Recipients on those clients will see broken images for every arrow CTA.

One tracking/open pixel also served over HTTP:
```
src: http://click.comms.adidas.com/CI0/0102019ed79b371d-...
```
This will suppress open tracking for any client that enforces HTTPS image loading.

**[WARN] Missing `alt` text on 2 images**
- `c870e4fe-acc2-4ea4-bc7d-ba8594ae770f` (dynamic image via `dv.adidas.com`)
- `rrFKKyp2T-XM08eT7pMJ4Y4soU4yv-N69bzLKDb54PE=452` (tracking pixel via `click.comms.adidas.com`)

Both have no `alt` attribute. Accessibility failure for screen readers; also exposes blank broken-image boxes to any client that blocks images with no fallback label.

**[INFO] Duplicate `@font-face` declarations**
`AdihausDIN` and `AdineuePRO` are each declared twice across two separate `<style>` blocks with identical `src` values. These resolve to system font fallbacks (Arial/Helvetica), so no custom font is actually loading — the duplication adds ~600 bytes of dead CSS with no effect.

**[INFO] Malformed charset `<meta>` tag**
```html
<meta content="text/html; charset=UTF-8" />
```
Missing `http-equiv="Content-Type"`. Should be:
```html
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
```
Without `http-equiv`, this tag has no effect. Most modern clients infer UTF-8, but the omission is non-standard per HTML 4.01 (which this DOCTYPE targets).

Unsubscribe footer and physical address were not visible in the truncated HTML provided — cannot confirm CAN-SPAM §5(a)(5) compliance from this source. Assumed present in non-truncated footer; should be verified against full render.
