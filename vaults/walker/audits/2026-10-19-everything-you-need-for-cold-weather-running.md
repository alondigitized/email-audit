## Technical Audit

# Technical Audit: New Balance, "Everything you need for cold weather running."

## 1. Technical Summary
The HTML is a reused ESP template with a few leftover placeholders and three images missing `alt`. The QA run found no broken links (12 probed). The supplied source is truncated, so unsubscribe, footer address, UTM parameters and merge tokens could not be checked.

## 2. Link & Tracking Issues
- **Link coverage is partial.** Only 12 of 38 links were probed and 26 were skipped as low-priority footer, utility and social links. QA reported no failures among the probed links.
- **Placeholder URL in CSS.** `.bgwhite { background-image: url('http://image.XXXXX.png'); }` is an unresolved placeholder. It is also plain `http://`, so it would be a mixed-content request, and it 404s if the class is ever applied.
- **Plain-text part is mostly tracking URLs.** 11,036 of 12,938 characters (about 85%) are URLs. This is a deliverability warning from QA. The cause is long redirect-wrapped links on `link.email.newbalance.com`.

## 3. Rendering & Accessibility
- **Missing `alt` on three images (QA-confirmed):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png`
  - `egR1f966kc_818512772_12440996_627406_23499076.gif` (on `/mo/`, so likely the open-tracking pixel, where `alt=""` is acceptable)
  - The two shipping images are content-bearing, so missing `alt` is a real accessibility gap there.
- **Duplicate `.bg1` rule.** It is declared as `#ffffff`, then redeclared as `#58546d`, so the later value silently wins. The dark-mode override also sets `.bg1{background:#151415 !important}`.
- **`@font-face` blocks have no `src`.** Every rule shown (`linotype-didot`, `proxima-nova`, etc.) lacks a `src` descriptor, so none load a font. One block also repeats `font-family` inside itself. Rendering falls back to Arial or Times New Roman.
- **Ineffective meta tag.** `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Doctype mismatch.** The HTML 4.01 Transitional doctype is combined with an XHTML `xmlns` attribute and self-closed `<meta ... />` tags. This is tolerated by clients but not valid.
- **Leftover template title.** `<title>New Balance Template</title>` is generic. Some clients and previews surface it.

## 4. Personalization & Merge Tokens
No issues found in the visible source. The truncated portion could not be checked for unresolved tokens.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication unverified.** The `Authentication-Results` header was not found, so SPF, DKIM and DMARC status is unknown. This is an artifact of the AgentMail relay, not a confirmed failure.
- **Unsubscribe and physical address not verifiable.** QA says an unsubscribe link is always probed, and it reported no failure. The footer and `List-Unsubscribe` headers were not in the supplied data.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
The truncated source and QA data include no destination URLs or UTM parameters, so no assessment is possible. Links route through `link.email.newbalance.com` redirects, which hide the final destination parameters from static inspection.

## 7. Recommendations
1. Add descriptive `alt` text to `ShippingIcons_06.png` and `ShippingBanner_DarkMode_03.png`. Set `alt=""` on the tracking GIF.
2. Remove the `.bgwhite` placeholder `http://image.XXXXX.png`, or replace it with an HTTPS asset.
3. Delete the conflicting duplicate `.bg1` rule.
4. Add `src` to the `@font-face` rules, or remove them. Web-font loading is also unreliable in most email clients.
5. Fix the meta tag to `<meta http-equiv="X-UA-Compatible" content="IE=edge">`, or drop it.
6. Shorten the plain-text part by using a text-specific template with fewer tracked links.
7. Re-run the audit with the full HTML and raw headers (`List-Unsubscribe`, `Authentication-Results`) to cover compliance, tokens and UTM checks.
