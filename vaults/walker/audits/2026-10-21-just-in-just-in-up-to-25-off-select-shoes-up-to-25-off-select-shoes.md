## Technical Audit

## 1. Technical Summary
The email has no confirmed broken links or hard failures (QA: 75% pass, 0 issues, 2 warnings). The source has template leftovers: a duplicated subject line, placeholder CSS and title, and three images without alt text. The HTML is truncated, so only the head, CSS and the QA data could be checked.

## 2. Link & Tracking Issues
- **Probe coverage:** 12 of 39 links were probed and 27 were skipped. No failures were reported for the probed set, and the skipped links are unverified.
- **Placeholder asset URL:** `.bgwhite` in the `<style>` block contains `background-image: url('http://image.XXXXX.png')`. It is a non-HTTPS placeholder that can't resolve, and it would trigger a mixed-content or 404 request wherever `.bgwhite` is applied.
- **Plain-text part:** 12,705 of 14,421 characters (about 88%) are URLs, which exceeds the 70% threshold. This points to long click-tracking URLs in the text alternative, and it is a known spam-filter signal.
- **Tracking pixel:** `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12483636_24342_23543836.gif` is the open-tracking pixel. It is expected, but see the alt-text note in section 3.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - `ShippingIcons_06.png` (`…/custloads/818512772/NBUS/myNB_Welcome/UpdatedImages/ShippingIcons_06.png`)
  - `ShippingBanner_DarkMode_03.png` (same path)
  - The tracking GIF above. This one should carry `alt=""` and be marked decorative.
- **Viewport meta:** `<meta name="viewport" content="initial-scale=1, user-scalable=yes" />` has no `width=device-width`, so mobile clients that honor the meta tag may not scale to device width.
- **Malformed meta:** `<meta content="IE=edge" />` has no `http-equiv` attribute, so it does nothing.
- **`@font-face` rules without `src`:** The rules for `proxima-nova`, `linotype-didot` and others declare no `src`, so no web fonts load. Text renders in the fallbacks (Arial or Times New Roman). One rule also repeats `font-family` inside the same block.
- **Conflicting `.bg1` rules:** `.bg1` is defined twice, first as `#ffffff` and then as `#58546d`. The later rule wins, so the first is dead CSS.
- **Doctype mismatch:** The HTML 4.01 Transitional doctype is combined with an `xmlns` attribute on `<html>`. This is low impact but inconsistent.
- **Title:** `<title>New Balance Template</title>` is a template placeholder. It shows in some clients and in browser-view tabs.
- **Stale asset folder:** The shipping images come from a `myNB_Welcome` folder, so they were reused from a welcome-series template.
- **Dark mode:** The `color-scheme` meta tags and the `prefers-color-scheme` block are present, and there is a dark-mode-specific asset (`ShippingBanner_DarkMode_03.png`). No defects were found, although the stylesheet is truncated.

## 4. Personalization & Merge Tokens
- **Duplicated subject:** The subject reads `Just in, Just in: up to 25% off select shoes: up to 25% off select shoes`. Both the "Just in" prefix and the offer text appear twice, which looks like a subject or preheader variable concatenated with itself or a template that already contains the phrase.
- **Unresolved tokens:** None were found in the visible source. The truncated body can't be checked.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication:** `Authentication-Results` was not found. QA attributes this to the AgentMail relay, so SPF/DKIM/DMARC status is unknown rather than failing. This is a tooling gap and not a confirmed defect.
- **Domain alignment:** The From domain is `email.newbalance.com` and the tracking domain is `link.email.newbalance.com`, on the same parent domain.
- **Unsubscribe and physical address:** QA states an unsubscribe link is always probed, but no result was reported. The truncated source doesn't show `List-Unsubscribe` or `List-Unsubscribe-Post` headers, the footer unsubscribe link or the postal address, so these are unverified.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- The visible source shows no UTM parameters or final destination URLs, because links go through the `link.email.newbalance.com` redirect wrapper. The redirect chain and UTM parameters can't be verified from this data.
- No landing-page mismatch was reported by QA for the 12 probed links.

## 7. Recommendations
1. Fix the subject-line template so the "Just in" prefix and the offer text each appear once.
2. Remove or replace the `http://image.XXXXX.png` placeholder in `.bgwhite`.
3. Add `alt` text to `ShippingIcons_06.png` and `ShippingBanner_DarkMode_03.png`. Use `alt=""` on the tracking GIF.
4. Set a real `<title>` and use `width=device-width` in the viewport meta.
5. Add `src` to the `@font-face` rules, or drop them and rely on the fallback stack. Fix the `IE=edge` meta and the duplicate `.bg1` rule.
6. Shorten the tracked URLs in the plain-text part, or reduce the number of links, to bring the URL share well under 70%.
7. Re-run the audit with raw headers (`Authentication-Results`, `List-Unsubscribe`) and the full HTML body to verify the compliance and UTM items.
