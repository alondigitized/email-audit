## Technical Audit

## 1. Technical Summary
The email renders from a generic New Balance template and has no broken links in the 12 probed. The issues are template leftovers (placeholder background URL, invalid `@font-face` rules), three images without alt text, and a plain-text part that is almost entirely tracking URLs. The HTML source is truncated and no headers were supplied, so several categories can't be fully verified.

## 2. Link & Tracking Issues
- **Plain-text bloat:** QA flagged `10668/12115` plain-text characters (about 88%) as URLs. The text part is mostly long ESP redirect links with little readable copy, which is a spam-filter risk.
- **Probe coverage:** 12 links were probed and 25 skipped (footer, utility and social links are deprioritized). No broken links were reported among those probed.
- **Placeholder asset URL:** the `.bgwhite` rule contains `background-image: url('http://image.XXXXX.png')`. This is an unresolved placeholder over insecure `http`. It will 404 anywhere the class is applied, and some clients flag mixed content.
- **Tracking pixel:** `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12356839_811931_23293623.gif` is a standard open pixel. It is fine functionally, but see section 3 for its missing alt.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png`
  - `egR1f966kc_..._23293623.gif` (the tracking pixel, so use `alt=""`)

  The two shipping images likely carry information (shipping messaging), so they need real alt text.
- **Invalid `@font-face` blocks:** every declaration (`linotype-didot`, `proxima-nova`, and so on) has no `src`. The rules do nothing, so all text falls back to Arial or Times New Roman. Some family names are also malformed, such as `font-family: linotype-didot,serif` and an unquoted `ITC Garamond Book Condensed`. One block repeats `font-family` twice.
- **Conflicting `.bg1` definitions:** `.bg1 {background-color:#ffffff}` is later overridden by `.bg1 {background:#58546d}`. The final colour is order-dependent and probably unintended.
- **Dark-mode link contrast:** `@media (prefers-color-scheme: dark) { a {color:#cf0a2c !important} }` over `body {background:#151415}` gives roughly 3.3:1. That is below the 4.5:1 WCAG AA threshold for body-size links. The rest of the dark-mode CSS is truncated, so other overrides may change this.
- **Document metadata:**
  - `<title>New Balance Template</title>` is a leftover template title.
  - `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
  - An HTML 4.01 Transitional doctype is paired with an XHTML `xmlns`, which is inconsistent but harmless.

## 4. Personalization & Merge Tokens
No issues found. No unresolved merge tokens appear in the visible source. The only unresolved placeholder is the `XXXXX` asset URL in section 2, which is not a merge token. The truncated remainder was not checked.

Links go through the ESP redirect domain `link.email.newbalance.com`, so UTMs would only be visible after resolving the redirect.

## 7. Recommendations
1. Add descriptive `alt` text to `ShippingIcons_06.png` and `ShippingBanner_DarkMode_03.png`, and `alt=""` to the tracking pixel.
2. Remove or replace `url('http://image.XXXXX.png')` in `.bgwhite`.
3. Add a `src` to the `@font-face` rules or delete them. Without a `src` they do nothing.
4. Fix the duplicate `.bg1` rule.
5. Raise the dark-mode link colour above a 4.5:1 contrast ratio against `#151415` (for example a lighter red).
