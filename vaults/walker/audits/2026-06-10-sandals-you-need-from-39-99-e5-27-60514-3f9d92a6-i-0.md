### 3. Rendering & Accessibility

**`http-equiv` missing on two `<meta>` tags (incorrect syntax)**
```html
<!-- as sent — both are missing http-equiv -->
<meta content="text/html; charset=utf-8" />
<meta content="IE=Edge" />

<!-- correct -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```
Without `http-equiv`, these tags are unrecognized by conforming parsers and have no effect. The charset declaration in particular is a silent no-op.

**`Src:` (capital S) in all 11 `@font-face` blocks**
```css
Src: url("https://braze-images.com/appboy/.../original.woff") format('woff');
```
CSS property names are technically case-insensitive per spec, but several email client CSS preprocessors (notably Outlook's WebView2 layer and some Android clients) do not normalize property names before parsing. All 11 occurrences should be lowercased to `src:`.

**`-ms-text-size-adjust` declared twice in the same `*` rule — conflicting values**
```css
* {
  -ms-text-size-adjust: 100%;   /* first declaration — dead code */
  -webkit-text-size-adjust: 100%;
  -webkit-font-smoothing: antialiased;
  -ms-text-size-adjust: none;   /* second declaration wins */
  text-size-adjust: none;
}
```
The first `-ms-text-size-adjust: 100%` is overridden by `none` two lines later. The dead declaration signals a copy-paste error and should be removed.

**`maximum-scale=1` in viewport meta (WCAG 1.4.4)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` blocks user-initiated zoom on iOS Safari. This fails WCAG 2.1 SC 1.4.4 (Resize Text). Remove the `maximum-scale=1` token; `initial-scale=1` alone is sufficient.

**Inconsistent font format strategy**
- Futura PT: `.woff` only — no `.woff2`, no TTF fallback
- HelveticaNow: `.ttf` only — no `.woff` or `.woff2`

`.woff2` offers ~30% better compression than `.woff` and is supported by all current email clients that honor `@font-face`. Mixed formats with no consistent fallback order increases load risk for one font family or the other depending on client.
