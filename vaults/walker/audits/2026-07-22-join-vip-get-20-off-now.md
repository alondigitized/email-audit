### 3. Rendering & Accessibility

**Bug — malformed `<meta>` tags (2 instances):**

```html
<!-- Missing http-equiv="Content-Type" — charset declaration may be ignored -->
<meta content="text/html; charset=utf-8" />

<!-- Missing http-equiv="X-UA-Compatible" — directive has no effect -->
<meta content="IE=Edge" />
```

Both tags are missing their `http-equiv` attribute. Without it, they are inert custom attributes. The charset tag in particular risks mis-encoding in clients that do strict HTTP-equiv parsing.

**Bug — `-ms-text-size-adjust` conflict in `*` reset:**

```css
*{
  -ms-text-size-adjust: 100%;   /* set first */
  ...
  -ms-text-size-adjust: none;   /* then overridden — "none" wins */
  text-size-adjust: none;
}
```

The `none` value on `*` disables all automatic text-size adjustment in IE and legacy Windows Phone clients, which can render body copy at unreadably small sizes. The `100%` declaration is effectively dead.

**Bug — `Src:` capitalization in all `@font-face` blocks (10 instances):**

```css
@font-face {
  font-family: 'Futura_PT_Regular';
  Src: url("https://braze-images.com/...") format('woff');  /* capital S */
}
```

CSS property names are case-insensitive per spec, but capitalized `Src:` is rejected by several CSS preprocessors and may trip strict-mode parsers in some webmail clients. All 10 `@font-face` declarations share this.

**Observation — no WOFF2 font sources declared.** HelveticaNow fonts use `.ttf` (truetype), which has weaker email client support than WOFF2. No `format('woff2')` fallback is present, meaning font loading fails silently in clients that require WOFF2.

**Non-standard CSS property in `:root`:**

```css
:root {
  color-scheme: light dark;
  supported-color-schemes: light dark;  /* not a valid CSS property */
}
```

`supported-color-schemes` was an early Apple draft that was never standardized as a CSS property. The `<meta name="supported-color-schemes">` tag (correctly present in `<head>`) is the right mechanism. The CSS declaration is harmless but dead weight.

**Alt text:** Cannot audit — `<img>` tags are not visible in the truncated source.
