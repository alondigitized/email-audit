## Technical Audit

# Technical Audit: "Hours left for 30% off sitewide"

## 1. Technical Summary
The email has a confirmed broken personalization slot (`Hi ,`) and a malformed Return Path pixel URL with no scheme. It also has two `http://` image sources, ignored `<meta>` declarations and accessibility gaps in the head. The HTML was truncated, so body links, footer and unsubscribe markup could not be checked.

## 2. Link & Tracking Issues
- **Broken pixel URL:** `<img src="pixel.app.returnpath.net/pixel.gif?r=964ce1db…">` has no `https://` or `//`. Clients resolve it as a relative path, so the request goes nowhere and the deliverability or inbox-placement tracking it feeds is lost. It also has no `alt`.
- **Mixed content:** two images load over plain HTTP (QA WARN):
  - `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif?mi_u=8107766165&mi_ecmp=…`
  - `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/dde00662-169f-447d-b0e2-fc65f6c2290c.png`

  Gmail's proxy upgrades these, but other clients may block them. The `.png` is on Skechers' own image host, so `https://` should be a trivial fix.
- **Third-party beacons:** five hidden `<img>` tags sit inside `display:none` wrappers. Three are `beacon.krxd.net` calls (two user-match, one ad-impression) and two are open pixels (`click.emails.skechers.com/open.aspx`, `ink1000.com`). Some clients strip `display:none` content, so these may fire inconsistently or not at all.
- **Unverified links:** 45 tracking links were skipped by the probe (click-redirect domains), so destination validity and redirect chains are unconfirmed.

## 3. Rendering & Accessibility
- **Missing `alt` text** (QA WARN) on `o.gif` and `dde00662-169f-447d-b0e2-fc65f6c2290c.png`. The `.png` is served from the content image library, so it is likely a visible image. The `krxd.net` and `returnpath` pixels also lack `alt`.
- **Ineffective meta tags:**
  - `<meta content="text/html; charset=utf-8" />` has no `http-equiv`.
  - `<meta content="IE=Edge" />` has no `http-equiv`.

  Both are ignored by parsers. The charset then depends on the MIME `Content-Type` header.
- **Zoom disabled:** `<meta name="viewport" content="…maximum-scale=1">` blocks pinch-zoom, which fails WCAG 1.4.4. `* { -webkit-text-size-adjust: none }` also disables iOS text resizing.
- **No `lang` attribute:** `<html xmlns="http://www.w3.org/1999/xhtml">` has no `lang`, which hurts screen-reader pronunciation.
- **Layout tables without roles:** the visible tables (for example `<table cellpadding="0" cellspacing="0" border="0">` and `<table width="1" height="1">`) have no `role="presentation"`.

## 4. Personalization & Merge Tokens
- **[FAIL] Empty greeting slot:** the greeting renders as `Hi ,`. The first-name field resolved to empty, and there is no fallback string in the ESP merge logic (for example `%%=IIF(Empty(@firstname),"there",@firstname)=%%` in SFMC). This is a user-facing defect.
- No raw unresolved tokens (`%%…%%`, `{{…}}`) were visible in the truncated source.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **[WARN] No `Authentication-Results` header:** SPF, DKIM and DMARC status is unknown. The QA note attributes this to the AgentMail relay, so it is likely a test-harness gap rather than a sender defect. It should be verified from raw headers at the receiving mailbox.
- **Hashed identifier in a third-party beacon:** `beacon.krxd.net/1x1_usermatch.gif?partner=…_sha25&partner_uid=9153f33f…ced00` passes what looks like a SHA-256 value, plus `subid=121173391`, to a third party. This is a privacy and consent-disclosure item, not a CAN-SPAM violation. Confirm it is covered by the privacy policy and opt-out handling.
- **Not verifiable:** the physical address, visible unsubscribe link and `List-Unsubscribe` and `List-Unsubscribe-Post` headers are not in the truncated source or QA data.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **Campaign ID consistency:** the ID `PRO_US_NA_U_SITESELECT_FULL_EN_11222026_PM` is the same in the `krxd` ad-impression beacon and the `ink1000` `mi_ecmp` parameter.
- **Unverified:** CTA hrefs, UTM parameters and landing pages are not in the truncated source. All 45 tracked links were skipped by the probe, so continuity with the "30% off sitewide" and "$49.99 doorbusters" offers (preheader) could not be validated.

## 7. Recommendations
1. Add a fallback to the first-name merge, for example `Hi there,`, or drop the salutation when the field is empty.
2. Fix the Return Path pixel to `https://pixel.app.returnpath.net/pixel.gif?r=…`.
3. Switch `image.emails.skechers.com` and `ink1000.com` to `https://`. Check that the `ink1000` host serves valid TLS.
4. Add descriptive `alt` text to `dde00662-….png`, and `alt=""` to the 1×1 tracking pixels.
5. Fix the meta tags to `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">` and `<meta http-equiv="X-UA-Compatible" content="IE=edge">`.
6. Remove `maximum-scale=1` from the viewport tag. Replace `-webkit-text-size-adjust: none` with `100%`.
7. Add `lang="en"` to `<html>` and `role="presentation"` to layout tables.
8. Re-run QA with the full HTML and raw headers to check the unsubscribe link, `List-Unsubscribe`, footer address, UTM parameters and SPF/DKIM/DMARC.
