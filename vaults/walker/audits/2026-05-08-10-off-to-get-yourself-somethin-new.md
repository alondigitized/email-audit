### 3. Rendering & Accessibility

**[HIGH] Two malformed meta tags — missing `http-equiv` attribute:**

```html
<!-- As written (broken): -->
<meta content="text/html; charset=utf-8" />
<meta content="IE=Edge" />

<!-- Should be: -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

Without `http-equiv`, neither tag is parsed as intended. Charset fallback behavior is client-dependent; Outlook/IE rendering mode override is a no-op.

**[MEDIUM] Conflicting `-ms-text-size-adjust` values in the same CSS rule:**

```css
* {
  -ms-text-size-adjust: 100%;   /* set */
  -ms-text-size-adjust: none;   /* overrides above — disables scaling */
}
```

The `none` value wins in cascade order, suppressing automatic text scaling in older Windows Mail clients (Outlook 2016/2019 webview). Should be `100%` only.

**[MEDIUM] `maximum-scale=1` on viewport blocks pinch-zoom:**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Fails WCAG 1.4.4 (Resize Text, Level AA). Remove `maximum-scale=1` or replace with `minimum-scale=1`.

**[LOW] Non-standard `Src:` capitalization in all `@font-face` blocks:**

```css
@font-face {
  font-family: 'Futura_PT_Regular';
  Src: url("...") format('woff');   /* capital S — non-standard */
}
```

CSS property names are case-insensitive per spec, so most clients will parse this correctly. However, stricter CSS validators and some older mobile clients may skip the declaration. Should be lowercase `src:`.

**[LOW] Futura PT fonts are `.woff` only; HelveticaNow fonts are `.ttf` only — no `.woff2`:**

`.woff2` offers ~30% better compression. Not a rendering bug, but adds unnecessary payload for HelveticaNow (TTF files are significantly larger).

**[INFO] HelveticaNow font URLs include cache-busting query strings; Futura PT URLs do not:**

```
# HelveticaNow (cache-busted):
.../original.ttf?1755182939

# Futura PT (no cache-busting):
.../original.woff
```

Inconsistency suggests Futura PT assets may be stale if the font file was ever updated at the same path.
