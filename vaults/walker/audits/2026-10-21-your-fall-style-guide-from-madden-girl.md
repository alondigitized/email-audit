## Technical Audit

## 1. Technical Summary
The visible HTML source and QA data show a standard ESP-built responsive template with no confirmed hard failures (QA: 86% pass, 0 issues, 1 warning). One unresolved `[UNIQUE]` placeholder in a tracking-pixel URL and a malformed tracking-pixel `src` are the only concrete defects. Most link destinations and the footer could not be verified.

## 2. Link & Tracking Issues
- **26 tracking links were not probed.** The QA tool skipped them as click-redirect domains (`*.emltrk.com`), so destination status, redirect chains and final landing URLs are unverified.
- **Malformed pixel URL.** `https://ieezzy5m.emltrk.com/v2/ieezzy5m?i=72180589&t=utm_campaign=SCA_20261021_madden_girl_AM​` ends with a zero-width space (U+200B) after `AM`. This is likely an artifact of copy/paste in the ESP template. Strict parsers may encode it as `%E2%80%8B`, which would corrupt the campaign value recorded for that hit.
- **Odd parameter nesting.** The UTM string is passed as the value of `t=`, a bare `utm_campaign=...` inside a query value, rather than as a separate parameter. Analytics will only read it correctly if the ESP unpacks it server-side.

## 3. Rendering & Accessibility
- **Missing alt on two tracking images.** `ieezzy5m.emltrk.com` and `0di86k1v.emltrk.com` have no `alt`. If these are 1×1 pixels (not confirmable from the truncated source), they should carry `alt=""`. Otherwise some clients and screen readers may announce the URL.
- **Link affordance removed globally.** The CSS rule `a, a:link, a:visited, a:hover, a:active ... { text-decoration:none !important; color:inherit !important; }` strips underline and color from every link. Any text link without its own styling will be indistinguishable from body text. This is a WCAG 1.4.1 risk.
- **Malformed meta tags.**
  - `<meta content="text/html;" charset="utf-8" />` has no `http-equiv`.
  - `<meta content="IE=edge" />` has no `http-equiv`.
  - Neither does what it intends. The `charset` attribute still works, so the impact is low.
- **Doctype mismatch.** The doctype is HTML 4.01 Transitional but the `<html>` tag carries `xmlns="http://www.w3.org/1999/xhtml"` and self-closing tags. It is harmless in email clients but inconsistent.
- **Competing breakpoints.** There are three sets (600px for `.responsive-text`, 660px, and 450px), plus a 320px block that is empty. This is not a confirmed defect.

## 4. Personalization & Merge Tokens
- **Unresolved placeholder.** `https://0di86k1v.emltrk.com/v2/0di86k1v?d=[UNIQUE]` still contains a literal `[UNIQUE]` token. Either the ESP substitutes it at open time or the per-recipient identifier was never populated. If it is not substituted, open tracking for this pixel is not recipient-specific.
- No other tokens were visible in the subject line or the truncated HTML.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication-Results header not found.** The QA tool notes this is expected via the AgentMail relay, so SPF/DKIM/DMARC status is unknown. It is not confirmed as a sender-side failure.
- **Not verifiable from the data provided.** The unsubscribe link, physical postal address and `List-Unsubscribe` / `List-Unsubscribe-Post` headers are not in the truncated source or the QA output. No issue is asserted.
- The From domain (`email.shoecarnival.com`) is a branded subdomain, which is consistent with proper sending setup.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **Only one UTM value is visible:** `utm_campaign=SCA_20261021_madden_girl_AM`. It is consistent with the subject (Madden Girl) and send date (2026-10-21).
- **`utm_source` and `utm_medium` are not visible.** They may be appended by the redirect or sit in the truncated portion.
- **Landing pages are unverified.** All 26 click links were skipped, so I could not check that destinations match the Madden Girl / Fall Style Guide content or that UTMs survive the redirect.

## 7. Recommendations
1. Strip the U+200B from the `ieezzy5m.emltrk.com` pixel URL and move the UTM into proper query parameters if the ESP allows.
2. Confirm that `[UNIQUE]` is substituted at send time. Check a seed inbox's raw source.
3. Add `alt=""` to tracking pixels.
4. Restore underline or color on inline text links (or confirm all links are styled buttons).
5. Fix the meta tags: `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">` and `<meta http-equiv="X-UA-Compatible" content="IE=edge">`.
6. Re-run the QA with a click-resolving probe (follow the redirects) to validate the 26 destinations and UTM persistence.
7. Capture raw headers from the original delivery, not the AgentMail relay copy, to verify SPF/DKIM/DMARC and `List-Unsubscribe`. Also run the QA on the full HTML so the footer can be checked.
