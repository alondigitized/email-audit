# 25% off is only in the app
**Score:** 6/10 · **Type:** Email audit · **2026-05-29**
## Executive summary

- Here we go — adidas again. I've genuinely lost count at this point, somewhere north of fifteen emails from them this spring. This one hits me with an app-exclusive 25% off deal and a code — SUNSHINE — which is actually a nice touch. The hero is clean, the number is big, and for a half-second I thought "okay, maybe this one." Then I read the fine print: *only the app has these savings.*
- That's where adidas lost me. I don't use the adidas app. I'm not going to download the adidas app. I'm 62, I shop on mobile browsers, and asking me to leave my email, find the app store, install something, and then navigate to a sale is not one step — it's five steps. Any one of them kills the deal.
- I'd mark this as read and move on. I wouldn't click, and I wouldn't forward it — nobody I know needs the adidas app either.

## What's working

- **"25% OFF IS LIVE" lands immediately** — big, clean, no ambiguity. That number stopped my thumb.
- **Code SUNSHINE is right there** — no hunting, no hidden reveal. Good habit.
- **Subject line is honest and specific** — "25% off is only in the app" tells me exactly what I'm walking into before I open it.
- **No render bugs** — email looked clean, layout held, nothing broken.

## What's weak

- **App-gating is a dealbreaker for me.** I'm not downloading another app to save 25%. That's friction stacked on friction.
- **No CTA button visible** — the email just gives me the code and explains the terms. There's no "Open App" button, no "Shop Now." I'm supposed to just… go figure it out.
- **Zero comfort/walking shoe signals.** The hero looks like brown fashion shoes or lifestyle product — I can't tell if this is relevant to what I actually buy from adidas.
- **Cadence fatigue is real.** This is easily the fifteenth email from adidas this spring. Even a solid offer lands differently when you're exhausted by the sender.
- **No deadline visible** — "25% OFF IS LIVE" tells me it started but not when it ends. That "IS LIVE" phrasing feels vague; I need to know if I have a day or a week.

## Recommendations

- 1. **Kill the app gate or at least offer a browser fallback.** If the app gets the code, fine — but give me a direct link too. "Get 25% off → open in app OR shop online" retains buyers like me who aren't going to install anything.
- 2. **Add a CTA button.** A big, tappable "Shop the Sale" or "Open in App" button is missing. The copy explains the offer but doesn't lead me anywhere.
- 3. **Show me one shoe I'd actually buy.** The hero image is abstract. Drop in a men's walking sneaker or a Cloudfoam-style comfort shoe and I'm three times more likely to click.
- 4. **Put a deadline on it.** "Ends Sunday" or "48 hours only" makes the decision easier.
- 5. **Rest the cadence.** Fifteen emails in six weeks at a score this low means each new send costs brand equity. Less frequent but more targeted beats this pace every time.

## Technical Audit — Adidas "25% off is only in the app"

### 1. Technical Summary

Two hard failures: a broken redirect URL and a completely absent plain-text body. Three HTTP (non-HTTPS) image sources will be blocked by major email clients. Overall pass rate reported at 75% but the broken link alone constitutes a broken user experience for at least one CTA.

---

### 2. Link & Tracking Issues

**[FAIL] Broken relative link URL**
QA detected `unknown url type: '/g/2f10cd6b-1528-4204-926e-b021f091224a?txn=6d7f7200-5b0c-11f1-bc20-8e0ec7ba23ea'`. The link `href` contains a bare path (`/g/...`) instead of a fully-qualified URL. The corresponding image renders from `https://dv.adidas.com/o/2f10cd6b-...` (HTTPS, correct), but the associated click target was not expanded by the ESP at send time. Any subscriber clicking this element hits a broken redirect.

**[WARN] 16 tracking links not probed**
All click-redirect domains (`click.comms.adidas.com`, `dv.adidas.com`) were skipped during HTTP probing. Destination URL reachability is unverified.

### 3. Rendering & Accessibility

**[WARN] 3 HTTP image sources** — will be blocked by Gmail (image proxy requires HTTPS), Outlook.com, and Apple Mail:
- `http://image.link.adidas.com/lib/fe6515707c62007e7715/m/3/b0c011a2-d468-414b-a8a2-8595b3ec7b34.jpg` (appears twice — same arrow asset)
- `http://click.comms.adidas.com/CI0/0102019e71b68c08-3fa0a66d-5e42-4c35-ba9f-476bfeb7b936-000000/L7m0G1AZJr89ZEO...`

**[WARN] 2 images missing `alt` text**
- Hero/content image: `src` beginning `https://dv.adidas.com/o/2f10cd6b-...`
- Click-tracking pixel: `src` beginning `http://click.comms.adidas.com/CI0/...`

Both fail WCAG 2.1 SC 1.1.1 (non-text content). The content image is a meaningful CTA image; the tracking pixel should carry `alt=""` (empty, decorative).

**Duplicate `@font-face` blocks**
The `<head>` contains three separate `<style>` blocks, each re-declaring `AdihausDIN` and `AdineuePRO` using only `local()` sources pointing to system fallbacks (Arial, Helvetica). No `url()` web font sources are present, so brand fonts never load in any client — the duplicated declarations add ~2KB of dead CSS with no rendering benefit.

**Missing `http-equiv` on charset `<meta>`**
`<meta content="text/html; charset=UTF-8" />` omits `http-equiv="Content-Type"`. Per the HTML 4.01 Transitional DOCTYPE declared, the attribute is required for charset to be parsed correctly by legacy Outlook MSHTML renderer.

### 5. Compliance

**[FAIL] Plain-text body is 0 characters**
The multipart MIME envelope contains no plain-text alternative. This violates best-practice CAN-SPAM guidance (FTC recommends a readable plain-text version) and triggers spam-filter penalties in SpamAssassin (`MIME_HTML_ONLY` rule) and Microsoft's EOP filter. Subscribers with plain-text clients or corporate policies forcing plain-text rendering receive a blank email.

**Unsubscribe / physical address**: HTML is truncated; presence of a one-click `List-Unsubscribe` header and physical mailing address (CAN-SPAM §5(a)(5)) cannot be confirmed from the excerpt alone.

**Authentication headers** (DKIM, SPF, DMARC) are envelope-level and not visible in the HTML source. Sending domain `us-news.comms.adidas.com` should be verified against DNS records independently.

### 6. Email-to-Site Continuity

The broken `/g/` link means at least one CTA cannot be evaluated for UTM parameter carriage. For the remaining 16 redirect links, destination URL UTM parameters are unverified (probing was skipped). Confirm that all `dv.adidas.com` redirect targets carry `utm_source`, `utm_medium`, and `utm_campaign` before reporting attribution.
