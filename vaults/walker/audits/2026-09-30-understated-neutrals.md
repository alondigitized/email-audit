## Technical Audit

## 1. Technical Summary
The email renders from a generic ESP template with leftover scaffolding. That includes a placeholder title, a placeholder `http://` background URL, and `@font-face` rules with no `src`. The automated checks found 0 hard failures. They did flag a URL-dominated plain-text part and three images without `alt` attributes.

## 2. Link & Tracking Issues
- 12 links were probed and 28 skipped. No probe failures were reported, and the unsubscribe link was included in the probe set. The 28 skipped links (footer, utility, social) are unverified.
- **[WARN] The plain-text part is 11,976 of 13,954 characters URLs (about 86%).** This points to long tracked redirect URLs on `link.email.newbalance.com`. The text/plain alternative is mostly noise, which can hurt spam scoring and readability in text-only clients.
- **Leftover placeholder in CSS:** `.bgwhite {… background-image: url('http://image.XXXXX.png');}` is a dead, non-HTTPS URL. If `.bgwhite` is applied anywhere, it issues a failed, mixed-content request.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png` (a banner, so this is content-bearing)
  - `…/mo/egR1f966kc_818512772_12335238_5371458_23232904.gif` (the open-tracking pixel). This one is low impact, but it should carry `alt=""`.
- **Invalid `@font-face` blocks:** `linotype-didot`, `proxima-nova`, `proxima-nova-condensed`, `proxima-nova-extra-condensed` and `ITC Garamond Book Condensed` are declared with no `src`. Some also use comma-separated family names (`font-family: linotype-didot,serif`). Web fonts can never load, so every client falls back to `Arial`/`Times New Roman`.
- **Malformed head markup:**
  - `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
  - `<title>New Balance Template</title>` is a leftover template title. It can show in some clients and web views.
  - The HTML 4.01 doctype is combined with an `xmlns` attribute and XHTML-style self-closing tags.
- **Conflicting CSS:** `.bg1` is defined twice, first `#ffffff` and later `#58546d`. The later rule wins, so elements using `.bg1` in light mode are purple-gray rather than white.
- **Dark-mode link contrast (needs verification, the source is truncated):** `@media (prefers-color-scheme: dark) { a {color:#cf0a2c !important;} .bg1{background:#151415 !important;} }` gives about 3.2:1 contrast for `#cf0a2c` on `#151415`. That is below the 4.5:1 WCAG AA minimum for body-size text. The `!important` on the bare `a` selector may also override white link colors on buttons.

## 7. Recommendations
1. Add descriptive `alt` text to `ShippingBanner_DarkMode_03.png` and `ShippingIcons_06.png`. Use `alt=""` on the tracking pixel.

3. Either add `src` URLs to the `@font-face` rules or delete them. Keep the Arial and Times fallbacks.
