## Technical Audit

## 1. Technical Summary
The primary opt-in CTA ("Opt-In to Texts Get 15% Off") returned HTTP 400 on probe, and two images lack alt attributes. The `<head>` also has a viewport setting that blocks zoom and two `<meta>` tags that don't work as written. The HTML was truncated and SPF/DKIM headers weren't available, so the body and the authentication status could not be fully audited.

## 2. Link & Tracking Issues
- **[FAIL] Broken link (400):** "Opt-In to Texts Get 15% Off" → `https://ablink.dsw.com/f/a/JAAwtJ9XMvwM75eC195fdw~~/AAQRxRA~/V80Yczt9...`
  - This is a tracked redirect, and the 400 comes from the redirect hop. The probe may have been rejected because it isn't a mobile or browser client, so it should be confirmed with a real-device click-through.
  - If it is a real failure, the 15% SMS-signup offer is dead for every recipient.
- **Coverage gap:** Only 12 of 71 links were probed and 59 were skipped, so the 62% pass rate covers just the highest-priority links.
- **Plain-text part:** 30,371 of 34,262 characters (~89%) are URLs. The long `ablink.dsw.com` tracking strings bloat the text alternative, and spam filters can penalize that ratio.
- **Tracking pixel:** `https://mi.dsw.com/p/up/e6f23fb0.../o.gif?mi_u=225090073&mi_ecmp=20261014_P260598_V3_WM-_MI_BAU_Val` is a third-party pixel. It carries a numeric user ID (`mi_u`) and a campaign tag in the query string.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - The image linked via `https://ablink.dsw.com/q/zhGCdOvYOEQT5HI3nGaJQw~~/...` has no alt. If it is a linked image, its destination is unannounced to screen readers.
  - `o.gif` has no alt. It is a tracking pixel and should carry `alt=""`.
- **Pinch-zoom blocked:** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />`. `maximum-scale=1` disables zoom in some clients, which fails WCAG 1.4.4.
- **Meta tags missing `http-equiv`:**
  - `<meta content="text/html; charset=utf-8" />` and `<meta content="IE=Edge" />` have no `http-equiv` attribute.
  - Neither declaration takes effect. Charset then relies on the HTTP/MIME header, and the IE compatibility directive is ignored.
- **Not assessed:** The HTML is truncated, so the body markup, heading structure and `lang` attribute could not be checked.

## 4. Personalization & Merge Tokens
No issues found. No unrendered merge tokens (`{{ }}`, `%%`, `[FIRST_NAME]`) appear in the visible source or the QA data. The truncation leaves the remainder unchecked.
