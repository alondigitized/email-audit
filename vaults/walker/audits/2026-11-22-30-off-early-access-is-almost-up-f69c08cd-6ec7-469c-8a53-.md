## Technical Audit

# Technical Audit: "30% off early access is almost up ⏱️"

## 1. Technical Summary
The email has one confirmed broken-experience defect, an empty greeting ("Hi ,"). It also has a malformed tracking-pixel URL, insecure `http://` image sources, and several accessibility problems in the head and markup. The HTML was truncated and the 44 tracking links were not probed, so footer, unsubscribe and UTM checks could not be completed.

## 2. Link & Tracking Issues
- **Malformed pixel URL (confirmed in source, not flagged by QA):** `<img src="pixel.app.returnpath.net/pixel.gif?r=964ce1db…" width="1" height="1" />` has no scheme. Clients will resolve it as a relative path, so the Return Path/Validity seed-tracking pixel will 404 or never fire. It also has no `alt`.
- **Non-HTTPS tracking pixel:** `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif?mi_u=8107766165&mi_ecmp=PRO_US_NA_U_SITESELECT_FULL_EN_11222026` is mixed content that clients may block, and it has no `alt`. It sits in a separate `<table width="1" height="1">` outside the hidden wrapper.
- **Third-party beacons:** Four `beacon.krxd.net` pixels (usermatch and ad_impression) are present. Two of them pass `partner_uid` values, one a 64-hex string that looks like a SHA-256 hash of a subscriber identifier. They have no `alt` attribute. Whether this is disclosed in the privacy policy cannot be verified from this data.
- **Unverified links:** 44 tracking links (`click.emails.skechers.com`) were skipped by the HTTP probe, so destinations and redirect health are unknown.

## 3. Rendering & Accessibility
- **Missing `http-equiv`:** `<meta content="text/html; charset=utf-8" />` and `<meta content="IE=Edge" />` have no `http-equiv`, so the charset and compatibility declarations have no effect.
- **No `lang` attribute:** `<html xmlns="http://www.w3.org/1999/xhtml">` declares no language.
- **Zoom disabled:** `<meta name="viewport" … maximum-scale=1>` prevents pinch-zoom (WCAG 1.4.4).
- **Text resizing blocked:** `* { -webkit-text-size-adjust: none; }` stops text resizing on iOS.
- **Focus outline removed:** `a { outline: none; }` removes the keyboard focus indicator.
- **Layout tables:** The visible layout tables (e.g. `<table cellpadding="0" cellspacing="0" border="0">`) have no `role="presentation"`.
- **Missing alt text (QA):** `o.gif` and `dde00662-169f-447d-b0e2-fc65f6c2290c.png`. The PNG is served over `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/…`, so it may be blocked or flagged as mixed content.

## 4. Personalization & Merge Tokens
- **[FAIL] Empty greeting slot:** The greeting renders as "Hi ," because the first-name field resolved to an empty string. The greeting markup falls outside the truncated source, so the exact token cannot be cited. In SFMC this usually means the AMPscript or personalization string has no fallback, for example `%%FirstName%%` with no default. A fallback such as "Hi there," would avoid it.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication-Results not found (QA warn):** SPF, DKIM and DMARC status is unknown. The QA check attributes this to the AgentMail relay, so it is a capture limitation rather than a confirmed sender failure.
- **Not verifiable:** The footer, physical address, unsubscribe link and `List-Unsubscribe` / `List-Unsubscribe-Post` headers are not in the truncated source or the headers provided. I am not flagging them as missing.
- **Privacy:** The hashed-identifier beacons in section 2 are a privacy-disclosure consideration, not a confirmed violation.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **Campaign ID:** The visible campaign ID is `PRO_US_NA_U_SITESELECT_FULL_EN_11222026`, passed to the ink1000 and krxd pixels.
- **Not verifiable:** UTM parameters and landing pages could not be checked, because all 44 links were skipped and the body was truncated.

## 7. Recommendations
1. **Fix the greeting fallback** so an empty first name never renders "Hi ,". This is the highest priority.
2. **Add the scheme to the Return Path pixel:** use `https://pixel.app.returnpath.net/pixel.gif?r=…`.
3. **Switch `http://` assets to HTTPS:** `ink1000.com/…/o.gif` and `image.emails.skechers.com/…/dde00662-….png`.
4. **Add `alt` text:**
   - Use `alt=""` on the tracking pixels, including the krxd beacons.
   - Write descriptive `alt` on the PNG if it is content.
5. **Correct the head:**
   - Change the metas to `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">` and `<meta http-equiv="X-UA-Compatible" content="IE=edge">`.
   - Add `lang="en"` to `<html>`.
   - Remove `maximum-scale=1`, and drop `text-size-adjust:none` or scope it to Apple data detectors.
   - Restore a focus style on links.
   - Add `role="presentation"` to layout tables.
6. **Re-run QA with the full HTML and the raw headers.** This would let the footer and unsubscribe checks, `List-Unsubscribe`, SPF/DKIM/DMARC and UTM continuity be assessed. Also probe a sample of the 44 `click.emails.skechers.com` links through to their final destinations.
