## Technical Audit — Skechers "Constant Best Seller" Email

### 1. Technical Summary
One broken personalization token is shipping to subscribers as a rendering defect. The email also serves all hosted images over HTTP rather than HTTPS, exposing them to mixed-content blocking across modern clients.

---

### 2. Link & Tracking Issues

**Third-party DMP pixel exposes hashed PII to Krux (Salesforce):**
```
https://beacon.krxd.net/1x1_usermatch.gif
  ?partner=LprH63a7_sfmc_100007688_sha25
  &partner_uid=9153f33fe5cdf59baf088bb835d3b39ef90f188bd8540a4faba92899227ced00
```
The `partner_uid` value is a SHA-256 hash of the subscriber's email address, transmitted to Krux for identity resolution. A second Krux pixel also sends the raw internal subscriber ID (`partner_uid=121173391`). These syncs require explicit consent under GDPR/CCPA; verify DPA coverage with Salesforce.

**27 tracked links** all route through `click.emails.skechers.com` — expected. UTM parameter presence on destination URLs cannot be confirmed from this source (see §6).

**Four distinct tracking pixels fire on open:**
- `click.emails.skechers.com/open.aspx` — ESP open pixel
- `beacon.krxd.net` (×2) — DMP user-match + impression
- `pixel.app.returnpath.net` — deliverability monitoring
- `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif` — third-party, HTTP-only (see §3)

### 3. Rendering & Accessibility

**HTTP image sources — mixed-content risk (14 affected assets):**

All images hosted on `image.emails.skechers.com` and the `ink1000.com` pixel use `http://`, not `https://`. Gmail, Outlook 365, and Apple Mail proxy or block non-HTTPS image sources. Affected assets include the logo, product imagery, app store badges, social icons, and the Curbside/AfterPay icons:
```
http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/dde00662-...png  (logo)
http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/11/49468f73-...png
http://www.ink1000.com/p/up/7076d8b15a776085/o.gif
[+11 more]
```

**Missing `alt` text on two images:**
- `o.gif` (ink1000.com tracking pixel) — no `alt=""` present
- `49468f73-4651-4af3-bea2-61d1ae5db486.png` (hosted on `image.emails.skechers.com`) — unlabeled in image-off rendering environments

**`maximum-scale=1` in viewport meta:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. WCAG 1.4.4 violation; blocks low-vision users from scaling content.

**`-webkit-text-size-adjust: none` applied globally:**
```css
* { -webkit-text-size-adjust: none; ... }
```
The `*` selector disables system-level font scaling across all elements, not just layout-sensitive ones. This overrides OS accessibility text-size settings on iOS.

**Duplicate responsive CSS blocks:** The `@media (max-width: 375px)` and `@media (max-width: 640px)` blocks contain identical rule sets. The 375px block is wholly redundant — it is a subset of 640px and will never apply rules the 640px block doesn't already cover. Dead code; negligible payload impact but warrants cleanup.

### 4. Personalization & Merge Tokens

**[FAIL] Empty first-name token rendering as `"Hi ,"` for affected subscribers.**

The greeting slot is shipping with an unresolved merge field. This is a subscriber-facing defect, not just a preview issue. The fallback/default value for the first-name token is either empty or missing. A conditional default (e.g., `%%[IF EMPTY(@firstname)]SET @firstname = "there"[ENDIF]%%` in AMPscript) should be in place.

### 5. Compliance

**CAN-SPAM / GDPR:**
The Krux SHA-256 email-hash sync (noted in §2) constitutes a transfer of derived PII to a third-party data broker. Under GDPR this requires a lawful basis and DPA; under CCPA it is a "sale/share" unless a service-provider contract is in place. Confirm contractual coverage is current.

Physical mailing address and unsubscribe link cannot be confirmed from the truncated source provided — standard for Skechers ESP sends, but should be verified against the full render.

**Authentication headers** are not visible from HTML source; DKIM/DMARC pass/fail cannot be assessed here. Sending domain is `emails.skechers.com` — verify SPF/DKIM alignment for this subdomain separately.

### 6. Email-to-Site Continuity

All 27 CTAs route through `click.emails.skechers.com` redirects. UTM parameter decoration on final destination URLs cannot be confirmed without resolving the redirects. A redirect-follow check against a sample CTA is recommended before each send.
