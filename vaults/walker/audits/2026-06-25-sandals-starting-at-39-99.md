### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta — confirmed issue:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This hard-blocks user zoom in mobile webmail clients and browsers. Violates WCAG 1.4.4 (Resize Text, Level AA). Remove `maximum-scale=1`.

**Non-standard CSS property casing in all `@font-face` blocks:**
```css
Src: url("https://braze-images.com/...") format('woff');
```
`Src:` with a capital S appears in every `@font-face` declaration. CSS property names are case-insensitive per spec, so this parses correctly in modern clients, but it is non-standard and may silently fail in strict or legacy renderers. Should be lowercased to `src:`.

Same issue with `Margin: 0` in the heading reset block — non-standard capitalization, low risk but inconsistent.

**Dark mode implementation** — classes like `.dm-bg-white`, `.dm-font-grey` are present and correctly scoped to `@media (prefers-color-scheme: dark)`. Appears structurally sound from the visible portion.
