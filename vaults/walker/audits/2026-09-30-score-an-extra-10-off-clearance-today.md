## Technical Audit: DSW, "Score an extra 10% off clearance today"

### 1. Technical Summary
The HTML source is truncated, so the audit covers the head and the automated QA results only. One material failure was found: the SMS opt-in CTA link returned HTTP 400. Smaller issues are the head meta tags, the viewport zoom lock, missing alt attributes and a URL-heavy plain-text part.

### 2. Link & Tracking Issues
- **[FAIL] Broken link (400), "Opt-In to Texts Get 15% Off".** The probe was sent to `https://ablink.dsw.com/f/a/plTkyNbQ4WhlKiTpMZADBA~~/AAQRxRA~/NWXDMtbe3Xwm…`.
  - A 400 from the ESP click-tracking domain can mean a malformed or truncated tracking token, or a probe rejected by the ESP. The QA data can't tell these apart, so verify it manually.
  - If real subscribers get the same 400, the SMS-acquisition CTA is dead.
  - The QA output shows an empty link-text/href field before the "link text" label. Check that the `href` isn't blank or malformed in the source.
- **Coverage gap.** Only 12 of 58 links were probed and 46 were skipped, so link health for the rest is unverified.
- **All tracked links sit behind a redirect.** They go through `ablink.dsw.com`, so any outage or token issue on that host affects every CTA.

### 3. Rendering & Accessibility
- **Viewport zoom lock.** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />` disables pinch-zoom and fails WCAG 1.4.4 (Resize Text).
- **Ineffective meta tags.**
  - `<meta content="text/html; charset=utf-8" />` has no `http-equiv`, so the charset isn't declared.
  - `<meta content="IE=Edge" />` has no `http-equiv` either.
  - Both should be `<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />` and `<meta http-equiv="X-UA-Compatible" content="IE=Edge" />`.
  - Charset is normally also set by the Content-Type header, so the impact is low.
- **Missing alt text, 2 images.**
  - `https://ablink.dsw.com/q/6C9nDhhZ-5QtxclcTGogOg~~/…` looks like an open-tracking pixel from its `/q/` path, but I can't confirm that from the truncated source.
  - `https://mi.dsw.com/p/up/e6f23fb0…/o.gif?mi_u=225090073&mi_ecmp=20260930_P261382_V1_W-_Offer_Trend` is a tracking pixel. Adding `alt=""` is enough for both.
- **Generic `<title>`.** `<title>DSW</title>` doesn't describe the message. This is minor.
