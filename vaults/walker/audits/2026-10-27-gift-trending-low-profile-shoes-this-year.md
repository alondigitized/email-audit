## 3. Rendering & Accessibility
- **Missing alt text:** `dv.adidas.com/o/ce8e7aa7-28b5-4b69-ae00-c8ce56cb970b?cp_tp=…` has no `alt`. If it is a content image, it is invisible to screen readers and blank when images are off.
- **Ineffective charset declaration:** `<meta content="text/html; charset=UTF-8" />` has no `http-equiv="Content-Type"`, so it does not declare the charset. This is only a risk if the MIME header lacks a charset.
- **Duplicated CSS:** The `<style>` blocks repeat the same `@font-face` and `@media (max-width:640px)` rules. This adds weight, and the weight matters because Gmail clips messages above roughly 102 KB.
- **Legacy markup:** The doctype is HTML 4.01 Transitional but the markup uses XHTML-style self-closing tags. This is low impact.
- **Font fallbacks:** `AdihausDIN` and `AdineuePRO` resolve only through `local('Arial'…)`, so they fall back to system fonts. That is expected.
