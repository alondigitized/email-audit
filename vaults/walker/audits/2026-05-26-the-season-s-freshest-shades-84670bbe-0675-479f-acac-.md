## Technical Audit

# Technical Audit — "The Season's Freshest Shades ☀️"

## 1. Technical Summary
Email renders on standard table-based scaffolding with responsive media queries, but ships with a broken merge token in the greeting and pervasive `http://` image sources that risk being blocked by modern mail clients. Tracking/beacon stack is heavy (SFMC, Krux, ReturnPath, ink1000) but functional.

## 2. Link & Tracking Issues
- 27 tracking/click-redirect links skipped by automated HTTP probe — link health was not verified end-to-end. Recommend a manual sample of `click.emails.skechers.com` redirects to confirm 2xx resolution.
- Multiple parallel tracking beacons fire on open: `click.emails.skechers.com/open.aspx`, two `beacon.krxd.net/1x1_usermatch.gif` calls, one `beacon.krxd.net/1x1_ad_impression.gif`, `pixel.app.returnpath.net/pixel.gif`, and `ink1000.com/p/up/.../o.gif`. No functional issue, but the ReturnPath pixel uses a protocol-relative-less `src="pixel.app.returnpath.net/..."` (missing scheme) — browsers/mail clients will resolve it against the email's base, which is undefined in MUAs and will likely 404.

## 3. Rendering & Accessibility
- **Missing `alt` attributes**: `o.gif` (ink1000 tracker — acceptable) and `49468f73-4651-4af3-bea2-61d1ae5db486.png` (content image — should have alt text for screen readers and image-blocking clients).
- **Non-HTTPS image hosts**: 9 images served over `http://image.emails.skechers.com/...` and `http://www.ink1000.com/...`. Gmail, Outlook.com, and Apple Mail Privacy Protection may proxy or block these as mixed/insecure content. Switch all to `https://`.
- `<meta content="IE=Edge" />` is missing its `http-equiv="X-UA-Compatible"` attribute — the tag is inert as written.
- First `<meta>` is also missing `http-equiv="Content-Type"`.
- Doctype is XHTML 1.0 Transitional — fine for email, but the `<style>` rule `a { text-decoration: none; }` strips link affordance globally; relies on inline overrides at each CTA.

## 4. Personalization & Merge Tokens
- **[FAIL] Empty greeting slot** — Greeting renders as "Hi ," indicating an unresolved first-name merge field (likely `%%FirstName%%` or AMPscript `%%=v(@FirstName)=%%` without a default). Add a fallback (e.g., `%%[ IF EMPTY(@FirstName) THEN SET @FirstName = "there" ]%%`) or strip the greeting block when the field is null.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- Cannot fully verify from the truncated source — unsubscribe link, physical postal address, and `List-Unsubscribe` / `List-Unsubscribe-Post: List-Unsubscribe=One-Click` headers were not provided. Confirm presence in the footer block and SMTP headers; required for Gmail/Yahoo bulk-sender compliance (Feb 2024 mandate).
- From-address `no-reply@emails.skechers.com` is a `no-reply` mailbox — CAN-SPAM permits it provided a working unsubscribe exists, but Gmail bulk-sender guidance discourages no-reply senders.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- Source is truncated before content CTAs are visible; UTM parameters on destination links could not be verified. The ink1000 tracker carries an internal campaign code `mi_ecmp=MKG_US_NA_U_MULTI_ENGAGEDOPEN_EN_05262026`, but this is a vendor parameter, not GA-compatible UTM. Confirm CTAs append `utm_source=email&utm_medium=email&utm_campaign=...` for site-side attribution.

## 7. Recommendations
1. **Fix merge token**: add a default-value guard on the first-name token so the greeting never renders "Hi ,".
2. **Migrate all image hosts to HTTPS**: rewrite the 9 `http://image.emails.skechers.com/...` and `http://www.ink1000.com/...` references; non-HTTPS images are increasingly blocked by Gmail/Apple Mail.
3. **Add `alt` text** to the content image `49468f73-...png` (decorative trackers can use `alt=""`).
4. **Fix ReturnPath pixel**: prepend `https://` to `pixel.app.returnpath.net/pixel.gif?...` — currently scheme-less and will not load.
5. **Repair `X-UA-Compatible` meta**: add `http-equiv="X-UA-Compatible"` (and `http-equiv="Content-Type"` on the charset meta).
6. **Verify** the unsubscribe footer + `List-Unsubscribe`/`List-Unsubscribe-Post` headers and end-to-end UTM tagging on CTAs (out of scope of the truncated source provided).
