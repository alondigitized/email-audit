### 3. Rendering & Accessibility

**Confirmed issues:**

**[HIGH] Duplicate `<meta name="viewport">` tags**
Two conflicting viewport declarations are present back-to-back:
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
<meta content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=yes" name="viewport" />
```
The second overrides the first in most parsers. The `maximum-scale=1` on the first conflicts with `user-scalable=yes` on the second. Pick one and drop the other.

**[HIGH] CSS mobile rules with missing dimension values**
Two rules inside `@media only screen and (max-width:480px)` have empty numeric values:
```css
.nav_padding { padding-top:px !important; padding-bottom:px !important; }
.nav_border  { border-top:px solid ; }
```
Both are invalid CSS. `.nav_padding` will produce zero padding on mobile; `.nav_border` will render no border. These are likely template variable substitution failures (a `%%VALUE%%` token that was never populated).

**[MEDIUM] Missing `http-equiv` on charset meta**
```html
<meta content="text/html; charset=utf-8" />
```
Should be:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```
Without `http-equiv`, the charset declaration is non-functional in legacy clients (Outlook 2007–2019).

**[LOW] Empty `<title>` element**
```html
<title></title>
```
Some spam filters score against empty titles. Apple Mail also surfaces the title as a fallback preview label.
