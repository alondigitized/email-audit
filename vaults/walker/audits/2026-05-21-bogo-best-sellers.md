### 3. Rendering & Accessibility

**Issue 1 — Malformed `<meta>` charset declaration (HIGH)**

```html
<meta content="text/html; charset=utf-8" />
```

Missing `http-equiv="Content-Type"`. Without that attribute, this tag is ignored by the parser — the charset declaration is silently dropped. Correct form:

```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```

Risk: character encoding falls back to client default; emoji in subject line (`✅`) may render as mojibake in older clients.

**Issue 2 — Incomplete viewport meta (LOW)**

```html
<meta name="viewport" content="width=device-width" />
```

Missing `initial-scale=1`. iOS Safari may apply auto-zoom on load without it. Correct form:

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

**Issue 3 — CSS grid selector typo (MEDIUM)**

```css
.fluid-row .col-9, .md-fluid-row .col-8 { width: 74.25% !important; }
```

Second selector targets `.col-8` instead of `.col-9`. This means `.md-fluid-row .col-9` elements receive no mobile width override, breaking 9-column fluid layouts on narrow viewports. Correct:

```css
.fluid-row .col-9, .md-fluid-row .col-9 { width: 74.25% !important; }
```
