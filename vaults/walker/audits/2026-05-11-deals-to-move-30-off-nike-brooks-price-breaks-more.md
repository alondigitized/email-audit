## Technical Audit

## Technical Audit — Shoe Carnival | SCA_20260511_nike_jordan_AM

---

### 1. Technical Summary

Three redirect/tracking URLs contain an injected zero-width space (`U+200B`) that causes ASCII encoding failures, likely breaking click-tracking and open-tracking for affected links. All other infrastructure appears functional; no compliance blockers detected in the available source.

---

### 2. Link & Tracking Issues

**CRITICAL — Zero-width space in tracking URLs (3 URLs affected)**

The QA confirms an `'ascii' codec can't encode character '\u200b'` error at position 74 in three URLs, all sharing the same malformed UTM tail:

```
...t=utm_campaign=SCA_20260511_nike_jordan_AM​
                                             ^-- U+200B zero-width space here
```

Affected URL patterns (emltrk.com click-redirect domain):
- `?rd&i=72180589&t=utm_campaign=...` — primary click redirect
- `?rl&i=72180589&t=utm_campaign=...` — likely unsubscribe/list redirect
- `?p&i=72180589&t=utm_campaign=...` — likely open/pixel tracking

**Root cause**: The zero-width space was likely introduced during copy-paste of the campaign name into the template or ESP URL builder. The character is invisible but breaks ASCII URL encoding at the transport layer.

**Impact**: These links will fail to resolve cleanly in any email client or redirect handler that strictly encodes URLs. Click data for these events will be lost or errored.

**WARN — 26 tracking links skipped**

All `ieezzy5m.emltrk.com` and similar redirect domains were skipped by the HTTP probe. The 3 FAIL items are a subset of these. No way to confirm landing page integrity for the remaining 23 without manual spot-check.

### 3. Rendering & Accessibility

**Missing alt text — content image**
```
src: https://image.email.shoecarnival.com/lib/fe3311737164047d701077/m/1/d06be110-6c0c-4df3-aeee-e04bf8e18969.jpg
```
This appears to be a content/hero image, not a tracking pixel. Missing `alt=""` degrades accessibility (screen readers) and breaks the image-blocked fallback experience.

**Malformed meta tag**
```html
<meta content="IE=edge" />
```
Missing the required `http-equiv="X-UA-Compatible"` attribute. Should be:
```html
<meta http-equiv="X-UA-Compatible" content="IE=edge" />
```
Minor — most modern clients ignore this tag entirely, but it's technically invalid markup.

**Duplicate CSS property in link rule**
```css
color:inherit !important; color:inherit;
```
The non-`!important` declaration is dead code. No rendering impact, but indicates a copy-paste artifact.

**Tracking pixels — alt text**
The emltrk open-pixel and the `0di86k1v` pixel are flagged for missing alt text. These should carry `alt=""` (empty string) to be semantically correct, though no visible impact.

### 6. Email-to-Site Continuity

The zero-width space in `utm_campaign=SCA_20260511_nike_jordan_AM​` means any clicks that do resolve through the redirect will deliver a malformed UTM value to the landing page. Attribution in GA4 or equivalent will either drop the parameter or record a garbage campaign name, severing the send↔conversion chain for this campaign.

The `t=utm_campaign=...` pattern (passing UTM as a query param to the tracking redirect, not directly in the destination URL) is ESP-standard for emltrk; not itself an issue, but it means UTM integrity depends entirely on the redirect handler correctly forwarding the value — which the encoding error prevents.
