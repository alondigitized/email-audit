## Technical Audit

## 1. Technical Summary
The visible HTML is a standard table-based responsive template with Apple and Samsung autolink fixes and a Gmail app fix. The QA data shows 86% pass, 0 failures and 1 warning. The one confirmed content defect is a tracking pixel with an unresolved `[UNIQUE]` placeholder. The source is truncated and the auth headers are unavailable, so compliance can't be fully verified.

## 2. Link & Tracking Issues
- **Unresolved placeholder:** `https://0di86k1v.emltrk.com/v2/0di86k1v?d=[UNIQUE]` has a literal `[UNIQUE]` in the `d=` parameter. If this was meant to be a per-recipient ID, the open pixel is not recording unique opens. This is the strongest finding.
- **Invisible character in URL:** the `ieezzy5m.emltrk.com` src ends with `...nike_AM​`, and the QA output shows a zero-width character after `AM`. If it is in the real `src`, it may be percent-encoded or break the `t=` value. It could also be an artifact of the QA extraction, so confirm it in the raw source.
- **Unprobed links:** 29 tracking links were skipped (`emltrk.com` click-redirect domains). Their destinations and HTTP status are unverified. This is a coverage gap, not a defect.

## 3. Rendering & Accessibility
- **Missing alt text:** both flagged images are `emltrk.com` tracking pixels. Impact is low, but add `alt=""` so screen readers skip them.
- **Malformed meta tags:**
  - `<meta content="text/html;" charset="utf-8" />` has no `http-equiv`.
  - `<meta content="IE=edge" />` has no `http-equiv="X-UA-Compatible"`, so it does nothing.
- **Doctype mismatch:** the doctype is HTML 4.01 Transitional, but the `<html>` tag carries `xmlns="http://www.w3.org/1999/xhtml"`. Browsers and clients tolerate this, but it is inconsistent.
- **Small mobile text:** `.responsive-text` is forced to `font-size: 12px !important` at `max-width: 600px`, and to 14px above 601px. Mobile text is smaller than desktop and below the common 14px minimum.
- **Link styling stripped:** the global rule `a { text-decoration:none !important; color:inherit !important }` removes link styling. Check in the full source that links are still visually distinguishable.

## 4. Personalization & Merge Tokens
- The `[UNIQUE]` placeholder above is the only token problem in the visible source.
- The truncated source shows no other unresolved merge tags such as `%%...%%`, `{{...}}` or `*|...|*`. The rest of the body can't be checked.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication:** `Authentication-Results` was not found. The QA tool attributes this to the AgentMail relay, so SPF, DKIM and DMARC status is unknown, not failed. Verify against the original message headers.
- **Unsubscribe and address:** the truncated source doesn't include the footer. I can't confirm the unsubscribe link, the physical postal address or the `List-Unsubscribe` and `List-Unsubscribe-Post` headers.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- The one visible campaign value is `utm_campaign=SCA_20261125_boots_clogs_nike_AM`. The date (20261125) and the AM send slot match today. The `boots_clogs_nike` segment doesn't obviously match the "Black Friday doorbusters / cozy styles starting at $19.98" subject. This may just be the campaign naming convention.
- UTM parameters on the actual landing-page URLs weren't verified, because the links were skipped.
- No landing-page alignment check was possible.

## 7. Recommendations
1. Fix the `d=[UNIQUE]` pixel so the ESP substitutes a real recipient or message ID. Check that other pixels and links don't have the same problem.
2. Check the raw source for the invisible character in the `ieezzy5m` pixel URL and strip it if present.
3. Add `alt=""` to both tracking pixels.
4. Correct the meta tags (`http-equiv="Content-Type"` and `http-equiv="X-UA-Compatible"`) and make the doctype and `xmlns` consistent.
5. Raise the mobile `.responsive-text` size to at least 14px.
6. Re-run QA against the full HTML and the original headers. This should cover SPF/DKIM/DMARC, `List-Unsubscribe`, the footer address and unsubscribe link, redirect resolution for the 29 skipped links, and UTM parameters on the landing pages.
