- 2. **Lead the Brooks tile with a comfort signal.** Even one line — "Ghost 17 · Max cushion · Wide widths available" — would turn a generic logo into a reason to click for someone like me.

### 2. Link & Tracking Issues

### 3. Rendering & Accessibility

**Malformed IE compatibility meta tag:**
```html
<meta content="IE=edge" />
```
Missing the required `http-equiv` attribute. Correct form:
```html
<meta http-equiv="X-UA-Compatible" content="IE=edge" />
```
Without `http-equiv`, Outlook 2007–2019 ignores this directive entirely, and the IE rendering engine version is uncontrolled.

**Dark mode declared light-only:**
```html
<meta name="color-scheme" content="light" />
<meta name="supported-color-schemes" content="light" />
```
Explicitly locks the email to light mode. If any subscriber has system-level dark mode, Apple Mail and the latest Samsung client will not apply OS-level inversion. Intentional if no dark mode stylesheet exists, but document the decision.

**Phone/SMS links globally disabled:**
```css
a[href^="tel"], a[href^="sms"] {
  color: inherit !important;
  pointer-events: none;
  cursor: default !important;
}
```
`pointer-events:none` makes any `tel:` or `sms:` link non-clickable in WebKit clients. If the email contains a customer service number, it will render as visible text but be un-tappable on mobile. Confirm no phone numbers appear in the body; if they do, this rule must be scoped or removed.
