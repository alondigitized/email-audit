### 4. Personalization & Merge Tokens

**[FAIL] Empty name merge token — confirmed broken experience**

The greeting renders as `"Hi ,"` — the first-name substitution variable resolved to an empty string. This indicates either:
- The subscriber record has a null/blank `first_name` field with no fallback default defined in the SFMC content block
- The AMPscript or personalization string lacks a fallback (e.g., `%%=v(@firstName)=%%` with no `IIF` guard)

Evidence: QA flag `"Greeting has empty name field (e.g. 'Hi ,')"` — confirmed FAIL.

Recommended fix (AMPscript):
```

]%%
```
