## Technical Audit

# Technical Audit: New Balance, "Up to 30% off select styles ends today"

## 1. Technical Summary
The email has no probe failures, but the template has several hygiene defects. These are a duplicated subject string, a leftover placeholder asset URL, a conflicting CSS rule, `@font-face` blocks with no `src`, and three images without alt text. The QA run gave an 88% pass rate with 0 issues and 1 warning. The HTML source was truncated and no raw headers were supplied, so the compliance and tracking findings are limited to what was visible.

## 2. Link & Tracking Issues
- **Plain-text part is mostly URLs.** QA reports 12,764 of 14,480 characters (88%) are URLs. This points to long redirect-wrapped tracking links in the text alternative, and it is a spam-filter and readability risk.
- **Probe coverage is partial.** 12 links were probed and 28 were skipped (footer, utility and social links were deprioritized). No broken links were reported among the 12, but the 28 skipped links are unverified.
- **Open-tracking pixel:** `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12430110_363993_23426463.gif` is served from the same redirect domain as the content images. It is not itself a defect, but see section 3 for its missing alt.
- **Placeholder URL in CSS.** `.bgwhite {… background-image: url('http://image.XXXXX.png');}` is a template placeholder and is non-HTTPS. If that class is applied, it requests a dead, insecure resource and can trigger mixed-content warnings.

## 3. Rendering & Accessibility
- **Missing alt text (3 images, confirmed by QA):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png`
  - `egR1f966kc_…gif`, the tracking pixel, which should have `alt=""`.
  - The first two carry content, so they should have real alt text.
- **Doctype and namespace mismatch.** The doctype is `HTML 4.01 Transitional`, but `<html xmlns="http://www.w3.org/1999/xhtml">` is set. They conflict, and `<meta charset>` and the `/>` self-closing tags are XHTML or HTML5 syntax.
- **Malformed meta tag.** `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Leftover template title.** `<title>New Balance Template</title>` was not replaced. Some clients and accessibility tools surface the title.
- **Conflicting CSS.** `.bg1` is defined twice, first as `background-color:#ffffff` and later as `background:#58546d`. The later rule wins, and it is overridden again in the dark-mode query with `!important`. This can produce unintended light-mode backgrounds wherever `.bg1` is used.
- **Ineffective `@font-face` rules.** Every declaration (`linotype-didot`, `proxima-nova`, and so on) has no `src`. No web font can load, so text always falls back to Arial or Times New Roman. One block also repeats `font-family` (`proxima-nova,sans-serif` is declared twice).
- **Reused welcome-series assets.** The images under `/custloads/…/NBUS/myNB_Welcome/UpdatedImages/` come from a welcome-series asset folder, which suggests the template was reused.

## 4. Personalization & Merge Tokens
- **Duplicated subject text.** The subject reads "Up to 30% off select styles ends today, up to 30% off select styles ends today". This looks like subject and preheader concatenation or a template variable populated twice, and it needs fixing on the send side.
- No unresolved merge tokens (such as `%%…%%`, `{{…}}` or `[FNAME]`) are visible in the truncated source.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Not verifiable from the supplied data.** The footer was truncated, and no `List-Unsubscribe`, `List-Unsubscribe-Post`, SPF, DKIM or DMARC results were provided.
- QA states an unsubscribe link is always included in probing, and no failure was reported for it.
- The From domain `email.newbalance.com` is a subdomain of the brand domain. Alignment cannot be confirmed without the headers.
- Physical postal address presence could not be checked.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **Not verifiable.** The truncated source shows no `href` values, so UTM parameters, redirect chains and landing-page match cannot be assessed.
- The 12 probed links reported no errors.

## 7. Recommendations
1. Fix the duplicated subject string in the send configuration.
2. Add descriptive alt text to `ShippingIcons_06.png` and `ShippingBanner_DarkMode_03.png`, and add `alt=""` to the tracking pixel.
3. Remove or replace the `http://image.XXXXX.png` placeholder in `.bgwhite`.
4. Resolve the duplicate `.bg1` definition and remove the dead `@font-face` blocks, or add a `src` to each.
5. Normalize the doctype and `xmlns`, fix `<meta http-equiv="X-UA-Compatible" content="IE=edge">`, and replace the `<title>`.
6. Shorten or reduce the URLs in the plain-text part, and add more plain-text copy to improve the text-to-URL ratio.
7. Re-run the audit with full headers and the complete HTML, so that unsubscribe headers, SPF/DKIM/DMARC, UTM tagging and the 28 skipped links can be checked.
