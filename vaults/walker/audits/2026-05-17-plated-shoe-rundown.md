### 3. Rendering & Accessibility

**`<meta charset>` missing `http-equiv`**
```html
<!-- actual -->
<meta content="text/html; charset=utf-8" />

<!-- correct -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```
Without `http-equiv="Content-Type"`, some legacy Outlook/webmail clients may ignore the charset declaration, risking mojibake on non-ASCII characters.

**Duplicate, conflicting `<meta viewport>` tags**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
<meta content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=yes" name="viewport" />
```
Two viewport declarations with contradictory `user-scalable` behavior. The first implicitly locks scale; the second permits it. Browsers use the last declaration — behavior is inconsistent across clients. Keep one.

**Malformed CSS values in `@media (max-width: 480px)`**
```css
.nav_padding { padding-top:px !important; padding-bottom:px !important; }
.nav_border  { border-top:px solid ; }
```
Both rules have missing numeric values — `px` without a number is invalid. These declarations will be silently dropped by all CSS parsers, meaning mobile nav padding and border are not applied. If these classes are used in the template, mobile nav rendering will be broken.

**`-webkit-text-size-adjust: none` on `*` selector**
```css
* { -webkit-text-size-adjust: none; }
```
Set to `none` globally, not `100%`. This completely disables font scaling in WebKit browsers, which is an accessibility regression — WCAG 1.4.4 (Resize Text) is violated in WebKit-based clients when users attempt to zoom.

**Empty `<title>` tag**
```html
<title></title>
```
No functional impact on email delivery, but some webmail clients (Gmail browser, Yahoo) surface the title in tab or preview contexts. Low priority.

**Custom web fonts loaded from external CDN**
```
src: url("https://www.hoka.com/on/demandware.static/...")
```
Gmail (webmail), Outlook (all versions), and Yahoo strip or block external `@font-face` declarations. The fallback font stack is not visible in the truncated source — confirm a safe system font fallback is declared so layout doesn't collapse.
