### 3. Rendering & Accessibility

**`Src:` (capital S) in all 10 `@font-face` blocks — invalid CSS**
```css
Src: url("https://braze-images.com/appboy/.../original.woff") format('woff');
```
The CSS property `src` is case-sensitive in spec-compliant parsers. Capitalized `Src` is silently ignored by most modern renderers, causing all custom fonts to fall back silently. Affects every declared face: `Futura_PT_Regular`, `Futura_PT_Medium`, `Futura_PT_Demi`, `Futura_PT_Bold`, and all six `HelveticaNow_*` variants.

**Missing `http-equiv` on two `<meta>` tags**
```html
<meta content="text/html; charset=utf-8" />
<meta content="IE=Edge" />
```
Both require `http-equiv` to be valid and honored by Outlook/IE rendering engines:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

**Conflicting `text-size-adjust` values in the same rule block**
```css
*{ -ms-text-size-adjust: 100%; -webkit-text-size-adjust: 100%; ... -ms-text-size-adjust: none; text-size-adjust: none }
```
`-ms-text-size-adjust` is declared twice with conflicting values (`100%` then `none`). The second declaration wins, disabling auto-sizing in IE/old Edge mobile. `text-size-adjust: none` also suppresses iOS pinch-to-zoom scaling, which is a WCAG 1.4.4 (Resize Text) failure.

**`maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user zoom on mobile. WCAG 1.4.4 non-conformance; also blocked by Apple's own WebKit rendering in iOS 10+, making it ineffective and still a declared accessibility violation.

**Non-standard shorthand order in mobile border rule**
```css
border-top: 1px #000001 solid !important;
```
Correct shorthand order is `width style color`. Some parsers reject non-standard order; should be `1px solid #000001`.

**`:root` dark mode block contains non-standard CSS property**
```css
@media (prefers-color-scheme: dark) {
  :root { color-scheme: light dark; supported-color-schemes: light dark; }
}
```
`supported-color-schemes` is not a CSS property — it is a `<meta name>` attribute only. Inside `@media (prefers-color-scheme: dark)`, the `color-scheme: light dark` declaration also contradicts itself (declaring `light` as supported while inside a dark-only query). Move `color-scheme: light dark` to `:root` outside the media query.

**Font assets on third-party CDN (`braze-images.com`)**
All 10 font files resolve from Braze's asset CDN. If Braze CDN is blocked by a corporate proxy or the file is deleted/expired, all custom typography degrades to fallbacks with no client-side warning. The `.woff`-only format (Futura PT faces) drops support for legacy clients; `.ttf`-only (HelveticaNow faces) lacks the `woff2` variant, missing compression gains.
