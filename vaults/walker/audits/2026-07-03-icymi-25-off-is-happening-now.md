## 3. Rendering & Accessibility

**[HIGH] Two meta tags are non-functional — missing `http-equiv`**

```html
<meta content="text/html; charset=utf-8" />
<meta content="IE=Edge" />
```

Neither tag has its required `http-equiv` attribute. Without it, they are ignored by all parsers. Correct forms:

```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

The charset declaration being inert is especially risky — encoding fallback behavior varies by client.

**[MEDIUM] `maximum-scale=1` blocks user zoom (WCAG 1.4.4)**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Prevents users from zooming in on mobile, which fails WCAG 1.4.4 (Resize Text, Level AA).

**[MEDIUM] Conflicting `text-size-adjust` in `*` selector — `none` wins**

```css
* {
  -ms-text-size-adjust: 100%;   /* set first */
  -ms-text-size-adjust: none;   /* overrides — none wins */
  text-size-adjust: none;       /* same issue, all browsers */
}
```

`-ms-text-size-adjust` is declared twice in the same `*` rule with conflicting values. The last declaration (`none`) wins in all cases. Globally disabling text-size-adjust can cause unexpected text scaling behavior on iOS/Android WebKit and Outlook Mobile.

**[LOW] Off-black color `#000001` used for "black" values**

```css
.border-top-black { border-top: 1px #000001 solid !important; }
.dm-font-black    { color: #000001 !important; }
```

One unit off true black (`#000000`). May be an intentional client-quirk workaround, but if not, it should be corrected to `#000000` to avoid any color-profile edge cases.

**[LOW] Font format coverage is incomplete**

Futura PT faces provide only `.woff` (no `.woff2`). HelveticaNow faces provide only `.ttf`. Neither format set includes `.woff2`, which has ~30% better compression and is supported by every modern email client that supports web fonts at all. Fallback stacks are present in CSS, so this is a performance issue, not a rendering failure.
