# Now on: Enjoy up to 25% off select shoes.
**Score:** 7/10 · **Type:** Email audit · **2026-06-07**
## Executive summary

- I saw "New Balance Offers" in my inbox and my thumb just kind of... hovered there. Not because I was excited, but because I've been doing this dance with them for weeks now. June 3rd was a "25% off select shoes." May 28th was "Starting today: up to 25% off select shoes." Before that, same offer, different subject line. This one says "Now on: Enjoy up to 25% off select shoes." I feel like I'm caught in a loop. They changed "Starting today" to "Now on" and called it a new email.
- I opened it anyway — old habit — and got a picture of two shopping bags sitting on a table. Not shoes. Bags. The headline told me what the deal was but didn't give me a single reason to care about my feet. No cushioning story, no comfort angle, nothing about wide widths or arch support. Just the same sale, rewarmed. And then a grid of products where the most interesting thing I spotted was the 327 Hook & Loop — a velcro shoe, which actually *would* get my attention — but it's buried four rows down between a sock pack and a baseball cleat.
- I'd probably mark this read and move on. Maybe I'd tap "Men" out of habit if I were bored at the doctor's office. I wouldn't forward this to anyone — what would I say? "Hey, New Balance is running that sale again"?

## What's working

- **Men button is right there.** First category listed, no hunting around. Good.
- **Offer amount is crystal clear** — 25% off shoes, 30% off clothes, use JUNESALE, ends Saturday. That's the full picture in two lines.
- **327 Hook & Loop showed up in the grid.** A velcro-closure walking shoe is exactly what I scan for. It shouldn't be buried — but at least it's in there.
- **Free shipping threshold is visible** in the top banner ($75+). That's useful information and I notice it.
- **No render issues.** Clean layout, nothing broken or overlapping. On my phone it loaded fine.

## What's weak

- **A shopping bag as the hero image.** That tells me nothing about the shoe I might be buying. I want to see a sole, a collar, a wide-width tag — something I can project my foot onto.
- **No comfort language anywhere in the email.** The word "cushion" does not appear. "Arch" does not appear. "Wide" does not appear. For someone shopping this brand for the 990v6 or the Fresh Foam line, this is leaving points on the table.
- **This is the fifth or sixth "25% off select shoes" email I've gotten this month.** At this point the offer doesn't feel like a deal, it feels like wallpaper. The cadence has completely eroded the urgency.
- **The product grid mixes stuff I have zero interest in** — an 8-pack of low-cut socks, what appears to be a baseball cleat (FuelCell Compact), alongside lifestyle shoes. Feels like a warehouse clearout, not a curated recommendation for me.
- **Fine print under the hero is unreadably small on mobile.** I know there are exclusions. I can't read them. That creates doubt before I even get to the product grid.

## Recommendations

- 1. **Lead with a shoe, not a bag.** Drop the kraft paper bag lifestyle shot entirely. Put the Fresh Foam Arishi or the 327 Hook & Loop dead-center in the hero. Give me a cushioned, wider-looking shoe and put "up to 25% off" right on the image.
- 2. **Segment the men's comfort walk shoes into their own send.** I don't need women's, kids', and socks in my email. A tighter, men's-comfort-walk-focused email would feel like it was sent to me specifically.
- 3. **Put the 327 Hook & Loop in the hero or at minimum the first product slot.** A velcro walking shoe is newsworthy for someone my age. Bury it fourth and I miss it.
- 4. **Change the deadline phrasing.** "Now through Saturday" is vague — what's the date? Say "Ends Sunday, June 8" so I know if I'm reading this Monday, it's already gone.
- 5. **Vary the offer or rest this email type.** If you've sent this subject line five times in six weeks, give it a week off. The Monday-after version of this same email will get even less engagement.

- **Subject Alt B:** `Ends Saturday: 25% off the shoes that don't argue with your feet`
- **Preheader Alt A:** `Plus 30% off apparel. Use code JUNESALE — no minimum on these picks.`
- **Preheader Alt B:** `Velcro closures, wide widths, cushioned soles — sale ends Saturday.`

### 3. Rendering & Accessibility

**Bug — duplicate `.bg1` class with conflicting values:**
```css
/* First definition (line ~6) */
.bg1 {background-color: #ffffff;}

/* Second definition (line ~80, overrides) */
.bg1 {background: #58546d;}
```
Any element using `.bg1` renders as purple-gray (`#58546d`), not white. The second definition wins in all CSS-supporting clients. One of these is a copy-paste error; verify which value is intended and remove the other.

**Bug — all `@font-face` blocks are missing `src:` declarations:**
```css
@font-face { font-family: linotype-didot, serif; font-weight: 400; font-style: normal; }
@font-face { font-family: proxima-nova, sans-serif; font-weight: 700; font-style: normal; }
/* ... (8 total, none have src:) */
```
These rules declare names but load nothing. `proxima-nova` and `linotype-didot` will silently fall back to `Arial`/`Times New Roman` in every client. If the intent is to pull from Adobe Fonts / Typekit via CSS embed URL, that link is missing from the `<head>`.

**Bug — malformed `@font-face` block (italic proxima-nova):**
```css
@font-face {
  font-family: proxima-nova, sans-serif;
  font-weight: 700;
  font-style: italic; font-family: proxima-nova, sans-serif;
}
```
`font-family` is declared twice on the same line with no separator. The second declaration technically overrides the first but the concatenation indicates a template authoring error. Clean to one declaration per property.

**Minor — `<meta>` missing `http-equiv` attribute:**
```html
<meta content="IE=edge" />
```
Should be `<meta http-equiv="X-UA-Compatible" content="IE=edge" />`. No functional impact in modern clients, but invalid HTML and will fail strict validators.
