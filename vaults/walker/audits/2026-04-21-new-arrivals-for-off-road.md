### 3. Rendering & Accessibility

**Duplicate and contradictory `<meta viewport>` tags:**
```html
<!-- Line 1 — disables user zoom -->
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
<!-- Line 2 — re-enables user zoom -->
<meta content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=yes" name="viewport" />
```
Parser behavior varies by client; the first declaration typically wins, meaning user zoom is disabled — an accessibility regression for low-vision readers.

**Empty `<title>` tag:**
```html
<title></title>
```
Used by some email clients (notably Outlook Web) as a fallback display string. Should contain either the subject line or a descriptive value.

**Missing `http-equiv` on charset meta:**
```html
<meta content="text/html; charset=utf-8" />
```
Should be:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```
Without `http-equiv`, the charset declaration is non-standard and ignored by strict parsers.

**`-webkit-text-size-adjust: none` on universal selector (`*`):**
```css
* { -webkit-text-size-adjust: none; }
```
This is applied globally instead of on `body` only, and uses `none` instead of `100%`. On iOS, `none` can prevent users from overriding text size at the OS level — accessibility violation. Should be `body { -webkit-text-size-adjust: 100%; }`.

**Web fonts via `@import` (Adobe Typekit / futura-pt, new-spirit):**
Typekit fonts are fetched via `@import url("https://p.typekit.net/...")`. Gmail (all surfaces), Outlook (Windows), and Yahoo strip `@import` and external font references. The rendered fallback font stack needs verification in the truncated body CSS — if no system font fallback is declared, text will render in the client default (typically Times New Roman on Outlook).

**Typekit kit last published 2022-03-23:**
```css
/*{"last_published":"2022-03-23 22:26:23 UTC"}*/
```
Over 3 years stale. If the font kit has been updated or fonts removed on Adobe's side, subset mismatches can cause rendering gaps. Worth confirming the kit is still active.
