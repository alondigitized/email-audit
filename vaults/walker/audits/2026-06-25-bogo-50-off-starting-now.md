# BOGO 50% off…starting NOW!
**Score:** 9/10 · **Type:** Email audit · **2026-06-22**
## Executive summary

- BOGO 50% off is the kind of math my brain actually does in a shoe store. Buy one pair, get the second one half off — suddenly I'm thinking about the slip-ons my feet have been asking for and maybe a second pair of walkers. The subject is short, plain, and DSW muscle memory got my thumb moving before I'd even processed the words. That much works.
- But the moment the email loaded I was staring at strappy sandals, platform heels, and kitten heels. Not a single men's shoe in the whole featured grid. The "Shop by Size" section runs 5 to 11 with a "Shop Wide Calf" button alongside it — that's women's boot sizing. DSW stocks New Balance, Hoka, Brooks walking styles in men's — but they decided to show me none of that. I'm a 62-year-old man with wider feet and I got the women's lookbook.
- I'd click anyway because the deal structure is genuinely good and I know where to find the men's section. But I wouldn't forward this to a friend — none of the guys I know are in the market for a strappy heel at half off.

## What's working

- **BOGO is a stronger offer structure than the $10-off loop** — after what feels like two weeks of "$10 off ends tomorrow," this feels like a reset. The math is better and the format is different enough to feel like a new chapter.
- **Hero legibility** — "BOGO 50% OFF*" is enormous, high-contrast text. No zooming, no squinting on a phone screen.
- **"HOT DEAL SUMMER" framing** — tees up the hero without being clever; I knew what I was looking at inside one second.
- **"SHOP WIDE WIDTH" button** — that's the only signal in the whole email that DSW thought about my feet specifically. Wide fit matters to me and I noticed it.
- **VIP section visible** — I can confirm my DSW VIP status applies without hunting. That small reassurance matters when I'm deciding whether to click now or wait.

## What's weak

- **Every featured shoe is women's** — the "So New, So You" grid shows six products: strappy sandals, platform heels, kitten heels, an ankle boot. Zero men's options. I might as well have received a different brand's email.
- **"Shop Wide Calf" button right next to Wide Width** — I know what calf-width boots are, and they're not for me. That button signals the whole size section was designed around women's boot shopping.
- **No end date on the BOGO** — "starting NOW" tells me when it launched, not when it dies. Without a deadline I feel no pressure to click today over next week.
- **No comfort or fit language anywhere in the hero** — cushioning, arch support, slip-on, walking — none of my keywords appear. The offer could apply to my shoes but nothing in the copy signals it.
- **Preview text padding** — the real preview copy ends after about 38 characters and then my inbox showed a long run of invisible filler characters. Doesn't break anything, but it's a sloppy trick that savvy subscribers notice.

## Recommendations

- 1. **Segment the product grid for the recipient** — show me men's comfort styles under the BOGO headline. One image of a New Balance or Hoka walker with "BOGO 50% off" above it and I'm clicking before I scroll.
- 2. **Add an end date** — "BOGO 50% off — ends Sunday" is urgency. "Starting NOW" is only half the sentence.
- 3. **Replace "Shop Wide Calf" with a men's wide-fit callout** — "Shop Men's Wide" or even just "Men's Wide Width" tells me I'm accounted for.
- 4. **One comfort/fit line in the hero subhead** — something like "Slip-ons, walkers, and wide widths included" signals the deal applies to my category without rebuilding the whole email.
- 5. **Drop the invisible-character preview padding** — write a proper 90-character preheader and let it breathe.
- **Subject Alt A:** `BOGO 50% off: buy one pair, get one half off`
- **Subject Alt B:** `Men's BOGO — your second pair is 50% off`
- **Preheader Alt A:** `Walking shoes, slip-ons, wide widths — all in the deal. Ends Sunday.`
- **Preheader Alt B:** `Pick any two pairs — the cheaper one is half off. No code needed.`

### 3. Rendering & Accessibility

**`Src:` (capital S) in all 10 `@font-face` blocks** — CSS property names are case-sensitive in some parsers. All `@font-face` declarations use `Src:` instead of the spec-required `src:`. Most email clients ignore web fonts entirely, so practical impact is low, but this is invalid CSS and could cause issues in WebKit-based preview renderers.

```css
/* all 10 blocks — example: */
Src: url("https://braze-images.com/.../original.woff") format('woff');
/* should be: */
src: url("...") format('woff');
```

**Contradictory `text-size-adjust` values in `*` selector** — the reset sets `-ms-text-size-adjust: 100%` (correct, prevents Outlook scaling) immediately followed by `text-size-adjust: none` (disables user/browser text scaling entirely). `none` can fail WCAG 1.4.4 (Resize Text) if subscribers rely on browser text zoom. The value should be `100%`, not `none`.

```css
*{
  -ms-text-size-adjust: 100%;   /* correct */
  -webkit-text-size-adjust: 100%;
  text-size-adjust: none;        /* should be 100% */
}
```

**`supported-color-schemes` is not a valid CSS property** — inside the `:root` block, `supported-color-schemes: light dark` is declared. This is an Apple `<meta>` tag name, not a CSS property. The correct CSS property is `color-scheme` only. The erroneous line has no functional effect but indicates a copy-paste error from the `<meta>` block.

```css
:root {
  color-scheme: light dark;           /* valid */
  supported-color-schemes: light dark; /* invalid — remove */
}
```

**Two `<meta>` tags are missing required `http-equiv` attributes:**

```html
<!-- Missing http-equiv="Content-Type" -->
<meta content="text/html; charset=utf-8" />
<!-- Should be: -->
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />

<!-- Missing http-equiv="X-UA-Compatible" -->
<meta content="IE=Edge" />
<!-- Should be: -->
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

Without `http-equiv`, these directives are inert. The charset declaration failing means Outlook on Windows may fall back to system encoding.
