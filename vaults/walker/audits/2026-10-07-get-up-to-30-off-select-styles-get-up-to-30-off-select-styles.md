# Technical Audit: New Balance Offers, "Get up to 30% off select styles"

## 1. Technical Summary
The email has no hard failures: the QA pass rate is 88% with 0 issues and 1 warning. The source does show template leftovers (a placeholder image URL, a generic `<title>`), a duplicated subject string, and three images with no alt text. The HTML source I received is truncated, so body links, footer and headers could not be inspected.

## 2. Link & Tracking Issues
- **Plain-text part is mostly URLs (QA WARN):** 12,804 of 14,530 characters are URLs, about 88%. The plain-text alternative is dominated by long tracking links, which is a spam-filter risk.
- **Link probing is partial:** 12 links were probed and 28 were skipped. The QA tool reports no broken links among those 12. The 28 skipped links (footer, utility, social) are unverified.
- **Insecure placeholder URL:** `.bgwhite {background-image: url('http://image.XXXXX.png')}` is a plain-HTTP placeholder left in the CSS. It will 404 wherever `.bgwhite` is used, and it is a mixed-content risk.
- **Tracking pixel:** `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12389888_1768701_23338646.gif` is an open-tracking GIF with no alt text.

## 3. Rendering & Accessibility
- **Missing alt text (QA WARN, 3 images):**
  - `ShippingIcons_06.png`
  - `ShippingBanner_DarkMode_03.png` (a content banner, so the missing alt is a real gap)
  - the tracking GIF above (should carry `alt=""`)
- **Fonts will not load:** every `@font-face` rule (`proxima-nova`, `linotype-didot`, and others) has no `src`, so clients fall back to Arial or Times New Roman.
- **Malformed meta tag:** `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Doctype mismatch:** the HTML 4.01 Transitional doctype is combined with an XHTML `xmlns` attribute and self-closed tags. This is not fatal, but it can trigger quirks in some clients.
- **Conflicting CSS:** `.bg1` is defined twice, first as `#ffffff` and later as `#58546d`. The later rule wins unless the dark-mode `!important` override applies.
- **Dark mode:** the dark-mode support (`color-scheme` meta, `prefers-color-scheme` block) is present. It also has a dedicated `ShippingBanner_DarkMode` asset.

## 4. Personalization & Merge Tokens

- **Leftover template title:** `<title>New Balance Template</title>` was never replaced.
- **Reused welcome assets:** the image paths contain `myNB_Welcome/UpdatedImages/`. The shipping assets appear to come from the welcome-series template.
- No unresolved `%%…%%` or `{{…}}` tokens were visible in the portion provided.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)

- SPF, DKIM, DMARC and `List-Unsubscribe` header values were not supplied, so they could not be verified.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)

## 7. Recommendations
1. **Fix the subject.** Find why the string repeats in the subject builder or dynamic content, and send only one copy.
2. **Add alt text.** Give `ShippingBanner_DarkMode_03.png` and `ShippingIcons_06.png` descriptive alt text, and set `alt=""` on the tracking GIF.

4. **Fix or remove the `@font-face` blocks.** Add `src` URLs, or delete the rules so the fallback fonts are intentional.
5. **Slim down the plain-text part.** Reduce the long tracking URLs and add real descriptive text, to improve the text-to-link ratio.
