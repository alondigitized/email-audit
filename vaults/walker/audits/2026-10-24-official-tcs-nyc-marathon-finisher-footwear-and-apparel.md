## Technical Audit

## 1. Technical Summary
The email's QA run found no failures, but the HTML source has template-leftover defects (placeholder `<title>`, placeholder CSS image URL, `@font-face` rules with no `src`). The plain-text part is mostly URLs, and two images lack alt text. The source was truncated, so findings about the body, footer and headers are limited to what the QA data covers.

## 2. Link & Tracking Issues
- 12 material links were probed and 19 were skipped, so 61% of the 31 links are unverified. The QA tool deprioritizes footer and social links, so those are the unchecked ones. No probed link was reported broken.
- Links go through the click-tracking domain `link.email.newbalance.com`. The final destinations and any UTM parameters can't be confirmed from the data provided.
- The inline CSS contains `.bgwhite {... background-image: url('http://image.XXXXX.png');}`. This is a placeholder URL over plain `http://`. It will 404 anywhere `.bgwhite` is applied, and it could trigger mixed-content blocking.

## 3. Rendering & Accessibility
- **Missing alt text (QA-confirmed):**
  - `https://link.email.newbalance.com/custloads/818512772/NBUS/myNB_Welcome/UpdatedImages/ShippingBanner_DarkMode_03.png`. This is a content image, so screen readers get nothing. The `myNB_Welcome` path suggests an asset reused from the welcome template.
  - `https://link.email.newbalance.com/mo/egR1f966kc_818512772_12505492_476004_23590016.gif`. This is almost certainly the open-tracking pixel. Missing alt is low impact here, but `alt=""` is still correct.
- **Placeholder title:** `<title>New Balance Template</title>` was never replaced. Some clients and archive or web-view pages show it.
- **Invalid meta tag:** `<meta content="IE=edge" />` has no `http-equiv`, so it does nothing.
- **Doctype mismatch:** The HTML 4.01 Transitional doctype is paired with `xmlns="http://www.w3.org/1999/xhtml"` and self-closing tags. This is harmless in most clients but inconsistent.
- **Ineffective `@font-face` blocks:** `proxima-nova`, `linotype-didot`, `proxima-nova-condensed` and `ITC Garamond Book Condensed` are declared with no `src`. No webfont will load, and clients fall back to `Arial` or `Times New Roman`. The `.fst10` and `.fst12` classes use `linotype-didot`, so they fall back to serif.
- **Conflicting `.bg1` rules:** `.bg1` is defined twice (`#ffffff`, then `#58546d`), and the second wins. If `.bg1` is applied, the result may not be the intended white.
- **Dark-mode link contrast:** The dark-mode rule `body {background:#151415 !important;} a {color:#cf0a2c !important;}` gives a contrast ratio of about 3.3:1 (my calculation) for any link that doesn't override it. That is below the WCAG AA threshold of 4.5:1 for normal-size text.

## 4. Personalization & Merge Tokens
No issues found. The truncated source shows no unresolved tokens.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication-Results missing (QA WARN):** SPF, DKIM and DMARC status can't be determined. The QA notes this is expected for the AgentMail relay, so it is a limit of the test setup and not evidence of a sender problem. Not assessable from the data provided. The destinations are hidden behind `link.email.newbalance.com` redirects, and no resolved URLs or UTM parameters were included.

## 7. Recommendations
1. Add descriptive alt text to `ShippingBanner_DarkMode_03.png`, and `alt=""` to the tracking GIF.
2. Remove or replace `background-image: url('http://image.XXXXX.png')` in `.bgwhite`, and use HTTPS if a background image is needed.
