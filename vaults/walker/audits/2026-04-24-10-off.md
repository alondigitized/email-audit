### 3. Rendering & Accessibility

**Confirmed issues:**

- **`maximum-scale=1` on viewport meta** prevents pinch-to-zoom on mobile.
  `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />`
  This is an accessibility failure (WCAG 1.4.4) and Apple/Android guidance explicitly discourages it for email.

- **`text-size-adjust: none` applied to `*` selector** globally disables browser text scaling across all elements. The same rule also sets `-webkit-text-size-adjust: 100%` earlier — the two conflict, and `none` wins for the unprefixed property. Small-text recipients using accessibility zoom will be affected.
  ```css
  *{-ms-text-size-adjust: 100%; -webkit-text-size-adjust: 100%; ... -ms-text-size-adjust: none; text-size-adjust: none}
  ```
  `-ms-text-size-adjust` is also declared twice in the same rule (100%, then none); the second declaration wins.

- **`<meta content="text/html; charset=utf-8" />` is missing `http-equiv`.**
  Should be `<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />`. Without `http-equiv`, some older clients (Outlook 2007/2010) will not recognize the charset declaration, which can cause emoji/special character rendering failures — relevant given the subject line relies on emoji.

- **`Src:` property in all `@font-face` blocks is capitalized**, which is invalid CSS (properties are case-sensitive in the spec). Most clients tolerate it, but it will silently fail in strict parsers.
  ```css
  Src: url("https://braze-images.com/...original.woff") format('woff');
  ```

- **Font format gaps:**
  - Futura PT fonts are served only as `.woff` — no `.woff2`. `woff2` is ~30% smaller and broadly supported; missing it increases load time.
  - HelveticaNow fonts are served only as `.ttf` — no `.woff` or `.woff2`. TTF is the least-compressed format. All web font requests go to `braze-images.com` (third-party CDN); a CDN outage silently falls back to system fonts.

- **Alt text on images** cannot be verified from the truncated source. Flag for manual check — DSW emails are image-heavy.
