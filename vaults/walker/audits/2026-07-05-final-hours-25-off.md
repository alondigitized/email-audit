### 3. Rendering & Accessibility

**[HIGH] `<meta>` tags missing `http-equiv` attribute**

Two meta declarations are malformed:
```html
<!-- Missing http-equiv="Content-Type" -->
<meta content="text/html; charset=utf-8" />

<!-- Missing http-equiv="X-UA-Compatible" -->
<meta content="IE=Edge" />
```
Without `http-equiv`, these tags are treated as unknown custom metadata and ignored by the parser. The charset declaration in particular is the fallback for clients that don't read the MIME header. Should be:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta http-equiv="X-UA-Compatible" content="IE=Edge" />
```

**[MEDIUM] Invalid `Src:` casing in all `@font-face` declarations**

All 10 `@font-face` blocks use `Src:` (capital S) instead of the valid lowercase `src:`:
```css
@font-face {
  font-family: 'Futura_PT_Regular';
  Src: url("https://braze-images.com/...") format('woff');
}
```
`Src:` is not a recognized CSS property; the correct property is `src:`. Most Chromium-based clients are tolerant, but strictly-conformant parsers (some webmail renderers) will silently drop the declaration and fall back to system fonts.

**[MEDIUM] `text-size-adjust` conflict disables mobile text scaling**

The `*` selector contains a contradiction and a hardcoded `none`:
```css
* {
  -ms-text-size-adjust: 100%;   /* set */
  -ms-text-size-adjust: none;   /* immediately overrides — net effect: none */
  text-size-adjust: none;        /* disables scaling in all unprefixed-supporting clients */
}
```
`text-size-adjust: none` prevents the OS from scaling text on small viewports. The email industry convention is `100%` (allow, but don't auto-inflate), not `none`. Setting `none` can cause copy to be unreadably small on certain Android clients.

**[LOW] `#000001` near-black color**

`border-top-black` and `.dm-font-black` use `#000001` instead of `#000000`. This is a known Gmail link-auto-detection workaround. Not a defect, but should be documented as intentional — any future color-system tooling that expects pure black (`#000000`) will see a mismatch.
