# $20 Off Is Calling ✨
**Score:** 9/10 · **Type:** Email audit · **2026-05-15**
## Executive summary

- This is a clean, formula-correct flash-sale send built around a tiered spend-and-save mechanic: $10 off $50, $20 off $75, code SAVE20, deadline May 17. The hero is unambiguous — a close-up model anchors the visual, the dollar amounts are large and high-contrast, and the "Shop now" button is visible above the fold. The product grid below ("Top searched online") anchors the offer to hair color specifically, which is the right category for a Sally Beauty subscriber.
- The structural problem is urgency is buried. "Ends May 17" appears in the fine print under the hero but nowhere in the subject line, which is where urgency does its heaviest lifting — at the inbox open decision. For a send explicitly calling itself a "Flash Sale," that's a real miss. The two-tier offer ($10 off / $20 off) also softens the punch; the reader has to do math before committing to either.
- Context matters here too: this lands one day after the May 14 Hot Tools send ($40% off styling tools). Back-to-back promotional days with different mechanics risk getting mentally merged by subscribers. The May 5 ion flash sale (8/10) outperformed this in focus precisely because it had a single message. This send has more visual richness but less message clarity.

## What's working

- Dollar amounts ($10 / $20) are large, high-contrast, and immediately legible in the hero
- Code "SAVE20" is explicit and easy to remember — no hunting required
- "Ends May 17" is visible in the hero sub-copy, creating time pressure post-open
- Hair color product grid ("Top searched online") grounds the discount to a real category with four named products
- No render bugs — images load, text is clean, layout holds

## What's weak

- Subject line omits the deadline entirely — "Ends May 17" only appears after the open, where it matters less
- Two-tier offer ($10 off $50 / $20 off $75) introduces math before the click — one threshold would hit harder
- "Shop now" is the weakest possible CTA copy — doesn't reinforce the discount or name the category
- Sent the day after a separate 40% off promotion; the cadence is running hot and this send doesn't have a distinct enough angle to stand apart
- Sally Beauty rewards program is completely absent — no loyalty hook despite the program existing

## Recommendations

- 1. **Put the deadline in the subject line.** "Ends May 17" or "2 Days Left" added to the subject would add the urgency signal that a flash sale requires but currently only delivers post-open.
- 2. **Collapse to one offer tier.** Lead with $20 off $75 only. Footnote the $10 tier in fine print if the business requires it. The double-tier structure dilutes the single punch this email needs.
- 3. **Rewrite the CTA.** "Claim $20 Off" or "Shop Hair Color Deals" beats "Shop now" by naming what you get and where you go.
- 4. **Add a single loyalty line.** Even one sentence ("Rewards members earn points on every order") uses an asset Sally Beauty already has and gives members an incremental reason to click.

**`'Founders Grotesk'` declared with no `@font-face`** (confirmed defect)
```css
a {
  font-family: 'Founders Grotesk', Helvetica, sans-serif;
}
```
Founders Grotesk is not a system font on any major OS. No `@font-face` block for it appears anywhere in the `<head>`. Every `<a>` element falls back to Helvetica/sans-serif. This affects all clickable links sitewide in the email.

**`white-space: pre` on `img` elements** (unusual, low-risk)
```css
img { -ms-interpolation-mode: bicubic; white-space: pre; }
```
`white-space: pre` is a text-layout property applied to replaced content. It has no effect on image rendering, but it signals the stylesheet was modified without full understanding — strip it to keep the ruleset clean.
