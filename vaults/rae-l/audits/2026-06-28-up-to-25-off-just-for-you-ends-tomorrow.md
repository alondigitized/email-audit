# Up to 25% off just for you ends tomorrow...
**Score:** 7/10 · **Type:** Email audit · **2026-06-28**
## Executive summary

- This is Glossier's second resurrection of the Friends of Glossier Sale — a sale that theatrically "ended" on June 19 across three emails in a single day, then came back on June 24 as "For your eyes only," and has now returned once more on June 28 with an almost identical frame: "ends tomorrow," same 20%/25% off structure, same code logic. The email itself is clean and well-built — branded flatlay, tight best-sellers grid, legible offer — but the credibility debt Glossier has been running up since mid-June is now the dominant fact. "Ends tomorrow" means nothing when subscribers have seen it five or six times in ten days.
- Inside the email the execution is competent. The hero communicates the tiered offer (20% sitewide, 25% on $100+) with a promo code (SAVEMORE), and the four-product best-sellers grid gives recipients something specific to click into. The visual hierarchy is functional but not tight — the headline is small relative to the flatlay image, and "Ends tomorrow" reads as a pill badge rather than a true hero statement.
- The lasting damage is to urgency credibility. At this point the subscriber has every reason to assume another send arrives in four days with the same deal. That's the single biggest problem in this email, and no copy tweak fixes it.

## What's working

- **Tiered offer is clearly stated** — "20% off sitewide or 25% off $100+" is unambiguous; subscribers know exactly what they need to spend to hit the better tier.
- **Promo code is visible in the hero** — SAVEMORE is easy to find and copy without hunting.
- **Best-sellers grid is solid** — Four named products (Glossier You, Boy Brow, Cloud Paint, Balm Dotcom) with category labels give real purchase intent something to latch onto.
- **Clean render, no visual bugs** — The flatlay image loads, buttons are intact, no overlapping text.

## What's weak

- **"Ends tomorrow" has zero credibility left** — This claim appeared June 19 (twice), June 24, and now June 28. A repeat subscriber has learned not to believe it.
- **Hero headline is undersized** — "ENDING TOMORROW" and the offer copy are small relative to the flatlay; the eye goes to the product image before the offer.
- **"Just for you" with a generic promo code is a contradiction** — SAVEMORE isn't personalized. The exclusivity signal in the subject collapses the moment the reader sees a generic code in the body.
- **No new reason to act** — Nothing in this email is different from the June 24 send: same discount, same framing, same CTA. There's no new product drop, no bundle, no loyalty tier reveal.

## Recommendations

- 1. **Kill the fake urgency or make it real.** If this is genuinely the last day, say something you haven't said before — confirm the code expires at midnight, show a countdown, or name a specific hard-stop. If you're going to keep running the sale, stop saying "ends tomorrow."
- 2. **Make the headline the hero.** "20% or 25% off — your choice" or the tiered structure deserves H1 treatment, not the product flatlay image. The flatlay should support the offer, not compete with it.
- 3. **Retire SAVEMORE, introduce a segment-specific code** — If the "just for you" claim is real (it's a segmented send), prove it with a code that looks unique. Even something like YOUGLOSS25 reinforces the personalization.
- 4. **Lead with one product, not four.** The best-sellers grid dilutes intent. Feature Balm Dotcom or Cloud Paint as a true hero link, then show supporting products below.
- 5. **Acknowledge the pattern and own it** — A single line like "We extended it — here's one more day" lands with more honesty than treating every send as if the previous ones didn't happen.
- **Subject Alt A:** `Last call: 25% off with SAVEMORE — tonight only`
- **Subject Alt B:** `We extended it. Your 25% off ends at midnight.`
- **Preheader Alt A:** `20% off everything, 25% off $100+. Code expires tonight — we mean it.`
- **Preheader Alt B:** `Use SAVEMORE before midnight — this one's actually the last send.`

### 1. Technical Summary
Email is Klaviyo-sent (ESP: `eml.glossier.com`, click tracker: `ctrk.klclick.com`) and built with Stripo-generated markup. One confirmed invalid HTML construct in the open-tracking implementation; remaining sections are truncated and several compliance items cannot be fully verified.

---

### 2. Link & Tracking Issues

**[CONFIRMED] Invalid open-tracking element**
```html
<span rel="stylesheet" href="https://ctrk.klclick.com/l/01KW8413GX68SRXPS7YAA0J3Q8_0"></span>
```
`rel` and `href` are not valid attributes on `<span>`. The standard implementation is a 1×1 `<img>` pixel. Some clients (notably Apple Mail with MPP, and strict HTML parsers) may silently drop this element, causing open-tracking undercounting. Klaviyo's standard open pixel should be `<img width="1" height="1" src="..." alt="">`.
