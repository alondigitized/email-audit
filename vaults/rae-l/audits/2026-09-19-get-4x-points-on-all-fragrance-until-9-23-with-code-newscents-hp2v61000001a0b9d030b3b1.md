# Get 4X points on all fragrance until 9/23 with code NEWSCENTS
**Score:** 6/10 · **Type:** Email audit · **2026-09-19**
## Executive summary

- Sephora actually leads with the offer this time: "4X POINTS¹ ON ALL FRAGRANCE" with code NEWSCENTS sits in a hot-pink banner at the very top, so the subject line and the render agree with each other before you even scroll. That's a step up from the brand's recent habit of subject/body mismatch (see the 2026-09-16 "Beauty's most wanted" send and the 2026-09-14 "BIG NEWS" send, both 6/10 for bait-and-switch).
- But the hero section undercuts its own promo. "BEAUTY FOR ALL / These picks will be on repeat" is generic filler copy sitting where the fragrance hero should be, and it's immediately followed by a giant Prada cologne bottle image with a separate "4X POINT PER DOLLAR" badge — two different visual "heroes" competing for the same slot. Below that, the email sprawls into an unrelated grid of "His New Scent Lineup" plus Benefit, Peter Thomas Roth, Khloé Kardashian fragrance, Olaplex, Glossier, Fresh, DAE, and Beautyblender products — none of which are fragrance, which dilutes a promo that was supposed to be about fragrance points.
- Net: strong open-to-scroll consistency, weak execution once you land — this is a fragrance offer wearing a general beauty catalog's body. Middling send, better than this week's worst but not up to the 2026-09-15 flash-sale standard (9/10).

## What's working

- Top banner states the exact mechanic (4X points, code NEWSCENTS, expires 9/23) with no ambiguity.
- The Prada bottle hero is a large, clean product image with no render bugs — no overlapping text, no broken assets.
- "Get a Mini" Burberry Goddess Amber Vanilla sample offer is a legible secondary CTA with clear terms ("ONLINE ONLY WITH $60 PURCHASE").
- Footer correctly reiterates the offer mechanic and dates for anyone who scrolled all the way down, reinforcing the code.

## What's weak

- The hero headline ("BEAUTY FOR ALL / These picks will be on repeat") has nothing to do with fragrance or the 4X points offer — it's a mismatched stock headline.
- Only one small section ("His New Scent Lineup") is actually fragrance; the rest of the email is a generic multi-category grid (makeup, hair, skincare, tools), burying the stated promo under unrelated products.
- No fragrance-specific product grid tied to the 4X offer — you get one hero bottle (Prada) and then a text link "Shop the Hottest Scents," no other scent SKUs shown.
- Visual hierarchy is muddled: banner → unrelated Burberry sample offer → generic "BEAUTY FOR ALL" hero → fragrance hero — the eye bounces between three different messages before settling.

## Recommendations

- 1. Cut the "BEAUTY FOR ALL / These picks will be on repeat" hero entirely and replace it with fragrance-specific hero copy that echoes the banner ("4X points, ends 9/23") — right now the strongest asset (banner) and the biggest visual block (hero) say different things.
- 2. Replace the generic multi-category grid with an actual fragrance product grid (3-6 named scents with price + points multiplier badge) so the body matches the subject promise.
- 3. Move "Shop the Hottest Scents" text link into a real button directly under the Prada hero — it's currently a small text CTA competing with a full-size "SHOP NOW" button above it for the wrong section.
- 4. Reconsider bundling the Burberry mini sample offer above the fold — it's a different offer (not a fragrance-points offer) and it delays the reader from reaching the fragrance hero.
