# Select brands are 50% off today 🤑
**Score:** 9/10 · **Type:** Email audit · **2026-09-15**
## Executive summary

- This is the rare Sephora "50% off Select Beauty" send that actually says what it does. Subject: "Select brands are 50% off today 🤑" — and the very first thing you see is a hot-pink "50% off Select Beauty" banner with a "TODAY ONLY" badge. No digest bait-and-switch, no K18-serum-that's-actually-a-flash-sale trick like 2026-09-14's two sends. It's the same honest execution as 2026-09-12's "Today only: 50% off select faves 🌶️."
- Below the fold it sprawls into a second campaign ("Beauty's Latest" / INNBEAUTY Project) and a long product grid, which dilutes the single-offer clarity that made the hero strong. It reads like two emails stapled together — one flash-sale blast, one new-launch showcase — competing for the same click.
- Judgement: solid, honest execution of a promo this brand has now run five-plus times in a week. The creative itself is clean; the fatigue is the real problem.

## What's working

- Hero banner delivers exactly what the subject promises — 50% off, today only, no mismatch.
- "TODAY ONLY" urgency badge is visible immediately without scrolling.
- Clear "SHOP NOW" CTA button directly under the hero offer.
- Product grid shows real prices and "NEW / LIMITED EDITION / ONLY AT SEPHORA" tags, giving concrete detail (sizes, dollar values, even "$44 value" comparisons).
- Beauty Insider loyalty tier bar (Insider/VIB/Rouge) is visible near the footer for members.

## What's weak

- The email pivots hard from the 50% off hero into an unrelated "Beauty's Latest" / INNBEAUTY launch section — two competing offers dragging on attention.
- "SHOP NOW" is used as the CTA on nearly every module; none of the copy is product- or benefit-specific.
- No models or demographic signal anywhere in the render — entirely product-shot based, so it's impossible to tell who this is being targeted at.
- Fine-print exclusion ("*Exclusions/terms apply. While supplies last.") sits directly under the headline offer in tiny type — technically disclosed, but easy to miss at a glance.
- This is at least the fifth near-identical 50%-off-beauty send from this account this week (09-09 through 09-15) — cadence fatigue is real.

## Recommendations

- 1. Cut the email to one campaign. Either send the 50% off flash sale alone, or the INNBEAUTY launch alone — stapling both cuts effectiveness of each.
- 2. Replace generic "SHOP NOW" with category-specific CTAs ("Shop the Sale," "Shop New Arrivals") so each module reads as its own action, not a repeated button.
- 3. Acknowledge the offer has been running for days — add "last chance" or "final day" framing if true, since a subscriber who's seen this five times needs a reason this send is different.
- 4. Move the exclusions disclosure slightly larger/clearer so the "honest offer" signal is unambiguous rather than reliant on fine print.
- **Subject Alt A:** `Last call: 50% off select beauty, ends tonight`
- **Subject Alt B:** `Your 50% off pick is waiting — today only`
- **Preheader Alt A:** `Benefit, Sephora Collection & COLOR WOW — up to half off, no code needed.`
- **Preheader Alt B:** `Plus: the new INNBEAUTY cleanser just dropped.`
