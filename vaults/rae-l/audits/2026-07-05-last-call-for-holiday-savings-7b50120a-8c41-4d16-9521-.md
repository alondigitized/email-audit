# Last Call for Holiday Savings
**Score:** 9/10 · **Type:** Email audit · **2026-07-05**
## Executive summary

- This is Sally Beauty's mechanical close on the same AMERICA25 campaign that ran July 3rd. The creative team did the right thing by relabeling the hero "Last Day to Save" rather than recycling the 4th of July patriotic framing — the holiday is over, and leaning into urgency instead of nostalgia is the smart pivot. The red hero section is clean, the code is prominent, and the 2-hour delivery callout in the utility bar adds a logistics reason to act today.
- The problem is what hasn't changed: same code, same discount depth, similar layout, back-to-back with yesterday's send. A subscriber who opened the July 3rd email and didn't buy has already tuned out, and this email gives them no new reason to act beyond "it's actually the last hour." The subject buries the 25% figure and the code entirely — the one fact that could change someone's behavior on the last send of a campaign.
- The trending items grid (Ion, L'Oreal, Salon Care, Beauty Secrets) is fine but generic. This final send deserved a tighter, more product-specific push — one hero item on markdown, or a category ("Last chance on hair color") rather than a catch-all.

## What's working

- Red hero with "Last Day to Save" headline lands cleanly — urgency reads immediately without needing to scroll.
- AMERICA25 code is visible and prominent in the hero body copy, not buried below the fold.
- The 2-hour delivery utility bar at top adds a same-day logistics hook that differentiates this from a generic "sale ends soon" email.
- Klarna callout below the fold is a solid trust-builder for anyone considering a larger cart.
- No render bugs — images load, text is legible, layout holds.

## What's weak

- Subject line omits the discount entirely — "Last Call for Holiday Savings" gives the subscriber no number, no code, and no category hook.
- "Holiday Savings" is already stale on July 5th; the holiday ended yesterday and the framing no longer creates resonance.
- Every CTA in the email reads "Shop now" — zero specificity across five separate click opportunities.
- The trending items section has no apparent logic connecting the four products — hair color, shampoo, and nail glue feel like an inventory pull, not a curated close.
- Back-to-back with the July 3rd send, this email has no new creative leverage to re-engage subscribers who skipped the prior email.

## Recommendations

- 1. **Put the discount and code in the subject.** This is the last send of the campaign — the subject should convert fence-sitters, not brand-aware openers. Every character that isn't "25% off" or "AMERICA25" is a missed close.
- 2. **Drop "Holiday Savings," write a deadline.** Replace the hero subhead with something like "Sale ends at midnight — 2-hour delivery still available." The holiday framing is expired; a clock is not.
- 3. **Pick one hero product and feature it.** The rose gold styling tool is already in the visual — name it, price it, link it directly. "Last Call: [Tool Name] — [original price] → [discounted price]" would outperform the generic grid on a last-day send.
- 4. **Rename the CTAs.** "Shop Hair Color," "Shop Nail," "Shop Tools" — each one earns a separate click and a lower friction path. "Shop now" ×5 is dead weight.
- 5. **Time-stamp the urgency.** "Ends midnight tonight" or "Ends at 11:59PM" is more credible than "Last Call" which has been used across multiple sends this week.
- **Subject Alt A:** `Last Call: 25% Off Ends Tonight — Code AMERICA25`
- **Subject Alt B:** `Today Only: 25% Off Sitewide (AMERICA25 Expires Tonight)`
- **Preheader Alt A:** `Hair color, styling tools, nails — free 2-hr delivery on $25+`
- **Preheader Alt B:** `AMERICA25 expires at midnight. Your order ships in 2 hours.`

**`img { white-space: pre; }`** (line in `<style>` block)
`white-space: pre` is not a valid or meaningful property for replaced elements like `<img>`. While browsers ignore it on images, it is a malformed rule that indicates template hygiene issues and could behave unexpectedly in non-standard renderers.

**`'Founders Grotesk'` referenced but never loaded**
The global `a` selector sets `font-family: 'Founders Grotesk', Helvetica, sans-serif`, but no `@font-face` declaration for Founders Grotesk exists — only Open Sans is loaded. Every link in the email falls back to Helvetica. If Founders Grotesk is a brand font, this is a rendering regression across all clients.

**Open Sans pinned to `v17`**
All six `@font-face` src URLs reference `fonts.gstatic.com/s/opensans/v17/...`. Current Open Sans on Google Fonts is v29+. Google typically preserves old version paths, but this is fragile and technically outdated.

**Web fonts in email — limited client support**
`@font-face` from an external URL renders only in Apple Mail, iOS Mail, and a small number of clients. Gmail (web and Android), Outlook (Windows), and Samsung Mail all strip or ignore it. Fallback stacks must carry the full visual weight — verify the Helvetica/sans-serif fallback is acceptable at production.

**`-ms-interpolation-mode: bicubic` on `img`**
IE-only property, unsupported in all modern email clients and browsers. Dead code; harmless but indicates template age.
