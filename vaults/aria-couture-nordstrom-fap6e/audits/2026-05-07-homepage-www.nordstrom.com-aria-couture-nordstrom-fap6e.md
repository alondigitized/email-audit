# Homepage snapshot · www.nordstrom.com · 2026-05-07
**Score:** 1/10 · **Type:** Site journey · **2026-05-07**
## Executive summary

- I opened nordstrom.com on my phone and got hit with a wall — literally a blank white page screaming "We've noticed some unusual activity." No hero, no sale, no Nordy Club welcome, nothing. This isn't a homepage experience; it's a security block page that treats me like a bot instead of one of their best customers. If I didn't already have the app installed, this would be a hard bounce.

## What's working

- **The Nordstrom wordmark** loads cleanly in the top-left — brand identity is legible, at least.
- **Customer Service phone number (1.888.282.6060)** is hyperlinked and functional, so if I were genuinely locked out I'd have a recovery path.
- **"© 2026 Nordstrom, Inc."** in the footer confirms the page is at least current-year infrastructure.

## What's weak

- **The entire homepage is missing** — what's served is a bot-detection interstitial, not a shopping experience.
- **No navigation, no categories, no search bar** — I can't get anywhere from this screen.
- **The language is accusatory** — "unusual activity" and "unidentified, automated traffic" — I'm a loyal Nordy Club member and this copy makes me feel like a suspect.
- **Zero personalization or session recognition** — if I were logged in, a signed-in customer should never land here.
- **The Affiliate Network link is the only outbound option** — deeply off-brand for a premium retailer's homepage.
- **No retry path or "continue as human" button** — I'm just stuck.

## Recommendations

- **Add a "Continue to Nordstrom.com" button** that lets a real user bypass the block with one tap — the current page offers no recovery for legitimate customers.
- **Replace the accusatory copy** ("unusual activity," "automated traffic") with neutral language: "We're having trouble loading the page — tap below to continue."
- **Surface a logged-in customer bypass** — if a valid session cookie or Nordy Club token is present, skip the block entirely and route to the personalized homepage.
- **Log and alert on false-positive block rates** — if this page is showing to real shoppers at any meaningful volume, it's actively destroying conversion for high-LTV accounts.
