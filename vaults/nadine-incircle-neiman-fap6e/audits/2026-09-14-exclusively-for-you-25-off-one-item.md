# Exclusively for you: 25% off one item
**Score:** 7/10 · **Type:** Email audit · **2026-09-14**
## Executive summary

- This is the first genuinely concrete, personalized-feeling offer in this brand's recent stretch — a real 25% off with a unique promo code (SEPT25-K9K1-Q52FS6) printed right in the hero, not another vague gift-card tier or pure editorial. It beats the last several sends (9/12's "Etro Collection," 9/13's "Wedding-guest looks") on offer clarity alone: mauve hero, big "25% OFF," a clear "TREAT YOURSELF" button, code banner directly below. Compare to 9/11's Beauty Event tote-with-purchase send (8/10) — this has similar concreteness but a bigger catch.
- The catch is the fine print: "one regular-price item," a long exclusion list running Akris through Vintage Watches (dozens of major designer brands excluded), and no visible expiration date above the fold — "Ends 9/15/26" is buried in the legal block at the bottom. That's a real bait-and-switch risk once a shopper reads past the hero. The 9-product grid underneath is generic seasonal merchandising, not tied to the offer.
- Net: solid hero mechanics dragged down by exclusionary fine print and a same-old grid. Middle-of-the-pack send, better than most of this week's editorial-only emails but not as clean as the Beauty Event.

## What's working

- Big, unambiguous "25% OFF" headline with a real, unique promo code visible without digging into T&Cs.
- Single clear CTA ("Treat Yourself") sized and placed well against the mauve hero.
- Clean visual hierarchy — offer, code, then product grid, then category buttons, in a logical top-down flow.
- No render bugs — images, buttons, and text all display cleanly.

## What's weak

- "Exclusions Apply" is the only fine-print flag visible in the hero; the actual exclusion list (dozens of top designers) only appears in tiny legal text at the very bottom.
- No visible deadline in the hero — "Ends 9/15/26 at 10:00 PM CT" is buried at the bottom, so there's no urgency cue where the eye actually lands.
- The 9-product grid (Mac Duggal dress, Burberry bag, Chloe boots, etc.) isn't obviously tied to the 25%-off eligibility — several of those brands may well be on the exclusion list, which risks a click-through letdown.
- Same generic "shop by category" 6-button grid this brand reuses across sends (women's clothing/men's/shoes/jewelry/handbags/home) — no fresh merchandising angle.

## Recommendations

- 1. Add a short deadline line directly under "Exclusions Apply" in the hero (e.g., "Ends 9/15") — urgency at the point of decision, not buried in legal copy.
- 2. Replace "Exclusions Apply" with something honest but reassuring, like "Exclusions apply — see eligible brands," and/or curate the product grid to only show items that actually qualify for the 25%, so there's no disconnect between hero promise and grid reality.
- 3. Swap the reused 6-button category grid for 2-3 curated "shop eligible categories" buttons tied to this specific promo.
- 4. Consider surfacing 2-3 example eligible brands/categories near the code so shoppers don't have to guess.
- **Subject Alt A:** `Your code inside: 25% off, ends tomorrow`
- **Subject Alt B:** `25% off one item — just for you`
- **Preheader Alt A:** `Your unique code is ready. Exclusions apply — ends 9/15.`
- **Preheader Alt B:** `Treat yourself: one item, 25% off, through tomorrow only.`
