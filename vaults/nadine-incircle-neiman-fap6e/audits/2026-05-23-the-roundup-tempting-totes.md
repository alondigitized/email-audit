# The Roundup: Tempting Totes
**Score:** 4/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- "The Roundup: Tempting Totes" is NM's editorial-format send — no discount, no urgency, just a curated product grid with the word "Tempting" doing all the selling. After six days of Designer Sale and spend-to-save mechanics, a pure editorial send is a sensible cadence reset. The creative is clean, on-brand, and well-produced.
- The problem is what's absent: there's no price, no brand name on most bags, no "on sale" tag, and no offer. This is essentially a shoppable lookbook — fine for brand building, but it asks the subscriber to do all the work. The CTA buttons ("Shop Totes," "Shop Must-Have Bags," "Shop New Arrivals") are category links, not product-specific pulls. The hero tote — which is gorgeous — has no label, no price, and no direct link copy.
- Net judgement: pleasant to look at, easy to ignore. It earns its right to exist in the cadence as a breather from promo hammering, but it won't move the needle.

## What's working

- **Clean visual hierarchy.** Hero bag is large, lit beautifully, and the eye lands on it immediately before moving to the product grid.
- **On-brand restraint.** White backgrounds, serif font, NM logo — fully consistent with the brand's editorial voice.
- **Product variety.** Four different bag silhouettes (structured tote, shoulder bag, bucket, slouch) cover a range of styles without feeling chaotic.
- **Secondary CTA variety.** "Shop Totes" + "Shop Must-Have Bags" splits intent cleanly — the two buttons serve different shopping modes.
- **Cadence break is warranted.** After back-to-back Designer Sale and spend-to-save sends (5/21–5/23), an editorial format is the right reset.

## What's weak

- **No prices anywhere.** Every bag is anonymous price-wise — zero purchase intent signals for a subscriber deciding whether to click.
- **No brand names visible on the grid bags.** Three of the four smaller bags appear to have designer names in tiny caption text, but they're barely legible at this render size — a real miss when NM's brand equity is its roster.
- **CTAs go to categories, not products.** "Shop Totes" is the weakest possible CTA — it sends someone to a wall of inventory rather than the specific bag that caught their eye.
- **"Tempting" is doing too much work.** The subject and headline both lead with a vague adjective rather than a concrete hook (a brand, a price point, a trend name).
- **No loyalty or member angle.** NM has an InCircle program; an editorial send like this is a perfect place to surface member-exclusive early access or bonus points on bags — absent here.

## Recommendations

- 1. **Add price (or "from $X") to each bag in the grid.** Even a single price point per item would give subscribers a reason to click rather than scroll past.
- 2. **Make brand names legible.** If these are Givenchy, Gucci, Bottega — say so in readable type. The brand name IS the CTA for luxury subscribers.
- 3. **Replace category CTAs with product-specific CTAs.** "Shop This Tote →" under each bag beats "Shop Totes" for a category page every time.
- 4. **Add an editorial hook or trend angle.** "Carry one bag all summer" or "The tote editors are reaching for" gives the email a reason to exist beyond "here are bags."
- 5. **Surface InCircle or member pricing.** Even a footnote — "InCircle members earn 5X points on bags this week" — converts an editorial into a promotional pull.

### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">
```
Prevents pinch-to-zoom. WCAG 1.4.4 failure. Apple and Google both penalize this in rendering scores.

**Dead commented-out viewport variants**
Three alternative viewport tags are left in `<head>` as HTML comments (`width=320, initial-scale=0.29`, `width=1024`, `user-scalable=no`). These suggest iterated A/B testing; dead code should be stripped before send.

**Title trailing whitespace**
```html
<title>Neiman Marcus </title>
```
Renders with trailing space in some client tab/title bar displays. Minor but indicates template hygiene gaps.

**CSS hamburger nav (checkbox hack)**
The mobile nav uses a `<input type="checkbox">` state hack with `visibility`/`opacity` transitions. Known rendering failures in Outlook Desktop and some Android WebView clients.

**Overlapping media query breakpoints**
Three separate `@media` blocks target 480px, 520px, and 600px in two `<style>` tags. No hard conflict, but parse order dependency and duplication increase risk of specificity bugs across clients.

---

### 4. Personalization & Merge Tokens

**`@user` variable — assignment is non-executable**

The template documents this in a header comment:
```
<!--/* SET @user = HASHED_EMAIL_SHA256 */-->
```
This is an HTML comment (`<!-- -->`) containing a JS-style `/* */` comment. Neither construct executes AMPscript. If no active AMPscript `%%[ SET @user = ... ]%%` block exists elsewhere in the untruncated template, `@user` resolves to an empty string at render time. Any downstream personalized tracking, suppression, or segmentation keyed on `@user` silently breaks.

**`@refid` is a no-op concatenation**
```
@refid = CONCAT(@base_refid,"")
```
Concatenating an empty string adds nothing. Not a functional bug, but dead code in the variable setup block.

**7 required variables documented; 2 lookup sources**
`@uEm` and `@cmdid` both look up from `NM_CRM_Feed`; `@user`/`@emailid` from `NM_Subscriber_New_Consolidated`. If either DE is unavailable at send time, all dependent variables silently fail — no fallback or error handling is visible in the truncated source.

### 7. Recommendations

1. Capture raw received headers at the MTA to confirm `List-Unsubscribe` and `List-Unsubscribe-Post` are present in the actual send envelope. If absent, add them to the SFMC send configuration.
2. Rebuild the plain-text version with readable body copy. At 87% URL density it is a near-certain spam-filter trigger with major providers.

6. Strip the three dead commented-out viewport variants from `<head>`.
