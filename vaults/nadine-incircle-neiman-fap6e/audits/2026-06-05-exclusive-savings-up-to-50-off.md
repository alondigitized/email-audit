# Exclusive savings up to 50% off
**Score:** 9/10 · **Type:** Email audit · **2026-06-05**
## Executive summary

- This is Neiman Marcus's Designer Sale continuation — the same red-hero architecture from the June 2 "fresh designer drops" send (which scored 8/10) is now recycled three days later under the subject "Exclusive savings up to 50% off." The creative is immediately legible: LIMITED TIME / THE DESIGNER SALE / UP TO 50% OFF, a nine-product grid anchored by Zimmermann, Loewe, Valentino Garavani, and Burberry, and a six-panel CTA row segmented by gender and category. It's a competent sale email.
- What it isn't is differentiated. Subscribers who opened June 2 are looking at the same red hero, the same 50% claim, the same product-grid layout — with no new creative hook to justify the repeat send. No prices are shown. "LIMITED TIME" floats without a deadline date. "Exclusive savings" in the subject is the kind of phrase every NM promotional email uses, which means it signals nothing.
- Net verdict: this does its job for casual browsers, but for anyone paying attention to NM's cadence — six emails in four days — the sale has been open long enough that the urgency framing reads as wallpaper.

## What's working

- Red hero with large "THE DESIGNER SALE / UP TO 50% OFF" is visually clean and reads in under two seconds on any screen size.
- Nine-product grid with visible brand labels (Rhude, Zimmermann, Loewe, Valentino Garavani, Burberry) gives the sale aspiration and credibility without cluttering the layout.
- Six-CTA panel (Women's Clothing, Men's, Shoes, Handbags, Dresses) is logically segmented — easy to self-select into the right lane.
- "Save on these designer styles before they're gone" adds lightweight scarcity that reinforces the hero's LIMITED TIME signal.
- "Exclusions Apply" is visible below the hero CTA — honest placement, above the fold.

## What's weak

- "Exclusive savings" in the subject is hollow; it's standard NM boilerplate and distinguishes this send from nothing.
- No price points anywhere — the product grid is a mood board, not a sale; a subscriber can't act without clicking through first.
- "LIMITED TIME" with no end date is soft urgency; anyone who got the June 2 Designer Sale send knows this promotion has been running for days.
- No personalization signal anywhere — the six-CTA grid could serve any NM subscriber, which means it's optimized for no one in particular.
- Cadence friction: this is NM's sixth email in four days (sale, gift card, arrivals, Pride, Father's Day); open fatigue is real and accumulating.

## Recommendations

- 1. **Add an end date to the hero.** "ENDS SUNDAY" or "48 HOURS LEFT" turns "LIMITED TIME" from decoration into motivation. Single highest-leverage change.
- 2. **Show at least one price.** Even one anchor — "Valentino Garavani mules, now $345 (was $690)" — makes the 50% claim concrete and converts browsers to buyers.
- 3. **Give repeat openers a fresh angle.** "New styles added to Designer Sale" would differentiate this from the June 2 send and reward subscribers who already opened that one.
- 4. **Drop "Exclusive savings" from the subject.** It adds zero information; the percentage already does the work.
- **Subject Alt A:** `The Designer Sale ends Sunday — up to 50% off`
- **Subject Alt B:** `New styles added: Designer Sale up to 50% off`
- **Preheader Alt A:** `Zimmermann, Valentino Garavani, Loewe and more — while they last.`
- **Preheader Alt B:** `Your favorites are going fast — shop before the sale closes.`

## Technical Audit

## Technical Audit — Neiman Marcus "Exclusive savings up to 50% off"

---

### 1. Technical Summary

The email is built on a standard Salesforce Marketing Cloud (SFMC) AMPscript template with table-based layout. Four QA warnings — two of which directly touch 2024 bulk-sender compliance requirements — require remediation before this template is used at scale.

---

### 2. Link & Tracking Issues

**26 tracking links present; all skipped by HTTP probe.**
All outbound links are wrapped in a click-redirect domain (consistent with SFMC's CloudPages tracking pattern off `e.neimanmarcus.com`). This is expected behavior, but it means:
- UTM parameters on destination URLs cannot be verified from the raw source alone.
- The probe correctly skips these; no broken-link confirmation is possible.

**`@refid` construction is a no-op:**
```
@refid = CONCAT(@base_refid,"")
```
Concatenating with an empty string produces exactly `@base_refid` with no modification. If this was intended to append a suffix (e.g., a version code), the suffix is missing. This may cause campaign attribution to collapse all variants under the same refid.

---

### 3. Rendering & Accessibility

**`maximum-scale=1` blocks user zoom (WCAG 2.1 SC 1.4.4):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">
```
Prevents pinch-to-zoom on mobile. Violates WCAG 1.4.4 (Resize Text, Level AA). Replace with `maximum-scale=5` or remove the constraint entirely.

**Three dead viewport meta tags in source:**
```html
<!--<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no" />-->
<!--<meta name="viewport" content="width=320, initial-scale=0.29">-->
<!--<meta name="viewport" content="width=1024">-->
```
Commented-out directives add template debt and risk accidental activation during copy-paste edits.

**iOS 9 hamburger animation hack still present:**
```css
body { -webkit-animation: bugfix infinite 1s; }
@-webkit-keyframes bugfix { from { padding: 0; } to { padding: 0; } }
```
This workaround targets iOS 9 (released 2015). iOS 9's market share is negligible; the animation loop runs on every render unnecessarily.

**`<title>` tag has trailing whitespace:**
```html
<title>Neiman Marcus </title>
```
Minor, but visible in tab previews in some desktop clients (e.g., Outlook Web).

---

### 4. Personalization & Merge Tokens

**Ambiguous `@user` scenario — one branch commented out:**
```
<!--/* SET @user = HASHED_EMAIL_SHA256 */-->
```
The comment block says "CHOOSE ONE SCENARIO BELOW" but the SHA256 branch is commented out. The active path sets `@user` via `Lookup("NM_Subscriber_New_Consolidated", "EMAIL_ID", "EMAIL_ADDRESS", @email)`. If the SHA256 scenario was intentionally deactivated, the comment should be removed; if it was accidentally left out, this is a data mismatch bug affecting downstream personalization that depends on `@user`.

**No visible fallback values for CRM lookups:**
```
@uEm = Lookup("NM_CRM_Feed", "uEm", "EMAIL_ADDRESS", @email)
@cmdid = Lookup("NM_CRM_Feed", "cmdid", "EMAIL_ADDRESS", @email)
```
SFMC `Lookup()` returns empty string on miss. If `@uEm` or `@cmdid` are appended to tracking URLs or used in conditional blocks without a default, subscribers not present in `NM_CRM_Feed` will generate malformed links or missing content. No `IIF`/`Default` guard is visible in the truncated source.

---

### 5. Compliance

**`List-Unsubscribe` header absent** *(QA: WARN)*
Google and Yahoo's February 2024 bulk-sender requirements mandate this header for senders of >5,000 messages/day. Its absence means Gmail will not render the native one-click unsubscribe button in the inbox UI, increasing spam complaints. Header should be: `List-Unsubscribe: <mailto:unsubscribe@e.neimanmarcus.com>, <https://...>`

**`List-Unsubscribe-Post` header absent (RFC 8058)** *(QA: WARN)*
Required alongside `List-Unsubscribe` to signal one-click POST support. Without it, Gmail treats the unsubscribe as a two-step flow, reducing compliance. Both headers are typically injected by the ESP at send time — confirm SFMC's sending configuration for this sending domain.

**Authentication-Results header not captured** *(QA: WARN)*
SPF and DKIM pass/fail status is unknown through the AgentMail relay. Cannot confirm DMARC alignment. This must be verified directly against the raw SMTP headers at delivery to confirm `e.neimanmarcus.com` is properly authenticated.

**Plain-text alternative is 87% URLs** *(QA: WARN)*
5,140 of 5,910 plain-text characters are URLs. A near-URL-only plain-text part is a known spam-filter signal and provides no readable fallback for clients that strip HTML. The plain-text version should carry substantive content mirroring the email body.

**CAN-SPAM physical address:** Cannot confirm from truncated source — verify footer contains a valid mailing address.

---

### 6. Email-to-Site Continuity

**UTM parameters unverifiable.** All 26 outbound links route through the SFMC click-redirect layer; destination URL parameters cannot be inspected from the raw source. Confirm that the CloudPages redirect targets append at minimum `utm_source`, `utm_medium`, `utm_campaign`, and `utm_content` before resolving to `neimanmarcus.com`.

**`@refid` is effectively unmodified `@base_refid`.** If `@refid` is appended to landing page URLs for campaign attribution, the `CONCAT(@base_refid,"")` pattern means no variant suffix is added — all traffic from this email will be indistinguishable at the refid level if multiple versions are sent.
