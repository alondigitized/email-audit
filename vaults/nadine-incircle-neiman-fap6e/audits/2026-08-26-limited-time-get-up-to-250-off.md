# Limited time: Get up to $250 off
**Score:** 5/10 · **Type:** Email audit · **2026-08-26**
## Executive summary

- This is finally a real, tiered dollar-off offer instead of the gift-card mechanic Neiman Marcus has run to death this month — a clean shift after "Ends tonight" (8/25) and "Ends soon" (8/23) both leaned on the same $75–$1,500 gift card structure. The hero is legible at a glance: LIMITED TIME, UP TO $250 OFF, a spend/save table (spend $400 save $100, spend $1,000 save $250), a visible code, and a black SHOP NOW button. Below that it reverts to the same brand-name-only nine-item grid this account has used since at least 8/24, and stacks a second offer (free shipping on $150+) right after it, which muddies which promo actually wins.
- The tiered discount is more concrete and easier to act on than "up to $1,500 gift card," so this should out-convert the last several sends on paper. But the body content is pure reuse — no new creative, no seasonal framing, no exclusions detail beyond "Exclusions Apply" twice — so it still reads as a templated blast, not a targeted one.

## What's working

- Hero communicates a real, understandable discount structure (spend/save table) instead of a vague gift-card range.
- Single clear CTA button ("SHOP NOW") sits directly under the offer with no scrolling needed.
- Promo code is visible in the hero, not buried in fine print.
- Category shortcut buttons (Women's Clothing, Men's Shoes, Handbags, etc.) give multiple low-friction entry points below the grid.
- No render bugs — images, text, and buttons all display cleanly.

## What's weak

- Product grid is the same brand-name-only format seen in the 8/24 and 8/25 sends — no price, no "new," no styling context, just a designer name under a photo.
- A second, competing offer (free shipping on $150+) is stacked right below the main discount, diluting the primary CTA and creating decision friction.
- "Exclusions Apply" appears with no visible detail — sale/reduced-price items, beauty, gift cards etc. are excluded per the fine print, but none of that shows in the render itself, so the discount may look bigger than it is to most shoppers.
- No urgency deadline shown in the visible creative (the 9/3 10PM CT cutoff is buried in the fine print at the bottom, not in the hero).
- Nothing distinguishes this from the brand's last five sends visually — same tan/black palette, same layout skeleton as the gift-card emails.

## Recommendations

- 1. Put the actual deadline ("Ends 9/3") in the hero, not just the footer fine print — this is the single easiest lift since urgency is currently invisible to anyone who doesn't read the legal text.
- 2. Drop or de-emphasize the free-shipping banner in this send — one offer, one CTA. If both must run, make free shipping a small footer line, not a full-width competing hero.
- 3. Add prices or "as low as" language to at least a few grid items so the $250-off math feels tangible against real product prices.
- 4. Swap 2-3 of the nine grid items for something this account hasn't shown yet — reusing the same rag & bone / Jimmy Choo mix as recent sends risks fatigue for anyone who's opened the last few.
- 5. Move "Exclusions Apply" into a one-line qualifier under the spend/save table (e.g., "excludes sale & beauty") so the offer reads as honest rather than vague.
- **Subject Alt A:** `Spend $400, save $100 — spend $1,000, save $250`
- **Subject Alt B:** `Up to $250 off ends 9/3 — shop new fall arrivals`
- **Preheader Alt A:** `Plus free shipping on orders $150+`
- **Preheader Alt B:** `Sale ends September 3rd at 10PM CT — use code SHOPFALL`
