# Reminder: Enjoy 25% off one item
**Score:** 9/10 · **Type:** Email audit · **2026-07-21**
## Executive summary

- This is NM's follow-up to the July 20 personalized InCircle send ("Just for you: 25% off one item," scored 9/10 here), resurfacing the same unique promo code 24 hours later for subscribers who haven't converted. The "Reminder" framing is a smart, low-pressure nudge — it signals the offer is expiring without manufacturing false panic. The hero is clean, scannable, and brand-consistent: blush field, oversized "25% OFF," personalized code box, and a nine-brand product grid that spans Miu Miu to Manolo Blahnik. For a luxury subscriber who hasn't yet clicked on the original, this is a well-timed push.
- The weakness is structural: the hero delivers the code but never delivers a button. There's no "Shop Now" CTA in the blush panel — the eye lands on the offer and then has to hunt for an action. The six category buttons only appear after scrolling past a full 3×3 product grid. For a reminder email where conversion is the only goal, that gap between offer and click is costing NM real revenue.
- Compared to the original July 20 send, this is essentially an identical creative with a "Reminder:" prepended to the subject. It works — but it doesn't evolve. A subscriber who ignored the first email is being shown the exact same layout, which means anyone who bounced due to lack of urgency or poor product-to-click path is facing the same friction again.

## What's working

- **Hero is immediately readable at a glance** — "25% OFF" in large type dominates the fold, with the blush background creating clear separation from the white body.
- **Personalized promo code displayed prominently** — the code box ("JULY25-1DGZ-RRLJPET") is well-formatted and easy to copy; the unique suffix reinforces that this is a member-gated offer.
- **"Just for you—save on an item you've been eyeing"** is a natural, behavioral hook that implies browse-data personalization without feeling surveillant.
- **Product grid is aspirationally on-brand** — Miu Miu, Chloe, Ferragamo, Oscar de la Renta, Jimmy Choo, Fendi, Veronica Beard, Ulla Johnson, Manolo Blahnik spans all major luxury categories without feeling padded.
- **"Reminder" subject framing is honest and low-pressure** — better than artificial countdown language that NM overuses elsewhere.

## What's weak

- **No hero CTA button** — the blush panel shows the offer and code but gives the reader nowhere to go; shoppers shouldn't have to scroll past nine product thumbnails to find a "Shop" button.
- **No explicit expiration date anywhere in the email** — "LIMITED TIME" is vague; a deadline ("Offer ends July 23") would convert hesitant subscribers who need a reason to act today.
- **Product thumbnails are too small and text-sparse** — nine brand names without prices or product titles; these read as ambient decoration rather than shoppable units.
- **Generic category buttons undercut the "just for you" positioning** — "SHOP WOMEN'S CLOTHING" is fine, but after priming the reader with personalized language, sending them to a category page breaks the promise.
- **Creative is a near-clone of the July 20 send** — for subscribers who bounced the first time, the same visual gives no new reason to convert.

## Recommendations

- 1. **Add a "SHOP WITH YOUR CODE" button directly below the code box** — this is the single highest-leverage change; right now the offer and the action are two scrolls apart.
- 2. **Add a hard deadline line under the hero** — even "Offer valid through July 23" would lift conversion among fence-sitters; the current "LIMITED TIME" copy doesn't close.
- 3. **Swap the generic category grid for 3 personalized "your top picks" product tiles** — if NM knows what the subscriber has been eyeing (as the copy implies), surface those specific items here with prices, not just brand logos.
- 4. **Refresh the creative even minimally** — a different hero color or a single new line of copy ("Still thinking it over?") signals that this isn't just a rebroadcast.
- **Subject Alt A:** `Your 25% off code expires soon — don't miss it`
- **Subject Alt B:** `Still thinking? Your exclusive 25% off is waiting`
- **Preheader Alt A:** `The offer ends soon — shop the item you've been eyeing before it's gone`
- **Preheader Alt B:** `One more day to use your personalized code on any regular-price item`

### 3. Rendering & Accessibility

**Commented-out viewport alternates (dead code)**
Three additional `<meta name="viewport">` tags are present but commented out directly in the `<head>`:
```html
<!--<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no" />-->
<!--<meta name="viewport" content="width=320, initial-scale=0.29">-->
<!--<meta name="viewport" content="width=1024">-->
```
These are harmless but indicate the template was patched rather than cleaned; they should be removed to avoid confusion during future edits.

**Global `p { text-align: center }` override**
The stylesheet applies `text-align: center` to all `<p>` elements. Any paragraph-level copy that should be left-aligned will require an inline override on every instance — a maintenance liability.

**`!important` saturation in media queries**
The responsive block applies `!important` to virtually every property. This is common email practice but makes targeted debugging difficult; worth noting for template maintainers.

**Alt text not verifiable** — the HTML is truncated before image tags appear. Confirm all `<img>` elements carry meaningful `alt` attributes (or `alt=""` for decorative images); screen readers and image-blocked rendering depend on this.

---

### 4. Personalization & Merge Tokens

**Ambiguous active scenario**
The template header documents two scenarios and instructs the sender to "CHOOSE ONE SCENARIO BELOW," but only one is commented out:
```
<!--/* SET @user = HASHED_EMAIL_SHA256 */-->
```
It is not possible to confirm from the truncated source which scenario is active or whether `@user` resolves to a hashed email or an `EMAIL_ID` lookup. If the wrong scenario is live, `@user` may be null or resolve to the wrong identifier for personalized link targeting.

**`@uEm` and `@cmdid` from CRM Feed**
Both require a successful `Lookup("NM_CRM_Feed", ...)` against the recipient's email address. If a subscriber is absent from `NM_CRM_Feed`, these will return null — downstream tracking or personalization dependent on these values will silently fail for that segment. No fallback is documented in the visible source.

**`@refid = CONCAT(@base_refid, "")`**
This is a no-op concatenation (appends an empty string). If the original intent was to append a segment suffix, the value is likely incorrect for the current send.

---

### 5. Compliance

**`List-Unsubscribe` header missing (QA WARN)**
The header was not captured by the AgentMail relay. Gmail and Yahoo have required this header for bulk senders (>5k/day) since February 2024. Its absence risks placement in spam folders and blocks Gmail's native unsubscribe UI. Confirm whether SFMC is injecting it at send time and whether the relay is stripping it.

**`List-Unsubscribe-Post` (RFC 8058) missing (QA WARN)**
One-click unsubscribe (the `POST` mechanism required by Google/Yahoo bulk sender policy) is not present. This is a separate deliverability risk from the above — even if the `List-Unsubscribe` header is present, the absence of the `Post` variant means one-click unsubscribe will not work in Gmail.

**`Authentication-Results` not found (QA WARN)**
SPF and DKIM pass/fail status is unknown because the relay did not surface the header. If DKIM is broken for `e.neimanmarcus.com`, emails will be treated as unauthenticated by major providers. Verify DKIM signing is active on the sending domain.

**CAN-SPAM physical address and unsubscribe mechanism** — not verifiable from the truncated source. Confirm both are present in the footer.
