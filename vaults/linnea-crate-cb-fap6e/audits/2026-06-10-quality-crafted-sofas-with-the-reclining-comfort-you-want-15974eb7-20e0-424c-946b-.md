# Quality-crafted sofas with the reclining comfort you want

- The core problem is timing and positioning. C&B already sent a seating email today ("New chairs are here, and guess what? - Fabric swatch configurators are visible mid-email — genuinely useful product detail for furniture consideration that most editorial sends skip.

- No render bugs — the email is clean, images load, layout holds.
- The lifestyle photography is aspirational and on-brand, matching the neutral/warm palette C&B has been consistent about.

## What's weak

- No promotional offer anchors the email — no sale, no threshold discount, no free shipping hook. Without a reason to act today, this is a catalog browse.
- The "reclining comfort" subject line promise isn't dramatized in the body hero — the copy doesn't lead with that feature or make it the organizing idea of the email.
- Two seating-category emails in one day from the C&B brand family creates cadence fatigue; a subscriber who already saw the chairs email is primed to skim.
- No urgency or time-bound element anywhere — nothing accelerates a decision.
- Social proof is absent — no reviews, no "best seller" badges, no customer count — which matters for a $1,000+ furniture consideration.

- 1. **Add a promotional hook.** Even a threshold offer ("Free white-glove delivery on orders over $X") would convert this from catalog browsing into an action email. This is the single highest-leverage change.
- 2. **Lead the body with the reclining story.** If the subject line promises reclining comfort, the hero copy and hero image should show a sofa *in recline* — not a standard room shot. The angle is good; commit to it.
- 3. **Add social proof to at least one hero product.** A "4.8 stars · 2,400+ reviews" badge on the lead sofa costs nothing and dramatically reduces friction for $1,000+ furniture.
- 4. **Don't schedule this same-day as the chairs email.** Stagger by 2–3 days to avoid intra-brand cannibalization. The tabletop send (7/10, 6/9) showed C&B can drive stronger engagement when the inbox isn't crowded with its own prior sends.
- 5. **Tighten the subject line.** "Quality-crafted" is filler adjective-stacking — cut it.

### 3. Rendering & Accessibility

**Confirmed issues:**

- **Conflicting desktop `max-width` rules.** Two separate `@media` blocks target desktop images:
  ```css
  @media only screen and (min-width: 768px) { img { max-width: 600px } }
  @media only screen and (min-width: 640px) { img { max-width: 640px } }
  ```
  At viewport widths ≥ 768px both rules apply; cascade order means the `640px` rule (declared last) wins, overriding the intended `600px` cap. One of these blocks should be removed.

- **`viewport` forbids user zoom.** `maximum-scale=1` in the viewport meta prevents pinch-to-zoom on mobile — a WCAG 1.4.4 (Resize Text) failure.

- **Wildcard `line-height` reset is overly aggressive.**
  ```css
  * { line-height: 100% }
  ```
  This flattens `line-height` on every element. Combined with `mso-line-height-rule: exactly`, it will compress any text with descenders in Outlook. Scope this to `td, p` at minimum.

- **Duplicate `format-detection` meta tags.** `telephone=no` and `address=no` each appear twice; `date=no` appears once in the compound tag and again as a standalone tag. Redundant — no rendering impact, but indicates template hygiene issues.

- **Duplicate charset declaration.** Both `<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />` and `<meta charset="utf-8">` are present. Harmless but redundant.

- **`<title>` is generic.** Title is `Crate & Barrel` with no subject context. Some clients (Gmail on Android) surface the `<title>` as a fallback — use the email subject line instead.
