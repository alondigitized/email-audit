The creative is strong — multiple styled room shots flow naturally down the email, and the neutral editorial palette is entirely on-brand. The email's fundamental weakness is that it brings no commercial engine. There are no broken images, no lorem ipsum, and no layout failures visible anywhere in the render.

### 3. Rendering & Accessibility

**Confirmed issues:**

**a. Conflicting desktop `img` max-width rules**
Two `@media` blocks both target desktop but set different `max-width` values:
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewport ≥ 768px, both rules apply. The `600px` rule wins due to source order, but at 640–767px the cap is 640px. This creates an inconsistent image ceiling that can cause layout overflow in the 640–767px range depending on container widths.

**b. `maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user zoom on mobile. This is a WCAG 1.4.4 (Resize Text, Level AA) violation and is also rejected by some mail clients' accessibility scanners.

**c. Conflicting `-webkit-text-size-adjust` declarations**
```css
/* In desktop CSS block: */
html { -webkit-text-size-adjust: none; }
/* In general settings: */
body { -webkit-text-size-adjust: 100%; }
```
`none` on `<html>` disables iOS auto-sizing entirely; `100%` on `<body>` is the correct safe value. The `none` declaration can cause text to render at unintended sizes in iOS Mail when images are blocked.

**d. `color-scheme` set to `light` only**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is fully opted out. Apple Mail and some Android clients will force-invert colors on elements that lack explicit dark-mode overrides, which can make white text on white backgrounds invisible. Intentional opt-out is acceptable but should be documented as a deliberate choice, not an oversight.

**e. Duplicate `format-detection` meta tags**
`telephone=no` and `address=no` appear in both a combined meta and in separate metas. No functional impact, but indicates template hygiene issue.
