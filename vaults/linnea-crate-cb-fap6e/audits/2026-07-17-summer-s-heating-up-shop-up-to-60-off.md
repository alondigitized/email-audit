# Summer’s heating up! Shop up to 60% off →
**Score:** 7/10 · **Type:** Email audit · **2026-07-17**
## Executive summary

- This is Crate & Barrel's broadest summer sale send — a 60%-off headline used to funnel subscribers into an omnibus email covering everything from living room furniture to Le Creuset cookware to a $200 sweepstakes to an app download push. The hero does its job: "up to 60% off The Summer Sale" is legible and prominent, and the coastal backdrop gives it seasonal energy. But the moment you scroll, focus dissolves into four or five competing narratives that have no obvious priority.
- The sweepstakes element ("enter for a chance to win $200") lands mid-email and feels grafted on rather than integrated — it works harder as an app-install incentive ("It's all in the app. Including your chance at $200!") than as a sale booster. The Le Creuset section is a direct repeat of yesterday's Breville/Le Creuset/Zwilling email, which already hit the same audience. That's two Le Creuset placements in 24 hours with essentially the same "over 20% off select Le Creuset" message — the second appearance lands significantly weaker.
- Bottom line: this is a capable but unfocused blast. The 60% headline is the strongest thing here; everything below it dilutes rather than deepens.

## What's working

- Hero "up to 60% off" is immediately readable — large type, clean contrast, lands first before any scroll.
- Seasonal framing ("Summer Sale") is appropriate for mid-July and matches the current promotional cadence.
- Sender name "Crate & Barrel SALE" signals a transactional send, which self-selects for deal-seekers — right audience for this message.
- Le Creuset brand name pull-through gives a concrete anchor in an otherwise category-broad email.
- The app tie-in to the sweepstakes is clever co-incentive structure, even if the placement is late.

## What's weak

- Four or five independent content blocks (furniture, sweepstakes, Le Creuset, dining room, app) compete without a hierarchy — there's no one hero product or offer to anchor on.
- The $200 sweepstakes sits mid-scroll with no above-the-fold teaser, wasting its strongest engagement hook.
- Le Creuset 20% off is a near-verbatim repeat of yesterday's July 16 "Save on Breville, Le Creuset & more! Shop up to 35% off" send — subscribers who clicked yesterday have zero reason to click again today.
- "Shop Now" CTAs are generic throughout; no button copy tells you what category you're landing in.
- No explicit sale deadline anywhere visible — "Summer's heating up" is seasonal flavor, not urgency.

## Recommendations

- 1. **Lead with the sweepstakes in the subject/hero** — "Enter to win $200 + 60% off the Summer Sale" makes this email categorically different from a standard promo blast. The $200 hook is the only thing competitors can't copy.
- 2. **Kill or delay the Le Creuset block.** It aired yesterday to the same list. Replace with a single, sharp hero product (a sofa, a dining table) at the highest discount percentage you can cite — one product at 60% beats a category banner.
- 3. **Add a deadline.** Even "Sale ends Sunday" anchors the urgency that "heating up" only implies.
- 4. **Rewrite the CTA buttons** to be destination-specific: "Shop Sofas," "Shop Dining," "Shop Le Creuset" — each click becomes intentional rather than generic.
- 5. **Move the app callout above the fold or into a banner strip** — it's doing real work (sweepstakes entry requires app) but subscribers won't find it mid-scroll.

### 3. Rendering & Accessibility

**Issue 1 — Conflicting desktop image breakpoints (likely rendering bug)**

Two media queries in `<head>` set conflicting `max-width` values for `img` on desktop:

```css
@media only screen and (min-width: 640px) { img { max-width: 640px } }
@media only screen and (min-width: 768px) { img { max-width: 600px } }
```

At 640–767 px (tablet landscape / small desktop), `max-width: 640px` applies. At 768 px+, `max-width: 600px` overrides it — images become **40 px narrower as the viewport widens**. This is almost certainly unintentional and will produce layout narrowing on standard 768 px+ desktop renders in WebKit/Blink preview panes (Apple Mail, Gmail web).

**Issue 2 — `maximum-scale=1` disables pinch-to-zoom**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Prevents user zoom. Violates WCAG 1.4.4 (Resize Text, Level AA). Several major email clients (iOS Mail) respect this tag.

**Issue 3 — Global `-webkit-text-size-adjust: none`**

```css
* { -webkit-text-size-adjust: none; ... }
```

Applied to all elements. Blocks OS-level font scaling for low-vision users on mobile Safari. Use `-webkit-text-size-adjust: 100%` (present on `body` separately but overridden by the `*` rule due to specificity).

**Issue 4 — Global `p { text-align: center }`**

All `<p>` elements are center-aligned by default. Any plain-text fallback content or dynamically injected copy that isn't wrapped in a container with an explicit alignment override will render centered regardless of intended layout.
