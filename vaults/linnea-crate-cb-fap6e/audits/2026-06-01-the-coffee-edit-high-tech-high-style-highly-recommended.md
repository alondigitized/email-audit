### 3. Rendering & Accessibility

**`maximum-scale=1` blocks zoom (WCAG 1.4.4)**
`<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />`
Prevents users from scaling text. Fails WCAG 1.4.4 (Resize Text, AA). Remove `maximum-scale=1`.

**Global `text-size-adjust: none` is overly broad**
`*{-webkit-text-size-adjust:none;-ms-text-size-adjust:none;}` applied to `*` rather than `body`. Can suppress OS-level accessibility font scaling on all elements.

**Conflicting desktop `img` max-width media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewport widths ≥768px the 768-breakpoint rule (600px) overrides the 640-breakpoint rule (640px), making images *narrower* at larger viewports. This is backwards. One rule should be removed or the 600px value should be the 640px breakpoint.

**Global `line-height: 100%`**
`*{ line-height: 100% }` — applied to every element. Multi-line text and headings will clip descenders. Should be scoped to table cells only.

**Duplicate `format-detection` meta tags**
`telephone=no`, `address=no`, and `date=no` are declared once in the combined tag and then re-declared individually. Redundant but harmless; indicates template cleanup was missed.
