# LOOK AGAIN: 2x Rewards + up to 50% off is happening now!
**Score:** 7/10 · **Type:** Email audit · **2026-05-18**
## Executive summary

- This is Crate & Kids' Memorial Day sale escalation using a "LOOK AGAIN" creative hook — the hero copy appears to say something negative at first glance, forcing a double-take that lands on the real offer (50% off + 2x Rewards). The concept is defensible on paper, but it arrives as the eleventh or twelfth email in roughly 72 hours from the Crate & Barrel family, and the offer is *weaker* than yesterday's Crate & Barrel flagship send ("ON NOW! Double Rewards + up to 60% off" at 60%). A subscriber who opened that one yesterday now sees Crate & Kids offering 50% — a confusing regression, not an escalation.
- The creative gimmick does create a moment of curiosity, and the product grid below the hero is clean and well-merchandised with real children's furniture. The 5-star social proof block adds credibility. But the email is fighting cadence fatigue more than bad design — by send #11, even a clever hook struggles to earn the open.
- Judgement: competent execution of a worn concept. The "LOOK AGAIN" subject device is the most interesting thing here; the body doesn't fully pay it off.

## What's working

- **Concrete offer is front and center** — "2x Rewards + up to 50% off" is stated in both the subject and immediately in the hero section, no hunting required.
- **Social proof lands mid-scroll** — the 5-star review block is visible and specific, which is rare in promo-heavy sends.
- **Product grid is focused** — children's furniture (cribs, sofas, nursery pieces) is consistent with the Crate & Kids sub-brand; no category confusion.
- **App download module is present** — a nice retention play for loyalty members mid-sale.
- **No visible render bugs** — images load, text doesn't overlap, layout holds.

## What's weak

- **Offer is a step backwards** — yesterday's Crate & Barrel lead send was 60% off; Crate & Kids coming in at 50% today reads as a lesser deal from the same family, not a separate sale.
- **"LOOK AGAIN" hero copy creates momentary confusion before clarity** — the double-take mechanic risks readers skimming past the offer rather than re-reading it.
- **Cadence is broken** — this is deep in a 72-hour deluge; even loyal subscribers are likely fatigued by now, which undercuts any urgency.
- **No specific deadline visible** — "happening now" is soft urgency; a concrete end date (e.g., "ends Monday") would do more work.
- **Subject line is 56 characters and front-loads a gimmick** — "LOOK AGAIN:" occupies the first 11 characters before any value proposition appears.

## Recommendations

- 1. **Lead with the deadline, not the gimmick** — the single highest-leverage change is putting a concrete end date in the subject and hero. "Ends Monday" converts a soft "now!" into real urgency.
- 2. **Reconcile the offer with the family cadence** — if Crate & Barrel was at 60%, Crate & Kids should be at 60% too, or explain why kids is different (e.g., "plus free shipping on nursery orders").
- 3. **Pay off the "LOOK AGAIN" conceit in body copy** — if the subject sets up a double-take, the hero should visually complete the joke (crossed-out wrong version → real offer revealed). The current render doesn't commit.
- 4. **Add one specific product with a named price** — "The Babyletto Hudson Crib, now $X" anchors the value better than a percentage range.
- 5. **Trim the subject** — move "LOOK AGAIN:" to the preheader and let the offer lead.
- **Subject Alt A:** `50% off kids furniture ends Monday — shop the sale`
- **Subject Alt B:** `Double Rewards + up to 50% off The Memorial Day Event`
- **Preheader Alt A:** `Look again — yes, this sale is real. Free shipping on orders $X+`
- **Preheader Alt B:** `Cribs, sofas, nursery essentials — all on sale through Memorial Day`

### 3. Rendering & Accessibility

**[HIGH] Conflicting desktop image max-width rules**
Two `min-width` media queries both target desktop and set conflicting `img` max-widths:
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }  /* declared first */
@media only screen and (min-width: 640px) { img { max-width: 640px } }  /* declared second — wins cascade */
```
Because the 640px rule is declared *after* the 768px rule, it wins for all screens ≥640px. The 600px rule is effectively dead. If the layout container is 600px wide, images will be allowed to overflow by 40px on desktop clients that honor `<style>` blocks (Gmail web, Apple Mail).

**[MEDIUM] `maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user zoom on mobile. WCAG 1.4.4 failure for low-vision users. Remove `maximum-scale=1`.

**[MEDIUM] Global `line-height: 100%` on `*` selector**
```css
* { line-height: 100%; }
```
`100%` is relative to font-size, not the element's own line-height, causing collapsed or overlapping text in some Outlook and Samsung Mail versions. Standard fix is `line-height: normal` or explicit `px`/unitless values.

**[LOW] Duplicate `format-detection` meta tags**
`telephone=no` and `address=no` are declared twice — once in the combined meta and again as standalone metas. Redundant; no functional impact but indicates sloppy templating.

**[LOW] No dark mode declaration**
`color-scheme: light` with `supported-color-schemes: light` forces light mode but provides no dark-mode overrides. Apple Mail and Outlook for Mac will invert background and text colors. If dark mode is intentionally unsupported, this is fine — but it should be a deliberate choice.
