# ON NOW! Up to 50% off furniture!
**Score:** 9/10 · **Type:** Email audit · **2026-06-28**
## Executive summary

- This is Crate & Barrel's second warehouse sale send on June 28 — the same day as "It's here! Up to 50% off our 4th of July Warehouse Sale" (scored 8/10 in brand history). Where that email led with the umbrella "warehouse sale" frame, this one narrows to furniture specifically — which is a smart category angle if the list is segmented to furniture browsers. As a broadcast send, though, it's cadence saturation: two "up to 50% off" emails from the same brand on the same day.
- The render is clean and well-produced. The hero image is a beautifully staged, aspirational living room that earns the C&B premium positioning. Multiple product modules below the fold give the subscriber real browsing targets — dining, bedroom, storage — and the visual language is consistent throughout. The merchandising does its job.
- The core problem is "ON NOW!" without a visible end date. The urgency label is doing the emotional work but the email body never backs it up with a specific deadline in the hero or any product module. After a week of daily "just got bigger" / "new deals hit" warehouse sale refreshes, a subscriber who got both today's emails has now seen this pitch six-plus times with no anchor for when it closes. The signal is fading.

## What's working

- Hero image is strong: a light, aspirational living room that earns the premium price point and stops the scroll
- "Up to 50% off furniture" offer is concrete and front-loaded — visible immediately below the logo
- Narrowing to furniture specifically is a sharper hook than the broader "warehouse sale" framing in parallel sends
- Multiple product modules (living room → dining → storage) give real browsing depth below the fold
- Clean layout, consistent C&B branding, no visible render bugs

## What's weak

- Second warehouse sale email on the same day as "It's here!" — subscribers who got both have now seen the same 50% off pitch twice in hours
- "ON NOW!" with no visible deadline in the hero or body undermines itself — urgency without a countdown is just noise
- The double "!!" in the subject line ("ON NOW!" + "furniture!") reads as mild spam-signal copy
- No loyalty or rewards layer visible in the hero — C&B has a program and this send doesn't leverage it
- CTA copy appears generic at this resolution — no category-specific language ("Shop Sofas," "Shop Dining") to reduce decision friction

## Recommendations

- 1. **Put a hard deadline in the hero** — "Ends July 4, midnight" next to the 50% off headline validates "ON NOW!" and gives an actual reason to click today vs. tomorrow
- 2. **Don't broadcast two warehouse sale sends on the same day** — if this is meant as a furniture-segment email, target furniture browsers only and gate it from the general sale list
- 3. **Sharpen CTA copy to a specific category** — "Shop Sofas & Sectionals" or "Shop Dining Tables" over a generic button; this is a furniture email, act like it
- 4. **Surface any member or early-access pricing** — even a single "Members: extra 10% off in cart" line gives loyal subscribers a reason this email is for them specifically
- 5. **Drop one exclamation point** — "ON NOW! Up to 50% off furniture" (no trailing "!") reads just as urgent without the stacked punctuation

### 3. Rendering & Accessibility

**Confirmed issues:**

**3a. Duplicate and conflicting image `max-width` media queries**
```css
@media only screen and (min-width: 768px) {
  img { max-width: 600px }
}
@media only screen and (min-width: 640px) {
  img { max-width: 640px }   /* overrides the 768px rule at all widths ≥ 640px */
}
```
The `min-width: 640px` rule appears after `min-width: 768px` in the same `<style>` block. At viewport widths ≥ 768px, both rules match and `max-width: 640px` wins due to cascade order, capping images at 640px rather than the intended 600px on wide viewports. If the template container is 600px, images will be allowed to expand to 640px on desktop clients that honor these queries (e.g., Apple Mail), potentially breaking layout.

**3b. Unresolvable zoom restriction**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` prevents pinch-to-zoom on iOS/Android. This is a WCAG 1.4.4 (Resize Text) violation and is blocked by iOS Safari 10+ regardless — but the declaration signals an accessibility gap in the build process.

**3c. Redundant `format-detection` meta tags**
The combined suppression tag and three individual tags are all present:
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```
Functionally harmless but adds ~200 bytes of head bloat and indicates copy-paste template debt.

**3d. Duplicate charset declaration**
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta charset="utf-8">
```
Both are present. Redundant; the `http-equiv` form is the XHTML-compliant version and the standalone `charset` is HTML5. No rendering defect, but flagged as template sloppiness.

**3e. Global `line-height: 100%` override**
```css
* { line-height: 100%; }
```
Applied via the universal selector with `!important` implications from surrounding rules. This suppresses line-height inheritance and can compress multi-line text rendering in Gmail Web and some Android clients. Typically overridden per-element in well-structured templates, but risky as a global default.
