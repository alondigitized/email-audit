# Today Only: FREE Shipping on ALL Orders!
**Score:** 7/10 · **Type:** Email audit · **2026-09-07**
## Executive summary

- This is the real deal by Build-A-Bear's own recent standard: a genuine sitewide offer — free shipping, no minimum, with a code — stated in the hero without any decoding needed. It beats the 2026-09-05 "New Season" send (4.0) and the 2026-09-06 "Porch Goose" send (5.0) on the single biggest lever this brand keeps missing: an actual, unambiguous discount visible in the first screen, similar in spirit to the 2026-08-19 flash sale (6.0) that was this brand's best recent performer.
- Where it falls apart is everything after the hero. The email pivots straight into a Anglerfish plush push, then Hello Kitty crossover, then a four-item product grid, then two more modules — the exact "stack modules and hope something lands" pattern flagged in the 2026-09-06 audit, just now bolted onto a real offer instead of a fake one. The LABORDAY code is also a stale holdover — Labor Day was over a week before this September 7 send — which undercuts the "Today Only" urgency the moment a reader notices it.
- Net: strong open/click potential on subject and hero alone, dragged down by a mismatched promo code and a body that has nothing to do with free shipping.

## What's working

- The hero states a concrete, no-asterisk offer — free shipping sitewide — with a visible code (LABORDAY) and a bold "SHOP NOW" button.
- "TODAY ONLY" badge creates real urgency without resorting to ALL-CAPS spam tricks or stacked exclamation points.
- Clean visual hierarchy: gradient hero pulls the eye first, offer copy is large and legible, no overlapping text or broken images anywhere in the render.
- Fine print ("Not valid on giant furry friends") is visible in the hero itself rather than buried at the bottom, which reads as honest.

## What's weak

- The promo code name LABORDAY is stale for a September 7 send — Labor Day 2026 was September 7 itself at the latest, but pairing a dated code name with "Today Only" reads like recycled creative, not a fresh push.
- After the hero, the email abandons the shipping offer entirely and runs four unrelated modules (Anglerfish, Hello Kitty Pochacco, a 4-item shop grid, Mini Beans/Back in Stock) — this is the same "category dump" structure the 2026-09-05 audit dinged.
- No reinforcement of the free-shipping offer anywhere below the hero — a second CTA or banner reminding shoppers of the code would have kept the offer top of mind through the scroll.
- "Shop By Product" grid has no pricing or sale badges, so it doesn't connect back to the free-shipping hook at all — it's a generic product carousel that could appear in any email.

## Recommendations

- 1. Rename the code to something evergreen or date-neutral (e.g., "SHIPFREE" or "TODAYONLY") — LABORDAY actively signals "this creative is a week stale" the moment a subscriber notices it.
- 2. Cut the email from five modules to two or three — hero + one product tie-in + footer nav. The Anglerfish/Pochacco/grid stack dilutes the single good offer this brand has sent in weeks.
- 3. Add a small persistent footer banner ("Free shipping ends tonight — code SHIPFREE") so the offer survives the scroll instead of disappearing after the first screenshot.
- 4. Tie the product grid to the offer explicitly ("free shipping on all 4") rather than presenting it as a disconnected catalog page.
- **Subject Alt A:** `Free Shipping Ends Tonight — No Code Needed Hassle`
- **Subject Alt B:** `Today Only: Ship Your Order Free, No Minimum`
- **Preheader Alt A:** `Use code SHIPFREE at checkout — new Anglerfish plush inside`
- **Preheader Alt B:** `Sitewide, no minimum, gone at midnight`
