### 3. Rendering & Accessibility

**Critical — `Aontent` typo on X-UA-Compatible meta tag:**
```html
<meta http-equiv="X-UA-Compatible" Aontent="IE=edge" />
```
`Aontent` is not a valid attribute. This tag is silently ignored, disabling IE/legacy Outlook rendering mode targeting.

**Critical — Duplicate MSO closing tags in VML conditional:**
```html
</o:PixelsPerInch></o:PixelsPerInch>
</o:OfficeDocumentSettings></o:OfficeDocumentSettings>
```
Malformed XML inside the `<!--[if gte mso 9]>` block. Outlook's VML parser is strict; duplicate closing tags can cause the entire conditional block to be dropped, breaking Outlook layout.

**High — `.shop-now-button` scoped only to mobile media query:**
```css
@media screen and (max-width: 480px) {
  .shop-now-button { background-color: #0046c8; ... }
}
```
No desktop/fallback declaration exists. Outlook (which ignores media queries) and wide-viewport clients render this button with zero styling.

**Medium — Invalid `border` shorthand on `#table-container`:**
```css
#table-container { border: 10px; border-radius: 20px 20px 20px 20px; }
```
`border: 10px` omits required `style` and `color` values. This is invalid shorthand — most parsers discard it, producing no border.

**Low — Non-standard capitalized CSS property names:**
```css
p { Margin: 0px !important; Padding: 0px !important; }
```
`Margin` and `Padding` (capital M/P) are not valid CSS property names. Some clients normalize these; others ignore them. Use lowercase `margin`/`padding`.

**Low — Trailing space in viewport meta content:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0 " />
```
Trailing space before closing quote. Benign in most parsers but technically malformed.

**Low — Redundant duplicate declaration in `.gmailfix`:**
```css
.gmailfix { display: none; display: none !important; }
```
Second declaration makes the first dead code. Single `display: none !important` is sufficient.
