# Extra 5% Ends Tonight. Don't Miss It.
**Score:** 6/10 · **Type:** Email audit · **2026-09-14**
## Executive summary

- This is the same LDAY-EX "extra 5%" hero Casper has now run at least six times since 08/23 — same hand-circled highlighter "5%," same green code badge, same guy-lounging-on-bed photo, now on code "LDAY-EX2." "ENDS TONIGHT" is credible this time (Labor Day genuinely just passed), but the creative is so recycled that a subscriber who's seen 09/07's "FINAL HOURS: Extra 5%" and 09/08's "Final hours to shop our Labor Day Doorbuster" sends will read this as the fifth "final" email in a row — urgency fatigue is real here.
- Below the fold the email actually does real work: a clean "find the mattress that works for you" comparison ladder (The One, Cloud One, Dream, Dream Max, Snow, Snow Max) with named use-cases, bestseller badge, and consistent price-off + CTA per product. ## What's working

- Clean, legible hero with clear code (LDAY-EX2) and unambiguous CTA button ("Shop subscriber exclusive").
- The product ladder below the fold is genuinely useful — each mattress tied to a specific need (cooling, aches, tossing/turning) with its own discount and CTA.
- "Best-seller" badge and named use-cases add real product guidance, not just generic upsell.
- No render bugs — images, badges, and buttons all display cleanly.
- Bundles/Pillows/Bedding/Furniture cross-sell grid at the bottom adds coverage without clutter.

## What's weak

- Hero creative (photo, highlighter-circle "5%," green code badge) is now a near-exact repeat of at least five prior sends since 08/23.
- "ENDS TONIGHT" is the fourth "final hours / ends tonight" framing in about a week, diluting real urgency.
- Subject uses the same "Extra 5%" language as 09/07 and 09/09 sends — no differentiation in the inbox.
- Fine print ("Savings based on comp. value") sits in tiny white text on the hero photo — easy to miss, borderline vague claim.

## Recommendations

- 1. Retire the "extra 5%" hero graphic entirely for a cycle — lead with the product ladder instead, since that's the section doing real selling work and hasn't been overexposed.
- 2. If the code must repeat, change the visual treatment (different photo, different badge color/shape) so it doesn't read as a copy-paste of last week's email.
- 3. Replace "ENDS TONIGHT" with a specific time ("Ends at 11:59pm ET") — a real deadline reads more credible than a bolded phrase repeated four times this week.
- 4. Drop "Take advantage before your best benefit clocks out" — vague filler; state what's actually ending (the code, the season).
