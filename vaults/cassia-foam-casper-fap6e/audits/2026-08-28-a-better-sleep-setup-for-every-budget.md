# A better sleep setup for every budget
**Score:** 6/10 · **Type:** Email audit · **2026-08-28**
## Executive summary

- This is Casper reusing the exact "Labor Day Subscriber Exclusive / extra 5% / code L-2026" hero from 2026-08-23's "Extra 5% savings just for you.*" send, verbatim down to the hand-circled 5% and the orange "Shop sale" button — the third time in six days this brand has run some version of the Labor Day discount stack (2026-08-18, 2026-08-20, 2026-08-23). Below that recycled hero, the email pivots into a genuinely well-organized "starter kit" bundle structure — three tiers (Great Value → Premium Comfort → Luxury Cooling), each with a price anchor, two paired products, and dual CTAs. That's a smart merchandising idea for a subject like "A better sleep setup for every budget," but it's buried under a hero that has nothing to do with the subject line's "budget" framing.
- The core problem is a mismatch between subject and hero: the subject promises budget-tiered solutions, but the first thing you see is a generic 5%-off code banner, then a "Paired for better sleep" lifestyle shot, and only after two more scrolls do you hit anything resembling "every budget." A reader skimming on mobile will bounce before reaching the actual payoff of the subject line.
- Solid execution on the bundle module, undercut by hero recycling and subject/hero disconnect. Middling send — better structured than 08-21's wellness detour, but less immediately compelling than 08-20's "Save 30%" hero.

## What's working

- Clear three-tier bundle ladder (Great Value / Premium Comfort / Luxury Cooling) with visible starting prices ($919.70, $1,743.73, $4,612.73) — genuinely matches the "every budget" subject promise once you scroll to it.
- Each tier shows two paired products with individual discount badges (10%/20%, 10%/30%, 10%/30%) and two distinct CTA buttons, giving a clear next action per product.
- No render bugs — images, badges, and buttons all display cleanly with consistent navy/white/coral color system.
- Footer has useful secondary CTAs (mattress quiz, store finder, SMS signup) without clutter.

## What's weak

- Hero is a straight repeat of 08-23's "Labor Day Subscriber Exclusive... extra 5%... code L-2026" creative — a subscriber who opened that email four days ago sees no new offer here.
- Subject says "A better sleep setup for every budget" but the hero and first visual section ("Paired for better sleep") show zero pricing or budget framing — the actual budget-tier content doesn't appear until well past the fold.
- The 5% badge math is confusing stacked against 10%/20%/30% product-level discounts shown later — unclear if the extra 5% applies on top of bundle savings or is a separate, competing offer.
- Fine print ("*Savings based on comp value") sits directly under the hero CTA in small text, which reads as the kind of buried caveat the rubric flags for offer honesty.

## Recommendations

- 1. Lead with the bundle-tier content, not the recycled 5% banner — move "Great Value / Premium Comfort / Luxury Cooling" up top so the hero actually matches the subject's "every budget" promise. This is the single biggest lift available.
- 2. Retire the "Labor Day Subscriber Exclusive" hero creative — it's now run unchanged for multiple sends; give it fresh copy or fold the 5% code into the budget-tier hero instead of stacking two separate offers.
- 3. Clarify whether the 5% code stacks with per-product discounts (e.g., "20% + extra 5% = 25% off The One") — stacking math sells harder than two disconnected badges.
- 4. Swap "Shop sale" for tier-specific CTA language in the hero (e.g., "Find your setup") to reinforce the budget-matching narrative from the first screen.

- **Subject Alt B:** `3 mattress + frame bundles, from $919`
- **Preheader Alt A:** `Starter, upgrade, or luxury — see what fits.`
- **Preheader Alt B:** `Bundles from $919.70, plus an extra 5% off.`
