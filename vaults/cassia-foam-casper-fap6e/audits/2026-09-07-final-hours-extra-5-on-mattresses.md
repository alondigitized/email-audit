# FINAL HOURS: Extra 5% on mattresses.*
**Score:** 7/10 · **Type:** Email audit · **2026-09-07**
## Executive summary

- This is the same Casper Labor Day arc closing out for at least the fourth time — the "Subscriber Exclusive / extra 5% / code LDAY-EX5" hero, same green highlighter-circle, same "FINAL HOURS" starburst badge that ran nearly identically on 08/30 ("Last chance: Extra 5% ends tonight") and 09/07 earlier today ("Today only: Extra 5%"). At this point a subscriber has seen this exact hero treatment three-plus times in two weeks, and the layout below it is a long, undifferentiated scroll of near-identical mattress cards (Cloud One, The One, Dream, Snow, Dream Max, Snow Max) each with the same "ENDS TONIGHT!" badge, same blue "Shop X" button, same price-strike format.
- Execution-wise it's clean: no render bugs, clear pricing math, a legible hero. But the true final-hours urgency ("FINAL HOURS" badge, "ends tonight" on six separate products) combined with knowing this is a repeat of yesterday's and last week's identical framing undercuts credibility — this brand has cried "last chance" too many times for it to still register as scarce.
- Judgement: solid production, exhausted creative. This is fatigue territory, not a standout send.

## What's working

- Hero is unambiguous: extra 5% off, stacked with up to 30-35% off, code LDAY-EX5 visible without scrolling.
- Two clear CTAs up top (Shop Mattresses / Shop Labor Day Sale) with good color contrast (orange/navy).
- Product grid is well organized by SKU with real prices, strike-through comps, and per-product "Save X% + extra 5%" math spelled out.
- No layout breakage, broken images, or overlapping text anywhere in the render.
- Category footer nav (Mattresses/Pillows/Bedding/Accessories) and a mattress quiz CTA give a lower-funnel path for non-mattress shoppers.

## What's weak

- "FINAL HOURS" urgency is diluted by six repeated "ENDS TONIGHT!" badges — visual noise more than urgency signal.
- This is a near carbon-copy of 08/30's "Last chance: Extra 5% ends tonight" send — same code LDAY-EX5, same badge, same hero bed photography style.
- Bottom third (Bundles/Pillows/Bedding/Furniture) is generic cross-sell with no offer specificity beyond "Save 35%/20%/10%" — feels bolted on.
- Six long product cards before any secondary content makes for a very long scroll with repetitive structure (image, strike-price, badge, one CTA, repeat).

## Recommendations

- 1. Retire "FINAL HOURS" / "ends tonight" language for at least one cycle — the brand has run "final"/"last chance" framing on 08/30 and again today; repeating it within a day (09/07 already had "Today only") kills credibility. Pick one true deadline per campaign and stop re-issuing it.
- 2. Cut the product grid from six mattresses to a top 3 — Cloud One, Dream, and one Max tier — to reduce scroll fatigue and sharpen focus on the best margin/promo items.
- 3. Differentiate the hero visual from the 08/23–08/30 sends (same bed photo/badge/highlighter treatment) so subscribers don't pattern-match this as a repeat before reading it.
- 4. Add a single sitewide countdown timer instead of six repeated static "ends tonight" bubbles — one dynamic urgency element reads as more credible than six identical static badges.
- **Subject Alt A:** `Extra 5% ends at midnight — mattresses only`
- **Subject Alt B:** `Last call: stack an extra 5% on your mattress`
- **Preheader Alt A:** `Code LDAY-EX5 stacks on top of up to 30% off — gone at midnight.`
- **Preheader Alt B:** `Cloud One, Dream, and Snow are all under sale price right now.`
