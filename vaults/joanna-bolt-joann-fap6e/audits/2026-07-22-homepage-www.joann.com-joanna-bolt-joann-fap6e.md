- **The 30% off banner** is in a high-contrast red strip right below the nav — I'd catch that instantly even on a quick scroll.
- **"Ask Mike" AI button** — honestly I'd probably tap that before digging through categories. It's labeled clearly and sits next to search.
- **"Buy Again" tab in the nav** — I'm a repeat buyer, I care about reordering the same thread and batting. That tab earns a tap from me.
- **"Savings" nav tab** is explicitly labeled — not buried under "Sale" or hidden in a flyout.

## What's weak

- **Promo code MERRY30 in July** — that's either a stale campaign or an A/B test gone wrong. Either way, I'm skeptical this deal is real.
- **Cookie consent modal eating the whole screen** — it completely blocks the hero and any below-fold content. I can't see products, categories, or what's being promoted beyond the banner.
- **No promo code auto-apply** — the banner says "use code MERRY30" which means I have to remember it at checkout. I've lost the discount more than once because of exactly this.
- **No visible category navigation to fabric or quilting** — from what I can see, the nav just says "Shop." One more tap to find fabric is one more opportunity to bail.
- **Wrong site entirely** — this is Michaels, not JOANN. If a browser redirect or misload happened on a real customer's phone, they'd likely just bounce.

## Recommendations

- **Fix the cookie modal on mobile** — either make it a slim bottom bar or auto-accept non-essential cookies with opt-out available. A full-screen blocker on first load is lost revenue.
- **Swap MERRY30 for a current-season code** — in July, run a "Summer Sew" or "Back to School" promo. Holiday codes in the off-season erode trust.
- **Auto-apply promo codes at checkout** — embed the discount in a tracked link so customers don't have to remember or type the code.
- **Add a quick-link strip below the nav** for top categories (Fabric, Quilting, Yarn, Floral) so repeat shoppers can get to their aisle in one tap instead of hunting through a flyout.
