# Your Special Offer: Earn 90K Bonus Miles With The Delta SkyMiles® Gold Amex Card
**Score:** 7/10 · **Type:** Email audit · **2026-11-13**
## Executive summary

- This is a clean, single-offer acquisition email for the Delta SkyMiles Gold Amex card. The hero says "90,000 Bonus Miles". Below it, the copy asks for $5,000 in spend within 6 months and gives an offer end date of January 27, 2027. The page then runs hero → "See Your Miles Add Up" math → two benefit tiles → "Apply with Confidence" → a long fine-print block. The hierarchy is easy to follow and the number is huge. This is a new card, Gold rather than the Reserve pitched in the Aug–Nov sends, so it isn't a pure repeat.

The benefit tiles (Check Two Bags Free, $120 Rideshare Credit) are decent, but each has a different CTA, and the lead CTA is a soft "View Details". ## What's working

- The "90,000 BONUS MILES" hero is the first thing the eye lands on, with an unmistakable number.
- A single card and a single offer, with no competing promos.
- The "Earn + Current Balance = Total" table makes the value tangible.
- Concrete benefit tiles (two free bags, $120 rideshare credit) tie the card to real travel use.
- A deadline of January 27, 2027 is stated, and the fee is disclosed up front ($0 intro, then $150).

## What's weak

- The "Current Balance: 0" line looks generic or wrong for an existing SkyMiles member.
- The subject is long, about 80 characters, and will truncate on mobile, so "Gold Amex Card" is cut off.
- Primary CTAs say "View Details" and "View All Benefits" rather than something like "Apply Now". The real "Apply Online" button sits at the bottom.
- The legal block is very long and dense, which makes the "honest offer" feel buried.
- The deadline is about two months out, so urgency is weak. This is also another Amex pitch in a long run of near-identical ones.

## Recommendations

- 1. Personalize the miles calculator with the member's real balance, or drop the "Current Balance 0" row.
- 2. Put a verb-led button like "Apply Now – Earn 90K Miles" in the hero. Keep one CTA copy throughout.
- 3. Shorten the subject so the offer fits in about 45 characters.
- 4. State the spend requirement ($5,000 in 6 months) in the hero, not only in the body.
- 5. Lead the benefit tiles with the ones relevant to the recipient's travel history, and add one proof point such as a rating or member count.
- 6. Vary the creative from the Reserve sends so the cadence doesn't feel like an eighth repeat.

## 3. Rendering & Accessibility
- **Missing alt text:** `3f473969-95d8-43bc-8d81-7bdb8c2d4dd8.png` has no `alt` attribute (QA WARN). Screen readers will announce the filename or nothing. If the image is decorative, it needs `alt=""` and `role="presentation"`.
- **Mixed content:** The same image uses `http://`. Clients and proxies that enforce HTTPS may block it or show a mixed-content warning. The image host is `image.o.delta.com`, so switching to `https://` should be straightforward.
- **Invalid document structure (from the source):**
  - Content precedes the `<!DOCTYPE html>`: the `<div style="font-size:0px; line-height:1px;">` lookup block and the comments come first. This can push some clients into quirks mode.
  - There are two nested `<html>` opening tags, `<html xmlns=... lang="en" dir="ltr">` followed by a bare `<html>`.
  - A `<div>` wrapping `<style>` blocks (`<!-- BEGIN CSS BLOCK --> <div style="font-size:0px...">`) sits inside `<head>`, where `<div>` is not valid.
- **Malformed CSS selector:** `ReadMsgBody { width: 100%; }` is missing its leading `.`, so it matches nothing. It should be `.ReadMsgBody`, though this is a legacy Outlook.com rule and low impact.
- **Non-standard viewport meta:** `content="width=device-width; initial-scale=1.0; user-scalable=yes"` uses semicolons where the spec calls for commas. Most clients tolerate it.
- **Deprecated X-UA-Compatible value:** `IE=9; IE=8; IE=7; IE=EDGE` is a legacy IE compatibility declaration with no practical effect today.
- **Hover-only styling:** `a:hover { color: #A7A8AA !important; }` changes link color to a lighter grey, but this is a hover state and no contrast failure is confirmed.
- **Positive:** `lang="en"`, `dir="ltr"`, `color-scheme: light`, `<w:DontUseAdvancedTypographyReadingMail/>` and `x-apple-disable-message-reformatting` are present.
