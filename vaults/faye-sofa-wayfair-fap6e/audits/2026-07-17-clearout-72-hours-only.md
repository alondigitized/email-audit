#  ⏱️ ❗ Clearout: 72 HOURS ONLY ❗ ⏱️
**Score:** 7/10 · **Type:** Email audit · **2026-07-17**
## Executive summary

- Wayfair goes full alarm-bell mode here: double timer emoji, double exclamation, all-caps "CLEAROUT," a 72-hour clock. The subject is the loudest thing they've sent this week, which would work if the body matched the energy — but it doesn't. Inside you get the same sprawling category grid they've run in every July send, plus the Affirm 0% APR module that has now appeared in at least three consecutive emails (July 15 "PAY-OVER-TIME SALE WITH AFFIRM," July 17 "KITCHEN FAUCETS PAY-OVER-TIME," and now here again). The hero 60% OFF tile and "picked just for you" personalization section are bright spots, but they're quickly swallowed by a 10-tile category dump that diffuses whatever urgency the subject line tried to create.
- The 72-hour framing is the strongest angle this email has and the body wastes it. A true time-gated clearout email would show a visible countdown, lean hard on one or two hero categories, and cut the category grid in half. Instead, it's a standard Wayfair blast wearing a stopwatch costume.
- Judgment: competent execution of a tired template. The cadence problem — multiple near-identical sends this week — is doing more damage to this brand's inbox presence than anything inside this email.

## What's working

- **Hero 60% OFF tiles** are prominent and land above the fold; discount depth is immediately legible.
- **"Picked just for you"** personalization section with star ratings is a genuine differentiator from the generic category tiles below it.
- **72-hour urgency** is the most credible time-bounded framing Wayfair has used this week — "72 HOURS ONLY" beats the vague "going on NOW" from the July 17 kitchen faucets send.
- **No render bugs** — layout is clean, images load, hierarchy is intact.
- **Wayfair Exclusive Rewards** surfaced in the footer, giving members a hook beyond the sale.

## What's weak

- **Subject spam signals** — two ❗ and two ⏱️ plus ALL CAPS "CLEAROUT" reads like a subject line generated by a "high urgency" template, not a confident brand. Filters notice this; so do fatigued subscribers.
- **Affirm 0% APR module appears again** — this is at minimum the third consecutive Wayfair send pushing Affirm financing this week. It's become wallpaper.
- **10-category tile grid kills focus** — after the hero, the eye has nowhere to commit. 30%, 45%, 55%, 40%, 55%, 40%, 50%, 40%, 50%, 45% is a number salad, not a sale.
- **No countdown timer in body** — the subject promises a ticking clock, the body doesn't deliver one. The 72-hour hook evaporates the moment you scroll past the hero banner.
- **"Shop all sales" CTA is the weakest possible button copy** — it lands the reader on an everything page, not the clearout.

## Recommendations

- 1. **Put a live countdown timer in the hero body** — the 72-hour premise demands it. Without it, "72 HOURS ONLY" is just punctuation.
- 2. **Strip the Affirm module or make it conditional** — subscribers have seen it every day this week. Either gate it to first-time Affirm users or cut it for this send.
- 3. **Collapse 10 category tiles to 3-4 clearout heroes** — pick the deepest discounts (60% off) and feature them with real product photography, not icon tiles. The grid is a navigation menu, not a sale.
- 4. **Replace "shop all sales" with "Shop the Clearout"** — ties back to the event name and feels time-limited.
- 5. **Subject line needs one fewer layer of decoration** — pick urgency OR emoji, not both twice.
- **Subject Alt A:** `Clearout ends Sunday: up to 60% off`
- **Subject Alt B:** `72-hour clearout — 60% off starts now`
- **Preheader Alt A:** `Picked-for-you deals on furniture, kitchen, outdoor + more — sale ends Monday morning.`
- **Preheader Alt B:** `Your personalized clearout: top discounts expire in 72 hours.`

### 3. Rendering & Accessibility

**Web font — WOFF only, no WOFF2:**
```css
@font-face {
  font-family: "Sofia";
  src: url(https://secure.img.wfrcdn.com/st4/stores/common/fonts/sofia/sofia_reg.woff) format("woff");
  mso-font-alt: "Arial"
}
```
Only `.woff` is declared. WOFF2 is supported by every modern email client that supports web fonts at all and offers ~30% smaller payload. Missing `format("woff2")` source means unnecessary bandwidth on supported clients.

**Outlook fallback is correct** (`mso-font-alt: "Arial"`) — no issue there.

**Subject line emoji density:**
```
⏱️ ❗ Clearout: 72 HOURS ONLY ❗ ⏱️
```
Four emoji characters in the subject. Gmail on Android and some Outlook builds strip or misrender stacked emoji sequences. This is a deliverability/rendering risk, not a code defect, but worth noting as a client-compat flag.

**Gmail hack present (expected):**
```css
u + .Gmail .u-P--5 { padding-left: 5px !important; padding-right: 5px !important }
```
Standard workaround for Gmail's CSS scoping bug — correctly implemented.

**Outlook cycle fix present (expected):**
```css
body[data-outlook-cycle] .u-OutlookAppStackingFix { width: auto !important; padding: 4px }
```
Standard Outlook New app fix — correctly implemented.

**`word-break: break-all` on product names:**
```css
.ProductRec-name { word-break: break-all; ... }
```
`break-all` can split mid-word for non-CJK text. `overflow-wrap: break-word` or `word-break: break-word` is less aggressive and preferable for English copy.
