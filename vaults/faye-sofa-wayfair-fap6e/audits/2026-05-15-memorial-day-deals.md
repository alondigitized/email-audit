# 🔴 ⚪ 🔵 MEMORIAL DAY DEALS 🔴 ⚪ 🔵
**Score:** 7/10 · **Type:** Email audit · **2026-05-15**
## Executive summary

- This is a full-volume Memorial Day blast from Wayfair — the subject emojis (🔴⚪🔵) gesture at patriotic theming, and there's a genuine "MEMORIAL DAY EXCLUSIVE doorbuster deals" banner midway through the scroll, but the email never commits to a single offer or category. It opens with a cascade of competing discount tiles — 70% OFF, 55% OFF, 40% OFF — with no hero to anchor the eye. The result is noise.
- Compare this to the May 14 send ("Your backyard = the hottest table in town") which scored 9/10: that email had a clean hero image, a surfaced promo code (`OUTDOOR10`), and a logical category flow. This one swaps all of that for volume. The "picked just for you" personalization block midway is a bright spot — star ratings visible, product tiles feel curated — but it arrives after three rows of competing discount banners have already exhausted attention.
- The bigger problem is cadence. Based on brand history, this is at minimum the second Wayfair email landing today (alongside "OUTDOOR WALL DECOR at a great price."), and Wayfair sent three emails on May 13 alone. A subscriber who's already deleted one Wayfair email today is not going to be more receptive to a second. The subject line's ALL CAPS + six-emoji stack is the cherry on top of a send that feels like a fire hose, not a conversation.

## What's working

- **"Picked just for you" personalization block** shows star ratings and curated products — the only section that feels like it was built for a specific person.
- **70% OFF lead discount** is legible immediately and sets an aggressive deal signal at the top of the fold.
- **Memorial Day theming is consistent** — the red/white/blue patriotic banner for "doorbuster deals" and the subject emojis align.
- **No render bugs** — all product images load, text is readable, layout is intact across the visible render.
- **"Shop all sales" CTA** is a clear button with unambiguous copy, even if it lands late.

## What's weak

- **No single hero offer** — five different discount percentages compete in the first two scroll-lengths; the eye has nowhere to land.
- **Subject line ALL CAPS + emoji overload** (🔴⚪🔵 on both sides) reads as inbox spam rather than urgency; it triggers pattern-matching filters in real humans.
- **No promo code anywhere visible** — the May 14 outdoor send used `OUTDOOR10` effectively; this send just says "deals" without a mechanism.
- **Cadence problem** — this is at least email #2 from Wayfair today; a subscriber who cleared one already is tuned out before opening.
- **"Doorbuster deals" section buried mid-scroll** — the most compelling copy in the email doesn't appear until the eye is already fatigued.

## Recommendations

- 1. **Move the doorbuster section to the hero.** Lead with the "MEMORIAL DAY EXCLUSIVE doorbuster deals" visual and surface one anchor offer (e.g., "Up to 70% off furniture, today only"). Everything else cascades below.
- 2. **Add a promo code.** The May 14 send proved this works. A `MEMDAY10` or `MEMDAY15` code gives subscribers a tangible mechanism and something to share — it also makes the send feel exclusive rather than generic.
- 3. **Kill three of the five discount banners.** Pick the one biggest offer and repeat it; competing percentage tiers feel like a liquidation flyer, not a curated deal.
- 4. **Fix the subject line.** Drop the emoji flanking, drop the ALL CAPS, get specific.
- **Subject Alt A:** `Memorial Day: up to 70% off — today only`
- **Subject Alt B:** `Your Memorial Day doorbuster deals are here`
- **Preheader Alt A:** `Furniture, rugs, outdoor — the biggest discounts of the season end Monday.`
- **Preheader Alt B:** `Use code MEMDAY10 — $10 off your first $100+. Ends Monday night.`
- 5. **Suppress to subscribers who already received the OUTDOOR WALL DECOR email today.** Sending twice in one day to the same list actively trains subscribers to ignore you.

### 3. Rendering & Accessibility

**Web font — missing `woff2` format:**
```css
@font-face {
  font-family: "Sofia";
  src: url(...sofia_reg.woff) format("woff");  /* woff2 absent */
  mso-font-alt: "Arial"
}
```
Only `woff` is declared. `woff2` (supported by Gmail/Apple Mail/modern clients) offers ~30% better compression. Without it, clients that support `woff2` still fall back to system fonts unnecessarily. Add `woff2` as the first format source.

**Aggressive word-break on product names (mobile):**
```css
.ProductRec-name { word-break: break-all; overflow: hidden; height: 48px !important }
```
`word-break: break-all` splits at any character boundary, including mid-word. Use `overflow-wrap: break-word` instead.

**Fixed heights on mobile product cells — text clipping risk:**
```css
.ProductRec-name      { height: 48px }
.ProductRec-price     { height: 40px }
.ProductRec-salesCopy { height: 28px }
```
Any product name, price, or promotional copy that exceeds these fixed dimensions will be silently clipped with no visual indicator. Replace with `min-height`.

**Subject line emoji — rendering risk:**
`🔴 ⚪ 🔵 MEMORIAL DAY DEALS 🔴 ⚪ 🔵` — 6 emoji codepoints. These render as replacement characters (□) in some enterprise environments (Exchange on older Windows, Lotus Notes) and some Android email clients. Preheader/snippet text impact should also be verified.
