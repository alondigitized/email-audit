### 3. Rendering & Accessibility

**Single breakpoint gap**
Two breakpoints are defined: `max-width: 480px` (primary) and `max-width: 320px` (footer links only). No intermediate breakpoint exists for tablets (481–768px), so layout falls through to desktop table widths on mid-size screens. This is a common trade-off in ESP-generated email but worth logging.

**`word-break: break-all` on `.ProductRec-name`**
```css
@media only screen and (max-width: 480px) {
  .ProductRec-name { word-break: break-all; ... }
}
```
`break-all` breaks at any character boundary, including mid-word. `overflow-wrap: break-word` or `word-break: break-word` would be less aggressive and preserve readability for long product names.
