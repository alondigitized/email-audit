### 3. Rendering & Accessibility

**Bug — Viewport meta missing hyphen (breaks mobile rendering):**
```html
<meta name="viewport" content="width=device-width, initial scale=1.0" />
```
`initial scale` should be `initial-scale`. The missing hyphen causes this directive to be silently ignored by all mobile clients, disabling responsive scaling on iOS Mail, Gmail mobile, and Samsung Mail.

**Bug — Invalid CSS `vertical-align` on `sup`/`sub`:**
```css
sup { vertical-align: text-top .6em; }
sub { vertical-align: text-bottom .9em; }
```
`text-top .6em` is not valid CSS syntax for `vertical-align` (it takes a single keyword or length, not both). Browsers silently drop the rule; superscript/subscript will render at the browser default, not the intended offset.

**Minor — Empty `<title>` tag:**
```html
<title></title>
```
Some accessibility tools and screen readers surface the document title. An empty title is benign but is a gap in the template.

**Minor — Duplicate `format-detection` meta tags:**
```html
<meta name="format-detection" content="telephone=no" />
<meta name="format-detection" content="address=no" />
```
These should be combined into one tag (`content="telephone=no, address=no"`). Redundant tags are harmless but indicate template sloppiness.
