# This Summer, Say Yes to Ultimate Sophistication at The St. Regis Toronto
**Score:** 9/10 · **Type:** Email audit · **2026-07-24**
## Executive summary

- This is a pure editorial brand send from the St. Regis sub-brand — a destination spotlight on the Toronto property covering dining, spa, and cocktail programming. No rate, no points offer, no discount. That's a deliberate creative choice, but it's also the email's single biggest weakness: after five consecutive Marriott credit card pushes in seven weeks (most recently the "Offer Ends Soon: 125K Points" countdown send on July 23), dropping a zero-offer brand magazine piece risks feeling tone-deaf to a subscriber who's clearly in loyalty-program, deal-consideration mode.
- The production quality is high. The hotel imagery is aspirational, the copy is on-brand for a St. Regis audience, the layout is clean three-section editorial with each section linking to its own detail CTA. This is a well-made email. The problem is it's the wrong email at the wrong moment in the cadence.
- The St. Regis branding and "This Summer" framing do the minimum to feel timely, but without a rate or package offer, this email has no conversion hook — just awareness for a destination most of Marriott's loyalty base won't visit this season.

## What's working

- **Property-specific editorial depth** — three distinct content sections (dining, spa, bar) give the email genuine informational density rather than one thin hero push.
- **Clean visual hierarchy** — the dining room hero lands first and clearly; the eye has a natural path through the sections.
- **Luxury production standard** — imagery and layout match St. Regis's brand positioning; no cheap-feeling clip art or generic hotel stock.
- **Marriott Bonvoy footer** — the loyalty branding at the bottom ties this back to the subscriber's existing program membership.
- **No render bugs** — images render, text is legible, layout holds.

## What's weak

- **Zero offer or rate** — "Discover Your Story" is not a hook for a Bonvoy member who's been receiving 125K-point credit card offers all summer; there's nothing to act on.
- **Subject line too long and too vague** — 72 characters, over the 50-char mobile threshold, and "Say Yes to Ultimate Sophistication" is brand-speak that carries no information.
- **No personalization** — the last six Marriott-family emails have said "Brooke" in the subject; this one doesn't, and the regression is immediately noticeable.
- **"Discover" CTA copy** — "DISCOVER YOUR STORY" is the soft, non-directive CTA the rubric explicitly flags; no verb-noun specificity.
- **Cadence collision** — arriving the same day as the July 23 "125K Points – Offer Ends Soon" Bonvoy push from the main brand, this email is the second Marriott-family send in one day, for a property and city most subscribers have no imminent travel plans for.

- 2. **Rewrite the subject with a name and specificity:**
- **Subject Alt A:** `Brooke, Toronto's Most Storied Hotel Has a Table for You`

### 3. Rendering & Accessibility

**`viewport` meta malformed** — missing hyphen in `initial-scale`:
```html
<meta name="viewport" content="width=device-width, initial scale=1.0" />
```
`initial scale` is not a recognized property; the directive is silently dropped. Mobile clients that parse this strictly will render at default zoom. Fix: `initial-scale=1.0`.

**`robots` meta has invalid value** — space inside directive:
```html
<meta name="robots" content="no index" />
```
`no index` (with space) is not a recognized token; `noindex` (no space) is. Low risk for email, but if any client or proxy crawls the rendered page, it will not be suppressed.

**Empty `<title>` tag:**
```html
<title></title>
```
Some screen readers and accessibility tools surface the document title. Should carry a descriptive value matching the email subject.

**Invalid CSS — `vertical-align` with two values:**
```css
sup {
  vertical-align: text-top .6em;  /* invalid */
}
```
`vertical-align` is a single-value property; `text-top .6em` will be rejected by CSS parsers. The `sup` offset will not render as intended. Fix: use `vertical-align: super` or `vertical-align: top` with a separate `position: relative; top: -0.4em`.

**`-webkit-text-size-adjust: none` (accessibility concern):**
```css
body { -webkit-text-size-adjust: none; }
```
`none` disables font scaling entirely on some iOS clients, including user-initiated zoom. WCAG 1.4.4 requires text to be resizable to 200% without loss of content. Use `100%` instead.

**Legacy font formats loaded unnecessarily:**
Each `@font-face` block loads `.eot` (IE 6–8) and `.svg` (deprecated Safari) formats alongside modern `.woff2`/`.woff`. No email client in active use supports these formats; they fire HTTP requests for no benefit. Remove `.eot` and `.svg` entries to reduce DNS/TCP overhead on open.
