# Technical Audit: "Top draft pick: NFL Nod Chairs!" (Crate & Barrel Kids)

The HTML source was truncated, so I only reviewed the head and the QA output. The footer, body links, and unsubscribe block were not available to inspect.

## 1. Technical Summary
The email's structure looks sound (`lang="en"`, XHTML doctype, MSO/VML fallbacks). The main confirmed problems are 28 images flagged for missing alt text and a viewport/text-size configuration that blocks user zoom. The header-based compliance and authentication checks could not be evaluated.

## 2. Link & Tracking Issues
- The QA run skipped 69 tracking links (`69 tracking link(s) skipped`) because they are click-redirect domains. Destination validity, redirect chains, and 404s are **unverified**, not confirmed good.
- The third-party pixels are `sr.rlcdn.com/448796.gif?...&n=1` to `n=5` (five LiveRamp calls), `mi.crateandbarrel.com/p/up/.../o.gif` (open pixel), and `dv.crateandbarrel.com/o/775e4367-...`. These are intentional tracking, but five repeated LiveRamp pixels add third-party requests and a privacy-disclosure surface.
- `mi.crateandbarrel.com/p/rp/f3c0d22992a01946.png?mi_u=...` appears 6 times with an identical URL. This looks like a per-module repeated pixel or beacon. It is redundant but not broken.

## 3. Rendering & Accessibility
- **Missing alt text on 28 images.** The 28 break down as:
  - Content images on `image.mail.crateandbarrel.com/lib/fe9013727564027a7c/m/1/` (for example `ec997ddd-...jpg`, `4f4a73dd-...jpg`, `bafa6654-...gif`, `d24f24c6-...gif`).
  - `bbf6f9d4-...png` under `/m/47/`.
  - One Scene7 asset: `s7d5.scene7.com/.../2026%5F1104%5FCBK%5FQualityGifting%5FSecondaryStor...`.
  - The `rlcdn`, `mi.`, and `dv.` tracking pixels.
  - If the content images have no alt, they are inaccessible to screen readers and render as blank space with images blocked. The tracking pixels should carry `alt=""` explicitly. The QA check flags a missing attribute, and I can't tell from the truncated source whether `alt=""` is present on them.
- **Viewport blocks zoom.** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />` disables pinch-zoom in supporting clients, which is a WCAG 1.4.4 concern.
- **Text resizing disabled.** `-webkit-text-size-adjust:none` appears in the global `*` rule and in `body`, in addition to `100%` elsewhere. This overrides user text-size preferences in WebKit clients.
- **CSS cascade bug.** The `@media (min-width: 768px) { img {max-width: 600px} }` rule comes before `@media (min-width: 640px) { img {max-width: 640px} }`. At ≥768px both match, and the later 640px rule wins, so the 600px cap never applies.
- **Template leftovers:**
  - The comment `<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->` is still in the source.
  - There is a duplicate `<meta charset>` alongside the `http-equiv` Content-Type.
  - There are three redundant `format-detection` meta tags.
  - The `<title>Crate & Barrel</title>` has an unescaped `&`, which is invalid in XHTML, and the title is generic rather than matching the subject.

## 4. Personalization & Merge Tokens
No issues found. No unrendered merge tokens (`%%...%%`, `{{...}}`) were visible in the available source. Tokens in the truncated body can't be ruled out.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)

The QA output itself says these may be stripped by the AgentMail relay. **These are unconfirmed, not demonstrated defects.** SPF, DKIM, DMARC, and one-click unsubscribe status are unknown.
- The footer with the physical address and unsubscribe link was in the truncated portion, so I could not check it.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Not assessable. The visible source has no `href` values, and all 69 tracking links were redirect domains that were not resolved. UTM parameters and landing page alignment are unverified.

## 7. Recommendations
1. Add descriptive `alt` text to the 14 content and creative images (the `image.mail.crateandbarrel.com` and Scene7 assets). Add `alt=""` to the tracking pixels (`rlcdn`, `mi.`, `dv.`).
2. Remove `maximum-scale=1` from the viewport meta, and replace `-webkit-text-size-adjust:none` with `100%`.
3. Reorder the `min-width` media queries (640px before 768px), or use a single query, so the intended 600px image cap applies.
4. Clean up the template: remove the `IMPUT HERE` placeholder comment, deduplicate the meta tags, and escape the `&` in `<title>` (`&amp;`).
5. Re-run the audit with the full headers (`List-Unsubscribe`, `List-Unsubscribe-Post`, `Authentication-Results`) and the untruncated HTML. Resolve the 69 redirect links to check destinations and UTMs.
6. Consider consolidating the five `rlcdn` pixels and six identical `mi.` pixel calls if they aren't each needed.
