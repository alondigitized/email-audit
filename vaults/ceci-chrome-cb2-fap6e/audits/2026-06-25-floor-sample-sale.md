# FLOOR SAMPLE SALE
**Score:** 5/10 · **Type:** Email audit · **2026-06-25**
## Executive summary

- This is a three-offer stack email — Floor Sample Sale up top, July 4th Sale in the middle, Warehouse Sale below — and the congestion is the story. CB2 is trying to squeeze three distinct promotions into a single send and each one undercuts the others. The Floor Sample Sale hero (the intended lead, given the subject line) is quiet and editorial: a cream sofa lifestyle shot with small serif text. Then the email shifts into a punchy red "JULY 4TH SALE UP TO 50% OFF" banner that immediately steals visual focus, and then a third warehouse sale block below that. The subscriber is left with no clear signal about what CB2 actually wants them to do.
- The floor sample concept is genuinely differentiated — it implies one-of-a-kind, store-specific pieces that won't be available next week — but the email does almost nothing to sell that scarcity. The "IN-STORE ONLY / FIND A STORE" mechanic is buried in small type, and there's no indication of categories, locations, or how long the event runs. Meanwhile the July 4th and Warehouse Sale blocks carry more visual weight and more specific percentages, making the hero feel like an afterthought in its own email.
- The "MORE FOR YOU" product grid at the bottom is the most shoppable section — six product tiles with names and prices — but it lands beneath two major promotional blocks and competes with a CB2 app promo, a loyalty block, a celebration gifting block, and a Crate & Barrel / Crateandkid cross-sell footer. This is a structurally overstuffed send.

## What's working

- **Floor sample hero image is clean and aspirational** — the cream sofa in a warm neutral room looks premium and editorial, consistent with CB2's best work.
- **"FIND A STORE" CTA is correctly labeled** — the in-store-only mechanic is at least surfaced, even if it's small.
- **Product grid with prices is useful** — the six "MORE FOR YOU" tiles show product names and dollar amounts, giving a concrete reason to click.
- **July 4th urgency block reads fast** — the red background + "UP TO 50% OFF" communicates the offer in under a second.
- **Brand family cross-sell is coherent** — Crate & Barrel and Crateandkid logos in the footer are tidy; CB2 handles the sibling-brand ecosystem better than most.

## What's weak

- **Three competing promotions with no hierarchy** — Floor Sample Sale, July 4th Sale, and Warehouse Sale all fight for attention; none wins.
- **Floor sample scarcity is invisible** — no locations mentioned, no categories, no end date; "in-store only" is meaningless without context.
- **July 4th banner is visually louder than the hero** — the red block with bold white type outranks the actual subject-line offer above it.
- **Footer is brutally long** — app download, earn rewards, gifting prompt, loyalty, legal, and two sibling brands stack below the fold with no breathing room.
- **"MORE FOR YOU" personalization feels generic** — a bookcase, a console stool, a wood wall shelf, and a dining table don't form a coherent recommendation story.

## Recommendations

- 1. **Dedicate this email to the Floor Sample Sale only.** Drop the July 4th and Warehouse Sale blocks entirely — those already have their own sends. Scarcity works when it's the only thing on the screen.
- 2. **Add scarcity specifics to the hero copy** — how many stores, which categories (furniture? lighting? rugs?), and a hard end date. "In-store only, while supplies last" is doing zero work.
- 3. **Make the "FIND A STORE" CTA bigger and primary** — it should be a full-width button, not a small text link. In-store traffic is the actual conversion goal.
- 4. **If July 4th must stay, push it below the fold as a secondary banner** — visually subordinate it so the hero story lands first.
- 5. **Trim the footer by 60%** — collapse app/loyalty/gifting into one compact block; the double Crate family cross-sell can move to a dedicated email.

- **Subject Alt B:** `One-of-a-kind floor samples, while they last`
- **Preheader Alt A:** `Up to X% off display pieces at your local CB2 — find yours.`
- **Preheader Alt B:** `These pieces exist in exactly one store. Come get them.`

### 3. Rendering & Accessibility

**HIGH — `maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. Fails WCAG 1.4.4 (Resize Text). This value should be removed.

**MEDIUM — Global `-webkit-text-size-adjust:none` on `*` selector**
```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none; ...}
```
Overrides text scaling across all elements, not just layout containers. This is more aggressive than the `body`-scoped version declared earlier and can harm readability on small screens.

**MEDIUM — `line-height: 100%` on `*` selector**
```css
*{ ... line-height: 100%}
```
Applied globally on `*` this can clip descenders and cause text overlap in table cells, particularly in Outlook and older Samsung clients. Should be scoped to layout-only elements.

**LOW — Mobile breakpoint/class width mismatch**
```css
@media only screen and (max-width: 418px) {
  .mobile { width:414px !important; ... }
}
```
Breakpoint fires at ≤418px but sets content width to 414px, leaving a 4px gap. On exactly 415–418px viewports the layout will have unintended right padding.

**LOW — `font-display: swap` in `@font-face` declarations**
```css
font-display: swap;
```
`font-display` is a browser CSS property with no support in any email client. It is silently ignored — not harmful, but dead code that signals a web-stylesheet was copy-pasted directly.

**LOW — Double slashes in font asset URLs**
```css
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
```
Three `@font-face` declarations use `//` path separators (`https://www.cb2.com//Styles/...`). Most CDN configurations normalize these, but it is a malformed URL and should be corrected.

**Noted — Cross-domain font loading**

`@font-face` declarations pull assets from two separate origins:
- `https://www.cb2.com/Styles/CB2/fonts/...`
- `https://www.crateandbarrel.com/webfonts/...`
