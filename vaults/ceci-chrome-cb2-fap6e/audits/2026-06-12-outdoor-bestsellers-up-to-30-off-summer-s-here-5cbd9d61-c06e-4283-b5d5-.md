## What's weak

- No visible deadline or urgency mechanism — "Summer's here!" is seasonal flavor, not a call to act now
- "Up to 30% off" leads with the ceiling, not the floor; most items are probably 20–25% off, which buyers know
- Heavy cadence context undercuts this send — sixth-plus email in 48 hours from the brand family means inbox fatigue is real
- No social proof visible (star ratings, "bestseller," units sold) on any product card — high-ticket outdoor furniture is a considered purchase that benefits from it

### 3. Rendering & Accessibility

**`maximum-scale=1` blocks pinch-zoom (WCAG 1.4.4 violation)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users from zooming on mobile. Remove `maximum-scale=1`.

**Global `-webkit-text-size-adjust: none` overrides browser accessibility settings**
```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none; ...}
```
Applied to the `*` selector, this disables OS-level font scaling for visually impaired users. Scope to `body` only, and use `100%` not `none`.

**Conflicting image `max-width` media queries**
```css
@media only screen and (min-width: 768px) { img {max-width: 600px} }
@media only screen and (min-width: 640px) { img {max-width: 640px} }
```
The 640px rule fires first; the 768px rule then contradicts it. At viewports ≥768px, images are capped at 600px despite the 640px rule also matching. Reorder so the wider breakpoint comes last, or consolidate into one rule.

**Duplicate `charset` declarations**
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta charset="utf-8">
```
Redundant; harmless but indicates template drift. Keep only the `http-equiv` form for broadest email client support.

**Duplicate `format-detection` meta tags**
The combined tag (`telephone=no,address=no,email=no,date=no,url=no`) and three individual tags (`date=no`, `address=no`, `telephone=no`) repeat the same directives four times. Remove the individual duplicates.
