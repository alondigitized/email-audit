# The best entryways from our saves
**Score:** 6/10 · **Type:** Email audit · **2026-06-22**
## Executive summary

- This is CB2's entryway-focused editorial send — a "saves" curation concept that borrows the social-media bookmark idea to frame a collection of console tables, mirrors, and marble accent pieces. The creative is clean and warm: the hero image is an aspirational hallway vignette with organic forms, cream textiles, and sculptural lighting, fully consistent with the brand language CB2 has been re-establishing since the June 19 Todd Snyder drop. After five or six consecutive Warehouse Sale hammer blows, this palate-cleanser will feel welcome to fatigued subscribers.
- The problem is the same one that plagued the June 21 Midcentury Era send: pure editorial with zero commercial hook. No discount, no member price, no time boundary, no specific product linked in the hero. "From our saves" is a genuinely interesting curation concept — someone chose these items; there is implied social proof — but the email never unpacks it. Whose saves? Why these pieces? The three editorial sections (SCULPTURE IN MARBLE, A STYLE OF ORIGINALITY, THERE'S MORE) read like a mood board, not a reason to click.
- Judgment: a visually appealing editorial email that doesn't close the loop. Strong enough to open, weak on click motivation. A curated "saves" story should surface the specific editors or at minimum put a price on at least one hero item.

## What's working

- Hero image is strong — warm entryway vignette with natural materials reads as aspirational without feeling generic.
- "From our saves" is a differentiating concept; it implies taste-editing by real humans, which is a scarce signal.
- No warehouse sale banner cluttering the top — a genuine break from the last week of sends.
- Three-section editorial structure (Marble, Originality, More) gives the eye a clean path to follow.
- Render is clean: no broken images, overlapping text, or layout breakage visible.

## What's weak

- No offer anywhere in the email — no price, no discount, no member exclusive. This is decoration without a destination.
- "From our saves" is never explained or attributed — whose saves? An editorial team? A designer? The concept evaporates before it lands.
- CTAs throughout appear as small, low-contrast text links — nothing resembling a clear button with specific copy.
- Three thematic sections (Marble, Originality, More) compete for attention without a hierarchy; unclear which is the primary CTA moment.
- Hero headline text is small and overlapping the lifestyle photography, reducing legibility.

## Recommendations

- 1. **Add at least one price anchor.** Even one "from $199" or "Member price: $349" in the hero transforms this from editorial to shoppable. Pure editorial works for New Arrivals, not for a "saves" concept implying someone picked the best.
- 2. **Attribute the saves.** "Saved by the CB2 Design Team" or "Our editors saved these first" — a single line of copy that earns the concept. The June 21 Midcentury send had the same gap; fix it here.
- 3. **Upgrade the primary CTA to a visible button.** Pick one section as the hero CTA moment and give it a button with specific copy: "Shop Console Tables" over a generic text link.

### 3. Rendering & Accessibility

**[HIGH] Unfilled template placeholder in `<head>`:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
This is a raw production artifact — a misspelled (`IMPUT` → `INPUT`) build-time comment that was never removed. It has no rendering impact but signals the template was not fully cleaned before send.

**[MEDIUM] Double-slash URLs on three `@font-face` declarations:**
```
https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2
https://www.cb2.com//Styles/CB2/fonts/BrownRegular/lineto-brown-regular.woff2
https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2
```
Most servers return a 301 redirect and resolve correctly, but some strict HTTP clients will reject the malformed path. Falls back to system sans-serif silently.

**[MEDIUM] Cross-domain font loading — `crateandbarrel.com`:**
```css
@font-face { font-family:"HNW05"; src: url("https://www.crateandbarrel.com/webfonts/...") }
```
Four HNW05 variants load from the parent brand's domain, not `cb2.com`. If `crateandbarrel.com` does not send `Access-Control-Allow-Origin` headers for cb2 email clients that enforce CORS (rare but present in some webmail renderers), these fonts will silently fail. Hosting all font assets under `cb2.com` eliminates the cross-origin dependency.

**[LOW] `maximum-scale=1` blocks user zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Violates WCAG 2.1 SC 1.4.4 (Resize Text). Users with low vision who rely on pinch-zoom cannot scale the content. Common in email but flagged for accessibility completeness.

**[LOW] `-webkit-text-size-adjust:none` applied globally:**
```css
* { -webkit-text-size-adjust: none; }
```
Suppresses OS-level font scaling on iOS/Android, compounding the zoom restriction above for users with accessibility needs.

**[LOW] Vestigial empty conditional comment block:**
```html
<!--[if !mso]><!-->  <!--<![endif]-->
```
No content between the conditional tags — leftover from template scaffolding. Harmless but noise.

**[LOW] Duplicate `@font-face` for "Lineto Brown Sub":**
The font is declared three times: once with `.eot`/`.woff` (no weight specified), once as `weight:400`, once as `weight:600`. The unweighted declaration has no `font-weight` descriptor, which means it may shadow one of the weighted declarations depending on cascade order in certain renderers.

**[INFO] Mobile breakpoint at 418px:**
```css
@media only screen and (max-width: 418px) { .mobile { width:414px !important } }
```
Intentional pairing (418 trigger → 414 layout width for iPhone SE). Does not fire for Android devices with CSS viewport widths between 419–599px, which will fall through to the desktop table layout. Standard email practice uses 480–600px as the responsive trigger.
