## Executive summary

- This is CB2's new-collection launch email — positioned editorially with the hero headline "NEW TO COVET" over a moody, well-styled living room vignette. The photography is on-brand and the art direction holds up, continuing the editorial tone CB2 has been cultivating since the July 10 Todd Snyder drop and the July 12 gallerist profile. - The fundamental problem is the subject line. "NEW COLLECTION" is four words and fourteen characters of nothing — no category, no name, no hook. CB2 proved with "JUST DROPPED: CB2 x Todd Snyder" (July 10) that they know how to write a launch subject; they chose not to here. ## What's working

- Hero photography is strong — dark sofa, layered rug, lamp vignette reads immediately as "aspirational living room" and matches CB2's editorial register.
- "Best Sellers You Haven't Seen at CB2" midway down is smart positioning — it gives permission to browse and frames social proof without requiring reviews.
- Multi-vignette layout breaks up the scroll — each module covers a different furniture category (seating, lighting, accent), giving the email breadth without feeling scattered.
- Brand logo and design language are immediately recognizable — no identity confusion.
- No visible render bugs — images load, layout is clean, no overlapping elements.

## What's weak

- Subject line "NEW COLLECTION" is the weakest CB2 has written in this audit window — far below "JUST DROPPED: CB2 x Todd Snyder" and even below the blunt "GET IT ON SALE." Nothing anchors the open.
- No price, no offer, no discount anywhere visible — after three 40%-off emails this week, switching to zero-offer cold-turkey with a generic subject is a hard pivot with no bridge.
- The collection has no name in the hero — "New to Covet" reads as a section label, not a campaign identity, so there's nothing memorable to carry into a second open.
- No urgency signal of any kind — no "just dropped," no limited qty, no deadline — which means the subscriber can defer indefinitely.
- Seven CB2 emails in five days; this one arrives without enough differentiation to justify the cadence slot.

## Recommendations

- 1. **Name the collection or anchor one hero product in the subject.** "JUST DROPPED: The New Fall Edit" or "New: The Covet Collection — Shop Before It Sells" — anything that gives a subscriber a reason to open *now* over *later*.
- 2. **Add a price anchor, even a small one.** Even "starting at $X" or "pieces from $299" gives a reason to click. A launch email with zero price signal feels like a lookbook, not a shop.
- 3. **Add a single urgency line.** "New arrivals sell fast" or "limited quantities" in the hero sub-copy costs nothing and closes the defer loop.
- 4. **Thin the cadence or earn each slot.** A 7th email in 5 days needs to be obviously different in value — a named collab, a real deadline, a member-only price. This one doesn't clear that bar.

### 3. Rendering & Accessibility

**Critical — Global `text-size-adjust: none`:**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
Applied to every element via the `*` selector. This suppresses OS-level font scaling for visually impaired users and violates WCAG 1.4.4 (Resize Text). The correct value is `100%`, not `none`.

**Mobile breakpoint mismatch:**
The single responsive breakpoint fires at `max-width: 418px` targeting a `.mobile` class set to `width: 414px`. This misses common viewport widths between 419px–767px — the email will render as desktop layout on mid-size phones (e.g., iPhone Plus/Pro Max in landscape).

**Font-face collision — three declarations for the same family:**
```css
@font-face { font-family: "Lineto Brown Sub"; src: url("...eot"); ... }
@font-face { font-family: "Lineto Brown Sub"; src: url("...woff2"); font-weight: 400; }
@font-face { font-family: "Lineto Brown Sub"; src: url("...woff2"); font-weight: 600; }
```
The first declaration omits `font-weight`, creating an ambiguous cascade. In practice, the latter two override it correctly, but the first block is dead weight that adds parse cost.

**"Lineto Brown Light Sub" missing woff2:**
```css
@font-face { font-family: "Lineto Brown Light Sub"; src: url("...lineto-brown-light.woff"); }
```
Only `.woff` is declared — no `woff2` format. All modern clients will download the larger `.woff` file unnecessarily.

**Cross-brand font dependency (HNW05 from crateandbarrel.com):**
Four `@font-face` blocks load `HNW05` from `https://www.crateandbarrel.com/webfonts/...`. A DNS or CDN issue on the sibling brand's domain directly degrades CB2 email rendering. These should be mirrored to CB2's own CDN or served from a shared static asset host.

**`max-height: 1000000px` on all elements:**
```css
* { max-height: 1000000px; }
```
This is a known Gmail clipping workaround but is applied globally via `*`. It can interfere with layout in clients that respect it literally. Scope it to `body` or the wrapper table only.
