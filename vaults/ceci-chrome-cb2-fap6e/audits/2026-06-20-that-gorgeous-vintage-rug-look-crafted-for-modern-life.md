### 3. Rendering & Accessibility

**Issue — Zoom disabled on mobile (WCAG 1.4.4 violation):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` blocks pinch-to-zoom on iOS. Drop the attribute or set `maximum-scale=5`.

**Issue — Text scaling suppressed globally:**
```css
html { -webkit-text-size-adjust: none; }
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
`none` (not `100%`) is applied twice — once on `html`, once via the universal selector. This prevents system-level font scaling for low-vision users. Change both to `100%`.

**Issue — Conflicting image max-width media queries (768px rule is dead):**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }  /* declared first */
@media only screen and (min-width: 640px) { img { max-width: 640px } }  /* declared second */
```
On screens ≥768px, both rules match; cascade order means the 640px rule wins, making the 768px constraint (600px) unreachable. Likely unintentional — reorder or consolidate.

**Issue — Overly broad `line-height: 100%` on universal selector:**
```css
* { line-height: 100%; }
```
Applied globally, this collapses line-height for all text to a single em, which clips descenders and compresses multi-line text. Should be scoped to specific elements.

**Minor — Duplicate `format-detection` meta tags:**
`telephone=no` and `address=no` are declared once in the combined tag and again as separate tags. Harmless but noisy.
