# New! Our softest sheets ever are here →
**Score:** 8/10 · **Type:** Email audit · **2026-06-10**
## Executive summary

- Crate & Barrel goes full superlative mode with "softest sheets ever" — a clean product-launch email anchored by a bold claim. The hero earns it: white and neutral bedding photography is prominent, the messaging is immediately on-category, and the layout is clean from top to bottom. The editorial format is comfortable territory for this brand, and the execution is technically clean.
- Where it falls short is persuasion. "Softest sheets ever" is asserted, never proven — there's no material name, thread count, or star-rating anchor in the hero to substantiate the claim. And on a day when Crate & Kids already dropped a sheets buyer's guide ("Not sure which sheets? Let us help.", 2026-06-10, 7/10), the combined bedding frequency in a single inbox session erodes novelty. What should feel like a launch event reads more like the second half of a bedding double-header.
- This is a competent, on-brand send. But the brand's ceiling — demonstrated by the coffee table guide (2026-06-09, 8/10) — requires pairing editorial mode with genuine substance. This email doesn't go that far.

## What's working

- Hero is immediately on-topic: sheets photography dominates the fold with the "softest ever" message leading.
- No render bugs — layout is clean, images load, visual hierarchy is unambiguous.
- Product range is well represented across multiple collections without feeling like a raw catalog dump.
- "New!" up front signals a genuine launch, not recycled promo copy.
- Brand voice is consistent — understated, editorial, recognizably Crate & Barrel throughout.

## What's weak

- "Softest sheets ever" is a headline superlative with zero visible proof in the hero — no material, thread count, or review badge to back it.
- No offer or price incentive — in an active bedding category, there's nothing compelling action today over next week.
- Same-day proximity to the Crate & Kids sheets guide blurs which brand to shop for bedding and dilutes the launch novelty.
- Long multi-collection format undercuts the single-hero "softest" story — it drifts into catalog mode partway down.

## Recommendations

- 1. **Put one proof point in the hero.** "Our softest sheets ever" hits differently with "100% TENCEL™" or "4.8 stars, 1,800+ reviews" underneath it. Without it, it's just a marketing claim.
- 2. **Add an introductory launch offer.** A launch-week free-shipping threshold or a "first to shop" member price gives subscribers a concrete reason to click now.
- 3. **Narrow to a single hero collection.** The coffee table guide (2026-06-09) worked because it focused. Pick one sheet set as the hero and lead the story from there.
- 4. **Stagger the Crate & Kids and Crate & Barrel sheets sends.** A buyer's guide and a launch email on the same day compete with each other for the same subscriber mindshare.
- **Subject Alt A:** `"Our new TENCEL™ sheets — the softest we've ever made"`
- **Subject Alt B:** `"Finally: sheets worth staying in bed for"`
- **Preheader Alt A:** `"[Material] — launching today in [X] colorways."`
- **Preheader Alt B:** `"Rated [X] stars by early testers. Shop the launch."`

### 3. Rendering & Accessibility

**[HIGH] Conflicting `img` max-width media queries — cascade bug**

```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }  /* declared after */
```

At viewports ≥ 768px, both queries match. The 640px rule is declared later in the stylesheet and wins the cascade, allowing images to render up to 640px inside a 600px container. Swap declaration order so the 768px rule is last.

**[MEDIUM] `maximum-scale=1` in viewport meta**

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

Prevents pinch-zoom on mobile. Fails WCAG 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**[MEDIUM] `-webkit-text-size-adjust: none` on universal selector**

```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; ... }
```

The universal `*` selector overrides text-size adjustment globally, not just on `body`. Combined with the zoom restriction above, this doubly blocks user text scaling. The `body`-scoped declarations (present separately) are sufficient; the `*` rule should drop these two properties.

**[LOW] Duplicate `format-detection` meta tags — 4 declarations, redundant**

```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<!-- ... then separately: -->
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```

The first tag covers all cases. The three subsequent tags are redundant and add unnecessary head weight. Consolidate to one.
