# On sale now: decor for indoors & out
**Score:** 9/10 · **Type:** Email audit · **2026-07-03**
## Executive summary

- This is CB2's seventh-plus email in the July 4th sale run — arriving the day before the holiday — and it makes a smart lateral move. Rather than repeating furniture or rugs (both hit in yesterday's sends), it narrows to **decor for indoors & out**, a distinct enough angle to justify another send. The countdown timer (four-plus days remaining, confirming this is a "long weekend" sale, not a "last chance") anchors the hero immediately, and the three-tier structure — hero 50% off decor → category shortcuts → Warehouse Sale at 60% — gives subscribers a clear decision ladder.
- The execution is clean and the visual hierarchy works. What holds it back is the from-name ("CB2 LONG WKND SALE" instead of just "CB2"), the generic SHOP NOW CTA, and the subject line that buries the punchiest part ("50% off") in favor of category description. Compared to yesterday's "SALE'S GOING FAST" (which earned an 8 by leaning hard on urgency), this send feels more browsable than urgent — which is fine for July 3rd, but a missed opportunity to close the holiday sprint hard.
- Clear verdict: a solid mid-series send that does its job — carves a new category lane, adds the countdown as proof of deadline, and has the "MORE FOR YOU" personalization grid as a legitimate conversion lever. Nothing broken, nothing spectacular.

## What's working

- **Countdown timer is front and center.** The 04:17:02:00 clock gives the sale a concrete end point without requiring the subscriber to trust a vague "limited time" claim.
- **Category pivot is legitimate.** After two furniture-heavy sends and a rugs send yesterday, "decor for indoors & out" is fresh enough to reopen the inbox for a subscriber who mentally filed those.
- **Three-tier discount architecture** (50% off decor → category shortcuts → Warehouse at 60%) creates a logical escalation; the Warehouse callout works as a reward for scrollers.
- **"MORE FOR YOU" personalized grid** with visible prices and individual product tiles is the strongest click driver in the email — specific, shoppable, and relevant.
- **No render bugs visible.** Images load, text is clean, layout holds.

## What's weak

- **From-name "CB2 LONG WKND SALE" trades brand recognition for campaign signaling.** Most subscribers scan the sender field for a trusted name; "CB2 LONG WKND SALE" reads like a list segment label, not a brand. Just "CB2" wins.
- **"SHOP NOW" CTA is the weakest possible verb-noun.** After 6+ emails, subscribers need a reason to click; "SHOP DECOR" or "SEE 50% OFF DECOR" would do real work.
- **Subject omits the actual offer.** "On sale now: decor for indoors & out" describes the category but never says 50% off — the most compelling fact is left for the body.
- **Cadence fatigue is real.** This is approximately the eighth email in the sale run in under a week. No segment reset or explicit "last real day" positioning is visible to re-earn attention from someone who has already tuned out.

## Recommendations

- 1. **Put the discount in the subject line.** The single highest-impact change: "50% off decor" in the subject pulls the body's hero into the inbox.
- **Subject Alt A:** `50% off decor — indoors & out`
- **Subject Alt B:** `Decor deal: 50% off inside + outside`
- **Preheader Alt A:** `Plus up to 60% off in the Warehouse Sale — sale ends Sunday`
- **Preheader Alt B:** `Pillows, vases, outdoor accents — all 50% off this weekend`
- 2. **Fix the from-name.** Change "CB2 LONG WKND SALE" back to "CB2" to preserve brand recognition in the inbox scan.
- 3. **Sharpen the hero CTA.** Replace "SHOP NOW" with "SHOP 50% OFF DECOR" — the offer IS the reason to click; say it on the button.
- 4. **Add explicit sale-end date to the hero block.** The countdown timer is great but "SALE ENDS JULY 7" in text beneath it would serve subscribers who read the email hours or days later when the timer may have reset or broken.
- 5. **Use the subject's "indoors & out" angle more aggressively in the body.** A side-by-side indoor/outdoor layout (e.g., a throw pillow vs. an outdoor lantern) would visually justify the dual promise and differentiate from the furniture-forward previous sends.

### 3. Rendering & Accessibility

**Issue 1 — Unfilled template comment in production `<head>`:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
This developer instruction was never removed. "IMPUT" is also misspelled ("INPUT"). Low rendering impact but signals the template was not fully QA'd before send.

**Issue 2 — `maximum-scale=1` blocks user zoom (WCAG 1.4.4 violation):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. Fails WCAG 2.1 SC 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**Issue 3 — `*` selector applies `-webkit-text-size-adjust:none` globally:**
```css
*{-webkit-text-size-adjust:none;-ms-text-size-adjust:none; ...}
```
Applying `none` (not `100%`) to all elements via the universal selector suppresses browser-level text scaling, compounding the zoom issue above. Should be scoped to `body` only and set to `100%`.

**Issue 4 — Double-slash in `@font-face` src URLs:**
```css
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
src: url("https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2")
```
Three of the six `@font-face` declarations have `//` after the domain. HTTP servers normalize this correctly, but it indicates copy-paste slop in the template.

**Issue 5 — Cross-domain font dependency on `crateandbarrel.com`:**
```css
@font-face { font-family:"HNW05"; src: url("https://www.crateandbarrel.com/webfonts/...") }
```
All four "HNW05" weight variants load from a sibling-brand domain. If `crateandbarrel.com` enforces CORS headers that block third-party requests, CB2 emails silently fall back to system fonts. Font assets should be self-hosted on `cb2.com` or a dedicated email CDN.

**Issue 6 — "Lineto Brown Light Sub" has no woff2 source:**
```css
@font-face {
  font-family: "Lineto Brown Light Sub";
  src: url("https://www.cb2.com/Styles/CB2/fonts/BrownLight/lineto-brown-light.woff");
}
```
Only `.woff` declared. All modern clients prefer `.woff2` for ~30% smaller payloads. The Regular weight has a `.woff2` entry; Light does not.

**Issue 7 — Mobile breakpoint at 418px is too narrow for some current devices:**
```css
@media only screen and (max-width: 418px) { .mobile { width:414px !important; } }
```
iPhone 16 Pro Max viewport is 430px wide; this breakpoint misses it. Standard safe value is `max-width: 480px`.
