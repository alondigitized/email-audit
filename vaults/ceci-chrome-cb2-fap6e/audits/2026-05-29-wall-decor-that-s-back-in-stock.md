# Wall decor that’s back in stock
**Score:** 8/10 · **Type:** Email audit · **2026-05-29**
## Executive summary

- This is CB2's back-in-stock notification for wall decor — a genuinely useful email type that can cut through heavy promotional cadence because it's behavioral. But CB2 squanders the setup immediately: the subject creates a specific, high-intent expectation ("items you may have missed are available again") and the hero headline answers with "SEIZE THE MOMENT." That's a lifestyle non-sequitur where a utility payoff should be. The open clicks into ambient editorial, not the restock confirmation the subject promised.
- The product grid does solid work from there — mirrors, prints, and decorative wall pieces shown with real product photography, a clear "SHOP WALL ART" CTA, and CB2's reliable visual cleanliness. No render bugs, no broken images, and the hierarchy from hero to grid to button is legible. But there's no price, no deadline, no sale tie-in to the active Midseason Sale running since yesterday's send. This feels like a campaign island — filed away in a content calendar without anyone asking "how does this connect to what we're doing this week?"
- Cadence is becoming a problem. This is CB2's third email on May 29 (or second, given the prior "These colors never go unnoticed" send today) in a week that has included Memorial Day doubles, a midseason sale launch, a green color story, and now two more sends. The back-in-stock angle is a smart format pivot after a heavy promotional run — but only if it pays off that pivot with specificity the sale emails couldn't provide.

## What's working

- **"SHOP WALL ART" CTA is clean and category-specific** — verb + noun, unambiguous placement, not "Discover" or "Explore."
- **Back-in-stock subject is high-utility framing** — genuinely useful signal for someone who'd been eyeing something; stands out from the week's promotional pile.
- **Product grid is well-curated** — arched mirror, nature prints, round mirrors — coherent aesthetic, no random SKU dump.
- **No render bugs** — clean layout, images load, no overlapping text or broken columns.
- **Subject line length is tight** — 31 characters, well within mobile clip threshold.

## What's weak

- **"SEIZE THE MOMENT" hero headline misses the back-in-stock brief entirely** — wastes the high-intent open by switching register to lifestyle editorial.
- **No pricing, no Midseason Sale tie-in** — the active sale from yesterday's 9/10 send disappears here; a missed layering opportunity.
- **Multi-product grid dilutes click motivation** — no one hero item anchors attention or creates a "that's the one I wanted" moment.
- **No explicit availability urgency in body** — "back in stock" in the subject sets up scarcity, but no copy in the visible render reinforces "limited quantities" or "selling fast."
- **Cadence is at its limit** — this is at minimum the fourth CB2 send in four days; the back-in-stock format needed to feel more earned and differentiated.

## Recommendations

- 1. **Rewrite the hero headline to pay off the subject** — "They're Back" or "Back In Stock: Our Most-Wanted Wall Decor" directly confirms the expectation the subject set. "SEIZE THE MOMENT" belongs in a lifestyle editorial, not a restock trigger.
- 2. **Add a scarcity signal in the body** — "Limited quantities" or "Last time these sold out fast" next to the product grid converts the subject's implied urgency into explicit copy.
- 3. **Tie to the Midseason Sale** — a single line ("Back in stock — and part of our Midseason Sale") would stack two motivators without adding complexity.
- 4. **Lead with one hero product, not the full grid** — pick the most-coveted restocked item (the arched mirror reads as the visual anchor), give it a dedicated hero treatment above the fold, then drop into the grid.
- 5. **Surface availability counts if possible** — "Only 12 left" next to the hero item would turn a browsing email into a conversion email.
- **Subject Alt A:** `Back in stock: the wall decor you've been waiting for`
- **Subject Alt B:** `They're back — and selling out again`
- **Preheader Alt A:** `Limited quantities on our most-wanted mirrors, prints, and more.`
- **Preheader Alt B:** `These sold out fast last time — shop before they're gone again.`

### 3. Rendering & Accessibility

**Issue — `font-display: swap` in email context (dead code):**
Three `@font-face` declarations include `font-display: swap`, which has zero support in any email client. It is harmless but adds noise and suggests the CSS was copied from a web stylesheet without adaptation.

```css
/* line ~80 in <head> <style> */
font-display: swap;  /* ignored by all email clients */
```

**Issue — Duplicate `@font-face` family name collision:**
`"Lineto Brown Sub"` is declared three times: once with no weight, once at `font-weight: 400`, and once at `font-weight: 600`. The unweighted declaration maps to a Light variant (`lineto-brown-light.woff`), which will conflict with the weight-400 declaration on clients that process all three rules. The last matching rule wins, making the unweighted block effectively dead:

```css
/* Declaration 1 — no weight, loads Light variant */
@font-face { font-family: "Lineto Brown Sub"; src: url(".../lineto-brown-regular.eot"); ... }

/* Declaration 2 — weight 400, loads Light variant */  
@font-face { font-family: "Lineto Brown Sub"; src: url(".../lineto-brown-light.woff2"); font-weight: 400; }

/* Declaration 3 — weight 600, loads Regular variant */
@font-face { font-family: "Lineto Brown Sub"; src: url(".../lineto-brown-regular.woff2"); font-weight: 600; }
```

**Issue — Cross-domain font dependency:**
`HNW05` is loaded from `crateandbarrel.com`, not `cb2.com`. CB2 email rendering has a hard dependency on Crate & Barrel's CDN availability. If that host goes down or the path changes, affected text falls back to system fonts silently.

```css
src: url("https://www.crateandbarrel.com/webfonts/1e07d600-...woff2")
```
