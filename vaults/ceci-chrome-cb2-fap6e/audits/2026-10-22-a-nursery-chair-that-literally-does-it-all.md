## Technical Audit

## 1. Technical Summary
The email uses a table-based XHTML Transitional layout with Outlook (MSO) conditional fallbacks and 88 redirect-wrapped links. QA reports 0 hard failures, but about 45 images lack alt text, and the unsubscribe and authentication headers could not be verified. The HTML source was truncated, so footer and link-level checks are incomplete.

## 2. Link & Tracking Issues
- **88 tracking links were not probed.** QA skipped them as click-redirect domains, so destination status, redirect chains, and UTM handling are unverified.
- **Many third-party and first-party tracking pixels.**
  - `https://sr.rlcdn.com/448796.gif?s=…&n=1` through `n=5` (5 LiveRamp pixels).
  - `https://mi.crateandbarrel.com/p/rp/f3c0d22992a01946.png?mi_u=…` (6 repeats).
  - `https://mi.crateandbarrel.com/p/up/50c75a732e99b42a/o.gif`.
  - `https://dv.crateandbarrel.com/o/d4272d5d-…?mi_cid=…&mi_mid=…`.
  - These add request weight and are blocked by many privacy clients. Open-rate data and any logic keyed to these pixels will be unreliable.
- **Template placeholder left in `<head>`.** The comment `<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->` is a leftover, and "IMPUT" is a typo. It is harmless to rendering but shows incomplete template cleanup.

## 3. Rendering & Accessibility
- **Missing alt text (about 45 `<img>` elements).**
  - Content images on `image.mail.crateandbarrel.com/lib/fe9013727564027a7c/m/1/*.jpg` are affected (for example `77959ca0-…jpg`, `fdbb2d8f-…jpg`).
  - The animated hero `Hero%5FEdit%5F3%5FTypography.gif` on `s7d5.scene7.com` is also affected.
  - If these images are blocked or read by a screen reader, there is no text equivalent.
  - The tracking pixels should carry `alt=""` rather than no alt attribute.
- **Zoom is restricted.** `<meta name="viewport" content="… maximum-scale=1" />` blocks pinch-zoom on some clients. `-webkit-text-size-adjust:none` (in `*{}` and `body`) also prevents iOS text resizing.
- **Invalid markup for the declared XHTML 1.0 Transitional doctype.**
  - `<title>Crate & Barrel</title>` uses an unescaped `&`; it should be `&amp;`.
  - `<meta charset="utf-8">` is not self-closed.
  - `Content-Type` and `charset` are declared twice.
  - `format-detection` is declared four separate times (`telephone`, `address`, `date`, and the combined entry).
- **Conflicting `img` max-width rules.**
  - `@media (min-width:768px){img{max-width:600px}}` is followed by `@media (min-width:640px){img{max-width:640px}}`.
  - At 768px and wider, both match and the later 640px rule wins. The 600px rule is dead code.
- **Single mobile breakpoint.** Responsive rules apply only at `max-width:460px`, so widths between 461px and 639px get no mobile adjustments.

## 4. Personalization & Merge Tokens

- **Hashed recipient identifiers.** `mi_u=56aaa2787a67…` and `mi_cid`/`mi_mid` are rendered per-recipient values, as expected.

The footer was truncated, so token checks there are incomplete.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **`List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) were not found.** QA notes AgentMail may strip them, so I can't confirm they are missing from the original send. If they are truly absent, this conflicts with Gmail/Yahoo bulk-sender requirements (one-click unsubscribe).
- **`Authentication-Results` is absent.** SPF, DKIM, and DMARC alignment are unverified. The sender domain `mail.crateandbarrel.com` matches the image host `image.mail.crateandbarrel.com`, which is consistent but not proof.
- **Footer and unsubscribe link not verified.** The physical address and the in-body unsubscribe link are outside the truncated source.
- **Hashed identifiers sent to a third party.** The LiveRamp pixels (`sr.rlcdn.com/448796.gif?s=…`) pass a hashed identifier to a third party. This is a privacy-disclosure consideration rather than a CAN-SPAM violation.

## 7. Recommendations
1. **Add alt text** to all content images (hero GIF, product tiles). Set `alt=""` on the tracking pixels.
2. **Re-run QA against the raw `.eml`**, or a source that preserves headers, to confirm `List-Unsubscribe`, `List-Unsubscribe-Post`, and `Authentication-Results`. If they are truly missing, add one-click unsubscribe.
3. **Resolve a sample of the tracked links** by following redirects. This will confirm final URLs, status codes, UTM params, and that the landing page matches the nursery-chair content.
4. **Remove `maximum-scale=1`** and `text-size-adjust:none` where possible.
5. **Clean up the template.** Escape `&` in `<title>`, deduplicate the meta tags, drop the 600px `img` rule, and delete the "IMPUT HERE" comment.
6. **Reduce redundant pixels** (6 repeated `mi.crateandbarrel.com` pixels and 5 `rlcdn` pixels) if page weight and blocking are concerns.
