# Let’s make your bathroom work for you →
**Score:** 6/10 · **Type:** Email audit · **2026-05-20**
## Executive summary

- Three emails in four days from Crate & Barrel, and this is where the sequence shifts gears — from welcome/offer to editorial content marketing. The bathroom organization theme is seasonally coherent (spring refresh, post-welcome engagement), but the execution lands somewhere between a catalog page and a real email. The sender label reads "Crate & Barrel SALE," which primes the subscriber for a discount, but the email body doesn't deliver one — there's no price-off callout, no urgency trigger, no expiry. That's a bait-and-switch at the sender level.
- The visual design is polished and on-brand: clean grid layout, good photography, no render issues. But the sheer volume of products shown — shelving, storage, vanity organization, then what appears to be bedroom and other categories creeping in at the bottom — dilutes focus. It tries to be a product discovery engine when it should be a single, resolved offer.
- This is a competent catalog blast dressed up as a personalized recommendation. It won't hurt the brand, but it won't move the needle either.

## What's working

- Clean, consistent Crate & Barrel visual identity — no render bugs, no broken images, layout holds well at mobile width.
- Bathroom as a category focus is seasonally smart — spring organization is a real consumer moment.
- Multiple products shown give a sense of depth and breadth in the category.
- Subject line at ~39 characters is mobile-friendly and avoids spam triggers.

## What's weak

- The sender label says "SALE" but no sale price, discount, or offer is visible in the body — that's a trust-damaging mismatch.
- No single hero product or anchor offer; the scroll is a grid of options that demand work from the reader.
- No urgency signal anywhere — no deadline, no "while supplies last," no countdownn.
- The email drifts into non-bathroom categories toward the bottom, undermining the focused bathroom pitch.
- This subscriber was promised a 10% welcome code four days ago — that code doesn't appear to be surfaced or reinforced here, leaving the most compelling lever unused.

## Recommendations

- 1. **Bring back the 10% welcome code.** This subscriber has an active offer. Reminding them it applies to bathroom storage products collapses the gap between browsing and buying. That's the single biggest lift available.
- 2. **Strip "SALE" from the sender name if there's no sale.** Or make it a sale — even a "Shop bathroom, starting at $29" anchors expectations honestly.
- 3. **Lead with one resolved hero product** (e.g., a specific shelving unit at a price), then cascade. Right now the hero is a concept; it should be a product.
- 4. **Cut the category drift at the bottom.** If the email is about bathroom, it's about bathroom. The bedroom/closet cross-sell is a conversion killer when the reader isn't warmed up.
- 5. **Add one urgency layer** — "Your 10% off expires in X days" would do it.

- **Subject Alt B:** `The bathroom edit: storage that actually fits`
- **Preheader Alt A:** `Shelving, vanity storage, and more — your welcome code still works`

### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta** — prevents users from pinching to zoom on mobile. WCAG 1.4.4 failure.
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```

**Conflicting `img` max-width media queries** — the `min-width: 768px → 600px` rule is dead code. The later `min-width: 640px → 640px` declaration overrides it at all widths ≥ 640px (CSS cascade, equal specificity, last declaration wins). Net effect: images cap at 640px on desktop, not 600px.
```css
@media only screen and (min-width: 768px) { img {max-width: 600px} }  /* overridden */
@media only screen and (min-width: 640px) { img {max-width: 640px} }  /* wins */
```

**Global `p { text-align: center }` reset** — forces center-alignment on all paragraphs, including any hidden preheader text. Can break left-aligned body copy if paragraph tags are used in content cells.

**Global `* { -webkit-text-size-adjust: none }` with `line-height: 100%`** — applied to all elements via the universal selector. `line-height: 100%` on non-text elements (tables, images) causes rendering inconsistencies in Gmail and Outlook on Windows.

**No dark mode support** — `color-scheme` and `supported-color-schemes` are both locked to `light`. Background colors set to `#e6e7e8` (light gray) will invert unpredictably in Apple Mail dark mode.

**Duplicate `format-detection` meta tags** — `telephone=no` and `address=no` each appear twice. Redundant but harmless; indicates template hygiene issues.
