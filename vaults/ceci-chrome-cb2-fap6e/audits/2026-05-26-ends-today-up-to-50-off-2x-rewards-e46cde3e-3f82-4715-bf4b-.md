# ENDS TODAY: Up to 50% off & 2x Rewards!
**Score:** 8/10 · **Type:** Email audit · **2026-05-26**
## Executive summary

- This is Crate & Kids' Memorial Day close — and it is, word-for-word, yesterday's "ENDS TOMORROW: Up to 50% off & 2x Rewards!" send with one word swapped. The sage dresser hero, product grid with category-level discount badges, mid-email Double Rewards pitch, and personalized picks section are all structurally identical to the May 25 audit. That's not a knock on execution; the layout is clean, the hierarchy works, and there are no render issues. But the creative does nothing to signal that this is the actual final moment — it just changes the countdown word.
- The Double Rewards section is well-placed: it intercepts subscribers who scrolled past the product grid without clicking and gives them a second value hook. The "we chose these for you" module adds warmth and personalization. These are the two things that make this send marginally better than a pure discount blast.
- Clear judgement: solid execution of a tired formula. A subscriber who didn't buy yesterday is being handed the same email with a different preposition. The urgency is technically earned — today IS the last day — but the creative doesn't feel like a finale.

## What's working

- **Hero image is clean and uncluttered**: the sage dresser render lets the "Up to 50% off" headline breathe without competing visual noise.
- **Double Rewards section is well-positioned**: mid-email loyalty hook catches the non-immediate-clicker and gives a second reason to act.
- **Visual hierarchy is logical**: hero → discount grid → loyalty pitch → personalized picks → app — the eye follows the path naturally.
- **"We chose these for you" personalization** lifts relevance for subscribers who aren't moved by the generic grid.
- **No render bugs**: images load, no overlapping text, layout holds.

## What's weak

- **Creative is nearly identical to yesterday's "ENDS TOMORROW" send**: one word changed in the subject; the body is a structural copy. Subscribers who didn't act yesterday receive no new reason to act today.
- **All four CTAs read "Shop Now"**: four identical buttons pointing to different categories — none of the copy tells you what you're actually shopping for.
- **No concrete price anchoring**: "up to 50% off" is the ceiling, not a real price. No was/now pair anywhere in the visible grid.
- **App download block dilutes the urgency message**: pushing an install in the middle of a "ends today" email is a conversion leak; it belongs in a non-sale context.

## Recommendations

- 1. **Give the hero a specific product at a real price**: "The Vale Dresser — $149 (was $299), today only" beats a category-level percentage every time. Pick one SKU, show the dollar amounts, make the value concrete.
- 2. **Rewrite the CTAs to match the category**: "Shop Dressers," "Shop Cribs," "Shop Nursery Rugs" instead of four "Shop Now" clones. This is the single fastest lift available here.
- 3. **Add a hard deadline**: "Ends at midnight PT" is more credible than "ends today" — it creates an actual mental clock and differentiates this send from the last six.
- 4. **Cut the app download block entirely from this send**: every module that isn't about closing the sale costs conversion rate. Move app promotion to a transactional or post-purchase email.

- **Subject Alt B:** `The Vale Dresser: $149 today only — final hours`
- **Preheader Alt A:** `Double Rewards through midnight — shop dressers, cribs, and more.`
- **Preheader Alt B:** `Your saved items are still 50% off. Sale ends at midnight PT.`

### 3. Rendering & Accessibility

**Confirmed issues:**

**3a. Conflicting `img { max-width }` breakpoints**
Two desktop media queries set conflicting values with no cascade winner logic:
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewport ≥ 768px, both rules match. The 640px rule appears last in the stylesheet and wins by cascade order, giving `max-width: 640px` — overriding the apparent 600px intent. If the container is 600px wide, images can overflow by up to 40px in some clients. **Swap rule order** or consolidate into a single breakpoint.

**3b. Duplicate `format-detection` meta tags**
`telephone=no`, `date=no`, and `address=no` each appear twice in `<head>` — once in a combined tag and once as individual tags. Redundant but harmless; tidy these to reduce head weight.

**3c. No dark mode support declared**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is explicitly blocked. Apple Mail and some Android clients will attempt their own color inversion, which can make white backgrounds dark and invert text colors unpredictably. If dark mode testing has not been done against this template, flag for QA.
