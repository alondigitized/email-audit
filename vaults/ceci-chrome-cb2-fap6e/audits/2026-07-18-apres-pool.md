# APRES POOL
**Score:** 7/10 · **Type:** Email audit · **2026-07-18**
## Executive summary

- "Après Pool" is CB2 doing what CB2 does best — lifestyle-as-product. The email leans into the aspirational leisure arc: white pod chairs, cocktail glasses, outdoor bar setups. After yesterday's "Floor Sample Sale" (and a full week of promotional drumbeat before that), this editorial reset is structurally smart. The visual execution is clean and on-brand, with a light cream/warm-neutral palette that earns the poolside mood.
- The problem is that "APRES POOL" does nothing to sell you anything specific. It's all vibe and no hook. The hero is beautiful but the email functions more as a brand moment than a conversion vehicle. CB2 keeps reaching for this editorial posture after sale runs — it works creatively, but the click story is weak because there's no concrete offer pulling you forward.

## What's weak

- **The subject line "APRES POOL" is all atmosphere, zero offer.** Ten characters is extremely short — it's mobile-friendly but tells you nothing about why to open now.
- **No visible urgency or price hook anywhere.** The product grid appears to show standard pricing with no clear promotional incentive — a pure editorial ask with no conversion pull.

### 3. Rendering & Accessibility

**[CONFIRMED] `maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users from pinching to zoom. Violates WCAG 2.1 SC 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**[CONFIRMED] Mobile breakpoint too narrow**
```css
@media only screen and (max-width: 418px) { .mobile { width:414px !important; } }
```
414px matches iPhone 8 Plus (2017). iPhone 15 Pro logical width is 393px — these devices fall *outside* the mobile breakpoint and receive no responsive overrides. Breakpoint should be raised to at least `600px` for broad coverage.

**[CONFIRMED] `line-height: 100%` applied universally**
```css
* { line-height: 100%; }
```
The universal selector sets `line-height: 100%` which is relative to font-size and commonly clips descenders in Outlook and some webmail clients. Should use a unitless value (e.g. `1.5`) or explicit `px`.

**[CONFIRMED] Duplicate `@font-face` declarations for same family**
Three separate `@font-face` blocks declare `font-family: "Lineto Brown Sub"` — one without weight/style descriptors, then two with explicit `font-weight: 400` and `font-weight: 600`. The unqualified first declaration creates an ambiguous match and can cause rendering to fall through to fallback fonts unpredictably in Gmail/Outlook.

### 6. Email-to-Site Continuity (UTM Params, Landing Page Alignment)

**Cannot audit** — no body links visible in truncated source. UTM parameter coverage cannot be confirmed.

**[NOTED] Cross-brand font origin**
```css
src: url("https://www.crateandbarrel.com/webfonts/1e07d600-3787-4517-bd3d-b140f9e54ec2.woff2")
```
The `HNW05` typeface is served from `crateandbarrel.com`, not `cb2.com`. While functionally it may work, any CORS policy change on the parent domain would silently break font rendering in this email. Fonts should be self-hosted or served from the same origin (`cb2.com`).

**[CONFIRMED] Double-slash in font URLs**
```css
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
```
Three `@font-face` URLs contain `//Styles` (double slash after the domain). Most servers normalize this with a 301, but some strict hosts return 400. These are likely causing silent font-load failures or extra redirect round-trips:
- `https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2`
- `https://www.cb2.com//Styles/CB2/fonts/BrownRegular/lineto-brown-regular.woff2`
- `https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2`
