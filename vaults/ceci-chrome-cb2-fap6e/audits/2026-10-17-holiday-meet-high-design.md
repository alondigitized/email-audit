## Technical Audit

## 1. Technical Summary
The email has one confirmed broken-experience defect: an unresolved merge token, `%%reviews_skulist%%`. It also has widespread missing alt text and 10 non-HTTPS third-party tracking pixels. The HTML was truncated and the link probe skipped all 78 tracked links, so the unsubscribe footer, UTM parameters and link destinations could not be verified.

## 2. Link & Tracking Issues
- **Unverified links:** 78 tracking links were skipped as click-redirect domains. Destination status, redirect chains and broken links are unknown.
- **Insecure pixels:** 10 Dotomi cookie-sync pixels load over `http://`:
  - `http://ads.dotomi.com/cookieredir/2437/pub1.php?d98e199b…=1` through `pub10.php`
  - `http://login.dotomi.com/ucm/UCMController?dtm_com=2&dtm_cid=2437&…`
  
  Clients that proxy images or block mixed content may drop them, so ad-sync and attribution would silently fail. They also add 11 third-party requests, and none have alt text.
- **First-party beacons:** `https://mi.cb2.com/p/up/09aebc5b21344cf7/o.gif?mi_u=…` and `https://dv.cb2.com/o/d097fa06-…?mi_cid=…` are HTTPS, but both lack alt text.
- **Font URLs:** two `@font-face` sources use a double slash, `https://www.cb2.com//Styles/CB2/fonts/...`. Two further `@font-face` blocks (`HNW05`) pull from `crateandbarrel.com`, which cross-loads another domain's assets. Clients that support web fonts will fall back if those paths don't resolve.

## 3. Rendering & Accessibility
- **Missing alt text:** 16 content images from `image.mail.cb2.com/lib/fe9213727564027a72/m/1/` have no alt attribute. Examples are `391ada82-…jpg`, `af3c04f2-…gif`, `8e957a75-…gif` and `6328b256-…jpg`. With images blocked, or for screen readers, the content is unreadable.
- **Zoom disabled:** `<meta name="viewport" … maximum-scale=1>` blocks pinch-zoom on mobile.
- **Text resize disabled:** `*{-webkit-text-size-adjust:none; … line-height:100%}` stops text resizing in WebKit clients.
- **Template residue:** a placeholder comment remains, `<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->`. It is harmless but shows an unfinished template.
- **Font fallback:** the `Lineto Brown Sub` family is declared three times with inconsistent weight and style descriptors (the first block has none). The first block has no `font-display`, so fallback behavior varies by client.
- **Doctype:** XHTML 1.0 Transitional with `lang="en"` and a `<title>`. No issue.

## 4. Personalization & Merge Tokens
- **FAIL:** the raw token `%%reviews_skulist%%` was found in the rendered output. This is the `%%…%%` personalization-string syntax used by Salesforce Marketing Cloud. The reviews or SKU-list dynamic content did not resolve, so the token may be visible to recipients or may have left an empty module. The truncated source doesn't show where it sits, so its visibility is unconfirmed.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Headers:** `List-Unsubscribe`, `List-Unsubscribe-Post` (RFC 8058) and `Authentication-Results` were not found. The QA data attributes this to the AgentMail relay stripping headers, so it is not evidence that CB2 omits them. SPF, DKIM, DMARC and one-click unsubscribe are unverified.
- **Footer:** the in-body unsubscribe link and physical postal address are in the truncated portion, so they are not confirmed either way.
- **From address:** `cb2@mail.cb2.com` uses a dedicated subdomain aligned with the brand, and the sending domain matches the image and tracking subdomains (`image.mail.cb2.com`). No issue.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Cannot be assessed. The 78 tracked links were not resolved, and no landing-page URLs or UTM parameters appear in the provided source. No issues are claimed.

## 7. Recommendations
1. **Fix the merge token (high):** resolve or suppress `%%reviews_skulist%%` in the SFMC send. Add a fallback or empty-state so the module is removed when the data source returns nothing.
2. **Add alt text (high):** give all 16 `image.mail.cb2.com` content images descriptive alt text. Give the tracking pixels `alt=""`.
3. **Move to HTTPS (medium):** change the 10 Dotomi pixels and the UCMController call to `https://`, or drop them if the cookie-sync is no longer needed.
4. **Allow zoom (medium):** remove `maximum-scale=1` from the viewport meta and `-webkit-text-size-adjust:none` from the universal selector.
5. **Clean up fonts (low):** remove the `//` in the font URLs, consolidate the `Lineto Brown Sub` declarations, and delete the template placeholder comment.
6. **Re-run QA (to close the open items):** re-run against the full untruncated source and the raw MIME headers, not the relay copy, to verify the List-Unsubscribe headers, authentication, the footer, and the click-redirect destinations and UTMs.
