### 3. Rendering & Accessibility

**Conflicting `img` max-width rules across two media queries:**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewports ≥768px, the 768px rule overrides the 640px rule, capping images at 600px on wider screens — likely unintentional. The 640px container limit should be the ceiling everywhere above 640px.

**`maximum-scale=1` blocks user zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on iOS — fails WCAG 1.4.4 (Resize Text, Level AA).

**Global text-size-adjust disabled:**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
Applied via wildcard selector rather than scoped to `body`. Compounded with `maximum-scale=1`, this eliminates two independent paths for user-initiated text scaling.

**Duplicate `charset` declaration:**
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta charset="utf-8">
```
Both are present. Harmless in practice but redundant; the `http-equiv` form is the legacy fallback for Outlook, the `charset` shorthand is the HTML5 form. Only one is needed per environment.

**Triple-redundant `format-detection` meta:**
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```
The first tag already covers all suppression; the three individual tags are dead weight and indicate copy-paste accumulation across template versions.

**Dark mode explicitly suppressed:**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Opts out of OS-level dark mode rendering in Apple Mail and Samsung Mail. Acceptable as a deliberate choice only if the design has been validated against forced-dark inversion — otherwise it risks harsh white backgrounds in dark-mode clients that ignore the hint.
