# Technical Audit: CB2, "Made to linger longer + 2X rewards is ending soon"

## 1. Technical Summary
The email has 28 images with missing alt text and 11 third-party tracking pixels loaded over plain `http://`. The HTML source was truncated and the unsubscribe-related headers weren't captured, so compliance and UTM continuity can't be confirmed from this data. Automated QA: 57% pass, 0 issues, 3 warnings.

## 2. Link & Tracking Issues
- **72 tracking links were not probed** (click-redirect domains). Destination resolution, redirect chains and dead links are unverified.
- **11 Dotomi (Epsilon) pixels use `http://`**, which is mixed content and may be blocked or downgraded by clients and proxies:
  - `http://login.dotomi.com/ucm/UCMController?dtm_com=2&dtm_cid=2437&...`
  - `http://ads.dotomi.com/cookieredir/2437/pub1.php` through `pub10.php?d98e199bf5027afea04b790655b3dee2=1`
- Those ten `pubN.php` calls are cookie-sync redirect pixels. They add ten extra third-party requests per open, which hurts load time and exposes the recipient to multiple ad-tech domains.
- **First-party open pixels are present and use HTTPS:** `https://mi.cb2.com/p/up/09aebc5b21344cf7/o.gif?mi_u=...` and `https://dv.cb2.com/o/f793f754-...?mi_cid=...`. Both lack alt text.

## 3. Rendering & Accessibility
- **15 content images have no alt attribute**, all on `https://image.mail.cb2.com/lib/fe9213727564027a72/m/1/`. Examples: `5c26e5b4-1736-4057-8954-c07f9606422e.jpg` and `0e1e902f-8429-4432-972f-4371347d5e52.jpg`. With images blocked, or in a screen reader, these render as blank space or read out filenames.
- **13 tracking pixels have no alt attribute** (the 11 Dotomi pixels plus `o.gif` and the `dv.cb2.com` pixel). These should carry `alt=""` so assistive tech skips them.
- **The viewport meta disables zoom:** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />`. This is a WCAG 1.4.4 concern on clients that honor it.
- **Template residue in the head:** the comment `<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->` was left in the source. It is harmless but shows the template wasn't cleaned.
- **Custom `@font-face` rules** point to `cb2.com` and `crateandbarrel.com` (HNW05), and some URLs contain a double slash (`https://www.cb2.com//Styles/...`). Many clients ignore web fonts, so the fallback stack matters. Verify it's defined on the elements that use these fonts.
- The `<title>` ("CB2, FURNITURE AND DECOR FOR THE MODERN HOME") is generic and doesn't match the subject line. This is minor.

## 4. Personalization & Merge Tokens
No issues found. The visible source shows no unrendered tokens (`%%…%%`, `{{…}}`, `[FIRSTNAME]`). Because the source was truncated, the body can't be fully ruled out.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **`List-Unsubscribe` not found** (QA WARN). The QA tool itself notes this may be an AgentMail relay capture limitation, so treat it as **unverified, not confirmed missing**.
- **`List-Unsubscribe-Post` (RFC 8058) not found** (QA WARN). Same caveat. Gmail and Yahoo bulk-sender rules require one-click support, so check the raw headers on a direct-delivery copy.
- **`Authentication-Results` not found** (QA WARN). SPF, DKIM and DMARC alignment are unknown. The sending domain is `mail.cb2.com`, and the image host `image.mail.cb2.com` is aligned with it.
- **In-body unsubscribe link and physical postal address could not be verified**, because the truncated HTML doesn't reach the footer.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Unverifiable. All 72 tracked links were skipped, and the visible source doesn't expose final destination URLs or UTM parameters. Nothing was observed that indicates misalignment.

## 7. Recommendations
1. Add descriptive `alt` text to the 15 `image.mail.cb2.com` content images. Add `alt=""` to all 13 tracking pixels.
2. Switch the Dotomi pixels (`login.dotomi.com`, `ads.dotomi.com/cookieredir/...`) to `https://`, or drop the ten `pubN.php` cookie-sync calls to cut third-party requests.
3. Remove `maximum-scale=1` from the viewport meta so users can zoom.
