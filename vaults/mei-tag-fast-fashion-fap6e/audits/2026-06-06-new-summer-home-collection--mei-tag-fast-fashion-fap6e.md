### 3. Rendering & Accessibility

**`@import` font loading will fail silently in most clients**

```css
@import url(https://fabric.hmgroup.com/fabric-fonts/0/northstar/css/fonts.css);
@import url(https://s1-cdn.hm.com/global/hm-fonts/4.0.1/oces.css);
```

`@import` inside `<style>` blocks is stripped by Gmail (both web and app), Outlook 2007–2021 (ignores entirely), and Yahoo Mail. Custom fonts will silently fall back to system fonts. This is a known H&M pattern — if fallback stacks are specified in the CSS, the visual impact is contained, but the external CDN requests still add DNS lookup latency for clients that do render them.

**`<meta http-equiv="content-type">` is legacy**

```html
<meta http-equiv="content-type" content="text/html; charset=UTF-8"/>
```

Should be `<meta charset="UTF-8">` per HTML5. The legacy form works but is unnecessary for modern clients.
