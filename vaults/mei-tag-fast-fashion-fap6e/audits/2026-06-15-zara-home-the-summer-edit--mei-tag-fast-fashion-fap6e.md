### 3. Rendering & Accessibility

**`line-height: auto` is invalid CSS.**
```css
.heightmobile { height: auto!important; line-height: auto!important; }
```
`auto` is not a valid value for `line-height`. Browsers will silently ignore it; the intended spacing will not apply on mobile.

**`user-scalable=no` blocks pinch-to-zoom (WCAG 1.4.4 failure).**
```html
<meta name="viewport" content="width=device-width; initial-scale=1.0; maximum-scale=1.0; user-scalable=no;" />
```
This prevents users with low vision from zooming. Removing `user-scalable=no` and `maximum-scale=1.0` is the fix.

**Invalid XHTML structure: `<div>` as direct child of `<table>`.**
The preheader block places a `<div style="mso-hide:all;">` between `<table>` and `<tr>`, which is invalid in XHTML Transitional:
```html
<table ...>
  <div style="mso-hide:all;">   <!-- INVALID: div cannot be direct child of table -->
    <tr><td>...</td></tr>
  </div>
```
Strict parsers (some Outlook versions) may reflow this unexpectedly. The `<div>` should wrap the entire `<table>`, not its rows.

**No `lang` attribute on `<html>`.**
```html
<html xmlns="http://www.w3.org/1999/xhtml">
```
Missing `lang="en"` causes screen readers to default to the OS language, breaking pronunciation for non-English users and disabling browser spell-check.

**Google Fonts loaded via `<link>` — will be stripped by Gmail and Outlook.**
```html
<link href="https://fonts.googleapis.com/css?family=Roboto+Condensed..." rel="stylesheet">
```
Gmail, Outlook (all versions), and Yahoo strip `<link>` tags. Roboto Condensed will not render for the majority of recipients; fallback fonts must be explicitly validated for visual fidelity.
