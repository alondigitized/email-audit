### 2. Link & Tracking Issues

If the ESP uses these comments to route analytics, the mismatch (`US_en` vs `US`) can cause split attribution in reporting dashboards.

---

### 3. Rendering & Accessibility

**Invalid `<div>` inside `<tr>` (confirmed)** — the preheader block places a `<div>` as a direct child of `<tr>`, which is invalid in XHTML and rejected by strict parsers:
```html
<div style="mso-hide:all;">
  <tr>
    <td ...><span style="display: none !important; ...">
```
A block element cannot be a sibling of `<tr>`; this can cause the entire preheader row to be dropped or misrendered in WebKit-based clients.

**Unclosed MSO conditional comment (confirmed)** — the conditional block opens but never closes:
```html
<!--[if !mso 9]><!-->
<div style="mso-hide:all;">
```
The matching `<!--<![endif]-->` is absent in the visible source. If it's also absent downstream, the `mso-hide` div may be rendered as visible content in Outlook.

**`viewport` meta uses semicolons instead of commas (confirmed):**
```html
<meta name="viewport" content="width=device-width; initial-scale=1.0; maximum-scale=1.0; user-scalable=no;" />
```
RFC/W3C spec requires comma-separated viewport values. Semicolons cause the directive to be silently ignored on iOS Safari and Android WebView, breaking responsive scaling.

**`user-scalable=no` (confirmed)** — WCAG 1.4.4 (Level AA) requires content to be resizable up to 200% without assistive technology. Disabling pinch-to-zoom fails this criterion.

**Google Fonts via `<link>` (confirmed):**
```html
<link href="https://fonts.googleapis.com/css?family=Roboto+Condensed..." rel="stylesheet">
```
Gmail (web + app), Outlook (all versions), and Apple Mail on iOS do not execute `<link>` in email `<head>`. Roboto Condensed will silently fall back to the system sans-serif in the majority of clients. Not a breakage, but the font load is wasted bandwidth on every open.

**Preheader padding characters** — `&#8199;&#847;` (Hair Space + combining-character) is a known technique but renders as a visible glyph in some older Android mail apps. Low-severity.

**`.ExternalClass * {line-height: 100%}`** — this Hotmail/Outlook.com hack targets a CSS class that Microsoft removed in 2018. Dead code, no impact.
