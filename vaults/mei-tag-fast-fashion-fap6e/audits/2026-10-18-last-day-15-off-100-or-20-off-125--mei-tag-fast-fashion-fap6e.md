# Technical Audit: H&M "Last day: 15% off $100 or 20% off $125"

## 1. Technical Summary
All 12 probed links, including Unsubscribe, return HTTP 403 from the `t19.email.hm.com/r/` redirector. Nearly every image lacks alt text, and the JSON-LD block is empty. Because the 403s are identical across every link, they most likely come from the redirector rejecting the QA probe, not from broken links.

## 2. Link & Tracking Issues
- **403 on every probed link (12 of 12).** The affected links include "Shop now", "Find a store", "Need it today? Order by 4pm ET…", the "H&M" logo link, an image link and "Unsubscribe". Example: `https://t19.email.hm.com/r/?id=h86be2572-…,54920c41,f87d72f6&did=1418857537&rid=3326930539&…`.
  - The ESP redirector is probably rejecting the non-browser user agent or the probe's IP. A uniform 403 across unrelated destinations points that way.
  - This is unconfirmed. Treat it as "unverified" until the links are tested with a real client.
- **Final destinations can't be checked.** Every link is wrapped, and the redirect was never followed. The 84 links that weren't probed (footer, utility and social) are unchecked.
- **Subscriber identifiers in every URL.** `rid=3326930539` and `erid=MzMyNjkzMDUzOQ==` (base64 of the same ID) appear in each URL. `p4` on the unsubscribe link repeats the ID. This is standard ESP tracking, but it means forwarded emails expose the subscriber ID.
- **Repeated destinations.** "Find a store" appears with 4 distinct link IDs (`f87d72c0`, `c5`, `ce`, `d3`) and "Shop now" with 4 (`f87d72a2`, `a3`, `7280`, `7282`). That is normal for per-placement tracking.

## 3. Rendering & Accessibility
- **Missing alt text.** The QA flagged about 20 images, mostly `cq5dam.web.1400.1400.jpeg` and `cq5dam.web.750.750.jpeg` under `image.hm.com/content/dam/hm/regional-local-activities/ame/2026-ame/wk-42/…` and `wk-43/…`.
  - The 1400px and 750px versions appear as pairs. This is likely a desktop/mobile swap using `.is-hidden-mobile` and `.is-hidden-desktop`.
  - Two tracking-pixel-style or linked images (`src=https://t19.email.hm.com/r/?id=h86be2572-…,1`) also lack alt text.
- **Filename as link text.** One link's text resolves to `[image: cq5dam.web.1400.1400.jpeg]` (`…f87d72a0`). A screen reader will announce the filename as the link's name.
- **Invisible characters in link text.** Two "Shop now" links (`…f87d7280`, `…f87d7282`) have link text containing zero-width characters (U+200C and U+FEFF) before "Shop now". These are probably preheader-padding spacers. They can affect text-based link matching and some screen readers.
- **Possible mobile hiding problem.** `.is-hidden-desktop` sets `line-height:auto!important`. `auto` is not a valid `line-height` value, so that declaration will be ignored. `line-height:normal` is the valid keyword. Low impact.
- **Web font imports.** `@import url(https://fabric.hmgroup.com/…)` and `@import url(https://s1-cdn.hm.com/…/oces.css)` are unsupported in Gmail and many clients. Fallback fonts should be defined, but the truncated source can't confirm that.

## 4. Personalization & Merge Tokens
No issues found. No unrendered merge tokens (`{{…}}`, `%%…%%`) are visible in the truncated source or the QA data. The per-recipient parameters (`rid`, `erid`, `p2`, `p5`) resolved to concrete values.

- **`List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) not found.** The QA tool itself notes the AgentMail relay may strip these headers, so this is unconfirmed. Gmail and Yahoo bulk-sender rules require both, so check the raw headers at the sending side.
- **`Authentication-Results` not found.** SPF, DKIM and DMARC status is unknown because the relay doesn't expose it. The From domain is `email.hm.com`. Verify with a direct seed test.
- **In-body unsubscribe link is present** (`…f87d72f6…&p4=3326930539&p5=9be06746…`). It returned 403 to the probe, so its function is unverified.
- **Postal address and physical footer** can't be checked because the HTML is truncated before the footer.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **No UTM parameters are visible.** The wrapped URLs carry only ESP params (`did`, `rid`, `erid`, `p1=DM6144149`, `p2`, `p3=20261018`). Any UTM tagging would be applied after the redirect.
- **Landing-page alignment can't be assessed.** The 403s blocked redirect resolution, so destinations and landing URLs are unknown. Re-run the QA with a browser-like user agent to resolve them.

## 7. Recommendations
1. **Re-probe the links with a real browser user agent, or by following redirects from a seeded inbox.** Confirm that "Shop now", "Find a store" and especially Unsubscribe resolve, and capture the final URLs and UTMs.
2. **Check raw message headers in a direct seed inbox.** Confirm `List-Unsubscribe`, `List-Unsubscribe-Post: List-Unsubscribe=One-Click`, and SPF, DKIM and DMARC alignment for `email.hm.com`.
3. **Add alt text to the images**, especially linked ones. Use `alt=""` for decorative images. Make sure the linked image at `…f87d72a0` has meaningful alt text, so its link name isn't the filename.
4. **Remove zero-width characters from visible CTA link text** (the two "Shop now" links). Move any padding to the preheader.
5. **Fix the `line-height:auto` declaration** in `.is-hidden-desktop`. Use `normal` or a pixel value.
