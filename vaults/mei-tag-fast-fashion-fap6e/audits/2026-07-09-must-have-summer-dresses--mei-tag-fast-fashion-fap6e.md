- The Wanderdoll x Emma Milton exclusive is the only actual news in this email and it's buried two-thirds down, competing for attention with a row of brand logos.

### 3. Rendering & Accessibility

**Confirmed issues:**

- **`-webkit-text-size-adjust: none` on `body`** — disables iOS text-scaling entirely, preventing users from zooming text. The correct value for accessibility compliance is `100%`, not `none`. The later `* { -webkit-text-size-adjust: 100%; }` rule does not override this on `body` itself (body selector has higher specificity than `*`).

  ```css
  /* Line ~35 */
  body, #body_style { -webkit-text-size-adjust: none; }
  /* Should be: 100% */
  ```

- **Mobile breakpoint at 460px** — industry standard is 600px. Devices with 461px–599px viewport width (many Android phones in landscape, small tablets) receive the desktop layout, causing potential overflow.

- **SVG font format included** — all `@font-face` declarations include an SVG fallback format. SVG fonts are deprecated and unsupported in all modern email clients. Adds payload weight with zero benefit.

  ```css
  url("https://images.asos-media.com/.../FuturaPT-Book.svg") format("svg");
  ```

- **`font-size: 0em` on `table, tr, td, th`** — this ghost-text gap fix is common, but the global scope means any inline text accidentally placed directly in a `<td>` without a child element will be invisible with no warning.

- **Dual charset declarations** — both `<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">` and `<meta charset="utf-8">` are present. Redundant but harmless; minor payload bloat.
