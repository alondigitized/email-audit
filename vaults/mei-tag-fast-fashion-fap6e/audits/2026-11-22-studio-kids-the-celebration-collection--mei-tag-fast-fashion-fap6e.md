# Technical Audit: Zara "STUDIO KIDS | The Celebration Collection"

## 1. Technical Summary
The QA run passed 38% of checks, with one hard failure (empty plain-text part) and several compliance and header warnings. The visible source is a Responsys-built XHTML table layout. It has 16 images without alt text and invalid markup in the preheader block. The HTML was truncated, so link, footer and unsubscribe markup could not be inspected.

## 2. Link & Tracking Issues
- **No `href` values were in the truncated source.** I can't verify link destinations, redirect chains or broken links.
- **Responsys open-tracking pixel:** `https://news.zara.com/pub/as?_ri_=X0Gzc2X%3D...` is present and has no alt attribute. It is a tracking pixel, so it should carry `alt=""`, and the QA tool is flagging it for that reason.

  - These are both left in the shipped HTML. This points to a template locale-selection step that didn't strip its output.

## 3. Rendering & Accessibility
- **Missing alt text (16 images per QA):**
  - Hero and content images: `img_01_en.jpg`, `img_02.jpg` through `img_05.jpg`, and `img_06_en.jpg`.
  - Footer images: `rrss1b.jpg` through `rrss6b.jpg`, `latredes142.jpg` (twice) and `download_en_b.jpg`.
  - The hero images carry the content, so with images blocked they render blank. The social icons are unlabeled links for screen-reader users.
- **Invalid markup:** `<div style="mso-hide:all;">` is placed directly inside a `<table>`, around `<tr>`. A `div` is not a valid child of `table`. Clients differ in how they repair this, so rendering is inconsistent.
- **Viewport meta:** `content="width=device-width; initial-scale=1.0; maximum-scale=1.0; user-scalable=no;"`
  - It uses semicolons instead of commas, so it is non-standard.
  - `user-scalable=no` and `maximum-scale=1.0` block pinch-zoom (WCAG 1.4.4).
- **Link color:** the global `a { color: #999898; }` is about 2.8:1 against the `#ffffff` background. That is below the WCAG AA 4.5:1 minimum for any text link that doesn't override it inline.
- **External web font:** `<link href="https://fonts.googleapis.com/css?family=Roboto+Condensed...">` sits in `<head>`.
  - Most clients (Gmail, Outlook) strip it.
  - The inline fallback font stack needs to be checked.
- **`<title>Zara</title>`** is generic.
- **Positive:** the outer tables use `role="presentation"`, and the preheader is hidden with `display:none`.
