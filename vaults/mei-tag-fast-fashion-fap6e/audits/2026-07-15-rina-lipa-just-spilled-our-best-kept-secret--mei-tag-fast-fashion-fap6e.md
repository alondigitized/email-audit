# Rina Lipa just spilled our best-kept secret
**Score:** 8/10 · **Type:** Email audit · **2026-07-15**
## Executive summary

- Okay so ASOS drops a Rina Lipa collab email and I genuinely did a double-take. After the disastrous comma-first subject line on July 11 and the "okay we're back" reset on July 13, this feels like the actual glow-up. A real celebrity edit, real editorial photography, a model who looks like she found the piece organically rather than being plastered on a billboard — this is ASOS playing trend-ownership rather than trend-chasing, and that matters to me more than almost anything.
- That said, the execution has a split personality. The top half is confident, clean, and curator-coded. Then it staples on a sale banner and a brand-logo grid like someone in the marketing stack hit "insert boilerplate" right before sending. The Zara and H&M emails I've been tracking this week don't do that nearly as awkwardly — even H&M's editorial denim send from a few days ago held its lane without cramming a discount module below it. ASOS loses the thread halfway down and suddenly I'm not in a collab editorial anymore, I'm on a clearance floor.
- Would I click? Yes — "SHOP THE EDIT" is exactly where I'm going. Would I forward to a friend? Only the top half. Would I screenshot and post? Maybe if Rina's fits are actually available in my size when I land. Mark as read without clicking? No way — the Rina Lipa name pull was too strong.

## What's working

- **The Rina Lipa name in the subject line lands hard.** As someone who tracks who sets the trend vs. who copies it, naming the influencer upfront tells me ASOS got here first — this isn't a dupe-drop, it's a collab reveal.
- **"STEAL RINA'S STYLE" is the right CTA framing.** It's aspirational without being inaccessible, and "SHOP THE EDIT" below it is the most specific button copy ASOS has written in this recent send cycle.
- **The model casting is genuinely good.** Yellow draped top, wide-leg denim, green micro bag — that is peak summer 2026 editorial and it reads as trend-setting, not trend-following. Model's age and energy matches me, which is rare even for ASOS.
- **The layout is clean.** After the July 11 merge-tag disaster I was braced for another broken element. Nothing's broken here. The hierarchy flows — big model, hook copy, collab section — it works.
- **"Secret's out" is a smart reset of the subject intrigue.** The "spilled" angle in the subject becomes "Secret's out" in the hero and it pays off as a mini narrative arc. Small thing, but I felt it.

## What's weak

- **"ENTER NOW" as the hero CTA is a dead end.** Enter what? A contest? A quiz? A portal? It's the vaguest possible action label and it undercuts the confidence of everything around it. This is not how you treat a Rina Lipa drop.
- **The sale section is a full vibe collapse.** That hot-pink "Looking for the Sale?" module is bolted onto a carefully constructed editorial email like duct tape on couture. It feels like two different briefs fighting each other.
- **"SHOP OUR TOP BRANDS" at the bottom is filler I've never clicked.** Lacoste logos below a Rina Lipa campaign? No continuity. H&M's denim email didn't do this — it held its single lane.
- **"DOWNLOAD THE APP" as a CTA in this email is misplaced energy.** I'm already in the email. The collab should be converting me to product, not to app store.

## Recommendations

- 1. **Fix "ENTER NOW" — it's doing real damage to click intent.** Replace with "SHOP RINA'S PICKS" or "SEE THE EDIT" so the action is tied to the Rina narrative.
- 2. **Cut or move the sale section to its own email.** This collab deserved a standalone send. The pink sale strip undercuts the premium positioning of the Rina moment. If the sale must appear, put it in the footer — not a full-width banner.
- 3. **Add one product detail to the collab section.** Even "the exact yellow top she wore" or a visible item name lifts click confidence significantly. Zara at least shows the item name; ASOS leaves me guessing.
- 4. **Remove the top brands grid.** It's noise. The Rina collab is the brand signal this email needs to carry.
- 5. **Give the collab a timestamp or scarcity cue.** "Available now — collab pieces selling fast" costs nothing to write and would push me to click before scrolling away.

### 3. Rendering & Accessibility

**Critical — `-webkit-text-size-adjust: none` on `body`:**
```css
body, #body_style {
  -webkit-text-size-adjust: none; /* ← breaks user zoom on iOS */
}
```
Should be `100%`, not `none`. Using `none` suppresses iOS Mail's automatic text resizing AND overrides the user's system accessibility font-size setting. This violates WCAG 1.4.4 (Resize Text). Fix: `body { -webkit-text-size-adjust: 100%; -ms-text-size-adjust: 100%; }`.

**Low — SVG font format included (deprecated):**
```css
url("https://images.asos-media.com/notification/content/fonts/FuturaPT-Book.svg") format("svg")
```
SVG fonts have been unsupported since iOS 4.2 (2010) and deprecated in CSS Fonts Level 4. Including them adds unnecessary payload on every open. Remove both SVG entries from `@font-face`; woff2 and woff cover all relevant email clients.

**Low — Media query breakpoint at 460px:**
```css
@media screen and (max-width:460px) { ... }
```
Standard email mobile breakpoint is 600px. Devices between 460px–600px viewport width (e.g., large Android phones in split-screen, Samsung Galaxy tablets) receive no responsive overrides. This could cause layout breakage in the `*[class=mob*]` grid columns at those widths.

**Low — `font-size: 0em` global table reset without confirmed cell reset:**
```css
table, tr, td, th { font-size: 0em; }
```
This is the standard zero-gap fix. Functional only if every content `<td>` resets font-size explicitly. If any content cell is missing the reset, text will render invisibly. Not verifiable from truncated HTML — confirm all `<td>` elements containing text reset to a non-zero `font-size`.

**Note — VML and conditional comment handling is correct:**
```html
<!--[if gt mso 15]> ... .vml-cta { display: block !important; } ... <![endif]-->
```
Outlook VML CTA pattern is properly gated. No issues.
