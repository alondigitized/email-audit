### 3. Rendering & Accessibility

**`user-scalable=no` in viewport meta — WCAG 1.4.4 violation**
```html
<meta name="viewport" content="width=device-width; initial-scale=1.0;
  maximum-scale=1.0; user-scalable=no;" />
```
Prevents pinch-to-zoom on mobile. This violates WCAG 2.1 SC 1.4.4 and is blocked by iOS Safari 10+ regardless, but should be removed.

**`line-height: auto` is invalid CSS**
```css
.heightmobile { height: auto!important; line-height: auto!important; }
```
`auto` is not a valid value for `line-height`. Valid values: `normal`, a unitless number, a length, or a percentage. This property will be ignored by conforming parsers, potentially collapsing line spacing on mobile.

**Duplicate `.bot40` declaration**
```css
.bot40 {padding-bottom: 40px!important;}  /* line ~1 of media query */
...
.bot40 {padding-bottom: 40px!important;}  /* line ~2 of media query */
```
Identical and harmless, but indicates copy-paste error in the stylesheet template.

**Google Fonts external `<link>` will not load in most clients**
```html
<link href="https://fonts.googleapis.com/css?family=Roboto+Condensed:400,700
  &display=swap&subset=cyrillic,cyrillic-ext" rel="stylesheet">
```
Gmail (both web and app), Outlook desktop, and several mobile clients strip or block external stylesheets. Roboto Condensed will silently fall back to whatever the client's default sans-serif is. No fallback stack is declared for body text.

**Invalid DOM structure in preheader block**
```html
<table ...>
  <tr><td>
    <table ...>
      <!--[if !mso 9]><!-->
      <div style="mso-hide:all;">
        <tr>   ← <tr> as child of <div> inside <table>
```
A `<div>` wrapping a `<tr>` directly inside a `<table>` is invalid in both HTML and the declared XHTML 1.0 Transitional. Browsers auto-repair it, but strict XML parsers and some email renderers will not. The preheader may be dropped or misrendered.

**Preheader hidden from Outlook via `mso-hide:all`**
The `<div style="mso-hide:all;">` wrapper prevents Outlook desktop from rendering the preheader node entirely. Outlook users will see no preview text.
