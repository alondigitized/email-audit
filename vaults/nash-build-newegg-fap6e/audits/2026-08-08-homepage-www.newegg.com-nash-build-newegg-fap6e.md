# Homepage snapshot · www.newegg.com · 2026-08-08
**Score:** 8/10 · **Type:** Site journey · **2026-08-08**
## Executive summary

- Newegg just walks up and speaks my language — combo deals, Shell Shocker, PC Builder, AI Hardware category all sitting right there above the fold. This isn't some lifestyle brand trying to sell me a vibe, it's a parts store that knows I'm here to spec a rig and save money doing it. Right now they're pushing a "Desk Setup Leveled Up" back-to-school hero plus a stacked AMD Ryzen 7800X3D combo deal, which is basically my Tuesday.

## What's working

- The AMD combo box ("Ryzen 7 9800X3D... Combo up savings $310.00") — this is exactly the kind of stacked-deal math I screenshot and send to my Discord build server.
- Shell Shocker module with the countdown-style deal card (MSI MAG X870 Tomahawk, 11% off, red price slash) — Shell Shocker is a Newegg signature and it's front and center, not buried.
- Left rail nav with "AI Hardware," "Components & Storage," "Computer Systems" one tap away — I don't have to hunt through generic mega-menu junk to get to GPUs.
- "Build with it" button on the AMD combo — that's a direct hook into PC Builder, which is literally my favorite tool on this site.
- Memory Finder banner ("Select the Right RAM") — smart compatibility-first tool placement, speaks to someone who actually cares about specs matching.

## What's weak

- No GPU-specific deal visible above the fold — for a Black Friday GPU hunter like me, that's the one category I scan for first and it's not front-loaded here.
- The Celeste chat bubble ("Hi, Celeste here! I'm now available as you browse the website too") pops up unprompted and partially overlaps the Memory Finder banner — feels like a chatbot interrupting my scroll.
- No loyalty/rewards balance or "Welcome back" personalization visible — it just says "Welcome / Sign In/Register," so it doesn't feel like it recognizes me as a repeat shopper.
- Bottom banner cuts off mid-word ("Massive") right at the screenshot edge — can't tell what that promo even is yet, feels like layout tension right where the fold is.

## Recommendations

- Swap one of the two combo-deal boxes for a GPU combo card (RTX 5070/5080 + PSU bundle) since that's higher-intent for the Black Friday GPU crowd than a prebuilt ABS desktop.
- Add a small "Rewards balance / EggPoints" chip near the account icon so returning shoppers like me see loyalty value without a click.
- Delay or shrink the Celeste chat bubble so it doesn't stack on top of the Memory Finder banner on first load.
- Give the Shell Shocker deal a visible countdown timer (not just "See all") — urgency copy is the whole point of that deal format and it's currently just a static discount badge.
