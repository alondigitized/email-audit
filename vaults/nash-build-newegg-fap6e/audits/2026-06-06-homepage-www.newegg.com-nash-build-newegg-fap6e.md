# Homepage snapshot · www.newegg.com · 2026-06-06
**Score:** 7/10 · **Type:** Site journey · **2026-06-06**
## Executive summary

- Newegg is my home turf and this page makes that obvious immediately — Shell Shocker and PC Builder are literally two of the first things I see in the nav. Right now they're pushing what looks like a celebration sale with a BNPL option and an AMD + MSI combo deal. The RGB hero imagery is pure builder energy, even if I can barely see it because the category nav drawer is eating the entire left half of the screen.

## What's working

- **Shell Shocker in the secondary nav** — this is the first thing I check every morning. Having it surfaced as a top-level nav item is exactly right; it tells me Newegg knows their audience.
- **PC Builder tool front and center** — one tap to check compatibility on a combo before I pull the trigger. Zero friction for my core workflow.
- **AMD Ryzen + MSI combo card** — product-level pairing visible above fold. Combo deals are literally how I shop Newegg; this is the right move.
- **RGB hero image** — even partially obscured, the multicolor lighting immediately signals "PC build site," not a generic electronics store.
- **Category nav depth** — Components & Storage is literally the first item. I can reach my category in one tap.

## What's weak

- **Nav drawer is open and covering the hero** — I can only see slivers of the main promo content. On mobile this is a real engagement killer; the promotional real estate behind it is completely wasted.
- **No account/loyalty state** — "Hello Select address" means I'm either not logged in or haven't set a delivery address. No EggPoints balance, no member hook, nothing pulling me toward spending.
- **"BUY NOW, PAY OV[ER...]"** is cut off — if that's the main value prop, it's literally unreadable in this viewport state.
- **"CELEBR[...]"** headline is clipped — I can't tell what event this is without dismissing the nav. The entire campaign is hidden behind a UI layer.
- **No urgency signal visible** — Shell Shocker usually has a live countdown timer. I can't see it here, which kills the time-pressure mechanic that makes Shell Shocker work.

## Recommendations

- **Auto-collapse the nav drawer on mobile page load** — let the hero and active promo breathe first. The category list can live in the hamburger; don't open it by default and bury the entire promotional surface.
- **Surface EggPoints balance in the header when logged in** — even "1,240 pts" next to an avatar icon would create a re-engagement pull and loyalty hook that's currently invisible.
- **Pin the Shell Shocker countdown timer above the fold** — that urgency mechanic is Newegg's biggest weapon with buyers like me. It should be unmissable, not hidden behind a nav state.
- **Make the AMD combo card full-width on mobile** — the Ryzen + MSI pairing is a great deal but it's partially clipped in the right column. Let it be the full-width hero it deserves to be.
