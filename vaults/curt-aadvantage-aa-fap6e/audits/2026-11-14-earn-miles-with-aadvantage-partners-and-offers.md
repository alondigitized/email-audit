- The hero headline is short and benefit-led, and the "Find tickets" button is clear.
- Each tile has its own specific CTA, such as "Upgrade & earn," "Book now" and "Find a rental."
- Concrete numbers appear in the tiles: 7,500 miles, 1,000 miles, and up to 35% off base rates.
- The dark theme with blue buttons is consistent, and the button contrast is good.
- The hotel and phone offers have visible deadlines (Nov. 30, Jan. 7).

- The email has no single hero offer. The headline promises events, but the body is mostly phone, gift cards, hotels and cars.
- The hero copy, "Earn miles on live events, or use your miles for tickets," gives no amount and no specific event.
- The footer has a broken or empty bordered box beside the App Store badge, and small broken-image icons.

- The email has no personalization or member status, and the "Gift cards" tile has no offer at all.

- 3. Fix the footer's broken images and the faint header text before the next send.
- 4. Move the fine print behind a short "Terms apply" link, or shorten it.
- 5. Put the deadline in the hero, not only in the tiles.

## Technical Audit

## 1. Technical Summary
The HTML structure is mostly sound: it has a preheader, MSO conditionals and a dark-mode block. The automated QA run (17% pass) flags 7 link failures, but most look like probe artifacts rather than confirmed defects. The confirmed problems are a relative-path background image, accessibility-hostile viewport and text-size settings, an `http://` image, and a malformed destination URL on the events link.

## 2. Link & Tracking Issues
- **"Upgrade & earn" (h=6694078), "doubled-domain" FAIL (reported twice).** Probably a false positive. The decoded `x=` param is `www.aa.com/web/i18n/aadvantage-program/earn-miles/att-offer.html?c=EML||20261113|MKT|USMCOC|PTR|ERINC|PNL||US_LYLTY_TRAN_Device_Upgrade`. That is a single destination domain wrapped by the `l.loyalty.ms.aa.com` redirector, with no merge error visible. Fix the QA rule rather than the email.
- **"Find tickets" (h=6694075), >10 redirects.** The destination is `www.aadvantageevents.com%3F_uid%3D…%26utm_campaign%3DPartner_Newsletter%3F%3F`. It has no `/` before `?` and ends in a stray `??`, so the final `utm_campaign` value becomes `Partner_Newsletter??`. That is a real defect in the URL. The redirect loop itself may come from the probe lacking cookies, so it needs a manual check.
- **"Book now" (h=6694076), TLS error `TLSV1_ALERT_PROTOCOL_VERSION`.** Unconfirmed. The target `www.aadvantagehotels.com` rejected the probe's TLS handshake. This is likely a probe client limitation, but verify with a modern client.
- **403s ("Find a rental", "American Airlines", "You are why we fly").** Unconfirmed. These are most likely bot or WAF blocking of the scanner on `aadvantagecars.com` and the `c|EML|PNL|…` tracking-code destinations. Do not treat them as broken for subscribers without a browser-based check.
- **Probe coverage.** The report shows "12 probed, 12 skipped", so link validation is incomplete. Footer and unsubscribe links were not verified in this report.

## 3. Rendering & Accessibility
- **Relative background URL (confirmed).** `#swapbg { background-image: url("20230508_HTML-32134_M_bg.png") }` in the mobile media query has no host or path. It will 404 in every client, so the mobile background swap fails.
- **Insecure image (confirmed).** The "oneworld logo" uses `src="http://i.loyalty.ms.aa.com/wpm/1021/ContentUploads/american_airlines/CTAs/oneworld_logo_special_online_80x80.gif"`. Clients may block it or show mixed-content warnings. Switch it to `https://`.
- **Zoom blocked (confirmed).** `<meta name="viewport" … maximum-scale=1>` prevents pinch-zoom, which fails WCAG 1.4.4 for resize.
- **Text resizing disabled (confirmed).** `* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; line-height: 100% }` blocks user text scaling and cramps line height globally.
- **Dark-mode risk.** `@media (prefers-color-scheme: dark) { span, a, td { color: #ffffff !important } }` forces white text on every cell, but only `.lightblue-bg` and `.cta-bg` get background overrides. Any cell with a light background that isn't covered by those classes would render white-on-light. This is not confirmed from the truncated source, so test it in Apple Mail and Outlook dark mode.
- **Duplicate MSO block.** The identical `<!--[if gte mso 9]>` style block appears twice. It is harmless but wasteful.
- **Web font dependency.** Roboto is loaded via both `<link>` and `@import`. Gmail and Outlook strip both, and the fallback stack is only declared in the MSO block.
- **Alt text** could not be assessed because the HTML is truncated.

## 4. Personalization & Merge Tokens
No issues found. No unresolved tokens (`{{…}}`, `%%…%%`, `[[…]]`) appear in the visible source. The "doubled-domain merge error" flags are false positives (see section 2).

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- `List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) were not found, and `Authentication-Results` was missing. The QA report attributes this to the AgentMail relay, so these are inconclusive rather than confirmed violations. Check the raw message headers from the original delivery.
- The physical address and unsubscribe link are not visible in the truncated HTML, so they cannot be confirmed either way.
- The sending domain `loyalty.ms.aa.com` and the tracking domain `l.loyalty.ms.aa.com` are aligned.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- Hotels: UTMs are present (`utm_source=partner-newsletter`, `utm_medium=email`, `utm_campaign=partner-placement`, `utm_content=search-hotels-cta`).
- Events: UTMs are present, but the URL is malformed (see section 2). `utm_source=AA_Mailer` is also inconsistent with the hotels link's `partner-newsletter`.
- Cars: `?clientID=399986` only, with no UTMs, so campaign attribution is missing.
- AA-owned links use the proprietary `c=EML|…|20261113|…` code instead of UTMs, which is consistent internally.
- The three partner links use three different UTM schemes.

## 7. Recommendations
1. Change the `http://` oneworld logo `src` to `https://`.
2. Replace the relative `#swapbg` URL with an absolute HTTPS URL.
3. Remove `maximum-scale=1` and the `-webkit-text-size-adjust: none` rule. Set line-height per element instead of `* { line-height: 100% }`.
4. Fix the events destination to `https://www.aadvantageevents.com/?_uid=…&utm_…=Partner_Newsletter` with no trailing `??`.
5. Add UTMs to the `aadvantagecars.com` link, and standardize the partner UTM scheme.
6. Add dark-mode background overrides for all containers, or scope the `td { color: #fff }` rule to the classed cells.
7. Re-run the 403 and TLS links in a real browser or modern HTTP client before treating them as broken.
8. Tune the QA doubled-domain rule so it doesn't flag redirector `x=` parameters, and capture raw headers so the compliance and authentication checks can resolve.
