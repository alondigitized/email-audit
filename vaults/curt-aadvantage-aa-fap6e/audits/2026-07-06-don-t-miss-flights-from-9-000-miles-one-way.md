# Don't miss: Flights from 9,000 miles one way
**Score:** 8/10 · **Type:** Email audit · **2026-07-06**
## Executive summary

- This is a near-verbatim replay of the June 22 send — same 9,000-miles hook, same destination grid, same "Find Flights" CTA — with "Don't miss:" prepended to the subject as manufactured urgency. Fourteen days is too short a gap to repeat the same creative; any member who received both sends will clock the repeat instantly, and the fake-scarcity prefix makes it worse rather than better.
- Inside the email, the execution is solid: destination grid is clean, mileage prices are legible, and the account summary at the bottom is a genuinely smart personalization touch. But five CTAs across four separate content blocks ("Find Flights," two "Book today" buttons, "View your offer," "Book your vacation") diffuse focus. There is no deadline, no fresh angle, no new reason to act compared to the June 22 send.
- The verdict: if you clicked on June 22, this is redundant. If you didn't, "Don't miss:" is not the argument that closes you.

## What's working

- **Mileage price is explicit and prominent**: "9,000 miles one way" appears in subject, hero copy, and the destination sections — no confusion about what's on offer.
- **Destination grid delivers aspiration**: The U.S. city photos and Mexico/Caribbean imagery give the email real visual pull.
- **Account summary is personalized**: Miles balance and Loyalty Points at the bottom are a nice reminder of what's at stake for the specific member.
- **Clean render throughout**: No broken images, no overlapping elements, no layout bugs visible.
- **"Find Flights" is immediately visible**: High-contrast blue button above the fold, easy to find without scrolling.

## What's weak

- **Subject is a lazy re-send signal**: "Don't miss: Flights from 9,000 miles one way" is the June 22 subject with a five-word urgency prefix — a subscriber receiving both will see through it.
- **No credible deadline**: "Don't miss" implies scarcity but there is no expiry date, no seat count, nothing to back the urgency up.
- **Five competing CTAs**: Find Flights + Book today × 2 + View your offer + Book your vacation scatter attention instead of driving a single conversion.
- **Miles-buying and Mastercard sections undercut the core message**: They introduce new asks (buy miles, open a card) that muddy what should be a clean redemption pitch.

## Recommendations

- 1. **Put a real date in the creative.** If the 9,000-mile fares expire, say when. "Book by July 20" in the hero — and subject — turns vague urgency into a decision point.
- 2. **Don't repeat the same offer inside two weeks.** Waiting until week four or five, or leading with genuinely new routes, would restore the impact this offer had on June 22.
- 3. **Consolidate to one CTA.** "Find Flights" should be the only button. Remove the Mastercard and miles-buying modules entirely for this send.
- 4. **Lead with a specific aspirational route.** "NYC → Cancún from 9,000 miles" outperforms a generic grid every time. Pick one hero destination and build the email around it.
- 5. **Drop "Don't miss:"** — it signals filler urgency and adds seven characters of dead weight. The specificity already in the subject does the work.

### 3. Rendering & Accessibility

**[HIGH] Broken relative image path in mobile CSS**
```css
#swapbg {
  background-image: url("../20230508_HTML-32134_M_bg.png")
}
```
Relative paths do not resolve in email clients. This mobile background image will silently fail to load for all recipients on viewports ≤480px. Path must be an absolute CDN URL.

**[MEDIUM] Unclosed `@media` block in dark mode CSS**
The `@media (prefers-color-scheme:dark)` block has no closing `}` before `</style>`. The browser/client CSS parser closes it implicitly, but behavior varies — some clients will drop all dark mode rules or bleed the ruleset into surrounding styles. Explicit closure required.

**[MEDIUM] Over-broad dark mode color override**
```css
span, a, td { color: #ffffff !important; }
```
Forces white on all anchors, spans, and cells in dark mode with no selector scoping. Any dark-background content area will render white-on-white text. Should be scoped to specific class selectors.

**[LOW] Duplicate `<!--[if gte mso 9]>` conditional blocks**
The identical MSO font-family style block appears twice in `<head>`. One copy is dead weight that adds ~400 bytes and creates maintenance confusion. Remove the duplicate.

**[LOW] Duplicate Google Fonts loading**
Fonts are requested via both `<link href="https://fonts.googleapis.com/css2?family=Roboto...">` and `@import url('https://fonts.googleapis.com/css2?family=Roboto...')` in a `<style>` tag. In clients that support external fonts, this fires two HTTP requests for the same resource. Keep one; convention in email is `@import` for broader fallback coverage.

**[LOW] `maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Blocks user-initiated zoom on mobile. Fails WCAG 1.4.4 (Resize Text, Level AA). Recommend removing `maximum-scale=1`.
