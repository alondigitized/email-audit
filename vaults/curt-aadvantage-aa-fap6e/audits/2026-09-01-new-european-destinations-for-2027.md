# New European destinations for 2027
**Score:** 5/10 · **Type:** Email audit · **2026-09-01**
## Executive summary

- This is a legitimate route-announcement email, and it's the strongest send I've seen from American in weeks — a clean, single-topic hero (three new PHL routes to Reykjavik, Vienna, Porto) followed by four well-photographed destination tiles, each with its own CTA. It finally has a real news hook instead of another recycled loyalty-program teaser or partner grab-bag like the Aug 17 "Use miles for memories" send.
- The problem is the same one that's dogged every recent send: Curt's AAdvantage box still shows "0 Award Miles" and "0 Loyalty Points," the exact same dead-account signal from the Aug 28 account-summary email. For a brand pushing "book now" on new routes, showing a member with zero balance and zero status undercuts any loyalty angle and makes the tile feel bolted on rather than personalized.
- Net: good creative, real news, clear CTAs — but it's future inventory (summer 2027 booking for PHL–KEF/VIE/OPO), so urgency is genuinely low, and the loyalty module is dead weight again.

## What's working

- Single clear hero message ("New destinations are taking off") with a bold "Book now" CTA above the fold.
- Four distinct destination tiles, each photographed well and each with its own specific CTA ("Search flights," "Browse flights," "Book now," "Book today").
- Copy is specific — actual airport codes and cities (PHL to KEF, VIE, OPO) rather than vague "explore Europe" language.
- No render bugs — images load cleanly, layout is consistent, no overlapping text.
- Genuine news hook (new routes for 2027), a real break from recycled loyalty-roadmap and partner-offer content.

## What's weak

- No fare, price, or introductory-offer anywhere — pure inspiration, zero conversion incentive.
- AAdvantage module again shows 0 miles / 0 points for Curt, the same flat, unpersonalized loyalty signal as the Aug 28 send.
- No urgency: routes don't launch until "next summer" 2027, so there's no reason to act today.
- "Book now" appears three times across different tiles with identical styling — no differentiation for which destination is the actual priority.

## Recommendations

- 1. Add a fare anchor ("Fares from $X") to at least the hero CTA — right now there's nothing to click toward except a bare search page.
- 2. Replace the flat 0/0 AAdvantage box with either a hide-if-zero rule or a route-relevant nudge ("Earn miles on these new routes") instead of a static account balance.
- 3. Add a soft urgency device tied to something real — "Reservations open [date]" or early-booking fare — since the routes themselves don't launch for a year.
- 4. Vary the CTA copy per tile more (it's already close — "Search," "Browse," "Book," "Book" — consider making the last one "Explore all routes" since it's a multi-city link, not a single destination).

- **Subject Alt B:** `Reykjavik, Vienna, Porto: new for 2027`
- **Preheader Alt A:** `Nonstop from Philadelphia — reserve early access`
- **Preheader Alt B:** `Iceland, Austria and Portugal join the map`
