# 30% Off New Sweater Arrivals
**Score:** 7/10 · **Type:** Email audit · **2026-10-12**
## Executive summary

- This is a clean, on-brand sweater send, and it is the weakest kind of Everlane email: one more 30% Friends & Family blast. The subject, hero and grid agree. A model in a grey crew over denim, "New In: Sweaters", a black SHOP NOW bar and six colorways in the grid. Nothing is broken and the eye lands on the hero first.
- It is also the same email I've seen all week. "Get Cozy While It's 30% Off" and "We Added An Extra 10% Off" both landed earlier today. "Cozy Styles at 30% Off" and "30% Off Better Cashmere" went out yesterday. This one adds nothing new: no end date, no price, no reason to act now. The only "new" is the word "New" in the hero.
- Judgement: competent but forgettable, and it will blur into the other seven. It's a fine reminder, but it does nothing for a subscriber who has already ignored the offer.

## What's working

- The hero is clear. One model, one sweater and a full-width black SHOP NOW bar make the action obvious.
- The subject matches the creative. "Sweaters" in the subject is "Sweaters" in the hero, so there is no bait-and-switch like the cashmere/puffer mismatch on 10/11.
- The 30% banner sits in the blue header above the logo, so the offer is seen before any scrolling.
- The six-tile grid is tidy and shows a useful color range: cream, chocolate, grey, black, navy and brown.
- The layout is clean, with no broken images or overlapping text.

## What's weak

- There is no deadline in the visible body. "Ends 10.13" appears only in the grey fine print at the bottom, so the urgency is buried.
- The grid tiles have no names, prices or sale prices. Nothing shows what 30% off actually saves.
- "SHOP NOW" appears twice and tells the reader nothing specific. The grid also doesn't look clearly tappable, so it is unclear which sweater a click leads to.
- The "BETTER PRICES, STILL EVERLANE" block repeats the offer a third time and takes up a lot of space without adding information.
- The "30% off sitewide & storewide" header sits against fine print that says "select styles", which makes the offer feel less honest.
- The "PS:" line is placed before the grid, not at the end. It reads as filler.

## Recommendations

- 1. Put the deadline in the hero: "Ends tomorrow, 10/13" in the header band, or "Last day" in the subject. Today's send is the best chance to use real urgency, and the existing promo already supports it.
- 2. Add a name and price line under each sweater tile, such as "Cashmere Crew $X → $Y", and link each tile to its product page.
- 3. Replace the generic CTA with a specific one, such as "Shop New Sweaters" or "Shop Cashmere Crew".
- 4. Remove the "BETTER PRICES" block, or swap it for a social-proof strip (reviews or a bestseller tag).
- 5. Cut the cadence. Send one strong Friends & Family email on the last day, not a daily near-duplicate.

- **Preheader Alt A:** `Six new colors in cashmere and wool. Friends & Family ends 10/13.`
- **Preheader Alt B:** `Last day for 30% off sitewide. Fresh knits just landed.`

## Technical Audit

## 1. Technical Summary
The email is a Klaviyo-built template that tracks clicks through `trk.send.everlane.com`. The one confirmed failure is a tracked link whose redirect target is a relative path. The header checks (List-Unsubscribe, Authentication-Results) could not be verified because of the AgentMail relay. The HTML source was truncated, so the body was only partly auditable.

## 2. Link & Tracking Issues
- **[FAIL] Relative redirect target.**
  - Link text is "Everlane", at `https://trk.send.everlane.com/l/01M4RXXD1H338NZ5N3P8GDPKXF_3`.
  - The probe reported `unknown url type: '/pages/womens?_kx=…&bxid=01KRSAQRJKNNCKD9WS2NMXDB0V&cm_flow_i…'`.
  - The path has no scheme or host. This suggests the tracker's redirect returns a relative `Location`, or the probe failed to resolve it.
  - Browsers resolve a relative `Location` against the tracker host (`trk.send.everlane.com/pages/womens`). That would 404 if it is real.
  - **Unconfirmed:** this could be a probe-side redirect-handling artifact. Re-test with `curl -sI` and check the raw `Location` header.
- **Coverage gap:** only 12 of 29 links were probed and 17 were skipped. The other 17 are unverified, not known good.

## 3. Rendering & Accessibility
- **Missing alt text:** the only flagged image is `https://trk.send.everlane.com/o/01M4RXXD1H338NZ5N3P8GDPKXF`. The `/o/` path indicates an open-tracking pixel. This is low severity, but it should carry `alt=""` so screen readers skip it.
- **Empty title:** `<title> </title>` contains only whitespace. This is minor and affects only web-view rendering and clients that show the title.
- **No other issues found in the visible source.** It has the viewport meta, MSO conditional comments, Outlook fix classes and mobile media queries. The rest of the body was truncated.

## 4. Personalization & Merge Tokens
No issues found. No unrendered tokens (`{{ }}`, `{%`, `*|…|*`) appear in the visible source or in the QA output.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe and List-Unsubscribe-Post (RFC 8058):** both are not found. QA attributes this to the AgentMail relay possibly stripping headers, so it is **unverified, not confirmed missing**. Check the raw message in a direct-delivery test, such as a seed Gmail inbox.
- **Authentication-Results:** not found, so SPF, DKIM and DMARC status is unknown. The cause is the same relay limitation.
- **Unsubscribe link and physical address:** the QA summary says an unsubscribe link is always probed, but no result is shown. The footer was truncated, so the in-body unsubscribe link and postal address could not be confirmed.
- **Sender:** `support@everlane.com` is a support mailbox used as the marketing From address. This is not a violation, but replies go to a support queue.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- The one visible destination carries Klaviyo params (`_kx`, `bxid`, `cm_flow_i…`) but no `utm_source`, `utm_medium` or `utm_campaign`. The string is truncated, so UTMs may sit later in the URL.
- The landing page is `/pages/womens`, a general women's page. The subject is "30% Off New Sweater Arrivals". This link is labeled "Everlane", so it is probably the header or logo link. Whether the CTAs go to a sweater collection could not be checked.
- Because of the relative-path failure above, the email-to-site handoff is unverified for this link.

## 7. Recommendations
1. Re-test the tracked link `…/l/01M4RXXD1H338NZ5N3P8GDPKXF_3` with `curl -sI` and inspect the raw `Location` header. If it is relative, fix the tracker or redirect configuration so it returns an absolute `https://www.everlane.com/pages/womens?…`.
2. Verify List-Unsubscribe and List-Unsubscribe-Post on a direct-delivery copy. Confirm SPF, DKIM and DMARC alignment from the headers there too.
3. Add `alt=""` to the `/o/` tracking pixel. Set a non-empty `<title>`.
4. Raise the probe cap beyond 12 links, or add a pass over the remaining 17, so more links are checked.
5. Confirm that `utm_*` parameters are present on the CTAs, and that sweater-specific CTAs land on a sweater collection page.
