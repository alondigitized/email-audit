# 30% Off Sitewide, Starting Now
**Score:** 8/10 · **Type:** Email audit · **2026-05-20**
## Executive summary

- This is Everlane's Memorial Day sale launch — and the offer escalation is the real story. After four emails pushing 20% off since May 16, the jump to 30% sitewide is the first genuinely new news Everlane has sent this week. The creative is classic Everlane: editorial model in a yellow sweater, bold "30% OFF SITEWIDE" overlay, single teal SHOP NOW button. Clean, legible, no gimmicks.
- But the email leaves conversion on the table in one obvious way: there is no end date anywhere. "Starting Now" tells subscribers the sale has kicked off — which is useful for early engagement — but without "Ends Monday" or "48 Hours Only," there is no compelling reason to click today rather than tomorrow. For a Memorial Day sale, this is a meaningful miss.
- This is the best promotional send in Everlane's recent sequence because the offer is real and the framing is honest. It is not, however, a high-urgency email — it is a clean announcement that expects the discount alone to do the work.

## What's working

- **Offer escalation lands clearly**: 30% off sitewide is a meaningful step up from the 20% that ran for four days — subscribers paying any attention will notice the upgrade.
- **Visual hierarchy is clean**: Logo → hero model → "30% OFF SITEWIDE" overlay → teal SHOP NOW button — the eye follows the right path with no clutter.
- **Subject line is the most direct in the sequence**: No reverse-psychology ("You Don't Want To Save?"), no vague editorial — just the offer and timing, 30 characters, no spam signals.
- **Memorial Day framing is timely**: The "MEMORIAL DAY EVENT" label contextualizes the discount seasonally without being overdone.
- **Secondary CTAs add navigational value**: SHOP NEW ARRIVALS / SHOP CULT FAVES / SHOP DENIM / SHOP TEES give subscribers meaningful category entry points beyond a generic homepage dump.

## What's weak

- **No end date means no urgency**: "Starting Now" announces the sale's arrival but gives no reason to act today. For a holiday with a hard Monday endpoint, this is the most actionable miss in the email.
- **Body copy below the hero is wasted space**: "The foundation of a better wardrobe, all in one place. From new arrivals to the pieces you wear most." is evergreen filler — it could run on any Everlane email, any day, any year.
- **No specific product or price point**: A single hero item — "The Organic Tee: was $40, now $28" — would make the 30% feel concrete rather than abstract.
- **Six emails in five days dilutes every send**: After this cadence, "Starting Now" lands with less urgency than it would have at a lower send frequency. Subscribers are already trained to wait and see.

## Recommendations

- 1. **Add an end date** — "Ends Monday at midnight" in both the subject line and the hero overlay. This is the single change that would lift click-through more than anything else.
- 2. **Rewrite the body copy below the hero** with the offer mechanic: "30% off everything sitewide — no code needed, discount applied at checkout." Functional copy beats brand copy in a promotional email.
- 3. **Anchor one hero product with before/after pricing** — the yellow sweater in the hero is compelling; give it a name, a price, and a direct product link.
- 4. **Consider holding one email next week** — the cadence this week has trained subscribers to wait for the next email rather than act on any individual one.

## Technical Audit — Everlane "30% Off Sitewide" Email

### 1. Technical Summary

Email is built on Klaviyo's MJML-based infrastructure with MSO conditional comments for Outlook compatibility. Several low-severity HTML/CSS issues are present; the HTML is truncated, preventing full verification of compliance elements and link tracking.

---

### 2. Link & Tracking Issues

**Cannot fully verify** — HTML is truncated before any `<a href>` tags appear in the body. The following must be confirmed against the full source:

- UTM parameters on all CTA links (`utm_source`, `utm_medium`, `utm_campaign` at minimum)
- Klaviyo click-tracking wrapper applied to all URLs (expected pattern: `trk.klaviyo.com` redirect)
- No raw `everlane.com` links bypassing tracking

**Confirmed observable:** External font loaded via `@import url(https://static-forms.klaviyo.com/fonts/api/v1/USb9mf/custom_fonts.css)` — this is a render-blocking request; if Klaviyo's CDN is unavailable, fallback stack (`Arial, Helvetica Neue, Helvetica, sans-serif`) activates silently.

---

### 3. Rendering & Accessibility

**Empty `<title>` tag:**
```html
<title> </title>
```
Contains only whitespace. Screen readers and some preview pane renderers (Gmail web) use `<title>` as the accessible document label. Should be set to the subject line or a descriptive string.

**Duplicate `img` CSS rule block:** The `img` rule appears twice in `<style>`:
```css
img { border: 0; line-height: 100%; outline: none; text-decoration: none; -ms-interpolation-mode: bicubic }
/* ... later ... */
img { border: 0; height: auto; line-height: 100%; outline: none; text-decoration: none; max-width: 100% }
```
The second block does not carry `-ms-interpolation-mode` and omits `height: auto` from the first. Merging these eliminates the redundancy and ensures consistent Outlook image scaling.

**Inconsistent responsive breakpoints:** Most mobile overrides target `max-width: 480px`, but the `.hide` utility class uses `max-width: 600px`:
```css
@media screen and (min-device-width: 10px) and (max-width: 600px) { .hide { ... } }
```
Elements toggled with `.hide` will be suppressed 120px wider than all other responsive behavior, potentially hiding content on tablets that the rest of the layout treats as desktop.

**Link color accessibility:** Global rule removes all link differentiation:
```css
a:not([name]) { color: #000; text-decoration: none }
```
If CTA buttons rely solely on background color (not confirmed from truncated HTML), links in body copy will be visually indistinguishable from surrounding text — fails WCAG 2.1 SC 1.4.1 (Use of Color).

**Image alt text:** Not verifiable from truncated source. Must confirm all `<img>` tags carry non-empty `alt` attributes, particularly hero and product images.
