## Technical Audit

## 1. Technical Summary
The email has one hard QA failure: the tracked "Everlane" link redirects to a relative URL that the checker could not resolve. Authentication and unsubscribe-header checks could not be evaluated because of the AgentMail relay, so they are unverified rather than confirmed failures. The HTML is truncated, so findings below cover only what is visible in the source and the QA data.

## 2. Link & Tracking Issues
- **[FAIL] Relative redirect target.** `https://trk.send.everlane.com/l/01M801QVN5EQHJZZY42HV9V2C1_3` (link text "Everlane") resolves to `/pages/womens?_kx=…&bxid=…&cm_flow_i…`, which has no scheme or host. A relative `Location` header is legal under RFC 7231, so this may be a probe limitation rather than a real break. Mail clients and browsers resolve it against the tracking host, though. If Klaviyo's redirector sends it without rewriting it to `https://www.everlane.com/pages/womens`, the click would land on `trk.send.everlane.com/pages/womens`, which is likely a 404. This needs a manual click-through to confirm.
- **Probe coverage is partial.** 12 links were probed and 22 skipped. Footer, utility and social links were deprioritized, so their status is unknown. The 43% pass rate partly reflects this.
- **Tracking pixel without alt.** `https://trk.send.everlane.com/o/01M801QVN5EQHJZZY42HV9V2C1` has no `alt`. This is the open-tracking pixel, so it is low severity. Adding `alt=""` is still the correct markup.

## 3. Rendering & Accessibility
- **Empty title.** `<title> </title>` contains only whitespace. Some clients and screen readers use it as the document name.
- **Small mobile text.** `@media (max-width:480px) { h4 { font-size: 10px !important; line-height: 1.3 !important } }` shrinks any `<h4>` to 10px on mobile. That is below the common 11–14px minimum for legibility. Whether it matters depends on whether `<h4>` carries real content in the truncated body.
- **Links have no visual affordance.** The global rules `a:link, a:visited, a:active, a:hover { color:#000; text-decoration:none }` strip underlines and colour from all links. Inline text links are then distinguishable only by context, which is a WCAG 1.4.1 risk.
- **Web font via `@import`.** `@import url(https://static-forms.klaviyo.com/fonts/api/v1/USb9mf/custom_fonts.css)` is ignored by Gmail and several other clients. The font stacks fall back to Arial/Helvetica, so this is graceful.

## 4. Personalization & Merge Tokens
No issues found. No unrendered tokens such as `{{ first_name }}` or `*|FNAME|*` appear in the visible source.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe and List-Unsubscribe-Post not found.** The QA notes AgentMail may not capture these headers, so this is unverified, not confirmed missing. Check the raw `.eml` or the sender's ESP settings (Klaviyo normally adds both).
- **Authentication-Results not found.** SPF, DKIM and DMARC status is unknown for the same reason. The visible sender is `support@everlane.com` while links use `send.everlane.com`, so alignment is plausible but unconfirmed.
- **Unsubscribe link.** The QA says one is always probed and reported no failure. Its presence in the footer cannot be confirmed from the truncated HTML.

## 6. Email-to-Site Continuity
- **No UTM parameters visible.** The only fully visible destination carries Klaviyo identifiers (`_kx`, `bxid`, `cm_flow_i…`) and no `utm_source`, `utm_medium` or `utm_campaign`. The parameter string is truncated, so UTMs may follow. Klaviyo's `_kx` token supports attribution on its own, so a missing UTM set would only limit analytics outside Klaviyo.
- **Destination alignment.** The link text is "Everlane" and it goes to `/pages/womens`. The subject, "The Best Merino Around", suggests a merino collection page. The generic link text and women's landing page cannot be checked against the body, which is truncated.

2. Verify `List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) and SPF/DKIM/DMARC from the original message source, not the relay copy.
