# 30% Off The Denim You Need
**Score:** 9/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- This is Everlane's fourth Memorial Day re-send in four consecutive days — the same 30% sitewide offer, now pivoted to denim. The category-pivot strategy (sitewide → dresses+sandals → linen → denim) is the correct playbook and the subject line is the strongest of the wave: "30% Off The Denim You Need" is specific, benefit-led, and short. The email body holds up: a clean hero, a tight product grid of six denim silhouettes, and two clear CTAs.
- The execution problem is the hero saying "30% OFF SITEWIDE" while the subject promises a denim-specific angle. The two don't align — a subscriber expecting a denim-focused email opens to a generic sitewide banner they've already seen three times. The body redeems it somewhat with the product grid, but the hero is a retread.
- Day 4 of the same offer. Subscribers who were going to buy have already bought. The cohort left are the fence-sitters, and the play for them is deadline urgency — which this email has in spirit (Memorial Day Event) but not in fact (no "ends Monday" callout). That one line would do more than another category pivot.

## What's working

- Subject line is the sharpest in the wave — short, direct, category-specific, readable on mobile in one glance.
- Six-product denim grid gives real variety (shorts, straight, wide-leg; multiple washes) — subscribers can self-sort without guessing.
- "SHOP NEW ARRIVALS" as the secondary CTA is meaningfully different from "SHOP NOW" — gives the fence-sitter a non-sale reason to click.
- No render bugs — clean layout, images loaded, no overlapping text.
- Brand voice is consistent and restrained; Everlane doesn't oversell.

## What's weak

- Hero copy says "30% OFF SITEWIDE" — the denim angle promised in the subject dissolves instantly on open.
- No explicit deadline. "Memorial Day Event" implies urgency but without "Ends Monday" or "2 days left," fence-sitters don't feel the clock.
- "You Need These / New-in styles" section creates confusion inside a sale email — are new arrivals included in the 30% off? Unclear.
- Zero social proof anywhere in the email — not a single review quote, star rating, or bestseller tag on the denim grid.
- This is the fourth near-identical email in four days; cadence fatigue is real by now for subscribers who've opened all four.

## Recommendations

- 1. **Fix the hero headline to match the subject.** Change "30% OFF SITEWIDE" in the hero overlay to "30% OFF ALL DENIM" or "30% Off — Denim Picks." The category pivot is the creative hook; the hero needs to honor it.
- 2. **Add a hard deadline.** "Offer ends Monday" anywhere in the top half — hero, subhead, or a one-line callout under the button — is the single highest-lift addition. Memorial Day is this weekend; the implied urgency exists but isn't activated.
- 3. **Clarify new arrivals vs. sale.** Either move the "You Need These" module to a different send or add a one-line note ("New arrivals are included") so buyers aren't confused about what's actually discounted.
- 4. **Add one social proof anchor.** A bestseller badge on the top denim style in the grid, or a two-line pull quote, would give a fence-sitter the final nudge.

### 3. Rendering & Accessibility

**Empty `<title>` tag**
```html
<title> </title>
```
Whitespace-only `<title>` — some screen readers and the iOS/Android native mail clients surface this as the preview label. Should be a descriptive string (e.g. `"30% Off Denim — Everlane"`).

**All link colors forced to black, no underline**
```css
a:not([name]) {color:#000;text-decoration:none}
a:link    {color:#000;text-decoration:none}
a:visited {color:#000;text-decoration:none}
a:hover   {color:#000;text-decoration:none}
```
Links are visually indistinguishable from body text for colorblind users and keyboard navigators. WCAG 2.1 SC 1.4.1 requires a non-color differentiator when contrast ratio between link and surrounding text is < 3:1.

**`h4` mobile font-size drops to 10px**
```css
@media only screen and (max-width: 480px) {
  h4 { font-size: 10px !important; line-height: 1.3 !important }
}
```
10px is below the 11px floor recommended by Apple/Google for mobile legibility. Likely to trigger auto-zoom in Safari.

**Duplicate `img` CSS block — `-ms-interpolation-mode` silently dropped**
Two `img` rules are declared; the second overrides the first and drops `-ms-interpolation-mode: bicubic`, which affects image sharpness in older Outlook versions. Consolidate into one block:
```css
img { border:0; height:auto; line-height:100%; outline:none;
      text-decoration:none; max-width:100%;
      -ms-interpolation-mode:bicubic }
```

**Responsive breakpoint mismatch**
Column stacking fires at `max-width: 480px`; the `.hide` utility class fires at `max-width: 600px`:
```css
@media screen and (min-device-width:10px) and (max-width:600px) { .hide { … } }
```
At 481–600px viewport widths, `.hide` elements are suppressed but columns have not yet stacked — potential layout gap on mid-size viewports (small tablets, large phones in landscape).
