# Don’t Miss Out: Extra 25% Off Sale
**Score:** 5/10 · **Type:** Email audit · **2026-09-07**
## Executive summary

- This is the fourth "Today Only: Extra 25% Off" variant in the brand history today, and by now the template is fully exhausted — same black "SHOP WOMEN'S SALE" / "SHOP MEN'S SALE" bar, same olive/cream text-over-photo hero split, same discount-stack framing ("already up to 70% off"). The hero photo this time is a soft, diffuse gold-and-white floral/watercolor blur — close in palette to the peony/tulip macro shot audited earlier today but even less distinct, almost abstract to the point of looking like a texture background rather than a product photo.
- There's no product shown anywhere in this email — no garment, no model, no flat-lay — just abstract color and text links. For a clothing retailer's "don't miss out" urgency send, that's a real miss: the email sells a discount, not anything you'd actually want to buy. Given the identical creative pattern running four times today with escalating subject urgency language, this reads as deliverability/inbox-fatigue risk more than a strong individual send.

## What's working

- Clean, on-brand minimalist layout consistent with Everlane's identity — no render bugs, text and image render correctly.
- Clear dual CTA split (Women's / Men's) lets the recipient self-segment immediately.
- Discount stack messaging ("Extra 25% off," "already up to 70% off") is prominent and easy to read.
- Legal/fine print is present but tucked at the bottom, not intrusive to the main read.

## What's weak

- No actual product is shown — the hero is an abstract floral blur with zero merchandising value.
- This is the same "Today Only / Extra 25%" template repeated for the fourth time today with only the background image swapped — severe creative fatigue.
- The urgency claim ("won't be here tomorrow") is undercut by the fact that nearly identical "today only" emails have run repeatedly across the day.
- Secondary nav block (Shop Women / Shop Men / New Arrivals / Best-Sellers) is generic and adds no incremental reason to click over the hero CTAs.

## Recommendations

- 1. Replace the abstract floral hero with an actual product shot — even one hero garment with the discount overlaid would out-perform pure texture art for click-through.
- 2. Stop re-sending the same "Today Only Extra 25%" creative multiple times per day — rotate in genuinely different offers or pause cadence to protect open rates long-term.
- 3. Add a specific proof point (top discounted item, price example, or category callout) instead of only "up to 70% off," which reads as vague after four repeats.
- 4. Tighten urgency copy to reference an actual countdown/time (e.g., "Ends tonight at 11:59 PM") rather than generic "won't be here tomorrow," which is now stale after repeated same-day use.

- **Preheader Alt A:** `Stack it with styles already up to 70% off — ends 11:59 PM PST.`
- **Preheader Alt B:** `A few hours left. Shop the sale before it's gone.`
