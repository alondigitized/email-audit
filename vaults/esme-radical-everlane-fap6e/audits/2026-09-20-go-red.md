# Go Red
**Score:** 6/10 · **Type:** Email audit · **2026-09-20**
## Executive summary

- This is Everlane's cleanest color-story send in the recent run — a single red-tee hero ("Well Red"), a tight six-SKU grid in the same color, then a straightforward "Extra 15% Off Sale Styles" banner. No personalization bugs, no broken images, no layout breakage. It's a legitimate step up from the "Hi There, ," disaster and the flat plain-text sale email earlier in the week.
- The problem is it's thin: one color, one silhouette idea, a discount banner with no deadline visible in the body, and a sustainability blurb that adds length without adding reason to click. It reads as "we photographed the sale colorway" rather than a considered campaign moment — competent, forgettable.
- Judgment: solid production quality, weak differentiation and urgency. Mid-pack for this brand's history, same territory as "Corduroy Has Entered the Chat" and "Do the Leg Work."

## What's working

- Clean, single-color hero ("Well Red") with a model in a red tee — immediate visual hierarchy, eye lands on the product first.
- Six-SKU grid all in the same red gives a coherent "shop the color" narrative without clutter.
- The 15% off sale banner (olive block, white text) is high-contrast and easy to spot when scrolling.
- Gendered CTA split ("Shop Women" / "Shop Men") under the discount banner reduces friction for finding relevant product.
- No render bugs — no lorem ipsum, no broken images, no overlapping text.

## What's weak

- No visible price, dollar amount, or exact discount stacking anywhere near the hero — the only concrete number ("Extra 15% Off") is buried two sections down.
- No urgency/deadline shown in the visible body; the expiration date only appears in the tiny legal fine print at the very bottom, invisible to a scrolling reader.
- The sustainability/impact-report block is a dead detour — it's not tied to red, not tied to the sale, and pushes the actual CTA further down.
- Subject "Go Red" and hero "Well Red" don't quite land together — cute wordplay, but neither says what's on offer (a sale) until well into the email.
- All six grid product shots have generic Everlane category names implied but no captions/prices visible in-image, so a shopper can't tell fit or price without clicking.

## Recommendations

- 1. Move the "Extra 15% Off Sale Styles" banner (or at least the discount callout) up near the hero — right now the reader has to scroll past the whole red grid before learning there's a sale at all. This is the single biggest lift available.
- 2. Add a real deadline in the visible body copy (e.g., "Ends Monday") instead of leaving it to sub-6pt fine print — urgency drives clicks more than color story does.
- 3. Cut or relocate the impact-report block below the primary CTA — it's on-brand but it's diluting focus in an email that should be pushing a discount.
- 4. Add price or "up to 70% off" framing directly under the hero image instead of only in the banner subhead.

- **Subject Alt B:** `The Red Edit: Extra 15% Off Sale`
- **Preheader Alt A:** `New color, bigger markdowns — ends Monday.`
- **Preheader Alt B:** `Sale styles just dropped an extra 15%.`

## Technical Audit — "Go Red" (Everlane)

**1. Technical Summary**
Email is built on Klaviyo's `kl-*`/`mj-*` template system with standard MSO/Outlook conditional comments; one probed link uses a malformed tracking redirect, and required compliance/authentication headers weren't captured in this pipeline.

**2. Link & Tracking Issues**
- Broken link: the "Everlane Logo" link resolves to `https://trk.send.everlane.com/l/01M2Y4DJ39GFY48CKYMWJAFF54_0`, and the underlying target query string is malformed — `_kx=...&bxid=...&cm_flow_i...` is truncated/invalid, producing `unknown url type: '/pages/womens?...'`. This will likely fail to redirect correctly for at least some clients.
- Open-tracking pixel present: `https://trk.send.everlane.com/o/01M2Y4DJ39GFY48CKYMWJAFF54` (standard Klaviyo `trk.send` open tracker).
- 12 of 28 material links were probed (16 footer/utility/social links deprioritized per probing methodology); no failures reported among those, aside from the logo link above.

**3. Rendering & Accessibility**
- Missing `alt` text on the tracking pixel image (`01M2Y4DJ39GFY48CKYMWJAFF54`, src `https://trk.send.everlane.com/o/...`). Low severity since it's a 1x1 open-tracking pixel, not content, but flagged per QA.
- `<title>` tag is empty (`<title> </title>`) — no subject/preview context for clients that surface the document title.
- Template includes correct MSO conditional blocks (`<!--[if mso]>`, `<!--[if lte mso 11]>`) and standard Klaviyo responsive/mobile breakpoint CSS (`max-width: 480px`) — no structural issues found here.
- Custom font import via `@import url(https://static-forms.klaviyo.com/fonts/api/v1/USb9mf/custom_fonts.css)` — `@import` in `<style>` is unsupported in many webmail clients (Gmail, Outlook.com), so custom font (`MaisonNeue-Light`) will silently fall back to the declared fallback stack (`Arial, "Helvetica Neue", Helvetica, sans-serif`). Not a bug, but worth noting as a rendering fallback point.

**4. Personalization & Merge Tokens**
No issues found — no unresolved Klaviyo merge tags (e.g. `{{ }}`) or personalization fallback failures visible in the truncated source.

**5. Compliance (CAN-SPAM, unsubscribe, authentication headers)**
- `List-Unsubscribe` header: not found in headers as captured. QA notes this may be an artifact of the AgentMail relay not preserving the header rather than the sender omitting it — cannot confirm root cause from this data alone.
- `List-Unsubscribe-Post` (RFC 8058, one-click unsubscribe): not found — if genuinely absent, this violates Google/Yahoo's 2024 bulk-sender requirements for one-click unsubscribe.
- `Authentication-Results` (SPF/DKIM/DMARC status): not found via the relay — authentication status is unknown, not confirmed failing.
- An in-body unsubscribe link is confirmed present per QA notes (always included in probing), so CAN-SPAM's basic unsubscribe-mechanism requirement appears satisfied at the body level even if headers are unverified.

**6. Email-to-Site Continuity (UTM params, landing page alignment)**
- Links route through Klaviyo's tracked-redirect domain (`trk.send.everlane.com/l/...`) rather than direct UTM-tagged URLs, so continuity can't be verified from the truncated HTML alone — the actual landing param set (`_kx`, `bxid`, `cm_flow_i...`) is only visible after redirect resolution.
- The one probed failure (logo link) means at least one entry point won't land on `/pages/womens` reliably due to the malformed query string.

**7. Recommendations**
- Fix the truncated/malformed query string on the Everlane logo link (`cm_flow_i...` appears cut off) so it resolves to a valid `/pages/womens?...` URL — verify by resolving `trk.send.everlane.com/l/01M2Y4DJ39GFY48CKYMWJAFF54_0` directly.
- Confirm with the sending platform (Klaviyo) whether `List-Unsubscribe` / `List-Unsubscribe-Post` headers are actually being sent — retest by pulling raw headers before the AgentMail relay to rule out relay stripping vs. sender omission.
- Add `alt=""` to the tracking pixel to satisfy accessibility linting even though it carries no visual content.
- Populate the `<title>` tag with the subject line or preview text for clients that expose it.
