## Technical Audit — Lowe's "FREE Toy Box Workshop" Email

---

### 1. Technical Summary

The email is structurally sound for a legacy table-based build, but carries three meaningful technical risks: a malformed DOCTYPE declaration, overlapping media query ranges that will conflict in the 375–480px viewport band, and a plain-text body that is nearly 80% raw URLs — a significant deliverability red flag. Compliance headers are unconfirmed at the relay layer.

---

### 2. Link & Tracking Issues

**29 tracking links unverifiable.** All click links are wrapped in the ESP redirect domain (`e.lowes.com`). The QA probe correctly skipped them; final destination URLs and UTM parameter presence cannot be confirmed from source alone.

**Plain-text part is 79% URLs (3,572 of 4,518 chars).** A plain-text alternative consisting almost entirely of raw redirect URLs with minimal human-readable prose is a known spam-filter trigger. RFC best practice requires a substantive text rendition, not a link dump.

No broken or 4xx-resolved links were detected in the probed set.

---

### 3. Rendering & Accessibility

**Malformed DOCTYPE.** The opening tag reads:
```
<!DOCTYPE html PUBLIC"-//W3C//DTD XHTML 1.0 Transitional//EN"
```
The required space between `PUBLIC` and the quoted FPI is missing. Strictly conforming parsers will reject this as a parse error; most email clients forgive it, but it is a defect in the delivered source.

**Overlapping media queries create rule conflicts in 375–480px.** Two separate `@media` blocks both apply to this viewport range:
- Block 1: `(min-width: 375px) and (max-width: 600px) and (-webkit-min-device-pixel-ratio:0)`
- Block 2: `(max-width: 480px)`

Any device in the 375–480px band will match both blocks. Where the same selector appears in both with different values (e.g., `.container` width, `.drop` display), the cascade order determines the winner rather than intent. This needs auditing against all shared selectors.

**DIN Next font CDN version mismatch.** `din-next.woff` is pulled from scaffold version `1.4.4` while `din-next-bold.woff` and `din-next-black.woff` are pulled from `1.2.0`. If these versions differ in font metrics, mixed-weight text blocks may render with inconsistent glyph sizes or spacing.

**Duplicate `local()` hints in all `@font-face` declarations.** Every custom font declares the same local name twice (e.g., `local('Fellix Regular'), local('Fellix Regular')`). This is harmless but indicates a copy-paste error in the font stack template.

**One confirmed image missing `alt` text:**
```
https://image.e.lowes.com/lib/fe9515707364027471/m/1/a22207c1-63c7-47c0-9e00-61227828e1fe.jpg
```
Screen readers will skip this image entirely. If it is decorative, `alt=""` should be set explicitly. If it is content-bearing (e.g., a hero or event image), a descriptive alt string is required for WCAG 2.1 compliance.

### 4. Personalization & Merge Tokens

No unresolved merge tokens or raw placeholder syntax (e.g., `{{first_name}}`, `[FNAME]`, `%%first%%`) are visible in the provided HTML excerpt. The subject line contains no personalization. Cannot fully confirm for the complete template without the untruncated source.

### 5. Compliance

**`List-Unsubscribe` header absent** (QA WARN). Whether this is a relay-capture gap or a genuine omission is unconfirmed, but Gmail and Yahoo's 2024 bulk-sender requirements mandate this header for any sender exceeding 5,000 daily messages. Absence will degrade inbox placement with both providers.

**`List-Unsubscribe-Post` header absent** (QA WARN). RFC 8058 one-click unsubscribe requires this header alongside a `List-Unsubscribe` mailto/HTTPS value. Gmail enforces one-click unsubscribe for bulk senders; missing this is a compliance gap independent of whether an unsubscribe link exists in the body.

**`Authentication-Results` header not found** (QA WARN). SPF and DKIM pass/fail status is unknown because the AgentMail relay did not surface the header. This must be verified directly — unauthenticated mail from `e.lowes.com` will be aggressively filtered or rejected by major mailbox providers.

CAN-SPAM: an unsubscribe mechanism and physical mailing address are expected in the body footer. These are not visible in the truncated source and should be confirmed against the full render.

---

### 6. Email-to-Site Continuity

All 29 actionable links pass through `e.lowes.com` click-redirect URLs. UTM parameters on destination landing pages cannot be verified from the HTML source. This is the highest-priority continuity risk: if the ESP redirect strips or omits UTM tags before forwarding to `lowes.com`, all click attribution in analytics will be lost or attributed to direct traffic.

No dead-end landing page issues were detectable from the available data.
