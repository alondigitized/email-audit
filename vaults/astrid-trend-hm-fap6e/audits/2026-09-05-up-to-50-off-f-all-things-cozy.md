# Up to 50% off (f)all things cozy
**Score:** 6/10 · **Type:** Email audit · **2026-09-05**
## Executive summary

- This is the same "THE LABOR DAY EVENT / UP TO 50% OFF SITEWIDE" hero H&M ran on 09/03 (8.00/10) — identical layout, identical bold black type on white, identical brunette-model-in-knitwear hero shot. The subject line "Up to 50% off (f)all things cozy" is new copy wrapped around old creative, the same trick H&M pulled on 09/04 with "Denim for the whole fam from $12.99" over the same block (6.00/10) and again on 09/01 with "Everyday staples with a nostalgic edge." The wordplay subject is at least more polished than 09/04's, but subscribers who opened yesterday or three days ago are looking at a near-duplicate email.
- The body itself is well-executed: clean grid, consistent product cards with visible strike-through pricing, a "SHOP BY" category footer, and a legible "EXTRA 10% OFF FOR NEW MEMBERS" banner up top. Sale % isn't visible on every item though — several products show only dollar amounts, and it takes scrolling to confirm the "up to 50%" claim is real. Solid execution, undermined by creative fatigue and a subject line that oversells "cozy" against a product mix that's mostly dresses, cardigans, and polos.

## What's working

- "UP TO 50% OFF SITEWIDE" is bold, black, and impossible to miss immediately below the hero.
- Strike-through original prices next to sale prices on every product card make the discount concrete and easy to scan.
- "EXTRA 10% OFF FOR NEW MEMBERS" banner adds a second, more specific incentive above the fold.
- "SHOP BY" category strip (Women/Men/Kids/Home/Beauty) gives a clear secondary path if the hero offer doesn't land.
- No render bugs — images load cleanly, layout is consistent top to bottom.

## What's weak

- This is the third time in five days this exact hero/layout block has been reused (09/01, 09/03, 09/04), just re-subtitled.
- Subject promises "all things cozy" but the lineup includes a polo shirt and slip-style dress that don't read as cozy/fall.
- No visible urgency or deadline anywhere in the body — "sitewide" sale with no end date shown undercuts any real urgency.
- Discount percentages aren't shown per-item; shoppers have to do the math from strike-through prices to confirm savings.
- "New Arrival" tags stacked next to sale prices sends a mixed signal — new stock discounted this deep can look like markdown fatigue rather than a seasonal event.

## Recommendations

- 1. Rotate the hero creative — a third reuse of the same shot/layout in one week is the single biggest drag here; swap in a genuinely cozy-coded image (chunky knit, layered fall styling) to match the subject's promise.
- 2. Add per-item discount badges ("40% OFF") on each product card instead of forcing subscribers to compare two prices.
- 3. Add a visible end date/countdown to the sitewide offer — "Ends Monday" or similar — since none of the recent sends in this run have shown real urgency.
- 4. Curate the product grid to skew fall/cozy (knits, cardigans, boots) and drop the polo shirt, which breaks the subject's promise.

## Technical Audit

Technical Summary
The email fails on delivery infrastructure: all 12 probed tracked links (CTAs, header logo, product images, unsubscribe) return HTTP 403, and the message lacks both List-Unsubscribe and Authentication-Results headers, indicating a broken or misconfigured ESP redirect domain (t19.email.hm.com).

Link & Tracking Issues
- All click-tracked links resolve through `https://t19.email.hm.com/r/?id=...` and return **403 Forbidden**, including both primary "Shop now" CTAs, the header "H&M" logo link, all six product image links, and the Unsubscribe link.
- Because every link shares the same redirector host and `did=1715700751&rid=3326930539` session identifiers, this points to a single upstream failure (expired/misconfigured redirect token or blocked crawler UA) rather than isolated broken links — but as observed, 100% of probed links (12/12) are non-functional.
- Two CTA instances contain zero-width/invisible characters in the anchor text (`"‌  ﻿Shop now"` — ZWNJ/BOM), which is typical ESP A/B tracking padding and not itself an error, but confirms these are duplicate tracked variants of the same broken link.

Rendering & Accessibility
- 21 `<img>` elements are missing `alt` attributes, including all product images (`cq5dam.web.*.jpeg`, and six `assets/hm/*` product photos) and the tracking pixel. Screen readers will announce these as unlabeled images.
- Extensive mobile-responsive CSS (`@media (max-width:699px)`) is present via `#optimize-css`, with explicit Outlook/Yahoo/Gmail handling (`mso-hide`, `#MessageViewBody`, `@media screen yahoo`) — no issues found in the provided markup.

Personalization & Merge Tokens
- The embedded `application/ld+json` schema.org block has multiple empty required fields: `subjectLine: ""`, `discountCode: ""`, `availabilityEnds: ""`, and `image`/`url` in the `PromotionCard` object are also empty strings. These are likely unresolved merge-token placeholders that failed to populate at send time, which will suppress Gmail's promo-card/annotation rendering.
- `availabilityStarts` is hardcoded to `"2018-12-31T18:59:59-05:00"` — a stale/unrelated date left in the template, inconsistent with the 2026-09-05 send date.

Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe header**: not found. Cannot confirm RFC 2369 one-click unsubscribe support at the header level.
- **List-Unsubscribe-Post header**: not found (RFC 8058). One-click unsubscribe via mail client is not confirmed.
- The in-body Unsubscribe link is present but is itself one of the 403-failing tracked links (`...p4=3326930539&p5=9be06746af74de7271d9dcc8d83f5742`), meaning the fallback unsubscribe mechanism is also non-functional as captured.
- **Authentication-Results header**: not found — SPF/DKIM/DMARC pass/fail status cannot be verified from available data.

Email-to-Site Continuity (UTM params, landing page alignment)
- Links use ESP redirect params (`p1=DM6016515`, `p2=ce7617e8860b8ca9a51e9937a544b55b`, `p3=20260905`) rather than standard UTM query parameters — no `utm_source`/`utm_medium`/`utm_campaign` present in the visible link structure, so campaign attribution in web analytics cannot be confirmed from this source.
- Destination landing pages cannot be evaluated: since the redirector itself returns 403, no final landing URL is reachable to check alignment with the email's offer.

Recommendations
1. Investigate the `t19.email.hm.com` redirect service immediately — 12/12 probed links (100%) return 403, including the unsubscribe link, which is a compliance-critical failure, not just a UX one.
2. Add `List-Unsubscribe` and `List-Unsubscribe-Post` headers to restore one-click unsubscribe support (RFC 2369 / RFC 8058).
3. Populate the empty `ld+json` fields (`subjectLine`, `discountCode`, `availabilityEnds`, `PromotionCard.image`/`url`) or remove the schema block if unused — empty required fields will block Gmail promotional markup rendering.
4. Add descriptive `alt` text to all 21 flagged images for accessibility and to preserve context when images are blocked.
5. Verify SPF/DKIM/DMARC alignment directly at the sending MTA, since `Authentication-Results` is absent in this capture (may be an artifact of the relay rather than the sender).
