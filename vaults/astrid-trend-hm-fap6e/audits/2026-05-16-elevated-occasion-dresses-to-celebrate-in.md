### 3. Rendering & Accessibility

**`@import` font loading will silently fail in major clients:**

```css
@import url(https://fabric.hmgroup.com/fabric-fonts/0/northstar/css/fonts.css);
@import url(https://s1-cdn.hm.com/global/hm-fonts/4.0.1/oces.css);
```

Gmail strips `<style>` blocks with `@import`; Outlook ignores them entirely. Both CDN fonts will not load for the majority of recipients. Fallback stack is not declared in the visible CSS — if the template relies on `NorthStar` or `OCES` for weight/spacing, layout will degrade silently.

**`format-detection` meta syntax is non-standard:**

```html
<meta content="telephone=no" name="format-detection"/>
```

The correct attribute order per spec is `name` before `content`. While most clients parse both orderings, the non-canonical form should be corrected: `<meta name="format-detection" content="telephone=no"/>`.
