# Summer-to-fall favorites from $9.99
**Score:** 8/10 · **Type:** Email audit · **2026-07-18**
## Executive summary

- This is H&M's latest entry in what has become a grinding sale run — the same "Up to 50% Off Sitewide" offer that anchored yesterday's TGIF blast is back, barely 24 hours later, wearing a new subject line. The subject — "Summer-to-fall favorites from $9.99" — is actually the strongest asset in the whole send: a concrete price anchor plus a season-transition hook that hints at a curated edit. Open it and neither payoff exists. There is no $9.99 item anywhere in the body. There is no summer-to-fall editorial narrative. What you get is "PEAK SUMMER SAVINGS / UP TO 50% OFF SITEWIDE" — the same creative skeleton as July 17.
- Structurally the email is passable. The 50% off headline dominates above the fold, the one-&-done dresses and tees sections give it a light editorial spine, and the category grid makes it easy to self-route. But four of seven category CTAs point to kids, two of the three body copy sections skew children's — heavy for a subject that implied a curated adult wardrobe edit. The body copy also has two visible errors: "From one summer days" reads unfinished, and "fail/proof" should be "foolproof."
- The subject overpromises, the body underdelivers, and the cadence is burning out.

## What's working

- **"From $9.99" in the subject is the best line in this send** — a concrete price anchor that earns the open in a way the body can't match
- **50% off headline lands immediately** — clear visual hierarchy, no hunting required to find the offer
- **Dresses and tees sections add editorial texture** — better than a pure discount grid
- **Clean render** — no broken images, no overlapping text, no layout artifacts
- **Category grid is self-service** — Women/Men/Girls/Boys routing makes it usable for household shoppers

## What's weak

- **The $9.99 price point from the subject does not appear in the email body** — biggest trust gap in the send; the subject implies a featured item, the body delivers nothing at that price
- **Two visible copy errors** — "From one summer days" (unfinished sentence) and "fail/proof" (should be "foolproof") are in the first body paragraph
- **Creative is near-identical to yesterday's TGIF send** — same 50% off offer, same "Peak Summer Savings" header, same layout; fourth sale email in three days
- **Preheader is a wasted utility bar** — "NEED AN ITEM SOONER? BUY ONLINE, PICK UP IN-STORE" is the first visible text in the email; if it bleeds into inbox preview, it completely undercuts the subject's price-anchor momentum
- **No urgency signal anywhere in the body** — 50% off sitewide with no end date gives subscribers zero reason to act now rather than tomorrow (or never)

## Recommendations

- 1. **Pay off the $9.99 promise** — feature one explicit hero item or a "from $9.99" callout section. The subject creates a concrete expectation the body must honor, otherwise the brand trains subscribers that its subjects are clickbait.
- 2. **Add a deadline** — "Sale ends Sunday" or even "This weekend only" would do meaningfully more conversion work than the open-ended discount currently does.
- 3. **Fix the body copy before next send** — "From one summer days" → "From long summer days"; "fail/proof" → "foolproof." Both are visible in the render and easy to catch.
- 4. **Write a real preheader** — the "NEED AN ITEM SOONER?" banner is a utility message that should not be the first text in a promotional email; swap it for dedicated preview copy that extends the subject.
- 5. **Trim kids real estate for adult-skewing subjects** — when the subject line signals an adult curated edit, lead with adult summer-to-fall looks and push kids to a secondary row.
- **Subject Alt A:** `Back-to-school styles from $9.99 — today only`
- **Subject Alt B:** `50% off: summer-to-fall picks, from $9.99`
- **Preheader Alt A:** `Dresses, tees + kids' essentials — all in the sitewide sale.`

### 3. Rendering & Accessibility

**`@import` for web fonts — high impact**

```css
@import url(https://fabric.hmgroup.com/fabric-fonts/0/northstar/css/fonts.css);
@import url(https://s1-cdn.hm.com/global/hm-fonts/4.0.1/oces.css);
```

`@import` inside `<style>` blocks is stripped or ignored by Outlook (all versions), Samsung Mail, and several Android clients. No fallback font stack is declared in the import rule itself, so these clients will fall back to the browser/client default rather than a controlled system font.

**`@media screen yahoo` pseudo-query**

```css
@media screen yahoo { .show-webkit-table { display: none; } }
```

This is a non-standard Yahoo Mail targeting hack. It has no effect in any standards-compliant renderer and only works in specific older Yahoo Mail versions. If this rule is load-bearing for layout, it should be verified against current Yahoo Mail behavior.

**Alt text and table structure** — cannot audit without full HTML.

### 4. Personalization & Merge Tokens

The JSON-LD block contains multiple unfilled template slots:

```json
{"@type":"EmailMessage","subjectLine":"","@context":"http://schema.org/"}
```
→ `subjectLine` is empty. Should be `"Summer-to-fall favorites from $9.99"` to match the envelope subject.

```json
{
  "availabilityEnds":"",
  "discountCode":"",
  "@type":"DiscountOffer",
  "description":"",
  "availabilityStarts":"2018-12-31T18:59:59-05:00"
}
```
→ `availabilityEnds`, `discountCode`, and `description` are empty strings — unfilled placeholders.
→ `availabilityStarts` is hardcoded to **2018-12-31**, roughly 7.5 years in the past. This is a stale template default that was never updated for this send.

```json
{"image":"","@type":"PromotionCard","promotionCardLayout":"SingleImageLayout","url":""}
```
→ Both `image` and `url` on `PromotionCard` are empty.

**Net effect:** Gmail's Promotions Tab annotation system reads this JSON-LD to render deal cards and images in the tab view. With empty `subjectLine`, `image`, `url`, and a past `availabilityStarts`, no annotation will render — the email appears as a plain entry with no deal card.
