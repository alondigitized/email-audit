# Apply code: SCHOOL20 | Stack w/ up to 50% off* deals!
**Score:** 6/10 · **Type:** Email audit · **2026-08-16**
## Executive summary

- This is a repeat of the 8/14 "SCORE AN EXTRA 20% OFF" send — same fabric-texture hero with a green-bordered box stacking "UP TO 50% OFF PLUS EXTRA 20% OFF," just swapping "SCHOOL20" copy emphasis and the subject line. It's the second time this exact hero-agnostic, product-flat creative has run in three days, and it still has no lifestyle photography or kids in the hero, which is a real miss for a parenting brand mid-back-to-school season.
- Below the fold it does pick up: a "we think you'll love these" grid, a genuinely nice Little Planet organic-layers seasonal block with an actual baby photo, then a bold red 70%-off clearance CTA grid with gender/age shop-by buttons, then a store-locator/rewards footer. So the email recovers visually as you scroll, but the hero — the thing that determines the open-to-click decision on mobile — is the weakest, most repeated asset in the whole send.
- Net: this is a coupon-stacking utility email dressed as a hero send. It'll perform on click-to-open for shoppers already in-cart, but it won't pull new opens or stop the scroll given how many near-identical variants have run this week.

## What's working

- The offer stack (up to 50% off + extra 20% with code SCHOOL20) is stated clearly and is the first thing seen, with a legible "Shop Now" button.
- Little Planet section has real seasonal lifestyle photography (baby in neutral organic layers) and a clear seasonal hook ("new organic layers for fall").
- 70% off clearance block uses strong color contrast (red) and shop-by-category buttons (Baby Girl/Boy, Toddler, Girl/Boy) that reduce friction for someone who knows what they want.
- Store locator with address/map and Carter's Rewards perks strip adds useful local/loyalty utility.
- No visible render bugs — images, text, and buttons all display cleanly.

## What's weak

- The hero is a flat fabric-texture background with no models, kids, or product — the third near-identical "stack the code" hero variant this week (8/11, 8/14, now 8/16).
- No urgency signal (no countdown, no "ends tonight/Sunday") despite this being a stacking-code promo that should feel time-bound.
- The "we think you'll love these" 9-product grid has no headlines, prices, or context — just thumbnails, so it reads more like a catalog dump than a curated pick.
- Two competing discount messages (50%/20% stack vs. 70% clearance) fight for attention without a clear "start here" hierarchy for the reader.

## Recommendations

- 1. Replace the flat-texture hero with a lifestyle photo (a family or kid in back-to-school outfits) behind the offer box — this is the single biggest lever; the brand's own Little Planet section proves they have the assets, just not up top.
- 2. Add a real deadline to the code stack ("through Sunday 8/20") to justify urgency and differentiate from the evergreen clearance offer.
- 3. Add product names/prices under at least the top row of the "we think you'll love these" grid so it functions as merchandising, not filler.
- 4. Reorder so clearance (bigger, punchier 70% off) leads and the stackable code is a secondary layer — or merge them into one hierarchy instead of two full-width competing CTAs.
- 5. Since this is the third hero-agnostic promo in under a week, alternate creative structure entirely on the next send (e.g., lead with Little Planet's photography) to break monotony for repeat openers.
