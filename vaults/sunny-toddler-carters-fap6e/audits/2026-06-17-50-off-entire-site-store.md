# 50% OFF ENTIRE SITE & STORE*
**Score:** 9/10 · **Type:** Email audit · **2026-06-17**
## Executive summary

- Carter's finally breaks the EXTRA20 code marathon — eight consecutive sends across nine days — with a clean step-change: "50% OFF ENTIRE SITE & STORE." That shift in offer type is the smartest thing about this send. After repeated code-based discounts that required the subscriber to remember and apply a coupon, a straight 50%-off headline feels like a genuine escalation, not just another nudge. The summer water-texture hero, seasonal and fresh, underlines that this is a different moment.
- The "PICKS FOR YOU" personalized product grid is the body's standout feature. It gives the email a reason to exist beyond a generic sitewide blast, and combined with the three-tier value ladder — 50% sitewide → 20% select faves → $3.99 clearance — the information hierarchy actually does work. You can enter at any intent level.
- What undercuts it: the asterisk on "ENTIRE SITE" immediately signals that "entire" is a lie. No deadline appears anywhere in the render, so there is no clock ticking. The secondary "20% OFF SELECT FAVES" tier sits oddly between the headline discount and the clearance floor — subscribers who've been following along will wonder how this compares to the stacked EXTRA20+60% offer they saw last week. A strong offer, moderately executed.

## What's working

- **EXTRA20 fatigue break:** First send in eight days not built around a coupon code; "50% OFF" reads as a genuine promotional step-up that earns attention.
- **"PICKS FOR YOU" personalized grid:** Real product recommendations tailored to the subscriber add perceived value and pull the eye toward specific click targets.
- **Three-tier value ladder:** 50% sitewide → 20% select faves → $3.99 clearance creates entry points for every deal-seeking intent level.
- **Summer water-texture hero:** Seasonal, clean, and visually differentiated from the beige/product-focused layouts of the recent EXTRA20 series.
- **In-store included:** "ENTIRE SITE & STORE" — both channels in one send is a meaningful coverage statement most competitors don't make.

## What's weak

- **Asterisk on "ENTIRE SITE" is an immediate trust signal:** The subject and hero both promise the whole site, then hedge with a footnote. Subscribers have been burned enough times to notice.
- **No deadline visible anywhere:** "50% OFF" with no end date removes the single lever most likely to convert passive readers into same-session buyers.
- **"20% OFF SELECT FAVES" tier creates confusion:** After stacking EXTRA20 on top of 60% clearance last week, a secondary 20% tier reads as a downgrade — the email doesn't explain the relationship between tiers.
- **"Shop Now" CTA is generic:** No verb-noun specificity — "Shop Baby Deals" or "Shop the Sale" would reduce decision friction.
- **Dense legal footer drags scroll-end:** The fine print block at the bottom is extensive and visually heavy; it's the last thing the eye sees.

## Recommendations

- 1. **Add a deadline — this is the single highest-lift change.** "Ends Sunday" or "48 hours only" turns a passive 50%-off page into a ticking clock. No other edit matters as much.
- 2. **Rewrite the hero fine print to set honest expectations upfront.** Instead of "ENTIRE SITE & STORE*" leading to buried exclusions, use "50% OFF SITEWIDE — some exclusions apply." Subscribers who feel deceived by asterisks don't click; they unsubscribe.
- 3. **Clarify or remove the "20% OFF SELECT FAVES" tier.** Either it stacks on the 50% or it doesn't — say which. If it doesn't stack, lead with why these picks are still worth it (limited quantities, new arrivals, collab brands).
- 4. **Swap "Shop Now" for category-specific CTAs on the hero.** The clearance section already does this well (Baby Girl / Baby Boy / etc.) — pull that same treatment up to the hero.
- 5. **Add deadline copy to the $3.99 clearance section:** "More markdowns added — while supplies last" is close but vague. "New markdowns every day through [date]" would drive return visits.
- **Subject Alt A:** `50% off site + stores — today only`
- **Subject Alt B:** `Carter's biggest sale: 50% off everything*`
- **Preheader Alt A:** `No code needed — 50% off automatically applied at checkout`
- **Preheader Alt B:** `Ends Sunday: 50% off + $3.99 clearance picks just added`

### 3. Rendering & Accessibility

**Empty `<title>` element**
```html
<title></title>
```
Screen readers announce this email as untitled. Should be set to match the subject line or a brief description.

**Google Fonts load path is correct but fragile**
```html
<!--[if !mso]><!-->
<link href="https://fonts.googleapis.com/css2?family=League+Spartan...">
<!--<![endif]-->
```
Conditional wrapping is correct (Outlook skips it). However, Google Fonts is blocked by default in many corporate environments (Outlook on the web, some iOS MDM profiles). No system-font fallback stack is visible in the truncated CSS — verify that the `font-family` declarations elsewhere include a safe fallback like `Arial, sans-serif`.

**`role="presentation"` on layout tables** — correctly applied. No issue.

**`alt=""` on tracking pixel** — correct for a decorative/hidden element. No issue.
