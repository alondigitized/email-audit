# 🎈It’s Labor Day 🎉 Site & store now 50% off*
**Score:** 6/10 · **Type:** Email audit · **2026-09-05**
## Executive summary

- This is the exact same skeleton-costume-with-pumpkin-props hero that got flagged in yesterday's 9/4 "Site & store 50% off" send — Carter's has now run a Halloween-branded product photo under a "Labor Day" banner two sends in a row, and it still doesn't make sense as a seasonal pairing. The rest of the email is a solid, well-organized catalog structure: a real offer stack (50% off plus an extra 20% with code LABORDAY), a "Just For You" grid, a Character Shop section with new Paw Patrol product, and a store-locator block — this is one of the more complete Carter's sends structurally.
- But the hero mismatch undercuts the whole open. A shopper landing on "Labor Day" and seeing a skeleton onesie with jack-o'-lanterns reads as either a template error or a brand that doesn't proofread its own campaigns — and since this is a repeat of yesterday's exact issue, it reads as a real production gap rather than a one-off. The offer itself is strong and the layout is clean; the creative selection is the single fixable flaw holding this back.

## What's working

- Clear, high-contrast offer stack up top: "50% OFF SITE & STORE" plus "EXTRA 20% OFF" with a visible promo code (LABORDAY).
- Strong page structure — hero, "Just For You" personalized-feeling grid, Character Shop (new Paw Patrol), Shop It All by age group, then a store locator with map and address.
- The Character Shop callout ties to a real, current pop-culture moment ("just in time for the big-screen premiere!") rather than generic filler.
- Rewards/curbside/app perks strip near the footer reinforces loyalty value without being pushy.
- No broken images, overlapping text, or lorem ipsum — the render itself is clean.

## What's weak

- The hero product (black skeleton skull-and-bones onesie with pumpkin props) is a Halloween item, not a Labor Day one — same mismatch flagged in the 9/4 "Site & store 50% off" send, now repeated.
- Subject/preview promise a Labor Day sale but the first thing you see visually is Halloween merchandise — creates a jarring, seasonally-confused first impression.
- "Just For You" grid is all denim/neutral basics with no product names or prices visible — feels generic rather than personalized despite the label.
- Multiple CTAs ("Shop Now," "Shop from $12," "Shop Baby/Toddler/Kid," "Get Directions") dilute the single primary action a reader should take.

## Recommendations

- 1. Swap the hero image for an actual current-season (early September) outfit — swim/back-to-school transitional pieces or fall basics — not Halloween costume merchandise. This is the same fix needed on 9/4 and hasn't been made.
- 2. Add product names/prices to the "Just For You" tiles so it reads as genuine personalization, not a stock denim grid.
- 3. Reduce hero CTA competition — keep "Shop Now" as the singular top action, let the Character Shop and Shop It All sections carry their own secondary CTAs lower down (already fine as-is, just don't add more above the fold).
- 4. Tighten the subject to match a real deadline if one exists (Labor Day is a single day — add "today only" or an end time to create credible urgency).
