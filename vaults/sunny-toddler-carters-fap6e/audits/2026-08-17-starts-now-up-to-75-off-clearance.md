# ⏰ STARTS NOW: Up to 75% off* clearance
**Score:** 7/10 · **Type:** Email audit · **2026-08-17**
## Executive summary

- This is a clean break from the back-to-school promo repeats and the fabric-texture stacking-discount emails — a genuine seasonal pivot to "after-school clearance," with a playground hero (basketball court, yellow poles, long shadows) that actually earns the theme instead of reusing a generic texture background. The "3 DAYS ONLY, WHILE SIZES LAST!" urgency plus "UP TO 75% OFF" is the biggest number this brand has shown all week, and it's presented with real visual hierarchy — headline, offer, single CTA, done.
- Below the fold it does something smart: a full size-grid (NB through 12/14) sits right under the hero, which is unusually useful for a parent shopper trying to gauge if their kid's size is even in stock during a clearance sweep. The rest — store locator, perks icons, rewards blurb, social — is boilerplate footer furniture, competently done but not differentiating.
- The weak spot is specificity: "up to 75% off" with no visible product, no category breakdown (is it shoes? outerwear? swim?), and a size grid that's just labels, not links to actual inventory. It reads as a strong subject-line/hero combo riding on a fairly thin body. Solid, above-average send for this brand's recent cadence — best hero in over a week, but leaves conversion on the table by not showing what's actually on clearance.

## What's working

- The "after-school clearance" playground hero is a genuinely new, on-brand creative — first real seasonal departure from the repeated fabric-texture/embroidered-sweatshirt sends this week.
- Clear single CTA ("Shop Now") sits directly under the offer stack with strong visual hierarchy — eye goes headline → 75% OFF → button.
- "3 DAYS ONLY, WHILE SIZES LAST!" gives credible, specific urgency tied logically to a clearance event.
- The size-grid block (NB–12/14) is a smart, practical addition for a parent trying to gauge stock relevance fast.
- No render bugs — clean image, legible white-on-photo text, no overlap or broken assets.

## What's weak

- Zero product imagery — no shoes, jackets, or outfits shown, so there's nothing concrete to anchor "75% off" against.
- Size buttons aren't visibly tied to categories (boys/girls/baby) or linked to specific collections — they're just a size selector with no context.
- "Up to 75%" is doing a lot of work with no supporting tiered breakdown (e.g., "extra 20% off clearance") like recent sends (8/14, 8/16) used.
- The store locator/map block eats significant vertical space before any product content — a lot of scroll for a clearance email with no items shown.

## Recommendations

- 1. Add a 3-4 product tile row (shoes, outerwear, basics) with strikethrough pricing under the hero — this is the single biggest lift since the email currently has zero product proof for a "75% off" claim.
- 2. Make the size grid clickable-looking with a category label above it (e.g., "Shop by size — girls" / "boys") so it reads as a merchandising tool, not decoration.
- 3. Move the store-locator/map block below the footer perks icons — it's pushing real content down in a promo-first email.
- 4. Tighten the fine print — "Coupon valid for one-time use" language undercuts the clean "just click and save" clearance framing; consider trimming to essentials with a "full details" link.
