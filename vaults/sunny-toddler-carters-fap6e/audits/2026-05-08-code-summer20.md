# Code: SUMMER20 ✨👀
**Score:** 7/10 · **Type:** Email audit · **2026-05-08**
## Executive summary

- A competent, on-brand summer sale email from Carter's. The hero is clear, the offer is generous (40% + extra 20% with code SUMMER20), and the summer theme is timely. The main weaknesses are a subject line that gives away the code without earning curiosity, no personalization, no deadline on the primary offer, and a fragmented CTA structure that dilutes the click impulse. Strong foundational execution, but the upper funnel (open) is undersold.

## What's working

- **Hero offer is hard to miss.** The gradient splash with "40% OFF + EXTRA 20% OFF" and the code is immediately legible. There's no ambiguity about what the email is offering.
- **Clearance module is a strong secondary hook.** "UP TO 70% OFF* CLEARANCE — New markdowns added" is a compelling reason to click even if the primary offer doesn't land.
- **Summer product grid is well-curated.** Six clean product images in the "Get Summer Ready" section show variety without feeling cluttered.
- **Store locator module is a nice touch.** The "Carter's near you!" section with a map thumbnail adds omnichannel utility that not every brand includes.
- **Clean render.** No broken images, no layout issues, no visible lorem ipsum or empty fields.

## What's weak

- **No urgency on the primary offer.** Neither the hero nor the category CTAs include an expiration date. The code SUMMER20 could be valid for one day or one month — unknown. This blunts click impulse.
- **Fragmented CTAs.** The "Shop It All" section splits into Baby / Toddler / Kid immediately. For someone who shops across all categories this is fine, but it kills momentum for casual browsers who'd respond to a single "Shop the Sale" action.
- **No personalization.** No first name, no category pre-selection, no "your picks." Standard batch-and-blast structure.
- **Subject line is anticlimactic.** Revealing the promo code in the subject leaves nothing to discover. The emoji (✨👀) add noise without adding meaning.
- **"UP TO" qualifier softens the headline.** The asterisks on both 40% off and 70% off are expected, but the "up to" framing means the real savings could be much lower for the most desirable items.

## Recommendations

- 1. **Add a deadline.** Even "Ends Sunday" or "48 hours only" in the hero or subject drives urgency that a static code never will.
- 2. **Test a single hero CTA button.** Replace the three split-category buttons in the "Shop It All" section with one "Shop the Summer Sale" button, then let the site's personalization layer determine landing page. A/B test it.
- 3. **Rework the subject line.** The code can live in the preview text. The subject should earn the open with the offer mechanic, not just print the code. See alts below.
- 4. **Pull a clearance hero product.** The 70% off module is strong — consider surfacing one specific clearance product in the hero or as a secondary visual to anchor price value.
- 5. **Add the deadline to the hero copy.** Even one line ("Through Sunday, 5/11") makes the stacked discount feel more credible and urgent.
