# 40% off is here today, gone tomorrow ...
**Score:** 7/10 · **Type:** Email audit · **2026-09-20**
## Executive summary

- This is the same 40% flat-tier coupon Kohl's has been running since 09-19 ("Enjoy 40% off + earn Kohl's Cash 🤩," 6.00/10), now dressed up with a "here today, gone tomorrow" urgency frame and a "Rewards Member Exclusive" flag at the top. The urgency angle is new copy, but the deadline itself ("Ends Sept. 20") is the exact same static date this brand has used across the entire streak since 09-10 — so the "gone tomorrow" framing is stale by the time this actually sends, which undercuts the one thing the subject is trying to sell.
- Below the fold it's the usual kitchen-sink layout: Martha Stewart collection push, kitchen appliances, home/dining, bedding, a clearance banner, then a four-item grid of completely unrelated products (a slushie maker, bath towels, jeans, a mattress topper) under "picked with you in mind" — which reads as generic cross-sell, not personalization. Visually clean, no render bugs, but this is a long, undifferentiated scroll that's been shipped with minor reskins for two weeks straight.
- Verdict: solid execution, tired strategy — the flat 40% is genuinely the best offer of the cycle, but the urgency hook is a copy trick sitting on a coupon that's been live for over a week, and the barcode-style coupon graphic near the bottom is a nice touch that's buried too far down to matter.

## What's working

- Clear, high-contrast hero: "40% off" in large red type is the first thing the eye hits.
- "Rewards Member Exclusive" badge at the top acknowledges loyalty status directly.
- Unambiguous CTA buttons ("Shop Now") repeated at every section break.
- Barcode/coupon-code block near the footer (code visible: CMH0NEK6KNL4R) gives a concrete, usable takeaway.
- No overlapping text, broken images, or layout breakage anywhere in the render.

## What's weak

- "Here today, gone tomorrow" urgency is undercut by the same static "Ends Sept. 20" deadline this brand has run for two weeks — it reads as manufactured urgency, not real scarcity.
- The bottom product grid ("Picked with you in mind") mixes a drink maker, towels, jeans, and a mattress topper — there's no coherent category logic, so it doesn't feel personalized despite the label.
- Email is very long with six+ distinct offer sections (appliances, home, dining, bedding, clearance, grid) before getting to the coupon code — hero offer is not reinforced with the actual code until deep in the scroll.
- Martha Stewart collection intro competes with the 40% hero for top-of-email attention instead of reinforcing it.

## Recommendations

- 1. Make the urgency real: if the coupon has been live for a week and expires same-day, don't market it as "gone tomorrow" — either shorten the actual window or drop the false-scarcity framing, since repeat subscribers have seen this expiration date before.
- 2. Move the coupon code/barcode block up near the hero so the CTA and the redemption mechanic are in the same view — right now a reader has to scroll past six sections to find it.
- 3. Replace the generic "Picked with you in mind" grid with an actual segment-driven set (if this subscriber has browsed home goods, lead with home; don't mix categories at random).
- 4. Trim the mid-email sections — appliances/home/dining/bedding/clearance is five distinct pitches in one send; consolidate to two before the CTA fatigue sets in.

- **Subject Alt B:** `Last call: 40% off ends today`
- **Preheader Alt A:** `Rewards members: your code is inside, no waiting in line.`
- **Preheader Alt B:** `Home, kitchen, and bedding — all 40% off through midnight.`
