# Want a FREE gift with purchase, Insider? 😍
**Score:** 7/10 · **Type:** Email audit · **2026-11-03**
## Executive summary

- This is the sixth or seventh Sephora Savings Event send in a week, and the first to change the pitch. The subject promises a free gift with purchase, but the hero still sells the 10% Insider and 30% Sephora Collection medallions. The gift (a parachute headband and washcloth, a $100+ order, Insider-only, "use code UNREADY") sits in a red block about a third of the way down. The subject leads with a mid-email perk and the hero leads with the same offer as 11/2.
- The email is built well. There is a clear "SHOP NOW" button, a code (ALLONSALE), a Free Same-Day Delivery strip, and a second ALLONSALE code block for new scents. It is also a very long scroll, with a product grid, a "Spot it. Shop it." section, a Kohl's store locator and a gift guide stacked below the hero. The subject's promise is easy to miss, and the shopper has to hunt for it.
- Judgement: strong execution and a well-targeted subject, but the creative doesn't match the subject. It is also the latest in a week of near-identical sends, so it risks reading as noise.

## What's working

- The subject addresses "Insider" directly, which signals segmentation to a loyalty member.
- The hero is clear. Two gold medallions (10% off Insider, 30% off Sephora Collection) with dates and a single black "SHOP NOW" button sit on a dark, festive background.
- The free-gift block is a visible red panel with a product image and a "USE CODE UNREADY" line.
- The perks strip (500-point challenge, Credit Card rewards) adds real member value.
- Free Same-Day Delivery is called out right under the hero.

## What's weak

- The free gift is not in the hero. It sits in the second block, so the subject's promise isn't what the reader sees first.
- The hero repeats the 10%/30% creative from the 11/2 "STARTS TOMORROW: 10% off EVERYTHING 😍" send and the 10/30 launch email. It has only a small "STARTS TODAY" change.
- The email has too many modules (product grid, hair gifts, scents, store locator, gift guide, barcodes). They dilute the offer and make the email very long.
- The free-gift fine print is small, with a $100+ threshold, a time limit ("9am PT") and "while supplies last". The gift code is hard to tell apart from the ALLONSALE code above it.
- The cadence is heavy. It is the latest in a run that began 10/29, and several of those sends carried the same 30% Sephora Collection offer.

## Recommendations

- 1. Move the free-gift block into the hero, with the product image and one code. Make the hero match the subject.
- 2. Cut the module count by half. Drop the Kohl's locator and gift guide from this send, or move them to a separate email.
- 3. Reduce the codes to one per email. ALLONSALE and UNREADY compete with each other.
- 4. Move the threshold ("$100+") up from the fine print into the headline.
- 5. Space out the sends. Do not run the same 30% hero five days in a row.
- **Subject Alt A:** `Insider gift: free headband + washcloth at $100`
- **Subject Alt B:** `Your free Insider gift ends tonight 🎁`
- **Preheader Alt A:** `Spend $100, get the parachute set. Plus 10% off through 11/9.`
- **Preheader Alt B:** `Use code UNREADY at checkout. While supplies last.`

## 3. Rendering & Accessibility
- **Missing alt text (WARN):** both tracking pixels have no `alt`. The impact is minor because they are non-content images, but an empty `alt=""` is cleaner.
- **Fixed width:** the wrapper table uses `width:700px; min-width:700px`. The visible `@media (max-width:480px)` rules only resize specific classes, so the HTML I can see doesn't show how the wrapper collapses on mobile. I can't verify this because the source is truncated.
- **Malformed CSS:** an `<!--[if mso]> ... <![endif]-->` conditional comment sits inside the `@media` block of the `<style>` tag. That is invalid placement and may cause some clients to drop the rule.
- **Meta tag:** `<meta name="robots" content="no index">` uses a non-standard value (`noindex` is the valid token). It has no practical effect.
- **Structured data:** the JSON-LD block has `"discountCode": ""` and an empty `PromotionCard`. Most clients ignore it, but the empty values are invalid or meaningless.

- I can't confirm landing page alignment because the post-redirect destinations aren't in the QA data. The 12 probed links reported no failures.
