### 3. Rendering & Accessibility

**Issue — `maximum-scale=1` blocks pinch-to-zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Disabling user zoom violates WCAG 1.4.4 (Resize Text, Level AA). Remove `maximum-scale=1` or raise it to `maximum-scale=5`.

**Issue — `-webkit-text-size-adjust: none` applied broadly:**
```css
div, a, tr, table, body, span, img, strong, td { -webkit-text-size-adjust: none; }
```
`none` suppresses iOS accessibility font scaling globally. The safe value is `100%`, which prevents automatic resizing without blocking user-initiated scaling.

**No issue — DOCTYPE and Outlook shims:** XHTML 1.0 Transitional and VML namespaces (`xmlns:v`, `xmlns:o`) are correct for the target client matrix.

**Minor — malformed `robots` meta value:**
```html
<meta name="robots" content="no index" />
```
`"no index"` (space) is not a valid directive; the correct token is `"noindex"`. Harmless in email (emails are not crawled), but indicates a copy-paste error in the template shell.
