# 10% off ends soon, Rosie
**Score:** 9/10 · **Type:** Email audit · **2026-05-20**
## Executive summary

- This is the expiry-reminder leg of Sephora's welcome-discount triggered sequence — the same code SE3ARPH that debuted in the 5/14 welcome email (scored 9/10) is now dressed in a "ENDS TODAY" countdown to force conversion. The bones are sound: a live timer, the code front-and-center, a personalized name in both subject and hero, and a multi-channel barcode covering sephora.com, in-store, and Kohl's. Mechanically, this does everything a reminder email should.
- The single biggest problem is a direct contradiction the recipient will likely catch: the banner screams "ENDS TODAY" with about 12 hours on the clock, but the hero copy says "Valid through 5/25/2026" — five days from now. False urgency that's visibly inconsistent is worse than no urgency. A sharp subscriber reads that mismatch as either a mistake or a manipulation, and either reading corrodes trust.
- The "Recommended For You" section is a nice merchandising touch on paper, but as a new member with no purchase history, those recommendations are algorithmic defaults dressed as personalization. And the "Wondering Why You Got This?" transparency block — creditable intent — burns hero real estate on something that belongs in the footer.

## What's working

- **Live countdown timer with "ENDS TODAY" creates strong above-the-fold urgency** — assuming the date contradiction is resolved, this is exactly the right treatment for a re-engagement reminder
- **Name personalization is consistent** — "Rosie" appears in the subject, the hero headline, and implied throughout; it doesn't feel bolted-on
- **Promo code SE3ARPH is prominent and repeated** — shown in the hero and again in the in-store barcode block, reducing friction for both channels
- **Multi-channel barcode at the bottom** (Sephora stores, sephora.com, Kohl's) elevates this above a standard email and makes it a usable artifact the recipient might screenshot
- **Beauty Insider loyalty context is maintained** — the email correctly positions this as a member benefit, not a generic blast

## What's weak

- **"ENDS TODAY" countdown vs "Valid through 5/25/2026" is a direct contradiction** — even the most casual reader will notice, and the credibility damage hits the very urgency this email is built around
- **"SHOP NOW" is a generic CTA** — for a first-purchase moment with a specific code in hand, this is a missed opportunity; the action the user is being asked to take is more specific than "shop"
- **"Recommended For You" is almost certainly generic defaults** — Sephora has no behavioral signal on this new member; the heading sets a personalization expectation the data can't back up yet
- **"Wondering Why You Got This?" block occupies prime mid-email space** — this is footer content running at hero height; it adds word count without adding conversion pressure

## Recommendations

- 1. **Fix the urgency contradiction first.** Either adjust the countdown to count toward 5/25 (5 days), or remove "ENDS TODAY" and let the valid-through date carry the urgency. The current state is the biggest trust leak in the email.
- 2. **Rewrite the CTA** from "SHOP NOW" to "Claim My 10% Off" or "Redeem SE3ARPH" — match the copy to the user's literal next action.
- 3. **Replace "Wondering Why You Got This?" with a category selector** ("What are you shopping first? → Skincare / Makeup / Fragrance / Hair") — keeps the transparency intent as a single footer line, reclaims the space for conversion.
- 4. **Relabel the recommendations honestly** — "Beauty Insider Bestsellers" or "Most-loved by new members" is more accurate than "Recommended For You" and actually builds more credibility.

### 3. Rendering & Accessibility

**`lang` attribute missing from `<html>` tag**
```html
<html xmlns="http://www.w3.org/1999/xhtml" ...>
```
No `lang="en"` (or locale equivalent). Screen readers cannot infer language; violates WCAG 3.1.1.

**`maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. WCAG 1.4.4 failure. Drop `maximum-scale=1` or set to `5`.

**Aggressive `text-size-adjust: none` applied to nearly every element**
```css
div, a, tr, table, body, span, img, strong, td {
  -webkit-text-size-adjust: none;
  -ms-text-size-adjust: none;
  -moz-text-size-adjust: none;
  text-size-adjust: none;
}
```
Overrides OS-level accessibility font scaling for users with low vision. Should be scoped to layout containers only, not inline/content elements.

**Malformed robots meta value**
```html
<meta name="robots" content="no index" />
```
Value is `no index` (space); spec requires `noindex` (no space). Inconsequential for email clients, but signals a copy-paste error in the template.
