# ENDS TODAY: up to 50% off select beauty 🫣
**Score:** 8/10 · **Type:** Email audit · **2026-06-23**
## Executive summary

- This is Sephora's true final-day push on the Major Summer Deals campaign — but the credibility of the deadline is already spent. June 22's "The Sephora Major Summer Deals chapter is closing ⏲️" told subscribers it was over yesterday; today's "ENDS TODAY" is the second closing signal in 24 hours, which makes the urgency read as manufactured rather than real. A subscriber who noticed the June 22 subject line has every reason to assume a June 24 "One more day!" arrives tomorrow.
- Structurally the email is well-assembled: a dual-offer hero, a loyalty layer with 500 bonus points and a delivery code, a product grid, and no render bugs. The free same-day delivery code (GETAWAY) is genuinely additive — it's a hook that the pure "50% off" subject line doesn't give you. The problem is everything else is a copy of the same campaign that's been running since June 11: same badge style, same "up to 50% off select beauty" phrasing, same generic "SHOP NOW" CTA. Subscribers who haven't converted in two weeks aren't going to be moved by a sixth variation of the same message.
- The one thing this email does right that the June 22 send didn't: the preheader adds the discount code, which is actionable new information. That's where to build, not on escalating the all-caps countdown.

## What's working

- **Dual-badge hero** — pairing "Up to 50% OFF" and "Up to 25% OFF" badges communicates a tiered offer and gives the eye two concrete anchor points rather than one vague promise.
- **Loyalty bonus above the fold** — "Beauty Insiders Get More" with 500 points and free same-day delivery is differentiated value that a non-member promo can't match; it's visible without scrolling.
- **Delivery code in the preheader/banner** — "USE CODE GETAWAY" is a specific, actionable hook that adds something beyond the headline discount.
- **Product grid with named items** — "Save on must-haves like these" shows real products, giving a reason to click that isn't just "trust us, there's a sale."
- **Clean render, no bugs** — layout is tight, images load, CTAs are legible; no execution failures.

## What's weak

- **Second "final day" in two consecutive sends** — June 22 already announced the campaign was closing; today's "ENDS TODAY" is the same beat one day later, which hollows out the urgency for any subscriber paying attention.
- **"ENDS TODAY" in all-caps at the start of the subject** — this pattern trips spam filters and reads as desperation rather than urgency to a list that's been getting this campaign for two weeks.
- **"Up to 50% off select beauty" for the sixth time** — the "select" qualifier has never been explained; subscribers who didn't buy in the first five sends still don't know if anything they want is included.
- **No personalization or segmentation** — same message to everyone, no name, no "because you love skincare" hook, no tier-specific framing. A Sephora Rouge member deserves different copy than a first-time Insider.
- **Four instances of "SHOP NOW" with no specificity** — the CTA never tells you what to shop, which category, or what specific deal awaits; it just asks for a click on faith.

## Recommendations

- 1. **Break the second-closing-day pattern with a time stamp, not another "ENDS TODAY"** — "Offer expires midnight tonight" is more specific and doesn't echo yesterday's subject line. The all-caps countdown has run its course.
- 2. **Kill the "ENDS TODAY" repeat in the preheader** — the subject already has it; use that slot for the code and a product signal instead of the echo.
- 3. **Make "select" visible** — a single inline "see which products qualify →" link next to "50% off select beauty" would defuse two weeks of subscriber suspicion about whether their cart items are included.
- 4. **Fork the CTA by loyalty status** — Rouge/VIB: "Claim 500 points + 50% off"; non-member: "Join free, ship free today." The structural work is already in the email body; the CTAs just need to follow.
- 5. **Add a category anchor to the hero** — "Up to 50% off suncare, skincare & more" gives the brain something to grab onto and converts faster than the generic promise.
- **Subject Alt A:** `Last chance tonight: 50% off beauty + free delivery code`
- **Subject Alt B:** `Your Beauty Insider bonus expires at midnight 🫣`
- **Preheader Alt A:** `Use code GETAWAY — offer ends tonight, not tomorrow`
- **Preheader Alt B:** `500 bonus points + same-day delivery, final hours`

### 3. Rendering & Accessibility

**`maximum-scale=1` prevents user pinch-zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This suppresses pinch-to-zoom on iOS/Android, an accessibility barrier for low-vision users. WCAG 1.4.4 requires content to be resizable up to 200% without loss of function. Remove `maximum-scale=1`.

**Aggressive `text-size-adjust: none` on all elements:**
```css
div, a, tr, table, body, span, img, strong, td {
  -webkit-text-size-adjust: none;
  -ms-text-size-adjust: none;
  -moz-text-size-adjust: none;
  text-size-adjust: none;
}
```
Applied globally rather than scoped to the outer wrapper. Disabling text-size-adjust on `body` or `div` can override OS-level accessibility font scaling. Standard practice is to apply only to `body` or the outermost wrapper table.

**Missing `lang` attribute on `<html>`:**
```html

```
No `lang="en"` present. Screen readers use this to select the correct pronunciation engine; its absence is a WCAG 3.1.1 violation.

**`<title>Sephora</title>` is generic:**
Assistive technology and some email clients surface the `<title>` tag. Should match the subject line or describe the email content for screen reader users.
