# Woo-hoo 🎉 Up to 25% off select shampoos and conditioners 🫧
**Score:** 7/10 · **Type:** Email audit · **2026-06-19**
## Executive summary

- This is a hair care-specific promotional send riding the same "Major Summer Deals" campaign Sephora has been running since early June — but the offer has quietly stepped down from the 50% off + 500 bonus points stack that anchored the June 11 and June 16 sends to a narrower "up to 25% off select shampoos and conditioners." The hero delivers that message clearly enough, but the email then spends seven more content blocks — Beauty for All, Save & Earn 500 Points, Spot it Shop it, *another* 50% off select beauty block, Free Same-Day Delivery, Father's Day gifts, and a Beauty Insider badge — all fighting for attention below it.
- The fatal flaw is self-sabotage: a subscriber who keeps scrolling will hit a "Up to 50% off Select Beauty" section *inside the same email*, which makes the hair care hero look like a consolation prize. If the broader 50% sale is still live (and the deadline "through Sun. June 22" suggests it is), there was no reason to lead with the weaker offer.
- The "Woo-hoo 🎉" opener on the subject wants to convey excitement but lands flat against an offer that is objectively less generous than what this brand sent just three days ago.

## What's working

- **Hero is on-category and immediate.** The "Up to 25% off Shampoos & Conditioners" headline is the first thing in the render — no ambiguity about what the email is about.
- **Deadline is visible.** "Save through Sun. 6/22" is in the hero block; subscribers know the clock is ticking.
- **Promo code is present.** Code appears in the hero, giving subscribers the mechanism to act.
- **Sephora branding is clean.** Logo, color palette, and type are all consistent; no render breakage or layout bugs visible.
- **Father's Day module is a smart timing add.** June 19 is two days before the holiday — that section earns its place.

## What's weak

- **The 50% off section buried mid-email cannibalizes the 25% off hero.** A reader scrolling past will ask why they should care about 25% off shampoos when 50% off everything is also active.
- **Seven competing content blocks kill focus.** Beauty for All, Save & Earn, Spot it Shop it, broader sale, same-day delivery, Father's Day, and Beauty Insider — each a separate CTA, zero hierarchy beyond the hero.
- **"Woo-hoo 🎉" subject tone doesn't match the offer.** That opener sets up a surprise or exclusive; 25% off one category after two weeks of 50% off doesn't pay it off.
- **Subject line is too long for mobile.** At roughly 60 characters with emoji, the back half ("and conditioners 🫧") gets clipped in most inbox previews.
- **No personalization.** Sephora's Beauty Insider tier info is sitting in their database; calling out "your top repurchase" or "your skin type's picks" was skipped entirely.

## Recommendations

- 1. **Kill the competing 50% off section or lead with it.** Either make hair care the unambiguous story *or* put 50% off in the hero and mention shampoos/conditioners as an example category. Burying a better offer below a weaker one is a trust erosion.
- 2. **Tighten the subject and cut to ≤50 chars.** The "Woo-hoo" prefix wastes 9 characters and signals nothing.
- **Subject Alt A:** `25% off shampoos & conditioners — this weekend`
- **Subject Alt B:** `Hair care: up to 25% off through Sunday`
- 3. **Write a real preheader.** The inbox preview (not visible in render, likely leaking boilerplate) is a second headline; it should state the code or reinforce the deadline.
- **Preheader Alt A:** `Use code APRFRAIR at $35+. Ends Sun. June 22.`
- **Preheader Alt B:** `Top shampoos & conditioners, up to 25% off. Ends Sunday.`
- 4. **Rename the CTA.** "SHOP NOW" appears at least four times in this email. "Shop Shampoos & Conditioners" on the hero button costs nothing and doubles specificity.
- 5. **Cut to 3 sections max.** Hero (hair care sale) → products grid (3-4 top picks) → footer loyalty callout. Everything else is noise for this specific send.

### 3. Rendering & Accessibility

**`maximum-scale=1` blocks user zoom (WCAG 1.4.4 violation)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users with low vision from pinching to zoom on mobile. Drop `maximum-scale=1`.

**Missing `lang` attribute on `<html>` element**
```html
<html xmlns="..." xmlns:v="..." xmlns:o="...">
```
No `lang="en"` — screen readers cannot infer language, breaking WCAG 3.1.1. Add `lang="en"`.

**Aggressive `text-size-adjust: none` on nearly every element**
```css
div, a, tr, table, body, span, img, strong, td { -webkit-text-size-adjust: none; ... }
```
Applied to `body`, `span`, `a`, and `td` globally. This suppresses OS-level font scaling for users with accessibility settings enabled. Scope it only to elements where layout breakage is documented (typically just `td` for Outlook).

**Generic `<title>` tag**
```html
<title>Sephora</title>
```
Some clients (Samsung Mail, webmail) display this as the email's window/tab title. Use a descriptive value matching the subject line.

**`robots` meta misspelling (low-severity)**
```html
<meta name="robots" content="no index" />
```
`no index` (with space) is not a valid robots directive; correct value is `noindex`. Harmless in email context since crawlers ignore email source, but indicates a template copy-paste error.
