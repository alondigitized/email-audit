The 403 webfont failures mean all recipients render fallback system fonts. This is a server-side permissions or CDN configuration issue — the fonts exist at these paths but access is blocked for external (email client) fetch requests.

### 3. Rendering & Accessibility

**Webfonts:** All 4 custom font files are unreachable (403). Every client that attempts to load them falls back to the stylesheet's declared fallback stack.

**Alt text:** 40 images are missing `alt` attributes entirely. This includes:
- All product imagery (`.jpg` files hosted on `image.mail.crateandbarrel.com`)
- The open-pixel and personalization pixels (`o.gif`, `f3c0d22992a01946.png`, `448796.gif`) — these tracking images should carry `alt=""` (empty, not absent) to suppress screen reader announcement

**Duplicate `format-detection` meta tags:** `telephone=no`, `address=no`, and `date=no` are each declared twice in `<head>` — once in a combined tag and once individually. Redundant but not harmful.

**`maximum-scale=1` on viewport meta:** Prevents user zoom on mobile. Accessibility anti-pattern (WCAG 1.4.4).

---

### 4. Personalization & Merge Tokens

No unrendered merge token syntax (e.g., `{{first_name}}`, `[FIRST]`, `%%TOKEN%%`) detected in the truncated HTML source. Personalization appears limited to pixel-level subscriber ID parameters rather than in-template dynamic content — no issues to flag.

---

### 5. Compliance

| Severity | Finding |
|---|---|
| WARN | `List-Unsubscribe` header absent or not captured by AgentMail relay |
| WARN | `List-Unsubscribe-Post` header absent — RFC 8058 one-click unsubscribe not implemented |
| WARN | `Authentication-Results` header not captured — SPF/DKIM pass/fail unknown |

**CAN-SPAM:** Physical address and unsubscribe mechanism must be present in the message body — not verifiable from the truncated HTML, but the footer should be confirmed to contain both.

**One-click unsubscribe:** Gmail and Yahoo have enforced `List-Unsubscribe-Post` (RFC 8058) for bulk senders since February 2024. Its absence is a deliverability risk, not just a compliance gap.

**SPF/DKIM:** Sending domain is `mail.crateandbarrel.com`; authentication status unverifiable due to relay header stripping. Should be confirmed against raw headers from a received copy.

---

### 6. Email-to-Site Continuity

The 22 tracked click links were not probed, so landing page UTM coverage cannot be confirmed. From the HTML structure and pixel params observed:

- Movable Ink params (`mi_u`, `mi_mid`) are present on pixel URLs but their presence on CTA destination URLs is unverified
- No UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) are visible in the webfont or pixel URLs, which is expected — but CTA link UTM tagging should be spot-checked against a decoded tracking redirect
- `cp_tp=v` on the Dynatrace pixel suggests view-event tracking is wired; click-event tracking (`cp_tp=c`) presence on CTAs is unconfirmed

---

### 7. Recommendations

1. **Fix webfont 403s (P1):** Audit CDN/origin access policy for `/webfonts/` — likely an IP allowlist or referer restriction blocking email client fetch requests. Either whitelist broadly or serve fonts via a dedicated email-safe CDN path.

2. **Add `List-Unsubscribe-Post` header (P1):** Required for Gmail/Yahoo bulk sender compliance. Configure in the ESP (Movable Ink / sending MTA) to include both `List-Unsubscribe: <mailto:...>` and `List-Unsubscribe-Post: List-Unsubscribe=One-Click`.

3. **Confirm SPF/DKIM pass on raw headers (P1):** Pull a raw received message and verify `Authentication-Results` shows `dkim=pass` for `mail.crateandbarrel.com`.

4. **Add `alt=""` to all tracking pixels (P2):** `o.gif`, `448796.gif`, and `f3c0d22992a01946.png` should carry empty alt attributes so screen readers skip them silently.

5. **Add descriptive alt text to product images (P2):** 33 product `.jpg` images have no alt attribute. At minimum, empty `alt=""` prevents screen readers from reading out raw filenames.

6. **Remove `maximum-scale=1` from viewport meta (P2):** Blocks pinch-to-zoom. Replace with `<meta name="viewport" content="width=device-width, initial-scale=1">`.

7. **Probe 22 tracking links offline (P2):** Decode a sample of click-redirect URLs to verify destination pages are live and carry expected UTM parameters.
