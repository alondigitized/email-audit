- Most of the email is nursery, strollers, a Halloween pumpkin bag and toys. That's wrong for a 36-year-old furnishing two adult houses.
- The "Up to 10% off" event banner sits right next to a free-shipping headline. Two offers compete, and 10% is underwhelming.

- The Design Desk appears twice, and the long legal block at the bottom runs dense and unreadable.

## Technical Audit

## 1. Technical Summary
The email is a table-based XHTML 1.0 Transitional layout from Movable Ink (`mi.crateandbarrel.com`) with responsive breakpoints at 460px. The only confirmed defects are missing `alt` attributes on about 32 flagged images and a few markup hygiene issues. The header and compliance warnings come from the AgentMail relay and can't be confirmed from this data.

## 2. Link & Tracking Issues
- **74 tracking links were not probed.** The QA check skipped them as click-redirect domains, so destination validity, redirect chains and UTM presence are unverified.
- **Third-party pixels:** I count 13 tracking pixels among the flagged images:
  - 6× `https://mi.crateandbarrel.com/p/rp/f3c0d22992a01946.png?mi_u=…` (the same URL repeated)
  - 5× `https://sr.rlcdn.com/448796.gif?s=…&n=1` through `n=5` (LiveRamp)
  - `https://mi.crateandbarrel.com/p/up/50c75a732e99b42a/o.gif`
  - `https://dv.crateandbarrel.com/o/447f062b-…`
- **Same identifier in two domains:** the `rlcdn.com` `s=` value (`dbe8da718e2997cce014546f16c5722eaa3c322f28d40f0a8386f8fd1015f5a8`) starts with the same string as the first-party `mi_u=dbe8da718e2997cce014546f16c5722eaa3c322f28d40f0a8386f8fd1…`. One recipient-level identifier is being passed to a third-party data broker. This is a privacy concern rather than a rendering defect.
- **Unneeded Scene7 spacer:** `https://s7d5.scene7.com/is/image/Crate/25%5FMI%5FBottom%5FSpacer%5F40px%5FWhite` is a separate image request for a 40px white spacer, which CSS padding could replace.

## 3. Rendering & Accessibility
- **Missing alt text (confirmed):** the QA list shows 32 images with no `alt` attribute. The list may be truncated, so the real count could be higher.
  - Content images: about 19, mostly `image.mail.crateandbarrel.com/lib/fe9013727564027a7c/m/1/*.jpg|gif|png`, plus `202504%5FCBK%5FJennyLind%5FJL%5FTertiary%5F02%5F20` on `scene7`. With images off or a screen reader, these give no text.
  - Tracking pixels and spacer: about 13, all of the pixels listed in section 2 plus the Scene7 spacer. These need `alt=""` (empty, not absent) so screen readers skip them.
- **Viewport meta:** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />` blocks pinch-zoom on supporting clients.
- **Text resize disabled:** `*{-webkit-text-size-adjust:none}` and `html { -webkit-text-size-adjust:none; }` stop user text scaling in WebKit clients. The same file also sets `body { -webkit-text-size-adjust:100% }`, so the rules conflict.
- **Unescaped ampersand:** `<title>Crate & Barrel</title>` is invalid under the XHTML doctype. It should be `&amp;`.
- **Leftover template placeholder:** `<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->` is still in the source, and `<!--[if !mso]><!--> <!--<![endif]-->` is empty.
- **Duplicate `<meta name="format-detection">` tags:** there are four in total (`telephone=no,address=no,email=no,date=no,url=no`, then separate `date=no`, `address=no` and `telephone=no`). The later tags are redundant.
- **Duplicate charset declarations:** both `http-equiv="Content-Type"` and `<meta charset="utf-8">` are present.
- **Global paragraph centering:** `p{margin:0 auto; text-align:center;}` forces every `<p>` to center.
- **Repeated rules:** `.ReadMsgBody` and `.ExternalClass` are each declared twice.
- **Incomplete source:** the HTML was truncated, so I couldn't check `lang`/`role` on layout tables, preheader text or link text.

## 4. Personalization & Merge Tokens
No issues found. The truncated source shows no unrendered merge tokens. Recipient-specific values appear only as hashed identifiers in the pixel URLs.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe and List-Unsubscribe-Post (RFC 8058):** the QA check didn't find either header. The check notes the relay may not capture them, so this is **unverified, not a confirmed defect**. Mailbox providers require one-click unsubscribe for bulk senders, so check the raw message in a direct-delivery inbox.
- **Authentication-Results:** not found. Again an AgentMail relay limitation, so SPF, DKIM and DMARC status is unknown.
- **In-body unsubscribe link and postal address:** the truncated source doesn't include the footer, so I can't confirm them.
- **From domain:** the From address is on `mail.crateandbarrel.com`, a subdomain separate from the apex domain. Alignment can only be confirmed from headers.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
Not assessable. All 74 links go through tracking redirects that weren't resolved, and no landing-page URLs or UTM parameters are visible in the truncated source. There is no confirmed continuity issue, but I can't confirm continuity either.

## 7. Recommendations
1. Add `alt` text to the roughly 19 content images, and use `alt=""` on all tracking pixels and the Scene7 spacer.
2. Remove `maximum-scale=1` from the viewport meta and drop the `-webkit-text-size-adjust:none` rules.
3. Change `&` to `&amp;` in `<title>`, and remove the `IMPUT HERE` placeholder comment, the empty `!mso` block and the duplicate meta and CSS rules.
4. Reduce the 6× `f3c0d22992a01946.png` pixel to one instance, and review whether the 5× LiveRamp `rlcdn.com` pixels and the shared hashed identifier match the brand's privacy disclosures.
5. Replace the Scene7 spacer image with CSS padding.
6. For the QA pipeline itself:
   - Capture the raw headers (`List-Unsubscribe`, `List-Unsubscribe-Post`, `Authentication-Results`) from a direct send instead of the relay, so these warnings can be resolved.
   - Resolve the 74 redirect links in a follow-up probe to check destinations and UTM parameters.
   - Pass the full HTML (not truncated) so the footer, unsubscribe link and address can be checked.
