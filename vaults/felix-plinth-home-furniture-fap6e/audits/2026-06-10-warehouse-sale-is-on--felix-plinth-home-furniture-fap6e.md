### 3. Rendering & Accessibility

**`maximum-scale=1` viewport blocks user zoom** (WCAG 1.4.4 risk)
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents low-vision users from scaling the email on mobile. `maximum-scale=1` should be removed.

**Global `*` text-size-adjust reset is overly broad**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
Applied to all elements rather than `body` only. Breaks text scaling in Outlook Mobile and some webmail clients. Scope to `body` only.

**Duplicate `@font-face` for `"Lineto Brown Sub"` with conflicting sources**
Three separate blocks declare the same family name — one loads only `.woff`, two others load `.woff2` with `font-weight: 400` and `font-weight: 600` respectively. Email clients without `@font-face` weight-descriptor support (e.g., older Outlook) will use the last-declared block for all weights, potentially rendering all text at bold or light weight.

**Double-slash path in multiple font URLs**
```css
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownRegular/lineto-brown-regular.woff2")
src: url("https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2")
```
`//` after the domain is technically malformed. Most servers normalize it, but CDN rules and strict caches may 404. Remove the extra slash.

**HNW05 font loads cross-domain from `crateandbarrel.com`**
```css

```
Four HNW05 weight variants depend on a sibling-brand CDN. If that domain path changes or goes down, all HNW05 text falls back silently. Should be mirrored to `cb2.com` CDN.
