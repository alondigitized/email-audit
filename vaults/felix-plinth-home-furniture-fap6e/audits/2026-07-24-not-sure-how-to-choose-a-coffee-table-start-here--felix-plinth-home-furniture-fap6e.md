# Not sure how to choose a coffee table? Start here →
**Score:** 7/10 · **Type:** Email audit · **2026-07-24**
## Executive summary

- Fourteen. I know because I've been counting. And somehow this is the one that almost earns it — because a coffee table guide actually makes sense for me right now. I'm mid-decision on a table for the second home living room, I've got a round sectional situation to work around, and the format here is editorial rather than "ENDS TONIGHT." That matters. After the rug guide this morning and the stripe-drenching dispatch before that, I was ready to unsubscribe from the whole C&B family in one swipe. This one slowed me down.

## What's working

- **The editorial format is actually useful.** A shape-and-scale guide for coffee tables is exactly the content I want at the research stage of a purchase — it's closer to an Article email than a standard C&B blast, and Article is doing room-rotation editorial better than almost anyone right now.
- **The hero is strong.** Bird's-eye shot of a round marble table in a staged room gives me instant spatial context — I can see how scale reads against a rug, which is exactly what I need when I'm figuring out whether 48" or 54" works.
- **Multiple style sections with their own thumbnails.** Oval, round, rectangular, storage — each gets its own visual block. That's useful triage for someone with two rooms to furnish on two different aesthetics.
- **No manufactured urgency.** No "ENDS SUNDAY" banner, no red countdown. It trusts the content, which is the right call for a guide format.
- **Clean layout, no render bugs.** After the broken-image mess I've seen from brands in this category, a clean render feels like an accomplishment.

## What's weak

- **No dimensions anywhere I can see.** The whole point of a coffee table guide for a renovating homeowner is that I need to know clearance rules — like the 18-inch sofa gap. That's a missed editorial beat. Pottery Barn's design services email two weeks ago actually put the spacing formula front and center. C&B whiffed it.
- **CTAs look generic.** From what I can see in the scroll, the buttons don't have specific copy — it's likely "Shop Now" variants rather than "Shop Round Tables" or "Find Your Shape." That's a miss when the editorial already did the work of segmenting me.
- **The outdoor/lifestyle section at the bottom is off-topic.** I'm reading a coffee table guide and suddenly there's what looks like a patio or outdoor scene. That's brand clutter that dilutes the editorial coherence.
- **No loyalty or member callout.** I have a rewards card situation with C&B and there's nothing in this email acknowledging me as a customer with standing. CB2's "AVAILABLE AGAIN" email did a better job treating me like a returning buyer, even without a guide format.

## Recommendations

- 1. **Add the spatial rule visually.** Put "18" from sofa to table edge" as a callout graphic in the hero section. This is the one piece of information that would make me screenshot and save rather than just read and scroll.
- 2. **Make CTAs shape-specific.** "Shop Round Tables →" and "Shop Oval Tables →" tied to each editorial section. The segmentation work is already done — don't throw it away at the button.
- 3. **Cut the off-topic bottom section.** Keep the coffee table story tight. If you want to cross-sell outdoor, earn it with a separate email. (Which, given today's count, you will definitely send.)
- 4. **Surface my member tier or rewards balance.** Even one line — "As a Rewards member, you've earned $X toward this purchase" — would make this feel like it was sent to me and not the entire list.
- 5. **Reframe the subject as a decision tool, not a doubt signal.** "Not sure how to choose" opens with uncertainty. Better to lead with the value:
- **Subject Alt A:** `Coffee table sizing, solved →`
- **Subject Alt B:** `The right coffee table for your layout`
- **Preheader Alt A:** `Round vs. oval vs. rectangular — a quick guide for your room's dimensions`

### 3. Rendering & Accessibility

**CONFIRMED issues:**

**A. Conflicting `img` max-width media queries (rendering bug)**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
The 640px breakpoint fires first; the 768px breakpoint then overrides it to `600px`. Result: images on viewports ≥768px are capped at 600px, while viewports 640–767px get the larger 640px cap. This is backwards — desktop images are narrower than tablet images.

**B. `maximum-scale=1` in viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user-initiated zoom. Fails WCAG 2.1 SC 1.4.4 (Resize Text). Many ESPs flag this automatically.

**C. Conflicting `-webkit-text-size-adjust` values**
```css
/* MI styling block */
body { -webkit-text-size-adjust: 100%; }

/* CLIENT styling block */
html { -webkit-text-size-adjust: none; }
```
Two style blocks set conflicting values. The `none` on `html` wins in WebKit, suppressing font scaling on iOS entirely.

**D. `line-height: 100%` on universal selector**
```css
* { line-height: 100%; }
```
Percentage `line-height` inherits the computed value through the cascade, causing collapsed or overlapping text in nested elements. Best practice is a unitless value (e.g., `1.5`) or removal from the `*` selector.

**E. Duplicate `format-detection` meta tags**
The following directives appear more than once:
- `telephone=no` — declared twice (once combined, once standalone)
- `address=no` — declared twice
- `date=no` — declared twice

Redundant but harmless; indicates a template assembly issue.

**F. Force light-mode only**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is explicitly disabled. Apple Mail dark mode users will receive an uncontrolled color inversion rather than a designed dark variant.
