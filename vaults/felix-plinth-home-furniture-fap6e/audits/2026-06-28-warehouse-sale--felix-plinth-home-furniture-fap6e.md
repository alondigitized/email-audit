# WAREHOUSE SALE

## Executive summary

- Forty-six. That's my rough CB2/Crate family count for June, and this one drops on a Saturday where I've already opened "Furniture on sale right now" from the exact same sender. Two CB2 emails in a single inbox session. I'm renovating a primary and a second home simultaneously, so furniture sale emails are not background noise for me — but this family has cried wolf so many times this month that I'm starting to auto-skim before I've even opened.
- The hero saves it, a little. Warm cream room, good wood tones, nothing broken — CB2's aesthetic does the heavy lifting the subject line refuses to do. The UP TO 60% OFF headline is the first thing my eye lands on, and the category tile grid below (Furniture, Lighting, Decor, Rugs, Shop All) is exactly how I want to navigate a sale across two houses with totally different needs. Then mid-scroll there's a second sale — a red July 4th banner offering UP TO 50% OFF — and now I'm doing math. Is the warehouse sale 60% off the same things that are 50% off for July 4th? Which one is better? ## What's working

- **Hero headline is immediate.** UP TO 60% OFF lands before the scroll starts — no teaser copy, no build-up.
- **Category tile grid is smart navigation.** Furniture / Lighting / Decor / Rugs matches how I actually shop a sale when I have two rooms to fill; this beats Wayfair's "LARGE AREA RUGS are heeere!" single-category blast by a mile.
- **"MORE FOR YOU" section is doing real work.** Named products with prices — the Eloer 55" Rectangular Black Marble Coffee Table, the Napa Volpi Dining Table — feel personalized in a way generic hero banners never do.
- **EARN 10% BACK mention.** Small but relevant. I run everything through a rewards card, so seeing the loyalty stack called out, even briefly, registers.
- **No render bugs.** Lifestyle photo is clean, no broken images, text isn't overlapping anything.

## What's weak

- **Two sales, one email, zero focus.** Warehouse Sale at 60% off and July 4th Sale at 50% off in the same send creates discount math I don't want to do. Article ran a clean, single-message July 4th email last week. CB2 is hedging.
- **"WAREHOUSE SALE" in all-caps is a liquidation tent sign.** The June 28 "Furniture on sale right now" from this same account was more specific. This subject reads like the auto-generated fallback.
- **No delivery or lead time information.** I'm renovating. Whether a dining table can arrive before August matters more than whether it's 55% or 60% off. Pottery Barn at least gestures at shipping windows; CB2 doesn't bother here.
- **Wedding registry block at the bottom.** "LET'S CELEBRATE" is for a different customer. I'm 36 and buying furniture for two houses I own, not registering for a first apartment.
- **This is the second CB2 email today.** That's not a visual issue but it's the single biggest thing killing open rates from this sender in my inbox.

## Recommendations

- 1. **Run one promotion per email.** Warehouse Sale or July 4th Sale — not both. Two offers stacked don't feel like double value, they feel like the marketing team couldn't decide.
- 2. **Move "MORE FOR YOU" above the fold.** The personalized product grid is the best reason to click, and it's buried after two banners and a Crate Kids crosslink. Lead with the specific pieces.
- 3. **Add a delivery hook to the hero.** "Ships before July 4th" or "In stock now — available for July delivery" next to furniture pieces would convert me faster than any percentage.
- 4. **Drop the wedding registry module or replace it.** "Building your own space?" with a link to the Room Planner or the Design Desk would fit this email's actual audience.
- 5. **Lower-case the subject and add the number.** Specificity does more work than volume.

### 3. Rendering & Accessibility

**`maximum-scale=1` on viewport meta (line 5):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Blocks user-initiated zoom on mobile. Fails WCAG 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**Universal selector text-size-adjust override:**
```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none;}
```
Applying this to `*` rather than `body` is overly aggressive and suppresses OS-level accessibility text scaling across all elements.

**Non-standard mobile breakpoint at 418px:**
```css
@media only screen and (max-width: 418px) { .mobile { width:414px !important; } }
```
Gap exists between 419px–767px — no media query targets this range. Devices in that band (many Android phones, tablets in portrait) receive desktop layout with no override. Standard thresholds are 480px or 600px.

**Stale developer comment in production HTML:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
Typo ("IMPUT") and placeholder text shipped to end recipients. No functional impact but indicates incomplete production hygiene.

**Redundant and conflicting `@font-face` for "Lineto Brown Sub":**
The same `font-family: "Lineto Brown Sub"` is declared three times:
- First: `eot` + `woff2` + `woff` (no `font-weight` specified → defaults to 400)
- Second: `woff2` only, `font-weight: 400`
- Third: `woff2` only, `font-weight: 600`

The first unweighted declaration conflicts with the second (both are weight 400, different source sets). Email clients resolve this unpredictably. The Light variant (`Lineto Brown Light Sub`) only declares `.woff` with no `.woff2` fallback.

**Cross-origin font loading from sibling brand:**
```css

```
CB2 email loads Helvetica Neue (HNW05) from `crateandbarrel.com`. If that domain's CDN is unavailable or applies CORS restrictions, the fallback font chain fires silently. Font should be hosted on `cb2.com` or a shared CDN.
