"From our saves" reads like a curated Pinterest board rather than a blast promo, which is a different energy than the June 21 "What's old is new again" send or the Todd Snyder collab I actually liked. I'll give them credit: the editorial format — sculpture in marble, personal objects, lifestyle vignettes in that warm cream-and-natural-wood palette — is on-aesthetic for what I'm actually trying to accomplish with that space.
- The problem is there's no offer. Zero. No percentage off, no free-shipping threshold, no clearance countdown. This is pure brand content dressed up as a shopping email. Article pulled this off with the Cillian Collection because the product itself was the news. Here, CB2 is curating items I can already find in their navigation — and they're asking for a click without giving me a reason other than "we have taste." The Pottery Barn "Sunny savings UP TO 70% OFF" send two weeks ago cleared the bar because the offer was loud and real. This one is just... pretty.

## What's working

- **Entryway focus is genuinely on-target** — I have a foyer project in flight right now. This is the first CB2 send in weeks that hit a real active need.
- **Editorial format suits the subject** — "saves" framing feels curatorial, not desperate, which is a meaningful departure from the last few discount blasts.
- **Neutral, organic color palette** — cream, warm wood, marble tones. This looks like a room I'm trying to build, not a room CB2 is trying to sell me.
- **No render bugs, clean layout** — navigation, hero, editorial sections, footer all stack correctly. After Wayfair's chaos-grid coffee-maker email, clean is a virtue.
- **No bait-and-switch** — subject says entryways, email shows entryways. Wayfair opened on coffee makers and delivered 70 categories. CB2 doesn't do that here.

## What's weak

- **No price, no offer, no hook** — I am a man running two renovation budgets simultaneously. I buy on the highest-rewards card because every dollar of margin matters. Give me a number.
- **"From our saves" is vague** — Whose saves? A CB2 editor? An algorithm? "The best entryways from our saves" sounds like a Pinterest board title, and not in a good way. It implies curation without telling me why I should trust the curator.
- **The CTAs are unreadable at mobile scale** — Button copy is too small in the screenshot to parse. "Shop now" to what? The console table? The mirrors? The category page? Article linked to a specific collection and it made the click feel purposeful.
- **Cadence fatigue is real** — This is email thirty-six since mid-May. June 20 alone delivered two. Even an email I'd otherwise love feels like noise at this volume.

## Recommendations

- 1. **Add one real offer** — Even "free shipping on orders over $149" anchors the email in commerce. Right now it's a brand deck.
- 2. **Name the hero product with a price** — Show the console table in the hero, name it, price it, link to it. Article did exactly this with the Cillian sofa and it worked. Don't make me click through to find out if I can afford the thing.
- 3. **Reduce cadence** — Two emails on June 20, a third June 21, now June 22. Even four emails in three days from a brand I like is pushing me toward "mark all as read."
- 4. **Clarify "saves"** — If this is truly curated by a CB2 stylist, name them. If it's algorithmic, drop the word. "Styled entryways we love right now" is honest and warmer.

### 3. Rendering & Accessibility

**[HIGH] Unfilled template placeholder in `<head>`:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
This is a raw production artifact — a misspelled (`IMPUT` → `INPUT`) build-time comment that was never removed. It has no rendering impact but signals the template was not fully cleaned before send.

**[MEDIUM] Double-slash URLs on three `@font-face` declarations:**
```
https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2
https://www.cb2.com//Styles/CB2/fonts/BrownRegular/lineto-brown-regular.woff2
https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2
```
Most servers return a 301 redirect and resolve correctly, but some strict HTTP clients will reject the malformed path. Falls back to system sans-serif silently.

**[MEDIUM] Cross-domain font loading — `crateandbarrel.com`:**
```css
@font-face { font-family:"HNW05"; src: url("https://www.crateandbarrel.com/webfonts/...") }
```
Four HNW05 variants load from the parent brand's domain, not `cb2.com`. If `crateandbarrel.com` does not send `Access-Control-Allow-Origin` headers for cb2 email clients that enforce CORS (rare but present in some webmail renderers), these fonts will silently fail. Hosting all font assets under `cb2.com` eliminates the cross-origin dependency.

**[LOW] `maximum-scale=1` blocks user zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Violates WCAG 2.1 SC 1.4.4 (Resize Text). Users with low vision who rely on pinch-zoom cannot scale the content. Common in email but flagged for accessibility completeness.

**[LOW] `-webkit-text-size-adjust:none` applied globally:**
```css
* { -webkit-text-size-adjust: none; }
```
Suppresses OS-level font scaling on iOS/Android, compounding the zoom restriction above for users with accessibility needs.

**[LOW] Vestigial empty conditional comment block:**
```html
<!--[if !mso]><!-->  <!--<![endif]-->
```
No content between the conditional tags — leftover from template scaffolding. Harmless but noise.

**[LOW] Duplicate `@font-face` for "Lineto Brown Sub":**
The font is declared three times: once with `.eot`/`.woff` (no weight specified), once as `weight:400`, once as `weight:600`. The unweighted declaration has no `font-weight` descriptor, which means it may shadow one of the weighted declarations depending on cascade order in certain renderers.

**[INFO] Mobile breakpoint at 418px:**
```css
@media only screen and (max-width: 418px) { .mobile { width:414px !important } }
```
Intentional pairing (418 trigger → 414 layout width for iPhone SE). Does not fire for Android devices with CSS viewport widths between 419–599px, which will fall through to the desktop table layout. Standard email practice uses 480–600px as the responsive trigger.
