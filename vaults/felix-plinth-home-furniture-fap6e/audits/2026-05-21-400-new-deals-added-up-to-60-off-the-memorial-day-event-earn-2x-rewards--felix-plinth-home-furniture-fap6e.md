# 400+ NEW DEALS ADDED! Up to 60% off The Memorial Day Event + Earn 2x Rewards
**Score:** 9/10 · **Type:** Email audit · **2026-05-21**
## Executive summary

- Twenty-one. I am calling this twenty-one emails from some configuration of the Crate & Barrel family in roughly 48 hours, and this one does the thing I've been waiting for: it bumps the number to 60%. That is a real escalation from yesterday's 40%, and I noticed. I am mid-renovation on two houses and actively shopping for a dining table and Dutch ovens for the second kitchen — so the offer actually connects. The email renders cleanly, the red hero lands, the product grid is relevant.
- But the subject line is screaming at me in ALL CAPS, which is the quickest way to make me feel like I wandered into a liquidation clearance event rather than a brand I've spent money with for six years. "400+ NEW DEALS ADDED!" is not a customer benefit — it's a warehouse count. And I've been watching this offer escalate from 40% to 60% in one day, which means either I missed something real yesterday or C&B is playing the artificial urgency game and hoping I don't notice.
- I would open this specifically for the 60% number, and I'd probably save it to my deal folder rather than buy on impulse. I'd text a friend before I'd forward it. Mark as read and revisit when I know my second kitchen's exact cookware needs.

## What's working

- **60% off clears a real threshold.** Yesterday at 40% I was holding. Today at 60% I'm at least opening tabs. That escalation, manufactured or not, works on me.
- **2x Rewards lives in the hero.** I optimize for card rewards obsessively, and they put this exactly where I need to see it — I don't have to scroll to confirm the stacking math.
- **Product diversity maps to my actual shopping list.** Furniture, cookware, tableware — I see things I need for both houses. This isn't a single-category blast like Wayfair's potting bench email last week.
- **Visual hierarchy is solid.** Red hero, offer copy, product grid, CTAs — my eye follows the intended path without fighting the layout. Pottery Barn's "ASAP" email had the same clean top-to-bottom flow.
- **Memorial Day campaign coherence holds.** The red-and-white palette, the event name, the urgency framing — it reads like a coordinated campaign, not a last-minute asset dump.

## What's weak

- **ALL CAPS subject is a hard miss.** Pottery Barn ran "Get your Memorial Day deals ASAP" and it read like a tip from someone who knows me. This reads like a Google Shopping ad from 2014. Article, which I've been comparing everything to this week, never shouts.
- **"400+ new deals added" is a headcount, not a hook.** I don't want to browse 400 items — I want to know which 3 things I should look at given what I'm actually building. CB2's "Find your favorite new thing" was vague but at least it implied curation.
- **Zero personalization.** I am an active C&B customer renovating two homes simultaneously, and this email treats me like a first-name-unknown stranger. I exist in their database. Use it.
- **Every CTA says "Shop Now."** After 21 emails, generic verb-noun is not enough. "Shop Dining Room" or "See Sofas at 60% Off" would map to my actual purchase path.

## Recommendations

- 1. **Kill the ALL CAPS immediately.** The offer is strong enough to carry itself. The yelling undercuts the brand positioning C&B has spent years building relative to Pottery Barn and Article.
- 2. **Name the deadline explicitly.** Memorial Day implies "ends Monday" — but I cannot see a hard end date anywhere in the email. "Through May 26" would convert me from "save for later" to "buy tonight."
- 3. **Swap generic CTAs for category-specific ones.** "Shop Dining" / "See Cookware Deals" / "Browse Sofas" tells me where to go and confirms the offer is real in my category, not just on throw pillows.
- 4. **Surface a single hero product with a real before/after price.** PB's "ASAP" email anchored on a specific featured sofa with a visible strike-through. Pick one Dutch oven or one dining table, show the real price, make it the lead. Eight simultaneous categories dilutes urgency.
- 5. **Write a distinct preheader.** At 76 characters, the subject is already crowding the preview slot in every mobile client I use. A real preheader — even one sentence — doubles the inbox real estate doing work for you.
- **Subject Alt A:** `Memorial Day: Up to 60% off + 2x Rewards through Monday`
- **Subject Alt B:** `60% off just dropped — and your rewards points stack`
- **Preheader Alt A:** `Furniture, cookware, and bedding at the best prices we've run this year.`
- **Preheader Alt B:** `Ends Monday. Use your highest-rewards card and earn double on top.`

### 3. Rendering & Accessibility

**[HIGH] Global `text-size-adjust: none` applied via wildcard selector**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; ... }
```
Disabling text-size adjustment on `*` (not just `body`) overrides user agent accessibility preferences globally. WCAG 1.4.4 violation risk. Should be scoped to `body` only.

**[MEDIUM] `maximum-scale=1` in viewport meta blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-zoom on mobile. WCAG 1.4.4 (Resize Text) failure on iOS. Remove `maximum-scale=1`.

**[MEDIUM] Dark mode explicitly suppressed**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Forces light rendering in Apple Mail and other dark-mode-capable clients. If the email's images have transparent backgrounds or hard-coded light backgrounds, this is correct — but it should be intentional and documented, not a default. No dark mode fallback CSS is present.

**[MEDIUM] Conflicting image `max-width` breakpoints**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewport ≥768px, the 600px rule overrides the 640px rule due to cascade order (768px block appears last). Images are constrained to 600px on desktop despite the container apparently being 640px wide. Either consolidate to a single breakpoint or reorder so the more-specific rule wins.

**[LOW] Global `line-height: 100%`**
```css
* { line-height: 100%; }
```
`100%` on `*` computes relative to font-size, which is fine for text but can collapse spacing on elements with no font-size set. Scope this to `td, p, span` instead.

**[LOW] Duplicate `<meta charset>` declarations**
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta charset="utf-8">
```
Both are present — redundant but not harmful. Keep only `<meta charset="utf-8">`.

**[LOW] Triplicate `format-detection` tags**
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```
The first tag already covers all values. The three subsequent tags are redundant template artifacts. Remove lines 2–4.
