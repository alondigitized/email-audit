### 3. Rendering & Accessibility

**`maximum-scale=1` blocks user zoom — confirmed violation:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on iOS/Android. Violates WCAG 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**Conflicting desktop image max-width rules:**
```css
@media only screen and (min-width: 768px) { img {max-width: 600px} }
@media only screen and (min-width: 640px) { img {max-width: 640px} }
```
At ≥768px both queries match; the 640px rule (declared last) wins, allowing images 40px wider than the 600px container. This produces a layout overflow on wide desktop clients. Keep only the 600px rule.

**Global `p { text-align: center }` in reset:**
```css
p{margin:0 auto; text-align:center;}
```
Center-aligns all paragraph text globally. Long-form body copy centered rather than left-aligned fails WCAG 1.4.8 (Visual Presentation) and is unusable for screen-reader linear flow.

**Duplicate `.ReadMsgBody` / `.ExternalClass` declarations** appear in both `<style>` blocks. Not a breakage risk, but inflates payload and signals copy-paste template assembly.

**Global `line-height: 100%` on `*`:**
```css
*{line-height: 100%}
```
Overrides all inherited line-height, compressing multi-line text in Gmail/Outlook. Should be scoped to the known problematic selectors (`.ExternalClass p`, etc.) rather than `*`.
