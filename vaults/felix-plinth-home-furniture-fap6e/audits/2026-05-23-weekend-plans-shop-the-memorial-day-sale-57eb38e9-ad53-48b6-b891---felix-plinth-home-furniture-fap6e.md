# Weekend plans? Shop the MEMORIAL DAY SALE ✔️
**Score:** 8/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- Twenty-two. That's the number. The "BONUS deals ❤️ Extra 20% off + Shop the Memorial Day Sale!" send — reviewed yesterday — was twenty-one, and here's Pottery Barn on a Saturday morning with number twenty-two. "Weekend plans?" they ask. Yeah, my weekend plans include unsubscribing from this list.
- That said — I opened it, and the email isn't bad. "Extra 20% off" is right in the hero where I can see it without scrolling, there's a clean product grid across furniture and bedding, and the "Recommended Just For You" personalization block at the bottom actually shows items that look relevant to the coastal-casual direction both houses are trending toward. The structure is honest: clear offer, clear button, no fake countdown timer, no bait-and-switch fine print I can spot.
- But I've seen this exact offer — Extra 20% off, Memorial Day Sale, "Select styles, exclusions apply" — in some variant of this send four times in three days. Crate & Barrel's "2x Rewards + up to 50% off" email earlier this week felt fresher because the stacking mechanic was different. This is the same song, same key, fourth chorus. I'd mark it read, maybe glance at the recommended section, and not forward it to anyone — they're all already on the same Pottery Barn list anyway.

## What's working

- **"Extra 20% off" lands immediately** — the hero hierarchy puts the offer before anything else, no scroll required, no mystery.
- **"Recommended Just For You" section** — this is the one move that separates this email from emails 18 through 21. Personalization signals that Pottery Barn actually knows what I've been browsing, which is the only thing that earns attention at send number twenty-two.
- **The product grid is category-diverse** — furniture, bedding, outdoor — covers the range I'm actually shopping across two properties simultaneously.
- **No render bugs I can see** — layout is clean, images load, button is tappable. Execution is solid.
- **Memorial Day timing is credible** — the weekend-deadline framing isn't manufactured urgency; the holiday is real.

## What's weak

- **Cadence has killed the offer** — Extra 20% off meant something on email one. By email twenty-two, it's background noise. Wayfair sent fourteen emails too, but at least one was "#kitchenmats" — weird, but different. This is a straight repeat.
- **"SHOP ALL SALE" CTA is a missed opportunity** — at this point in the funnel, I know the sale exists. A CTA like "Shop New Markdowns" or "Shop Outdoor Furniture" would feel like information instead of a redirect.
- **Subject line "Weekend plans?" is trying too hard to be casual** — the conversational hook doesn't land when it's attached to the fifth Memorial Day blast; it reads like a brand that thinks we're friends.
- **No loyalty math visible** — the "earn more" micro-copy in the hero is tiny. Crate & Barrel puts the 2x Rewards mechanic front and center in the subject line itself. I run my purchases through a rewards card and I want to know the stacking story upfront, not hunt for it.

## Recommendations

- 1. **Rotate the offer mechanic** — Extra 20% has run four times. Lead with free shipping, early access to new arrivals, or double Key Rewards points. Same financial value, different read.
- 2. **Make "Recommended For You" the hero** — put the personalized items above the fold and let them carry the email. That's the one thing the generic sale blast can't replicate. CB2's "Pieces worth lusting after" editorial approach works because it leads with curation, not discount.
- 3. **CTA copy should be specific to a category** — split into "Shop Outdoor" / "Shop Bedding" / "Shop Furniture" buttons based on browse history, not one catch-all.
- 4. **Kill the "Weekend plans?" subject framing** — it feels like the social team wrote it. Go transactional and direct.
- **Subject Alt A:** `Extra 20% off — outdoor furniture picks`
- **Subject Alt B:** `Your saved items: now 20% off`
- **Preheader Alt A:** `Plus, earn double Key Rewards through Monday.`
- **Preheader Alt B:** `Furniture, bedding & outdoor — ships free this weekend.`

The `mi_mid` and `cp_cid` session tokens in the URL suggest this may be a session-scoped link that expired before send, or a misconfigured campaign code on the router.

### 3. Rendering & Accessibility

**PHP `header()` calls embedded in CSS block (template defect)**

The final `<style>` block contains raw PHP function calls that were not stripped before send:
```css
header('Content-Type: image/jpeg');
header("Cache-Control: no-store, no-cache, must-revalidate, max-age=0");
header("Cache-Control: post-check=0, pre-check=0", false);
header("Pragma: no-cache");
```
CSS parsers silently ignore these, so rendering is unaffected, but this confirms a template assembly failure — a server-side image-generation script's PHP headers were copied verbatim into the email template.

**3 images served over HTTP — may be blocked by client image proxies**
| File | Domain |
|---|---|
| `spacer_0.gif` | `http://edm.westelm.com` (cross-brand domain) |
| `Foot_NonMem_PB.jpg` | `http://edm.potterybarn.com` |
| `slices_02.jpg` (Key CC banner) | `http://edm.potterybarn.com` |

The `spacer_0.gif` from `westelm.com` is a cross-brand asset — potentially a shared CDN artifact, but anomalous in a Pottery Barn send.

**38 images missing `alt` text**

Includes content images (product grid `slices_01` through `slices_13`, banner `S26_MemorialDaySale_UrgencyTopBanner_FinalWeekend.jpg`, outdoor banner, and the full footer slice set). When images are blocked, the email renders as a blank white column with no readable content. WCAG 2.1 SC 1.1.1 non-conformant.

**Viewport locks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` prevents pinch-to-zoom in mobile browsers — an accessibility regression flagged by WCAG 1.4.4.

**`<title>` element is empty** — screen readers and some clients announce "Untitled" in the message preview pane.
