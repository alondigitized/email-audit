### 3. Rendering & Accessibility

**[HIGH] Unfired developer placeholder in `<head>`**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
Template production comment with a typo ("IMPUT") was not removed before send. Harmless to rendering but confirms the template was not properly sanitized.

**[MEDIUM] Conflicting `img` `max-width` media queries — desktop images may overflow container**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At 768px+ both queries match. Equal specificity means last-declared wins — the 640px constraint overrides the 600px rule. Images will be allowed to render at 640px on desktop, potentially overflowing a 600px table container.

**[MEDIUM] `maximum-scale=1` blocks pinch-to-zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Disabling user zoom is an accessibility violation (WCAG 1.4.4 — Resize Text). Remove `maximum-scale=1`.

**[LOW] `color-scheme` restricted to `light` only**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Suppresses dark-mode adaptation in Apple Mail and Gmail. No dark mode overrides are present in the stylesheet. This is intentional for brand control but will render as white-on-dark if the subscriber's OS forces dark mode.

**[LOW] Universal selector sets `line-height: 100%` and `mso-line-height-rule: exactly`**
```css
*{ mso-line-height-rule:exactly; line-height: 100% }
```
Applying `exactly` line-height to all elements risks descender clipping on taller glyphs in Outlook. Scope this to specific selectors rather than `*`.

**[LOW] Duplicate `format-detection` meta tags**
The combined tag appears first, then individual tags for `date=no`, `address=no`, `telephone=no` are repeated. Redundant, no functional impact, but signals template sloppiness.

**[LOW] Empty comment placeholder**
```html

```
Orphaned template placeholder node, no rendering impact.
