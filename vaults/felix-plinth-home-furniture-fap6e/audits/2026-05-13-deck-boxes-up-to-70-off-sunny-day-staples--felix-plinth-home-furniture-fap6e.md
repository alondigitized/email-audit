# DECK BOXES 🏖️ UP TO 70% OFF sunny-day staples 
**Score:** 6/10 · **Type:** Email audit · **2026-05-13**
## Executive summary

- Memorial Day outdoor sale from Wayfair — this one landed at the right time given I'm mid-renovation on two patios and actively shopping deck storage. The subject pulled me in, but the moment I opened it, it's the same format I've seen from Wayfair probably forty times this year: a massive scrollable grid with a dozen product categories, five different discount levels, and the kitchen sink. I'm actively in the market for exactly the stuff in this email — deck boxes, outdoor seating, maybe a pergola for the second place — and I still had trouble finding a reason to click anything specific.
- The "picked just for you" headline is doing work it hasn't earned. This doesn't feel personalized; it feels like a mass-send with my segment's category filter turned on. I've bought outdoor furniture, lighting, and rugs from Wayfair in the last 18 months. They have data on me. "Picked for you" should show me the actual products I've been circling, not twelve category tiles.
- I'd probably save this to my inbox folder and come back to it before the Memorial Day deadline — which, notably, isn't called out anywhere with an actual date. I wouldn't forward it. Maybe I'd screenshot the deck box discount for my partner.

## What's working

- **Memorial Day clearance timing is exactly right** — I'm actively pricing outdoor storage in May, so this landed in the correct season with intent already present.
- **"Deck boxes" in the subject line is unusually specific for Wayfair** — they usually just say "outdoor furniture" and that specificity caught me.
- **Wayfair's brand recognition earns the open** — I know exactly what I'm walking into, and that's not nothing.
- **Free & easy delivery over $35 banner** — visible mid-scroll, and relevant since I'm shipping to two addresses right now; any shipping clarity is a win.
- **Discount magnitude is real** — "up to 90% off" on some items and the multi-tier savings thresholds ("spend $500, save $50") give me something to optimize against if I'm consolidating a big order.

## What's weak

- **The "up to" discount stacking is exhausting** — I see 90% off, 70% off, 43% off, 15% off, and $700 in savings all in one scroll. Which is real? It reads like a clearance bin, not a curated sale.
- **Too many product categories competing at once** — deck boxes, rugs, gazebos, hot tubs, electric fireplaces, benches... I lost the thread. An email that's about everything is an email about nothing.
- **The ALL CAPS in the subject line is a minor flag** — "DECK BOXES" reads like a spam folder candidate; I opened it because I know Wayfair's sender domain, not because the subject felt trustworthy.
- **No specific product shown for the hero offer** — I'm not landing on the actual deck box page; I'm landing on a category browse. That's friction I don't need when I'm in a buying mindset.
- **No member pricing or rewards callout** — I buy via the highest-rewards card and track loyalty benefits. Wayfair has a loyalty tier. Not mentioned anywhere visible.

## Recommendations

- 1. **Show the actual hero product.** Lead with one specific deck box — a name, a photo, the original price, the sale price. Not "up to 70% off deck boxes." Show me the $349 box marked down to $104. That's what makes me click.
- 2. **Drop the multi-discount soup.** Pick one discount mechanic per email. The 90% off / 70% off / 43% off / 15% off / $700 combo destroys credibility. Choose the story.
- 3. **Put a deadline on the sale.** "Memorial Day" implies urgency but doesn't close the loop. "Ends Monday, May 25" would work. Use the actual date.
- 4. **Surface rewards math** if I have a points balance or tier status. I'm a repeat buyer — treat me like one.
- 5. **Consolidate the product grid.** Cut the hot tub and the electric fireplace from an outdoor-deck-box email. I'll get those in a separate send; they dilute the outdoor-storage story here.

### 3. Rendering & Accessibility

**Custom web font — partial client support**

```css
@font-face {
  font-family: "Sofia";
  src: url(https://secure.img.wfrcdn.com/st4/stores/common/fonts/sofia/sofia_reg.woff)
       format("woff");
  mso-font-alt: "Arial"
}
```

- `mso-font-alt: "Arial"` is set correctly for Outlook fallback.
- Gmail (Android/web), Yahoo, and AOL will ignore `@font-face` and silently fall back to the device default sans-serif — **not Arial**. If the design depends on Sofia for proportional spacing or headline sizing, layout may shift in those clients.
- Only a `.woff` source is declared; no `.woff2`. Most modern email clients that do honor web fonts prefer `.woff2` for download size. Low severity, but worth noting.

**`word-break: break-all` on product names**

```css
@media only screen and (max-width: 480px) {
  .ProductRec-name { word-break: break-all; overflow: hidden; display: block; height: 48px !important }
}
```

`word-break: break-all` is aggressive — it breaks at any character boundary, not word boundary. On mobile, single-word product names will be mid-word split if they overflow. `word-break: break-word` or `overflow-wrap: break-word` is the safer choice.

**Fixed pixel heights on dynamic content blocks**

Multiple product and event cells use `height: XX px !important`:
```css
.ProductRec-stars, .ProductRec-shippingCopy { height: 16px }
.ProductRec-price { height: 40px; vertical-align: top }
.ProductRec-salesCopy { height: 28px; vertical-align: top }
.u-HalfWidthBlock .EventBlock-name { height: 48px !important }
```

If any product name, price string, or shipping copy exceeds the fixed height (e.g., long sale price like "Was $249.99, Now $74.99"), the overflow is clipped. This is a known pattern in Wayfair's system, but worth flagging if any A/B or personalized content can produce longer strings.
