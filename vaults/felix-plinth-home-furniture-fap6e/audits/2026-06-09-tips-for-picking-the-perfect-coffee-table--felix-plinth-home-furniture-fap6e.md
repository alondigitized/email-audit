I scrolled expecting callouts — height ratios, round-vs-rect for sectionals, material durability — and got... more product tiles. CB2's sofa personalization email did the service-journalism thing with actual editorial weight. This doesn't.

- 4. **Kill the decorative ampersand section or make it functional.** If it links to the full buying guide or the C&B Insider program, it earns its space. As a visual accent mid-scroll, it's just friction.
- 5. **Segment this.** I have two homes in renovation. A "second home" or "new space" tag in the subject would have made me click before I even opened it.

### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta — accessibility defect**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user-initiated zoom in iOS Safari. Fails WCAG 1.4.4 (Resize Text). `maximum-scale` should be removed.

**Conflicting desktop `img` max-width media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
Both rules have equal specificity; cascade order means the `640px` rule always wins for viewports ≥ 640px, making the `600px` cap unreachable. Images will render at up to 640px wide on all "desktop" viewports. Likely unintentional — one rule should be removed or breakpoints should be non-overlapping.

**Universal `line-height` override is over-broad**
```css
* { line-height: 100% }
```
Applies to all elements including headings and list items. Can collapse multi-line text in clients that don't override it. Should be scoped to `body, td, p` at most.

**No dark mode support declared**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Opts out of dark mode entirely. No `@media (prefers-color-scheme: dark)` block present. Images with white or near-white backgrounds may render poorly in dark-mode clients (Apple Mail, Gmail Android). Not a defect per se, but a known rendering gap.

**Duplicate `format-detection` meta tags**
`format-detection` is declared three times — once as a combined value, then individually for `date` and `address` and `telephone`. The redundancy is harmless but indicates the template was assembled by concatenation without deduplication.
