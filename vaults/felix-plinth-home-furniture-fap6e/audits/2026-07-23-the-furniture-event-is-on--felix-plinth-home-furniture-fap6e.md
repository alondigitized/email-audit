# THE FURNITURE EVENT IS ON
**Score:** 9/10 · **Type:** Email audit · **2026-07-23**
## Executive summary

- Thirty-three. That's the CB2 count in my July inbox, and I'm leading with it because yesterday this same brand sent me two emails telling me the 40% sale was ending — one at some point saying "UP TO 40% OFF ENDS TODAY," another a few hours later saying "Hours left for up to 40% off." I scored those a 6 and an 8. Today, apparently, the thing that ended... is on. "THE FURNITURE EVENT IS ON." Incredible.
- I opened it anyway. Not out of curiosity — I'm renovating two properties simultaneously and forty percent off furniture is real money. The hero delivers: the 40% is loud, the CTA is clean, and the Rewards section buried below the fold actually caught me. Ten percent back with no annual fee is a number I'll run against my Amex points math. That's a genuine value prop. It just arrives after I've been trained to believe this brand's urgency signals are fiction.
- I'll click — specifically to check tables and seating for the second property. But I won't forward it, and I won't feel good about clicking. The bait-and-extend pattern has cashed out the goodwill. Pottery Barn sent 37 emails this month too, but when they said "coffee tables" last week I was literally mid-decision on a coffee table — that's targeting. This is a foghorn.

## What's working

- The 40% hero is immediately legible — I didn't need to scroll or decode; it reads at a glance
- "SHOP THE FURNITURE EVENT" is cleaner CTA copy than most of what CB2 has run this month; it's a verb, it names the thing
- The Rewards section is the sleeper value prop — 10% back, no annual fee is compelling for someone who tracks rewards math; should be higher up
- Visual hierarchy holds — hero, offer, CTA, then supplemental modules below; the eye moves naturally
- No visible render bugs — clean spacing, no broken images, nothing bleeding into each other

## What's weak

- The sale ended yesterday, twice, with confirmation emails. Now it's "on." I have the receipts in my inbox folder; every future urgency signal is now suspect
- The rug section is pure noise — I'm done on rugs; this is CB2 filling modules rather than reading my actual purchase stage
- "More For You" product grid reads like inventory clearance dressed up as personalization — Article surfaces specific dining chairs when I'm in a dining spiral; CB2 dumps a grid
- No specific pieces called out in the hero; Pottery Barn's coffee table email last week was ten times more actionable because it named the exact category I was deciding on
- Cadence fatigue means the Rewards section — legitimately interesting — barely registers because I'm in scan-and-archive mode by email 33

## Recommendations

- 1. **Name a category or hero piece in the subject line** — "THE FURNITURE EVENT IS ON" is a foghorn; "Sofas & dining — 40% off starts now" is a reason to stop scrolling
- 2. **Move or integrate the Rewards pitch into the hero** — "10% Back When You Shop the Event" reinforces buy-now intent and differentiates CB2 from Wayfair's Black Friday in July shouting match
- 3. **Own the extension** — "We extended it" is charming and human; pretending yesterday's "ENDS TODAY" didn't happen is insulting to anyone with an inbox folder
- 4. **Condition the rug module or kill it** — in a furniture event context, serve furniture; rug cross-sell can live in a separate send
- 5. **Give the "More For You" grid actual signal** — if I've browsed dining tables on CB2.com, show me dining tables; Article does this; CB2 can too
- **Subject Alt A:** `Sofas, dining, seating — 40% off today`

- **Preheader Alt A:** `10% back with CB2 Rewards. No annual fee.`

## Technical Audit — CB2 "THE FURNITURE EVENT IS ON"

### 1. Technical Summary

Table-based XHTML 1.0 Transitional email with MSO/VML conditional comment blocks and a custom web font stack. Several template hygiene issues and one confirmed accessibility violation are present in the visible HTML; full link/compliance analysis is limited by the truncated source.

---

### 2. Link & Tracking Issues

**Cross-domain font dependency** — Four `@font-face` declarations load assets from `https://www.crateandbarrel.com/webfonts/` (a separate domain from `cb2.com`). If that domain has a CDN hiccup or DNS issue, the `HNW05` font family degrades silently. No fallback font is specified in the `a {}` rule that would match `HNW05`.

**Double-slash URLs** — Three font `src` values contain a double slash:
```
https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2
https://www.cb2.com//Styles/CB2/fonts/BrownRegular/lineto-brown-regular.woff2
https://www.cb2.com//Styles/CB2/fonts/GTSectra/GT-Sectra-Display-Regular.woff2
```
Most servers normalize this, but it is a defect in the template. Click-tracking URLs and UTM parameters cannot be audited from the truncated source.

---

### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta (WCAG 1.4.4 violation):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This prevents pinch-to-zoom for users with low vision. Apple Mail and some Android clients honor this attribute.

**Global text-size-adjust suppression:**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
Applied to every element — not just specific problematic nodes. This compounds the zoom issue above and can trigger WCAG 1.4.4 failures in audit tools.

**`@font-face` conflict — three declarations for the same family name:**  
`"Lineto Brown Sub"` is declared three times: once with no weight/style descriptor (loads only `.woff`), once as `font-weight: 400` (`.woff2`), and once as `font-weight: 600` (`.woff2`). The unscoped first declaration may override the weight-specific ones in older clients.

**`font-display: swap` in email `<style>` block:**  
This CSS property is ignored by virtually all email clients. It has no effect here and adds dead code.

**Narrow breakpoint — `max-width: 418px`:**  
The responsive block targets 418px and hardcodes `.mobile { width: 414px }`, which is iPhone 6/7/8-specific. Devices wider than 418px but narrower than the desktop layout (~690px) receive no responsive treatment.

**Unremoved template placeholder:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
"IMPUT" is a misspelling of "INPUT." This comment is a template artifact that was not cleaned before send. It is inert but indicates the template was not fully audited pre-deployment.
