# Up to 50% off furniture & more
**Score:** 8/10 · **Type:** Email audit · **2026-07-01**
## Executive summary

- Forty-nine. Maybe fifty. I've genuinely lost the exact count on CB2/Crate family emails for June, but I know "NEW JUST IN" was sitting two slots above this in my inbox yesterday, and "SALE OF THE SUMMER" is still unread above that. So the first thing I do — reflexively at this point — is check whether this is just another re-skin of the same campaign. It's not, quite. "The July 4th Sale" is a real hook, the July 4th holiday is tomorrow, and "up to 50% off furniture" is not a meaningless number when I have two rooms in two houses that need sofas. That tan linen-ish sectional in the hero? I looked at that for a beat longer than I should have.
- The structure is tighter than I expected. Hero → category tiles (Outdoor, Rugs, Lighting) → a Warehouse Sale kicker at 60% off → a personalized "More For You" product grid. That layering is smarter than the blast-the-whole-catalog approach I got from Wayfair's triple-star emoji email this week. And the marble/stone round coffee table in the Warehouse Sale module? That's the kind of piece CB2 does better than anyone — PB would have styled it with too much linen, Article would have made it look like a tech startup lobby.
- That said, this is still email fifty-something from a family of brands that has been in my inbox every. single. day. this month. I'd mark it as read, pull out my phone later tonight to actually browse the sale, and not forward it to anyone. But I might click.

## What's working

- **July 4th timing is legitimate** — "The July 4th Sale" gives this email an actual cultural hook, unlike the vague "SALE OF THE SUMMER" from two days ago that could have dropped any Tuesday in June.
- **50% off furniture is genuinely relevant to me right now** — Two renovation projects, two furniture budgets; a half-price offer on furniture lands differently than a half-price offer on candles.
- **The Warehouse Sale at 60% off is a real escalation** — Most emails stop at the hero discount; burying a higher percentage deeper in the email actually rewards scrollers, which I am.
- **The "More For You" personalized grid** — Actual products with prices showing up here means CB2 is using my browse/purchase history, which I appreciate. Compare this to Wayfair's generic star-emoji sends that have zero personalization signal.
- **The hero sofa is aspirational and contemporary** — Correct aesthetic for the audience; this doesn't look like a Pottery Barn catalog shoot, and that distinction matters.

## What's weak

- **Cadence is the enemy of urgency** — When you've sent me roughly fifty emails in thirty days, "July 4th Sale" doesn't feel urgent; it feels like the next slot in the queue. Article has sent me five times in two weeks and I still opened all five because each one had a distinct creative reason to exist. This one barely squeaks by.
- **"& more" is doing zero work in the subject** — It's a wasted five characters that could have been "rugs" or "lighting" or "outdoor" — categories I'm actively shopping for a second home outdoor space.
- **The category CTA copy is all "SHOP NOW"** — Outdoor, rugs, lighting — three different destinations, three identical buttons. One of those is definitely what I want; none of the copy distinguishes them.
- **No shipping or delivery mention for furniture** — I'm buying a sofa online for a house I'm renovating. Lead time, white-glove delivery, return policy — any of those signals would make me feel safer clicking to add to cart. Pottery Barn at least surfaces "free shipping on orders $149+" somewhere in the frame.

## Recommendations

- 1. **Add a delivery/lead-time callout in the furniture section** — One line: "Ships in 4–6 weeks / free delivery on orders $X+" would remove the single biggest friction point for furniture buying online.
- 2. **Make the subject line earn its second half** — Drop "& more" and replace with a specific category: "Up to 50% off furniture + outdoor" or "Up to 50% off furniture — sale ends July 4th."
- 3. **Differentiate the category tile CTAs** — "Shop outdoor sale," "Shop rug sale," "Shop lighting sale" costs nothing and cuts the cognitive load of three identical "SHOP NOW" buttons.
- 4. **Lead with the Warehouse Sale (60% off) as a secondary hero** — Right now it's buried. If I'm scanning on mobile, I might never reach the better offer. Either surface it in the subject or move it above the category tiles.
- 5. **Give me a cadence break signal** — Even something like "Ends July 4th — last sale email of the week" would feel like respect for my inbox.

**Potential issue — double-slash font URLs:** Several `@font-face` src declarations contain double slashes that produce a technically malformed path:
```
url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
```

Most servers normalize this silently, but it can cause cache misses or 404s depending on CDN/server config. The single-slash declarations elsewhere in the same file (`https://www.cb2.com/Styles/CB2/fonts/BrownLight/lineto-brown-light.woff`) are correct.

### 3. Rendering & Accessibility

**Issue — `maximum-scale=1` in viewport meta:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents user-initiated zoom. Fails WCAG 2.1 SC 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**Issue — global text-size-adjust suppression:**
```css
*{-webkit-text-size-adjust:none;-ms-text-size-adjust:none; ...}
```
Applied via the universal selector to every element. Intended to prevent iOS font inflation but disables all user agent text scaling. Should be scoped to `body` only.

**Issue — narrow mobile breakpoint:**
```css
@media only screen and (max-width: 418px) {
  .mobile { width:414px !important; }
```
Breakpoint is 418px, targeting iPhone SE–era widths. Modern phones (iPhone 15 Pro = 430px logical width, Pixel 9 = 412px) fall outside this or right at the edge. Recommend raising to `max-width: 480px` or `600px`.

**Issue — conflicting desktop image constraints:**
```css
@media only screen and (min-width: 768px) { img { max-width: 100% !important } }
@media only screen and (min-width: 690px) { img { max-width: 690px } }
```
The 690px rule appears after the 768px rule in source order. At viewports ≥ 768px both apply; cascade order means `max-width: 690px` wins over `max-width: 100% !important` — but only if the `!important` is on the 768px rule and not the 690px rule. The `!important` on the 768px rule makes its specificity higher regardless of order, so the 100% rule actually wins at ≥768px. This ordering is confusing and should be consolidated into a single rule.

**Issue — duplicate `@font-face` for "Lineto Brown Sub":**
Three separate `@font-face` blocks declare the same family name. The first (without `font-weight`) includes `.eot` sources for legacy IE; the second and third add weight-specific `woff2`-only variants. The unweighted block may conflict with the weight-400 block in some clients.

**Issue — dev artifact comment left in production:**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
Typo ("IMPUT" vs "INPUT") and an unfilled template placeholder. Should be removed before send.

**Issue — cross-domain font dependency:**
```css
@font-face { font-family:"HNW05"; src: url("https://www.crateandbarrel.com/webfonts/...") }
```
Four HNW05 variants load from `crateandbarrel.com`, not `cb2.com`. This is a runtime dependency on a sibling brand's domain. If that domain goes down or its CORS policy changes, these fonts break silently in clients that enforce CORS on `@font-face` (rare in email, but a brittleness risk).
