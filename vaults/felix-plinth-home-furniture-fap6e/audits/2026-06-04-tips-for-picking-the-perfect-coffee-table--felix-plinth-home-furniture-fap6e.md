## What's working

- **The editorial pivot is timed well** — after four hard-sell clearance emails, a genuine guide lands like a gear shift. It signals the brand knows something beyond discounts.
- **The size/proportion diagram** is exactly the kind of content I'd screenshot and send to my architect — real utility for someone actively measuring rooms.
- **Neutral, modern lifestyle photography** reads as aspirational without being inaccessible; the tone matches how I'd style either property, not a showroom I'd never shop in.
- **Multiple table shapes and styles shown together** makes comparison easier in one email than three separate Wayfair searches — that's genuinely better than Wayfair's approach, which gave me bath mats in two separate sends with no visual cross-comparison.
- **Clean layout, no render bugs** — unlike a few Pottery Barn sends I've gotten recently, nothing is overlapping and the hierarchy reads top to bottom without confusion.

## What's weak

- **No offer** — not even a member pricing callout or "design services" hook at the bottom. Given that I'm clearly a high-intent buyer (I'm on their list, I'm renovating), leaving this as a pure-content send with zero commercial lift feels like a missed opportunity. CB2's Todd Snyder drop email managed to be editorial *and* drive to a specific collection at the same time.
- **No size or price range surfaced for the products shown** — the size guide explains proportions but doesn't let me quickly filter by my room dimensions or budget. Pottery Barn's "Chris Loves Julia" send at least showed some $$ anchors in the product grid.
- **The clearance hangover is real** — this could've been sequenced better. If I got this guide *first* this morning and the clearance emails *after*, I'd be in better shape. As it sits, "helpful C&B" feels reactive rather than intentional.
- **No personalization** — I've bought from this brand. It knows I'm not shopping for accent chairs or nursery items. A "based on what you've browsed" hook would've made this feel less like a batch-and-blast guide and more like a recommendation.

- 1. **Embed at least one member-pricing or loyalty callout** — even a subtle "Design Desk members, here's how to apply this" or "In-store design services: book free" would convert this from a read to an action.
- 2. **Add a "Shop tables sized for your room" CTA** with a filtering shortcut (e.g., "under 48\" / 48–60\" / 60+") — takes the sizing diagram from educational to transactional in one move.
- 3. **Sequence this email earlier in the day** — if this had been the 8am opener and the clearance emails had followed, the brand story would read as generous rather than desperate.
- 4. **Surface price anchors on the product grid tiles** — even "from $399" underneath each table gives me a reason to click vs. just save.
- 5. **Personalization hook in the hero** — "You've been browsing living room furniture" or similar would make this feel like it was triggered, not blasted.

### 3. Rendering & Accessibility

**Conflicting image `max-width` media queries (head `<style>`):**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
The 768px rule appears *after* the 640px rule in source order, so at viewports ≥768px both rules apply and the 600px cap wins (cascade order). The intent appears to be a 640px wide container but images are capped at 600px on desktop — a 40px discrepancy that will produce right-side gaps or unexpected image scaling.

**Viewport blocks user zoom:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` prevents pinch-to-zoom in iOS Mail and some Android clients. This is an accessibility failure (WCAG 1.4.4 — Resize Text). Remove `maximum-scale=1`.

**Global `-webkit-text-size-adjust: none`:**
```css
* { -webkit-text-size-adjust: none; ... }
```
Applied to every element via the universal selector. The standard recommendation is `-webkit-text-size-adjust: 100%` on `body` only; `none` on `*` can suppress legitimate OS-level text scaling for users with visual impairments.

**No dark mode support:**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is explicitly opted out. This is a deliberate choice but worth flagging — Apple Mail and Gmail Android will force-invert colors on images and backgrounds, which may produce unexpected visual artifacts despite the opt-out.
