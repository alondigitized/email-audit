# Our favorite look from our new collab is…
**Score:** 6/10 · **Type:** Email audit · **2026-07-21**
## Executive summary

- Twenty-five. That's the C&B family tally in July after this one, and I want to be upfront because it's doing real work on my patience. The subject line teased me — I'll give it that. The ellipsis cliffhanger is low-key effective, and "new collab" at least signals something has changed from the endless "quality furniture that lasts" drum. But when I opened it I immediately hit a mode I know too well: a long-scroll fashion-forward collab reveal where the hero is all about the designer and very little about what I'm actually supposed to be shopping for.
- The email looks clean. No broken images, the layout holds, and the palette — warm neutrals, creams, a deep olive — is genuinely nice. The collaboration seems to be a celebrity or designer partnership with furniture and maybe some textiles, and there are multiple product vignettes laid out below the hero. But the whole thing lands soft. There's no price, no offer, no urgency. It's vibes-only, and when I'm juggling two renovation timelines and a Wayfair cart that's been sitting at $3,400 for a week, vibes don't move the needle.
- I'd mark this as read and maybe revisit if Pottery Barn didn't send me their version of the same "designer collab" story two days ago with actual product availability and a 20%-off-first-purchase hook visible in the hero.

## What's working

- **Subject actually created curiosity.** The ellipsis is a cheap trick but it worked — "Our favorite look from our new collab is…" made me want to finish the sentence, which is more than yesterday's dining chair email did.
- **Visual palette is cohesive and appealing.** Warm neutrals, textured fabrics, organic shapes — this reads like a real interior, not a catalog drop.
- **Multi-product scroll layout is well-structured.** The vignettes beneath the hero give a sense of the full collab collection, which is what I'd want to see before committing to anything.
- **No render bugs visible.** Layout held on mobile width, images loaded, no overlapping text — basic but appreciated given how often CB2 has fumbled this.

## What's weak

- **No offer anywhere I can see.** Zero price points, no percentage off, no free shipping callout. This is pure brand marketing dressed as a promotional email, and I've been burned by that enough times to notice.
- **The collab partner's identity is buried or unclear from the hero.** If I opened because I wanted to know "our favorite look is…," the answer should be immediate — name big, face big. Whatever reveal is happening felt muted at thumbnail scale.
- **Demographic mismatch in the hero.** The styling in the hero image leans feminine and editorial. I'm a guy renovating two homes — I want to see how this looks in a dining room or a study, not a styled couch vignette that reads more Anthropologie than C&B.
- **Twenty-five emails in July is the actual problem.** Even if this were a 9/10 email, the fatigue tax is real. Pottery Barn paced their July sends better, and I trust them more because of it.

## Recommendations

- 1. **Put a product name and price in the hero — one line.** "The [Collab Name] Sofa. Starting at $1,299." locks the sale intent immediately and stops this from reading as an editorial-only send.
- 2. **Lead with the collab partner's name visually.** Don't make me scroll to learn who this is with. If the name carries weight, put it in the first 200 pixels — think Article's "home tour" framing, which opened with a clear byline.
- 3. **Add a concrete offer or at minimum a free-shipping callout.** Wayfair puts free shipping on everything over $35 and makes it the first line. I don't expect C&B to match that pricing structure, but an offer — even "free shipping on this collab through Sunday" — would justify the open.
- 4. **Reduce cadence or segment this send.** This is a collab announcement, not a clearance event — it should feel special. Sending it into an inbox that's already received four emails from the same brand family this week kills the specialness.

### 3. Rendering & Accessibility

**[ISSUE] `maximum-scale=1` blocks user zoom (WCAG 1.4.4)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. WCAG 2.1 SC 1.4.4 failure. Remove `maximum-scale=1`.

**[ISSUE] Conflicting `img` max-width media queries**
```css
@media only screen and (min-width: 640px) { img {max-width: 640px} }
@media only screen and (min-width: 768px) { img {max-width: 600px} }
```
Both fire on viewports ≥768px. Source order gives the 768px rule (`max-width: 600px`) precedence, silently overriding the 640px rule. If the intended max is 640px on desktop, the 768px block is incorrect. If 600px is correct, the 640px rule is dead code.

**[ISSUE] `-webkit-text-size-adjust: none` on `html`**
```css
html { -webkit-text-size-adjust:none; }
```
Disables OS-level text scaling on iOS. Accessibility concern for low-vision users; prefer `-webkit-text-size-adjust: 100%`.

**[ISSUE] Dark mode disabled with no fallback**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Forces light-only rendering. Apple Mail and Outlook dark mode will either invert colors or render the email with poor contrast. No `@media (prefers-color-scheme: dark)` override is present in the visible CSS.

**[MINOR] Duplicate style rules across two `<style>` blocks**
`.ReadMsgBody`, `.ExternalClass`, and `table td { border-collapse }` are declared in both the first and second style blocks. No rendering breakage, but increases parse overhead and complicates maintenance.
