## What's weak

- **No offer.** During 4th of July sale week. Pottery Barn has "STARTS NOW 💥" in the subject. CB2 had floor samples. This has "forever faves." I'm a rewards-card optimizer — I don't buy full price on furniture unless I have a genuine reason not to wait.
- **"Forever faves" is the laziest possible copy hook.** It means "stuff we always sell." It signals zero editorial effort or curation rationale. Why these items? Why now? I have no idea.
- **Cadence fatigue is real** — this is my twentieth C&B family email and the two Bear watch-party sends last week were genuinely excellent. Coming down from that to a permanent-collection roundup feels like a bad hangover.
- **Nothing on sale, no loyalty pricing visible** — as someone who actively tracks rewards math across cards, no discount = very little pull to click now vs. waiting for an actual event.

### 3. Rendering & Accessibility

**`maximum-scale=1` restricts user zoom (WCAG 1.4.4)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users from pinching to zoom. WCAG 1.4.4 (Resize Text) requires text to be resizable to 200% without loss of content.

**Conflicting desktop `img` max-width rules**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewports ≥768px, both rules match. The 640px rule appears *later* in the stylesheet, so it wins via cascade — images cap at 640px instead of the intended 600px on all desktop viewports.

**Duplicate `format-detection` meta tags**
`telephone=no`, `address=no`, and `date=no` each appear twice (once in a combined tag, once in individual tags). Redundant but not harmful; creates maintenance noise.

**No dark mode styles**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Declares light-only support with no `@media (prefers-color-scheme: dark)` block. On Apple Mail, Gmail app, and Outlook (dark mode), the `#e6e7e8` body background will be inverted by the client, potentially clashing with hardcoded foreground colors.

**Global `line-height: 100%` on `*` selector**
```css
*{...; line-height: 100%}
```
Applied universally before client-specific overrides. Multi-line text blocks with no explicit `line-height` will collapse to a cramped single-em baseline in some clients.
