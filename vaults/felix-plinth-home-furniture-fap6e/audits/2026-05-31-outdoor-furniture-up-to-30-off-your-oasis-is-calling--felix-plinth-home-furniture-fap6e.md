- Hero offer lands above the fold with zero ambiguity — outdoor patio imagery, "up to 30% off," lifestyle shot that isn't generic beige nothing
- Category nav row is genuinely useful: Outdoor Sofas & Sectionals, Outdoor Dining, Lounge Chairs, Umbrellas gives me four specific entry points without making me hunt
- Product tiles in the "we love these for you" section include visible prices — the minimum courtesy for furniture where sticker shock is real

- Card promo at the bottom closes the rewards loop — if you're going to drop $1,400 on a sectional, being reminded the card earns you money on this transaction is useful context

## What's weak

- "Up to 30% off" remains the hedge I've learned to distrust — Wayfair runs the same language and I've clicked through enough times to know it means 30% on the one piece I don't want and 8% on the piece I do
- No deadline anywhere in the email — Pottery Barn put a hard end-date on its bedding free-shipping send (the 8/10 I reviewed this week) and it created actual urgency; this one just says "your oasis is calling" with a directional arrow
- The "we love these for you" headline implies personalization that the rendered product grid doesn't confirm — if this is just a standard bestseller pull with a warm headline, it's a small but real trust tax
- Twenty-five emails from the C&B family this cycle — the brand got the category right but burned through enormous goodwill getting here; the three Crate & Kids sends I reviewed earlier today should not have existed

- 1. Add a hard end-date to the hero — "Sale ends June 3" or "72 hours left" converts "maybe later" into "open tab now"; CB2's recent sale send had the same missing deadline and I flagged it there too
- 2. Give one hero product a name and a price in the email body itself — "Emilio Outdoor Sofa · Was $1,299 · Now $909" anchors the 30% claim with something real and stops the "up to" hedge from doing its cynical work
- 3. Tie the card promo to this specific transaction — "Earn 10% back on this order with the Crate & Barrel Card" is three times more effective than "the card you love just got better," which sounds like a credit product ad, not a purchase incentive
- 4. Drop or fix the personalization pretense — either surface my actual browse history in that product grid or swap "we love these for you" for "bestsellers this week" and own the fact it's editorial, not algorithmic

### 3. Rendering & Accessibility

**Issue: `maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. WCAG 2.1 SC 1.4.4 (Resize Text) violation. Remove `maximum-scale=1`.

**Issue: `-webkit-text-size-adjust: none` applied globally**
```css
html { -webkit-text-size-adjust:none; }
* { -webkit-text-size-adjust:none; -ms-text-size-adjust:none; }
```
Two separate rules both suppress text size adjustment. The `html`-scoped rule is redundant and the `*`-scoped rule is overly broad. Standard practice is `-webkit-text-size-adjust: 100%` (not `none`) on `body`.

**Issue: Conflicting `img` max-width media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
Rule order means screens ≥768px get `600px` (the later 768px rule wins), but screens 640–767px get `640px`. This is likely intentional (email container is 600px), but the 640px query is dead code for practical purposes — it only fires in a 128px window that most clients don't hit. Remove or consolidate.

**Issue: No dark mode support declared**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
`supported-color-schemes: light` explicitly opts out of dark mode. Apple Mail and Outlook will auto-invert colors, potentially breaking image rendering and text contrast. At minimum, test in forced-dark-mode clients.

**Cannot assess:** `alt` text on images, heading hierarchy, color contrast ratios — all image/content blocks are in the truncated portion.
