# ENDS TODAY: Up to 50% off & 2x Rewards!
**Score:** 9/10 · **Type:** Email audit · **2026-05-26**
## Executive summary

- This is now the third Crate & Kids email I've logged since Sunday. The hero is a sage six-drawer dresser sitting in what is clearly a styled nursery shot — lamp, layered textiles, the whole soft-toned baby-room vibe. I don't have a baby room. I have a gut-renovation master bedroom and a second-home living room that needs a sofa. These are not the same problem.
- The email itself is cleanly executed — "Double Rewards is the best time to shop" lands well, the hierarchy is fine, no render gremlins. If I were a parent shopping for a crib and a patterned rug for a kid's room, this would be a solid send. But the "we chose these for you" personalization section is doing a lot of work to convince me the algorithm knows me, while serving up what is unmistakably a crib and nursery accessories. That is not what a personalization engine that has my purchase history should be surfacing.
- I would not click. I would not forward. I'm flagging it mentally as the same thing I saw on May 26 under the "FINAL DAY" subject line — same offer, same email, same wrong inbox. Mark as read and move on.

## What's working

- **Hero offer is immediate and legible** — "Up to 50% off" and "The Memorial Day Event" are visible without scrolling; no guesswork on what the email is about.
- **Double Rewards is a genuine hook** — 2x Rewards messaging shows up with a dedicated CTA block, which is the right execution for a loyalty play. Pottery Barn buries this; C&B Kids puts it in its own section.
- **Visual hierarchy holds** — logo → hero → category tiles → personalization → loyalty CTA. The eye moves naturally downward, even on a narrow mobile width.
- **Clean render** — no broken images, no overlapping type, no layout collapse. The grid of three product thumbnails is tidy.
- **"The Design Desk" is a nice differentiator** — even in a promotional send, that section signals service depth. Not relevant to me right now but it's a brand-building inclusion that doesn't feel bolted on.

## What's weak

- **Complete demographic miss** — the personalization section shows a crib. I own no cribs. I have never searched for cribs. The "we chose these for you" label is actively making this worse by claiming it's targeted.
- **Zero adult home content** — even one "shop the dresser from the hero" CTA would have given me a reason to explore. The hero dresser actually looks nice, and it goes nowhere I care about.
- **Cadence is cooked** — this is the same "ENDS TODAY / 50% off / 2x Rewards" template I already received from this same sender. It's the same subject line structure as the May 26 "FINAL DAY" send. At some point the offer loses its urgency when the deadline keeps refreshing.
- **"Shop Now" is a weak CTA** — every single button in this email says "Shop Now." Even Wayfair, which sent me email twenty-two about stair treads, managed to put a product name on at least one button.

## Recommendations

- 1. **Suppress Crate & Kids sends to subscribers with no child-category purchase history.** This is the single highest-lift change. No subject line optimization fixes a list-targeting problem this fundamental.
- 2. **Retire the "we chose these for you" label** if the logic can't distinguish between a childless renovator and a new parent. False personalization is worse than no personalization — it makes me distrust future personalization.
- 3. **Make the hero dresser shoppable.** Even if this is a kids dresser, link it directly. "Shop the Hero" or a visible price would give me something to click on reflex.
- 4. **Vary the CTA copy** — "Shop Furniture," "Shop Bedding," and "Shop Rugs" are already the category names above the buttons. The buttons should say something the labels don't: "View the sale," "See all rugs," "Explore beds."
- 5. **Collapse the loyalty CTA into the hero.** CB2's best sends lead with the offer + the reward in a single block. Having a full separate "Double Rewards" section midway down splits the email's momentum.
- **Subject Alt A:** `Memorial Day sale ends today — up to 50% off`
- **Subject Alt B:** `Your rewards double today only`
- **Preheader Alt A:** `Furniture, bedding, rugs — 50% off through midnight.`
- **Preheader Alt B:** `Double your points on everything in the sale.`

### 3. Rendering & Accessibility

**Confirmed issues:**

**3a. Conflicting `img { max-width }` breakpoints**
Two desktop media queries set conflicting values with no cascade winner logic:
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
At viewport ≥ 768px, both rules match. The 640px rule appears last in the stylesheet and wins by cascade order, giving `max-width: 640px` — overriding the apparent 600px intent. If the container is 600px wide, images can overflow by up to 40px in some clients. **Swap rule order** or consolidate into a single breakpoint.

**3b. Duplicate `format-detection` meta tags**
`telephone=no`, `date=no`, and `address=no` each appear twice in `<head>` — once in a combined tag and once as individual tags. Redundant but harmless; tidy these to reduce head weight.

**3c. No dark mode support declared**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is explicitly blocked. Apple Mail and some Android clients will attempt their own color inversion, which can make white backgrounds dark and invert text colors unpredictably. If dark mode testing has not been done against this template, flag for QA.
