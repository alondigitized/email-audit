### 3. Rendering & Accessibility

**Alt text missing on all 42 images** — every `<img>` in the email body lacks an `alt` attribute. This affects:
- Screen reader users (WCAG 2.1 §1.1.1 failure)
- Subscribers with images blocked (no fallback text for product names or CTAs)
- Apple Mail image-off rendering (blank layout)

Notable missing-alt images include all product shots (`m/1/*.jpg`), the animated GIF (`c5d25a72-...gif`), and the Movable Ink dynamic image (`dv.crateandbarrel.com/o/3f94cf7f-...`).

**`maximum-scale=1` in viewport meta:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This prevents pinch-to-zoom on mobile, an accessibility barrier for low-vision users (WCAG 2.1 §1.4.4).

**Duplicate `format-detection` meta tags:** `telephone=no`, `address=no`, and `date=no` each appear twice — once in a combined declaration and once individually. Redundant but harmless.

**`<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->` comment left in production source** — template placeholder not removed before send.
