# The rug that ties it all together
**Score:** 7/10 · **Type:** Email audit · **2026-06-15**
## Executive summary

- Twenty-nine. I'm leading with it because that's the CB2 count in my inbox since mid-May, and this one is actually different enough that I noticed. It comes from a separate sender — CB2 Free Design Services — which I clocked immediately, because I do track which list I'm on. More importantly, this is the first CB2 subject in weeks that isn't an all-caps countdown. No "WAREHOUSE SALE ENDING TONIGHT." Just a quiet, lowercase editorial hook with an unmistakable Lebowski wink. For a 36-year-old Millennial who knows every Big Lebowski quote, it landed.
- The email drops the sale angle entirely and leads with a design service push — how to choose a rug (size, use, style), then three clean CTAs for booking a free design appointment. Given that I'm actively mid-renovation on two properties and have been running mental math on living room rugs since March, this is genuinely useful content rather than inbox pollution. The "Not Sold Out Yet" product block at the bottom with what looks like a $1,900 price tag feels like an afterthought bolted on by a different team, but the main body holds.
- Would I click? Yes — the "Start Your Free Design Appointment" CTA is unambiguous and the service is free, which means zero friction on my end. Would I forward it? No — this is only useful to me because I happen to be at the exact right moment in a renovation. Compare it to Article's "Summer hosting made simple" from last week: Article managed to be editorially useful *and* drop specific products I could impulse-buy in the same send. This CB2 email is all service funnel, no impulse trigger. I'm clicking the appointment, not the $1,900 item.

## What's working

- **The subject breaks the CB2 pattern.** After "48 HOURS LEFT: VINTAGE ON SALE" and "ALMOST OVER: Design Legends Sale," a lowercase editorial title actually reads as a different sender. The Lebowski reference is a real Millennial unlock.
- **The how-to-choose structure is clean.** Size → Use → Style is the right order and doesn't condescend. Exactly what I'd expect from a brand trying to justify its design service tier.
- **Three-way meeting format respects my schedule.** In Person / Virtual / Call Us as co-equal options removes the friction of having to drive to a showroom. Virtual is where I'm ending up.
- **Free design appointment is a credible offer for a two-home renovator.** This is the first CB2 email in weeks where the word "free" means "saves me real money" rather than "free shipping on a $400 throw."
- **Sender sub-brand distinction is noticed.** CB2interiors@ feels curated, not mass-blast. That alone bought it thirty extra seconds of my attention.

## What's weak

- **The "Not Sold Out Yet" block at the bottom is an identity crisis.** The email earns its editorial credibility for seventeen scroll-inches, then staples a $1,900 product promo to the bottom. It reads like the merchandising team muscled in at the last minute.
- **No rug imagery in the "Shop by Material" section I could actually act on.** Wayfair's "Inside: 8' X 10' OUTDOOR RUGS" from last week showed me product dimensions in the subject line. CB2's material thumbnails are too small to compare at a glance.
- **Zero urgency on the appointment booking.** If "free design appointments" fill up, I have no idea. A "limited slots available" or "book before July 4th" line would move me faster.
- **Cadence fatigue is real regardless of this email's quality.** The twenty-eight emails before it have trained me to pre-skim anything from a CB2 domain. This one had to fight through that noise with no help from prior sends.

## Recommendations

- 1. **Add one urgency line to the design appointment CTA.** "Appointments fill up fast in summer" or a real slot count would turn this from "I'll do it later" to "I'm booking now." That's the single change that lifts conversions on this email.
- 2. **Cut or elevate the "Not Sold Out Yet" product block.** Either make it a real hero with a price break ("Designer pick: 40% off this rug this week") or cut it entirely. A $1,900 product with no context or offer attached adds clutter without earning its placement.
- 3. **Make the "Shop by Material" section scannable.** Wool vs. Indoor/Outdoor vs. Natural Fiber should each show a representative rug at human scale. Pottery Barn's catalog-style material breakdowns do this better — I can judge a rug type in half a second there.
- 4. **Let the editorial voice go one layer deeper.** "Consider Size" is table stakes. What I actually want is "For a sectional that seats six, here's the rug size math." One specific data point would distinguish this from generic how-to content.

### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta (line ~6)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Blocks pinch-to-zoom on mobile. Violates WCAG 1.4.4 (Resize Text, Level AA).

**Global text-size-adjust suppression**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
```
Applied to every element. Prevents OS-level font scaling for low-vision users. Should be scoped to `body` at most, and set to `100%` not `none`.

**Unfilled template placeholder in `<head>`**
```html
<!--[IMPUT HERE CLIENT FONT IMPORT SCRIPT if needed]-->
```
Production HTML contains a build-time comment that was never removed. "IMPUT" is also misspelled ("INPUT"). Low severity but signals the template was not fully finalized before send.

**Cross-brand font asset dependency**
```css
@font-face { font-family:"HNW05"; src: url("https://www.crateandbarrel.com/webfonts/...") }
```
Four `HNW05` variants load from `crateandbarrel.com`, not `cb2.com`. This creates a hard dependency on a sibling-brand domain. If that domain's CDN or CORS policy changes, the font silently falls back.

**Duplicate `@font-face` declarations for "Lineto Brown Sub"**
Three separate `@font-face` blocks declare the same `font-family: "Lineto Brown Sub"` with overlapping sources and weights. The third and fourth declarations (woff2-only, with explicit `font-weight: 400/600`) override the full multi-format block. Cascade order may produce unexpected font selection in older clients.

**Double-slash paths in font URLs**
```css
src: url("https://www.cb2.com//Styles/CB2/fonts/BrownLight/lineto-brown-light.woff2")
```
Four font `src` URLs contain `//` after the domain (not protocol-relative — these are literal double-slash paths). Most servers normalize this silently, but it is a malformed path.

**Conflicting `img` max-width media queries**
```css
@media only screen and (min-width: 768px) { img { max-width: 100% !important } }
@media only screen and (min-width: 690px) { img { max-width: 690px } }
```
At viewports ≥ 768px, the `!important` rule wins and images scale to 100% width rather than capping at 690px. Intended cap likely only applies between 690–767px.
