# NEW summer toys, NEW outdoor furniture & more!
**Score:** 8/10 · **Type:** Email audit · **2026-06-03**
## Executive summary

- Forty. That's the C&B family inbox count now, and I want to make that number visible before I say anything else — because this is the fourth email from the Crate & Barrel ecosystem landing on June 3rd alone. I got the furniture bestsellers edit, then the kitchen finds, then the coziest bed for the pet, and now I'm being routed to Crate & **Kids** for outdoor furniture. Let me sit with that segmentation decision for a second. I'm renovating two homes simultaneously and I don't have children. Crate & Kids' entire brand identity — the stroller in the scroll, the toy grid, the nursery vignette — is doing everything it can to tell me I'm on the wrong list.
- That said, the outdoor furniture in the hero actually stopped me for half a beat. The beach-setting shot with the patio seating is aspirational in the right direction — I've been building out a second-home patio and I have C&B furniture pages open in a browser tab right now. But the moment I scroll and hit "most-loved toys" followed by a stroller, I've already mentally closed the tab. The outdoor furniture angle is buried in a kids brand email when it should be headlining the main Crate & Barrel account, which already sent me a furniture edit earlier today.
- Mark as read. Wouldn't forward. Wouldn't click through to the furniture specifically because my next move would be "why is C&B main not sending me this?"

## What's working

- **Hero image lands right.** The outdoor patio scene with the seating is genuinely seasonal and relevant — correct visual for someone actively buying patio furniture right now.
- **Subject line outdoor furniture call-out.** "NEW outdoor furniture" is the one phrase that earns the open; it's specific enough to pull someone mid-renovation out of inbox fatigue.
- **Clean render.** No broken images, no overlapping text, layout holds — which, after the volume of email I've gotten today, feels like basic table stakes met.
- **Seasonal coherence.** Summer toys + outdoor furniture + new arrivals in June is a logical editorial package even if it's addressed to the wrong person.

## What's weak

- **Wrong sub-brand for my segment.** Sending outdoor furniture through Crate & Kids to a non-parent on the C&B main list is a segmentation failure. Article never does this — their kitchen email last week was sent from Article, to people who look like they care about kitchens. This feels like a suppression list that wasn't checked.
- **Stroller mid-scroll kills it.** The moment a stroller appears in the product grid, I've confirmed this email wasn't built for me. CB2's "New markdowns" email this week ran a cleaner single-audience format than this.
- **Fourth email today, different sub-brand.** The cadence doesn't feel like a strategy; it feels like four teams hitting send independently. Pottery Barn had the same problem — nine emails in 48 hours — but at least they were all PB, not PB Kids appearing between them.
- **"NEW...NEW...& more!"** subject registers mild alarm bells. Two all-caps "NEW"s and an ampersand shorthand land closer to clearance-sale energy than editorial. The 60% off email two days ago used the same ALL CAPS approach.
- **No offer specificity.** No percentage off, no free shipping threshold visible, no member pricing. Just "new arrivals" dressed as a headline — which, compared to Wayfair leading with a concrete mattress deal or CB2's markdown framing, feels like empty calories.

## Recommendations

- 1. **Route outdoor furniture to the C&B main account, not C&B Kids.** This is the single change with the highest lift. The same patio hero, stripped of strollers and toy grids, sent from crateandbarrel.com to people who've browsed outdoor furniture — that's a different email.
- 2. **Suppress C&B family cross-sends on days with 3+ touches already.** I should not be getting four emails from the same corporate family in one calendar day. Build a 24-hour suppression window across Crate & Barrel, Crate & Kids, and CB2.
- 3. **Lead with one outdoor hero product, linked directly.** Not a category page — a specific sectional or dining set with a name and a price. Wayfair's mattress email this week did this better: one product, one price, one click.
- 4. **Drop the double "NEW."** One instance, maybe in the preheader. Two in the subject reads promotional-spam.

### 3. Rendering & Accessibility

**`<title>` brand mismatch.**
```html
<title>Crate & Barrel</title>
```
Email is sent from the "Crate & Kids" sub-brand. Title tag is low-visibility in clients but surfaces in tab labels and some accessibility trees.

**`maximum-scale=1` in viewport meta blocks user zoom.**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom; fails WCAG 1.4.4 (Resize Text). A known accessibility anti-pattern in email, but flagged as a recurring infrastructure issue.

**`-webkit-text-size-adjust: none` in desktop CSS overrides body fix.**
```css
html { -webkit-text-size-adjust: none; }   /* desktop block */
body { -webkit-text-size-adjust: 100%; }   /* general reset */
```
The `html`-level `none` takes precedence over the `body`-level `100%` in WebKit. Net effect: text scaling is disabled on Safari/iOS regardless of user settings.

**`line-height: 100%` applied globally via `*` selector.**
```css
* { line-height: 100%; }
```
Overrides all line-height, including inherited values from accessible user stylesheets. Can compress paragraph readability.

**Conflicting `img` max-width media queries produce a narrowing regression.**
```css
@media only screen and (min-width: 640px) { img { max-width: 640px } }
@media only screen and (min-width: 768px) { img { max-width: 600px } }
```
Between 640–767px images render at 640px; at ≥768px they cap at 600px — images become *narrower* as viewport widens. The 768px rule should be removed or set ≥640px.

**`.showmobile` width hardcoded to `414px`.**
```css
.showmobile { width: 414px !important; }
```
Will clip on screens narrower than 414px (e.g., 360px Android). Use `100%` or a percentage.

**Duplicate `format-detection` meta tags — 4 declarations, 3 redundant.**
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```
The combined declaration on line 1 is sufficient; the three individual tags are noise.
