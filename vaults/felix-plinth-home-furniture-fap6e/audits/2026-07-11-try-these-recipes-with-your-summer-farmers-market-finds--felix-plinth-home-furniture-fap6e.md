### 3. Rendering & Accessibility

**[CONFIRMED] Conflicting image max-width media queries will produce incorrect sizing at 640–767px viewports:**
```css
@media only screen and (min-width: 640px) { img { max-width: 640px } }
@media only screen and (min-width: 768px) { img { max-width: 600px } }
```
At 640–767px, the 640px rule fires; at 768px+, it is overridden to 600px — meaning images *shrink* as the viewport widens. The 600px rule looks like it was meant to constrain the container, not imgs, or the breakpoints are inverted.

**[CONFIRMED] `maximum-scale=1` in viewport meta blocks zoom (WCAG 1.4.4 violation):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users with low vision from pinch-zooming. Should be removed or set to `maximum-scale=5`.

**[CONFIRMED] Global `*` rule applies `text-size-adjust: none` and `line-height: 100%` to all elements:**
```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none; max-height:1000000px; mso-line-height-rule:exactly; line-height: 100%}
```
`line-height: 100%` on the universal selector can cause text overlap in multiline spans; `text-size-adjust: none` suppresses the browser's mobile readability correction more broadly than intended (should be scoped to `body` or container tables only).

**[CONFIRMED] Duplicate `format-detection` meta tags — three redundant declarations:**
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">      <!-- duplicate -->
<meta name="format-detection" content="address=no">   <!-- duplicate -->
<meta name="format-detection" content="telephone=no"> <!-- duplicate -->
```
Harmless but adds unnecessary weight and signals sloppy template hygiene.
