### 3. Rendering & Accessibility

**`maximum-scale=1` in viewport meta (line 7):**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Disables user-initiated zoom on mobile. Accessibility failure (WCAG 1.4.4, Success Criterion). Remove `maximum-scale=1`.

**Conflicting desktop `img` max-width breakpoints:**
```css
@media only screen and (min-width: 768px) { img {max-width: 600px} }
@media only screen and (min-width: 640px) { img {max-width: 640px} }
```
The 640px rule is declared after the 768px rule. At any viewport ≥ 768px, both queries match and the 640px rule wins due to cascade order — the 768px rule is dead code. Images render at 640px max-width at all desktop widths, not 600px as intended for 768px+.

**Dark mode:** `color-scheme: light` and `supported-color-schemes: light` force light mode with no dark alternative. Not a bug, but images with white backgrounds will exhibit halo artifacts in dark-mode clients (Apple Mail, iOS Mail) that override forced-light.

**Wildcard `line-height: 100%`:**
```css
* { line-height: 100%; }
```
Applies to all elements including headings. Can collapse line spacing on multi-line text in some clients.

**Alt text on images:** Cannot confirm — source truncated before `<img>` tags in the body.
