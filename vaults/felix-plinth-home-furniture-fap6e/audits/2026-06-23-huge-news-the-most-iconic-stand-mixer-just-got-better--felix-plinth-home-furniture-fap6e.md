### 3. Rendering & Accessibility

**[HIGH] `maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom, violating WCAG 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**[MEDIUM] Global text-size-adjust disabled**
```css
* { -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
html { -webkit-text-size-adjust: none; }
```
Overrides OS-level text scaling preferences. Should be `100%`, not `none`.

**[MEDIUM] Conflicting desktop image max-width breakpoints**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
The 640px rule is declared after the 768px rule. On screens ≥768px both apply; the 640px rule wins due to source order, capping images at 640px even though the 768px rule intended 600px. Swap declaration order or consolidate into one breakpoint.

**[LOW] Duplicate `format-detection` meta tags**
```html
<meta name="format-detection" content="telephone=no,address=no,email=no,date=no,url=no">
<meta name="format-detection" content="date=no">
<meta name="format-detection" content="address=no">
<meta name="format-detection" content="telephone=no">
```
Four declarations; last three are redundant. Harmless but indicates copy-paste template drift.

**[LOW] Duplicate charset declaration**
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta charset="utf-8">
```
Both present. The second is the modern form; the first is legacy XHTML. Remove the `http-equiv` version.

**[LOW] Global `line-height: 100%`**
```css
* { line-height: 100%; }
```
Applied universally via `*` selector. Can collapse line spacing on multi-line body text in some clients. Scope this to specific reset targets rather than `*`.
