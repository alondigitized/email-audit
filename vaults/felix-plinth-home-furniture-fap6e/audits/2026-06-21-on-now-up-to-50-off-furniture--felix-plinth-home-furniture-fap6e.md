# ON NOW! Up to 50% off furniture!
**Score:** 9/10 · **Type:** Email audit · **2026-06-21**
## Executive summary

- Eight. That's where the C&B family count sits in my inbox now, and this one landed within hours of the "Up to 50% off furniture = the BEST time to shop" send I already read today. Same offer. Same percentage. Same brand. Different subject line with "ON NOW!" slapped in front to manufacture urgency that doesn't exist when I watched the identical sale launch this morning.
- That said, the email itself is competent. The hero — cream sectional, bright airy room — is the exact visual vocabulary that works on me during a renovation cycle. There's a mid-email callout on Orchard wood dining sets with what looks like a countdown mechanic, and that's actually the kind of specific hook that would pull me into a product page. I'm actively comparing dining tables for the second house. The "our team fitted for you" curation section at the bottom adds a modest layer of personalization that the hero doesn't have.
- But I'm not clicking today. The "ON NOW!" urgency is hollow when I already know this sale has been live since at least this morning's send. I'll drop this in my inbox folder and monitor to see if C&B actually escalates the offer or keeps recycling the same 50% language all week. Nothing to forward — my partner already saw the earlier version.

## What's working

- **Hero sofa image is on-target** — cream sectional in a bright, open living room is exactly the aspirational reference I'd pin for the primary renovation.
- **Orchard dining set callout with a countdown** — surfacing a specific product with what appears to be a time window is smarter than every other module in this email; it's the only place scarcity feels real.
- **Category shortcuts land early** — I can route to sofas, dining, or bedroom without hunting. Good information architecture when I'm buying across multiple rooms simultaneously.
- **Clean render** — no broken images, no overlapping type, nothing that signals a rushed send.
- **Summer timing is right** — a furniture markdown in late June aligns with when I'm actually pulling the trigger on pieces for the second house.

## What's weak

- **Same-day cadence is the actual story** — "Up to 50% off furniture = the BEST time to shop" already hit my inbox today. Two emails, same offer, same percentage, same brand, same calendar day. CB2's "Even more markdowns just added" send two days ago worked because it felt like a genuine escalation off a prior send — this is just inbox padding.
- **"ON NOW!" reads as theater** — the urgency is fabricated when the identical sale is already running. I'd rather have a concrete end date than all-caps performance.
- **No loyalty or rewards callout anywhere** — I run C&B purchases through a card that earns on eligible spend, and I track whether member pricing unlocks anything. If that exists here, I can't see it.
- **"Up to 50% off" is doing heavy lifting** — Pottery Barn ran "UP TO 70% OFF" the same weekend and I wasn't fully sold on that number either, but at least it created more headline pull. The Orchard countdown buried mid-scroll is more compelling than the hero; those two should trade places.

## Recommendations

- 1. **Retire the second same-day send or differentiate it completely** — if this was the "dining room" edition and the earlier send was "living room," I'd actually respect the split. As structured, it's just cadence bloat with a new subject line.
- 2. **Move the Orchard dining set countdown to the hero** — that specific product + deadline combination is the most action-driving element in this email and it's buried below the fold. Lead with the scare.
- 3. **Surface member pricing or rewards math** — one line ("Members save an extra X%") or a card callout changes the decision math for someone running the numbers across three brands.
- 4. **Add in-stock or showroom availability signals** — at this scale of purchase I want to know if I can see it in person before I commit.

- **Subject Alt B:** `The dining table you've been watching: now 50% off`
- **Preheader Alt A:** `Plus sofas, bedroom, and bestsellers all in the sale.`
- **Preheader Alt B:** `Ends soon: specific deals on the pieces actually worth buying.`

### 3. Rendering & Accessibility

**[HIGH] Viewport `maximum-scale=1` blocks pinch-to-zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents users from zooming in on text. Violates WCAG 1.4.4 (Resize Text, Level AA). Remove `maximum-scale=1`.

**[MEDIUM] Conflicting `text-size-adjust` declarations**
The wildcard rule overrides the body-scoped rule:
```css
/* wildcard — declared first, lower specificity but overrides in some parsers */
*{ -webkit-text-size-adjust: none; -ms-text-size-adjust: none; }
/* body — declared later but same effective specificity on <body> */
body { -webkit-text-size-adjust: 100%; -ms-text-size-adjust: 100%; }
```
Result is browser-dependent. iOS Safari may suppress auto-scaling entirely, causing small text to stay small after device rotation.

**[MEDIUM] Conflicting `img max-width` media queries — wrong cascade order**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }  /* declared after */
```
On screens ≥768px, both queries fire; the later-declared 640px rule wins due to cascade order. Images cap at 640px on desktop, not 600px as likely intended. Swap declaration order or use a ≥768px max-width rule that explicitly supersedes.

**[LOW] Duplicate `format-detection` meta tags**
`telephone=no`, `address=no`, and `date=no` are each declared twice — once in the combined tag and again as individual tags. Redundant; no functional harm but indicates template hygiene issues.

**[LOW] Dark mode explicitly disabled without fallback**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Email clients that force dark mode (Outlook 2019+, some Android Gmail builds) may invert or desaturate colors unpredictably since no `prefers-color-scheme: dark` CSS block is present to control the outcome.
