# Selling fast! The Spring Refresh Event is going, going...nearly gone!
**Score:** 8/10 · **Type:** Email audit · **2026-05-13**
## Executive summary

- Okay, Crate & Barrel — fair. This is one of the brands I actually track, so it went into my "Refresh" folder before I even looked at it. The Spring Sale with 30% off is real news when you're mid-renovation on two properties at once. The hero is that warm, earthy bedroom moment — terracotta-ish tones, nice linen — which is squarely in the direction I've been pulling for the second home. So the visual does some real work.
- That said, the subject line reads like a QVC countdown clock. "Going, going…nearly gone" is doing a lot of melodrama for a promotional mailer from a brand I spend actual money at. I don't need to be startled into clicking; I'm already on your list. The "we love these for you" section is interesting — product recommendations feel personalized — but the recommendations I can see in the thumbnail look like benches and tables, which, fine, but I can't tell if they're connected to anything I actually browsed. The Crate Kids bunk bed section is a swing-and-a-miss for me specifically.
- Would I click? Yes — but it's the sale percentage and the hero image doing the lifting, not the copy. I'd click through to the event landing page, scan the furniture by room, then probably tab to Wayfair to check if the same SKU is anywhere cheaper. Wouldn't forward it; this one's personal research.

## What's working

- **30% off is hard to ignore when you're buying furniture at scale.** That number is front and center in the hero. No digging required.
- **The hero bedroom image matches the aesthetic I'm actually chasing** for the second home — warm neutrals, natural materials, not the over-styled hyper-white look that dominated five years ago.
- **Visual hierarchy is clean.** Logo → offer → CTA → categories → recs → card promo. I never lost the thread.
- **The credit card callout is smart.** I consolidate purchases on the highest-rewards card, and the CB card reminder is relevant if I'm about to drop $1,500 on a bed frame.
- **"We love these for you" section signals they know I'm in their system.** Even if the recs are algorithm-y, it doesn't feel like a blast to the full list.

## What's weak

- **The subject line is breathless in a way that reads cheap.** "Going, going…nearly gone!" is fine for a flash sale on socks. For a brand at this price point, it undercuts the premium positioning.
- **"Up to 30% off" hides more than it reveals.** Is the sectional I've been eyeing at 30%? Or is it the $49 throw pillow? I've been burned by "up to" language too many times.
- **Crate Kids bunk beds are not where my head is right now.** It's not offensive, just noise — takes up visible real estate that could've gone to outdoor furniture or rugs, which I'm actively sourcing.
- **The same Spring Refresh framing has been in my inbox from at least two other brands this week.** The concept isn't wrong, but the execution doesn't distinguish Crate & Barrel from the crowd when the subject line could have been written by anyone.

## Recommendations

- 1. **Lead with what's actually discounted, not just the percentage.** If the sectionals, dining tables, or bed frames are in the event — say that. "Sofas, dining, and bed frames up to 30% off" turns a generic sale into a reason to click for someone furnishing specific rooms.
- 2. **Rewrite the subject to match the brand's actual tone.** Crate & Barrel earns trust by feeling slightly aspirational. "Nearly gone!" belongs to a different brand tier.
- 3. **Swap Crate Kids for outdoor furniture in this send** if the audience is skewed toward homeowners actively renovating — summer's coming and the patio sourcing window opens in May.
- 4. **Make the "up to 30%" credible with one anchor product.** Show one high-ticket item with a before/after price in the hero or the second section. That anchors the discount and drives trust.
- **Subject Alt A:** `Spring Refresh Event: up to 30% off sofas, dining & more`
- **Subject Alt B:** `30% off ends soon — your Spring Refresh picks`
- **Preheader Alt A:** `Bed frames, sectionals, dining tables — the biggest sale of the season.`
- **Preheader Alt B:** `Rugs, sofas, lighting — move fast before sizes sell out.`

### 3. Rendering & Accessibility

**`<title>` entity encoding error**
```html
<title>Crate & Barrel</title>
```
The document declares XHTML 1.0 Transitional, which requires strict XML encoding. The bare `&` must be `&amp;`. Parsers that enforce XHTML will reject this.

**`maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Disabling pinch-zoom is a WCAG 1.4.4 (Resize Text) failure. Drop `maximum-scale=1`.

**`-webkit-text-size-adjust: none` on `*` selector**
```css
*{ -webkit-text-size-adjust:none; ... }
```
Prevents font scaling on iOS. Should be `100%`, not `none`. Conflicts with the correct `body { -webkit-text-size-adjust:100% }` defined later in the same stylesheet.

**Conflicting `img { max-width }` rules**
```css
@media only screen and (min-width: 768px) { img { max-width: 600px } }
@media only screen and (min-width: 640px) { img { max-width: 640px } }
```
Both are labelled `/* For desktop */` but the 640px breakpoint fires first and is overridden by 768px. At exactly 640–767 px viewport width, images cap at 640 px; above 768 px they cap at 600 px — the narrower value wins despite the wider viewport. The rule ordering should be inverted or consolidated.

**Duplicate `format-detection` meta tags**
`telephone=no` and `address=no` each appear twice — once in a combined tag and again as standalone tags. Redundant but harmless; indicates template hygiene issue.

**No dark mode support**
```html
<meta name="color-scheme" content="light">
<meta name="supported-color-schemes" content="light">
```
Dark mode is suppressed entirely. Apple Mail and Gmail app will force-invert or override colors unpredictably on dark-mode devices. At minimum, add `light dark` and test.

**`max-height:1000000px` on `*` selector**
```css
*{ max-height:1000000px; ... }
```
The Outlook line-height hack is applied globally rather than scoped to the elements that need it. This is a known workaround but should be limited to `table`, `td`, or specific classes to avoid side effects in modern clients.
