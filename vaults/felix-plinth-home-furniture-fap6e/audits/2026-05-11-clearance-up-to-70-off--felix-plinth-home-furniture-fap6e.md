# 🔴 CLEARANCE ⚪ UP TO 70% OFF 🔵
**Score:** 7/10 · **Type:** Email audit · **2026-05-11**
## Executive summary

- This is a classic Wayfair clearance blitz — Memorial Day angle, stacked discount headlines, a mile-long scroll of product modules. I'll be honest: the moment I see ALL CAPS and three flag emojis in the subject, part of my brain files it next to "the coupon mailer I get from the grocery store." That said, I'm actively furnishing two properties right now, so I'm at least going to crack it open on principle.
- Inside, there's real volume here — outdoor furniture, lighting, bedroom pieces, storage — all relevant to what I'm dealing with week-to-week. But this email doesn't *know* that about me. It's a clearance firehose aimed at everyone on the list. "Picked just for you" is doing a lot of heavy lifting when what I'm actually looking for is a specific side table or a flush-mount fixture that isn't discontinued. The BOGO 15% off buried right under the 70% off headline is also a quiet credibility hit — those are not equivalent offers, and leading with the bigger number before shrinking it is exactly the move that makes me double-check the fine print.
- I'd scan it, click maybe one product if the thumbnail looked right, then move on. Wouldn't forward it — Pottery Barn's sale emails feel more curated and I'd rather send that version to my partner.

## What's working

- **Memorial Day peg is believable.** It's mid-May, the timing tracks, and the header makes the urgency legible at a glance.
- **Wayfair sender name is trusted.** I'm on their list for a reason; the deliverability from `members.wayfair.com` signals they're treating me as an existing customer.
- **"Picked just for you" has star ratings.** Small thing, but social proof in that module actually makes me slow down on a product thumbnail in a way a bare price tag doesn't.
- **Free delivery threshold is visible.** $35 bar is displayed clearly near the bottom — that's table stakes for furniture but I appreciate it being said explicitly rather than buried in footer legalese.
- **Render is clean.** No broken images, no placeholder text, layout holds on the viewport I'm looking at.

## What's weak

- **The subject line reads like a clearance rack sticker, not an invite.** ALL CAPS + three colored-circle emojis = the visual equivalent of a car dealership sign spinner. Doesn't match how I think about Wayfair when I'm in "serious home project" mode.
- **BOGO 15% sandwiched next to 70% off is a downgrade.** It reads like a bait-and-switch without actually being one — but the juxtaposition kills confidence in both offers.
- **No category filtering.** If they know I've been browsing outdoor seating and pendant lights, none of that intent is reflected here. Everything from coolers to office chairs shares equal real estate.
- **CTA copy is lazy.** "Savings ›" repeated across every module tells me nothing about where I'll land. I want to know if I'm going to a curated clearance room or a 40,000-item filtered grid.
- **Scroll fatigue is real.** This email is very long. By the time I'm four sections in, I've already stopped reading discount percentages because they're all the same shape.

## Recommendations

- 1. **Cut the email in half.** Pick three categories, not ten. For my segment (active home projects, multi-room buyer), lead with furniture + outdoor, drop everything else into a "more clearance" link.
- 2. **Kill the ALL CAPS subject and flag emojis.** Write it like a friend with good taste tipping me off, not a megaphone.
- 3. **Make BOGO its own send or move it to the footer.** It competes with and undermines the 70% off headline.
- 4. **Give the CTAs real copy.** "Shop Outdoor Clearance" beats "Savings ›" every single time for someone who wants to know where they're going before they tap.
- 5. **Tie "Picked for you" to something behavioral.** Even a single line — "Because you've been browsing seating" — would make that module feel worth my time.

### 3. Rendering & Accessibility

**Fixed-height containers on mobile — confirmed issue:**

```css
@media only screen and (max-width: 480px) {
  .ProductRec-name { height: 48px !important }  /* + word-break: break-all */
  .ProductRec-price { height: 40px; vertical-align: top }
  .ProductRec-salesCopy { height: 28px; vertical-align: top }
  .ProductRec-stars, .ProductRec-shippingCopy { height: 16px }
}
```

These hard pixel heights will clip product names, prices, or copy if the text is longer than the box or if system font scaling is active (accessibility/large-text users). `word-break: break-all` on `.ProductRec-name` also breaks mid-word regardless of whitespace, which degrades legibility.

**Font loading — minor issue:**

```css
@font-face {
  font-family: "Sofia";
  src: url(https://secure.img.wfrcdn.com/st4/stores/common/fonts/sofia/sofia_reg.woff) format("woff");
  mso-font-alt: "Arial"
}
```

Only `.woff` is declared — no `.woff2` source. Modern clients will download the larger .woff file unnecessarily. `.woff2` should be listed first with `.woff` as fallback. This is a performance issue, not a rendering failure.

**CSS block size:** The `<head>` CSS block is very large. Gmail clips messages at ~102 KB total; if the full email approaches that threshold, the CSS block will be partially dropped and mobile layout will break.
