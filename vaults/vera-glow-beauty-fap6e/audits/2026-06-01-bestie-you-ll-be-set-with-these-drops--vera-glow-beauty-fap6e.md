# Bestie, you’ll be set with these drops ✨ 
**Score:** 8/10 · **Type:** Email audit · **2026-06-01**
## Executive summary

- Email twenty. I counted. And this one — arriving on the first day of Pride Month — is a completely unthemed product catalog dressed up as a "weekly highlight reel." The hero is pretty: a powder compact in a dreamy pink haze with clever wordplay for a highlighter feature. I give them that. But before I even get to the hero, I'm staring at a banner that reads "YOUR WELCOME OFFER IS WAITING! USE CODE KBWZ-P3IM-87IM-GITCK TO REDEEM." I've received nineteen emails from e.l.f. in the last sixteen days and they're serving me a welcome trigger. That's not a nice-to-meet-you; that's a broken automation that tells me exactly how much they know about my subscriber history, which is apparently nothing.
- It's June 1. Sally Beauty just tied a whole BOGO mechanic to National Nail Week — an actual calendar occasion — and Charlotte Tilbury is doing polished editorial storytelling on every send. E.l.f. markets itself as "for every eye, lip, and face" and has historically gone big on Pride. Today they sent me the same grid of unnamed product thumbnails they've been sending since mid-May. No Pride hook. No seasonal frame. No offer. Just "drops."
- I'd mark this read without clicking. I will not forward it.

## What's working

- "YOUR WEEKLY HIGHLIGHT REEL" is genuinely clever wordplay for a highlighter-forward hero — that's one of the few subject-to-hero payoffs e.l.f. has earned this month.
- Dual hero CTAs ("SHOP BEST SELLERS" / "SHOP NEW ARRIVALS") give me a choice between comfort and curiosity, which is smart structure.
- "HOT AS E.L.F. THIS WEEK." uses a bold editorial header that adds some urgency without a countdown — the four-product grid below it works.
- The footer benefits row is clean and scannable: free shipping at $35, free gifts at $35, Afterpay, Beauty Squad app — all stated clearly with no asterisks hiding the threshold.
- No render bugs anywhere — everything loaded, layout held, text was readable at mobile size.

## What's weak

- The welcome code banner is a full trust-breaker on email twenty. "YOUR WELCOME OFFER IS WAITING!" in all-caps with a raw alphanumeric code string looks like a trigger misfire, and it is.
- It's June 1. E.l.f. has zero Pride Month content. For a brand that runs "for every eye, lip, and face" as their tagline, this is a visibility and credibility miss that I notice immediately.
- "YOUR NEW OBSESSIONS" shows a grid of tiny, nameless product thumbnails — no product names, no prices, no shade callouts. I'm staring at colored rectangles. Drunk Elephant at least gives me enough detail to know what I'm clicking.
- The subject "Bestie, you'll be set with these drops" tells me nothing — no category, no product, no offer. ILIA pulls this vague-intrigue trick every send and it's exhausting across my entire beauty inbox. Glossier is on their third hero for the Pink Capsule Collection this week; I'm over "drops" that don't tell me what's dropping.
- Zero loyalty math. I'm on Beauty Squad. There's no points multiplier, no reward tier nudge, no "earn X more points to your next reward" — nothing that treats me like a known member rather than a cold prospect.

## Recommendations

- 1. **Kill the welcome trigger for active subscribers.** A subscriber-status guard that mutes the welcome flow for anyone past email #2 (or 30 days in, whichever comes first) would fix the biggest trust problem in this email. Ship that rule before the next send.
- 2. **Add a Pride Month hook.** It's literally day one. Lead with "for every eye, lip, face — and identity," feature the most inclusive shade range, highlight a community partnership if one exists. Sally Beauty showed this week that tying a mechanic to a calendar occasion drives action. Take the gift.
- 3. **Name the products in the grid.** If I can't see the product name and price in the thumbnail, I have to click just to find out what I'm looking at. That's friction. Charlotte Tilbury includes enough product context in the email body that I make a purchase decision before I click.
- 4. **Add a loyalty moment to the hero.** One line — "Earn double Beauty Squad points this week" or "You're X points from your next reward" — converts browsers into buyers for members like me who are always doing the math.
- 5. **Earn the "weekly" framing.** If this is meant to be the weekly highlight reel, let it be the only e.l.f. email that week. Twenty emails in sixteen days is not a weekly reel. It's a firehose.

### 3. Rendering & Accessibility

**`<title>` tag is empty.**
```html
<title></title>
```
Some clients (iOS Mail, Gmail web) surface the title in browser tabs or notification previews. Empty title is a missed signal and causes validation warnings.

**Invalid `font-family` declaration — empty string as first value.**
```css
font-family:'',Verdana,Sans-serif
```
The leading empty string `''` is invalid CSS. Browsers silently skip it and fall back to Verdana. This pattern is consistent with an unfilled template variable (e.g., a custom font name that was never substituted). Confirm the template variable is bound before send.

**Google Fonts loaded twice with inconsistent specs.**
- In `<head>` (non-MSO only): `https://fonts.googleapis.com/css?family=Jost` — loads default weight only
- In inline `<style>` in `<body>` (all clients): `@import url('https://fonts.googleapis.com/css2?family=Jost:ital,wght@0,100..900;1,100..900&display=swap')` — loads full weight range

Non-MSO clients issue two separate HTTP requests for the same font. The `<link>` variant loads a narrower weight set than the `@import`, creating a race condition where the lighter weight spec could win depending on parse order.

**`tabindex="-1"` on logo link removes it from keyboard tab order.**
```html
<a href="https://links.elfcosmetics.com/…" target="_blank" style="outline:none" tabindex="-1">
```
Combined with `outline:none`, this makes the logo link completely unreachable via keyboard navigation. WCAG 2.1 SC 2.1.1 requires all interactive elements to be keyboard-accessible.

**`#MessageViewBody a` suppresses link underlines globally.**
```css
#MessageViewBody a{color:inherit;text-decoration:none}
```
This Gmail-targeted rule removes underlines from all links inside message body, which may violate WCAG 2.1 SC 1.4.1 (use of color) if link color alone doesn't distinguish them from surrounding text.

**Nested `nl-container` table structure (template-in-template artifact).**
The outer wrapper already establishes `<table class="nl-container">`, and a second identical `nl-container` is rendered inside a `<div>` within a body cell. This is a template composition artifact (a block was embedded inside another block) and can cause double-margin or alignment drift in Outlook.
