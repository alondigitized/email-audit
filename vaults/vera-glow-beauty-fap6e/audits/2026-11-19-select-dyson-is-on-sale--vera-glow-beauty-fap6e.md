## Technical Audit

## 1. Technical Summary
The visible HTML source is a 700px table-based XHTML 1.0 Transitional layout with first-party click tracking on `app.sephora.com`. The only hard QA failure is the missing plain-text part. The header warnings (List-Unsubscribe, Authentication-Results) are not verifiable from this capture. The source was truncated, so footer, unsubscribe, and most link evidence were not available.

## 2. Link & Tracking Issues
- **No confirmed broken links.** The QA run probed 12 of 45 links and skipped 33, and it reported no probe failures.
- **Click tracking is first-party.** Links use `https://app.sephora.com/T/v61000001a1f4337…?__dU__=…`, a redirect-wrapped URL. The final destinations are not visible, so they could not be checked.
- **Open pixel:** `<img src='https://app.sephora.com/O/AQEAAZcF2g…' style="display:none; max-height:0; font-size:0; overflow:hidden; mso-hide:all"/>`. It is hidden, which is expected for an open pixel. The QA "missing alt text" warning refers to this image, so it is a **false positive**. The pixel is not user-visible, and an empty `alt=""` would still be cleaner.

## 3. Rendering & Accessibility
- **Zoom disabled:** `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">`. `maximum-scale=1` blocks pinch-zoom, which conflicts with WCAG 1.4.4 (Resize Text).
- **Fixed wrapper width:** the wrapper table has `style="min-width:700px; width:700px"`. The only media query is `@media (max-width:480px)`, and it adjusts font sizes and logo/icon dimensions but not the wrapper. This likely causes horizontal scroll or shrink-to-fit on narrow clients that honor `min-width`. I could not confirm this beyond the truncated source.
- **Malformed style block:** `<!--[if mso]> img.mso-size {…} <![endif]-->` sits inside the `@media` rule in the `<style>` block. Conditional comments there are not valid CSS and may be dropped, or may interfere with the rules after them, in some clients.
- **Invalid meta value:** `<meta name="robots" content="no index">` should be `noindex`. It has no practical effect in email.
- **Schema markup:** the JSON-LD block has `"discountCode": ""` and a bare `PromotionCard` with no properties. Gmail will likely ignore or reject it.
- **Plain-text part:** QA reports `[FAIL] Plain-text fallback missing or too short: Text version is 0 chars`. A missing text/plain alternative hurts deliverability and accessibility. It could be a relay capture artifact, so check the raw MIME to confirm.

## 4. Personalization & Merge Tokens
No issues found in the visible source. No unrendered merge tokens (`%%…%%`, `{{…}}`, `[FIRSTNAME]`) appear. The empty `discountCode` in the JSON-LD is the only empty field and is not a merge failure.

## 5. Compliance
- **Headers:** QA flagged `List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) as not found, and `Authentication-Results` as not found. QA attributes these to the AgentMail relay stripping or not capturing headers. The data does **not** confirm a real defect, so they are unverified rather than failures. Check the raw message headers at the source.
- **Footer:** the physical address and unsubscribe link are in the truncated portion, so they could not be assessed. QA says an unsubscribe link was included in the probe set, but it gave no result.

## 6. Email-to-Site Continuity
Cannot assess. The final landing URLs and any UTM parameters are not visible, because tracking is wrapped in the `app.sephora.com/T/…` redirect and the source was cut off. No continuity issues are evidenced.

## 7. Recommendations
1. Add a text/plain alternative (QA FAIL), after verifying in the raw MIME that it is really absent.
2. Remove `maximum-scale=1` from the viewport meta.
3. Make the 700px wrapper fluid (`width:100%; max-width:700px`) and drop `min-width:700px`, or add a mobile override.
4. Move the `<!--[if mso]>` block out of the `@media` rule.
5. Clean up the JSON-LD (remove the empty `discountCode` and the bare `PromotionCard`) and fix `no index` to `noindex`.
6. Re-run QA against the raw `.eml` to verify List-Unsubscribe, List-Unsubscribe-Post, and SPF/DKIM/DMARC, and against the full HTML to cover the footer and final landing-page URLs and UTMs.
7. Ignore the alt-text warning for the tracking pixel. Suppress it in the QA tool for `display:none` 1×1 images.
