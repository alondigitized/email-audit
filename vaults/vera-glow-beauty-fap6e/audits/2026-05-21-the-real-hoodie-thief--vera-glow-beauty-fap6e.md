### 2. Link & Tracking Issues

**Non-standard open-tracking mechanism** — the email fires a render-tracking request via:

```html
<span rel="stylesheet" href="https://ctrk.klclick.com/l/01KS3XBXCJRHWR33BDYVR4YE0N_0"></span>
```

`rel="stylesheet"` on a `<span>` is semantically invalid HTML and is used here as a workaround to trigger a network call without an `<img>` pixel (to survive image-blocking). Some strict clients may suppress this request anyway, and it will generate a console error in browser-based clients. Klaviyo's canonical open-tracking pixel (`<img>` with 1×1 transparent GIF) is the more reliable fallback; both should be present.
