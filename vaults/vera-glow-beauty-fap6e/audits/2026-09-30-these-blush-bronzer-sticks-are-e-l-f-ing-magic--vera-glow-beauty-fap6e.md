- 2. Cut the repeated "$7" copy and use that space for one social-proof line, like a star rating or a review count.

## Technical Audit

## 1. Technical Summary
The HTML is a table-based, Braze-rendered template with a proper viewport meta, VML/MSO fallbacks, and a hidden preheader. Automated QA scored a 27% pass rate. The main findings are four click-tracked links that failed on redirect resolution, a 0-character plain-text part, and compliance and authentication headers that couldn't be verified.

## 2. Link & Tracking Issues
**4 of 12 probed links failed with `unknown url type`.** In each case the tracker at `links.elfcosmetics.com/f/a/...` resolved to a **relative** path with no scheme or host:
- `/products/power-grip-primer?Size=Regular+0.8+oz+%2F+24+ml` ("Shop Now")
- `/products/cream-glide-lip-liner?Color=Mauve+Aside+-+Warm+Rose+Mauve` ("Shop Now")
- `/account/login?return_to=%2Faccount` ("Receipt scanning - Earn rewards anywhere you shop e.l.f.")
- `/pages/mobile-app?af_reengagement_window=30d&shortlink=email&utm_medium=email&af_dp=com.elfcosmetics.app%3A%2F%2Fhome&source_caller...` ("beauty squad - Download the e.l.f. app")

**What this means:** the redirect target is a relative `Location`, or the destination URL was stored without its domain. The QA probe can't follow that. A browser would resolve it against `links.elfcosmetics.com`, which is the tracking host, not the storefront. If that host doesn't proxy those paths, real users would hit 404s. The HTML source alone doesn't show which case applies, so confirm this with a manual click-through.

The other 28 links were skipped by the probe, so their status is unknown.

## 3. Rendering & Accessibility
- **Missing alt text:** one image (`src=https://links.elfcosmetics.com/q/X8sb3KnW...`). The `/q/` path on the tracking domain suggests an open-tracking pixel, where empty alt is acceptable. Add `alt=""` explicitly.
- **Empty `<title>`:** `<title></title>` in `<head>`.
- **Empty font-family value:** `font-family:'',Verdana,Sans-serif` in the `mobile_hide` block. It's harmless because of the fallbacks, but it's malformed.
- **Preheader:** the hidden div contains literal asterisks (`*witchful*`), which will show in inbox preview text.
- **Google Fonts `<link>`:** it's wrapped in `<!--[if !mso]><!-->` and falls back to Arial, so it's safe.
- The main hero image has `alt="e.l.f."`, and layout tables use `role="presentation"`.

## 4. Personalization & Merge Tokens
No issues found. The truncated source shows no unresolved tokens such as `{{ }}` or `%%`. Coverage is partial because the HTML was cut off.

## 5. Compliance
- **[FAIL] Plain-text part is 0 chars.** It is missing, or the relay didn't capture it. A missing text alternative hurts deliverability and accessibility.
- **[WARN] `List-Unsubscribe` and `List-Unsubscribe-Post` (RFC 8058) not found.** The QA notes say the AgentMail relay may strip these, so treat this as unverified rather than confirmed. Gmail and Yahoo require one-click unsubscribe for bulk senders.
- **[WARN] `Authentication-Results` not found.** SPF, DKIM and DMARC alignment can't be assessed through the relay. The sender domain `m.elfcosmetics.com` and the tracking domain `links.elfcosmetics.com` differ, which is normal for a subdomain setup.
- The QA notes say an unsubscribe link was probed, and no failure was reported for it. The physical address wasn't visible in the truncated source.

## 6. Email-to-Site Continuity
- UTM parameters can't be verified on the four failed links. Only the app link shows `utm_medium=email`, and that sits inside an AppsFlyer-style parameter set (`af_dp`, `shortlink=email`).
- The product links preserve variant deep-link parameters (`Size=`, `Color=`), which is good.
- The receipt-scanning link points to `/account/login?return_to=/account`. Unauthenticated recipients land on a login wall rather than the feature itself.

## 7. Recommendations
1. Manually verify the four tracked redirects. If the `Location` is relative, have the ESP or Braze link config emit absolute `https://www.elfcosmetics.com/...` destinations.
2. Add a plain-text multipart alternative, or confirm whether the relay is dropping it.

4. Fill in `<title>`, add `alt=""` to the tracking pixel, and remove the empty `font-family:''` declaration.
5. Replace the asterisks in the preheader text.
6. Confirm UTM tagging on the product links once the redirects resolve.
