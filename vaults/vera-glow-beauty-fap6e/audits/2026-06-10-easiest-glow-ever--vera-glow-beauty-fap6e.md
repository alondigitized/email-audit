### 3. Rendering & Accessibility

**`maximum-scale=1` blocks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-to-zoom on mobile. Violates WCAG 1.4.4 (Resize Text). Remove `maximum-scale=1`.

**`-webkit-text-size-adjust:none` on wildcard selector**
```css
*{-webkit-text-size-adjust:none; -ms-text-size-adjust:none; ...}
```
Disabling text-size adjustment globally is an accessibility anti-pattern. Use `-webkit-text-size-adjust:100%` (already set on `body`) and remove from `*`.

**`line-height: 100%` on wildcard selector**
```css
*{line-height: 100%}
```
This overrides the `body` rule and can clip descenders in tight cells. Remove from `*`; apply only where needed.

**HTML comments inside `<style>` block — CSS syntax error**
```css
@media only screen and (max-width: 600px) {
  *[class=hide] { display: none !important;}
  <!-- *[class=contenttable] { width:414px !important;} -->
  <!-- *[class=mobile] { width:414px !important;height: auto !important;} -->
```
`<!-- -->` is not valid CSS comment syntax. Some parsers will treat the content as a parse error and drop the surrounding rules. Replace with `/* ... */` or remove entirely.

**Duplicate font loading (3 of 4 weights)**

BrownBold, BrownLight, and BrownThin are loaded via both `<link>` in `<head>` AND `@import` in the `<style>` block, doubling network requests:
```html
<link href="https://db.onlinewebfonts.com/c/4150d76a852e1c349e0b6fe15f29d9ca?family=Brown+Bold" ...>
```
```css
@import url(https://db.onlinewebfonts.com/c/4150d76a852e1c349e0b6fe15f29d9ca?family=Brown+Bold);
```
Remove one set. Prefer `<link>` (non-blocking) over `@import` (blocking).

**Uncontrolled third-party font CDN**

BrownRegular is self-hosted at `drunkelephant.com/on/demandware.static/...`. The other three weights depend on `db.onlinewebfonts.com`, a third-party service with no SLA. If that CDN is unavailable at render time, 75% of the brand font stack silently falls back to system fonts. Recommend self-hosting all four weights on `drunkelephant.com`.
