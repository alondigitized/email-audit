### 3. Rendering & Accessibility

**Issue — `maximum-scale=1` blocks zoom (WCAG 1.4.4)**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
Prevents pinch-zoom in mobile browsers and webmail. Users with low vision cannot enlarge text. Remove `maximum-scale=1`.

**Issue — Blanket `text-size-adjust: none` on body-level elements**
```css
div, a, tr, table, body, span, img, strong, td {
  -webkit-text-size-adjust: none;
  -ms-text-size-adjust: none;
  ...
}
```
Applied across nearly every element type. Acceptable on `table`/`td` to prevent Outlook reflow, but suppressing it on `body`, `div`, `span`, and `a` blocks OS-level font scaling for accessibility users. Scope this to `table, td` only.

**Acceptable** — XHTML 1.0 Transitional DOCTYPE and VML namespaces (`xmlns:v`, `xmlns:o`) are intentional Outlook compatibility patterns, not defects.

**Acceptable** — `<meta name="robots" content="no index">` is correct practice to prevent webmail-served copies from being indexed.
