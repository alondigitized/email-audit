That's three sends running now — 9/4's "Well damn, 20% off," 9/5's "Lookitchoo, 20% off!," and now this — same code, same 20%, same "our little secret" bit dressed up in a new hat. - That said, this is actually the cleanest execution of the three. The hero product shot with the dropper mid-pour is genuinely pretty, the GWP callout ($36 five-piece set free at $110+) is a real added incentive I haven't seen dressed up quite this way this week, and the "you're gonna like these guys" social-proof grid with live "X people are checking this out" counters is a nice touch — Glossier's been running the same fragrance banner four times this month with zero personalization like that.

## What's working

- The five-piece GWP at $110+ is a concrete, well-priced incentive ($36 value) that's new news versus the last two sends.
- Hero product photography is genuinely gorgeous — better art direction than Sally Beauty's tangled-hands nail shot from earlier this week.
- The "X people are checking this out" live counters on the product grid are a smart trust/urgency cue I don't usually see from this brand.
- Star ratings visible on every grid item give me real product-quality signal before I click, something Sephora's Stacking Weekend spam has skipped entirely.

## What's weak

- DRUNKVIP20 is the exact same code I've now seen 9/4, 9/5, and today — the "keep it between us" framing has completely lost its magic.
- Zero personalization — no name, no "since you loved Protini last time," nothing that says they know I'm Rouge/Diamond across the aisle, just a generic blast.
- The dark divider bar between the hero and the GWP section reads like a rendering glitch at first glance, not an intentional design choice.
- No shade/skin-type callouts anywhere despite this being a skincare brand — Ulta's Kamo shade-finder email from 9/2 at least tried to make it personal.

## Recommendations

- 1. Kill the "secret sale" framing entirely — it's dead after three consecutive sends with the same code. Lead with the GWP instead since that's the actual new offer.
- 2. Add basic segmentation — reference my last purchase or skin concern so it doesn't read like a blast to the whole list.
- 3. Move the $110 GWP threshold up near the hero, not buried mid-scroll, since it's the strongest lever in this email.
- 4. Vary the discount code across sends so loyal openers don't feel like they're getting recycled copy.
