# Black Friday just got real 🌟 50% OFF starts now 🎊
**Score:** 8/10 · **Type:** Email audit · **2026-11-27**
## Executive summary

- Seventh Sephora email in a week, and this one finally has a number worth stopping for. "Black Friday Starts Online Now: 50% OFF" is the biggest thing on the page. It's in huge white type on black, with sequins, and I get it in half a second. Then I read the fine print: "on select gifts for them and beauty faves for you," with a dagger and "available on in-store merchandise only." So it's 50% off some things, and I don't know which. The product row under the hero doesn't show any 50% prices.
- The next 2,000 pixels are Cyber Week tiles, "You Might Also Like," a 30% off tools banner, a Kohl's store locator and a gift guide. After the 11/26 "Stop scrolling" send and the 11/25 Cyber Week one, this reads like the same sequins with a bigger number. I'd click Shop Now, because I always check Black Friday. I wouldn't forward it. I'd also be annoyed if the 50% turned out to be a handful of gift sets.

## What's working

- The 50% hero is impossible to miss and the single black "SHOP NOW" button is clear.
- The purple top banner gives 4X points on fragrance gift sets with code CYBERSCENT. That's the points math I actually care about, and it ends 11/30.
- The product tiles show real prices with strikethroughs: Dr. Jart $52 → $36.40, LANEIGE $24 → $18, Summer Fridays $24 → $19.20. I can do my own math from those.
- The "Only at Sephora" and "New, limited edition" tags help me tell launches from restocks.
- The barcode at the bottom works as a Kohl's coupon, which is a useful in-store touch.

## What's weak

- "50% off" has no named brands or categories. The dagger fine print and "select gifts" feel like bait-and-switch. The tiles under the hero don't match the headline either: Dr. Jart is about 30% off and LANEIGE 25%.
- Beauty Insider tier benefits are missing. As a Rouge member I see nothing about my tier, early access or points multipliers beyond the one fragrance banner.
- It's a very long scroll with five or six competing modules. The Kohl's map takes up a whole screen and has nothing to do with Black Friday deals.
- The sequin background is the same creative from 11/22 to 11/26, so it's wallpaper by now.
- The "Want more Cyber Week deals?" section mixes in a different promo window (11/30) from the hero's 11/27–11/29, which is confusing.

## Recommendations

- 1. Name the 50% items in the hero. Show three or four actual 50%-off products with the sale price, not the dagger copy.
- 2. Cut the Kohl's map and the "You Might Also Like" repeats so the email is half as long.
- 3. Add a tier line, like "Rouge: extra early access + points," so it feels like it knows me.
- 4. Make the points offer and the deadline the same date range as the hero.
- **Subject Alt A:** `50% off starts now: the gift sets I'd grab first`
- **Subject Alt B:** `Black Friday 50% off + 4X points on fragrance`
- **Preheader Alt A:** `Select gift sets, 11/27–11/29. See every 50% pick.`
- **Preheader Alt B:** `Rouge: stack 4X points with code CYBERSCENT through 11/30.`
- Compared with the others in my inbox: Ulta's $10-off-$50 is smaller but crystal clear. Sally's "20% off sitewide" with a code is more honest than a dagger-footnoted 50%. e.l.f.'s gift-set email led with one hero and a free item, which is easier to act on than Sephora's six modules.

## Technical Audit

## 1. Technical Summary
The email is a fixed-width 700px XHTML table layout with no plain-text part (QA FAIL, 0 chars). The truncated HTML shows no broken merge tokens. Link, unsubscribe and authentication checks are inconclusive: the source is cut off, and the header warnings are likely relay artifacts.

## 2. Link & Tracking Issues
- **No link results.** QA probed 12 material links and skipped 34. It reported no failures, but it gave no per-link status, so I can't confirm any link is healthy. Footer, social and utility links were deprioritized, and the unsubscribe link was always probed.
- **Two tracking pixels are present:**
  - `https://app.sephora.com/O/AQEAAZcF2g…` is a hidden `<img>` with `display:none; max-height:0; font-size:0; mso-hide:all`.
  - `https://mi.sephora.com/p/up/f6716d0a0f52104e/o.gif?mi_u=4970293024993920&mi_ecmp=20261126_Cyber_Week_Black_Friday_Fan_Faves_Thursday_PM_All_Else` is a 1x1 open pixel.

- **JSON-LD is empty.** `<script type='application/ld+json'>` contains `"@type": "DiscountOffer", "discountCode": ""` and a bare `"@type": "PromotionCard"`. The empty code makes the markup useless for Gmail promo annotations.

## 3. Rendering & Accessibility
- **Plain-text fallback is missing (QA FAIL).** The text version is 0 chars. This hurts spam scoring and text-only clients. It may be a capture artifact, but the QA check failed as reported.
- **Missing alt text (QA flagged 3 images):**
  - The Epsilon-hosted image `20261126_Cyber_Week_Black_Friday_Fan_Faves_Thursda…` has no `alt`. If it is content or a CTA, screen readers and image-blocked clients get nothing. I can't see its markup in the truncated source.
  - `o.gif` already has `alt="" aria-hidden="true"`, so QA's warning is a false positive. An empty `alt` is correct for a decorative pixel.
  - The `app.sephora.com/O/…` pixel has no `alt` at all. It is hidden, but it should still get `alt=""`.
- **Zoom is blocked.** `<meta name="viewport" content="… maximum-scale=1">` disables pinch-zoom on mobile, which is a WCAG 1.4.4 concern.
- **Layout is wider than a phone screen.** The wrapper table has `min-width:700px; width:700px`. The only media query is `@media (max-width:480px)`. Unless the truncated remainder overrides this, narrow viewports will scroll horizontally.
- **Malformed CSS.** An MSO conditional comment sits inside the `@media` block: `<!--[if mso]> img.mso-size {…}<![endif]-->`. Non-MSO parsers may treat `<!--` as a CDO token. That can invalidate the next rule, `.mobileHeaderTierRouge`, in some clients.
- **Invalid meta value.** `<meta name="robots" content="no index">` should be `noindex`. It has no practical effect in email.
