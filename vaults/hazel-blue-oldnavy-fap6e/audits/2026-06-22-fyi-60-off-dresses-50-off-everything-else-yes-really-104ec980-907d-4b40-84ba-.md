# FYI: 60% off dresses + 50% off everything* else (yes, really!)
**Score:** 7/10 · **Type:** Email audit · **2026-06-22**
## Executive summary

- This is Old Navy's seventh consecutive send in a roughly week-long promotional wave, and it's the first one to make **dresses** the headline offer (60% off) rather than shorts & swim. That's a meaningful creative pivot — the category rotation gives inbox-fatigued subscribers a new reason to look — but the email undermines it immediately: the hero image leads with "TODAY ONLY / 50% OFF EVERYTHING" before you ever register the dress angle. The subject and the hero are misaligned on which deal is the lead.
- The email is structurally clean — single-column mobile layout, no broken images, clear seasonal imagery — and the "TODAY ONLY" urgency is credible. But with six prior sends carrying nearly identical deal stacks, the "yes, really!" in the subject line is doing defensive work that better offer rotation would make unnecessary.
- Net read: solid execution, weak strategy. The template is sound; the promotional calendar is burning out the subscriber list.

## What's working

- **"TODAY ONLY!" urgency is prominent in the hero** — the deadline is surfaced immediately, not buried in a footer.
- **Dress-forward subject line is a genuine category pivot** from the shorts/swim/dresses triple-stack that's run all week; it gives subscribers a fresh hook.
- **Visual hierarchy is intact** — hero > mid-email HOT NEW GEAR lifestyle block > denim section > clearance — the eye follows a logical path.
- **No render bugs** — images load, layout is single-column and aligned, no overlapping text visible.
- **Clearance section at bottom** extends browsing opportunity without diluting the primary offer.

## What's weak

- **Hero leads with "50% OFF EVERYTHING," not the dresses claim** — subscribers who opened for the dress deal have to hunt for validation; the hero and subject are out of order.
- **Seventh consecutive send in the same promotional window** — the "yes, really!" parenthetical signals the brand knows subscribers are tuning out, which is a red flag not a fix.
- **No obvious personalization signal** — no name, no size preference, no "back in your size" hook anywhere visible.
- **HOT NEW GEAR block feels like a distraction** — a mid-email lifestyle block for a separate category interrupts the dress narrative without a dedicated CTA for it.
- **Double "Clearance / Clearance" at the bottom** reads as two stacked identical tiles rather than differentiated men's/women's entry points; the labeling is too generic to drive a targeted click.

## Recommendations

- 1. **Flip the hero to match the subject** — lead with the 60% off dresses visual and make the 50% everything secondary. Right now the email contradicts itself in the first scroll.
- 2. **Cut the send or change the category** — this wave has been running since June 19. Either end the promotion or rotate to a genuinely new category (kids, denim, accessories) to reset inbox fatigue before the next send.
- 3. **Label the clearance tiles** — "Women's Clearance" and "Men's Clearance" with distinct imagery converts better than two generic "Clearance" blocks.
- 4. **Add a size/fit personalization hook** — even a "your summer wardrobe" or "new dresses in your size" line moves the needle if the list is segmented.
- 5. **Drop the "yes, really!" defensiveness** — it signals distrust. A tight deadline ("ends tonight") does the same job with more credibility.
- **Subject Alt A:** `Today only: 60% off all dresses (your summer haul starts here)`
- **Subject Alt B:** `Dress for less — 60% off today only + 50% off everything else`
- **Preheader Alt A:** `Plus 50% off the rest of the store — one day only, no excuses.`
- **Preheader Alt B:** `Summer dresses at 60% off. Today only. Go.`

**Outlook conditional — global `line-height: 0px` on `td`**

```css
<!--[if gte mso 9]>
td { line-height: 0px; mso-line-height-rule: exactly }
```

This resets all `<td>` line-height to zero in Outlook 2013+. Correctness depends entirely on every `<td>` having an explicit inline `line-height` override. If any content cell lacks one, text will collapse. This is a common Outlook hack but high-risk if the template is modified without awareness.

```

```

Tracking pixels should carry `alt=""` explicitly (empty string) so screen readers skip them. The omitted attribute causes some readers to announce the filename.
