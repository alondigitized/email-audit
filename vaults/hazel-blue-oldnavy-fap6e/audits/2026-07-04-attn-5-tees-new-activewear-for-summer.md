# ATTN: $5 tees + new activewear for summer
**Score:** 6/10 · **Type:** Email audit · **2026-07-04**
## Executive summary

- This is Old Navy's second send on July 4 — after "$5 TEES (Yes, $5!) + 40-70% OFF DEEP END DEALS" earlier today — and the tee hero is unchanged: the same "$4 / $5 / $6" price grid with the same rainbow of color swatches and the same "3 DAYS ONLY!" badge. The "new activewear" half of the subject is genuine new creative — the "HOT NEW GEAR" dark module with an athletic model provides real visual contrast — but it arrives as a secondary block after the recycled tee unit, which means neither message lands with full force. A VIP LOUNGE section adds a loyalty touch that works in isolation.
- The biggest problem here is cadence and creative fatigue. This is effectively the fourth email pushing $5 tees across two days (July 3, July 4 AM, and now July 4 PM). The "ATTN:" prefix in the subject reads as a spam-y attention hack rather than earned urgency, and splitting focus between two distinct offers (tees + activewear) weakens both. The July 3 send — the tightest execution of this tee formula — already captured the high-intent buyer; this second July 4 send is reaching diminishing returns on everyone else.
- Verdict: a structurally adequate email let down by aggressive same-day re-send cadence, a fragmented dual-offer structure, and zero creative evolution on the tee hero.

## What's working

- **HOT NEW GEAR module delivers real novelty** — dark background, athletic model in motion, "new" framing breaks the promotional monotone and gives activewear shoppers a reason to click.
- **$4 / $5 / $6 price grid is still legible and specific** — the tiered anchor works visually even on repeat.
- **Color swatches add genuine product detail** — variety of tee colors signals broad inventory.
- **VIP LOUNGE section surfaces a loyalty benefit** — a real differentiator for members, positioned visibly in the mid-email.

## What's weak

- **Second July 4 send with the same tee hero** — brand history shows an identical "$5 TEES + deals" email already deployed today; this is back-to-back fatigue in a single inbox session.
- **"ATTN:" subject prefix reads spam-y** — this is the inbox equivalent of clearing your throat; it adds character count without adding meaning.
- **Dual-offer structure dilutes both messages** — "tees + new activewear" means neither segment gets a dedicated hook.
- **"3 DAYS ONLY!" urgency is fully exhausted** — subscribers who saw July 3's identical badge and didn't convert won't be moved by a third repetition.
- **Product tiles at the bottom appear to show "$0" pricing** — if those are not loading correctly, that's a trust-eroding render issue for any user whose client doesn't fetch images.

## Recommendations

- 1. **Kill the second July 4 send, or commit to one message.** If activewear is ready to launch, give it its own dedicated email with a clean subject — don't bolt it onto a tired tee reprompt. Two sends in one day requires the second to bring genuinely new creative or a new offer tier.
- 2. **Drop "ATTN:" entirely.** Lead with the concrete offer. Every character it occupies is wasted preview-window real estate.
- 3. **Give the activewear launch proper hero treatment.** "HOT NEW GEAR" is buried as a secondary module; an activewear-focused email with a hero image first and the tees as a supporting footer would make a cleaner editorial choice.
- 4. **Retire the "3 DAYS ONLY!" badge if it's now day 3.** If today is the last day, say "Final hours — $5 tees end tonight." That's a true urgency signal, not a repeated countdown.

## Technical Audit — Old Navy "$5 tees + new activewear for summer"

### 1. Technical Summary

The email renders on a standard XHTML 1.0 Transitional + VML stack with responsive CSS breakpoints; core layout is functional. The primary technical concerns are a broken tracking/personalization pixel, missing compliance infrastructure, and a plain-text body that is nearly entirely URLs.

---

### 2. Link & Tracking Issues

**FAIL — Broken pixel URL (cp.oldnavy.com)**
The Contentsquare/personalization pixel resolves to an internal redirect path `/g/97dd76b6-...` that the HTTP client cannot handle (`unknown url type: '/g/...'`). The pixel fires on open but the redirect chain terminates with an unresolvable relative-path response.

- Evidence: `https://cp.oldnavy.com/o/97dd76b6-b4c1-4685-a7cd-9305ccc8e740?mi_mid=...`
- Impact: open-event personalization data (likely Movable Ink or similar) is not being recorded correctly for this send.

**INFO — 23 click-redirect links skipped**
All CTA links route through `click.email.oldnavy.com`. Not a defect, but final destination URLs could not be probed; UTM parameter validation below is therefore limited to what is visible in the HTML source.

---

### 3. Rendering & Accessibility

**WARN — Missing `alt` text on tracking pixel**
The cp.oldnavy.com `<img>` pixel has no `alt` attribute:
```html
<img src="https://cp.oldnavy.com/o/97dd76b6-..." width="1" height="1">
```
Screen readers will announce the full URL. Should be `alt=""` (empty string, not absent).

**INFO — Outlook conditional CSS sets `td { line-height: 0px }`**
The MSO block applies `line-height: 0px; mso-line-height-rule: exactly` globally to all `td` elements in Outlook 2013+. This is a known Outlook spacing fix but will suppress any `td`-level line-height overrides set elsewhere unless they use `mso-line-height-rule: at-least`.

**INFO — Duplicate media query class selectors**
`.MspaceTop` and `.MspaceBot` are each defined twice in the responsive block (comment in source acknowledges this). No functional breakage, but dead CSS weight.

---

### 4. Personalization & Merge Tokens

No unfired merge tokens (e.g., `{{first_name}}`, `[FNAME]`) are visible in the truncated source. The schema.org `Organization` block is statically populated — no dynamic fields. No issues found from what is visible.

---

### 5. Compliance (CAN-SPAM / RFC 8058)

**WARN — `List-Unsubscribe` header absent**
Not detected by the AgentMail relay. Gmail and Apple Mail use this header to surface the native unsubscribe button; its absence increases spam classification risk and violates Google/Yahoo 2024 bulk sender requirements for senders >5k/day.

**WARN — `List-Unsubscribe-Post` header absent (RFC 8058)**
One-click unsubscribe (POST-based) is not supported. Required by Google/Yahoo bulk sender policy since February 2024.

**WARN — No physical mailing address detected**
CAN-SPAM §5(a)(5) requires a valid physical postal address in the message body. The HTML source truncation may exclude the footer, but the QA check found no address. Needs verification against full source.

**WARN — `Authentication-Results` header not captured**
SPF/DKIM/DMARC pass/fail status is unknown through the AgentMail relay. Cannot confirm `oldnavy@email.oldnavy.com` is DMARC-aligned with `oldnavy.com`.

---

### 6. Email-to-Site Continuity

All CTAs pass through `click.email.oldnavy.com` redirects, so UTM parameters cannot be inspected directly from the source. The redirect chain for the broken cp.oldnavy.com pixel terminates before resolving — any personalization or A/B test assignment tied to that open event is lost. No misfired destination URLs are confirmed, but 23 links were untestable.
