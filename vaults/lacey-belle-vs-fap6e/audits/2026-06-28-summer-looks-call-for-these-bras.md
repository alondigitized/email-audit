# Summer Looks Call for These Bras
**Score:** 5/10 · **Type:** Email audit · **2026-06-28**
## Executive summary

- VS is running a second consecutive editorial bra send — June 27 was "Packing for Your Trip" and now June 28 is "Summer Looks Call for These Bras." The creative follows the same format: dark hero section with model imagery, a product grid across bra styles, then a hard pivot mid-email to the VS Candy Shoppe (fragrances, body care) before landing on a discount offer buried lower. The problem is the email is trying to do two things — sell bras editorially and cross-sell beauty — and neither gets enough room to close.
- The hero section works. Dark background, strong model imagery, bras foregrounded clearly. But the email bloats quickly: the Candy Shoppe section is visually jarring after the lingerie spread, and by the time the "SAVE 15%" (or similar) callout appears, you're already past the engagement window.
- This is a competent execution of a format VS has used before, but sending back-to-back editorial bra emails with no differentiated offer between them is a cadence mistake. A subscriber who didn't open June 27 will feel like this is a repeat. One who did open it will wonder what's new.

## What's working

- Hero is strong — dark background with models creates a confident, brand-consistent opening that matches the "Summer Looks" framing.
- "VS Candy Shoppe" section adds visual variety with colorful product photography; breaks up the lingerie monotony mid-email.
- Subject line is 33 characters — well within mobile-safe range, reads clean in any inbox.
- No render bugs visible — images load, text renders properly, layout is intact.
- Seasonal framing ("Summer Looks") gives the editorial a reason to exist without manufacturing a fake deadline.

## What's weak

- Two consecutive editorial bra emails (June 27 + 28) with no meaningful differentiation — the subscriber who opened yesterday sees this as a repeat.
- The VS Candy Shoppe section mid-email is a tonal whiplash — fragrance/body care sandwiched between lingerie categories reads as product-fill, not curated cross-sell.
- No prominent discount in the hero — the offer (looks like "SAVE 15%") is buried well below the fold, making the email feel like a browse prompt rather than an action trigger.
- CTA buttons are not legible at render size — impossible to confirm what the button copy says, which suggests they may be too small or low-contrast on mobile.
- No urgency signal anywhere visible — the email gives no reason to act today over tomorrow.

## Recommendations

- 1. **Differentiate from June 27** — If you're going to run two editorial bra sends in two days, the product selection has to be clearly different. "Summer Looks" bras vs. "Travel" bras should feature non-overlapping styles. As-is this reads like the same send with a new subject.
- 2. **Move the offer to the hero** — "SAVE 15%" or whatever the actual mechanic is should appear in the first visible block alongside the bra hero. Right now it's buried, which kills click intent.
- 3. **Kill or cut the Candy Shoppe cross-sell** — Either give it its own dedicated send or drop it. Mid-email beauty cross-sell in a bra editorial breaks the purchase path.
- 4. **Add one urgency signal** — A "Shop before Sunday" or "Summer stock selling fast" line in the header costs nothing and gives the editorial a close.
- 5. **Make CTA copy legible and specific** — "Shop Summer Bras" beats "Shop Now" every time.

## Technical Audit — Victoria's Secret "Summer Looks Call for These Bras"

---

### 1. Technical Summary

The email has malformed document structure (content-bearing table rendered inside `<head>`), a broken JSON-LD block, and 11 third-party retargeting pixels loaded over plain HTTP — all of which will be silently blocked or cause parse errors in modern clients. Compliance headers are not visible to the relay.

---

### 2. Link & Tracking Issues

**Duplicate open pixel**
`https://click.e1.victoriassecret.com/open.aspx?EACYRJCNYUSETBAKBYG6ASF4YY.70255&d=70255&bmt=0` appears twice in the truncated HTML (once near the `<body>` open, once inside the first content table). Inflates open-rate counts.

**19 tracking links not probed**
All click links route through `click.e1.victoriassecret.com`. Destination URLs and UTM parameter presence cannot be confirmed from the source alone (see §6).

**Broken JSON-LD structured data**
```json
{ "@type": "DiscountOffer", "@type": "PromotionCard", "image": "", "url": "" }
```
- Duplicate `@type` key — second value silently overwrites first; neither type is registered in schema.org. `PromotionCard` is not a valid schema.org type.
- `image` and `url` are empty strings — Gmail's promotional tab annotations (if targeted) will receive no enrichment.

---

### 3. Rendering & Accessibility

**Malformed document structure**
A full `<table>` containing the JSON-LD `<script>` is rendered inside `<head>` before any `<meta>` or `<style>` tags. Browsers/clients that strictly parse HTML will either move or drop this table, potentially displacing the JSON-LD block or triggering premature body parse.

**`<title>` in wrong position**
```html
<title style="display: none; max-height: 0px; overflow: hidden;"></title>
```
This `<title>` tag is inside a `<td>` in the body, not in `<head>`. It is also empty — the preheader text slot appears unpopulated.

**Zoom disabled**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=0">
```
`user-scalable=0` / `maximum-scale=1` blocks pinch-to-zoom. Fails WCAG 1.4.4 (Resize Text).

**11 HTTP pixel images — missing alt text + mixed content**
All 11 Dotomi retargeting pixels use `http://` (not `https://`) and have no `alt` attribute:
- `http://login.dotomi.com/ucm/UCMController?dtm_com=2&dtm_cid=2482&dtm_cmagic=f55cad&dtm_fid=103&dtm_format=6&cli_promo_id=...`
- `http://ads.dotomi.com/cookieredir/2482/pub1.php` through `pub10.php` (same hash token across all 10)

Gmail, Outlook.com, and Apple Mail block mixed-content images by default. These pixels will fail to fire, meaning retargeting suppression lists built from this email will be incomplete.

**One content image missing alt text**
`https://image.e1.victoriassecret.com/lib/fe92137274640d7b71/m/179/5bcec3ac-502d-4d8f-b48c-0a3d20e6e3c2.png` — missing `alt`. If images are blocked, this renders as a broken placeholder with no text fallback.
