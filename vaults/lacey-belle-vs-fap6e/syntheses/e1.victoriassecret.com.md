# Certainly! Here are the recommendations for migrating the mixed-content HTTP pixel assets and ensuring compliance with m

### Recommendations

#### High Priority: Migrate All Mixed-Content HTTP Pixel Assets

To ensure secure loading of tracking images in modern email clients, all third-party retargeting sync pixels should be migrated to HTTPS. This includes:

1. **MI Open Pixel**
   - Current URL: `http://mi.victoriassecret.com/p/up/bc3d99b3ec2e075f/o.gif`
   - Suggested Migration:
     ```plaintext
     https://secure.mi.victoriassecret.com/p/up/bc3d99b3ec2e075f/o.gif
     ```

2. **Dotomi UCM**
   - Current URL: `http://login.dotomi.com/ucm/UCMController?dtm_com=2&dtm_cid=2482&...`
   - Suggested Migration:
     ```plaintext
     https://secure.login.dotomi.com/ucm/UCMController?dtm_com=2&dtm_cid=2482&...
     ```

3. **pub1.php – pub10.php**
   - Current URL: `http://ads.dotomi.com/cookieredir/2482/pub{1-10}.php?...`
   - Suggested Migration:
     ```plaintext
     https://secure.ads.dotomi.com/cookieredir/2482/pub{1-10}.php?...
     ```

#### Medium Priority: Add `alt` Attributes to Tracking and Content Images

Ensure that all images, including tracking pixels and content images, have appropriate `alt` attributes:

1. **Tracking Pixels**
   - Example:
     ```html
     <img src="https://secure.mi.victoriassecret.com/p/up/bc3d99b3ec2e075f/o.gif" alt="" />
     ```

2. **Content Images**
   - Example for the content/logo image:
     ```html
     <img src="https://mi.victoriassecret.com/p/rp/eb81ca741916f4dd.png" alt="Victoria's Secret Logo" />
     ```
   - Example for another content image:
     ```html
     <img src="https://image.e1.victoriassecret.com/lib/fe92137274640d7b71/m/179/5bcec3ac-502d-4d8f-b48c-0a3d20e6e3c2.png" alt="Fragrance Hero Image" />
     ```

#### High Priority: Add One-Click Unsubscribe Headers

Ensure that the email includes `List-Unsubscribe` and `List-Unsubscribe-Post` headers to comply with Gmail and Yahoo requirements:

```html
<meta name="mailing-list-unsub" content="mailto:unsubscribe@victoriassecret.com?subject=Unsubscribe">
```

Or in the header:
```plaintext
List-Unsubscribe: <mailto:unsubscribe@victoriassecret.com?subject=Unsubscribe>
List-Unsubscribe-Post: List-Unsubscribe=One-Click
```

#### Medium Priority: Ensure CAN-SPAM Compliance

Include a physical mailing address in the email footer to comply with CAN-SPAM requirements:

```html
<p>Victoria's Secret<br/>
100 Victoria's Secret Drive<br/>
Columbus, OH 43219</p>
```

### Summary of Recommendations

| Priority | Issue | Action |
|---|---|---|
| **High** | Mixed-content HTTP pixel assets | Migrate all Dotomi/MI pixels to HTTPS and add `alt` attributes. |
| **Medium** | Tracking images missing alt text | Add appropriate `alt` attributes for tracking and content images. |
| **High** | One-click unsubscribe headers | Include `List-Unsubscribe` and `List-Unsubscribe-Post` headers in the email. |
| **Medium** | CAN-SPAM physical address | Ensure a physical mailing address is included in the email footer. |

By addressing these issues, Victoria's Secret can improve the security, accessibility, and compliance of their emails, leading to better deliverability and user engagement.
