# It looks like the technical audit for Victoria's Secret "Scent Event Early Access" email has identified several critical

### Recommendations

| Priority | Issue | Action |
|---|---|---|
| **High** | 12 HTTP pixel assets | Migrate all Dotomi/MI pixels to HTTPS to ensure secure content delivery. This will prevent mixed content warnings in modern email clients. Ensure that all third-party tracking scripts and images are served over HTTPS. |
| **High** | List-Unsubscribe header — MISSING | Add the `List-Unsubscribe` or `List-Unsubscribe-Post` headers to comply with Gmail and Yahoo requirements for bulk senders (>5K/day). This will help prevent inbox demotion risks. Ensure that these headers are included in both the message headers and HTML content if necessary. |
| **High** | CAN-SPAM physical address | Verify and include a clear, visible physical mailing address in the email footer or header to comply with CAN-SPAM requirements. This should be present in all emails sent out by Victoria's Secret. |
| **Medium** | Plain-text URL density — HIGH RISK | Review and optimize the plain-text alternative of the email to ensure it is not overly link-heavy. Consider manually crafting a more engaging and less link-dense version that complements the HTML content effectively. |
| **Medium** | Content images missing alt text | Add `alt` attributes to all content images, including logos and decorative elements, to improve accessibility for screen readers. Ensure that each image has meaningful `alt` text or use empty `alt=""` tags where appropriate. |
| **Low** | Viewport blocks user zoom | Remove the `user-scalable=0` attribute from the viewport meta tag to ensure users can adjust their viewing experience on mobile devices. This will improve accessibility and user experience. |

### Summary of Key Issues

1. **Mixed Content (HTTP Assets):**
   - Ensure all third-party tracking pixels are served over HTTPS.
   - Migrate Dotomi/Criteo retargeting sync pixels to secure URLs.

2. **List-Unsubscribe Header:**
   - Add `List-Unsubscribe` and `List-Unsubscribe-Post` headers to comply with Gmail and Yahoo requirements for bulk senders.

3. **CAN-SPAM Compliance:**
   - Include a clear physical mailing address in the email footer or header.

4. **Plain Text URL Density:**
   - Optimize plain text content to reduce link density and improve readability.

5. **Image Accessibility:**
   - Add `alt` attributes to all images, including logos and decorative elements.

6. **Viewport Meta Tag:**
   - Remove the `user-scalable=0` attribute from the viewport meta tag to allow user zooming on mobile devices.

By addressing these issues, Victoria's Secret can improve the security, accessibility, and compliance of their email campaigns, leading to better deliverability and engagement rates.
