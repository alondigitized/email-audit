## Technical Audit — Skechers "Final Call: Extra 15% Off" (2026-07-05)

---

### 1. Technical Summary

The email is a standard SFMC-deployed HTML table layout with no catastrophic rendering failures, but carries a pervasive HTTP (non-HTTPS) image loading problem across nearly all asset references, plus several third-party tracking pixels that expose subscriber identity data without clear user consent disclosure.

---

### 2. Link & Tracking Issues

**Third-party identity sync pixels present:**
- `beacon.krxd.net/1x1_usermatch.gif?partner=LprH63a7_sfmc_100007688_sha25&partner_uid=adf27fee...` — hashed email (SHA-256) passed to Krux/Salesforce DMP
- `beacon.krxd.net/1x1_usermatch.gif?partner=LprH63a7_sfmc_100007688_subid&partner_uid=122277199` — raw subscriber ID exposed
- `pixel.app.returnpath.net/pixel.gif?r=964ce1dbf0...` — Validity/Return Path inbox monitoring pixel

These fire on open, transmitting subscriber identity to three external domains. Whether this is disclosed in the privacy policy is out of scope here, but the `partner_uid` values are cleartext in the HTML source.

**27 click-redirect links** all route through `click.emails.skechers.com` — expected for SFMC, not a defect, but confirms no direct destination URL is auditable from source alone.

**Open pixel uses HTTPS correctly:** `click.emails.skechers.com/open.aspx` — no issue.

---

### 3. Rendering & Accessibility

**HTTP image sources (11 affected assets):**

All `image.emails.skechers.com` assets use `http://` not `https://`. Modern email clients (Gmail, Outlook 2019+, Apple Mail) will either block or proxy these, causing broken images for a significant portion of recipients.

Affected images include high-visibility assets:
- Skechers logo: `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/dde00662-169f-447d-b0e2-fc65f6c2290c.png`
- App Store badge, Google Play badge
- Curbside Pickup, AfterPay, Find A Store icons
- Instagram, Facebook, YouTube social icons

**Third-party open pixel also HTTP:**
- `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif` — non-HTTPS tracking pixel will be blocked by Gmail proxy (images served via `googleusercontent.com` cache require HTTPS origin)

**Missing alt text (2 images):**
- `o.gif` (ink1000 pixel) — tracking pixel, acceptable to omit
- `49468f73-4651-4af3-bea2-61d1ae5db486.png` — unknown content image, needs `alt=""` minimum or descriptive text

**CSS redundancy:** Media query for `.hideme/.hidden/.mobile-hidden` is duplicated identically in two `<style>` blocks — not a rendering defect but adds unnecessary payload.

**`-webkit-text-size-adjust: none`** applied globally — suppresses iOS font scaling for accessibility users who rely on it. `100%` is the safer value.

### 5. Compliance

**CAN-SPAM / CASL:**
- Physical mailing address and unsubscribe mechanism not visible in the truncated source — these are required. Assumed present in the non-truncated footer; cannot confirm.
- Preheader text (`Save Big with Up to 40% Select Styles`) is present and properly hidden via `display:none !important`.

**Authentication headers:** Not auditable from HTML source. Sender domain `emails.skechers.com` should have SPF, DKIM, and DMARC configured — verification requires header inspection of a delivered copy.

**Data residency concern (informational):** SHA-256 hashed email is transmitted to `beacon.krxd.net` on open. If any recipients are EU/UK-based, this constitutes personal data transfer under GDPR Art. 46 and requires a lawful basis in the send flow.
