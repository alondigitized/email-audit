## Technical Audit

## 1. Technical Summary
The email has one confirmed merge-token failure (empty greeting, `"Hi ,"`) and a malformed Return Path tracking pixel with no URL scheme. It also loads two images over plain `http://` and declares its charset and compatibility meta tags incorrectly. Only the first 5 of the 29 tracking links could be assessed, and no footer or unsubscribe markup was in the truncated source.

## 2. Link & Tracking Issues
- **Scheme-less pixel URL:** `<img src="pixel.app.returnpath.net/pixel.gif?r=964ce1db…" width="1" height="1" />` has no `https://` or `//`. Clients resolve it as a relative path, so it either 404s or is never fetched, and the Return Path/Validity seed tracking is lost.
- **Insecure tracking pixel:** `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif?mi_u=8108404282&mi_ecmp=MKG_US_NA_U_MULTI_ENGAGEDL14D_EN_10152026` is plain HTTP. Gmail's image proxy and Apple Mail Privacy Protection may block or rewrite it, and mixed content can trigger warnings in some clients.
- **Unverified links:** 29 links on click-redirect domains were skipped (QA: "skipped HTTP probe"). Destination status and redirect chains are unverified.
- **Not an issue:** the open pixel `https://click.emails.skechers.com/open.aspx?…&d=100224&bmt=0` uses HTTPS.

## 3. Rendering & Accessibility
- **Missing alt text:**
  - `o.gif` (ink1000.com), flagged by QA.
  - `dde00662-169f-447d-b0e2-fc65f6c2290c.png`, flagged by QA, on `http://image.emails.skechers.com/lib/fe3115707564047a731c78/m/1/…`.
  - The three `beacon.krxd.net` 1x1 GIFs also have no `alt` attribute. They are hidden, so the impact is low.
- **Insecure content image:** the `dde00662…png` image is served over `http://`, so it may be blocked by some clients and show as a broken image.
- **Malformed meta tags:** `<meta content="text/html; charset=utf-8" />` and `<meta content="IE=Edge" />` have no `http-equiv`, so neither declares anything. No charset is effectively set, which risks mojibake on the `®` in `<title>Skechers®</title>`.
- **Zoom disabled:** the viewport meta has `maximum-scale=1`, which blocks pinch-zoom (WCAG 1.4.4).
- **No focus indicator:** the global rule `a { outline: none; }` removes keyboard focus indication.
- **Missing language and table roles:** `<html>` has no `lang` attribute. The visible layout tables (`<table class="widthFull" width="640" …>`) have no `role="presentation"`. This is based on the visible portion only.

## 4. Personalization & Merge Tokens
- **[FAIL] Empty greeting slot:** the greeting renders `"Hi ,"`. The first-name field resolved to empty and there is no fallback value (for example "Hi there,"). Any recipient without a stored first name gets a visibly broken greeting.
- No unresolved raw tokens (such as `%%…%%` or `{{…}}`) appear in the visible source.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Authentication headers:** QA reports `Authentication-Results` not found. The relay is AgentMail, so SPF/DKIM/DMARC alignment for `emails.skechers.com` is unverified. This is a test-harness limitation, not a confirmed sender failure.
- **Unsubscribe and address:** the truncated source does not include the footer. The unsubscribe link, physical postal address and `List-Unsubscribe` / `List-Unsubscribe-Post` headers could not be checked.
- **Third-party identifiers:** `beacon.krxd.net/1x1_usermatch.gif?…partner_uid=adf27fee…189a` passes a 64-character SHA-256 value to a third party. A second `usermatch` call passes `partner_uid=122277199` (subscriber ID). This is not a violation in itself, but the privacy policy should disclose it.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- **Cannot verify:** all 29 links go through click-redirect domains and were not probed, so UTM parameters and landing pages are unconfirmed.
- **Campaign ID:** the only campaign identifier visible is `MKG_US_NA_U_MULTI_ENGAGEDL14D_EN_10152026`, in the krxd and ink1000 pixels. Check that it carries through to the site-side UTM/analytics parameters.

## 7. Recommendations
1. Add a fallback to the first-name merge field (for example "Hi there,") or drop the greeting when the field is empty. This is the only confirmed user-visible break.
2. Fix the Return Path pixel to `https://pixel.app.returnpath.net/pixel.gif?r=…`.
3. Switch `ink1000.com` and `image.emails.skechers.com` to `https://`, and confirm both hosts serve valid TLS.
4. Add `alt=""` (decorative) or descriptive alt text to `o.gif`, `dde00662…png` and the krxd beacons.
5. Correct the meta tags to `<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />` and `<meta http-equiv="X-UA-Compatible" content="IE=edge" />`.
6. Remove `maximum-scale=1`, restore a visible `:focus` style, and add `lang="en"` and `role="presentation"` to the layout tables.
7. Rerun the audit against the full HTML and raw headers. That would let us verify the footer, unsubscribe link, `List-Unsubscribe`, DKIM/SPF/DMARC, and the redirect destinations and UTMs of the 29 skipped links.
