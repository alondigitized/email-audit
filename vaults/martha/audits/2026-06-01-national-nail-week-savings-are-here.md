### 3. Rendering & Accessibility

**`http-equiv` missing on two `<meta>` tags:**
```html
<!-- Missing http-equiv="Content-Type" -->

<!-- Missing http-equiv="X-UA-Compatible" -->

```
Both tags are parsed correctly by most modern clients via fallback, but they are technically malformed per the XHTML spec. Outlook 2016 and some legacy clients rely on `http-equiv` being explicit.

**`Founders Grotesk` has no `@font-face` declaration:**
```css
a { font-family:'Founders Grotesk', Helvetica, sans-serif; }
```
Six `@font-face` blocks are declared for Open Sans only. `Founders Grotesk` is never defined, so every anchor element silently renders in Helvetica. If this is intentional, the font name should be removed. If not, the font file must be hosted and declared.

**`white-space:pre` applied to all images:**
```css

```
`white-space` is a text property with no defined effect on replaced elements like `<img>`. This is harmless in most clients but is dead/incorrect CSS that suggests a copy-paste error from a text rule. Should be removed.

Standard practice is 600px. A 499px threshold may clip content on standard 375px iPhones in landscape or on Android devices with viewport scaling. Cannot confirm impact without seeing layout containers.
