## Technical Audit — Skechers "Summer Starts With the Right Pair" Email

### 1. Technical Summary

One broken experience (empty personalization token in greeting) and a systemic HTTP image issue affect deliverability and rendering across modern email clients. All other categories are clean.

---

### 2. Link & Tracking Issues

**No broken destination links confirmed.** All 26 click-redirect URLs route through `click.emails.skechers.com` and were skipped by the HTTP probe (expected for wrapped tracking links — not a defect).

Three pixel trackers fire in a hidden `<div>`:
- `click.emails.skechers.com/open.aspx` — ESP open pixel (SFMC)
- `beacon.krxd.net/1x1_usermatch.gif` — Krux/Salesforce DMP user-match (×2)
- `beacon.krxd.net/1x1_ad_impression.gif` — DMP impression beacon

One additional pixel fires via a separate `<table>` block:
- `http://www.ink1000.com/p/up/7076d8b15a776085/o.gif` — third-party open tracker, **HTTP only** (see Section 3).

The `returnpath.net` pixel (`pixel.app.returnpath.net/pixel.gif`) uses a bare hostname without `https://`, which will be blocked by Outlook/Gmail image proxies.

### 4. Personalization & Merge Tokens

**[FAIL] Empty greeting token — confirmed broken experience.**

QA check detected `"Hi ,"` — the subscriber first-name merge field resolved to an empty string. This indicates either:
- The merge field (likely `%%First Name%%` or `{{first_name}}`) was not suppressed with a fallback default, or
- The subscriber record has a blank `first_name` value and no conditional block catches it.

Expected pattern (SFMC AMPscript):
```
%%[
  SET @fname = AttributeValue("First Name")
  IF NOT EMPTY(@fname) THEN
]%%
Hi %%=v(@fname)=%%,
%%[ ELSE ]%%
Hi there,
%%[ ENDIF ]%%
```

This should be treated as a production defect — it renders visibly broken to any subscriber with a missing first name.
