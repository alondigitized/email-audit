## What's weak

- This is Sally email number eight-ish in ten days. Even a genuinely solid send is fighting my inbox fatigue at this point — "More hair care, more savings" from July 20 was a better email and I still mentally lumped it in with the pile.
- Zero loyalty mention. I'm in the Rewards program. Not one callout to points, member pricing, or "Beauty Club exclusive" — I'm being treated like a cold stranger, not a returning customer.
- Six products, six identical "Shop now" buttons — there's no editorial point of view about what I should actually try first.
- The model is stunning but she reads "Sally HQ beauty shoot," not "actual woman who buys drugstore-priced salon products." Slight disconnect from how I actually see myself shopping for this.

- 2. **Pick one hero product and own it.** Choose the Miracle Leave-In or the Hair Mask, link directly to that PDP, and let the grid be the supporting cast — not six equal-weight options with no recommendation.
- 3. **Put the deadline in the subject line.** "Ends Sunday" or "This weekend only" adds urgency that the current subject completely lacks.

### 3. Rendering & Accessibility

**Issue 1 — Malformed charset meta tag.**
```html
<meta content="text/html; charset=utf-8" />
```
Missing `http-equiv="Content-Type"`. Per RFC 2854 and email client parsing behavior, this tag is silently ignored by some clients (Outlook, older Android). Correct form:
```html
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
```

**Issue 2 — `'Founders Grotesk'` referenced but not declared.**
The global `a` rule specifies:
```css
a { font-family: 'Founders Grotesk', Helvetica, sans-serif; }
```
No `@font-face` declaration for Founders Grotesk exists in the visible `<style>` block (only Open Sans variants are loaded). All anchor text will silently fall back to Helvetica/sans-serif. If this is intentional, the dead font-family reference should be removed to keep the stylesheet clean; if not, the `@font-face` declaration is missing.

**Issue 3 — Stale Google Fonts version.**
All Open Sans `@font-face` rules reference `v17`:
```
https://fonts.gstatic.com/s/opensans/v17/...
```
Current Open Sans is v40+. While functional, pinned-old-version URLs are a maintenance risk (Google has retired very old font versions before). Also note: Gmail strips external CSS including `@font-face`, so these only fire in Apple Mail, Outlook on Mac, and webmail clients that allow external stylesheets.

**Issue 4 — `white-space: pre` on `img`.**
```css
img { -ms-interpolation-mode: bicubic; white-space: pre; }
```
`white-space` is a non-inherited property that does not apply to replaced elements like `<img>`. It is harmless but indicative of a copy-paste artifact in the template base.
