# 🖼️ Honor their service with a custom frame.
**Score:** 4/10 · **Type:** Email audit · **2026-05-24**
## Executive summary

- This is a Memorial Day tribute send from Michaels Custom Framing — a genuinely on-occasion email that pairs an emotional angle ("Honor their service") with a real, layered offer (70% off custom framing, $10 off in-store + online, $29 10-Minute Custom Framing). The hero image of framed flags and military mementos lands the message instantly, and the eye drops cleanly to the 70% banner.
- The execution is competent but cramped. There are essentially three offers stacked vertically — 70% off, $10 off, and the $29 10-Minute service — and they fight each other for attention. The "Two ways to shop" framing tries to organize it, but the second half of the email turns into a process explainer (Customize → Upload → Frame → Pick Up) that dilutes the urgency of the headline offer.
- Net: solid seasonal hook, honest offer, but the layout is doing too much. A tighter single-offer hero would convert better.

## What's working

- Memorial Day tribute framing is timely and emotionally specific — not a generic % off blast.
- Hero imagery (framed flag, medals, military photos) communicates the use-case in one glance.
- 70% off is a large, unmissable headline number with clear visual hierarchy.
- The $29 "10-Minute Custom Framing" offer adds a concrete, low-commitment entry point.
- Brand identity is consistent — Michaels Custom Framing lockup top and bottom.

## What's weak

- Three competing offers (70% off, $10 off, $29 service) split attention instead of compounding it.
- The "How it works" four-step process eats real estate that could carry product or social proof.
- CTAs are not visible/legible at this zoom — buttons feel buried in dense blocks of text.
- No visible end date on "Limited-Time Offer" — credibility of urgency suffers.
- Subject emoji 🖼️ is fine but adds nothing; the emotional weight of "Honor their service" doesn't need a picture-frame icon.

## Recommendations

- 1. **Lead with one offer.** Make 70% off custom framing the single hero. Move $10 off and the $29 service into secondary tiles below the fold.
- 2. **Put a real deadline on the urgency.** "Ends Memorial Day" or "Through 5/26" instead of vague "Limited-Time."
- 3. **Cut the 4-step "how it works" block** for this send — it belongs on a landing page, not in a holiday tribute email.
- 4. **Add one customer photo / review** of a finished military shadowbox to anchor the emotional pitch.
- 5. **Make the primary CTA copy specific** — "Start your tribute frame" beats "Shop Now."
- **Subject Alt A:** `Honor their service — 70% off custom framing`
- **Subject Alt B:** `Memorial Day: frame the flag, the photo, the medal`
- **Preheader Alt A:** `Custom shadowboxes for medals, flags & service photos. Ends Monday.`
- **Preheader Alt B:** `70% off custom framing + $29 10-minute service this weekend only.`

# Technical Audit — Michaels Custom Framing (2026-05-24)

## 1. Technical Summary
HTML is a legacy Salesforce Marketing Cloud (SFMC) table-based template using HTML 4.01 Transitional with several minor code defects (typos, invalid CSS values). Tracking infrastructure (Coremetrics/`cm_mmc`) is present and the open pixel is wired.

## 2. Link & Tracking Issues
- Open pixel present: `https://click.em.michaelscustomframing.com/open.aspx?5TLEFBP4BTKU3A4NNW54WKARSA.100216` — wired correctly.
- Click-tracking domain `click.em.michaelscustomframing.com` used on the "View in Browser" CTA via SFMC `qs=` redirector — OK.
- Header-logo destination link is **commented out** (`<!-- <a href="…HEADER_LOGO"> -->`), so the logo is not clickable. This is a tracked-click loss on a high-traffic element.
- The header-logo URL (in the comment) contains a base64-encoded subscriber email in `customerEmail=bWlyYS1nbGl0dGVyLW1pY2hhZWxzLWZhcDZlQGV0ZWxsLmFwcA==` exposed in a query string — PII leakage to any downstream referrer/analytics if uncommented as-is.

## 3. Rendering & Accessibility
- Doctype declared *after* an SFMC content wrapper `<table>`, so markup before `<!DOCTYPE>` will trigger quirks mode in some clients.
- Invalid CSS: `@-ms-viewport { width: device-width; s }` — stray `s` token.
- Invalid CSS: `max-height: auto !important;` (twice) — `auto` is not a valid value for `max-height`; rule is dropped.
- Typo: `a:visted` should be `a:visited` — visited-link color override never applies.
- Open-pixel `<img>` has `alt=""` (correct for decorative), but the wrapping `<div style="font-size:0; line-height:0;">` lacks `aria-hidden`. Minor.
- Tracking-link anchor uses `target="_blank"` without `rel="noopener noreferrer"`.
- No `lang` attribute on `<html>` — screen-reader language detection falls back.
- `<body text="#000000">` uses a deprecated HTML attribute alongside inline `style` — harmless but legacy.

## 4. Personalization & Merge Tokens
- No unresolved merge tokens (`%%…%%`, `{{…}}`) visible in the supplied source.
- Subscriber email is embedded base64-encoded in tracking URLs (`customerEmail=…`) — personalization is functional but transmits identifiable data in URL params.

## 5. Compliance (CAN-SPAM, unsubscribe, auth)
- HTML source is truncated before the footer; unsubscribe link, postal address, and authentication (SPF/DKIM/DMARC) headers are not visible in the provided excerpt — **cannot verify**.
- Sending domain `em.michaelscustomframing.com` is a properly delegated subdomain, consistent with aligned DKIM/SPF practice, but evidence of headers is not in scope here.

## 6. Email-to-Site Continuity
- Tracking parameters use legacy Coremetrics `cm_mmc=EMAIL-_-Custom_Frame-_-20260524_S2_CustomFrame_FF_US-_-HEADER_LOGO` rather than standard UTM (`utm_source`/`utm_medium`/`utm_campaign`).
- No `utm_*` parameters detected in the provided source — if GA4/most modern analytics are used on the landing site, the email's contribution will not auto-attribute without a server-side mapping.
- Landing page alignment cannot be verified from source alone.

## 7. Recommendations
1. Uncomment the header-logo `<a>` wrapper (or remove the dead block) and strip the base64 `customerEmail=` param from the URL — pass it via the SFMC redirector only.
2. Fix CSS defects: remove stray `s` in `@-ms-viewport`, replace `max-height: auto` with `max-height: none` (or delete), correct `a:visted` → `a:visited`.
3. Move `<!DOCTYPE>` to the top of the document, above the SFMC wrapper table, to avoid quirks-mode rendering.
4. Add `lang="en"` on `<html>` and `rel="noopener noreferrer"` to all `target="_blank"` anchors.
5. Add UTM parameters to landing URLs in parallel to `cm_mmc` for GA4 attribution (e.g., `utm_source=email&utm_medium=crm&utm_campaign=20260524_CustomFrame_FF_US`).
6. Re-run the audit against the full HTML to verify unsubscribe link, physical postal address, and `List-Unsubscribe` / `List-Unsubscribe-Post` headers for CAN-SPAM and one-click compliance.
