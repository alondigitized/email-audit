# Homepage snapshot · www.michaels.com · 2026-07-20
**Score:** 4/10 · **Type:** Site journey · **2026-07-20**
## Executive summary

- Okay, so the first thing I see when I open Michaels is a giant cookie consent banner eating my entire screen — so I literally cannot tell you what the hero looks like. What I *can* see is a 30% off promo with the code **MERRY30**… and today is July 20th. *Merry* Christmas, I guess? Michaels clearly loves a deal, but this feels like someone forgot to swap out the holiday campaign, and the blocked-by-banner experience is not giving me the warm Pinterest-inspo vibes I came here for.

## What's working

- **"Buy Again" tab** — as someone who re-orders Crayola bulk packs and glitter glue every other month, this is genuinely useful and I'm glad it's above the fold
- **MakerPlace in the top nav** — my rewards program is prominently named, not buried; I feel seen as a member
- **30% off banner** — the offer itself is solid and the code is visible; I would absolutely copy that code if I hadn't been distracted by the cookie wall
- **"Ask Mike" CTA** — a friendly AI assistant button is on-brand for a craft store; I'd tap it to find a birthday party kit fast
- **"Savings" as a dedicated nav tab** — coupon-first shopper like me goes straight there

## What's weak

- **Cookie consent popup blocks 80%+ of the viewport** — I can't see the hero, product imagery, or any lifestyle content; this is the single biggest conversion killer on this screen
- **MERRY30 in July** — a Christmas promo code in midsummer makes the offer feel either broken or forgotten; I'd wonder if it even works
- **No visible CTA button** — below the promo banner there's just the cookie wall; nothing says "Shop Now," "Get Inspired," or "Build a Birthday Kit"
- **No loyalty balance or personalized greeting** — I'm presumably logged in (or at least recognized), and I see zero "Hi Mira, you have 500 points" type hook
- **Zero craft/project imagery above fold** — the hero is completely obscured; I have no idea what Michaels wants me to care about right now

## Recommendations

- **Dismiss the cookie banner by default on return visits** (or shrink it to a slim bottom bar) — blocking the hero on re-engagement is a guaranteed bounce for anyone who isn't highly motivated
- **Swap MERRY30 for a summer/back-to-school campaign code** — something like SUMMER30 or CRAFT30 would feel timely and not raise red flags about whether the code is expired
- **Surface a loyalty balance chip** next to the MakerPlace nav link — "You have 320 pts · Redeem" would keep members like me engaged and convert that tab tap into a session
- **Add a quick-tap row of summer project categories** immediately below the promo banner — "Birthday Kits," "Kids' Crafts," "Seasonal Decor" — so I can get to my category in one tap even with the banner dominating
