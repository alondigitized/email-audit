# Final weekend 🔔 Extra 20% off select styles
**Score:** 8/10 · **Type:** Email audit · **2026-07-03**
## Executive summary

- This is Pottery Barn's sixteenth-plus send in the July 4th campaign and the second on July 3rd alone. By any subscriber's count, "Final weekend" is the first subject line in this entire sequence that actually earns its urgency — July 4th is Saturday, so the deadline is real, not manufactured. The creative structure is meaningfully different from prior sends: the Open Box Outlet section is new, and the "Recommended Just For You" block adds genuine personalization. That said, the brand has trained its list to ignore these emails through sheer volume, and the "select styles" qualifier in the subject line does quiet work to undermine what looks like a broad sitewide offer inside.
- Visual execution is clean. The 2×2 category grid with specific discount depths (70% off Bedding, 40% off Sofas & Chairs) is more useful than the vague "up to X% off" hero-only format used in prior sends. The Open Box Outlet callout with its own "Extra 20% off" is the lone genuinely additive content in this campaign.
- Verdict: best send of the July 4th run on execution, but too late in a too-crowded sequence to rescue open rates. The damage is cadence, not creative.

## What's working

- **"Final weekend" subject framing is the first chronologically honest urgency hook in this campaign** — July 4th is actually two days away.
- **Category tiles with specific discount depths** (Up to 70% Bedding, Up to 40% Sofas & Chairs, Up to 70% Pillows & Decor, Up to 40% Outdoor) give the eye a fast scanning path that prior sends lacked.
- **Open Box Outlet Deals section is genuinely new content** — no prior send in this sequence surfaced outlet pricing; it's differentiated and targets a distinct buyer intent.
- **"Recommended Just For You" personalized product block** is visible and signals the brand is using browse/purchase data rather than blasting everyone the same grid.
- **Render is clean** — no broken images, no overlapping text, consistent Pottery Barn visual identity throughout.

## What's weak

- **"Select styles" in the subject vs. a broad 20% off presentation in the body** creates a quiet bait-and-switch expectation gap — the email never prominently restates the exclusion inside.
- **Bell emoji (🔔) is a weak creative choice** — on July 2nd the brand already used a crystal ball emoji for the same discount; this reads like a random emoji swap, not a creative decision.
- **CTA copy is generic** — "SHOP NOW" / "SHOP SALE" throughout; zero category-specific CTAs (e.g., "Shop Outdoor" on the outdoor tile) despite the category grid being the layout's centerpiece.
- **Cadence penalty is real** — this is the second email today and the sixteenth-plus in the series; any marginal urgency "Final weekend" creates is eroded by the volume of identical prior sends.

## Recommendations

- 1. **Surface the "select styles" exclusion inside the body** — add a single line beneath the hero ("Applies to sale styles; exclusions include rug pads and gift cards") so the subject/body feel consistent rather than bait-and-switch.
- 2. **Add category-specific CTA copy on each tile** — replace "SHOP NOW" with "Shop Outdoor Sale," "Shop Bedding Sale," etc. Easy lift, higher click relevance.
- 3. **Move Open Box Outlet above the category grid** — it's the only genuinely new content in 16 sends; leading with it would differentiate the email at first scroll, not bury it below the fold.
- 4. **Cut send frequency immediately after this email** — one "campaign close" send on July 4th morning is the right cadence; any additional sends on July 4th itself will cannibalize deliverability reputation.
- **Subject Alt A:** `Final 2 days: Extra 20% off bedding, sofas & more`
- **Subject Alt B:** `Sale ends Sunday — extra 20% off + Open Box deals`
- **Preheader Alt A:** `Plus extra 20% off Open Box Outlet items — outlet pricing stacked on top`
- **Preheader Alt B:** `Bedding up to 70% off, sofas up to 40% — weekend cutoff`

### 1. Technical Summary

One CTA link returns a hard 403, rendering the credit card acquisition banner completely non-functional. The email also contains three HTTP image sources, ~50 images missing alt text, PHP `header()` directives embedded inside a CSS `<style>` block, and missing List-Unsubscribe headers — all of which pose deliverability, rendering, and compliance risk.

---

### 2. Link & Tracking Issues

**[FAIL] Broken link — 403 response**
The credit card "Apply & Buy" banner link returns 403:
```
https://clickcp.potterybarn.com/c/da01b407-b21c-4618-a71b-f83bef0dd682
  ?brandCode=POTTERYBARNCB
  &marketingChannelCode=APPLYANDBUY
  &cm_ite=PB_header_nonmember
```
This is a top-of-email placement (`cm_ite=PB_header_nonmember`). Every click on that banner goes nowhere. Likely a misconfigured or expired redirect entry in the `clickcp.potterybarn.com` click-tracking system.

**[WARN] 23 tracking links not probed**
All links through `click.e.potterybarn.com` and `clickcp.potterybarn.com` were skipped by the HTTP probe. Status of destination URLs (potterybarn.com product/category pages) is unverified.

**[WARN] Plain-text body is 74% URLs**
11,950 of 16,178 chars in the plain-text part are raw URLs. This ratio is a known spam-filter signal in Gmail and Outlook filtering heuristics.

---

### 3. Rendering & Accessibility

**[FAIL] PHP `header()` directives inside `<style>` block**
The following server-side PHP code appears verbatim inside a `<style>` tag:
```css
header('Content-Type: image/jpeg');
header("Cache-Control: no-store, no-cache, must-revalidate, max-age=0");
header("Cache-Control: post-check=0, pre-check=0", false);
header("Pragma: no-cache");
```
This is dead code in an HTML email context — email clients will parse it as invalid CSS. It indicates a dynamic image script was copy-pasted into the email template without sanitization.

**[FAIL] 3 HTTP image sources — will be blocked by major clients**
Gmail, Apple Mail, and Outlook on secure networks actively block mixed-content HTTP image loads:
- `http://edm.westelm.com/we/evergreen/spacer_0.gif` — cross-brand asset, HTTP
- `http://edm.potterybarn.com/pb/thekey/CC_Banner/PB/Foot_NonMem_PB.jpg` — footer credit card banner, HTTP
- `http://edm.potterybarn.com/pb/2022/0311_Key_CC_Email_BrandBanner/slices_02.jpg` — 2022-era asset path, HTTP
- `http://svopn.potterybarn.com/?sv_cid=0053_00597&sv_emopen=true&...` — open-tracking pixel, HTTP (also see §5)

**[WARN] ~50 images missing `alt` text**
Virtually every content image in the email has an empty or absent `alt` attribute, including all product images, banner slices, and footer images. With images disabled (default in many enterprise email clients), the email renders as blank white rows with no text fallback.

**[WARN] Mismatched asset path for top banner**
The urgency banner `src` pulls from a `MemorialDayBanners/` directory:
```
https://edm.potterybarn.com/pb/2026/US/MemorialDayBanners/S26_MemorialDaySale_UrgencyTopBanner_FinalWeekend.jpg
```
For a July 4th sale send, this path suggests the asset was either recycled from a Memorial Day template or a wrong image is being served. Verify the rendered image matches campaign intent.

**[WARN] Empty `<title>` element**
`<title></title>` is blank. While minor, some clients display this in tab/window labels, and it's a signal of template hygiene issues.

**[WARN] `maximum-scale=1` on viewport meta**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
This prevents users from pinching to zoom, which is an accessibility barrier on mobile. WCAG 2.1 SC 1.4.4 requires text to be resizable to 200% without assistive technology.

### 5. Compliance (CAN-SPAM, Unsubscribe, Authentication)

**[WARN] `List-Unsubscribe` header absent**
The QA relay did not capture a `List-Unsubscribe` header. Gmail and Yahoo require this header for bulk senders (>5k/day) per their 2024 enforcement guidelines. Absence can result in the email being routed to spam or the unsubscribe flow being degraded.

**[WARN] `List-Unsubscribe-Post` (RFC 8058) absent**
One-click unsubscribe as required by Gmail/Yahoo bulk sender policy is not confirmed. Without this, Gmail's native unsubscribe button may not appear or may fall back to a slower flow.

**[WARN] `Authentication-Results` header not captured**
SPF and DKIM pass/fail status is unknown due to AgentMail relay behavior. Cannot confirm DMARC alignment for `e.potterybarn.com` sending domain.

**[WARN] Open-tracking pixel is HTTP**
```
http://svopn.potterybarn.com/?sv_cid=0053_00597&sv_emopen=true
  &sv_sveme=lila-hearth-potterybarn-fap6e@etell.app
```
An HTTP open pixel will be blocked by Apple Mail Privacy Protection proxy (which upgrades to HTTPS at prefetch) and may fail silently in clients that enforce HTTPS-only. Open rate data from this pixel is likely inaccurate.
