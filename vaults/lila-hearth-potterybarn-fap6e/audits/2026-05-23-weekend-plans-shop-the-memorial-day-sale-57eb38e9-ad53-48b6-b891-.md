# Weekend plans? Shop the MEMORIAL DAY SALE ✔️
**Score:** 9/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- This is the fourteenth Pottery Barn Memorial Day email in roughly six days — and it shows. The template is identical to the prior run: red hero banner, "Extra 20% off Select Styles," a category image grid, then a "Recommended Just For You" personalization block. Pottery Barn already declared "Final weekend!" on 5/22, so arriving the next morning with "Weekend plans?" feels not like a follow-up but like a reset of the clock — which quietly kills any urgency they'd built.
- That said, the email itself is competently executed. The hero delivers the offer clearly, the render is clean, and the "Recommended Just For You" block is a genuine personalization signal most brands don't bother with. The category grid covers outdoor furniture, bedding, and indoor upholstery — appropriate Memorial Day fare.
- The problem isn't the creative. It's the cadence. Fourteen sends in six days on the same promotion, with escalating urgency language that keeps getting contradicted by the next morning's email, trains subscribers to ignore every signal. This send is fine in isolation; in context, it's noise.

## What's working

- **Hero is immediately legible** — "Extra 20% off" reads in under a second, offer is not buried.
- **"Recommended Just For You" block** is a real personalization signal; specific product cards rather than generic category banners.
- **Clean render** — no broken images, no overlapping text, category grid loads correctly.
- **Appropriate category breadth** — outdoor dining, outdoor seating, bedding, indoor sofas all visible; covers the Memorial Day home-sale occasion well.
- **"SHOP NOW" CTA is above the fold** and high-contrast against the dark hero banner.

## What's weak

- **Cadence has collapsed credibility** — "Final weekend!" ran yesterday (5/22); this send implicitly undoes it. A subscriber who opened both knows the urgency is manufactured.
- **"Weekend plans?" opener is flabby** — conversational hook wastes the first few characters of a subject line that should be working harder on a competitive inbox day.
- **No loyalty or member pricing signal** — Pottery Barn has a rewards program; nothing visible here differentiates a member from a cold prospect.
- **Category grid links to categories, not hero products** — nothing anchors a specific must-have item, so there's no focal pull toward the click.
- **Offer has been visible for six days** — "Extra 20% off select styles" started appearing May 17–18; at this point a returning subscriber has either bought or decided not to.

## Recommendations

- 1. **Stop sending daily until the offer actually expires** — one send today, one on Memorial Day itself (Monday), done. The brand is training its list to tune out every send.
- 2. **Make the subject do work the hero can't** — lean into the specific category or a single hero product rather than restating the banner copy.
- 3. **Inject a concrete deadline with a specific time** — "Ends Monday at midnight" is more credible than "weekend" after six days of "almost over."
- 4. **Surface a specific hero product** — pick one item (e.g., a best-selling outdoor sofa) and lead with it rather than a category collage; gives a reason to click that a category grid can't.
- 5. **Add a loyalty-member pricing callout** — "Members save an extra 5%" or similar differentiates recipients and rewards opens.
- **Subject Alt A:** `Extra 20% off ends Monday — top Memorial Day picks`
- **Subject Alt B:** `Last day: Extra 20% off furniture & bedding`
- **Preheader Alt A:** `Outdoor sofas, dining sets, and bedding — all on sale through tonight.`
- **Preheader Alt B:** `Your recommended picks are on sale now. Ends Memorial Day.`

### 1. Technical Summary

One confirmed broken CTA link (403) blocks the credit card apply-and-buy flow. Three images are served over HTTP in a 2026 send, and PHP `header()` function calls were accidentally embedded in a `<style>` block — a clear template assembly defect.

---

### 2. Link & Tracking Issues

**[FAIL] Broken link — 403 on credit card apply CTA**
```
https://clickcp.potterybarn.com/c/da01b407-b21c-4618-a71b-f83bef0dd682
  ?brandCode=POTTERYBARNCB
  &marketingChannelCode=APPLYANDBUY
  &external_id=PB_Email_MemberBanner
  &cm_ite=PB_header_nonmember
```
The `marketingChannelCode=APPLYANDBUY` path on the `clickcp.potterybarn.com` router is returning 403. This is the Key credit card banner CTA — a revenue-bearing link — and it is dead for all recipients. The `mi_mid` and `cp_cid` session tokens in the URL suggest this may be a session-scoped link that expired before send, or a misconfigured campaign code on the router.

**23 click-tracking links skipped** — all routed through `click.e.potterybarn.com`. Destination URLs and UTM integrity cannot be verified without following redirects; flagged for manual spot-check.

**Open-tracking pixel served over HTTP**
```
src: http://svopn.potterybarn.com/?sv_cid=0053_00597&sv_emopen=true
     &sv_sveme=lila-hearth-potterybarn-fap6e@etell.app
```
HTTP pixels are blocked by default in Gmail, Apple Mail, and Outlook. Open-rate data for this campaign is likely underreported.

---

### 3. Rendering & Accessibility

**PHP `header()` calls embedded in CSS block (template defect)**

The final `<style>` block contains raw PHP function calls that were not stripped before send:
```css
header('Content-Type: image/jpeg');
header("Cache-Control: no-store, no-cache, must-revalidate, max-age=0");
header("Cache-Control: post-check=0, pre-check=0", false);
header("Pragma: no-cache");
```
CSS parsers silently ignore these, so rendering is unaffected, but this confirms a template assembly failure — a server-side image-generation script's PHP headers were copied verbatim into the email template.

**3 images served over HTTP — may be blocked by client image proxies**
| File | Domain |
|---|---|
| `spacer_0.gif` | `http://edm.westelm.com` (cross-brand domain) |
| `Foot_NonMem_PB.jpg` | `http://edm.potterybarn.com` |
| `slices_02.jpg` (Key CC banner) | `http://edm.potterybarn.com` |

The `spacer_0.gif` from `westelm.com` is a cross-brand asset — potentially a shared CDN artifact, but anomalous in a Pottery Barn send.

**38 images missing `alt` text**

Includes content images (product grid `slices_01` through `slices_13`, banner `S26_MemorialDaySale_UrgencyTopBanner_FinalWeekend.jpg`, outdoor banner, and the full footer slice set). When images are blocked, the email renders as a blank white column with no readable content. WCAG 2.1 SC 1.1.1 non-conformant.

**Viewport locks user zoom**
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1" />
```
`maximum-scale=1` prevents pinch-to-zoom in mobile browsers — an accessibility regression flagged by WCAG 1.4.4.

**`<title>` element is empty** — screen readers and some clients announce "Untitled" in the message preview pane.

### 6. Email-to-Site Continuity

The 23 click links all pass through `click.e.potterybarn.com` before landing on `potterybarn.com`. UTM parameter presence on final destination URLs cannot be confirmed without following the redirect chain — manual spot-check required.

The broken `APPLYANDBUY` link (`cm_ite=PB_header_nonmember`) uses Pottery Barn's internal campaign tracking params but no standard `utm_*` params are visible in the raw URL, which means even if the link were live, attribution in GA4/Adobe would depend entirely on the router appending UTMs on redirect.

No direct `potterybarn.com` links bypass the click-tracker, so if the tracker is down, all links fail simultaneously — no fallback.
