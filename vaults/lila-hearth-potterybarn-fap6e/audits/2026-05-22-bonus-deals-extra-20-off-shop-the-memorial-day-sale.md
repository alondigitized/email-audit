# BONUS deals ❤️ Extra 20% off + Shop the Memorial Day Sale!
**Score:** 8/10 · **Type:** Email audit · **2026-05-22**
## Executive summary

- This is Pottery Barn's twelfth Memorial Day email in roughly six days, and "BONUS deals" is the most revealing subject line yet — because there is nothing bonus inside. Open it and you get the exact same red banner, the exact same "Extra 20% off select styles," and the same five-category discount grid that has anchored every send since last Tuesday. The 5/22 "Final weekend!" send at least had a real calendar hook to justify the send; this one invents urgency out of thin air.
- The one genuine upgrade over the recent wave is a personalized "Recommended For You" product section with actual thumbnails and prices. That section is more compelling than the generic category grid above it — and it's buried near the bottom. If Pottery Barn inverted the layout and surfaced personalized picks first, this would be a materially better email.
- As it stands, this send will convert the stragglers who haven't bought yet. Everyone else has learned to ignore the red banner.

## What's working

- Red "MEMORIAL DAY SALE — Extra 20% off" banner is immediately readable and above the fold; the offer is the first thing the eye lands on.
- Category grid (Furniture, Bedding, Outdoor, etc.) with per-category discount percentages gives clear wayfinding for a subscriber who already knows what they want.
- "Recommended For You" personalized product section with real thumbnails and prices is the strongest element in the email — actual intent signal.
- "Earn 10% Back in Rewards" loyalty callout is visible and adds incremental value for members scanning the email.
- Clean render — no broken images, no overlapping text, no obvious layout failures.

## What's weak

- "BONUS deals" in the subject line is a claim the email cannot back up — nothing inside is new, added, or bonus versus the prior 11 sends.
- No visible deadline anywhere above the fold; "Extra 20% off" with zero time pressure on Day 6 of the same sale is structurally inert.
- The category discount grid creates an internal contradiction: Furniture is "Up to 50% off" but Sofas & Chairs is "Up to 20% off" — the biggest-ticket items carry the smallest discount, which undermines the hero claim.
- All five category CTAs read "SHOP NOW" — no differentiation, no specificity, no reason to choose one over another.
- "Recommended For You" is buried below the fold when it's the most personalized, highest-intent content in the email.

## Recommendations

- 1. **Drop "BONUS deals" entirely — replace with the real calendar hook.** The sale ends this weekend; that is the only honest urgency available. Make the subject do that work.
- 2. **Put a visible deadline in the red banner.** Not fine print — "Ends Sunday" or "2 days left" in the hero itself. Every single prior send in this campaign skipped this and left money on the table.
- 3. **Move "Recommended For You" to hero position.** Personalized product picks outperform category grids every time. Put them first; push the grid below.
- 4. **Collapse the category grid to two tiles.** Feature Furniture and Outdoor (peak Memorial Day purchase intent); remove the visual noise of Bedding, Bath, and Sofas competing for the same click.
- 5. **Fix the discount contradiction.** If sofas are only 20% off, don't headline "Up to 50% off Furniture" two tiles above — it sets expectations you can't meet for the biggest-ticket category.
- **Subject Alt A:** `Extra 20% ends Sunday — your picks are waiting`
- **Subject Alt B:** `2 days left: extra 20% off + picks chosen for you`
- **Preheader Alt A:** `Your personalized picks + Memorial Day discounts — shop before it's over.`
- **Preheader Alt B:** `Furniture, bedding, outdoor — your top picks at an extra 20% off this weekend only.`

## Technical Audit — Pottery Barn "Memorial Day Sale / Extra 20% Off"

### 1. Technical Summary

Two hard-broken CTAs (403) and PHP source code leaked into a `<style>` block are the critical defects. The email also carries a systemic alt-text gap across 38+ images and three mixed-content HTTP asset loads that will trigger security warnings in modern clients.

---

### 2. Link & Tracking Issues

**[CRITICAL] Credit card apply link returns 403**
```
https://clickcp.potterybarn.com/c/da01b407-b21c-4618-a71b-f83bef0dd682
  ?brandCode=POTTERYBARNCB&marketingChannelCode=APPLYANDBUY
  &external_id=PB_Email_MemberBanner&cm_ite=PB_header_nonmember
```
This is the Key Rewards / credit card banner CTA — a revenue-generating placement. The server returns 403, meaning all clicks on that module land on an error page.

**[CRITICAL] West Elm CDN spacer image 403**
```
http://edm.westelm.com/we/evergreen/spacer_0.gif
```
Cross-brand asset from the West Elm CDN. Returns 403 and is also HTTP (see §3). Likely a stale evergreen footer module that was never updated to a Pottery Barn host.

**Tracking links:** 24 click-redirect URLs via `click.e.potterybarn.com` were not probed. Destination UTM coverage cannot be confirmed from the source alone (see §6).

---

### 3. Rendering & Accessibility

**[CRITICAL] PHP code injected into `<style>` block**

Inside a `<style>` tag in `<head>`, the following raw PHP appears as literal CSS text:

```css
header('Content-Type: image/jpeg');
header("Cache-Control: no-store, no-cache, must-revalidate, max-age=0");
header("Cache-Control: post-check=0, pre-check=0", false);
header("Pragma: no-cache");
```

This is unexecuted PHP that leaked from a server-side template. It is inert in the browser but is technically invalid CSS. Some strict email clients may reject or partially mangle the entire `<style>` block upon encountering this, causing layout breakage.

**[HIGH] 38 images missing `alt` text**

Nearly every content image — all 13 `slices_NN.jpg` hero/body images, all product images (Westin mattress, Cayman bed, farmhouse bed, curtain brackets, sheet set, etc.), the outdoor sale banner, and all 18 footer slices — has no `alt` attribute. Subscribers with images disabled (common on corporate mail servers) see a blank email. Screen reader users get no context.

**[HIGH] 3 image sources over plain HTTP**

| Image | Source |
|---|---|
| `spacer_0.gif` | `http://edm.westelm.com/we/evergreen/spacer_0.gif` |
| `Foot_NonMem_PB.jpg` | `http://edm.potterybarn.com/pb/thekey/CC_Banner/PB/Foot_NonMem_PB.jpg` |
| `slices_02.jpg` | `http://edm.potterybarn.com/pb/2022/0311_Key_CC_Email_BrandBanner/slices_02.jpg` |

The open-tracking pixel also fires over HTTP:
```
http://svopn.potterybarn.com/?sv_cid=0053_00597&sv_emopen=true&sv_sveme=...
```
Gmail, Apple Mail, and Outlook 365 will block or proxy these. Mixed content warnings may suppress the images entirely; the HTTP open pixel will produce inaccurate open-rate data as it's intercepted by Apple MPP and Gmail Image Proxy regardless.

**[LOW] `<title>` tag is empty**

`<title></title>` — some clients display this in preview or tab labels.

**[LOW] Conflicting viewport meta tags**

Two viewport directives are commented out but still present in source; the active one (`width=device-width, initial-scale=1, maximum-scale=1`) conflicts with the `@media (min-width: 700px) { img { max-width: 650px } }` rule immediately below it. Minor but worth noting for QA hygiene.

### 5. Compliance

**[WARN] `List-Unsubscribe` header not captured**
QA relay did not observe the header. If it is genuinely absent at delivery time (not just a relay artifact), this violates Google/Yahoo bulk sender requirements (enforced since February 2024) and reduces deliverability to Gmail addresses.

**[WARN] `List-Unsubscribe-Post` (RFC 8058) not captured**
One-click unsubscribe is required by Google/Yahoo for bulk senders. Absence triggers increased spam placement.
