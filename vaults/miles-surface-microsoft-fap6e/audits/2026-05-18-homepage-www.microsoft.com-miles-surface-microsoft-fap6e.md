# Homepage snapshot · www.microsoft.com · 2026-05-18
**Score:** 4/10 · **Type:** Site journey · **2026-05-18**
## Executive summary

- This is Microsoft's mobile store homepage positioned as a deal-discovery surface with an AI-first interaction model — which is very on-brand for 2026 Microsoft. The "Microsoft Store Deals" headline tells me exactly what they want me to do, and the quick-filter chips for Surface and consoles feel aimed directly at someone like me. That said, one glaring issue immediately kills confidence: there's a literal "Placeholder text" dropdown sitting on the page. That's not a vibe problem, that's a shipped bug.

## What's working

- **"Refurbished Surface" chip** — I've bought refurb Surface hardware before at education pricing. This chip is a one-tap entry point I'd actually use.
- **"Consoles under $500" chip** — Directly speaks to my Game Pass + Xbox world. Useful filter shorthand.
- **Laptop + Xbox controller imagery** — The product shot with gaming iconography is the single strongest signal that Microsoft knows who is likely on this page. It earns attention.
- **AI "Ask a question" search bar** — As a native tech user, I appreciate this. I'd probably type "Surface Studio 2+ deals" and see what comes back.
- **"Trade-in offers" chip** — Surface loyalist behavior is to upgrade on trade-in cycles. This chip is smart.

## What's weak

- **"Placeholder text" dropdown** — This is shipped content. It's visible above the fold on a mobile viewport, and it signals that QA missed a build step. Immediately erodes trust for a tech-literate user.
- **No explicit CTA button** — The page converts me to *search*, not to *buy*. The AI input is a discovery tool, not a conversion trigger. I'd want a "Shop Surface Deals" button somewhere.
- **"$500+ in added value"** — Bundle language that obscures what I'm actually getting. Is it game credits? Accessories? Subscriptions? I can't tell from this screen.
- **No account/membership hook** — I'm a returning Microsoft customer. There's zero sign that the page knows me or has anything personalized to show me.
- **No trust signals** — No reviews, no return policy mentions, no secure checkout badge. For a purchase of Surface magnitude, this matters.

## Recommendations

- **Kill "Placeholder text" immediately** — Ship a real module or remove the accordion entirely. A live QA sweep of mobile viewports would catch this in 10 minutes.
- **Add a hard CTA button below the AI search bar** — Something like "See all Surface deals →" so users who don't want to chat can still find a path to product pages.
- **Make "$500+ in added value" scannable** — Replace with a tooltip or inline explainer: "Includes Game Pass Ultimate (12 mo.), Office, and Xbox controller — valued at $X." Specificity converts; vagueness bounces.
- **Surface the Xbox Game Pass membership hook** — If I'm a Game Pass subscriber logged into my Microsoft account, show me a personalized "your member deals" module. This is table-stakes for a loyalty ecosystem Microsoft already has.
