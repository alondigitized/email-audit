# Homepage snapshot · www.microsoft.com · 2026-05-13
**Score:** 1/10 · **Type:** Site journey · **2026-05-13**
## Executive summary

- Welp. I opened microsoft.com and the entire viewport is a chatbot named "Store Assistant" with an "End conversation" modal sitting on top of it. I cannot see the homepage at all — zero hero, zero nav, zero product imagery. Whatever Microsoft is actually selling today is completely buried under an AI layer I never asked for. As a Surface loyalist this is... not a great look.

## What's working

- The "Store Assistant" chatbot intro copy is legible and warm ("I can also connect you with a Microsoft Sales Associate") — if I'd intentionally opened the chat, that's decent onboarding
- The blue accent color on "End conversation" button is on-brand Fluent Design; at least the modal looks like Microsoft made it

## What's weak

- The "End conversation" confirmation modal stacked on top of the already-open chatbot is a double-interruption — I'm being asked to confirm ending something I never chose to start
- The entire homepage is inaccessible; every rubric criterion that requires seeing a hero, product rail, or promo banner scores zero by definition
- "Store Assistant is powered by AI, so surprises and mistakes are possible" — fine print visible in the chat window is an odd trust signal to lead with
- No way to reach Surface, Xbox, or any Microsoft product from what I can see; this chatbot has fully hijacked navigation

## Recommendations

- Kill the auto-open chatbot or gate it behind a deliberate user action — popping it on first load blocks the homepage experience entirely
- The "End conversation" confirmation modal is unnecessary friction; a single close button on the chat widget is sufficient
- If the AI assistant must be present, render it as a minimized FAB in the corner so the homepage hero and nav remain accessible
- Add a "Shop Surface" or "Xbox Game Pass" shortcut inside the chat itself so at least the modal routes loyalists somewhere useful instead of offering only a dead end
