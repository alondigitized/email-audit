# Happening NOW! Extra 25% off select clearance ⏰
**Score:** 7/10 · **Type:** Email audit · **2026-06-02**
## Executive summary

- This is the third send of DICK'S "Extra 25% off select clearance" creative in four days — the May 30 launch scored 8/10, the May 31 "Final Hours" resend scored 8/10, and now here it is again on June 2 with a near-verbatim subject ("Happening NOW!" vs. "is happening NOW!"). The red hero block, the multi-lane product grid, the green SHOP NOW buttons — it's the same template, same offer mechanics, same visual DNA. Nothing is broken and the execution is clean, but the creative has run out of shelf life.
- The product lanes are still well-chosen for a Walker-type persona: sandals and casual shoes lead, DSG basics follow, and the Fiver Shoe Drop at up to 50% off is a genuine value signal. But a real subscriber has seen all of this before, and the re-send without any creative refresh or escalating offer (it's still 25%, not a step-up to 30%) gives the inbox no reason to re-engage.
- The verdict: competent template, dead creative cadence. The email would earn an 8 in isolation; in context it's a 6 at best because most engaged subscribers already clicked or ignored this offer twice.

## What's working

- **Hero hierarchy is immediate.** Large white "EXTRA 25% OFF" on red registers in under a second — no hunting for the offer.
- **Product lane variety.** Sandals, DSG basics, Fiver Shoe Drop, golf — enough range that multiple sub-interests can find something.
- **Honest exclusions disclosure.** "Unless noted, exclusions apply" appears near the top, not buried in fine-print footer.
- **BOGOF 50% off Walter Hagen lane** adds a second, stronger offer mechanic that differentiates from the pure clearance framing.
- **App/loyalty nudge at bottom** extends the engagement path for ScoreCard members.

## What's weak

- **Exact same offer as May 30 and May 31 — no escalation, no new hook.** This is the third bite at an identical apple.
- **"Happening NOW!" adds no deadline.** A clock emoji isn't a deadline; there's no "ends tonight" or "through Sunday" visible anywhere.
- **No hero product specificity.** The 25% hero doesn't name a product, brand, or category — it could be from any sporting goods email.
- **Zero personalization signals.** No first name, no gender-matched creative, no "based on your recent browsing" framing anywhere in the render.
- **CTA copy is generic throughout.** Every lane uses "SHOP NOW" — not a single button says "Shop Sandals" or "See Shoe Drop Deals."

## Recommendations

- 1. **Escalate the offer to justify the re-send.** Even +5% ("Now 30% off") or "Final 48 hours" framing signals this isn't just the same email again. Without escalation, repeat sends train unsubscribes.
- 2. **Add a hard deadline in the subject and hero.** "Ends Tonight" or "Through Sunday" converts "happening now" urgency into actionable tension.
- 3. **Rename at least one SHOP NOW button to the lane's category.** "Shop Sandals & Slides" or "See the Fiver Drop" takes 30 seconds and meaningfully lifts click specificity.
- 4. **Swap the hero creative.** Even a new color or a single featured product shot breaks the déjà-vu pattern for subscribers who saw May 30 and 31.

- **Preheader Alt A:** `Sandals, DSG tees, Fiver shoes — deals close out this week`
- **Preheader Alt B:** `30+ clearance categories. Ends Sunday.`

## Technical Audit — DICK'S Sporting Goods Clearance Email

---

### 1. Technical Summary

The email carries multiple broken JSON-LD blocks (invalid syntax, stale dates, unfilled placeholders) that will silently fail Gmail's structured data pipeline, and a syntax error in MSO conditional CSS that may corrupt Outlook rendering. Core link tracking and responsive layout are structurally sound.

---

### 2. Link & Tracking Issues

**Tracking pixel uses CSS hide instead of dimension hide**
```html
<img src='https://app.dickssportinggoods.com/O/...' 
     style="display:none; max-height: 0px; font-size: 0px; overflow: hidden; mso-hide: all"/>
```
`display:none` is stripped by some clients (Gmail, Outlook) before the request fires, which can under-count opens. Standard practice is `width="1" height="1"` with no `display:none`.

**No issues** with click-tracking redirect pattern (`/T/` URLs via Epsilon/Harmony). All CTA `href` values route through `https://app.dickssportinggoods.com/T/...` as expected.

---

### 3. Rendering & Accessibility

**MSO conditional CSS — syntax error**
```css
<!--[if (gte mso 9)|(IE)]>
  div { ... padding:0;" }   ← stray double-quote before closing brace
<![endif]-->
```
The extra `"` before `}` in the `div` rule is invalid CSS. Outlook's parser may ignore the entire rule or discard subsequent declarations in the block, potentially breaking `div` background inheritance in Outlook 2016–2021.

**Logo `src` URL is truncated in source**
```
https://dsg.images.harmony.epsilon.com/_phoenix/_dev/AEM/img/headers/brand-logo--dk…
```
The path ends with `…`, suggesting the provided HTML was cut. If the actual deployed source is also truncated, the logo will produce a broken image. Needs verification against the live render.

**No issues** with `lang="en"`, `charset="UTF-8"`, `viewport` meta, `role="presentation"` on layout tables, or responsive breakpoint logic.

---

### 4. Personalization & Merge Tokens

No unresolved merge tokens visible in the truncated source (no `%%token%%`, `{{token}}`, or `[%token%]` patterns). Subject line carries no personalization — consistent with what's in the HTML.

### 5. Compliance (CAN-SPAM, Unsubscribe, Authentication)

The truncated source does not include the footer region, so physical mailing address and unsubscribe link cannot be confirmed here. These are required by CAN-SPAM and must be present in the full render.

**JSON-LD contains invalid, incomplete structured data — flag for Gmail Actions compliance:**

```json
{
  "@type": "DiscountOffer",       // ← not a valid Schema.org type
  "description": "",              // ← empty placeholder
  "discountCode": "",             // ← empty placeholder
  "availabilityStarts": "2020-03-06T06:00:00-04:00",  // ← 6-year-old stale date
  "availabilityEnds": ""          // ← empty placeholder
}
```

```json
{
  "@type": "PromotionCard",       // ← not a valid Schema.org type
  "image": ""                     // ← empty placeholder, never filled
}
```

Additionally, the JSON-LD block contains JavaScript-style `//` comments:
```js
// GIF & WEBP images are not supported...
// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
```
JSON does not permit comments. This makes the entire `<script type="application/ld+json">` block invalid JSON, which means Gmail's structured data parser will reject the whole payload and no promotional annotation will render in the Gmail Promotions tab.

---

### 6. Email-to-Site Continuity (UTM Params, Landing Page Alignment)

Cannot assess UTM parameters on destination URLs because the `?__dU__=` query strings are opaque Epsilon tracking tokens that wrap the final destination. The actual UTM attribution (if any) is encoded inside those tokens and cannot be inspected from the HTML source alone. Recommend verifying via link decode/preview in the ESP dashboard that `utm_source`, `utm_medium`, and `utm_campaign` are appended to all destination URLs before the send.
