### 1. Technical Summary

Built on Oracle Responsys. Primary technical risks are invalid JSON-LD (JS-style comments, empty promotional fields, stale 2020 campaign date) and a malformed CSS rule inside the MSO conditional block that may silently drop Outlook styles.

---

### 2. Link & Tracking Issues

- **Responsys redirect wrapper** (`app.dickssportinggoods.com/T/...`) present on all CTAs — expected for platform.
- **`__dU__` merge token** appears as a literal query parameter in the logo href:
  `...?__dU__=v0G4RBKTXg2Gs8NEX0-RpwlL2_Q96sIof5wvgkGa1Vs...`
  Confirm this token is substituted at send time; if a subscriber receives the raw token string, the redirect will break or log incorrectly.
- **UTM parameters** not visible in the encoded destination URLs within the truncated source. Cannot confirm utm_source/medium/campaign pass through to dickssportinggoods.com without decoding the full redirect chain.

---

### 3. Rendering & Accessibility

**Broken MSO conditional CSS — stray `"` in `div` rule:**
```html
<!--[if (gte mso 9)|(IE)]><style type="text/css">
  ...
  div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
</style><![endif]-->
```
The `"` before `}` is invalid CSS. Outlook's parser may reject the entire rule block, allowing layout divs to inherit incorrect spacing/sizing.

**Preheader text not properly hidden:**
The preheader ("See Messi create magic. Witness Lamine Yamal's rise.") sits as raw text inside a `<td>` that suppresses it via `font-size:0; line-height:0; height:0`. This technique is unreliable in some Outlook/MSO versions. Standard pattern is a dedicated `<span>`:
```html
<span style="display:none; max-height:0; overflow:hidden; mso-hide:all;">...</span>
```

**Logo `src` truncated in provided source** (`https://dsg.images.harmony.eps…`) — cannot verify the full URL resolves. Flagging for QA confirmation.

**Positive signals:**
- `lang="en"` on `<html>` ✓
- `role="presentation"` on all layout tables ✓
- `a[x-apple-data-detectors]` override present ✓
- Mobile breakpoint styles present ✓

**Cannot verify:** `alt` attributes on all `<img>` tags — source is truncated before body images appear.

---

### 4. Personalization & Merge Tokens

**JSON-LD script block has three distinct problems:**

**(a) JS-style comments inside JSON — invalid syntax:**
```json
{ // GIF & WEBP images are not supported...
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
JSON does not support `//` comments. This causes the entire `<script type="application/ld+json">` block to fail parsing. Gmail's Promotions tab annotation will be silently suppressed.

**(b) All `DiscountOffer` fields are empty:**
```json
"description": "",
"discountCode": "",
"availabilityEnds": ""
```
If no discount applies this send, remove the block entirely. An empty `DiscountOffer` provides no value and occupies the annotation slot.

**(c) Stale `availabilityStarts` date:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 2020 template placeholder that was never updated. Gmail may discard the offer as expired.

**(d) `PromotionCard.image` is empty** — the designer comment `// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!` confirms the image URL was never populated. Gmail promo card will render without an image or fail to render entirely.

**Segmentation:** `id="header-non-sc-member"` on the header table signals this is the non-ScoreCard variant. Verify the suppression logic for ScoreCard members is correctly applied at Responsys send segmentation.
