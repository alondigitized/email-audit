# An EXTRA 25% off select clearance is a click away... shop now!
**Score:** 5/10 · **Type:** Email audit · **2026-06-19**
## Executive summary

- This is, by any honest count, the sixth or seventh consecutive send of essentially the same email from DICK'S Clearance sub-account in under 72 hours. The hero is the same dark-red banner with "EXTRA 25% OFF" in massive white type, the product grid below follows the same golf → bikes → bags → rewards cadence, and even the subject-line formula ("EXTRA 25% off select clearance is a click away") is a slight remix of the June 17 "You won't want to miss an extra 25% off" send. The Father's Day angle gets one more lap here (June 19, two days before the holiday), which provides a thin veneer of freshness — but the underlying creative is pixel-identical to the prior sends.
- Where the email lands well is execution fundamentals: clean render, bold visual hierarchy, recognizable sender, and a real concrete offer front-and-center. But any subscriber who has opened this inbox in the last three days has already mentally catalogued this as noise. No cadence signal is more damaging to future open rates than sending the same offer repeatedly with a reshuffled subject line.
- The bottom line: this is a technically competent email deployed against a dead audience segment. The brand burned through its goodwill on the first two sends; everything after is diminishing returns.

## What's working

- **Hero does its job** — "EXTRA 25% OFF" in oversized white type on dark red lands immediately; no ambiguity about the offer.
- **Multi-category product grid** — Golf clothing, bikes, bags, and brand callouts (adidas, UA VRST) give shoppers several entry points without feeling cluttered.
- **Father's Day hook is still credible** — A June 19 send with "Father's Day is June 21" framing is genuinely timely, unlike a post-holiday re-send.
- **Rewards section visible** — The 20% back in rewards callout adds a loyalty layer above the clearance discount, which is a real secondary conversion lever.

## What's weak

- **Cadence fatigue is severe** — This is the fifth or sixth near-identical send from this sub-account in ~72 hours; the inbox experience is pure noise for any engaged subscriber.
- **Subject line is too long and too familiar** — At 62 chars it clips on mobile, and "EXTRA 25% off select clearance" has now appeared verbatim in at least four consecutive subject lines.
- **No new hook or creative differentiation** — The June 17 "You won't want to miss" send already used the curiosity-gap angle; this one's "…is a click away" doesn't add anything new.
- **No urgency mechanism** — Unlike the June 16 Father's Day deadline send that had a countdown clock, this email has no hard end-date for the 25% off offer, making the "shop now" demand feel hollow.
- **Product specificity is low** — The grid shows category images, not individual hero products with names, prices, or sizes — nothing that would stop a browse-scanner.

## Recommendations

- 1. **Kill the cadence** — The highest-leverage fix is not in this email; it's suppressing this sub-account from sending again until the prior three sends have fully burned through unengaged subscribers. No creative tweak saves a sixth identical email.
- 2. **Add a hard deadline** — Bring back the countdown clock mechanic from the June 16 send: "Extra 25% off clearance — ends tonight at midnight." Credible urgency is the one signal this creative series has been missing since the Father's Day deadline lapsed.
- 3. **Surface one hero product** — Pin a single specific item (e.g., "Nike men's running shoes, was $110, now $62 after extra 25%") above the fold. Price transparency converts better than category grids.
- 4. **Shorten and differentiate the subject** — The current line is 62 chars and echoes every prior send.
- **Subject Alt A:** `Last call: extra 25% off clearance ends tonight`
- **Subject Alt B:** `Nike gear from $22 — extra 25% off clearance`
- **Preheader Alt A:** `Deals on golf, bikes, bags and more — but not for long.`
- **Preheader Alt B:** `Stack your rewards: earn 20% back on every clearance buy.`

## Technical Audit — DICK'S Sporting Goods Clearance Email

---

### 1. Technical Summary

The email's rendering infrastructure is largely sound (table layout, conditional VML, responsive breakpoints), but the `<script type="application/ld+json">` block contains multiple production-blocking defects — invalid JSON syntax, stale dates, and unfilled placeholder values. One CSS syntax error in an Outlook conditional comment also warrants a fix.

---

### 2. Link & Tracking Issues

**Open-tracking pixel** — missing `alt` attribute:
```html
<img src='https://app.dickssportinggoods.com/O/v610000019ee190d90...'
     style="display:none; max-height: 0px; ..." />
```
The `alt` attribute is absent. While invisible, some strict email clients (e.g. Lotus Notes legacy, some accessibility scanners) flag bare `<img>` tags. Add `alt=""`.

**Logo image URL contains `/_dev/` path segment:**
```
https://dsg.images.harmony.epsilon.com/_phoenix/_dev/AEM/img/headers/brand-logo--dk…
```
The source is truncated, but `/_dev/` in a production asset URL is a red flag — this may be resolving to a staging/dev CDN path. Confirm the full resolved URL points to the production Harmony/Epsilon asset, not a dev environment.

**Redirect-wrapped links** — tracking URLs route through `app.dickssportinggoods.com/T/...` (Epsilon), which is expected. UTM parameter passthrough cannot be verified without resolving the final destination URLs (see §6).

---

### 3. Rendering & Accessibility

**CSS syntax error in Outlook conditional comment:**
```css
<!--[if (gte mso 9)|(IE)]><style>
  div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
</style><![endif]-->
```
There is a stray `"` immediately before the closing `}` in the `div` rule. This is a CSS parse error; Outlook's rendering engine may drop the entire rule or produce unexpected layout in mso-targeted clients.

**Tracking pixel in `<td id="ssl">`** — `mso-hide:all` is present, which correctly suppresses it in Outlook. No other issues with this pattern.

**`border-collapse:separate` on all tables** — used intentionally to enable `border-radius` (e.g. `border-radius:8px 8px 0px 0px` on the header table). This is a known workaround but `overflow:hidden` on a `<table>` is unreliable in Outlook; border-radius will be ignored in mso clients regardless.

**Web fonts** — `@font-face` for Archivo is gated inside `@media screen`, so Outlook/mso clients correctly fall through to `Arial, sans-serif`. No issue.

---

### 4. Personalization & Merge Tokens

**JSON-LD block contains JavaScript-style comments — INVALID JSON:**
```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@context": "http://schema.org/",
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
JSON does not permit `//` comments. This block will fail to parse in any JSON-compliant consumer (Gmail Promotions tab rich annotations, schema validators). The entire LD+JSON payload is silently rejected.

**Stale hardcoded date in `DiscountOffer`:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This date is ~6 years in the past. It should be populated with the actual campaign start date via a merge token or template variable.

**Unfilled placeholder values left in production:**
```json
"description": "",
"discountCode": "",
"availabilityEnds": "",
"image": ""
```
Four fields in the LD+JSON schema are empty strings — these appear to be template placeholders that were never populated. Combined with the invalid JSON above, Gmail's Promotions tab annotations will not render for this send.

**Designer TODO comment left in send:**
```
// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
```
Internal production instruction left in the live email source.
