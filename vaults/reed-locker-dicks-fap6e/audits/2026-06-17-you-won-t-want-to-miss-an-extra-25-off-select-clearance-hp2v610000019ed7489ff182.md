# 👋 You won't want to miss an extra 25% off select clearance
**Score:** 7/10 · **Type:** Email audit · **2026-06-17**
## Executive summary

- This is the third "Extra 25% Off Select Clearance" email from the DICK'S Clearance sub-account in roughly 48 hours — June 16 sent the dark-red hero, June 17 sent a near-carbon copy (flagged in the brand history as such), and this send is effectively a third iteration of the same creative. The hero is confident: "EXTRA 25% OFF" in massive white type on dark red reads instantly, the SHOP NOW button is clearly placed, and the $10 ScoreCard module adds a loyalty angle. Structurally sound.
- The problem is the subject line. "You won't want to miss" is FOMO padding — a four-word throat-clear before the actual offer. For the third consecutive clearance email in two days, a subscriber's more likely reaction is "I've seen this" than "I'd better open." The open-rate lift from re-sending the same offer with soft FOMO copy is likely negative at this cadence.
- The email earns its clicks if opened — multiple category modules, a Father's Day deadline hook, same-day delivery callout, and the ScoreCard reward all give a motivated shopper reasons to act. But the brand needs to earn the open first, and that's where this send stumbles.

## What's working

- **Hero reads in under a second.** Dark red + oversize "EXTRA 25% OFF" type dominates immediately; no visual ambiguity about the offer.
- **ScoreCard $10 Bonus Reward module is well-placed.** Dark green block breaks the red monotony and surfaces the loyalty angle for members.
- **Father's Day + same-day delivery callout.** The fulfillment module ("Get it by Father's Day" / same-day delivery) adds a credible, time-bound reason to act today.
- **Multi-category product grid.** Nike/adidas/VRST, outdoor, soccer, clothing — enough variety that most sporting goods subscribers will find their lane.

## What's weak

- **Third near-identical clearance email in ~48 hours.** Brand history shows June 16 and June 17 both had this exact hero — the cadence alone suppresses opens on this send.
- **Subject is FOMO-framed, not offer-led.** "You won't want to miss" wastes 4 words before the value prop; offer-led subjects outperform at this volume.
- **Product thumbnails are too small to shop.** The category modules are visually compressed — images are thumbnail-sized, making it hard to want to click into any specific product.
- **No countdown or hard deadline on the clearance offer itself.** The Father's Day deadline is present but tucked low; the hero clearance offer has no urgency mechanism tying it to a specific end date.
- **"Select clearance" qualifier is vague.** Three sends in, subscribers still don't know what's actually in clearance — a featured hero product or specific category would anchor the offer.

## Recommendations

- 1. **Rotate the hero product.** Put one specific product or category (e.g., "Nike Running — Extra 25% Off") in the hero to signal this isn't the exact same email as yesterday. Even a different colorway of the banner breaks the pattern.
- 2. **Rewrite the subject to lead with the offer.** Strip the FOMO preamble; make it direct and specific to differentiate from prior sends.
- **Subject Alt A:** `Extra 25% off clearance — Nike, adidas, VRST & more`
- **Subject Alt B:** `Clearance just got cheaper: extra 25% off ends soon`
- 3. **Add a hard deadline to the clearance offer in the hero.** "Ends Sunday" or a small countdown clock (as used effectively in the June 16 Father's Day deadline email) converts browsers.
- 4. **Surface one featured clearance item above the fold.** A single compelling hero product with a price (e.g., "$89 → $50 after extra 25% off") beats a generic category grid for click-through.
- **Preheader Alt A:** `Nike, adidas, VRST, outdoor gear — all on clearance, all an extra 25% off`
- **Preheader Alt B:** `Clearance + an extra 25% off. Father's Day shipping still available.`

## Technical Audit — DICK'S Sporting Goods Clearance Email

### 1. Technical Summary
Standard table-based email with Outlook conditional comments, responsive CSS, and Epsilon/Harmony ESP tracking. Two structural defects in the JSON-LD block and one CSS syntax error in the MSO conditional comment require remediation before this drives Gmail Promotions tab card rendering.

---

### 2. Link & Tracking Issues

**Tracking pixel present and hidden correctly** — `https://app.dickssportinggoods.com/O/v610000019ed7489ff1826a2f369fb45280/...` is embedded as a 0px hidden `<img>` with `display:none; max-height:0px` inline style. Rendering is correct.

**`__dU__` parameter in tracked click URLs** contains what appears to be a base64-encoded subscriber token (e.g., `v0G4RBKTXg2Gs8NEX0-RpwlL2_Q96sIof5wvgkGa1VsPIAdb...`). This is ESP-standard but confirms PII-adjacent data is encoded in click URLs — relevant for GDPR/CCPA link audit if the redirect chain logs full URLs server-side.

**Full link inventory not auditable** — HTML is truncated after the logo `<a>` tag. Only one click URL is visible in the provided source. All visible links route through `app.dickssportinggoods.com/T/...` redirect pattern — consistent with Epsilon tracking.

---

### 3. Rendering & Accessibility

**CSS syntax error in MSO/IE conditional comment** (`<head>` block):
```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
The stray `"` before `}` closes the `style` attribute value prematurely in strict XML parsers. Outlook renders via IE's Trident engine, which may silently discard the `div` rule entirely — resulting in unintended background-color inheritance for Outlook clients.

**Evidence:** `<!--[if (gte mso 9)|(IE)]><style type="text/css">... padding:0;"}</style>`

**Font loading** — Google Fonts `Archivo` loaded via `@font-face` with `font-display:swap` inside `@media screen` — correctly scoped so Outlook never attempts the web font. No issue.

**`role="presentation"` on layout tables** — present throughout visible source. Correct.

**`lang="en"` on `<html>`** — present. Correct.

**Alt text on logo image** — truncated before `alt` attribute is visible; cannot confirm. Flagged as unverifiable.

---

### 4. Personalization & Merge Tokens

**JSON-LD structured data block has four unfilled fields:**

```json
"description": "",
"discountCode": "",
"availabilityEnds": "",
"image": ""
```

These are Gmail Promotions tab schema fields (`DiscountOffer`, `PromotionCard`). Empty `image` and `description` will cause Gmail to suppress the promotional card entirely — the card requires at minimum a valid image URL and description string.

**Stale `availabilityStarts` date — critical:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 6-year-old placeholder timestamp. Gmail's promotions parser uses this field; a past date may cause the card to be deprioritized or not rendered as an active offer.

---

### 5. Compliance

**Invalid JSON in JSON-LD block:**
```javascript
// GIF & WEBP images are not supported and will be filtered out.
// Sample image is 538x138, 3.9 aspect ratio
// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
```
JavaScript `//` line comments are **not valid JSON**. The `<script type="application/ld+json">` block must be parseable as strict JSON. These comments will cause the entire structured data block to be rejected by schema parsers (Google, Gmail), silently dropping all three schema objects.

**Unsubscribe / CAN-SPAM footer** — not present in the truncated source. Cannot confirm physical mailing address, unsubscribe link, or `List-Unsubscribe` header. These are required — flagged as unverifiable from provided HTML.

**Authentication headers (SPF/DKIM/DMARC)** — not assessable from HTML source alone. Sending domain is `e.dcsg.com` (Epsilon subdomain). Alignment between `From: DSG@e.dcsg.com` and any `d=` value in DKIM must be verified at SMTP layer.

Click URLs route through `app.dickssportinggoods.com/T/...` ESP redirect. UTM parameters would be injected at redirect resolution — cannot verify from source. The redirect destination for the logo link is not auditable without following the redirect chain.

Offer context in subject line ("extra 25% off select clearance") should align with the `discountCode` and `description` fields in the JSON-LD schema — both are currently empty (see §4).
