# They're here! Up to 50% off this week's deals 👉
**Score:** 7/10 · **Type:** Email audit · **2026-07-07**
## Executive summary

- This is DICK'S attempting a format reset — shifting from the four-day "UP TO 70% OFF CLEARANCE / FINAL HOURS" sprint into a recurring weekly-deals digest. The header says "This Week's Deals," the layout organizes offers by category (HOKA shoes, clothing, golf balls, Adidas/Casio, bikes, outdoor equipment), and the rewards loyalty block gets real estate near the bottom. That structural choice is sound — the weekly digest format is more sustainable than the clearance countdown cadence.
- The problem is the sequencing. Yesterday's send screamed "FINAL HOURS" on 70% off; today leads with "Up to 50% off." For any subscriber who opened yesterday, that reads as: the sale just ended and the new best offer is *worse*. The step-down from 70% to 50% — even explained by a category shift from clearance to regular deals — is invisible to the recipient. "They're here!" is also underworked for an opener; it gestures at excitement without grounding it in anything specific.
- The email is clean, well-structured, and loads correctly. It's a solid execution of a format DICK'S should lean into — just dropped into the worst possible slot in a sprint that wore out its welcome three emails ago.

## What's working

- **Category-driven layout is scannable.** HOKA, golf, bikes, outdoor gear — each section has its own product image and headline. A subscriber can skip to their interest in two seconds.
- **Named brand callouts add credibility.** HOKA and Adidas appearing by name (not just "select styles") give the deals section specificity that "select clearance" never had.
- **Rewards block surfaces a real incentive.** The 20% back on qualifying purchases near the bottom is a meaningful hook, and the Scorecard Rewards section reinforces brand loyalty rather than pure transaction urgency.
- **No render bugs visible.** Layout holds, images load, text doesn't overlap.
- **Hero hierarchy is clean.** Eye goes 50% OFF → category tiles → rewards, without visual noise.

## What's weak

- **50% after 70% is a perceived demotion.** The last three sends peaked at 70% off. Dropping to 50% with no explanation will read as "the good sale is over" even if these are entirely different product sets.
- **"They're here!" is all tease, no payoff.** The subject opener promises something arrived — but the body doesn't have a new launch, a new season, or a new collection. It's the same categories, same deals format. The tease collapses on arrival.
- **No urgency mechanism.** Yesterday had a countdown timer. Today has "this week's deals" — a seven-day window that creates no pull. Nothing in the email tells the subscriber why today is the right day to click.
- **Most individual offers are 40%, not 50%.** The hero promises 50% but the section headers show 40%. "Up to" covers it legally, but the experience is mild bait-and-switch for the reader's attention.
- **Cadence fatigue is compounding.** This is the sixth promotional email since July 4. Even a well-executed send gets tuned out at this frequency.

## Recommendations

- 1. **Lead with what's new, not what's cheaper.** The "This Week's Deals" format works best when it feels like an editorial — "here's what dropped this week." Pick one hero product (a specific HOKA colorway, an Adidas set, a camp-ready bike) and lead with that, not a discount headline. Make the email feel like a curated pick, not another clearance notice.
- 2. **Anchor the weekly-deals format with a fixed send day and consistent subject pattern.** "Your Monday deals from DICK'S" builds habit; "They're here! Up to 50% off" sounds like every other promo. The weekly format only earns trust if subscribers know what to expect.
- 3. **Retire the 50% headline when the body is 40%.** Match the headline to the dominant offer in the email. "Up to 40% off this week's picks" is more honest and lands better than a hero that oversells by 10 points.
- 4. **Add one time-bound reason to act.** Even "Offers valid through Sunday" gives the subscriber a reason not to close and forget.
- **Subject Alt A:** `Your DICK'S Weekly: HOKA, Adidas, bikes + more`
- **Subject Alt B:** `40% off this week — running, golf, bikes, outdoor`
- **Preheader Alt A:** `New deals drop every week. This week: HOKA running shoes, Adidas, golf balls + gear.`
- **Preheader Alt B:** `HOKA, Adidas, Casio, bikes — this week's best picks, valid through Sunday.`

### 2. Link & Tracking Issues

The destination URLs are opaque in the redirect token — cannot confirm UTM parameters are appended. If the ESP is not injecting UTMs at click-time, GA4 / attribution will record sessions as direct.

**Open-pixel placement**
```html
<img src='https://app.dickssportinggoods.com/O/v610000019f3c2310159df59ff4bbe5c898/…'
```

### 3. Rendering & Accessibility

**`border-collapse:separate` on the main wrapper table**
```html
<table … style="border-collapse:separate; border-spacing:0; …">
```
`border-collapse:separate` is atypical for email and can introduce 1–2 px gaps between cells in Outlook and older Android Mail. Standard email practice is `border-collapse:collapse`. Appears consistent across all tables in the visible source.

**`border-radius` on the header table without Outlook VML fallback**
```html
style="border-radius:8px 8px 0px 0px; overflow:hidden;"
```
Outlook (all versions using Word rendering engine) will ignore `border-radius` and render square corners. No MSO conditional VML alternative is present for this element. Visual inconsistency in Outlook, not a breakage.

**Truncated `<img>` tag — alt text unverifiable**
```html
<img id="logo" src="https://s7d6.scene7.com/is/image/DSGAEMSites/brand-logo--dks-2?wid=248&hei=…
```
The HTML was truncated before the `alt` attribute. If `alt=""` is omitted or empty on the logo, it fails WCAG 1.1.1 (non-text content). Cannot confirm from supplied source.

**Web font scoped inside `@media screen` only**
```css
@media screen { @font-face { font-family: Archivo; … } }
```
Correct — prevents Outlook from attempting to load the font. No issue.

### 4. Personalization & Merge Tokens

**JSON-LD contains JavaScript-style comments — invalid JSON**
```json
{ // GIF & WEBP images are not supported…
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
`//` comments are not valid JSON. `<script type="application/ld+json">` is parsed as strict JSON by Gmail's structured data engine. This will throw a parse error and suppress all three schema objects (Organization, DiscountOffer, PromotionCard) in Gmail's rich preview.

**`PromotionCard.image` is empty — designer placeholder shipped**
```json
"image": ""
```
The comment `// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!` was never resolved. This means the Gmail promotional grid card will have no image even if the JSON-LD were valid.

**`DiscountOffer` has stale placeholder date and empty fields**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00",
"availabilityEnds": "",
"description": "",
"discountCode": ""
```
`availabilityStarts` is 2020 — clearly a template default never updated. `availabilityEnds` and `description` are empty strings. Even if the JSON parse error is fixed, Gmail would render a discount offer with a 6-year-old start date.
