# This is a big deal! Up to 70% off select clearance
**Score:** 7/10 · **Type:** Email audit · **2026-07-05**
## Executive summary

- This is the second DICK'S email on July 5th leading with "Up to 70% off" clearance — the earlier send today ("Up to 70% off?! Yes! Save on select clearance styles now 😎") already spent that headline. Coming back same-day with "This is a big deal! Up to 70% off select clearance" is creative redundancy, not escalation. A subscriber who opened the morning send has no new reason to open this one.
- The execution itself is clean: the red hero is legible, the 70% OFF typography dominates immediately, and the product grid works well — Nike shoes at 65% off, electronics up to $120 off, Blackstone Grills up to $160 off all give specific anchors to click toward. The layout renders without visible bugs.
- The core problem is message saturation, not creative failure. The same offer, same visual language, same clearance framing, same day. At some point a third email today with "Up to 80% off?!" would be parody — they're already one send past the line.

## What's working

- **Hero is immediately legible** — "UP TO 70% OFF" in bold white on red lands in under a second, no decoding required.
- **Product grid anchors with specific numbers** — "$120 off Electronics," "$160 off Blackstone Grills," "65% off Nike Shoes" give concrete reasons to click, unlike a generic percentage-only hero.
- **Category nav is functional** — Men's / Women's / Kids / Fan Shop / All Sale lets a subscriber jump directly to their department.
- **No visible render bugs** — clean grid, no broken images, no overlapping text.
- **ScoreCard loyalty is surfaced** — member brand reinforcement in the footer, consistent with recent sends.

## What's weak

- **Same-day duplicate offer** — the morning send already burned "Up to 70% off." This one adds nothing new; it reads as a resend, not a follow-up.
- **"This is a big deal!" is self-assessed hype** — the brand tells you it's a big deal instead of showing you. Compare to the July 3 "Stop scrolling! An EXTRA 30% off" which led with the *action* signal.
- **No urgency or deadline visible** — nothing in the hero or CTAs communicates when this expires. The July 4th "Ends. Tonight." send worked precisely because it had a hard stop; this one has none.
- **"SHOP NOW" CTAs are entirely generic** — every product category gets the same button. "Shop Nike Shoes" or "Shop Clearance Electronics" would lift click specificity meaningfully.
- **Persona targeting is absent** — the grid scatters across Nike shoes, women's clothing, electronics, grills, baseball gear. No segmentation signal for this recipient.

## Recommendations

- 1. **Don't send this at all same-day as an identical offer.** If the morning email already ran "Up to 70% off," this send should either introduce a new product category (e.g., "Just added to clearance: electronics"), a new offer tier (e.g., an extra stackable %), or wait until tomorrow. Two emails with the same headline on the same day trains subscribers to ignore the second one.
- 2. **Swap "This is a big deal!" for the dollar anchor.** The subject buries the most compelling numbers — $160 off grills, $120 off electronics — in the body. Lead with a specific dollar amount in the subject.
- 3. **Add an expiry signal.** Even "Ends Sunday" or "While supplies last — clearance goes fast" creates urgency the current email completely lacks. The July 4th "Ends. Tonight." send demonstrated this works.
- 4. **Specificity on CTAs** — replace all "SHOP NOW" instances with category-matched copy: "Shop Nike Clearance," "Shop Electronics Deals," "Shop Grills."
- **Subject Alt A:** `$160 off grills. $120 off electronics. Up to 70% clearance.`
- **Subject Alt B:** `Nike, electronics, grills — clearance ends soon`
- **Preheader Alt A:** `New categories just added — shop before sizes run out.`
- **Preheader Alt B:** `Summer clearance: the biggest discounts of the season, while they last.`

### 3. Rendering & Accessibility

**MSO CSS syntax error — confirmed.** In the `<!--[if (gte mso 9)|(IE)]>` conditional block, the `div` rule has a stray double-quote before the closing brace:

```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```

The trailing `"` before `}` is invalid CSS. Outlook's HTML renderer may reject or partially apply the entire rule, potentially breaking `div` layout in MSO clients.

**`<link rel="icon">` is dead code.** Favicon links are browser-only and are ignored or stripped by all major email clients (Gmail, Outlook, Apple Mail). Not harmful, but adds noise to `<head>`.

**Alt text — cannot confirm** from truncated source. The logo `<img id="logo">` has no visible `alt` attribute in the excerpt. Verify alt text is present on all images for screen readers and image-blocked clients.

### 4. Personalization & Merge Tokens

**JSON-LD block has three defects**, all in `<script type="application/ld+json">`:

**a) JavaScript-style comments in JSON — invalid syntax.**
```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": "" }
```
JSON does not support `//` comments. This is a parse error — Gmail's structured data parser will reject the entire block, disabling the Promotions tab card entirely.

**b) Stale `availabilityStarts` date.**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
Date is 6 years old — clearly a template default that was never replaced. `availabilityEnds` is also empty (`""`).

**c) `PromotionCard.image` is empty.**
```json
"image": ""
```
Even if the JSON parse error were fixed, an empty image URL means no card image renders in the Gmail Promotions tab.
