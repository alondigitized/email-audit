# Extra 25% off select clearance is happening NOW! Don't miss out...
**Score:** 8/10 · **Type:** Email audit · **2026-05-30**
## Executive summary

- This is the "DICK'S | Clearance" sub-brand again, and it's the eighth send from DICK'S in roughly four days. The creative is competent — clean red hero, tight hierarchy, multiple product lanes — but the brand is deep into subscriber fatigue territory. After May 29's "50% off clearance" blast and May 30's "Flash Sale Up to 50% Off" send (already audited today at 7/10), a third same-day email from the same brand is a deliverability and trust problem more than a creative problem.
- The one genuinely differentiated hook here is "Extra 25% off" — implying a stacked discount on top of already-marked-down clearance prices. That's a real value signal, not just another "Up to 50% Off" headline. But the email undercuts itself immediately: a "Flash Sale: Up to 50% Off" module appears about two sections down, which reads as the same deal repackaged. A subscriber who noticed both sends today will feel bait-and-switched or just confused.
- The multi-lane product structure (athletic wear, baseball bats, golf sets, outdoor gear) is functionally fine but diffuses any one category from owning the scroll. The bottom "Must-have gear for an epic summer?" grid is the strongest product section and it's buried below the fold.

## What's working

- **"Extra 25% off" is a meaningfully differentiated frame** — stacking on clearance implies a real incremental deal, not just repackaging the same % headline.
- **Red hero lands with force** — large type, high contrast, visual hierarchy is immediate and unambiguous.
- **No render bugs** — images load, text doesn't overlap, layout holds clean.
- **Category tabs ("MEN / WOMEN / KIDS / ALL SALE") appear early** — gives navigation purpose before the scroll.
- **"This Week's Deals" product grid at the bottom** carries real product thumbnails with legible pricing context.

## What's weak

- **"Flash Sale: Up to 50% Off" module directly below the hero contradicts the hero** — is the deal Extra 25% off clearance, or 50% off flash sale? Both in one email creates confusion.
- **Subject has two clichés stacked end-to-end** — "is happening NOW!" and "Don't miss out..." are the two most overused urgency phrases in retail email, and together they read as desperate.
- **Cadence is now a material problem** — this is the third DICK'S send today (or close to it) and eighth in four days; the open will suffer regardless of creative quality.
- **No specific deadline visible** — "happening NOW" without an end time/date makes the urgency feel manufactured.
- **CTA copy is all "SHOP NOW"** — every section uses the same button label; no section-specific language to differentiate the categories.

## Recommendations

- 1. **Make the stacked-discount math explicit in the subject** — "Extra 25% off" means nothing until you say what it stacks on. "Extra 25% off already-reduced clearance" is cleaner and more compelling than the current construction.
- 2. **Cut the "Flash Sale: Up to 50% Off" module** from this send — it's in the Flash Sale email already. Including both in the clearance email kills the lead message.
- 3. **Add a deadline.** "Extra 25% ends tonight at midnight" is worth 10× more than "is happening NOW!"
- 4. **Swap generic CTAs for category-specific copy** — "Shop Nike Training," "Shop Baseball Bats," "Shop Golf Sets" turns SHOP NOW into intent signals.
- 5. **Drop this to a single send today** — the Flash Sale email and this one should not coexist in the inbox on the same day. Pick one.
- **Subject Alt A:** `Extra 25% off clearance — stacks on already-reduced prices`
- **Subject Alt B:** `Your clearance just got cheaper: extra 25% off ends tonight`
- **Preheader Alt A:** `Nike, golf, outdoor and more — clearance prices drop again today.`
- **Preheader Alt B:** `Already marked down. Now an extra 25% off. Today only.`

## Technical Audit — DICK'S Sporting Goods Clearance Email

---

### 1. Technical Summary

ESP is Epsilon/Harmony; all tracking routes through `app.dickssportinggoods.com`. The email contains critical JSON-LD parse errors and multiple unfilled template placeholders that will silently fail structured data rendering in Gmail's Promotions tab.

---

### 2. Link & Tracking Issues

**Click-tracking redirect chain is opaque** — all CTA hrefs are Epsilon redirect URLs (`app.dickssportinggoods.com/T/v610...`). Final destination URLs and any UTM injection cannot be verified from source alone; requires redirect-chain inspection.

**Tracking pixel present** — `id="ssl"` cell contains a 0×0 pixel at `https://app.dickssportinggoods.com/O/v610000019e7a9119c9c1ac3e369ff0aab4/89f535fbed464eff00004c5a42963aa1`. Missing `alt=""` attribute (see §3).

**Logo image URL truncated in source** — `https://dsg.images.harmony.epsilon.com/_phoenix/_dev/AEM/img/headers/brand-logo--dk…` — likely an excerpt artifact, but should be confirmed; a broken `src` serves a broken image to all clients.

---

### 3. Rendering & Accessibility

**Tracking pixel missing `alt` attribute** — `<img src='https://app.dickssportinggoods.com/O/...' style="display:none; max-height: 0px; ..."/>` has no `alt=""`. Screen readers and strict parsers flag this.

**Outer table `width` attribute conflicts with inline CSS** — `<table class="wrapper" width="600" ... style="width:100%; max-width:600px">`. The HTML attribute `width="600"` overrides `width:100%` in Outlook/mso path even though CSS wins elsewhere; can cause fixed-width rendering at 600px on some legacy clients instead of fluid layout.

**MSO conditional IE guard is dead code** — `<!--[if (gte mso)|(IE)]>` includes the IE branch. IE is fully EOL; this adds bytes with no benefit.

**`border-collapse:separate` + `border-spacing:0`** — unusual combination on the outer wrapper. Functionally equivalent to `collapse` here but can produce 1px gaps in some rendering engines on certain `border-radius` scenarios.

---

### 4. Personalization & Merge Tokens

**`<script type="application/ld+json">` contains invalid JSON — CRITICAL**

The block includes JavaScript single-line comments (`//`), which are not valid JSON. All compliant JSON parsers (including Gmail's structured data processor) will reject the entire block:

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

**Consequence:** Gmail Promotions tab annotation (deal badge, promo card image) will not render.

**Stale `availabilityStarts` date** — `DiscountOffer.availabilityStarts` is hardcoded as `"2020-03-06T06:00:00-04:00"`. This is six years stale and should be a dynamic merge token tied to send date.

**Empty required fields in structured data:**

| Field | Value | Impact |
|---|---|---|
| `DiscountOffer.description` | `""` | No deal text in Promotions tab |
| `DiscountOffer.discountCode` | `""` | No promo code surfaced |
| `DiscountOffer.availabilityEnds` | `""` | No expiry shown |
| `PromotionCard.image` | `""` | No card image in Gmail |

These are designer-fill placeholders that shipped unfilled.

### 6. Email-to-Site Continuity

UTM parameters are not visible in raw `href` values — all links are pre-redirect Epsilon tokens. Epsilon is expected to append UTM params post-redirect, but this must be confirmed by resolving a sample redirect chain (e.g., `curl -L -I "https://app.dickssportinggoods.com/T/v610..."`). If UTM injection is not configured in the ESP, attribution will be lost for all clicks from this send.
