# CLEARANCE pricing adds an extra 25% OFF select items
**Score:** 8/10 · **Type:** Email audit · **2026-06-16**
## Executive summary

- This is DICK'S Clearance sub-account doing its job competently but mechanically. The hero is bold — "EXTRA 25% OFF" on a dark red field lands immediately, and the clearance hook is one of the more honest, friction-free offers in recent DICK'S sends. Unlike the Flash Sale account's repeated same-day blasts (June 13–15), this arrives from a distinct sub-account with its own cadence, which buys it marginally more goodwill.
- The problem is density without focus. Below the hero, the email dissolves into a six-plus module grid covering shoes, beauty/wellness, outdoor furniture, pool gear, and Father's Day gifts with no connective thread. The ScoreCard $10 cross-sell — the same loyalty promotion from the June 15 ScoreCard send — appears again here, making the inbox feel redundant even across sub-accounts.
- The email does the clearance job. It doesn't do anything memorable with it.

## What's working

- Hero offer is unmistakable — "EXTRA 25% OFF" in large white text on dark red is the first thing the eye hits, no hunting required.
- Sending from "DICK'S | Clearance" is smart sub-account hygiene; it separates cadence from the Flash Sale bombardment running the same week.
- Brand logo row (adidas, VRST, and others) gives instant category signals for brand-loyal shoppers.
- Father's Day tie-in is present and calendar-appropriate for the June 16 send date.
- No visible render bugs — images are small but clean, no overlapping text or broken layouts.

## What's weak

- No urgency signal anywhere visible — no "ends Sunday," no countdown, no "while supplies last" callout; clearance without a deadline is just a permanent price.
- The ScoreCard $10 Bonus Reward cross-sell is a direct repeat of the June 15 loyalty send — same offer, same framing, accumulating subscriber fatigue across sub-accounts.
- Six-plus product modules with no hierarchy beyond the hero — shoes, wellness, outdoor, pool gear, Father's Day all compete equally, diluting click intent.
- Subject line runs 52 characters with "CLEARANCE" in all-caps at the front — slightly punishing on mobile and slightly shouting.
- CTA copy throughout appears to be generic "Shop Now" variants — no specific verb+noun pairings to drive category-specific clicks.

## Recommendations

- 1. **Add a visible deadline to the hero.** "Extra 25% Off — ends Sunday" would immediately lift urgency without any redesign. This is the single highest-ROI change available.
- 2. **Pick one Father's Day hero product** and lead the second module with it rather than burying the holiday angle mid-scroll. Father's Day is the only credible time peg in this email; use it.
- 3. **Retire the ScoreCard cross-sell** for this send cycle. It ran on June 15. Running it again on June 16 in a different sub-account trains subscribers to ignore it.
- 4. **Rewrite subject to lead with the percentage, not the category.** "Extra 25% off clearance" front-loads the value; "CLEARANCE pricing adds an extra 25% OFF" buries the number.
- 5. **Preheader should name a category**, not echo the hero. "Father's Day gifts, shoes, outdoor gear — all in clearance" would add information the subject doesn't carry.
- **Subject Alt A:** `Extra 25% off clearance — ends Sunday`
- **Subject Alt B:** `Your clearance extra 25% kicks in now`
- **Preheader Alt A:** `Shoes, outdoor gear, Father's Day gifts — all marked down further`
- **Preheader Alt B:** `Clearance prices just got lower — shop before it's gone`

**Web font loading** — `@font-face` loads Archivo from `fonts.gstatic.com`. This works in Gmail/Apple Mail but is blocked in Outlook desktop; fallback to Arial is correctly specified.

**Redundant CSS declaration** — `body { font-family: Archivo,Arial,sans-serif; font-family: Archivo,Arial,sans-serif!important }` declares the same property twice. The `!important` copy is sufficient; the first line is dead weight but causes no rendering defect.

---

### 4. Personalization & Merge Tokens

**JSON-LD block is malformed** — the `<script type="application/ld+json">` block contains JavaScript single-line comments (`//`), which are invalid JSON:

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

JSON does not allow `//` comments. Any JSON-LD parser (Gmail, Google Search) will reject the entire block. **This silently disables all Gmail Promotions tab annotations.**

**Unpopulated merge fields in JSON-LD** — even if the syntax were fixed, these fields are empty:

| Field | Value | Impact |
|---|---|---|
| `DiscountOffer.description` | `""` | No annotation text |
| `DiscountOffer.discountCode` | `""` | No promo code shown |
| `DiscountOffer.availabilityEnds` | `""` | No expiry shown |
| `PromotionCard.image` | `""` | No promotional image in Gmail tab |

**Stale hardcoded date** — `"availabilityStarts": "2020-03-06T06:00:00-04:00"` is a 2020 template default that was never updated. Gmail may suppress the annotation or display an expired offer signal.

---

### 5. Compliance

**From / sending domain** — `DSG@e.dcsg.com` (subdomain sender). Authentication headers (SPF, DKIM, DMARC) are not visible in the HTML source; they must be verified in the raw message headers. Epsilon-managed sending infrastructure typically handles these, but spot-check is warranted.

**CAN-SPAM / unsubscribe** — Footer is not included in the truncated source provided. Cannot confirm presence of:
- Physical mailing address
- Unsubscribe link / one-click unsubscribe (`List-Unsubscribe` header)

These are required for CAN-SPAM compliance and Gmail/Yahoo sender requirements (2024). **Audit requires the full HTML.**

---

### 6. Email-to-Site Continuity

All clicks pass through the Epsilon redirect (`/T/…`), making it impossible to confirm UTM parameters from the HTML source alone. The redirect layer should be appending campaign-level UTMs before forwarding to `dickssportinggoods.com`. Verify by decoding one redirect URL and confirming `utm_source=email&utm_medium=email&utm_campaign=…` (or equivalent) is present on the landing page.

The clearance offer in subject (`extra 25% OFF select items`) should map to a clearance landing page, not a generic homepage — this cannot be confirmed from the truncated source.
