# ⚽ Must‑haves for the big soccer stage ⚽
**Score:** 8/10 · **Type:** Email audit · **2026-06-11**
## Executive summary

- This is DICK'S most focused soccer email of the week, and probably the most coherent creative they've deployed in this World Cup window. "THE STAGE IS SET" is a strong, timely hero — the national-kit imagery (Mexico green, USA white, other federation colorways) is specific and telegraphs exactly what you're buying. The brand-tiered module structure (Nike → adidas → PUMA each get a dedicated section) turns what could be a chaotic grid into a browsable editorial. The "Order by 6/22 for Father's Day" deadline in the banner pulls double duty: it catches both the soccer fan and the last-minute gift buyer.
- The glaring miss is price. DICK'S has spent the past two weeks conditioning their subscriber base with 40–60% off headlines — the June 9 "Where It All Kicks Off" adidas co-brand (5/10) and the June 11 Father's Day Savings Event (9/10) are both recent comp. This email offers zero discount signal in the hero or any module. A subscriber accustomed to that cadence will bounce faster than the editorial quality warrants.
- The bottom "Check out these picks" product grid is tiny and undersized — it reads like leftover real estate rather than a merchandising moment. Cut or significantly expand it.

## What's working

- **"THE STAGE IS SET" hero** is visually dominant, FIFA-timely, and a clean break from the clearance-compilation format DICK'S has been running since late May.
- **Brand-tiered modules** (Nike / adidas / PUMA in sequence) give the email genuine editorial structure — each section is self-contained and browsable.
- **"Order by 6/22 for Father's Day"** in the top banner creates dual urgency without feeling forced — soccer fan and gift buyer audiences each get a hook.
- **FIFA ticket cross-sell** ("Select 2025 FIFA World Cup Game Tickets!") is a smart aspirational interrupt — it adds energy without diluting the product focus.
- **Clean mobile render** — no broken images, clear section breaks, readable hierarchy throughout.

## What's weak

- **No price anywhere in the hero or modules** — after two weeks of 40–60% off headlines from this sender, this reads as a full-price ask with zero persuasive anchor.
- **Every CTA reads "SHOP NOW"** — six modules, six identical button labels. At minimum the FIFA ticket module should say "Find Tickets" (it does, actually — the product modules should follow suit).
- **"Gear Up for USA's First Match" module headline is dateless** — when is the first match? The urgency argument dies without a date.
- **Bottom "Check out these picks" grid** is visually undersized and low-contrast — it adds noise without adding conversion surface.
- **No ScoreCard / loyalty pricing visible** — DICK'S has one of the better loyalty programs in sporting goods retail; none of it shows up here.

## Recommendations

- 1. **Add a price anchor to the hero** — even "Shop All Soccer | Select Styles Up to 30% Off" under the hero CTA would stop the trained discount-scanner from bouncing immediately.
- 2. **Date-stamp USA's first match in the module headline** — "Gear Up for USA's First Match — June 15" converts "maybe later" into "I need to order now."
- 3. **Vary CTA button copy by section** — "Shop Nike Jerseys," "Shop adidas Kits," "Find FIFA Tickets" each earn more clicks than six identical "SHOP NOW" labels.
- 4. **Promote the FIFA ticket cross-sell higher** — it's a genuine differentiator vs. every other sports retailer; bury it less.
- 5. **Cut or replace the bottom product grid** — if it isn't linked to soccer, it fragments the message. If it is soccer product, show it bigger.
- **Subject Alt A:** `⚽ Gear up before USA's first kick — June 15`
- **Subject Alt B:** `National jerseys for every federation — shop now`
- **Preheader Alt A:** `Nike, adidas & PUMA federation kits — order by 6/22 for Father's Day delivery`
- **Preheader Alt B:** `USA, Mexico, and more — plus FIFA tickets. Order by June 22.`

### 1. Technical Summary

The email is built on Epsilon/Harmony infrastructure with standard MSO conditionals and responsive breakpoints. Three confirmed code-level defects exist: invalid JSON-LD that will silently break Gmail Annotations, a CSS syntax error in the Outlook conditional block, and stale template placeholder data left in the structured-data payload.

---

### 2. Link & Tracking Issues

**No broken links confirmed** from the visible source. All CTAs route through Epsilon's redirect layer at `app.dickssportinggoods.com/T/v610000019eb84de...` with `__dU__` user-token parameters — expected for this ESP.

**UTM passthrough unverifiable** from the truncated source. The `__dU__` token encodes destination, but the decoded landing URL is not exposed in this excerpt. Confirm downstream UTM params (`utm_source`, `utm_medium`, `utm_campaign`) survive the redirect in QA; Epsilon sometimes strips or overwrites them depending on template config.

**Tracking pixel placement** — the open-tracking image is correctly hidden:
```html
<img src='https://app.dickssportinggoods.com/O/v610000019eb84de...' 
     style="display:none; max-height: 0px; overflow: hidden; mso-hide: all"/>
```
Missing `alt=""` attribute (see §3).

---

### 3. Rendering & Accessibility

**MSO conditional CSS has a stray double-quote** — causes a parse error in Outlook's CSS engine:

```css
/* BROKEN — note the " before } */
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
Should be `padding:0;}`. This may cause Outlook to ignore the entire rule block for `div` elements.

**Duplicate `font-family` declaration on `body`:**
```css
body{font-family:Archivo,Arial,sans-serif;font-family:Archivo,Arial,sans-serif!important}
```
The second declaration is redundant. Not a rendering bug in practice, but indicates copy-paste residue in the template base.

**Missing `alt=""` on tracking pixel** — screen readers will attempt to read the src URL aloud. Add `alt=""` to suppress.

**`<html lang="en">` present** — no issues. All `<table>` elements carry `role="presentation"` — correct.

---

### 4. Personalization & Merge Tokens

No unresolved merge tokens (e.g., `%%FIRSTNAME%%`, `{{name}}`) visible in the provided source excerpt — good.

**Stale template data in JSON-LD DiscountOffer:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 6-year-old date — clearly an unfilled template default, not this send's actual promotion window. Gmail Annotations parses this block; a past `availabilityStarts` with an empty `availabilityEnds` may cause the offer to be treated as expired.

### 5. Compliance

**Sending domain** `e.dcsg.com` is a subdomain of `dcsg.com` (DICK'S corporate). SPF/DKIM/DMARC alignment depends on Epsilon's configuration for this subdomain. No authentication headers are visible in the provided source (headers not included in excerpt) — verify via `Authentication-Results` header in a received copy.
