# Up to 50% off deals🚨 Don't miss these finds for you...
**Score:** 7/10 · **Type:** Email audit · **2026-05-11**
## Executive summary

- This is a classic DICK'S Sporting Goods weekly promotional blast — high production value, strong hero, but aggressively broad. The "UP TO 50% OFF" hero does its job: it's the first thing the eye lands on, and the "SHOP NOW" CTA is unambiguous. The email stacks six or seven distinct product stories — shoes, women's apparel (CALIA/VRST), YETI drinkware, golf (TaylorMade 3X points), kayaks, and a clearance push — with its own CTA button for each. That's a lot of competing asks.
- The clearance section buried mid-to-lower gets a green "EXTRA 25% OFF" banner which almost functions as a second hero, creating confusion about what the actual lead offer is. The loyalty angle (3X ScoreCard points on TaylorMade) is buried and niche — whoever cares about it will likely miss it.
- Bottom line: this is a competent, high-frequency retail send. It's efficient as a weekly deal digest but does no meaningful targeting work. You get what you pay for when every segment gets the same email.

## What's working

- **Hero is unambiguous.** "UP TO 50% OFF" over a dark arena image grabs attention immediately; "SHOP NOW" is right there.
- **Seasonal relevance.** YETI "Summer Anthem and Seafoam" and the summer clearance push tie cleanly to the send date.
- **75% off clothing call-out is genuinely aggressive.** CALIA/VRST/Under Armour at up to 75% is a strong offer that stands out among the sections.
- **No obvious render bugs.** Layout renders cleanly — no broken images, overlapping text, or blank sections visible.
- **ScoreCard loyalty integration.** The 3X points section acknowledges the loyalty program, which rewards the subscriber base.

## What's weak

- **Too many heroes.** Six standalone sections each with their own "SHOP NOW" button dilute focus and fatigue the reader before they reach the best offer (75% off apparel).
- **Subject line is long and emoji-noisy.** "Up to 50% off deals🚨 Don't miss these finds for you..." runs over 50 characters, and the 🚨 reads like an alarm bell rather than a premium brand signal.
- **Zero personalization.** "Finds for you" in the subject is boilerplate — there's nothing in the send that indicates DICK'S knows anything about this recipient's purchase history or sport preference.
- **3X Points is buried and context-free.** The ScoreCard promotion appears mid-scroll with no explainer for non-members; loyal members who golf would care, but it's easy to scroll past.
- **Clearance competes with the hero.** The "EXTRA 25% OFF" green banner lower in the email creates a second visual anchor that undercuts the 50% off message established at the top.

## Recommendations

- 1. **Pick one lead offer and own it.** Drop the hero discount to a specific category ("Up to 75% Off CALIA & Under Armour") rather than a vague "up to 50% off everything." The 75% apparel offer is actually stronger than the hero presents.
- 2. **Trim the subject to under 50 characters and kill the 🚨.** A cleaner signal converts better.
- **Subject Alt A:** `Your 75% off window is open — CALIA, UA & more`
- **Subject Alt B:** `Up to 75% off sportswear + YETI's summer colors`
- **Preheader Alt A:** `CALIA, VRST, Under Armour, DSG — this week only at Dick's.`
- **Preheader Alt B:** `YETI's summer palette is here. Plus: kayaks, shoes, clearance.`
- 3. **Move the clearance section to the bottom.** Keep "EXTRA 25% OFF" as a tail offer, not a visual interrupt mid-email.
- 4. **Give the 3X points CTA its own context sentence.** "ScoreCard members: golf gear earns triple points this week" is scannable and actionable. What's there now is just a badge.
- 5. **Consolidate CTAs.** Reduce to 2-3 "SHOP NOW" buttons: one for apparel, one for YETI/gear, one for clearance. Fewer clicks = clearer intent signal.

### 1. Technical Summary

The email is structurally sound (correct MSO conditionals, responsive CSS, `role="presentation"` on layout tables), but the JSON-LD structured data block contains invalid syntax and multiple unfilled template placeholders that will cause Gmail's promotion tab parsing to fail silently. The preheader text is also misaligned with the subject line, indicating a likely content-swap error.

---

### 2. Link & Tracking Issues

**Open-tracking pixel** — Present and correctly suppressed:
```html
<img src='https://app.dickssportinggoods.com/O/v610000019e1685b7f1959a0bf4bbe5be50/...'
     style="display:none; max-height: 0px; font-size: 0px; overflow: hidden; mso-hide: all"/>
```
No issue with implementation.

**CTA links** — All route through `https://app.dickssportinggoods.com/T/v610000019e1685b7f1959a0bf4bbe5be50/...` proprietary redirect chains. This is functional but means UTM parameter presence on destination URLs **cannot be confirmed** from source alone (see §6).

**Source truncation** — HTML is cut before the full link list. A complete link audit requires the full source.

### 3. Rendering & Accessibility

**Duplicate `font-family` declaration** — `<style>` block sets `body { font-family: Archivo,Arial,sans-serif }` twice: once normally, once with `!important`. Redundant; the second declaration overrides the first. Low severity, but indicates a copy-paste artifact in the template.

**Logo `alt` attribute** — `<img id="logo">` `src` is truncated in the provided source; `alt` text cannot be confirmed. If absent, screen readers will announce the raw filename or skip it entirely.

**`role="presentation"`** — Correctly applied to all layout tables. No issue.

**`lang="en"`** — Set on `<html>`. No issue.

**MSO conditional comments** — Present and correctly structured for Outlook rendering. No issue.

### 4. Personalization & Merge Tokens

These blank fields will prevent Gmail's Promotions tab from rendering the annotated offer card. The feature is wired up but non-functional as sent.

**Stale `availabilityStarts` date:**


This is a 6-year-old date — clearly a template default that was never updated for this send. Combined with the empty `availabilityEnds`, the offer window is invalid.

The preheader sits in `<td id="ssl">` and renders as preview text in inbox clients. These two messages are thematically incongruent — this pattern is consistent with a preheader block that was not updated when the main template content was swapped.

### 5. Compliance

**CAN-SPAM physical address and unsubscribe link** — The HTML source is truncated before the footer. Cannot confirm presence. Full source required to verify.

**Sending domain** — `From: DSG@e.dcsg.com` uses an ESP subdomain. DKIM/SPF/DMARC alignment cannot be assessed from HTML alone; requires inspection of the actual message headers (e.g., `Authentication-Results`, `DKIM-Signature`).

**JSON-LD contains invalid syntax** — JavaScript-style single-line comments (`//`) are not valid JSON per RFC 8259:

```javascript
{ // GIF & WEBP images are not supported...
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

This will cause JSON parsers to reject the entire `<script type="application/ld+json">` block, making all three structured data objects inert.

---

### 6. Email-to-Site Continuity

All links use the `/T/` redirect chain; final destination URLs are not visible in source. It is **not possible to confirm** whether UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) are appended on redirect resolution. This must be verified by following a representative link and inspecting the landing page URL.

The subject line ("up to 50% off") and preheader ("YETI Summer Anthem colors are here") signal two different campaign angles. If these map to the same landing page, one message will be unsupported. If they map to different landing pages, the single-template approach may be wrong.
