# Up to 50% OFF is here — check this week's DEALS we selected for you
**Score:** 9/10 · **Type:** Email audit · **2026-07-24**
## Executive summary

- This is DICK'S Sporting Goods' twelfth-or-so promotional blast in roughly a week — and it reads like it. The hero leads with the now-familiar "Up to 50% OFF" over a beach lifestyle image, the CALIA/VRST/DSG clearance block reappears (same as the July 24 clearance send and the July 21 clearance send before it), and the subject line's "we selected for you" personalization claim sits completely unearned against an obviously mass-blast product grid.
- What separates this one slightly from the prior week's stack is a named product hero: On Cloud X4 Training Shoes at 50% off for Men's and Women's. That's a premium brand, a specific model, and a real deal. If you're in the market for On Cloud shoes, this email works. If you're not, everything else collapses back into the same rotating DICK'S clearance blur.
- The execution is clean — no render bugs, clear CTAs, summer lifestyle imagery that fits the season. But subscribers who've received all twelve of these sends are operating on fumes of attention. The "selected for you" subject framing is the right instinct; the email body doesn't deliver on it at all.

## What's working

- **On Cloud X4 hero deal** — naming a specific $100+ shoe brand at 50% off is the first product-level hook this week's DICK'S sends have managed.
- **No render bugs** — images load, layout holds, CTA buttons are visible and clearly labeled.
- **Category navigation bar** — Men's / Women's / Kids / Shoes / Golf / The Summer Shop gives subscribers a quick escape hatch if the hero isn't for them.
- **Visual hierarchy** — the eye hits "UP TO 50% OFF" on the hero immediately; the section-by-section scroll cadence is readable on mobile.

## What's weak

- **"Selected for you" is a lie the body can't keep** — the product grid below the hero is a standard mass-blast assortment (golf driver, treadmill, tumbler, T-shirt, camp chair); there is zero evidence of personalization.
- **CALIA/VRST/DSG/Alpine 70% off block is repeat clearance** — this exact sub-block has appeared in at least three emails this week; it lands with zero surprise.
- **Subject is 67 characters — too long for mobile** — truncates before "we selected for you" on most clients, which is the only differentiating phrase in the subject.
- **No deadline anywhere in the email** — "this week's deals" is too vague to create urgency; prior sends at least used "ends tonight" or countdown timers.
- **Product grid is category-chaotic** — golf club, treadmill, and camp chair share the same "top deals" row; no persona cohesion.

## Recommendations

- 1. **Add a real deadline** — even "Deals valid through Sunday" tightens the offer and distinguishes this from a permanent sale page. The July 22 "ends tomorrow" send outperformed for exactly this reason.
- 2. **Let the On Cloud deal own the subject line** — the shoe deal is the only genuine hook; bury it below "50% OFF" generic language and you've wasted it.
- 3. **Cut or hide the CALIA/VRST clearance block** — subscribers who wanted it already bought it from three prior sends. Replacing it with a second specific product deal would materially lift click-through.
- 4. **Commit to the "selected for you" premise** — even a simple "Since you've browsed running shoes…" intro copy would make the personalization claim credible.
- 5. **Trim the product grid to one category** — or at minimum, segment it ("If you golf" / "If you train") so each section feels targeted instead of random.

- **Subject Alt B:** `Your pick: On Cloud, Nike, gear deals — up to 50% off`
- **Preheader Alt A:** `Men's and Women's On Cloud X4 at half price — plus clearance up to 70% off.`
- **Preheader Alt B:** `This week's best price drop: On Cloud X4 Training Shoes, 50% off.`

## Technical Audit

## Technical Audit — DICK'S Sporting Goods Email

---

### 1. Technical Summary

The email has a well-structured responsive HTML skeleton with proper MSO conditionals and `role="presentation"` on tables, but the JSON-LD structured data block contains invalid JSON that will silently fail in Gmail's annotation engine, and a PromotionCard template was shipped with an empty `image` field and designer comments still intact.

---

### 2. Link & Tracking Issues

**No broken links detected** from visible anchors in the truncated source. All links route through the ESP redirect domain `app.dickssportinggoods.com/T/...`.

**Open-tracking pixel** is present at:
```
https://app.dickssportinggoods.com/O/v610000019f95d380cb93a16df4bbe5be50/5dc3da2417ee429000004c5a42963aa1
```
Hidden correctly via `display:none; max-height:0px; mso-hide:all`. No issue.

**Redirect token** `v610000019f95d380cb93a16df4bbe5be50` appears in both the open-pixel URL and all tracked links — confirms subscriber-level tracking is wired.

---

### 3. Rendering & Accessibility

**JSON-LD block contains JavaScript-style comments — invalid JSON.** The `<script type="application/ld+json">` block has three `//` line comments:

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@context": "http://schema.org/",
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

`JSON.parse()` will throw on any `//` token. Gmail's annotation parser will reject the entire `ld+json` block, meaning no Gmail Promotions tab annotations will render for any recipient.

**`PromotionCard` is not a schema.org type.** The valid Gmail Promotions annotation types are `DiscountOffer` and `SiteLinksSearchBox`. `PromotionCard` is unrecognized and would be ignored even if the JSON were valid.

**Font loading via external `fonts.gstatic.com`** — scoped inside `@media screen` which is correct; clients that block remote CSS (e.g., older Outlook) fall back to `Arial, sans-serif` as expected.

**`alt` text** cannot be fully audited from the truncated source, but the logo `<img id="logo">` src is cut off before an `alt` attribute is visible — needs verification against full source.

---

### 4. Personalization & Merge Tokens

Subject line asserts "we selected for you," implying behavioral or segment personalization, but no merge tokens (`{{`, `%%`, `[%`, etc.) are visible in the truncated HTML body.

**Stale structured data dates** in `DiscountOffer`:
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00",
"availabilityEnds": ""
```
`availabilityStarts` is over 6 years in the past. `availabilityEnds` is an empty string. Even if the JSON were valid, Gmail would likely suppress a promotion with a start date of 2020 and no end date.

---

### 5. Compliance

**Cannot audit from truncated source:** the unsubscribe link, physical mailing address (CAN-SPAM §5(a)(5)), and List-Unsubscribe header are not present in the provided excerpt. These must be verified in the full source and raw message headers.

**Sending domain:** `DSG@e.dcsg.com` — `e.dcsg.com` is the ESP subdomain. SPF/DKIM/DMARC alignment requires verification at the header level, not available from HTML alone.

---

### 6. Email-to-Site Continuity

All CTAs route through `app.dickssportinggoods.com/T/...` redirect URLs. UTM parameter passthrough cannot be confirmed without resolving the redirect chain — the encoded destination URL is not visible in the raw link.

**Risk:** If UTM params are appended by the ESP at redirect time rather than baked into destination URLs, any redirect failure (DNS, 5xx on the redirect service) will land users on the destination with no campaign attribution.

---

### 7. Recommendations

| Priority | Issue | Fix |
|---|---|---|
| **Critical** | `//` comments in `ld+json` block — invalid JSON, all Gmail annotations silently fail | Strip all `//` comment lines before send |
| **Critical** | `PromotionCard` is not a valid Gmail annotation type | Replace with `DiscountOffer` or remove the block entirely |
| **Critical** | `"image": ""` — empty PromotionCard image with unfilled designer comment shipped to production | Populate or remove the field; add a preflight check for empty required fields |
| **High** | `availabilityStarts: "2020-03-06"` is 6 years stale; `availabilityEnds` is empty | Set to current campaign window dates |
| **Medium** | UTM passthrough not verifiable from source | Resolve one tracked link and confirm `utm_source`, `utm_medium`, `utm_campaign` appear on landing page |
| **Verify** | `alt` text on logo and product images — cut off in truncated source | Audit full HTML; all `<img>` must have non-empty `alt` |
| **Verify** | Unsubscribe link, physical address, List-Unsubscribe header — not in excerpt | Confirm presence in footer and raw message headers |
