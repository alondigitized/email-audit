# SUMMER CLEARANCE EVENT is here: Up to 70% off!
**Score:** 7/10 · **Type:** Email audit · **2026-07-18**
## Executive summary

- This is DICK'S fifth 70%-off Summer Clearance email in five days, and the creative is indistinguishable from the July 16 "Limited time! 💸 Up to 70% off select clearance" send that scored 8/10 here. Same dark hero, same oversized gold "70% OFF" badge, same category browse rail, same tiered product sections by sport (court shoes, golf gear, DSG sets), same ScoreCard loyalty block at the bottom. At some point "Summer Clearance EVENT" stops reading as an event and starts reading as wallpaper.
- The email itself is competent. Visual hierarchy is clean: the hero dominates, the offer is readable from arm's length, and the sub-offers — 30% off court and training shoes, specific dollar prices on golf gear — add useful specificity beneath the fold. The ScoreCard earn-back block is a genuine subscriber benefit.
- The problem isn't the execution — it's the fifth time seeing it. A subscriber who opened Tuesday's clearance send has zero new information here.

## What's working

- Dark hero with massive gold "70% OFF" text creates instant visual impact — no ambiguity about the offer.
- Sub-offers (30% off select court and training shoes, specific $14.99-range golf shoes) give category shoppers a concrete hook beyond the umbrella discount.
- ScoreCard loyalty earn-back block mid-email gives members a reason to prefer the in-store or app channel over just clicking to web.
- Layout is clean — no render bugs, images load, buttons are present and labeled.

## What's weak

- Structurally identical to the July 16 dark-hero clearance send — a subscriber who opened that one has no new reason to engage here.
- "SUMMER CLEARANCE EVENT is here" in subject ALL CAPS reads like volume-cranked copy, not an actual event announcement.
- No deadline anywhere in the subject line or hero — "is here" implies permanence, which kills urgency.
- The "up to" qualifier on 70% is doing a lot of heavy lifting with no visible floor price or minimum purchase detail in the hero.

## Recommendations

- 1. **Rotate the creative** — change the hero color, the sport spotlight, or the product story. The July 15 "Fresh Picks" editorial frame (10/10 here) proved DICK'S can break this pattern entirely. Five consecutive dark-hero clearance emails is subscriber fatigue in the making.
- 2. **Put a hard deadline in the hero and subject** — "Ends Sunday" or "72 hours left" converts "is here" from ambient noise into actual urgency.
- 3. **Segment by sport** — instead of a kitchen-sink catalog dump, lead with the one category this subscriber actually shops. 70% off running gear hits harder than 70% off everything.
- 4. **Pull the ScoreCard block up** — move it directly below the primary CTA so the loyalty earn-back reinforces the click decision, rather than fighting golf clubs for attention.

## Technical Audit

## Technical Audit — DICK'S Sporting Goods Summer Clearance Email

---

### 1. Technical Summary

The email is built on Salesforce Marketing Cloud (SFMC) with standard MSO/Outlook conditional comments and a responsive CSS framework. Two significant issues require immediate attention: invalid JSON-LD syntax that will silently break Gmail structured data rendering, and multiple stale/empty template fields that indicate incomplete population before send.

---

### 2. Link & Tracking Issues

**Open-tracking pixel — missing `alt` attribute**
```html
<img src='https://app.dickssportinggoods.com/O/v610000019f74c206959d31e9369fe94bd8/...'
     style="display:none; max-height: 0px; ..."/>
```
The pixel has no `alt=""`. While invisible, some spam filters flag `<img>` tags without alt text.

**Template placeholder comment left in live HTML**
```html
<!--Replace/Paste SSL Here-->
```
This comment appears directly after the open-tracking pixel in the `id="ssl"` cell, indicating a template snippet that was not cleaned up. Exposes internal authoring workflow language to any recipient who views source.

**Click tracking** uses SFMC's `/T/` redirect path — standard, no issue. Redirect chain resolves correctly for the logo link based on the visible portion.

---

### 3. Rendering & Accessibility

**Invalid JSON inside `<script type="application/ld+json">`**
JavaScript-style `//` line comments appear inside the JSON-LD block:
```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@context": "http://schema.org/",
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
JSON does not support `//` comments. Gmail's structured data parser will reject the entire `<script>` block, silently dropping any promotional annotation from the inbox. This is a send-blocking defect if Gmail annotations are intended.

**Google Fonts via `fonts.gstatic.com`**
The `@font-face` declarations reference `/v7/` of Archivo. This is loaded only under `@media screen`, which is appropriate. Fallback to `Arial, sans-serif` is correctly specified. No defect — noted for completeness.

**`<link rel="icon">` in `<head>`**
Most email clients strip or ignore `<link>` tags. No rendering impact, but adds bytes with no benefit in an email context.

---

### 4. Personalization & Merge Tokens

The JSON-LD `DiscountOffer` object contains multiple unpopulated fields:
```json
"description": "",
"discountCode": "",
"availabilityStarts": "2020-03-06T06:00:00-04:00",
"availabilityEnds": ""
```

- `availabilityStarts` is hardcoded to **March 6, 2020** — a 6-year-old stale default from the template. This is the most visible signal that the JSON-LD block was not populated before send.
- `discountCode`, `description`, and `availabilityEnds` are all empty strings.
- The `PromotionCard` `image` field is also an empty string — the inline comment `// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!` was sent verbatim to recipients.

Additionally, `"@type": "DiscountOffer"` and `"@type": "PromotionCard"` are **not valid Schema.org types**, which compounds the structured data failure.

---

### 5. Compliance

**From domain:** `DSG@e.dcsg.com` — `e.dcsg.com` is a dedicated ESP subdomain of `dcsg.com` (Dick's Sporting Goods corporate domain). Consistent with standard SFMC sending infrastructure; no domain spoofing concern.

**Authentication headers (DKIM/SPF/DMARC):** Not derivable from HTML source. Must be verified at the envelope/header layer via a tool such as mail-tester.com or by inspecting received headers.

---

### 6. Email-to-Site Continuity

UTM parameters cannot be fully assessed from the truncated source — only the logo link's SFMC click-tracking URL is visible, and it resolves through `app.dickssportinggoods.com/T/...` before hitting the destination. The destination URL and whether UTM params (`utm_source`, `utm_medium`, `utm_campaign`) are appended post-redirect cannot be confirmed without inspecting the full redirect chain or additional link HTML.

**If UTM params are omitted from redirect destinations**, analytics will attribute clearance event traffic to direct rather than email.
