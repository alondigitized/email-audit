# Up to 50% off is available now with this week's deals
**Score:** 5/10 · **Type:** Email audit · **2026-07-15**
## Executive summary

- This is a direct replay of the July 14 "This week's deals" send — same blue 50%-off hero, same Summer Clearance 70%-off dark section underneath, same category-grid catalog dump below that. The subject even rhymes with yesterday's ("This week's deals are waiting ➡️ see what's up to 50% off"). A real subscriber who opened yesterday's email will feel like they're looking at a duplicate, because they basically are.
- The creative itself is competent catalog work: clean grids, clear percentage callouts across seven categories (clothing, outerwear, golf, team sports, outdoors, fan shop, fitness), and a legible visual hierarchy. The 50% OFF hero punches fine. But stacking two near-identical "This Week's Deals" emails on consecutive days is a cadence mistake that tanks open rates on the second send — it trains subscribers to skip the first one and wait, or to disengage entirely.
- The 70% Summer Clearance module buried mid-scroll is actually the stronger offer here, yet it plays second fiddle to a weaker, recycled 50%-off hero. That's backwards.

## What's working

- **50% OFF hero is instantly readable** — blue field, large white type, no ambiguity on the offer.
- **Category navigation row ("Footwear / Apparel / Outdoors / Fitness…")** gives quick-scanners a way to self-select directly to their category without reading the whole email.
- **Seven distinct discount modules** give the email legitimate breadth — something for almost every sporting goods shopper.
- **70% Summer Clearance section** is a harder number than the hero and has real urgency if you're hunting clearance.
- **No render bugs** — images load, text is legible, layout holds.

## What's weak

- **Déjà vu cadence** — this is functionally the same email as July 14's "This week's deals." Two identical frames in 24 hours is subscriber fatigue in real time.
- **Hero under-delivers vs. the 70% offer buried below** — leading with 50% when 70% clearance is live is a missed hierarchy call.
- **"Available now" is the weakest possible urgency** — no deadline, no countdown, nothing that makes this week feel different from any other week.
- **Zero personalization or segmentation signal** — every category is thrown in, which means no category feels curated for anyone.
- **CTA copy is generic** — no visible button copy beyond "SHOP NOW"-level language across all seven modules.

## Recommendations

- 1. **Lead with 70% OFF, not 50%** — the Summer Clearance number is harder, scarcer-feeling, and differentiates this send from yesterday's. Make it the hero, move 50%-off to a secondary row.
- 2. **Add a real deadline** — "ends Sunday" or "through July 20" turns "available now" into actual urgency and gives subscribers a reason to act today vs. tomorrow.
- 3. **Don't send this email the day after an identical one** — either merge Friday/Saturday sends into one, or make the second send a "last chance" frame with an actual deadline rather than a fresh catalog drop.
- 4. **Pick one anchor category per send** — with seven modules, nothing feels curated. A footwear-led send, a golf-led send, and a team-sports-led send would each feel more targeted and land higher CTR than a catalog dump.
- 5. **Rewrite the subject to lead with the harder number:**
- **Subject Alt A:** `Up to 70% off Summer Clearance — shop this week's deals`
- **Subject Alt B:** `Clearance hits 70% off + more deals inside`
- **Preheader Alt A:** `Clothing, shoes, golf, fitness & more — deals end Sunday`
- **Preheader Alt B:** `7 categories on sale — find your deal before it's gone`

## Technical Audit

## Technical Audit — DICK'S Sporting Goods Promotional Email

---

### 1. Technical Summary

The email uses a standard MSO/responsive table layout with Salesforce Marketing Cloud tracking infrastructure. Three confirmed defects: invalid JSON-LD that will break Gmail Promotions tab rendering, a stale hardcoded date from 2020 in the schema markup, and malformed CSS in the Outlook conditional block.

---

### 2. Link & Tracking Issues

**No issues found with click-tracking setup.** All CTAs route through `app.dickssportinggoods.com/T/<token>` with per-link tracking identifiers. Open pixel at `app.dickssportinggoods.com/O/<token>` is correctly hidden via `display:none; max-height:0px; mso-hide:all`.

**One concern:** The `__dU__` query parameter carries a base64-encoded payload in logo/CTA links. This is SFMC's standard encrypted subscriber identifier, but its presence in every link means unsubscribe action can be derived from click data — not a defect, but worth confirming it matches the unsubscribe token.

---

### 3. Rendering & Accessibility

**Defect — malformed CSS in MSO conditional block:**
```css
<!--[if (gte mso 9)|(IE)]>
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
A stray `"` appears before the closing `}`. This is syntactically invalid CSS and will be silently dropped by Outlook's CSS parser. Depending on what `div` styles are expected, this could cause layout shifts in Outlook 2016–2021.

**Advisory — logo `alt` text not confirmable:** The logo `<img>` tag is truncated in the provided source before the `alt` attribute. Verify that `alt="DICK'S Sporting Goods"` (or equivalent) is present; if missing, the logo renders as a broken image in image-blocked environments.

**No issues found** with responsive breakpoints (`max-width:480px` block), `role="presentation"` on layout tables, or `x-apple-data-detectors` suppression.

---

### 4. Personalization & Merge Tokens

**Defect — unpopulated JSON-LD template fields:**

The `<script type="application/ld+json">` block contains unfilled template slots sent to recipients:
```json
"description": "",
"discountCode": "",
"availabilityEnds": "",
"image": ""
```
These empty strings indicate the template was not fully merged before send. Gmail's Promotions tab uses this data for deal cards and image carousels — empty fields suppress those features.

**Defect — hardcoded 2020 date:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a stale placeholder, not a merge token. Gmail will render this as a deal that started 6 years ago; some inbox filters deprioritize promotions with past-dated availability.

---

### 5. Compliance

**Defect — invalid JSON inside `application/ld+json`:**
```javascript
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@context": "http://schema.org/",
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
JavaScript `//` comments are **not valid JSON**. `JSON.parse()` will throw on this block; Gmail's structured data parser will reject the entire `ld+json` payload. This is a hard parse failure, not a degraded experience — no Gmail Promotions features will activate.

**CAN-SPAM / unsubscribe — not verifiable from truncated source.** The footer containing the physical mailing address and unsubscribe link is not included in the provided HTML excerpt. Confirm these are present before flagging as compliant.

**Authentication — not verifiable from HTML.** Sending domain `e.dcsg.com` is a standard SFMC subdomain. SPF/DKIM/DMARC alignment must be verified via raw message headers, not HTML source.

---

### 6. Email-to-Site Continuity

No explicit UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) are present in any `href` before the `app.dickssportinggoods.com/T/` redirect. If UTMs are not appended by the SFMC redirect rules at click time, GA4/Adobe Analytics will classify this traffic as direct or referral, not email.

Verify in SFMC's link-tracking configuration that UTM injection is enabled on the `T/` redirect path for this send. A test click to a destination URL should show `utm_medium=email` in the resolved URL.
