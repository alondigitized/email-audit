# Welcome to the team! Here's $20 off $100+
**Score:** 6/10 · **Type:** Email audit · **2026-05-02**
## Executive summary

- A competent but generic welcome email that leads with a $20 off $100+ discount code, then tries to do four things at once: redeem the offer, explain app benefits, push product recommendations, and introduce loyalty perks. The hero section is clear and the discount code is prominently surfaced. The rest of the email bloats the message and dilutes focus. For a welcome email, this is too transactional and not enough "here's why you belong here."
- Functional but not exceptional. The offer is real and the code is legible — that's the core job, and it's done. Everything below the fold is noise that competes with the conversion intent.

## What's working

- **Discount code is front and center.** `WELFWSGPP9TTJJG` is large, clearly formatted, and accompanied by a "Shop Online Now" CTA. No hunting required.
- **Offer terms are explicit.** "$20 off qualifying purchase of $100 or more" is stated without ambiguity.
- **App download module is distinct.** The DICK'S app section has its own visual block and a clear value prop (manage ScoreCard, get offers).
- **Product grid adds browsability.** Six product tiles give the email some content depth and potential impulse click targets.

## What's weak

- **Hero image does little work.** A truck in the mountains with "WELCOME" overlaid communicates nothing about DICK'S specifically. It could be an outerwear brand, a truck ad, or an REI email.
- **Welcome email is trying to be everything.** Loyalty intro + discount redemption + app download + product picks + ScoreCard education = no clear north-star action.
- **"Stay tuned for:" section is filler.** Three small icon tiles (email exclusives, new products, alerts) with vague copy fill vertical space without offering value. This is padding.
- **Product recommendations feel untargeted.** Kids' shoes, men's casual sneakers, women's shoes — no coherent logic. There's no "because you're new" framing that makes this feel curated vs. algorithmic.
- **The offer expiry is buried.** "Expires 7 days from the date of this email" appears in fine print below the code — it should be near the CTA to create urgency.
- **Coupon module says "In-Store Coupon" ambiguously.** It's unclear whether the code is online-only, in-store-only, or both.

- 4. **Personalize or cut the product grid.** If you don't know what sport the new member cares about, ask. "What do you play?" with 4–5 sport icons would differentiate this and feed future targeting.
- 5. **Clarify online vs. in-store redemption.** Make the channel explicit in the offer headline, not just in the fine print.

### 3. Rendering & Accessibility

**Issue 1 — CSS syntax error in MSO conditional block (confirmed):**

```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```

There is a stray `"` immediately before the closing `}`. This is a parse error. Outlook's CSS parser may drop this rule or all subsequent rules in the same `<style>` block, causing layout collapse on desktop Outlook (2016/2019/365).

**Issue 2 — Invalid CSS class name (confirmed):**

```css
img.4x{max-width:150px!important}
```

CSS identifiers cannot begin with an unescaped digit (CSS Selectors Level 3, §4.1.3). This selector is invalid and will be silently ignored by spec-compliant parsers. The correct form is `img.\34 x` (escaped) or rename to a letter-prefixed class (e.g., `img.quad`).

**Issue 3 — `line-height:0` on text elements (MSO block):**

```css
body, .body, h1, h2, h3, h4, h5, h6, p, span, a, li, ol, ul, blockquote {line-height:0; mso-line-height-rule:exactly;}
```

This is intentional Outlook boilerplate but is a single-point-of-failure: if the MSO conditional block partially fails (e.g., due to Issue 1 above), text elements inherit `line-height:0` in Outlook and become invisible. Defensive practice is to scope this to a wrapper class rather than bare element selectors.
