# Up to 50% OFF starts with this week's DEALS
**Score:** 7/10 · **Type:** Email audit · **2026-07-19**
## Executive summary

- This is DICK'S seventh consecutive promotional blast in roughly five days, and it arrives as a frankenstein merge of two previously separate campaigns: the "50% off this week's deals" series and the "70% Summer Clearance" series — both now crammed into a single long-scroll email. The creative is structurally identical to every prior send: dark hero, large percentage badge, category nav rail, product tiles, clearance callout, app promotion, footer. At this cadence, the inbox has been fully desensitized — even a subscriber who loves DICK'S has been trained to ignore these.
- There are some genuine content wins: naming the HOKA Clifton 22 specifically (rather than just "running shoes") is exactly the kind of product signal that earns a second look. And the "starts with this week's DEALS" framing in the subject — implying 50% is just the floor — creates a mild breadcrumb into the email's deeper 70% clearance. That's a real copywriting idea buried in an exhausted format.
- The verdict: mechanically competent, but the cadence has run this creative into the ground. The July 17 send (8/10) had freshness on its side; this one doesn't. Fatigue is the enemy here, not execution.

## What's working

- **HOKA Clifton 22 specificity** — naming the shoe model (not just "running shoes") gives performance-minded buyers a real reason to look.
- **"starts with" subject framing** — suggests the 50% is a floor, creating mild curiosity to open and see what's deeper.
- **Clear visual hierarchy** — 50% OFF hero badge is impossible to miss; eye flow is immediate.
- **Summer Clearance 70% banner** — second strong offer anchors the bottom half and gives budget shoppers a second hook.
- **App promotion inclusion** — "All in the App" section targets mobile-first shoppers separately.

## What's weak

- **Cadence is completely broken** — this is email #7 in ~5 days, two of which were near-identical "50% deals" sends, three were "70% clearance" sends. The format has no novelty left.
- **Two campaigns fighting each other** — 50% deals AND 70% clearance in one email dilutes both. Neither offer gets to own the moment.
- **No specific end date anywhere** — "this week's" is soft urgency; no visible countdown or deadline in the body.
- **Zero personalization** — no name, no sport, no category preference surfaced — this is a broadcast to the full list.
- **Category nav rail adds noise** — "Shoes, The Summer Shop" links above the fold split attention before the main offer registers.

## Recommendations

- 1. **Pick one campaign per email** — either "this week's deals" OR "70% clearance," not both. Each needs space to land. Merging them makes each feel weaker.
- 2. **Add a specific deadline** — "Ends Sunday at midnight" beats "this week's" every time. Make the urgency visible in the body, not just implied by the subject.
- 3. **Lead with the named product** — if HOKA Clifton 22 at 20% off is the strongest hook, make that the hero, not a generic "50% OFF" badge. Product-first beats percentage-first for engaged subscribers.
- 4. **Suppress to recent openers / active buyers** — the list needs segmentation badly; at minimum, rest non-openers for 48h after this many back-to-backs.
- 5. **Break the dark hero** — literally any visual format change (white background, lifestyle photo, product close-up) would signal to the inbox that something is different this time.
- **Subject Alt A:** `HOKA Clifton 22 is 20% off right now`
- **Subject Alt B:** `Your next running shoe just got cheaper`
- **Preheader Alt A:** `Plus 70% off clearance ends this weekend — shop before it's gone`
- **Preheader Alt B:** `Clifton 22, VRST gear, Titleist vests — big deals, real prices`

## Technical Audit

## Technical Email Audit — DICK'S Sporting Goods "Up to 50% OFF" Campaign

---

### 1. Technical Summary

The email has correct MSO conditional scaffolding and a functional responsive structure. The primary technical failures are in the JSON-LD structured data block, which contains invalid syntax and multiple unfilled placeholders — these will cause Gmail Promotions Tab annotation to fail entirely.

---

### 2. Link & Tracking Issues

- All CTAs route through `app.dickssportinggoods.com/T/{hash}` click-tracker redirects — standard ESP behavior.
- Open-tracking pixel at `app.dickssportinggoods.com/O/{hash}` is hidden with both `display:none` on the `<img>` and `height:0` on the parent `<td id="ssl">` — redundant but harmless.
- UTM pass-through cannot be confirmed from the truncated source; no `utm_source`, `utm_medium`, or `utm_campaign` parameters are visible in any exposed URL. Verify the redirect target injects or preserves UTMs (see §6).

---

### 3. Rendering & Accessibility

**CSS syntax error in MSO conditional block:**
```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"
```
The rule closes with `"` instead of `}`. Older MSO renderers may fail to parse subsequent rules in this block.

**Conflicting table width declarations on main wrapper:**
```html
<table width="600" style="width:100%; max-width:600px">
```
The `width="600"` HTML attribute overrides `width:100%` on clients that honor presentational attributes, breaking fluid scaling on viewports below 600px. Remove the attribute-level `width="600"` and rely on the CSS.

**Missing `alt` attribute on tracking pixel:**
```html
<img src='https://app.dickssportinggoods.com/O/...' style="display:none; ..."/>
```
No `alt=""` present — should be explicitly set to empty string for screen reader compliance.

**Logo `alt` text:** Cannot confirm from truncated source — verify `alt` is set on `<img id="logo">`.

**Font version:** Archivo loaded from `/v7/` path on `fonts.gstatic.com` — this is an older revision. Not blocking, but worth updating.

**`@font-face` scoping:** Correctly wrapped in `@media screen` — Outlook will not attempt to load web fonts. No issue.

---

### 4. Personalization & Merge Tokens

**Invalid JSON-LD — JavaScript comments present (hard failure):**

JSON does not support `//` comments. The following lines inside `<script type="application/ld+json">` are invalid JSON and will cause the entire structured data block to be rejected by Gmail's parser:
```
// GIF & WEBP images are not supported and will be filtered out.
// Sample image is 538x138, 3.9 aspect ratio
// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
```

**Unfilled placeholder fields in JSON-LD:**
```json
"description": "",
"discountCode": "",
"availabilityEnds": "",
"image": ""
```
All four are empty strings — these are template fields that were never populated for this send.

**Stale `availabilityStarts` date:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 2020 date. Not updated for the current campaign — Gmail will render an expired offer in the Promotions Tab if the block were otherwise valid.

---
