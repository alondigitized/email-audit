# Up to 60% off select clearance is YOURS!
**Score:** 6/10 · **Type:** Email audit · **2026-09-18**
## Executive summary

- This is DICK'S running the same red "UP TO 60% OFF SELECT CLEARANCE" white-box hero it's been iterating on all month — same red gradient background, same bold black-on-white percentage callout, just bumped from 50% to 60% this time. The layout below is dense but organized: a clean category nav, then a long, legible cascade of merchandising blocks (running shoes, DICK's-exclusive apparel, cleats, fan shop, golf balls, outdoor gear, cardio equipment) each with its own clear "Shop Now" CTA, plus a $20-off-$100 text-alert unit and a "check out these picks" product grid near the footer.
- The execution is clean — no render bugs, good contrast, readable type — but it's the same template DICK'S has been sending on a near-daily cadence (9/12 through 9/17 all ran variations of this exact "UP TO X% OFF" hero). The only real news here is the number going from 50 to 60, which is a stronger offer but risks reading as "yet another deals email" to anyone who's opened the last five.
- Verdict: well-built, on-brand, and the escalated discount is a genuine improvement, but creative fatigue is now the biggest liability — the hero needs a new visual treatment, not just a bigger number.

## What's working

- Clear, high-contrast hero: "UP TO 60% OFF" is unmissable and readable at a glance.
- Strong offer escalation — 60% off is a bigger number than every prior send this stretch (all previously topped out at 50%).
- Well-organized body with distinct, scannable merchandising sections, each with its own CTA button.
- Category nav bar (Men's / Women's / Kid's / $25 and Under / Fan Shop / All Sale) gives quick wayfinding beyond the hero offer.
- No visual bugs — images load, buttons render, spacing is consistent throughout.

## What's weak

- The hero creative (red gradient, white box, bold percentage) is a near-exact repeat of the 9/12–9/17 sends — only the number changed.
- No urgency or deadline anywhere in the hero — "while they last" is vague, not a credible time-bound push.
- The email is very long with many competing offers (shoes, apparel, cleats, fan gear, golf balls, outdoor gear, cardio equipment) which dilutes the single "60% off" hook.
- No product-level detail (sizing, fit, ratings) visible for any featured item, so there's nothing to firm up a click beyond generic imagery.

## Recommendations

- 1. Swap the hero creative treatment (different color block, photography-led hero, or animated GIF) while keeping the 60% number — the message is strong, the wrapper is stale.
- 2. Add a real deadline to the hero subhead (e.g., "Ends Sunday") to convert the offer into urgency rather than open-ended clearance language.
- 3. Trim the body — lead with 2-3 top clearance categories instead of seven, and push cleats/golf balls/cardio into a secondary "more deals" digest.
- 4. Surface a specific hero product (a shoe or apparel item with price crossed out) right under the headline so the eye has one concrete thing to click, not just a category button.
- **Subject Alt A:** `60% off clearance ends Sunday — shop now`
- **Subject Alt B:** `Your best clearance deal yet: up to 60% off`
- **Preheader Alt A:** `Running shoes, fan gear, and golf balls all included.`
- **Preheader Alt B:** `New markdowns just added — inventory is limited.`

## Technical Audit

1. Technical Summary
Email fails plain-text fallback and unsubscribe-header checks, and every content/tracking image is missing alt text.

2. Link & Tracking Issues
- CTA link uses a click-tracking redirector (`https://data.em.dcsg.com/ee/v1/mclick?params=...&pid=v1.THX…`) with an opaque encoded `params` blob — no visible destination URL or UTM parameters present in the visible querystring, so destination/landing page cannot be verified from source.
- Open-tracking pixel present: `https://data.em.dcsg.com/ee/v1/open?params=...` — functioning as expected, but flagged by QA as an image with no alt text (acceptable for a tracking pixel, not a real issue).
- QA notes only 12 of 65 links were probed (53 skipped, deprioritized footer/utility/social); untested links' destinations are unconfirmed.

3. Rendering & Accessibility
- 12 content images missing `alt` attributes, including primary merchandising images (`0918-stw-6am-40-shoes`, `0918-stw-6am-70-clothing`, `0918-stw-6am-cleats`, `0918-4pm-fan-shop`, `0918-stw-6am-maxfli-golf`, `0918-stw-6am-60-quest`, `0918-stw-6am-cardio`) and icon images (`icon-vc-sms-1`, `icon-vc-sportsmatter`, `icon-vc-bpg-1`, `icon-vc-favorite-1`, `icon-location-2025-1`). Screen readers will announce these as unlabeled/skip content entirely, losing the "60% off" messaging conveyed only via image.
- MSO/Outlook conditional comments and `@media` mobile rules are present and structured correctly (`.mobile-off`, `.mobile-cta`, etc.) — no structural rendering issues found in the truncated source.
- Web font (`Archivo`) loaded via `@font-face` inside `@media screen` block with `Arial, sans-serif` fallback declared on `body` — acceptable degradation path.

4. Personalization & Merge Tokens
No merge tokens or personalization variables visible in the truncated HTML source — no issues found (note: source is truncated, so this is not a complete check).

5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- `List-Unsubscribe` header: not found in QA scan (may be a relay-capture limitation rather than a true absence — flagged WARN, not FAIL).
- `List-Unsubscribe-Post` (RFC 8058 one-click unsubscribe): not found — if genuinely absent, this fails Gmail/Yahoo 2024+ bulk-sender requirements for one-click unsubscribe.
- `Authentication-Results` header (SPF/DKIM/DMARC): not found — cannot confirm authentication status via this relay; treat as unverified rather than failing.
- Plain-text MIME fallback: present but only 9 characters — effectively empty. This is a CAN-SPAM/deliverability risk (multipart/alternative should contain a substantive text equivalent) and will likely trigger spam-filter scoring on some providers.
- No unsubscribe link/footer visible in the truncated HTML, though QA notes "an unsubscribe link is always included" among the 53 skipped/deprioritized links — presence not directly confirmed in the excerpt shown.

6. Email-to-Site Continuity (UTM params, landing page alignment)
- Cannot confirm UTM parameter presence/consistency — CTA destination is obscured behind the `mclick` redirector's encoded `params` payload rather than a plain query string. Landing page alignment cannot be verified without decoding/following the redirect.

7. Recommendations
- Add descriptive `alt` text to all 12 flagged content/icon images, particularly the four offer-graphic images that carry the primary "60% off" message, so the discount is conveyed if images are blocked.
- Populate the plain-text MIME part with a real text equivalent of the email body (current 9-char fallback is non-compliant in practice).
- Verify `List-Unsubscribe` and `List-Unsubscribe-Post` headers are actually being sent by the ESP (dcsg.com/em.dcsg.com) — confirm via raw headers from a non-relay capture, since AgentMail may simply not be surfacing them.
- Confirm SPF/DKIM/DMARC alignment for `em.dcsg.com` directly with the sending ESP, since `Authentication-Results` wasn't captured here.
- Follow/decode the `mclick` redirector for the primary CTA to confirm the final landing URL carries correct UTM parameters and matches the advertised clearance category page.
