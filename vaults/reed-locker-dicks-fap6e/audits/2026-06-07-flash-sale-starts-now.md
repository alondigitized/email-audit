# Flash Sale starts now!
**Score:** 8/10 · **Type:** Email audit · **2026-06-07**
## Executive summary

- "Flash Sale starts now!" is a welcome format reset after nine consecutive "Extra 25% off clearance" beats — and DICK'S has quietly escalated the underlying clearance offer from 25% to **30%** without fanfare. The email is a multi-category roundup (clearance shoes, collabs/HBCU clothing, golf clubs, Marucci bats, fishing gear) that structurally resembles the June 4 and June 5 "Best Deals of the Week" sends that scored 9/10. The olive-toned hero banner is punchy and modern; the per-category deal modules give the eye places to land and convert.
- The damage from prior-send fatigue is real, though. A subscriber who has received nine near-identical clearance emails since May 30 — including *two* on June 6 alone — is primed to glance-and-delete. "Flash Sale starts now!" is a better subject than anything in that run, but it still lacks a number, a category, or an end-date that would make it feel genuinely urgent rather than "DICK'S doing another promo thing."
- The email earns its keep on merit. The Golf and Baseball modules with named products (Marucci CAT12, specific driver/iron combos) are the standout differentiators vs. the clearance-sludge run. This should outperform the June 6 sends materially.

## What's working

- **Format reset is well-timed.** "Flash Sale" framing breaks the clearance monotony after a week of identical creative.
- **Offer escalation is buried.** The clearance offer jumped from 25% → **30% off** — a genuine upgrade that would convert clearance shoppers who tuned out the prior run.
- **Named-product modules punch above weight.** "50% Off Marucci CAT12 Baseball Bats" and "Up to $300 Off Select Golf Clubs" give sports-specific shoppers a concrete reason to scroll deep.
- **Category breadth is strong.** Men's, Women's, Kids, Golf, Baseball, Fishing — one email does the work of five targeted sends without feeling chaotic.
- **Hero visual is differentiated.** The olive/camo background is a departure from the red clearance banners that have dominated for nine sends.

## What's weak

- **No end-date on the "Flash Sale."** "Starts now" implies urgency but without a deadline ("ends Sunday," "48 hours only"), it reads more like a headline than a countdown.
- **"SHOP NOW" CTA copy is generic across every module.** Seven modules, seven identical CTAs — none name the category being shopped.
- **Clearance escalation is undersold.** 25% → 30% is meaningful but there's no "we raised the discount" framing to reward subscribers who saw the prior sends.
- **Golf category feels inconsistent.** "PathSync Vilas Balls" copy is oddly specific and reads like a product-feed dump rather than curated copy.
- **Cadence context works against it.** A subscriber who received two emails yesterday and ~9 total in the past week is primed for fatigue regardless of this send's quality.

## Recommendations

- 1. **Put a number in the subject.** "Flash Sale: Extra 30% off + up to 50% off everything" beats the abstract "starts now" and gives a concrete hook the inbox has been missing for days.
- 2. **Add a deadline anywhere in the hero.** Even "Ends Sunday" in the subhead turns browsing intent into urgency.
- 3. **Differentiate CTA copy per module.** "Shop Clearance Shoes" / "Shop Golf Clubs" / "Shop Bats" — one line each, costs nothing, lifts CTR.
- 4. **Make the 25% → 30% escalation visible.** "We raised it — now EXTRA 30% off" in the clearance module rewards loyal subscribers and re-engages the segment that tuned out at 25%.
- 5. **Cut the PathSync module or rewrite the copy** — the product name without a clear benefit or % headline is a dead zone in an otherwise well-structured send.
- **Subject Alt A:** `Flash Sale: Extra 30% Off + Up to 50% Off`
- **Subject Alt B:** `Flash Sale ends Sunday — up to 50% off now`
- **Preheader Alt A:** `Marucci bats, golf clubs, clearance shoes — all on sale this weekend only.`
- **Preheader Alt B:** `We raised the clearance discount. Extra 30% off starts now — ends Sunday.`

### 1. Technical Summary

The email is built on Epsilon/Harmony infrastructure with standard click-tracking redirects and an open pixel. The primary technical defects are an invalid JSON-LD block (JavaScript comments embedded in JSON) and a stale 2020 template date that will cause structured data parsing failures in Gmail's promotional annotations.

---

### 2. Link & Tracking Issues

**Open/tracking pixel — possible template placeholder not replaced**
```html
<img src='https://app.dickssportinggoods.com/O/v610000019ea192d97fca32aaf4bbc780a0/...'
  style="display:none; max-height: 0px; ..."/>
<!--Replace/Paste SSL Here-->
```
The comment `<!--Replace/Paste SSL Here-->` immediately follows the pixel. If the pixel token above it is not the final send-specific value, opens will not be counted. Confirm the `O/` path token is deployment-specific and not a template stub.

**Click-tracking redirect domain**
All CTAs route through `app.dickssportinggoods.com/T/v610000019ea192d97fca32aaf4bbc780a0/...`. This is consistent and expected for Epsilon tracking. No broken or mismatched redirect domains detected in the visible portion.

**Truncated image URL — possible staging CDN**
```
https://dsg.images.harmony.epsilon.com/_phoenix/_dev/AEM/img/headers/brand-logo--dk…
```
The `_dev` path segment is present in the logo `src`. Verify this resolves to a production CDN path, not a staging asset. A `_dev` path that 404s in production will render a broken logo.

---

### 3. Rendering & Accessibility

**`border-collapse` conflict between MSO conditional and inline styles**
MSO conditional block sets:
```css
table { border-collapse: collapse; }
```
But the wrapper table uses:
```html
style="border-collapse:separate; border-spacing:0;"
```
`border-spacing:0` on a `separate` table mimics `collapse` visually, but in Outlook the MSO rule overrides to `collapse`, discarding the `border-radius:8px` on the header card. Rounded corners will not render in Outlook.

**`role="presentation"` applied consistently** — no issues found in visible tables.

**No `alt` text visible** on logo `<img id="logo">` in the truncated source. If the `alt` attribute is absent or empty on a linked image, screen readers will announce the URL. Requires verification against full source.

**Google Fonts loaded via `@media screen`** — correct practice; Arial fallback is declared. No issue.

---

### 4. Personalization & Merge Tokens

**Conditional content for ScoreCard members**
The header table carries `id="header-non-sc-member"`. This implies a corresponding `header-sc-member` variant should exist. The truncated source does not include it — confirm the full template has both variants and that the send logic selects the correct one per recipient segment. A missing SC-member block would cause non-SC members to receive the SC member header (or vice versa).

**No unresolved `{{merge_token}}` placeholders visible** in the truncated source. Cannot confirm for body/footer — full source required.

### 5. Compliance

**JSON-LD block contains JavaScript-style comments — invalid JSON**
```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@context": "http://schema.org/",
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
JSON does not permit `//` comments. Every JSON parser (including Gmail's structured data extractor) will reject this entire `<script type="application/ld+json">` block. The Gmail Promotions tab annotation will not render.

**Stale `availabilityStarts` date in `DiscountOffer` schema**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 6-year-old template default. Even if the JSON were valid, Gmail would likely discard a promotion with a start date in 2020. `availabilityEnds` is also an empty string, which is invalid ISO 8601.

**`discountCode` and `description` are empty strings**
```json
"discountCode": "",
"description": ""
```
Empty required fields indicate the structured data block was never populated for this send.

**`PromotionCard.image` is empty**
```json
"image": ""
```
The designer comment confirms this was a manual step that was skipped.

**`DiscountOffer` is not a recognized Schema.org type** — the correct type is `Offer`. Gmail may silently reject unknown `@type` values.

**CAN-SPAM / unsubscribe** — the HTML is truncated before the footer. Cannot confirm physical mailing address or unsubscribe link presence. These must be verified against the full source.

**Authentication headers** (SPF, DKIM, DMARC) are not visible in HTML source — requires raw email headers for verification.

Confirm that the redirect destination URLs include campaign UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) so that GA4 / analytics attribute sessions correctly. Epsilon redirects that drop UTM tags will attribute flash-sale traffic as direct.
