# Order now… get it there by Father's Day! 🛒
**Score:** 7/10 · **Type:** Email audit · **2026-06-16**
## Executive summary

- This is DICK'S Sporting Goods' Father's Day deadline play — a last-call logistics email anchored by a real-time countdown clock ("Final Hours: 07 | 59 | 48") in the hero. The urgency mechanism is the right call; Father's Day shipping deadlines are one of the few moments where a countdown feels earned rather than manufactured. The email stacks four to five distinct value propositions on top of each other (Nike deals, Fan Shop 50% off, ScoreCard $10 reward, in-store pickup), which dilutes the lead instead of letting the deadline hook breathe.
- The biggest structural problem is familiar from the DICK'S cadence this week: it's the same multi-module compilation format used in the June 13–15 Flash Sale blasts, now draped in Father's Day language. The hero image (father and son in orange shirts) is on-theme, but the overall email reads as a checklist deployment rather than a focused send. It does the job, but it doesn't own the moment.
- Compared to the June 15 ScoreCard send (8/10) which had one sharp hook, this one tries to be that email and the clearance email and the loyalty email simultaneously.

## What's working

- **Countdown timer is immediately visible** — "Final Hours: 07 | 59 | 48" in the hero is the strongest urgency signal DICK'S has used all week; it makes the delivery deadline viscerally real.
- **Father's Day hero image is on-brand** — two people in warm outdoor gear, clearly reads as a gifting context without being saccharine.
- **ScoreCard $10 Bonus Reward module is present** — loyalty benefits are surfaced mid-email, consistent with the June 15 member send; rewards members get a second reason to click.
- **"Get it by Father's Day or Store Pickup" section handles the last-minute objection** — the store pickup fallback is smart for people who've missed the shipping window.
- **Subject line is under 50 characters** and clearly states the action + deadline without spam signals.

## What's weak

- **Module overload kills focus** — five distinct sections (Nike Favorites, Fan Shop 50% Off, ScoreCard reward, store pickup, summer gear grid) means no single offer dominates; the eye has nowhere to land.
- **"Shop Now" CTA copy is generic across all modules** — after four Flash Sale emails this week, "Shop Now" reads as wallpaper; a deadline-specific CTA ("Order by tonight →") would carry the urgency the timer sets up.
- **No specific product hero** — the best Father's Day emails win by surfacing one aspirational product; this one serves a grid of thumbnails that require effort to engage with.
- **Cadence fatigue is real** — this is the sixth-plus DICK'S email in roughly 72 hours. Even a good send loses authority in a flooded inbox.

## Recommendations

- 1. **Strip to one offer + one CTA.** Pick the strongest hook (50% off Fan Shop gear, or the $10 ScoreCard bonus) and build the whole email around it. Every additional module here costs attention.
- 2. **Rewrite every "Shop Now" to "Order by Tonight"** or "Get It There in Time →" — the countdown sets up urgency that the CTAs then abandon.
- 3. **Lead with a specific product hero**, not a lifestyle shot. One great product (e.g., a Nike polo, a cooler, a grill tool set) with a price and the shipping deadline directly beneath it would outperform the generic father/son image.
- 4. **Surface store pickup as the primary CTA** for anyone who sees this email the day before Father's Day — the shipping window is likely closed; in-store is the real hook at this point.
- **Subject Alt A:** `Last chance to get it there by Father's Day`
- **Subject Alt B:** `Order by tonight — arrives by Father's Day 🛒`
- **Preheader Alt A:** `Free shipping on $49+. Final hours to guarantee Sunday delivery.`
- **Preheader Alt B:** `Or grab it in-store — pickup available today.`

## Technical Audit

**Technical Audit — DICK'S Sporting Goods Father's Day Email**

---

## 1. Technical Summary

Email is deployed on the Epsilon/Harmony ESP platform with standard MSO/Outlook conditional rendering guards in place. Several JSON-LD template defects and a suspicious `_dev` asset path in the logo URL require immediate attention before future sends.

---

## 2. Link & Tracking Issues

**Open tracking pixel confirmed** — 1×1 image fires on render:
```
https://app.dickssportinggoods.com/O/v610000019ed20f96a1bb6a376e96c65848/57e84161...
```
This is standard ESP behavior but the pixel `<img>` has no `alt=""` attribute and no `display:none` in MSO-targeted conditional comments — Outlook may render a broken image icon if the pixel request fails before rendering completes. The inline `style="display:none; max-height:0px"` is present for most clients but MSO requires the conditional comment wrapper too.

**No UTM parameters detected** — all CTA links route through `app.dickssportinggoods.com/T/…` Epsilon redirect tokens. If Google Analytics or any downstream analytics system expects `utm_source` / `utm_medium` / `utm_campaign` params on landing pages, this send will produce dark traffic against organic/direct. Verify whether the Epsilon redirect appends UTMs server-side before the final destination redirect.

---

## 3. Rendering & Accessibility

**Duplicate `font-family` declaration on `body`** (lines 11–12 of the `<style>` block):
```css
body { font-family: Archivo, Arial, sans-serif; font-family: Archivo, Arial, sans-serif !important }
```
The first declaration is redundant. No functional breakage but signals copy-paste template hygiene issue.

**Tracking pixel missing `alt` attribute:**
```html
<img src='https://app.dickssportinggoods.com/O/...' style="display:none; ..."/>
```
Should be `alt=""` for screen reader compliance.

**Logo image URL truncated in source extract** — cannot confirm `alt` text is present. Requires full-source verification.

**MSO conditional CSS includes an unclosed `div` style rule** (spurious trailing `"` after `padding:0`):
```css
div {background-color:inherit; ... padding:0;"}
```
The trailing `"` after the closing `}` is invalid and may cause MSO style parsing to drop subsequent rules in the conditional block.

---

## 4. Personalization & Merge Tokens

**Critical — JSON-LD block contains JavaScript-style inline comments**, which are invalid JSON:
```json
{ // GIF & WEBP images are not supported...
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```
This will throw a JSON parse error in Gmail's structured data parser and in any validator. The `PromotionCard` image field is also empty — the designer annotation was never replaced with a real URL. Gmail Promotions tab annotation will fail entirely.

**Stale `availabilityStarts` date in `DiscountOffer`:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a 6-year-old template default that was never populated. `availabilityEnds` and `discountCode` are also empty strings. Validators and Gmail's Promotions tab will reject or ignore this block.

## 6. Email-to-Site Continuity

**`_dev` path segment in logo asset URL:**
```
https://dsg.images.harmony.epsilon.com/_phoenix/_dev/AEM/img/headers/brand-logo--dk…
```
The `_dev` directory in a production send is a red flag — this may be a staging/development asset that was promoted without updating the URL. If the dev asset CDN path is not publicly accessible in production or gets rotated, the logo will break for all recipients. Verify this resolves to the correct production asset.

**Tracking redirects via `app.dickssportinggoods.com/T/…`** will pass through Epsilon's link-tracking layer before hitting the final destination. If the final URLs do not carry UTM parameters (see §2), click attribution in Google Analytics will be lost.
