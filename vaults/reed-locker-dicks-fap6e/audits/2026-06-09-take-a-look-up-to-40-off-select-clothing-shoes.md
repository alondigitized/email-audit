# Take a look: Up to 40% off select clothing & shoes
**Score:** 7/10 · **Type:** Email audit · **2026-06-09**
## Executive summary

- This is a broad clothing-and-shoes category compilation — DICK'S stepping back from the clearance/flash-sale drum they've been beating since May 30 and showing a wider assortment. The hero is clean: two athletic models (male dominant/left), a clear "Up to 40% Off" headline, and a visible SHOP NOW button. Below the fold the email becomes a lot — flip flops, YETI, Columbia, Aira 4D shoes, JOOLA pickleball, a 50% off panel, and a product grid. There's real value here; the Aira 4D price drop ($150 → $84.99) is a compelling specific item.
- The problem is context. Two days ago subscribers got a 50% off Flash Sale and two "up to 50% off" weekly deals compilations. Dropping to 40% and calling it a look at the category feels like a step backward in offer intensity. The subject line opener "Take a look:" wastes 11 characters on nothing — it's the email equivalent of clearing your throat. And this is the seventh DICK'S email in five days; the cadence is objectively fatiguing.
- Verdict: competent creative, weak positioning. Should score better than it will because subscribers are primed to scroll past DICK'S at this send frequency.

## What's working

- Hero layout is clean — male model left, female right, both in athletic wear, offer copy dominant above the fold.
- Specific price drop visible mid-email: Aira 4D dropped to $84.99 (was $150) — that's a real signal, not just a vague "up to X% off."
- Multiple named brands (YETI, Columbia, JOOLA, Aira) give the compilation credibility and scannability.
- The big "50% OFF" red panel lower in the email is a strong visual anchor for scrollers.
- No visible render bugs — layout holds, images load, buttons are clear.

## What's weak

- "Take a look:" opener in the subject is filler — cuts mobile display length and adds zero open incentive.
- 40% headline reads as a downgrade after subscribers just received 50% flash-sale and weekly-deals emails; no explanation for why this is worth opening now.
- Seven emails in five days — cadence fatigue will suppress opens regardless of creative quality.
- "SHOP NOW" CTA copy is generic; none of the CTAs in the email use a specific verb/noun pair that matches the offer.
- No visible urgency signal — no deadline, no countdown, no "ends tonight."

## Recommendations

- 1. **Cut "Take a look:" entirely** — lead with the offer. "Up to 40% off clothing & shoes" in 40 chars is stronger than 51 chars of weak-opener + offer.
- 2. **Add a deadline** — even "this week only" or "through Sunday" dramatically lifts urgency without much effort.
- 3. **Anchor the subject on the specific item** — the Aira 4D drop ($150 → $84.99) is a concrete hook the subject line is completely ignoring.
- 4. **Rewrite at least one CTA** — "Shop Aira 4D" or "Shop Men's Tees" beats "SHOP NOW" for click relevance.
- 5. **Compress send cadence** — combining the last three "deals" sends into one weekly digest would protect opens on the sends that matter.

## Technical Audit: DICK'S Sporting Goods — "Up to 40% off select clothing & shoes"

### 1. Technical Summary

The email's JSON-LD promotional annotation block contains invalid JSON (JavaScript comments) that will silently fail to parse in all Gmail Promotions Tab processors. A secondary CSS syntax error exists inside the MSO conditional stylesheet.

---

### 2. Link & Tracking Issues

**No issues found** in visible link structure. All CTA hrefs route through Salesforce Marketing Cloud redirect (`app.dickssportinggoods.com/T/...`) with proper token encoding. The open-tracking pixel (`/O/...`) is present and hidden via inline CSS (`display:none; max-height:0px`), which is standard.

---

### 3. Rendering & Accessibility

**MSO conditional CSS syntax error — confirmed.**

In the `<!--[if (gte mso 9)|(IE)]>` block:
```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
There is a stray `"` immediately before the closing `}`. This makes the `div` rule unparseable in Outlook/IE rendering engine, which may cause layout collapse in full-width divs under MSO.

**Google Fonts CDN in email body.** `fonts.gstatic.com` woff2 loads will be blocked by Outlook, Apple Mail in some configurations, and all webmail clients that strip `@font-face` inside `<style>`. The Arial fallback is correctly specified, so this is a rendering degradation, not a breakage.

**`<link rel="icon">` in `<head>`.** Email clients ignore this tag entirely; it triggers an unnecessary external HTTP request to `https://www.dickssportinggoods.com/home/assets/icons/dsg/favicon.ico`. No functional impact but adds noise.

---

### 4. Personalization & Merge Tokens

**Invalid JSON in `<script type="application/ld+json">` — confirmed critical.**

The script block contains JavaScript-style `//` line comments, which are not valid JSON:

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

`application/ld+json` is parsed as strict JSON, not JavaScript. These comments will cause the entire script block to throw a `SyntaxError` in every spec-compliant parser — meaning Gmail's Promotions Tab annotations, rich preview cards, and any inbox-enhancement features tied to this schema block are silently non-functional.

**Stale hardcoded `availabilityStarts` date.**

```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```

This is a fixed date from March 2020. If this is meant to reflect the current send window, it must be populated dynamically via a merge tag at send time.

**Empty required fields in JSON-LD:**

| Field | Value |
|---|---|
| `DiscountOffer.description` | `""` |
| `DiscountOffer.discountCode` | `""` |
| `DiscountOffer.availabilityEnds` | `""` |
| `PromotionCard.image` | `""` |

These empty strings will either suppress the annotation entirely or render incomplete previews in Gmail's Promotions tab.
