# Up to 50% OFF is happening NOW — shop this week's DEALS
**Score:** 5/10 · **Type:** Email audit · **2026-08-23**
## Executive summary

- This is the same green-locker-room "UP TO 50% OFF" hero DICK'S has run repeatedly this month — 8/20's "This week's deals = up to 50% off!!" and 8/22's flash sale both use near-identical padlock/locker imagery and the same white-outlined box treatment. The subject line drops the exclamation-point urgency of the flash sale sends but keeps the same generic "shop this week's deals" framing that's shown up before.
- Below the hero, it's the standard DICK'S digest: a full-scroll of category tiles (men's/women's/kids'/team sports/golf), then a second "UP TO 60% OFF SELECT CLEARANCE SCORES" red banner buried deep in the email, then a picks grid. Nothing here is broken, but nothing differentiates this send from the five before it in the brand history — same structure, same offers, same models, just reshuffled.
- Judgement: functional, on-brand, zero render bugs, but this is fatigue territory. A subscriber who's opened 3+ of these this week has seen every asset in this email already.

## What's working

- Clean render — no overlapping text, no broken images, all product photography loads correctly.
- Clear top-of-fold value prop: free same-day pickup + free shipping over $49 stated right under the header.
- Good category segmentation with quick-nav pills (Men's, Women's, Kids', Shoes, Team Sports, Back-to-School Shop).
- Two distinct offers stacked (50% off sitewide hero + 60% off clearance banner) give the email a genuine reason to scroll.
- "Check out these picks" product grid at the bottom adds concrete, clickable SKUs rather than ending on a category tile.

## What's weak

- This is the third+ near-identical "Up to 50%" locker-room hero this month (8/16, 8/20, 8/22, now 8/23) — visual creative fatigue is real at this cadence.
- Subject line is generic and interchangeable with at least four prior sends — nothing in it signals what's new or different about today's deals.
- The stronger 60% off clearance offer is buried roughly two-thirds down the scroll, under six other category blocks — most recipients on mobile won't reach it.
- No urgency mechanism (no countdown, no "ends tonight") despite subject implying "happening NOW."
- Hero CTA is a plain "Shop Now" linking to a generic deals page, not a specific category or product — weak click signal.

## Recommendations

- 1. Retire the green-locker "UP TO 50% OFF" creative for at least two weeks — it's been the hero on 8/16, 8/20, 8/22, and now 8/23. Swap in the 60% clearance red banner as the hero instead since it's the stronger, more specific offer.
- 2. Add a visible deadline (date/time) to the hero — "happening NOW" with no end time reads as permanent, not urgent.
- 3. Move the picks grid or a "trending now" strip higher, right after the hero, so mobile users see specific products before six category tiles.
- 4. Differentiate the subject line from the recent run — reference the clearance angle or a specific category instead of the same "Up to 50% off... shop deals" template.
- **Subject Alt A:** `New clearance drops + up to 60% off — today only`
- **Subject Alt B:** `Back-to-school gear from $15 — deals end Sunday`
- **Preheader Alt A:** `Fresh markdowns on shoes, cleats, and backpacks — plus free pickup today.`
- **Preheader Alt B:** `Clearance just got deeper. Shop before sizes run out.`

## Technical Audit

## 1. Technical Summary
Email renders via a standard Epsilon/Harmony (DSG) responsive table layout with MSO conditional fallbacks; automated QA shows a 43% pass rate driven by a broken unsubscribe link, missing email authentication/unsubscribe headers, and widespread missing alt text.

## 2. Link & Tracking Issues
- **Unsubscribe link is broken**: resolves to `https://app.dickssportinggoods.com/U/v61000001a0303e9674a855926e965fd798/db39a08e98c64b1b0000021ef3a0bd02`, which redirects to an error page (`/pc/Error/Error?aspxerrorpath=/pc/subscription`). This is a CAN-SPAM compliance risk, not just a broken link (see §5).
- All probed links use the Epsilon/Harmony click-tracking redirector pattern `https://app.dickssportinggoods.com/T/v6.../...?__dU__=...` (e.g., the header logo link). This is consistent and expected for this ESP.
- 12 of 66 total links were probed (54 skipped as low click-likelihood footer/social/utility links per the QA tool's prioritization) — no broken links found among the probed set other than unsubscribe.

## 3. Rendering & Accessibility
- **10 images missing `alt` text**, including the SSL/open-tracking pixel, all four seasonal category images (`2026-0820-dks-swd-4pm-new-mens`, `2026-0823-dks-swd-4pm-new-womens`, `2026-0823-dks-swd-4pm-new-kids`, `2026-0820-dks-swd-4pmsports`), the golf promo image, and 5 footer icons (SMS, SportsMatter, BPG, favorite, store-locator icons). Screen readers and images-off clients will render these as blank/unlabeled.
- The `<script type="application/ld+json">` block contains inline `//` comments (e.g., `// GIF & WEBP images are not supported...`), which is **invalid JSON** — this is unparsed template/build boilerplate that leaked into the deployed HTML (also several fields are empty: `"description": ""`, `"discountCode": ""`, `"image": ""`, `"availabilityEnds": ""`). Any consumer parsing this structured data (e.g., Gmail annotations) will fail on the comments.
- MSO conditional CSS block has a malformed rule: `div {background-color:inherit; ... padding:0;"}` — stray trailing `"` before the closing brace is a syntax error in that Outlook-targeted stylesheet.
- Mobile responsive rules (`@media screen and (max-width:480px)`) are otherwise well-formed with standard `!important` overrides.

## 4. Personalization & Merge Tokens
- No unresolved merge tags (e.g., `%%FIRSTNAME%%`, `{{token}}`) visible in the truncated source.
- No issues found in the visible portion; note the source was truncated so downstream personalization blocks weren't fully inspectable.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **Unsubscribe link fails** (see §2) — this is a CAN-SPAM violation risk since the mechanism must remain functional; an error page does not constitute a working opt-out.
- **`List-Unsubscribe` header not found** — may be a QA/relay capture limitation (AgentMail) rather than confirmed absence; flagged as WARN, not FAIL.
- **`List-Unsubscribe-Post` header not found** — one-click unsubscribe (RFC 8058) cannot be confirmed as supported.
- **`Authentication-Results` header not found** — SPF/DKIM pass/fail status could not be verified via the AgentMail relay; this is an infrastructure/measurement gap, not confirmed auth failure.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
- Not assessable from the truncated source — no destination/landing-page URLs with UTM parameters were visible outside the ESP click-tracking redirector wrapper. Recommend re-running with full HTML to verify UTM presence and landing-page match.

## 7. Recommendations
1. Fix the unsubscribe link target (`/U/v61000001.../...bd02` → currently 404/error page) — highest-priority compliance fix.
2. Add `alt` attributes to all 10 flagged images (empty `alt=""` is acceptable for the tracking pixel; descriptive text needed for the 4 category images, golf image, and footer icons).
3. Remove the invalid `//` comments and populate/remove empty fields in the `application/ld+json` block so it parses as valid JSON.
4. Fix the malformed MSO conditional CSS rule (stray `"` in the `div` selector block).
5. Confirm with the sending platform (or capture raw headers directly rather than via the AgentMail relay) whether `List-Unsubscribe`, `List-Unsubscribe-Post`, and `Authentication-Results` are actually present — current WARNs may be a measurement artifact, not a real gap.
