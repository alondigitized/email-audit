# Flash Sale begins NOW! Enjoy up to 50% OFF while you can
**Score:** 7/10 · **Type:** Email audit · **2026-05-30**
## Executive summary

- This is DICK'S seventh email in four days under a fresh sub-brand identity — "DICK'S | Flash Sale" — after the May 29 clearance blast, two May 28 deals sends, and three May 27 sends. Swapping the sender name is a legitimate tactical move to break through inbox fatigue, and the mid-email "Extra 25% OFF Select Clearance" is a genuinely stacked, additive offer that makes this marginally more compelling than the May 29 clearance send. But the underlying template is identical: same multi-lane category grid, same SHOP NOW buttons, same Up to 50% OFF hero. The cosmetic rebrand doesn't change the bones.
- The National Runners Month hook is the one element that earns its place — it gives the athletic imagery a purposeful seasonal anchor in May rather than decoration. The real problem is that "Flash Sale begins NOW! ... while you can" promises urgency it doesn't deliver. No end date appears anywhere in the render. Urgency without a clock is just noise, and the subscriber who has already ignored six DICK'S emails this week is not going to be moved by vague language.
- Call this a 7 — the new sender identity and stacked offer earn a marginal bump over the May 28–29 runs, but it's still a repeat send in a fatigued cadence.

## What's working

- **New sender identity** ("DICK'S | Flash Sale") breaks the inbox pattern vs. this week's earlier sends and signals something distinctly different is arriving.
- **"Extra 25% OFF Select Clearance"** is a specific, stacked offer — genuinely additive to base clearance pricing and surfaced visibly mid-email.
- **National Runners Month tie-in** gives the running/athletic imagery a credible May hook rather than generic lifestyle filler.
- **"Up to 40% OFF Select Fan Shop Gear"** adds a second distinct offer lane with its own audience, broadening relevance.
- **10% Back in Rewards** section is visible — loyalty members have a reason to engage beyond the surface headline discount.

## What's weak

- **No hard deadline anywhere.** "Flash Sale begins NOW! ... while you can" is urgency theater — no end date, no countdown, nothing to create real time pressure.
- **Template fatigue is visible** — same swim lanes, same SHOP NOW button copy, same layout skeleton as every DICK'S send this week. "Flash Sale" label is surface dressing on an identical frame.
- **The "DICK'S 2% Off" section is a baffling offer** sandwiched into a 50%-off email — 2% reads as fine print or a data error, not a benefit.
- **No hero product.** Every lane links to a broad category; there's no single featured item to anchor desire or create urgency around a specific thing.
- **Cadence context undermines the urgency framing** — after six previous DICK'S emails this week, "Flash Sale begins NOW" lands as manufactured pressure, not a real event.

## Recommendations

- 1. **Add a hard end date to the Flash Sale** — this is the single highest-lift change. "Ends Sunday at midnight" converts vague urgency into a real decision deadline and gives subscribers a reason to act today instead of deferring.
- 2. **Lead the hero with the stacked 25% OFF clearance offer** — the most differentiated news is buried mid-scroll; promote it to the hero where it can drive the open-to-click bridge.
- 3. **Kill or reframe the "2% Off" section** — if it's a ScoreCard rewards multiplier, say so explicitly ("Earn 2% extra on DSG brands for ScoreCard members this weekend"). As-is it competes against a 25% headline and loses badly.
- 4. **Feature one hero product** — a specific UA runner's shoe or a DSG trail jacket would anchor desire better than "Shop All Running."
- 5. **Rest the sub-brand for two days** — DICK'S Main + DICK'S Clearance + DICK'S Flash Sale on consecutive days trains the segment to tune out all three; suppress for 48 hours post-send.
- **Subject Alt A:** `Flash Sale: Extra 25% off clearance — ends Sunday`
- **Subject Alt B:** `Your clearance just got cheaper (25% more off, today only)`
- **Preheader Alt A:** `National Runners Month deals stacked on top of clearance prices.`
- **Preheader Alt B:** `UA, ON, DSG gear — extra 25% off select styles while Flash Sale runs.`

### 1. Technical Summary

The email uses a standard Epsilon/Harmony ESP stack with MSO conditional rendering and responsive breakpoints. Two concrete infrastructure defects were found: invalid JSON-LD that will silently fail Gmail Promotions tab enrichment, and a stale year comment indicating template hygiene issues.

---

### 2. Link & Tracking Issues

**Tracking pixel present and correctly suppressed:**
```
https://app.dickssportinggoods.com/O/v610000019e77b4adaba5d26f369fea4b34/cee10e4336…
```
Pixel uses `display:none; max-height:0; overflow:hidden; mso-hide:all` — correct multi-client suppression pattern.

**All CTAs wrapped in Epsilon redirect URLs** (`/T/v6…`) with subscriber-level `__dU__` tokens. UTM pass-through depends entirely on redirect configuration; UTM parameters are not visible in the raw HTML, so continuity cannot be confirmed from source alone. (See §6.)

**No bare/untracked links observed** in the visible portion.

---

### 3. Rendering & Accessibility

**[HIGH] Invalid JSON in `<script type="application/ld+json">`:**
JavaScript-style `//` comments appear inside the JSON-LD block — JSON does not support inline comments. This causes a JSON parse error, silently breaking the entire structured data block for all three schema entries.

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

**[MEDIUM] CSS syntax error in MSO conditional block:**
Stray `"` before closing brace in `div` rule:
```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
This invalidates the MSO `div` reset rule. Impact is limited to Outlook's rendering engine, but the fix is trivial.

**[LOW] Google Fonts pinned to versioned path `/s/archivo/v7/`:**
Google periodically invalidates old version paths. Pinning to `v7` risks the custom font silently 404ing over time; the `local()` fallback ensures graceful degradation to Arial, but it is worth monitoring.

**Positive:** `role="presentation"` applied consistently to layout tables. MSO pixel-density and PNG settings are present. Responsive breakpoints at 480px use `!important` overrides correctly.

---

### 4. Personalization & Merge Tokens

**[MEDIUM] Unfilled PromotionCard `image` field:**
```json
"@type": "PromotionCard",
"image": ""
```
Empty string — template placeholder was never populated. Gmail will discard the card.

**[MEDIUM] Unfilled DiscountOffer fields:**
```json
"description": "",
"discountCode": "",
"availabilityEnds": ""
```
Three fields left blank. Either intentional (no public code) or missed during production. The empty `availabilityEnds` may cause Gmail to ignore the offer annotation entirely.

**[LOW] `availabilityStarts` carries a 2020 date:**
```json
"availabilityStarts": "2020-03-06T06:00:00-04:00"
```
This is a stale template default, not the actual send date.

**Segmentation flag:** Header table `id="header-non-sc-member"` implies a ScoreCard-member variant exists. Only the non-member branch was provided for review; member variant parity could not be verified.

No unrendered merge token syntax (e.g., `{{first_name}}`, `[FNAME]`) observed in the visible HTML.

All links are wrapped in Epsilon `/T/` redirects. The redirects must be verified to append UTM parameters (e.g., `utm_source=email&utm_medium=email&utm_campaign=flash_sale`) before the destination URL. Without direct redirect inspection, UTM continuity is unconfirmed.
