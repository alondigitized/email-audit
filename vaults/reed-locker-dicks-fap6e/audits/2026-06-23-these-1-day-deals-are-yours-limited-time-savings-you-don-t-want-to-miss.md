# ⏳ These 1-day deals are YOURS + limited-time savings you don't want to miss. ⏳
**Score:** 7/10 · **Type:** Email audit · **2026-06-23**
## Executive summary

- This is the **third Deal Days email from DICK'S on June 23 alone** — following the launch send ("Our Biggest Sale of Summer is ON!") and the urgency reminder ("Tick, tock! ⏰"). The creative vehicle is familiar: the same green Deal Days header, the same "Our Biggest Sale of Summer" hero headline, and the same SHOP NOW button hierarchy. What's new and genuinely useful are the "TODAY ONLY" tagged product deals in a horizontal carousel near the top, and a secondary hook about 3/4 down — a green "EXTRA 30% OFF Select Clearance" banner. Those two additions are the email's only real differentiation from its predecessors.
- The layout is clean and the visual system is executed without bugs, but the email is trying to do too much: 1-day deals, "score even more" savings, seasonal drinkware, clearance blowout, and an app CTA are all competing for attention in one scroll. The 30% off clearance angle is the freshest value prop but it's buried below several product rows, meaning a lot of subscribers will never reach it.
- The core judgment: competent execution of a now-fatigued creative, sent at a cadence (3x in one day) that actively trains subscribers to stop opening. The "1-Day Deals" feature with TODAY ONLY tags is a strong structural idea that deserved its own isolated email earlier in the day — not a supporting act buried in a multi-section blast.

## What's working

- **"TODAY ONLY" tagged carousel** — product-level urgency with individual deal tiles is a good upgrade over generic "sale is on" hero copy; actually gives the subscriber a reason to click today specifically.
- **Green Deal Days visual system is coherent** — the brand event identity (color, typography, DEAL DAYS lockup) carries through without fragmentation.
- **"EXTRA 30% OFF Select Clearance" banner is a credible incremental hook** — clearance percentage off is a specific, honest value proposition that's different from the vague "savings" language in prior sends.
- **No render bugs visible** — clean layout, no overlapping elements, product images load correctly.
- **Multiple product categories represented** — fitness equipment, outdoor (Blackstone), drinkware, and baseball/softball give the email some breadth.

## What's weak

- **Third email in one day is cadence abuse** — by this point, subscribers are conditioned to ignore; even a subscriber who loves the brand will mentally file this as noise.
- **Hero headline is identical to the "Our Biggest Sale of Summer is ON!" send** — the subject implies new content ("1-day deals") but the hero doesn't reinforce that; opening feels like a repeat.
- **30% off clearance is buried** — the freshest, most concrete offer appears 3/4 down the email after multiple product rows; most mobile readers won't reach it.
- **"SHOP NOW" appears on every CTA** — no specificity: "Shop Grills," "Shop Nike," "Shop Clearance" would each create sharper click intent.
- **Subject line is bloated** — 74+ characters of combined generic copy ("limited-time savings you don't want to miss" is filler), and double hourglass emojis feel spammy at a glance.

## Recommendations

- 1. **Make this email only about 1-Day Deals** — strip it to the carousel + a single clearance CTA; the multi-category clutter dilutes the urgency the "TODAY ONLY" tags create.
- 2. **Surface the 30% off clearance above the fold** — lead with the most specific offer (a real percentage), then let the 1-day carousel serve as the supporting act below it.
- 3. **Diversify CTA copy** — replace all "SHOP NOW" instances with category-specific copy ("Shop Grills," "Shop Nike Apparel," "Shop Clearance 30% Off") to drive click specificity.
- 4. **Cut the send** — honestly, the highest-impact change is not sending a third email today. If you must send, time it as the only evening send after a full-day gap.
- 5. **Rewrite the subject to center the actual offer:**
- **Subject Alt A:** `TODAY ONLY deals inside + extra 30% off clearance ⏳`
- **Subject Alt B:** `1-day deals drop now — grab them before midnight`
- **Preheader Alt A:** `New Deal Days rotating picks — today's only around for hours.`
- **Preheader Alt B:** `Extra 30% off clearance + daily deals change at midnight.`

## Technical Audit

## Technical Audit: DICK'S Sporting Goods "Deal Days" Email

---

### 1. Technical Summary

Email is delivered via Epsilon/Harmony ESP (`e.dcsg.com` / `app.dickssportinggoods.com`) using standard table-based layout with MSO conditional comments. The most significant technical defect is invalid JSON in the `<script type="application/ld+json">` block, which will cause structured data to be silently dropped by all parsers.

---

### 2. Link & Tracking Issues

**No broken links confirmed from visible source.** All CTA links route through Epsilon's click-tracking redirect at `app.dickssportinggoods.com/T/v610000019ef61ec08c95e9926e96c660a0/...` — this is expected for the ESP.

**Concern — UTM passthrough not verifiable:** The Epsilon redirect wrapper obscures whether UTM parameters are appended server-side to destination URLs. If the redirect does not inject `utm_source`, `utm_medium`, and `utm_campaign` before handing off to `dickssportinggoods.com`, attribution in GA4/Adobe Analytics will be lost. This cannot be confirmed from HTML alone — requires a click-through trace.

---

### 3. Rendering & Accessibility

**Issue — Tracking pixel missing `alt` attribute:**
```html
<img src='https://app.dickssportinggoods.com/O/v610000019ef61ec08c95e9926e96c660a0/...'
  style="display:none; max-height: 0px; ..."/>
```
No `alt=""` on this hidden image. Screen readers and strict accessibility scanners will flag it. Fix: add `alt=""`.

**No issues** with MSO conditional comments — both `gte mso 9` and IE guards are present and properly formed.

**Concern — Google Fonts CDN dependency:**
The `@font-face` block loads Archivo from `https://fonts.gstatic.com/`. This CDN call is blocked by Gmail's image proxy in some configurations and by corporate firewalls. The Arial fallback will apply silently, which is acceptable, but the font load attempt generates an external request that some security tools flag.

---

### 4. Personalization & Merge Tokens

**Critical — Unfilled merge fields in JSON-LD:**

```json
{
  "@type": "DiscountOffer",
  "description": "",
  "discountCode": "",
  "availabilityStarts": "2020-03-06T06:00:00-04:00",
  "availabilityEnds": ""
}
```

- `description`, `discountCode`, `availabilityEnds` are all empty strings — unfilled template placeholders.
- `availabilityStarts` is hardcoded to **2020-03-06** — a 6-year-old stale date from a prior template. This is a template authoring defect, not a rendering issue, but it corrupts any inbox-level promotion card data.

```json
{
  "@type": "PromotionCard",
  "image": ""
}
```
- `image` is also an empty string — the Gmail Promotions tab card will have no image.
