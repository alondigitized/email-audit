# Don't wait! Score an EXTRA 25% off select clearance while you can...
**Score:** 7/10 · **Type:** Email audit · **2026-06-06**
## Executive summary

- This is the ninth execution of DICK'S Clearance's "Extra 25% off select clearance" creative since May 30 — and critically, the **second send today**, following this morning's "We can't let you miss an EXTRA 25% off select clearance!" (scored 6/10). The urgency language has escalated from "Score" to "Don't wait!" to "We can't let you miss" and back, but the underlying creative is identical. A subscriber who opened either of today's previous sends has no reason to engage with this one.
- The email itself is structurally competent. The red hero banner dominates correctly, multiple clearance categories (shoes, jackets, kayaks, headphones, baseball bats) are represented, and a Father's Day module appears at the bottom — the only genuinely new element from earlier sends this week. The layout is clean with no visible render bugs.
- The core problem isn't execution, it's fatigue. The brand has sent this offer so many times in seven days that even a motivated clearance shopper will scan the subject line, recognize the pattern, and delete without opening. Novelty has been completely burned off.

## What's working

- Red "EXTRA 25% OFF" hero banner is immediately dominant — offer is legible at a glance.
- Category breadth (shoes, outerwear, kayaks, electronics, baseball) serves a wide sports household.
- Father's Day module ("Father's Day by June 21") is a timely new addition that prior sends in this series lacked.
- SHOP NOW and VIEW DEALS dual-CTA structure keeps both intent levels covered.
- Clean layout with no broken images or overlapping elements.

## What's weak

- Second send today on the same creative — subscriber trust burns with every duplicate.
- Subject line ("Don't wait! Score an EXTRA 25% off…") is 70+ characters and truncates badly on mobile.
- "Don't wait!" urgency is completely unanchored — no end date or countdown is visible in the body.
- "EXTRA" in the subject is redundant caps noise after eight prior sends using the same word.
- The Father's Day module is buried below-the-fold rather than being surfaced as the differentiated hook in the subject.

## Recommendations

- 1. **Lead with Father's Day, not the repeat clearance hook.** "Dad's gift is on clearance — save 25% before June 21" tells a new story. The clearance offer stays but gets a reason.
- 2. **Set a hard deadline.** Pick a date (June 8, this Sunday, tonight midnight) and put it in the subject and hero. Without it, "Don't wait!" is hollow and no different from the last eight sends.
- 3. **Suppress this segment.** Anyone who clicked or opened the June 6 morning send should not receive a second identical email the same day. This is a list hygiene and suppression problem, not a copy problem.
- 4. **Retire "EXTRA 25% off" as the subject anchor.** Nine sends have burned this phrase. Rotate to "Up to 75% off" (visible in the body) or a specific category callout.
- **Subject Alt A:** `Father's Day gear: 25% off clearance, ends Sunday`
- **Subject Alt B:** `Up to 75% off — clearance prices drop tonight`
- **Preheader Alt A:** `Shoes, kayaks, bats, headphones — all on clearance this week`
- **Preheader Alt B:** `Find Dad's gift before June 21 — extra 25% off clearance`

## Technical Audit

## Technical Audit — DICK'S Sporting Goods Clearance Email

---

### 1. Technical Summary

The email uses a standard Epsilon/Harmony ESP stack with MSO conditional fallbacks and responsive mobile overrides. Two confirmed bugs: invalid JSON-LD that will silently fail structured data parsing, and a stale template date in the schema markup. Several empty schema fields suggest an incomplete production build process.

---

### 2. Link & Tracking Issues

**Tracking domain:** All links route through `app.dickssportinggoods.com` (Epsilon tracker). The logo href contains a `__dU__` parameter — confirm this is the correct personalization token for the deployed segment, not a template placeholder.

**UTM visibility:** The truncated source does not show UTM parameters on click-through links. If UTMs are being appended post-redirect by the ESP, verify `utm_source`, `utm_medium`, and `utm_campaign` survive the redirect chain. Cannot confirm from source alone.

**Tracking pixel:** `<img src='https://app.dickssportinggoods.com/O/v610000019e9e8e0feabdfe75f4bbc782e8/...'` is missing `alt=""`. Not a rendering issue (it's hidden), but will generate accessibility validator warnings.

---

### 3. Rendering & Accessibility

**MSO conditional CSS syntax error** — stale `"` character in the conditional stylesheet:
```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```
The trailing `"` before `}` is invalid CSS. Most Outlook versions will silently drop the entire `div` rule, which is the intended behavior anyway, but this indicates the template base is dirty.

**`role="presentation"` on all layout tables** — correct, no issues.

**`lang="en"` on `<html>`** — present, no issues.

**Logo `<img>` alt text** — source is truncated at the `src` attribute; alt text cannot be confirmed. Flag for manual check.

---

### 4. Personalization & Merge Tokens

**`id="header-non-sc-member"`** — the header block carries a conditional ID suggesting a ScoreCard member variant exists. Verify the suppression/swap logic is deployed and that SC members do not receive this non-member header.

**Empty `discountCode` field in DiscountOffer schema** — `"discountCode": ""` is unfilled. If this is a no-code promotion, the field should be omitted entirely, not sent as an empty string.

---

### 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)

Source is truncated and does not include the footer. Cannot verify:
- Physical mailing address (required, CAN-SPAM §5(a)(5))
- Unsubscribe mechanism (required, CAN-SPAM §5(a)(3))
- One-click List-Unsubscribe header (RFC 8058 / Gmail/Yahoo sender requirements)

**Action required:** Manually confirm footer and `List-Unsubscribe` / `List-Unsubscribe-Post` headers are present in the full deployed message.

---

### 6. Email-to-Site Continuity

Cannot confirm destination URL alignment without the full link set, but the ESP redirect pattern (`/T/` path) is consistent with Epsilon click tracking. If `utm_campaign` is set to a campaign ID that maps to the clearance landing page, verify the landing page is live and the extra 25% off is reflected in cart pricing — not just on the PDP.
