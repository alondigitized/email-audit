# 💰 Discover up to 50% off this week's DEALS!
**Score:** 7/10 · **Type:** Email audit · **2026-05-29**
## Executive summary

- This is DICK'S Sporting Goods' fifth consecutive nearly-identical deals blast this week, and the structural repetition is now a real liability. The bones are fine: a 50% OFF hero, multi-lane product grid covering sandals, resort shorts, Nike shoes, golf gloves, basketball hoops, and camping gear, with "SHOP NOW" buttons throughout. The offers are real and the layout is clean. But the May 27 "Best deals of the week" email and the May 28 "Our best deals just dropped" email had the same hero, the same multi-lane structure, and the same percentage range. At this point, the 50% OFF headline has been conditioned into background noise.
- The clearance cross-promo banner — "HUNDREDS OF NEW CLEARANCE STYLES" in the red mid-email module — is the most interesting editorial choice, and also the most confused one. The clearance sub-brand is already sending its own dedicated emails today. Injecting it into the middle of a deals digest turns both messages into something weaker: the main email loses editorial focus, and the clearance push loses its standalone impact.
- The email is competent and harmless. It's also the strongest current argument for unsubscribing.

## What's working

- **Specific percentage callouts by category** — "20% Off Select Sandals and Casual Shoes," "Up to $100 Off Select Basketball Hoops," and "Up to 50% Off Camping and Gear" are real signals, not just the vague hero figure.
- **Clean render, no broken assets** — layout holds with no overlapping text, missing images, or placeholder copy visible.
- **Category nav tabs** — Men / Women / Kids shortcuts at the top let the reader self-select without scrolling every lane.
- **Seasonal product mix** — resort collection and camping gear are contextually correct for late May.
- **50% OFF hero lands immediately** — field/sunrise creative reads clearly and the discount number is the first thing the eye hits.

## What's weak

- **"Discover" is the softest verb in a deals email vocabulary** — it signals leisure browsing, not urgency; it actively undersells a 50% offer.
- **The 50% OFF hero has been sent so many times this week it is now invisible** — May 27, 28 (twice), and now May 29 all lead with the same headline; repeat openers have been trained to discount it.
- **Clearance mid-email banner is an editorial collision** — inserting a separate sub-brand in the middle of a weekly deals digest confuses both messages; the main email loses focus and the clearance push loses isolation.
- **No single hero product** — seven simultaneous offer lanes with equal visual weight create decision paralysis; none of the deals is presented as *the* reason to click today.
- **"This week's" provides no credible deadline** — it reads as always-on, not expiring; there's no "ends Sunday" or specific date to create real urgency.

## Recommendations

- 1. **Pick one deal and make it the hero** — the basketball hoops at $100 off or 50% on camping are genuinely strong; lead with one, not seven.
- 2. **Replace "Discover" with a verb that matches the offer** — "Save," "Grab," or "Shop" all signal action; "Discover" signals a catalog.
- 3. **Remove the clearance mid-banner** — clearance is getting its own sends; the cross-promo dilutes both emails rather than amplifying either.
- 4. **Add an explicit deadline** — "Ends Sunday" converts "this week's" from ambient to actionable.
- 5. **Collapse to 3 strong lanes** — four product categories competing equally kills click decisions; consolidate and add depth to fewer offers.
- **Subject Alt A:** `Save up to 50% on camping, hoops + more — ends Sunday`
- **Subject Alt B:** `20% off Nike + half off camping — this week only`
- **Preheader Alt A:** `Ends Sunday: your picks from sandals, hoops, resort gear, and more`
- **Preheader Alt B:** `Camping at 50% off + $100 off basketball hoops inside`

## Technical Audit — DICK'S Sporting Goods Promotional Email

**ESP:** Epsilon/Harmony (`e.dcsg.com` sending domain, `app.dickssportinggoods.com` click/open tracking, `dsg.images.harmony.epsilon.com` image CDN)

### 1. Technical Summary

The email is structurally sound for major clients, but the JSON-LD structured data block contains fatal syntax errors that disable all Gmail Promotions tab annotations, and several schema fields are stale or empty — meaning the email renders as a plain promotional message in Gmail rather than with deal/discount cards.

---

### 2. Link & Tracking Issues

**No broken links detected** in the truncated source. All tracked links route through `app.dickssportinggoods.com/T/` (Epsilon click-tracker) with encoded `__dU__` subscriber tokens — expected for this ESP.

**One concern:** The open-tracking pixel `<img src='https://app.dickssportinggoods.com/O/v610000019e758e7ea2a8f205f4bbcfb920/...'/>` is missing an `alt=""` attribute. While hidden via `display:none`, strict accessibility parsers and certain security filters flag srcless or alt-less tracking pixels. Add `alt=""`.

The containing `<td id="ssl">` also carries a stale template comment: `<!--Replace/Paste SSL Here-->`. The pixel appears populated, but the comment signals the cell was a paste-target that wasn't cleaned up from the master template.

---

### 3. Rendering & Accessibility

**Duplicate `font-family` declaration** in the base stylesheet:

```css
body {
  font-family: Archivo, Arial, sans-serif;
  font-family: Archivo, Arial, sans-serif !important; /* redundant */
}
```

The first declaration is overridden by the `!important` version immediately after. The first line is dead code — remove it.

**`<link rel="icon">` in `<head>`** — ignored by every major email client and adds unnecessary payload. Strip it from the template.

**MSO conditional inconsistency:** The `<head>` block correctly uses `<!--[if (gte mso 9)|(IE)]>` with version qualifier. The body uses `<!--[if (gte mso)|(IE)]>` (no version). While functionally equivalent for modern Outlook, the inconsistency suggests different template fragments were merged. Normalize to `(gte mso 9)` throughout.

**Logo `<img>` src truncated** in the source provided — cannot confirm `alt` attribute. If missing, add `alt="DICK'S Sporting Goods"`.

### 6. Email-to-Site Continuity (UTM Params, Landing Page Alignment)

### 7. Recommendations

**Critical — fix before next send:**

1. **Invalid JSON-LD — kills all Gmail Promotions tab annotations.** The `<script type="application/ld+json">` block contains JavaScript-style `//` comments, which are illegal JSON syntax. Every major JSON parser (including Gmail's schema processor) will reject the entire block, disabling `DiscountOffer` deal cards and `PromotionCard` imagery in the Gmail Promotions tab.

   Affected lines (evidence):
   ```json
   { // GIF & WEBP images are not supported and will be filtered out.
     // Sample image is 538x138, 3.9 aspect ratio
     "@context": "http://schema.org/",
     "@type": "PromotionCard",
     // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
     "image": ""
   }
   ```
   Strip all `//` comments. JSON does not support comments.

2. **Stale and empty structured data fields.** Even after fixing comments, the schema fields are non-functional:

   | Field | Current value | Issue |
   |---|---|---|
   | `DiscountOffer.availabilityStarts` | `"2020-03-06T06:00:00-04:00"` | 6-year-old hardcoded date — offer is expired before it starts |
   | `DiscountOffer.availabilityEnds` | `""` | Empty — Gmail drops cards without a valid end date |
   | `DiscountOffer.discountCode` | `""` | Empty — required for deal card rendering |
   | `DiscountOffer.description` | `""` | Empty |
   | `PromotionCard.image` | `""` | Empty — no hero image will appear in Promotions tab |

   These fields must be populated per-send (ideally via ESP dynamic content) or the entire JSON-LD block should be removed to avoid silently broken schema.
