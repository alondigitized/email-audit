# 🕙 Time's running out to shop DICK'S Deal Days 🕙
**Score:** 8/10 · **Type:** Email audit · **2026-06-26**
## Executive summary

- This is a mid-day June 26 send — the warm-up to the same-day "HURRY...Deal Days end TODAY!" campaign close already audited at 9/10. The creative is solid: green hero, four specific percentage-off blocks (Titleist golf, Nike Club Fleece, Blackstone grills, GoPro/New Balance Golf), a Summer Shop section, and a "Must-have gear" shelf of individual products. The render is clean, the hierarchy reads properly, and the offers are real numbers.
- The problem is entirely in the subject line. "🕙 Time's running out to shop DICK'S Deal Days 🕙" is a word-for-word rerun of the June 25 send that scored 9/10 — same framing, same clock emoji bookends, just one day later. For anyone who got the June 25 email, this reads as duplicate mail before they even open it. When a deal has already been "running out" for 24 hours, the urgency deflates.
- The body delivers more than the subject earns. A subscriber who opens will find genuine value — four named brands with credible discounts. The failure is at the inbox level, where the subject invites deletion-by-pattern-recognition.

## What's working

- Four offer blocks with specific percentages (40%, 20%, 40%, 30%) and named brands — exactly the specificity that drove the June 24 brand-naming email to 9/10.
- Clean render: all images load, no overlapping text, no broken layout gaps.
- Visual hierarchy is tight — hero deal days branding locks the eye before the product grid.
- Offer variety (golf gear → apparel → grills → cameras/golf equipment) covers multiple buyer modes in one send.
- The Summer Shop category section (Summer Grilling / Outdoor Gear) extends browsing beyond the highlighted offers.

## What's weak

- Subject line is a near-exact repeat of the June 25 "Time's running out" send — subscribers who've been in the campaign since June 24 are conditioned to skip it.
- No specific end date or time-of-day deadline anchors the urgency in the body ("limited-time savings" is vague without a clock or end-time).
- "SHOP NOW" across all four offer CTAs is interchangeable — no offer-specific pull ("Shop Blackstone Grills" or "Shop Golf Deals" would create more intent).
- Cadence context is brutal: this is at minimum the twelfth Deal Days send across three days, landing between an already-fatigue-saturated June 25 and the campaign-close email later this same day.

## Recommendations

- 1. **Differentiate the subject from June 25.** The single highest-lift change is a subject that doesn't read as yesterday's rerun. If this is a morning send before the "end TODAY!" closer, lean into the sale's final day structure or name a specific brand.
- 2. **Add a time anchor in the body.** "Deals end tonight at midnight" or "Last day: June 26" turns "limited-time" from boilerplate into real urgency.
- 3. **Make CTAs offer-specific.** "Shop Titleist Deals" instead of "SHOP NOW" on the golf block; "Shop Grills" on the Blackstone block. Low engineering cost, higher intent signal.
- 4. **Consolidate the June 26 sends.** If the email program must send twice on the final day, give this one the specific-brand subject and save "end TODAY!" framing exclusively for the closer.

## Technical Audit

## Technical Audit — DICK'S Deal Days Email

---

### 1. Technical Summary

Table-based layout with Outlook conditional comments and Epsilon/Harmony tracking infrastructure. Three confirmed code-level defects: invalid JSON-LD that will break Gmail promo cards, unfilled template fields, and a CSS syntax error in the Outlook conditional block.

---

### 2. Link & Tracking Issues

**No broken links confirmed** in the visible source. All CTA and logo hrefs route through `app.dickssportinggoods.com/T/...` (Epsilon redirect layer) — standard for this ESP.

**Tracking pixel** (`id="ssl"`) at `https://app.dickssportinggoods.com/O/v610000019f047b0f1a9a9ab5369ff04b84/...` is missing `alt=""`:
```html
<img src='https://app.dickssportinggoods.com/O/...' style="display:none; ..."/>
```
Some spam filters score hidden images without an alt attribute more aggressively.

**UTM passthrough** cannot be confirmed — Epsilon redirect URLs obscure destination params. Verify that `utm_source`, `utm_medium`, `utm_campaign` are appended at redirect resolution and survive to the landing page.

---

### 3. Rendering & Accessibility

**Outlook conditional CSS — syntax error.** The `div` rule has a stray `"` before the closing brace:

```css
div {background-color:inherit; font-size:0; line-height:100%; margin:0; padding:0;"}
```

The trailing `"` is invalid and may cause the entire `<![if (gte mso 9)|(IE)]>` stylesheet block to be dropped, breaking layout in older Outlook versions.

**Dark mode**: No `<meta name="color-scheme">` or `<meta name="supported-color-schemes">` present. Background is hardcoded `#F5F5F5` / `#FFFFFF` without dark-mode overrides — renders poorly in Apple Mail dark mode.

**Logo `<img>` tag** is truncated in the source provided; cannot confirm presence of `alt` attribute. Flag for verification.

`role="presentation"` is correctly applied to all layout tables. `<html lang="en">` is set.

---

### 4. Personalization & Merge Tokens

**Critical — JSON-LD contains JavaScript-style comments**, which are not valid JSON:

```json
{ // GIF & WEBP images are not supported and will be filtered out.
  // Sample image is 538x138, 3.9 aspect ratio
  "@type": "PromotionCard",
  // DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!
  "image": ""
}
```

`//` comments cause JSON parsers to reject the entire `<script type="application/ld+json">` block. Gmail's promotional tab card rendering will silently fail — no promo card will appear.

**Unfilled template fields** in the same block:

| Field | Value | Issue |
|---|---|---|
| `DiscountOffer.description` | `""` | Empty |
| `DiscountOffer.discountCode` | `""` | Empty |
| `DiscountOffer.availabilityEnds` | `""` | Empty |
| `DiscountOffer.availabilityStarts` | `"2020-03-06T06:00:00-04:00"` | **Stale 2020 date — never updated from template baseline** |
| `PromotionCard.image` | `""` | Empty — designer instruction left in production send |

Even if the `//` comments were removed, the `availabilityStarts` date from 2020 and empty `availabilityEnds` would render the offer card invalid.

The `availabilityStarts: 2020-03-06` in JSON-LD means Gmail may classify this as an expired offer, potentially deprioritizing promo tab placement.
