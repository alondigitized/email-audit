# Find up to 50% OFF this week's DEALS
**Score:** 5/10 · **Type:** Email audit · **2026-08-27**
## Executive summary

- Same green-locker "UP TO 50% OFF" hero DICK'S has run on repeat since 8/16 — this is at minimum the sixth near-identical version of this creative this month, and the subject ("Find up to 50% OFF this week's DEALS") is one of the most generic yet, with no specific product, category, or deadline to differentiate it from yesterday's "Flash Sale" or the day before's near-identical send.
- The body is a well-organized category browser — Men's/Women's/Kids'/Team Sports/Golf, each with clean lifestyle-plus-product-shot pairing and its own "Shop Now" — and the layout renders cleanly with no visual bugs. But it's structurally identical to prior sends: locker hero up top, category grid, red clearance banner at the bottom. A subscriber who's opened three of these this week has seen this exact shape already.
- This is a functional, on-brand email that will underperform because of fatigue, not execution. Judgement: ship it if it must go out, but the brand needs a genuinely different hero and subject before the next send — this well is dry.

## What's working

- Clean render — no overlapping text, broken images, or layout breaks anywhere in the scroll.
- Category grid (Men's, Women's, Kids', Team Sports, Golf) is well-organized with a clear product shot + lifestyle shot pairing per section.
- Each category card has its own unambiguous "Shop Now" CTA, reducing friction to a specific category.
- ScoreCard loyalty points balance is visible at the top ("300 Points · 410 Points til Reward"), a nice personalized touch.
- Order-ahead convenience line (same-day delivery, in-store pickup) adds a secondary utility hook beyond the discount.

## What's weak

- Subject is the vaguest version of this promo yet — "this week's DEALS" gives no product, category, or urgency signal, worse than 8/26's "Flash Sale... ends tonight."
- Hero creative (green locker + "UP TO 50% OFF") is a near-duplicate of at least five prior sends this month — zero visual differentiation in the inbox history.
- No visible preview/preheader text complementing the subject — nothing to add context before open.
- No countdown timer or explicit deadline anywhere in the hero or fine print, despite "this week's" implying time-boundedness.
- Bottom clearance banner ("UP TO 60% OFF SELECT CLEARANCE") duplicates the top hero's exact format (bold %, red/dark background), so the email essentially pitches the same "big percentage on colored background" beat twice.

## Recommendations

- 1. Replace the locker-room hero entirely — this exact motif is burned out after 5+ repeats this month. Lead with an actual product hero (e.g., the golf or back-to-school imagery already in the body) paired with a specific offer.
- 2. Make the subject concrete: name a category or anchor a real deadline instead of generic "this week's DEALS."
- 3. Add preview text that names a specific category or bestseller, distinct from the subject, to give the inbox line a reason to open.
- 4. Differentiate the top hero from the bottom clearance banner — right now they're visually redundant beats.
- 5. Add a real countdown or explicit end-date since "this week" implies urgency the email doesn't back up.

## Technical Audit — DICK'S Sporting Goods "Find up to 50% OFF this week's DEALS"

### 1. Technical Summary
Email sends via Salesforce Marketing Cloud (`app.dickssportinggoods.com` tracking links, `dcsg.com` sending domain) with Scene7/Epsilon asset hosting. ### 3. Rendering & Accessibility
- 10 images flagged with missing `alt` attributes, including all four hero/category banners (`storewide-4pm-mens-new`, `-womens-new`, `-kids-new`, `-sports-new`) and the tracking pixel, plus five footer icon images (SMS, SportsMatter, BPG, Favorite, Location). Screen readers and blocked-image fallbacks will render this content as blank.
- MSO/Outlook conditional comments present and well-formed (`<!--[if (gte mso 9)|(IE)]-->`), with a ghost table wrapper for Outlook layout — no issue.
- Responsive rules (`@media screen and (max-width:480px)`) are scoped correctly with `!important` overrides for mobile — no issue.
- Web font (`Archivo`) is loaded via `@font-face` inside a `@media screen` query with `Arial` fallback in the base `font-family` stack — correct progressive-enhancement pattern, no issue.

### 4. Personalization & Merge Tokens
- No visible unresolved merge tags (e.g. `%%FirstName%%`, `{{...}}`) in the visible source provided.
- The embedded `ld+json` block contains empty/placeholder fields (`"discountCode": ""`, `"image": ""` for the `PromotionCard` type, and stale `availabilityStarts": "2020-03-06..."`) — these are internal ESP template scaffolding comments (`// DESIGNER, ADD YOUR PROMO IMAGE URL BELOW!`) left unpopulated. Also note: the JSON contains `//` comments, which is invalid JSON — any consumer strictly parsing this `application/ld+json` block will fail to parse it.

### 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- Unsubscribe link is broken (see §2) — this is a CAN-SPAM functional failure, not just a UX bug, since the mechanism must work.
- `List-Unsubscribe` header not present in the captured headers (QA WARN) — no in-client one-click unsubscribe available; may be relay-side capture rather than a true absence.
- `List-Unsubscribe-Post` (RFC 8058) not found — one-click unsubscribe unsupported, which Gmail/Yahoo bulk-sender requirements expect as of their 2024 policies.
- `Authentication-Results` header not found — SPF/DKIM pass/fail status could not be verified from available data; flag as unknown rather than fail.

### 6. Email-to-Site Continuity (UTM params, landing page alignment)
- All observed CTA and logo links route through SFMC click-tracking redirects (`/T/...`) rather than direct UTM-tagged URLs, so final landing-page UTM parameters aren't visible in the truncated source — cannot confirm alignment.
- The one link whose final destination is known (unsubscribe) lands on a broken/error path, confirming at least one tracking-redirect misconfiguration exists in this send.

### 7. Recommendations
1. Fix the unsubscribe redirect mapping so `/U/...` resolves to `/pc/subscription` (or correct path) instead of `/pc/Error/Error?aspxerrorpath=/pc/subscription`.
2. Add `alt` text to all 10 flagged images, prioritizing the four hero category banners (currently zero accessible content if images are blocked).
3. Implement `List-Unsubscribe` and `List-Unsubscribe-Post` headers to meet RFC 8058 one-click unsubscribe requirements.
4. Verify SPF/DKIM/DMARC alignment produces a visible `Authentication-Results` header (or confirm this is an artifact of the AgentMail relay rather than the original send).
5. Remove the invalid `//` comments from the `application/ld+json` block or strip unused placeholder fields (`discountCode`, `image`) so the structured data is valid, parseable JSON.
6. Populate or remove the stale `availabilityStarts: "2020-03-06"` value in the `DiscountOffer` schema block.
