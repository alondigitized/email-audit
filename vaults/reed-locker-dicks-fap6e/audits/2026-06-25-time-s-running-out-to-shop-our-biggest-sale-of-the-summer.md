# Time's running out to shop our biggest SALE of the summer! ☀️⏰
**Score:** 9/10 · **Type:** Email audit · **2026-06-25**
## Executive summary

- This is the urgency-close installment of DICK'S Deal Days — by the brand history count, roughly the eighth or ninth email in this campaign across three days. The subject line ("Time's running out...") is a near-rerun of June 23's "Tick, tock! ⏰" send and communicates nothing that prior sends haven't already said. The visual system — green DEAL DAYS hero, category nav tiles, green SHOP NOW button, product card grid — is pixel-for-pixel identical to the previous seven sends.
- What distinguishes this one: the body contains "today's the last day!" which, if true, is the first credible deadline in the entire campaign rather than manufactured urgency. And the Extra 30% Off Select Clearance is a genuinely new offer type — clearance-specific markdown that hasn't headlined any prior send in this series.
- The critical failure is that both of those hooks are buried. "Today's the last day" doesn't appear in the subject; "Extra 30% Off Clearance" is two-thirds down the scroll. The subject could have been written by an algorithm averaging the previous eight sends, and it reads that way.

## What's working

- "Today's the last day!" in the body is the most credible urgency signal this campaign has produced — specific, presumably true, and not manufactured.
- Extra 30% Off Select Clearance is a genuinely new offer type; clearance shoppers have a real reason to click that the mid-week sends didn't provide.
- Product cards with anchored starting prices ($18.00, $5 select items) give concrete value signals beyond percentage banners.
- The green DEAL DAYS visual system loads instantly recognizable — zero cognitive overhead for returning subscribers.

## What's weak

- Subject is a generic urgency rehash — it could have been swapped for "Tick, tock!" from June 23 without anyone noticing; neither the closing date nor the clearance offer appear in it.
- Subject is ~61 characters, well over the ~50-char mobile threshold; the back half truncates in most clients.
- Extra 30% Off Clearance — the most compelling new offer — is buried roughly two-thirds down the scroll, well below where most subscribers will bail.
- No loyalty or ScoreCard member benefits visible anywhere in the render; a meaningful loyalty nudge here would separate deal-seekers from the general blast.

## Recommendations

- 1. **Rewrite the subject to surface "last day" and "30% off clearance" — both of the things that actually make this send different from the previous eight.** The two differentiators are real; the subject wastes them.
- **Subject Alt A:** `Last day: Extra 30% off clearance + today's deals`
- **Subject Alt B:** `Deal Days ends today — clearance now 30% off`
- **Preheader Alt A:** `Final hours on Deal Days. Clearance just got an extra 30% off.`
- **Preheader Alt B:** `Shop clearance before it closes — extra 30% off today only.`
- 2. **Promote the Extra 30% Off Clearance module to the hero or second position.** The most novel offer in the email is buried; swap it to the first scroll-visible module so clearance-hunters don't miss it before they bounce.
- 3. **Cut two of the four body sections.** A "last day" urgency email doesn't need 1-day deals, limited-time savings, clearance, AND must-have summer gear simultaneously — it needs one clear CTA with velocity behind it. Consolidate to closing deals + clearance.
- 4. **Add a ScoreCard member call-out.** Any loyalty tier benefit (early close access, extra points on clearance) would separate subscribers who have a reason to buy today from those who are just browsing.

### 1. Technical Summary

The email uses a standard Epsilon/Harmony table-based layout with proper doctype, charset, viewport, and MSO conditionals. Two confirmed code defects stand out: invalid JSON-LD (JS-style comments + stale 2020 date) and a CSS syntax error in the MSO conditional block that will affect Outlook rendering.

### 2. Link & Tracking Issues

**No broken links visible in the truncated source.** All CTA hrefs route through Epsilon's click-tracking domain (`app.dickssportinggoods.com/T/v610000019efe57acbc938a7d6e966eb1e0/...`), which is expected.

**Cannot confirm UTM parameter passthrough** — final redirect destinations are not visible in the truncated HTML. See §6.

---

### 3. Rendering & Accessibility

**MSO conditional CSS — stray `"` character (confirmed bug):**
```html
<!--[if (gte mso 9)|(IE)]><style>
  div {background-color:inherit; ... padding:0;"}
</style><![endif]-->
```
The closing `"` before `}` is a CSS syntax error. Outlook's MSO engine may drop the entire `div` rule or misparse surrounding rules, causing layout shifts in Outlook 2016–2021.

**Tracking pixel missing `alt` attribute:**
```html
<img src='https://app.dickssportinggoods.com/O/...' style="display:none; ..."/>
```
`alt=""` is absent. Screen readers and strict HTML validators will flag this. Should be `alt=""` explicitly.

**Google Fonts Archivo pinned to `v7`:**
```
url(https://fonts.gstatic.com/s/archivo/v7/k3kQo8UDI-1M0wlSfdnoLmvDIaI.woff2)
```
Archivo is now at v20+. The v7 URL is still served by Google's CDN but is a stale pin — if Google rotates or deprecates the hash-based v7 path, the fallback font (Arial) activates silently. Low urgency, but worth updating to the current variable-font URL.

**`role="presentation"` on all layout tables:** Correctly applied.
**`lang="en"` on `<html>`:** Present.

### 5. Compliance

**JSON-LD block is invalid JSON (confirmed bug):**
```js
<script type="application/ld+json">
[{
  // GIF & WEBP images are not supported...  ← JS comment, not valid JSON
  "@type": "PromotionCard",
  "image": ""   ← empty required field
}, {
  "@type": "DiscountOffer",
  "availabilityStarts": "2020-03-06T06:00:00-04:00",  ← stale placeholder
  "availabilityEnds": "",   ← empty
  "discountCode": "",       ← empty
  "description": ""         ← empty
}]
</script>
```

Three distinct issues:
- **`//` comments are not valid JSON.** The script block will fail JSON parsing in any Gmail client that attempts to render the promo annotation. The `PromotionCard` annotation will not appear in Gmail's Promotions tab as a result.
- **`availabilityStarts: "2020-03-06"`** is a stale template value from 2020. This will cause the `DiscountOffer` structured data to appear expired to any parser that validates it.
- **`"image": ""`** on `PromotionCard` — an empty image URL means Gmail's native promo card image will not render even if the JSON is fixed.

**CAN-SPAM / unsubscribe:** The HTML is truncated before the footer — cannot confirm physical address or unsubscribe link presence from source provided. These are required; the audit team should verify in the full source.

**Sending domain:** `DSG@e.dcsg.com` — `e.dcsg.com` is a legitimate Epsilon-managed subdomain for DCSG. SPF/DKIM/DMARC alignment should be verified against `dcsg.com`'s published DNS records; cannot confirm from HTML source alone.
