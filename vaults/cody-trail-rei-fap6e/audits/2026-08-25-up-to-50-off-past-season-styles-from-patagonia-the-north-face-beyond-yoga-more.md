## Technical Audit

1. Technical Summary
The email is a standard MJML-generated responsive template using REI's mLinks click-tracking redirector and AppsFlyer mobile deep-linking; automated QA found widespread link-check failures (likely a timeout/probing artifact rather than confirmed dead links), systemic doubled-domain merge errors in mobile deep-link URLs, missing compliance headers, and several image/accessibility gaps.

2. Link & Tracking Issues
- All 10 probed CTA/body links plus the Unsubscribe link returned `[FAIL] The read operation timed out` against `mlinks.rei.com/a/zc/24132/...` redirect URLs. This pattern (100% of probed links, including unsubscribe, all on the same tracking domain) is consistent with the mLinks redirector rate-limiting or blocking the QA prober rather than each individual link being broken — but it cannot be confirmed as healthy from this data alone and should be manually verified before send.
- Doubled-domain merge error (14 instances): AppsFlyer deep-link URLs are malformed — the `af_r` and `deep_link_value` parameters contain unencoded `https://www.rei.com/...` values concatenated directly onto the `mobile.rei.com/AkCd/?af_r=` base without URL-encoding, e.g.:
  `https://mobile.rei.com/AkCd/?af_r=https://www.rei.com/f/scd-deals?cm_mmc=...&deep_link_value=/f/scd-deals?cm_mmc=...&pid=email_com_gm_it&c=...`
  Because `af_r` is not percent-encoded, the nested query string (`cm_mmc=...`) breaks out into the top-level query params, corrupting `cm_mmc` attribution and any params after it. This affects at least 4 distinct destination targets (`/f/scd-deals`, `/c/footwear/f/scd-deals`) across CTA and Image links.

3. Rendering & Accessibility
- 5 images missing `alt` text: two `sp.rei.com` tracking/content pixels, the `mlinks.rei.com/e/eo` open-tracking pixel, and two `mi.rei.com/p/cp/.../o.gif` pixels (one with a malformed path — `/p/cp//o.gif`, empty segment between double slashes).
- 2 images served over `http://` instead of `https://` (`sp.rei.com/q/pgHR3PZ5v8CBFngRZYg7Rw~~/...` and `sp.rei.com/q/ISkQnADzBlsoVyhG19IaOg~~/...`), which mail clients enforcing mixed-content/TLS policies may block, causing broken images.
- Template uses standard MSO conditional comments and `mj-column-per-*` responsive classes; no other structural rendering issues surfaced by QA.

4. Personalization & Merge Tokens
- No unresolved merge tokens (e.g. `{{...}}`, `%%...%%`) detected in the visible HTML/QA output.
- The `mi.rei.com/p/cp//o.gif` pixel has an empty path segment (`cp//o.gif`) where a merge value (likely a customer/campaign ID) appears to have failed to populate — worth confirming against the working `mi.rei.com/p/cp/703f865d19a48d73/o.gif` pixel in the same email, which populated correctly.

5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- Unsubscribe link is present in the HTML (`mlinks.rei.com/e/eh?...`), satisfying the visible-unsubscribe-link requirement, though it also returned a timeout in the link probe (see §2).
- `List-Unsubscribe` header: not found — QA notes this may be a relay capture limitation rather than a true absence; cannot confirm compliance either way from this data.
- `List-Unsubscribe-Post` (RFC 8058 one-click unsubscribe): not found — same caveat as above.
- `Authentication-Results` (SPF/DKIM): not found — same relay-capture caveat; SPF/DKIM pass/fail status is unknown from this data.

6. Email-to-Site Continuity (UTM params, landing page alignment)
- Campaign tracking uses `cm_mmc` (not standard `utm_*`) params, consistently formatted as `email_com_gm_it-_-20260825_CLR_FW34_z_z_z-_-202608250924-_-26_{n}_401_{id}_z_{Placement}` across CTAs — internally consistent naming/placement scheme.
- Destination paths (`/f/scd-deals`, `/c/footwear/f/scd-deals`) are broken by the doubled-domain/unencoded-parameter bug in §2, meaning `cm_mmc` attribution will not reliably reach the landing page for users on the AppsFlyer mobile deep-link path.

7. Recommendations
- Fix the AppsFlyer deep-link generation to URL-encode the `af_r` and `deep_link_value` parameter values before appending them to `mobile.rei.com/AkCd/?...` — this is the highest-priority fix, affecting attribution on every mobile CTA/image link tied to `/f/scd-deals` and `/c/footwear/f/scd-deals`.
- Manually verify (outside the automated prober) that the `mlinks.rei.com` links actually resolve — the 100%-timeout pattern including the unsubscribe link suggests a prober-side block, but this should not be assumed without a manual check given unsubscribe compliance is at stake.
- Add `alt` text to the 5 flagged images, including the two tracking pixels and `mlinks.rei.com/e/eo`.
- Serve the two `sp.rei.com` images over `https://` instead of `http://`.
- Investigate the empty path segment in `mi.rei.com/p/cp//o.gif` — likely a missing merge value.
- Confirm with the ESP/relay whether `List-Unsubscribe`, `List-Unsubscribe-Post`, and `Authentication-Results` headers are genuinely absent or simply not captured by the AgentMail relay, since these directly affect CAN-SPAM one-click unsubscribe and deliverability posture.
