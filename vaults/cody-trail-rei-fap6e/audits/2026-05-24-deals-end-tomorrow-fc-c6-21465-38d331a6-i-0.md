# Deals end tomorrow!!! 😰
**Score:** 6/10 · **Type:** Email audit · **2026-05-24**
## Executive summary

- REI is in full panic-mode urgency now — "Deals end tomorrow!!!" with triple exclamations and a sweating-face emoji, plus a countdown timer that's hit `0:00:00` in the hero. That zeroed-out timer is a real render bug; if a recipient opens this and sees 0:00:00, they assume the sale already ended. Either the timer JavaScript didn't render in this client or the hero needs a different fallback state.
- This is the eighth or ninth Anniversary Sale email in roughly twelve days, and the creative is starting to feel like recycled scaffolding: 20% off coupon block, "Popular picks, going fast" grid, "Up to 50% off past-season styles," NEMO spotlight at the bottom. All the right pieces, but the subject line has crossed into spammy territory ("!!!" + 😰 emoji) and the preview is just sale-end repetition.
- Verdict: solid merchandising, but the broken countdown and shouting subject line drag this down. For a Walker-persona shopper this still has the comfort-tier picks (camp chairs, sleeping pads, NEMO) that matter, but the urgency feels manufactured rather than earned.

## What's working

- Coupon code `ANNIV26` is visible, simple, and worth 20% off a full-price item — a concrete, claimable mechanic.
- "Popular picks, going fast" grid shows real categories (camp chairs, tents, sleeping pads) with clear 25%/40% off badges.
- Members Save More callout is present near the hero, reinforcing loyalty value.
- "Up to 50% off past-season styles" panel with the Patagonia/Marmot/Columbia/prAna brand row is a strong secondary lane.
- NEMO 25% off bottom feature gives one clear category-led close.

## What's weak

- Countdown timer reads `0:00:00` — visual bug that makes the email look expired before the recipient even reads it.
- Subject line "Deals end tomorrow!!!  😰" stacks three exclamations + a stress emoji — pure spam-filter bait and tonally desperate.
- This is roughly the ninth Anniversary Sale email in twelve days; the creative is repeating itself with diminishing returns.
- Preview text appears to be sale-ending fluff that just echoes the subject rather than adding a hook.
- Hero hierarchy is muddy — "Deals end really soon" + zeroed timer + coupon block + member badge all compete for the first glance.

## Recommendations

- 1. **Fix or replace the timer.** A 0:00:00 hero is worse than no timer. Either ensure it renders live in the client or swap to a static "Ends 5/25 at 11:59pm PT" line.
- 2. **Strip the subject of "!!!" and 😰.** One exclamation max, no anxiety emoji — REI's brand voice doesn't beg.
- 3. **Lead the body with the 20% coupon, not the countdown.** Promo code `ANNIV26` is the actual value lever; make it the hero, with the deadline as supporting copy.
- 4. **Cut the "Popular picks" grid for this final send and lean into one persona-fit hero** (sleeping pads + camp chairs for the comfort crowd) — closing emails convert better when narrowed.
- 5. Subject and preheader alts:
- **Subject Alt A:** `Last day for 20% off — code ANNIV26`
- **Subject Alt B:** `Anniversary Sale ends tomorrow night`
- **Preheader Alt A:** `Use ANNIV26 at checkout. Members save more.`
- **Preheader Alt B:** `One full-price item, 20% off. Ends Sunday 11:59pm PT.`
