# New workout styles that go beyond
**Score:** 7/10 · **Type:** Email audit · **2026-07-21**
## Executive summary

- This is lululemon's July 21 new-arrivals editorial — a summer sets launch featuring sweat-wicking fabric as the hero narrative. It's a clean, on-brand send that continues the post-Summer-Sale pivot we first saw in the July 14 French Terry email (scored 7/10), which the brand signaled as a deliberate return to full-price editorial mode. Same playbook here: lifestyle photography, a single functional claim, small text CTAs pointing to the new-arrivals feed.
- The problem is the subject. "New workout styles that go beyond" is lululemon's blandest register — "beyond" lands nowhere. No urgency, no collection name, no benefit hook. After the Summer Sale drumbeat that ran through July 16, subscribers know this brand can be specific when it wants to be (see July 11's "Summer Sale faves, moving fast" scoring 8/10 for exactly that reason). Dropping that specificity now feels like a missed opportunity.
- The email renders cleanly but converts weakly. No price, no deadline, no reason this week beats next week. It earns a look but not a click.

## What's working

- **Hero narrative is tight.** "Summer sets, in." + "When your reps heat up, sweat-wicking fabric powers through." is concise and product-led — one claim, one category, done.
- **Multi-image editorial grid** shows the sets from multiple angles and on multiple models without feeling like a catalogue dump.
- **Brand render is clean.** No layout breaks, no overlapping text, no broken images — the email just works visually.
- **"Shop new styles this week."** is a light but effective mid-email break that organizes the product grid without overselling.
- **Seasonal coherence.** Stadium stairs, heat-wicking fabric, summer color palette — all cohesive and timely for late July.

## What's weak

- **Subject is vague to the point of inaction.** "That go beyond" says nothing — beyond what, beyond where? Every lululemon email could use this copy.
- **No CTA buttons visible** — only small text links beneath the hero copy. A subscriber who scrolls past that paragraph has no anchor to pull them back.
- **No price or offer.** After weeks of Summer Sale conditioning, a full-price email with zero incentive and zero scarcity needs stronger editorial pull to compensate.
- **Product tiles in the lower grid are tiny** — four small images with no visible price, no product name callout, no size/fit context at glance.
- **No preheader** (or leaking first-text) — the visual email opens cold with the lululemon logo; whatever preview text lands in the inbox is likely "Summer sets, in." which only partially complements the subject rather than extending it.

## Recommendations

- 1. **Rewrite the subject to name the specific benefit or collection.** "Beyond" is placeholder copy. Tie it to heat, sweat, or the sets theme.
- **Subject Alt A:** `Summer sets built for the heat`
- **Subject Alt B:** `New: sweat-wicking sets for peak summer`
- 2. **Add an explicit preheader that bridges subject to hero.** Right now the first visible text ("Summer sets, in.") will likely bleed as preview — it's fine but redundant with Alt A above.
- **Preheader Alt A:** `Fabric that works as hard as you do — shop new arrivals`
- **Preheader Alt B:** `Just dropped: sets made for sweaty season`
- 3. **Swap at least one text-link CTA for a visible button** in the hero section. The inline "Shop Now" text is too easy to scroll past.
- 4. **Add product name + price to the lower grid tiles.** Four mystery thumbnails with no context are low-conversion. Even adding the collection name ("Align Set — $148") would lift CTR.
- 5. **Create a lightweight urgency hook.** Not a fake deadline, but something like "New this week" or "Limited colorways" — the brand has enough equity that scarcity framing lands cleanly without feeling manipulative.

### 3. Rendering & Accessibility

**Bug — invalid `letter-spacing` values on `.guest-voice-*` classes:**

```css
.guest-voice-lg { letter-spacing: -2%; }
.guest-voice-md { letter-spacing: -2%; }
.guest-voice-sm { letter-spacing: -1%; }
```

`letter-spacing` does not accept percentage values in CSS. All three will silently fall back to `normal` letter-spacing in every email client. Intended value is likely `-0.02em` / `-0.01em`.

**Bug — `supported-color-schemes` declared inside `:root` CSS block:**

```css
:root {
  color-scheme: light dark;
  supported-color-schemes: light dark;  /* not a valid CSS property */
}
```

`supported-color-schemes` is valid only as a `<meta>` attribute (already present correctly elsewhere in the head). The `:root` declaration is a no-op and will be ignored by all CSS parsers. No functional impact, but it's dead code that suggests a copy-paste error.

**`#000001` background for `.black` class:**

```css
.black { background-color: #000001; }
```

Off-by-one from true black `#000000`. This is a known workaround to prevent certain email clients from treating a pure-black `#000000` as transparent, so it may be intentional — but should be documented internally to avoid future "is this a bug?" confusion.
