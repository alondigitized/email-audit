# Catch the latest restock

- This is a lululemon restock-notification email anchored on the Define Cropped Jacket in *Nulu, with a supporting grid of six restocked women's SKUs — wide-leg pants, a Like a Cloud bra, Align Ribbed Cami Dress, Align shorts, Steady State shorts, and Track That shorts. - The problem is that the scarcity promise is too vague to convert. - The execution is clean and the brand voice is intact. But this reads like a filler send between launches rather than a purposeful restock alert.

- Scarcity framing is a genuine creative variation after four consecutive new-product-launch sends; it's a different and valid reason to email.

- "Members shop first" + Early Access: Citrus Sizzle is a legitimate membership hook that rewards loyalty subscribers.

- Subject line names nothing — "Catch the latest restock" could come from any apparel brand and gives a subscriber no reason to prioritize opening.

- No pricing visible anywhere in the email — not even a "from $X" anchor to calibrate the offer.

- 2. **Make Citrus Sizzle the lead or give it its own send** — early access is a membership retention signal and it's been buried. If it's included here, it should be the secondary hero, not footer filler.
- 3. **Add a real scarcity signal** — "Back for 72 hours" or "Limited sizes remaining" makes the urgency credible. Right now it's a claim with no backing.

### 3. Rendering & Accessibility

**`letter-spacing` uses invalid percentage values**
```css

.guest-voice-md { letter-spacing: -2%; }
.guest-voice-sm { letter-spacing: -1%; }
```
`letter-spacing` accepts only `<length>` values (`px`, `em`) or `normal` — percentages are not valid per the CSS spec and will be silently ignored by all email clients. The intended tracking compression on these display classes will not render.

Applied to `p`, `ul`, `ol`, `li`, `h1`–`h5`, and multiple named classes. CSS Fonts Level 4 permits arbitrary numeric weights for variable fonts, but email client support is inconsistent. Clients without variable-font support will round to `400` (normal), which may shift visual weight noticeably.
