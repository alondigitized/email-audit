# XPLR Pass exclusive: Spend $150+ & get 20% off.
**Score:** 7/10 · **Type:** Email audit · **2026-05-23**
## Executive summary

- This is a loyalty recruitment email masquerading as a member exclusive — and that confusion is its biggest problem. The subject line says "XPLR Pass exclusive" which telegraphs insider treatment, but the hero CTA says "Join Now," which is a non-member recruitment call. An existing XPLR Pass member opens this expecting a reward and gets a sign-up pitch instead. An attentive subscriber also knows the 25% off deal from May 14 and 16 is a better offer than today's 20% off $150+ threshold — the campaign is subtly degrading its own incentive.
- There's a functional second email buried underneath: the "Up to 25% Off Select Gear / Shop Sale" section is clean, credible, and seasonally anchored. If that had led the email, this would score higher. Instead it sits below a confusing XPLR hero that sends loyal customers hunting for the real offer.
- Six promotional TNF emails in nine days — all repeating ENDS 5.25 — is also compressing the urgency signal. The deadline feels less like a hard stop and more like wallpaper at this point.

## What's working

- Subject line is specific, under 50 chars, and delivers a concrete number — strong inbox performance expected.
- Dark hero section creates sharp visual contrast; the offer hierarchy (headline → body → CTA) is legible at a glance.
- "Shop Sale" CTA in the second section is the clearest, most honest call to action in the email.
- ENDS 5.25 deadline is consistently applied across both sections, reinforcing the campaign arc.
- No render bugs — images load, text doesn't overlap, layout holds.

## What's weak

- "MEMBER EXCLUSIVE" header + "Join Now" CTA is a direct contradiction — the email signals exclusivity to existing members, then asks them to join.
- 20% off $150+ is a step down from the 25% off that led both May 14 and May 16 sends; loyal subscribers will notice the offer degraded.
- The blue jacket product image is large and prominent but appears to link to a general sale, not that specific jacket — wasted real estate.
- "Summer adventures await with savings on must-have activewear, trail shoes and more" is generic filler that adds no buying incentive.
- Six emails in nine days with the same ENDS 5.25 anchor has flattened urgency — the deadline no longer lands as pressure.

## Recommendations

- 1. **Pick an audience and commit.** If this email is for existing XPLR members, the hero CTA should be "Shop Your Exclusive Offer," not "Join Now." If it's recruitment, drop "MEMBER EXCLUSIVE" from the banner. The contradiction is the single biggest lift available.
- 2. **Lead with Shop Sale, not loyalty recruitment.** The "Up to 25% Off" section is the stronger shopping hook — put it at the top, make the jacket image link to a specific product, and move XPLR recruitment to a secondary module below.
- 3. **Refresh the urgency copy.** After nine days of "ENDS 5.25," change the framing to something like "Final 48 hours" or "Last weekend before the sale ends" — recalibrate rather than repeat.
- 4. **Tie the jacket to a product page.** The model image is the strongest visual asset in the email. A direct link to that jacket (with a name, a price, and a "Shop This Look" overlay) would convert far better than a generic sale link.
- 5. **Subject Alt A:** `Members only: 20% off your next $150+ order`
- 6. **Subject Alt B:** `Your XPLR perk is live — 20% off, ends Sunday`
- 7. **Preheader Alt A:** `Memorial Day weekend starts now. Stack your savings before 5.25.`
- 8. **Preheader Alt B:** `Free shipping + 20% off — your XPLR Pass rate, valid through Sunday.`

### 3. Rendering & Accessibility

**CSS Syntax Error — missing `font-family:` property name (affects all clients):**

```css
/* Broken — orphaned font stack, no property declaration */
table, td {
  'HelveticaNeue-Medium', 'Helvetica Neue Medium', 'Helvetica Neue', Helvetica, Arial, sans-serif;
}
h1, h2, h3, h4, h5, h6 {
  'HelveticaNeue-Medium', ... !important;
}
```

Both rules omit `font-family:`. Every CSS parser will silently ignore these declarations; fallback system fonts will render instead.

**Invalid inline style on `<body>` — missing semicolon:**

```html
style="font-family:..., sans-serif margin: 0; padding: 0;"
```

No `;` separates the font-family value from `margin: 0`. The `margin` and `padding` declarations are swallowed as part of the font-family value and never applied.

**`align-content` on `<td>` elements:**

```css
.disclaimer { align-content: center !important }
```

`align-content` is a flexbox/grid property and has no effect on table cells. Intended behavior is `text-align: center`.

**Unclosed media query block:**

The `@media only screen and (max-width: 480px)` block in the second `<style>` tag is missing its closing `}` before `</style>`. Styles after the last declared rule may leak outside the media query in permissive parsers.

**Missing alt text on spacer image (QA confirmed):**

```
src: https://image.e.thenorthface.com/lib/.../TNF-spacer-100px_01.jpg
```

Spacer images must carry an explicit `alt=""` to silence screen-reader announcements. Currently absent.

Missing headers expose the send to spam-folder sorting and potential enforcement action at both providers.

**Authentication-Results not captured:**

78% of the plain-text part (5,461 / 6,996 chars) is URLs. A usable plain-text alternative is required by CAN-SPAM; a dump of redirect URLs does not satisfy that requirement and is a spam-filter signal.

CAN-SPAM physical address and unsubscribe link are assumed present (not visible in truncated source) — confirm in full source review.

### 6. Email-to-Site Continuity

UTM parameters on CTA links could not be confirmed — all 27 links route through the SFMC click-redirect domain and were not probed. At minimum, verify that decoded destination URLs carry:
