## Technical Audit

## 1. Technical Summary
The email is a Salesforce Marketing Cloud send (`click.e.thenorthface.com/?qs=…`, `image.e.thenorthface.com`) with invalid inline and head CSS and malformed table nesting. Authentication and unsubscribe headers could not be verified because the relay didn't capture them, and the HTML source is truncated before the footer.

## 2. Link & Tracking Issues
- **Probe coverage:** All 46 tracking links were skipped by the QA probe because they are click-redirect domains. Destination validity and redirect behavior are unverified.
- **Hidden honeypot link:** The first link in the body wraps a 1×1 hidden image: `<a href="https://click.e.thenorthface.com/?qs=ABp7Im…"><img src=".../honeypot_pixel.png" width="1" height="1" style="display: none;"></a>`. This looks like an intentional bot or scanner trap. It is not a defect, but it will register clicks from link-scanning security gateways unless the sender filters them.
- **Plain-text part:** QA reports 8653 of 10248 characters (about 84%) are URLs. This is from the long encoded `qs=` tokens and is a spam-filter signal.

## 3. Rendering & Accessibility
- **Invalid body inline style:** `<body … style="font-family:'HelveticaNeue-Medium', …, Arial, sans-serif margin: 0; padding: 0;">` has no `;` after `sans-serif`. The `font-family` declaration is malformed and `margin`/`padding` are dropped from the inline style. The `<style>` block's `body { margin: 0 auto !important; padding: 0 !important }` partly covers this.
- **Missing property names in head CSS:** `table, td { 'HelveticaNeue-Medium', … sans-serif; }` and `h1, h2, … h6 { 'HelveticaNeue-Medium', … !important; margin: 0px; }` have no `font-family:` property. The font stack is never applied to tables, cells or headings.
- **Unclosed `@media`:** The `@media only screen and (max-width: 480px) {` block inside the `<!--[if false]><!-->` style tag has no closing `}` before `</style>`. Parsers usually recover, but behavior varies by client.
- **Malformed table nesting:** `<table bgcolor="#f4f4f4" …>` is followed directly by `<table id="backgroundWrapper" …>` with no `<tr><td>` between them. The outer table also lacks `role="presentation"`, `cellpadding` and `cellspacing`. The inner `<table><tr><td>` holding the preheader has no `role="presentation"` either. Screen readers may announce these as data tables.
- **Missing alt text:** `honeypot_pixel.png` has no `alt` (QA flag). The image is `display:none`, so the impact is minimal, but `alt=""` would clear the warning.
- **Good:** `lang="en"`, `<title>`, a viewport meta tag, MSO/VML namespaces and a hidden preheader with `&zwnj;&nbsp;` padding are all present.

## 4. Personalization & Merge Tokens
No issues found. No unresolved merge tokens (`%%…%%`, `{{…}}`, `[FIRST_NAME]`) appear in the visible source. The source is truncated, so the rest of the body is unchecked.

## 5. Compliance (CAN-SPAM, unsubscribe, authentication headers)
- **List-Unsubscribe:** Not found. QA notes the relay may not capture it, so this is unconfirmed rather than a confirmed absence.
- **List-Unsubscribe-Post (RFC 8058):** Not found, with the same caveat. One-click unsubscribe is required by Gmail and Yahoo for bulk senders.
- **Authentication-Results:** Not found, so SPF, DKIM and DMARC alignment for `e.thenorthface.com` are unverified.
- **Footer:** The in-body unsubscribe link and postal address can't be assessed because the source is truncated before the footer.

## 6. Email-to-Site Continuity (UTM params, landing page alignment)
No confirmed issues, but this can't be assessed. All visible links are opaque `click.e.thenorthface.com/?qs=…` redirects, and the probe skipped them. Landing URLs, UTM parameters and alignment with the "Footwear built for holiday adventures" subject cannot be checked.

## 7. Recommendations
1. Fix the `body` inline style by adding `;` after `sans-serif`. Add `font-family:` to the `table, td` and `h1–h6` rules.
2. Close the `@media (max-width: 480px)` block with `}`.
3. Wrap the nested `backgroundWrapper` table in a `<tr><td>` of the outer table. Add `role="presentation"`, `cellpadding="0"` and `cellspacing="0"` to the outer table and the preheader table.
4. Add `alt=""` to `honeypot_pixel.png`.
5. Re-run the audit against raw `.eml` headers (or a direct seed inbox) to confirm `List-Unsubscribe`, `List-Unsubscribe-Post` and SPF/DKIM/DMARC results.
6. Follow a sample of the `click.e.thenorthface.com` links with a redirect-following check to verify the final URLs, UTM parameters and status codes.
7. Re-run the audit on the full, untruncated HTML to cover the footer, merge tokens and remaining links.
