# Memorial Day Sale: Save 25% on select gear
**Score:** 8/10 · **Type:** Email audit · **2026-05-14**
## Executive summary

- This is a clean, competent Memorial Day sale email from The North Face. The hero lands fast: "Up to 25% Off Select Gear" with a hard deadline (ENDS 5.25) and a single CTA. The four-category grid below — Women's, Men's, Footwear, Bags & Gear — covers the store without overwhelming. For an outdoor/activewear shopper, the relevance is immediate.
- The execution is solid but generic. "Up to 25%" is the softest possible framing of a discount — it promises the ceiling, not the floor — and the email never narrows to a hero product or specific item worth clicking for. The XPLR Pass loyalty program appears twice (top banner + footer) but adds noise rather than urgency; it doesn't tell a member what they unlock during this specific sale.
- Verdict: a reliable volume-send that will drive traffic, but leaves a meaningful click uplift on the table by staying category-wide instead of anchoring on one compelling product.

## What's working

- Hard deadline ("ENDS 5.25") is in the hero section — removes the ambiguity of a vague "limited time" framing.
- Visual hierarchy is tight: logo → offer headline → CTA → category grid. The eye moves naturally down.
- Four-category grid does efficient job of routing segments (Women's, Men's, Footwear, Bags) without requiring separate emails.
- No render bugs — images load, text is legible, no broken layout.
- XPLR Pass loyalty callout at the top acknowledges existing members without gate-keeping the offer.

## What's weak

- "Up to 25% off" is a ceiling, not a floor — the weakest possible discount signal; most items are probably 15–20% off at best.
- No hero product. The email is a gateway to a sale page, not a reason to click *now* on something specific.
- The preheader ("Join XPLR Pass™ Loyalty Program | Free Shipping. Points for Rewards.") is a loyalty acquisition pitch — a missed opportunity to reinforce the Memorial Day offer or add an urgency layer.
- Zero social proof: no star ratings, no "bestseller" badge, no "X people bought this today." For a sale send, that's a credibility gap.
- CTA copy "Shop Sale" is interchangeable with every other sale email — no hook.

## Recommendations

- 1. **Lead with a specific hero product** — pull the #1 selling jacket or trail shoe into the hero with a "Was $189 → $141" price anchor. One real product beats four category tiles for click intent.
- 2. **Rewrite the CTA to match the product** — "Shop Trail Shoes" or "Shop Women's Jackets" beats "Shop Sale" every time.
- 3. **Swap the preheader for an urgency hook** — use it to reinforce the deadline or tease the best deal, not recruit new loyalty members.
- 4. **Add a "bestseller" badge or a sold-count callout** to one hero item — social proof on a sale send consistently lifts click rate.
- 5. **Tighten the discount framing** — "Save 25% on trail shoes & activewear" beats "up to 25% off select gear" because it names *what* is on sale.
- **Subject Alt A:** `Save 25% on trail gear — ends Sunday`
- **Subject Alt B:** `Your Memorial Day sale picks are here (ends 5.25)`
- **Preheader Alt A:** `Trail shoes, jackets & bags — sale ends May 25`
- **Preheader Alt B:** `25% off activewear & footwear · XPLR members get free shipping`

### 1. Technical Summary

### 3. Rendering & Accessibility

**Bug — `font-family` property name missing (CSS parse error)**
Two rules in `<style>` omit the property name entirely:
```css
/* as written — invalid */
table, td { 'HelveticaNeue-Medium', 'Helvetica Neue Medium', ... }
h1, h2, h3, h4, h5, h6 { 'HelveticaNeue-Medium', ... !important; margin: 0px; }
```
Both should be `font-family: '...'`. Every conforming CSS parser will ignore these declarations; fallback rendering depends entirely on client defaults.

**Bug — missing semicolon in `<body>` style attribute**
```html
<body style="font-family:'HelveticaNeue-Medium', ..., sans-serif margin: 0; padding: 0;">
```
The semicolon after `sans-serif` is absent. `margin` and `padding` declarations are silently dropped in strict parsers (notably WebKit-based mobile clients).

**Bug — unclosed `@media` block corrupts non-Outlook mobile styles**
Inside the `<!--[if false]><!--> ... <!--<![endif]-->` non-Outlook block, the `@media only screen and (max-width: 480px)` rule set is never closed with a final `}`. All CSS that follows in the same `<style>` tag leaks outside the media query scope in non-Outlook clients.

**Bug — outer `<table>` missing `<tr><td>` wrapper**
The `#backgroundWrapper` table is a direct child of the outer `bgcolor="#f4f4f4"` table with no intervening `<tr><td>`. This is invalid HTML table structure and produces undefined rendering in Outlook (which parses tables strictly).

**`align-content: center` used in email context**
Used on `.disclaimer`, `.showMobile`, and inside the media query. `align-content` is a flexbox/grid property; it has no effect on block or table-cell elements in any major email client. Intent appears to be `text-align: center`.

### 5. Compliance

**[WARN] `List-Unsubscribe` header absent**
Per Google and Yahoo bulk sender requirements (enforced February 2024), all commercial mail to Gmail/Yahoo must include this header. Its absence at the AgentMail relay layer means one-click unsubscribe is non-functional regardless of any footer link in the HTML body.

**[WARN] `List-Unsubscribe-Post` header absent**
RFC 8058 one-click POST mechanism is not present. Gmail's native unsubscribe button relies on this header; without it Gmail may display a degraded or absent unsubscribe prompt, increasing spam complaints.
