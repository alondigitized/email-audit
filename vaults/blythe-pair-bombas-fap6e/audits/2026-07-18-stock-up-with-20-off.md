# Stock Up with 20% Off
**Score:** 8/10 · **Type:** Email audit · **2026-07-18**
## Executive summary

- This is Bombas's first discount-code send in a week-long blitz of product launches — following the Marvel collab, dressy lightweights, All Sport socks, Slouchy Rib socks, and gripper slippers, all within seven days. The email is a tidy four-category catalog (Everyday, Compression, Sport, Dressy) anchored by a "REFRESH YOUR TOP DRAWER" hero, and the creative holds up fine. The layout is clean, the category coverage is logical, and the 20% offer is prominent.
- The problem is structural: the code is COMFORT20 and the body reads "Get 20% off your **first order**." The subject line says "Stock Up with 20% Off" — no asterisk, no qualification. Any existing subscriber who opens this in good faith, prepared to stock up, will find the offer doesn't apply to them. That is not a minor omission; it is the entire email's value proposition gone. Either this is a welcome/acquisition email misdirected to the retention list, or it's a list-wide send with a new-customer code that the majority of recipients cannot redeem. Either way, the conversion engine is broken.
- The catalog format also recycles the structural playbook from the July 11 "Everything New for Summer" send (4/10) — same Women/Men split, same category sweep, same footer CTA block. The 20% offer should have differentiated this; instead it arrives with an exclusion that neutralizes it.

## What's working

- **Hero hierarchy lands immediately** — "REFRESH YOUR TOP DRAWER" fills the top viewport, code is visible above the fold, no scrolling needed to understand the offer.
- **Four-category structure is coherent** — Everyday → Compression → Sport → Dressy covers the range without feeling scattered; cleaner than the July 11 everything-dump.
- **Code is prominent and repeated** — COMFORT20 appears in the hero banner and in the body copy, reducing any chance a reader misses it.
- **Clean render** — no broken images, no overlapping text, no lorem ipsum or empty fields visible.
- **Subject line is under 25 characters** — mobile-friendly, and the verb "Stock Up" signals purchasing intent efficiently.

## What's weak

- **"First order only" buried below the fold, missing from subject** — the subject promises "20% Off" broadly; the email delivers a welcome code that most subscribers on this list cannot use. Bait-and-switch territory.
- **No deadline** — "Stock Up" without any urgency signal (ends Sunday, 48 hours only, etc.) removes the one lever that could force action on a discount email.
- **Catalog format repeats July 11's structure** — this is effectively "Everything New for Summer 2.0" with a coupon stapled on; subscribers who remember that send (4/10) will feel diminishing returns.
- **No social proof** — eight days of daily emails and not a single review count, star rating, or "our bestseller" callout across the entire send.
- **Cadence fatigue** — seventh Bombas email in seven days; "Stock Up" is doing heavy lifting to make this feel different from the six that preceded it.

## Recommendations

- 1. **Fix the offer mismatch first.** If COMFORT20 is genuinely first-order only, this email should not go to the existing subscriber list with "Stock Up with 20% Off" in the subject. Either swap the code for a loyalty offer (10% back in Bee Rewards, member-pricing event) or replace the code entirely with a multi-buy mechanic (e.g., buy 3 packs, save 20%). The category-sweep format actually pairs well with a "buy more, save more" tier — lean into it.
- 2. **Add a deadline.** Any discount email without an expiry is a slow leak. Even "ends Sunday" would double urgency signals.
- 3. **Pick one hero product per gender, link directly.** The Everyday 6-Pack is the highest-utility offer in the grid; make one of them the click magnet, not the category page.
- 4. **Inject one social proof signal.** Pull the bestseller label or a review count into the Everyday section — it's the one category that earns "stock up" behavior, and proof seals it.

- **Subject Alt B:** `Your Sock Drawer Deserves a Refresh (20% Off)`
- **Preheader Alt A:** `Everyday, Compression, Sport, Dressy — all 20% off through Sunday`
- **Preheader Alt B:** `Four categories, one code. COMFORT20 expires soon.`

### 3. Rendering & Accessibility

**Bug — broken mobile CSS selector (missing dot):**
```css
/* @media only screen and (max-width:600px) */
mobile-third { width: 33% !important; max-width: 33% !important; }
```
The leading `.` is missing. This selector targets an element named `mobile-third` (invalid), not `.mobile-third` class elements. Any column using this class will not collapse to one-third width on mobile. The scoped version at `max-width:480px` uses `.mobile-third` correctly, making the behavior inconsistent between breakpoints.

**Minor — duplicate `xmlns` attribute on `<html>`:**
```html
<html xmlns="http://www.w3.org/1999/xhtml" ... xmlns="http://www.w3.org/1999/xhtml">
```
Duplicate attribute is technically invalid XML; harmless in practice since all major email clients ignore it, but should be cleaned up.

**No issues found:** charset declaration, viewport meta, `format-detection`, MSO pixel density, dark mode `color-scheme` meta pair, `role="article"` + `aria-roledescription` + `aria-label` on the wrapper div, `lang`/`dir`/`xml:lang` on both `<html>` and the article div.

### 6. Email-to-Site Continuity (UTM / Landing Page)

**Cannot audit links** — truncated before CTAs. When reviewing full source, verify:
- UTM params present on all destination URLs: `utm_source`, `utm_medium`, `utm_campaign`, and ideally `utm_content` per CTA
- Offer discount rate on landing page matches email claim (see schema conflict below)

**Schema metadata conflict — discount rate mismatch:**
```html
<meta content="Over 25% Off Select Packs" itemprop="description" />
```
Subject line says **"20% Off"**; schema `DiscountOffer` description says **"Over 25% Off Select Packs"**. This structured data surfaces in Gmail's Promotions tab annotation. If the schema value is stale from a prior campaign, Gmail may display the wrong discount to users before they open. Confirm which rate the landing page reflects and align all three (subject, schema, page).

**Secondary schema note:** Schema URL uses `http://schema.org/DiscountOffer` — Gmail prefers `https://schema.org/`. Switch to `https` for reliable Promotions tab rendering.
