# Homepage snapshot · www.adidas.com · 2026-05-14
**Score:** 1/10 · **Type:** Site journey · **2026-05-14**
## Executive summary

- Bro. I opened adidas.com and got a wall. Not a hero, not a Samba drop, not my adiClub points — a security block page with a reference error code and big bold text telling me I can't be here right now. As someone who opens CONFIRMED daily and pre-orders before the hype even lands, getting hard-blocked by my own brand's homepage is a genuinely bad look. Whatever WAF or bot-detection layer adidas is running just fumbled a loyal customer.

## What's working

- **The adidas wordmark and three-stripe logo** render crisply at the top — at least I know whose site broke on me.
- **The error copy is legible** — all-caps bold type is on-brand typographically, even if the message is a disaster.

## What's weak

- **The entire page is a security block** — `Reference Error: 0.6f10f17.1778782178.1e3d12e` and "UNFORTUNATELY WE ARE UNABLE TO GIVE YOU ACCESS TO OUR SITE AT THIS TIME." That's everything I see.
- **No recovery path visible** — there's no retry button, no link to the app, no customer service CTA. I'm just dead-ended.
- **Zero brand experience** — no hero, no product, no offer, no navigation. The block swallows the entire viewport.
- **"A security issue was automatically identified"** — vague and slightly alarming language. Makes me feel flagged, not welcomed.
- **The "What could have caused this?" section** is cut off at the bottom, which means the only actionable text is partially hidden and I'd have to scroll to find it — on an error page.

## Recommendations

- **Tune the WAF/bot-detection rules** so that normal mobile browser sessions from real users don't trip the block — a three-stripe loyalist on CONFIRMED daily should never see this screen.
- **Add a human-facing recovery CTA** on the block page itself: "Open the CONFIRMED app" or "Shop via adidas app" so the session isn't totally lost.
- **Replace the cold error language** ("a security issue was automatically identified") with something warmer — "We hit a snag. Try refreshing or open our app to keep shopping."
- **Surface the adiClub login link** on the block page — if I'm a known member, a sign-in redirect could bypass the block and also confirms I'm a real human.
