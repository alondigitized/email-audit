# adidas by Stella McCartney SS26
**Score:** 7/10 · **Type:** Email audit · **2026-05-27**
## Executive summary

- This email is two emails stitched together and the seam shows. The top half is a genuine editorial — a striking high-fashion hero shot, "BREATHE. FOCUS. GO." as a campaign line, and aspirational copy about the adidas by Stella McCartney SS26 collection. The bottom half is a generic gift card promo ("BUY A $100 GIFT CARD FOR $80") that has nothing to do with the collection above it. The result is a split identity: the fashion-minded subscriber gets a jarring detour into GC upsell territory, and the GC buyer gets no reason to care about Stella McCartney first.

- Hero image is strong — flowing plaid editorial with natural movement reads as premium and on-brand for a high-fashion collab.
- "BREATHE. FOCUS. GO." is a punchy, memorable campaign line that earns its white space.
- Render is clean — no broken images, no overlapping text, layout holds.
- The gift card offer is arithmetically clear: $100 value for $80 is a straightforward, honest deal.
- Subject line names the collaboration and season exactly, which is findable/searchable by anyone who knows the brand.

## What's weak

- No individual products are shown — the entire collection section is one editorial image and three lines of copy with a generic CTA.
- The gift card block is completely disconnected from the Stella McCartney narrative — no bridge copy, no contextual relevance.
- "SHOP NOW" repeated twice does no selling — neither button tells you what you're shopping.
- The preheader ("Explore the latest adidas best sellers.") is placeholder-grade copy that actively fights the elevated tone of the subject line.
- Demographic mismatch for the list: the prior five sends skewed heavily male (AE2, Man Utd, soccer history) — this send needed to be a tighter segment.

- 3. **Make the CTAs specific.** "Shop the Collection" for the collab, "Get the Gift Card" for the GC block. "SHOP NOW" twice in one email is wasted copy.
- 4. **Rewrite the preheader entirely.** It has to match the editorial register of the subject.

### 2. Link & Tracking Issues

us-promotions-vouchers%2Fwhat-should-i-know-about-gift-cards/1/...
```
This is a merge/encoding error in the ESP template. The redirect engine cannot resolve it correctly.

**[FAIL] Destination URL returns 403**
```
https://www.adidas.com/us/help/us-promotions-vouchers/what-should-i-know-about-gift-cards
```
Independently probed; returns HTTP 403. The page either requires auth, is geo-blocked, or has been removed. Both the wrapped and unwrapped variants of this link fail.

**[FAIL] Malformed URL fragment on personalization block**
```

The QA parser flagged an `unknown url type: '/g/c6835498...'` error, indicating the source template contained a relative path (`/g/...`) that was incorrectly prefixed with the dv.adidas.com host rather than resolved against the canonical base. ### 5. Compliance

**[WARN] `List-Unsubscribe` header absent**
Not captured by the AgentMail relay. If genuinely missing from the SMTP envelope, this violates Google/Yahoo 2024 bulk sender requirements for >5k/day senders. Adidas unambiguously qualifies. Needs server-side verification before concluding it's missing vs. relay-stripped.

**[WARN] `List-Unsubscribe-Post` header absent (RFC 8058)**
One-click unsubscribe (required by Google/Yahoo policy) depends on this header pairing with `List-Unsubscribe`. Same caveat — verify at SMTP layer.

**[FAIL] Plain-text MIME part: 0 characters**
No `text/plain` alternative is present. This is a CAN-SPAM soft requirement and a strong deliverability signal. Spam filters score multipart/alternative emails significantly higher than HTML-only sends.
