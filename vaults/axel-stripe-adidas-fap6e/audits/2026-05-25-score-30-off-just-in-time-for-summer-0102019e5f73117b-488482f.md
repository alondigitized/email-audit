# Score 30% off—just in time for summer
**Score:** 8/10 · **Type:** Email audit · **2026-05-25**
## Executive summary

- This is a stripped-down discount blast — nothing more. "END OF MAY SAVINGS" in oversized white type on black, a 30% off hook, three segmented CTAs, and then the footer. Clean execution, but the creative ambition stops at "we have a code." The subject line's "Score" wordplay doubling as the promo code name is the single piece of craft visible in this send.
- The deeper problem is context. This email landed on the same day as the Anthony Edwards 2 "Believe That" send, which also led with 30% off summer staples. That May 25 AE2 email at least had an athlete and a shoe. This version strips all product imagery and repeats the offer — it reads like a re-blast to non-openers, not a standalone campaign. At seven-plus sends in seven days, adidas is burning its list for a mid-range discount that has now appeared twice in 24 hours.
- Structurally sound, strategically redundant. The subscribers still paying attention by send seven deserve better than pure text on a code they've already seen.

## What's working

- **"Score" / SCORE code wordplay** — subject verb doubles as the promo code; the few subscribers who notice it will remember it.
- **Clean render** — no broken images, no layout breakage, no overlapping elements. Deliberately minimal.
- **Segmented CTAs** — three distinct buttons (MEN / WOMEN / KIDS) rather than one generic "Shop Now" reduces decision fatigue at the click point.
- **Short subject line** — 38 characters hits cleanly on mobile without truncation.
- **Offer is fully visible above the fold** — on a small render, the 30% off + code SCORE is legible before any scrolling.

## What's weak

- **Zero product photography** — there is nothing to want. The AE2 email same day had an athlete and a hero shoe; this is just typeset savings language. No visual desire-creation at all.
- **Preheader wastes its real estate** — "Explore the latest adidas best sellers" at the top adds nothing to "Score 30% off—just in time for summer." Inbox preview is a second subject line; this one ignores it.
- **Same-day duplicate offer** — sending the identical 30% off message twice on May 25 signals list-burn, not urgency. Subscribers who ignored the AE2 email aren't going to convert on a plainer version of the same deal.
- **No deadline specificity in the body** — "End of May" sits in the hero headline but the body copy never pins a hard date. Fine print says May 26 midnight, which is oddly specific for a send dated May 25.
- **No adiClub callout** — after four onboarding emails last week pointing to loyalty points, there's no bridge here. Missed chance to layer member pricing or bonus-points framing onto the discount.

## Recommendations

- 1. **Add one hero product shot** — even a single flat-lay of summer sneakers or a lifestyle image makes this email something to aspire to, not just a coupon. Without it, the 30% off offer lands the same as a text SMS.
- 2. **Rewrite the preheader** — currently "Explore the latest adidas best sellers" is a wasted slot. Replace it with copy that extends the subject offer rather than repeating the nav.
- **Preheader Alt A:** `Use code SCORE—full price + sale styles, ends May 31.`
- **Preheader Alt B:** `Shorts, tees, sneakers—30% off sitewide with code SCORE.`
- 3. **Add a hard deadline in the body** — "Limited time" is not urgency. "Ends May 31 at midnight" is.
- 4. **Don't send this on the same day as AE2** — stagger this as a Day+1 or Day+2 re-engagement send to non-openers. As a standalone send on May 25 it cannibalizes the AE2 email and signals list fatigue.
- 5. **Tie it to adiClub** — one line like "adiClub members get an extra 5% on top" creates a reason for loyalty members to prefer opening adidas emails over competitor noise.
- **Subject Alt A:** `End of May: 30% off with code SCORE`
- **Subject Alt B:** `Your summer wardrobe, 30% off — code SCORE`

### 2. Link & Tracking Issues

**[FAIL] Broken redirect — unknown URL type**

The click-tracking wrapper at `dv.adidas.com` is resolving to a relative-style path instead of an absolute URL:


The outer redirect URL is valid (`https://dv.adidas.com/o/794b4f7d...`), but the decoded destination is a bare `/g/...` path with no hostname. Any subscriber clicking this link lands on a broken page or gets a redirect error. This is the highest-priority fix before any resend.

### 3. Rendering & Accessibility

**[WARN] Six HTTP image sources (same asset, repeated)**

The arrow icon `b0c011a2-d468-414b-a8a2-8595b3ec7b34.jpg` is referenced six times over plain HTTP:

Gmail, Outlook.com, and Apple Mail all block mixed-content HTTP images by default. All six instances should use `https://`.

**[WARN] Two images missing `alt` text**

- Dynamic offer image: `https://dv.adidas.com/o/794b4f7d-a584-4a99-8cee-46fa44cc9181?...`
- Tracking pixel / spacer: `http://click.comms.adidas.com/CI0/0102019e5f73117b-...`

**Note on font declarations:** `@font-face` rules for `AdihausDIN` and `AdineuePRO` declare only local system fallbacks (`Arial`, `Helvetica`, `Calibri`) — no remote font URLs. This is intentional for email deliverability (no external font requests), but the font names in `font-family` declarations will never actually resolve. The CSS is harmless but misleading; the fallback stack is doing all the work.

### 5. Compliance

**[WARN] `List-Unsubscribe` header not found**

CAN-SPAM and Gmail/Yahoo 2024 bulk-sender requirements mandate a `List-Unsubscribe` header. The QA note flags this as potentially dropped by the AgentMail relay, but the absence must be confirmed at the MTA level before treating as a false negative. If genuinely absent, this is a deliverability and compliance risk.

**[WARN] `List-Unsubscribe-Post` header not found (RFC 8058)**

One-click unsubscribe (required by Gmail/Yahoo for senders >5k/day) depends on this header pairing with `List-Unsubscribe`. Absent together, bulk send reputation will degrade.

**[WARN] `Authentication-Results` header not captured**

SPF/DKIM pass/fail status is unknown. The sending domain `us-news.comms.adidas.com` is a subdomain of `comms.adidas.com` — alignment depends on the DKIM `d=` value matching the envelope domain. Cannot clear without raw header access.

The HTML does include `<meta name="ROBOTS" content="NOINDEX, NOFOLLOW">` and `<meta name="referrer" content="no-referrer">` — both correct for email.
