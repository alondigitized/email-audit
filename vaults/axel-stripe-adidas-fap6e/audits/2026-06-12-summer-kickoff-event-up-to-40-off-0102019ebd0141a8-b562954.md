# Summer Kickoff Event: Up to 40% off
**Score:** 10/10 · **Type:** Email audit · **2026-06-12**
## Executive summary

- This is the Summer Kickoff Event email — a clean, on-brand send with a bold black hero, a clear 40% off offer, and three gender-segment CTAs. The structure is familiar because it IS familiar: this is nearly beat-for-beat the same email adidas sent on June 3 (same headline, same black background, same red graphic element, same tripartite CTA block). If you got that one, this one lands as a déjà vu, not a reminder.
- The second module — STRAVA X ADICLUB — is actually the most interesting thing in the email. Bundling a Strava subscription into adiClub is a genuinely differentiated loyalty hook, and it's been buried below three sale CTAs like an afterthought. That's a missed opportunity.
- The single biggest structural failure is the absence of a deadline. "STARTS NOW" tells you nothing about when it ends. No urgency, no close date, no "ending Sunday" — the 40% off just floats in the void.

## What's working

- **Hero hierarchy is clean.** "SUMMER KICKOFF EVENT" → "UP TO 40% OFF STARTS NOW" lands in the right order at the right scale.
- **Subject line is short and clear.** 36 characters, reads fine on mobile, no spam signals.
- **Three-segment CTA block is scannable.** Men / Women / Kids in a clear vertical stack — easy to self-select.
- **STRAVA X ADICLUB is a genuine differentiator.** Unlocking a Strava subscription via adiClub is a specific, tangible benefit that goes beyond a generic markdown.
- **Render is clean.** No broken images, no overlap, no junk text leaking into the body.

## What's weak

- **Creative recycling is visible.** The June 3 "Score big on the best gear, now up to 40% off" email was structurally and visually identical — same offer, same layout, same black hero. This feels like the same file with a new subject line.
- **No deadline anywhere.** "STARTS NOW" is not urgency. There is no end date, no "Event ends Sunday," nothing to motivate opening or clicking today vs. next week.
- **No product imagery in the sale block.** The entire top section is typography and a flag-motif graphic. You can't see what's on sale.
- **Preheader repeats the offer.** "Start summer off right by shopping new favorite styles for up to 40% off" echoes the 40% off claim from the subject — wasted preheader real estate.
- **STRAVA module is buried.** The most distinctive value prop in this email sits below three generic CTAs where a significant share of recipients never reach it.

## Recommendations

- 1. **Add a deadline.** One line — "Event ends June 15" or a countdown-style callout — transforms the whole email from a passive browse invitation into an action trigger. This is the single biggest lift available.
- 2. **Show a product.** Swap the all-typography hero for a hero that includes three or four actual product shots inline with the MEN / WOMEN / KIDS CTAs. Give the eye something to covet.
- 3. **Move STRAVA X ADICLUB above the fold (or give it its own send).** It's too good to bury. If the adiClub audience overlaps with runners/trackers, this module deserves its own send — not second billing to a generic sale.
- 4. **Rewrite the preheader to add new information.** The current preheader repeats the offer; use it to name the category or add a specific product callout.

- **Preheader Alt A:** `New markdowns on men's, women's and kids' favorites — just added.`

## Technical Audit — adidas "Summer Kickoff Event" Email

---

### 1. Technical Summary

One confirmed broken redirect renders a CTA non-functional; eight arrow-icon images are served over HTTP and will be blocked by major clients. Plain-text fallback is absent, and compliance headers (List-Unsubscribe, SPF/DKIM) could not be verified due to AgentMail relay capture limitations.

---

### 2. Link & Tracking Issues

**[FAIL] Broken redirect — one CTA dead**

The click tracker at `https://dv.adidas.com/o/2e158291-c472-4490-a621-142b584c271f` responds with a redirect to a bare path:

```
/g/2e158291-c472-4490-a621-142b584c271f?txn=29c77200-6774-11f1-9fcb-3efb318f62ec
```

QA reports: `Link error: unknown url type`. A relative-path redirect that omits the scheme and host resolves correctly in browsers via the `Location` header base URL, but the path `/g/…` is not a recognized resolvable scheme for non-browser HTTP clients, and any non-standard redirect handler (email pre-fetchers, some mobile clients) will fail silently. Confirm the adidas redirect service at `dv.adidas.com` is returning a fully-qualified `https://` URL in its `Location` header for this UUID.

**[INFO] 36 tracking links not probed**

All click-redirect domains (`click.comms.adidas.com`, `dv.adidas.com`) were skipped. Destination URL integrity and UTM parameters cannot be confirmed for those links from this audit alone.

---

### 3. Rendering & Accessibility

**[FAIL] 8 HTTP image sources — same asset, same file**

The arrow icon (`b0c011a2-d468-414b-a8a2-8595b3ec7b34.jpg`) is referenced 8 times via HTTP:

```
src="http://image.link.adidas.com/lib/fe6515707c62007e7715/m/3/b0c011a2-d468-414b-a8a2-8595b3ec7b34.jpg"
```

Gmail, Apple Mail, and Outlook 2019+ block mixed-content images. All 8 instances will render as broken images in those clients. Fix: replace `http://` with `https://` on `image.link.adidas.com`.

**[WARN] Additional HTTP image — tracking pixel served insecurely**

```
src="http://click.comms.adidas.com/CI0/0102019ebd0141a8-b562954d-e51e-4225-a4a0-c5160094cac7-000000/Y1ikChWYuZD_5G0ksO-NCCzgt..."
```

Open-tracking pixel also on HTTP. Same blocking risk; also missing `alt` text (see below).

**[WARN] Missing alt text — 2 images**

- `https://dv.adidas.com/o/2e158291-c472-4490-a621-142b584c271f` — no `alt` attribute
- `http://click.comms.adidas.com/CI0/0102019ebd0141a8…` — no `alt` attribute

Screen readers and image-off rendering modes will produce blank gaps. CTA images should carry descriptive alt; tracking pixels should carry `alt=""` (empty string, not omitted).

**[INFO] Custom fonts fall back unconditionally**

`@font-face` declarations for `AdihausDIN` and `AdineuePRO` reference only `local()` sources (Arial, Helvetica, Calibri). No remote font URL is loaded. These fonts will never render unless pre-installed on the recipient's device. This appears intentional but means brand typography is never delivered via email.

**[INFO] Duplicate `@font-face` block**

The font declarations appear twice — once in the main `<style>` block and once in a `<!-- For Yahoo Android App -->` comment-wrapped block. No functional impact, but adds unnecessary CSS weight.

### 5. Compliance (CAN-SPAM, Unsubscribe, Authentication)

**[WARN] `List-Unsubscribe` header — not captured**

QA did not detect this header. This is flagged as a possible AgentMail relay artifact, not a confirmed absence. However, if the header is genuinely missing:

- Gmail and Yahoo (as of Feb 2024 bulk sender requirements) will suppress the native unsubscribe UI for senders over 5,000/day.
- Deliverability scoring will be negatively affected.

Verify the raw SMTP headers on a direct delivery (outside the relay) to confirm presence of:
```
List-Unsubscribe: <mailto:...>, <https://...>
```

**[WARN] `List-Unsubscribe-Post` (RFC 8058) — not captured**

One-click machine unsubscribe is a Yahoo/Google bulk sender requirement for >5k/day. Same caveat as above re: relay capture — verify in raw headers.

**[WARN] `Authentication-Results` — not captured**

SPF, DKIM, and DMARC pass/fail status cannot be determined from this relay capture. The sending domain `us-news.comms.adidas.com` should be covered by adidas's DMARC policy; confirm with a direct header inspection or a mail-tester.com run.

**[INFO] `ROBOTS: NOINDEX, NOFOLLOW` and `referrer: no-referrer` present**

Both meta tags are in the `<head>`. No issues.
