### 3. Rendering & Accessibility

**Google Fonts `<link>` tag will not load in email.**
```html
<link href="https://fonts.googleapis.com/css?family=Roboto+Condensed:400,700..." rel="stylesheet">
```
Gmail (webmail and iOS/Android apps), Apple Mail, and all Outlook desktop versions strip or block external `<link>` stylesheets. The font will silently fall back to the client's default sans-serif. If the design depends on Roboto Condensed for sizing or layout, rendered output will differ from QA screenshots.

**Invalid DOM structure in preheader block.**
```html
<table ...>
  <tr><td>
    <table ...>
      <!--[if !mso 9]><!-->
      <div style="mso-hide:all;">
        <tr>  <!-- div is not a valid parent of tr -->
          <td ...>preheader text</td>
        </tr>
      </div>
```
A `<div>` wrapping a `<tr>` inside a `<table>` is invalid in both HTML and XHTML. Most parsers will attempt to recover by moving the `<div>` outside the table, which may duplicate or displace the preheader content in clients with strict parsers (Yahoo Mail, some Outlook versions).

**Viewport meta uses semicolon separators — non-standard.**
```html
<meta name="viewport" content="width=device-width; initial-scale=1.0; maximum-scale=1.0; user-scalable=no;" />
```
The CSS spec requires commas, not semicolons, as separators. Most mobile browsers tolerate semicolons, but this is technically malformed and may fail in stricter WebKit builds.

**`user-scalable=no` / `maximum-scale=1.0` — accessibility violation.**
Blocks pinch-to-zoom. This violates WCAG 2.1 SC 1.4.4 (Resize Text) and is a common rejection criterion in accessibility audits. Remove both attributes.

**Missing `lang` attribute on `<html>`.**
```html
<html xmlns="http://www.w3.org/1999/xhtml">
```
No `lang="en"` is present. Screen readers cannot infer the document language for correct pronunciation. Add `lang="en"` (or the appropriate locale code).
